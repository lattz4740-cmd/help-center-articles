ការរៀបចំ Google Cloud ដោយ​ស្វ័យប្រវត្តិ

ទិដ្ឋភាព​រួម​

Outline Manager រួម​បញ្ចូល​មុខងារ​ដែល​អាច​ឱ្យ​អ្នក​កំណត់​រចនាសម្ព័ន្ធ​ម៉ាស៊ីន​មេ Outline ដោយ​ស្វ័យប្រវត្តិ​នៅ​លើ​ម៉ាស៊ីន​មេ​ដែល​ដំណើរការ​លើ Google Cloud។ ប្រសិន​បើ​អ្នក​សម្រេច​ថា​ប្រើប្រាស់​មុខងារ​នេះ Outline Manager នឹង​ស្នើ​ឱ្យ​អ្នក​ចូល​ដោយ​ប្រើ​គណនី Google របស់​អ្នក ដែល​នឹង​ផ្ដល់​ការអនុញ្ញាតOAuth ជាក់លាក់​ដល់​ការដំឡើង Outline Manager លើ​ឧបករណ៍​របស់​អ្នក​សម្រាប់​គោល​បំណង​កំណត់​រចនាសម្ព័ន្ធ​គណនី Google Cloud របស់​អ្នក។

ប្រសិន​បើ​អ្នក​មិន​ចង់​ផ្ដល់​ការអនុញ្ញាត​ទាំង​នេះ​ទេ អ្នក​អាច​អនុវត្ត​តាម​ការណែនាំ​អំពី​ការរៀបចំ​កម្រិត​ខ្ពស់​នៅ​ក្នុង Outline Manager ដើម្បី​ដំណើរការ Outline លើ Google Cloud Platform។

ការអនុញ្ញាតដែលត្រូវផ្ដល់ឱ្យ​

ដើម្បី​ផ្ដល់​ការរៀបចំ​ដោយ​ស្វ័យប្រវត្តិ Outline Manager តម្រូវ​ឱ្យ​មាន​ការអនុញ្ញាត​ដូច​ខាង​ក្រោម​ពី​គណនី Google របស់​អ្នក។

Google Cloud Platform​

  • មើល និង​គ្រប់គ្រង​ធនធាន​ Google Compute Engine របស់​អ្នក
  • មើលទិន្នន័យរបស់អ្នក​នៅលើសេវាកម្មនានា​របស់ Google Cloud និងមើលអាសយដ្ឋានអ៊ីមែល​នៃគណនី Google របស់អ្នក

ព័ត៌មានគណនី​មូលដ្ឋាន​

  • មើល​អាសយដ្ឋានអ៊ីមែល​ចម្បង​នៃគណនី Google របស់អ្នក
  • ភ្ជាប់​អ្នក​ជាមួយព័ត៌មានផ្ទាល់ខ្លួនរបស់អ្នក​នៅលើ Google

សិទ្ធិ​ចូល​ប្រើ​បន្ថែម​

  • គ្រប់គ្រង​គម្រោង Cloud Platform របស់​អ្នក
  • មើល និង​គ្រប់គ្រង​គណនី​ទូទាត់​វិក្កយបត្រ​ Google Cloud Platform របស់​អ្នក
  • គ្រប់គ្រង​ការ​កំណត់​រចនាសម្ព័ន្ធ​សេវាកម្ម Google API របស់​អ្នក

ការអនុញ្ញាត​ទាំង​នេះ​អនុញ្ញាត​ឱ្យ​យើង​ដំណើរការ​មុខងារ​កម្រិត​ខ្ពស់​សម្រាប់​គ្រប់គ្រង​ម៉ាស៊ីន​មេ Outline របស់​អ្នក ដែល​រួម​មាន៖

  • ការអនុញ្ញាត​ឱ្យ​អ្នក​ជ្រើសរើស​គណនី​ទូទាត់​វិក្កយបត្រ​ត្រឹមត្រូវ
  • ការបង្កើត​គម្រោង​ថ្មី ដើម្បី​រៀបចំ​ម៉ាស៊ីន​មេ Outline របស់​អ្នក
  • ការផ្ដល់​បញ្ជី​មជ្ឈមណ្ឌល​ទិន្នន័យ​ដែល​អាច​ប្រើ​បាន
  • ការបង្កើត​ម៉ាស៊ីន​និម្មិត​ថ្មី​ដើម្បី​ដំណើរការ Outline
  • ការកំណត់​រចនាសម្ព័ន្ធ​ម៉ាស៊ីន​និម្មិត​ថ្មី​ដោយ​ប្រើ Outline

ការដកហូត​ការអនុញ្ញាត​

អ្នក​អាច​ដក​ហូត​សិទ្ធិ​ចូល​ប្រើប្រាស់ Google Cloud Platform សម្រាប់ Outline Manager ដោយ​ចូល​ទៅ​កាន់​គណនី​របស់​ខ្ញុំ។ ប្រសិន​បើ​អ្នក​ដក​ហូត​សិទ្ធិ​ចូល​ប្រើប្រាស់ ម៉ាស៊ីន​មេ​ទាំងឡាយ​ដែល​អ្នក​បាន​បង្កើត​ដោយ​ប្រើ​ការរៀបចំ​ដោយ​ស្វ័យប្រវត្តិ​នឹង​នៅ​តែ​ដំណើរការ​ដដែល ប៉ុន្តែ​នឹង​លែង​បង្ហាញ​នៅ​ក្នុង Outline Manager ទៀត​ហើយ។ ដើម្បី​ស្ដារ​សិទ្ធិ​ចូល​ប្រើប្រាស់​វិញ គ្រាន់​តែ​ភ្ជាប់​ទៅ Google Cloud Platform ឡើង​វិញ ដោយ​ចាប់ផ្ដើម​លំហូរ​រៀបចំ​ដោយ​ស្វ័យប្រវត្តិ។

ការរៀបចំ​គម្រោង Outline​

ការរៀបចំ Google Cloud ដោយ​ស្វ័យប្រវត្តិ​ប្រើប្រាស់​គម្រោង Google Cloud តែ​មួយ ដើម្បី​រៀបចំ​ម៉ាស៊ីន​មេ Outline របស់​អ្នក។ គម្រោង​នេះ​ត្រូវ​បាន​បង្កើត​ក្នុង​អំឡុង​ពេល​ប្រើប្រាស់​ការៀបចំ​ដោយ​ស្វ័យប្រវត្តិ​លើក​ដំបូង ដោយ​មាន ID គម្រោង​ដែល​បាន​ណែនាំ ដែល​ចាប់ផ្ដើម​ដោយ “Outline-” បន្ទាប់​មក​ជួរ​អក្សរ​ដែល​រួម​មាន​តួ​អក្សរ​ចៃដន្យ។ អ្នក​អាច​ជ្រើសរើស ID គម្រោង​ផ្សេង​បាន​នៅ​ពេល​បង្កើត ប្រសិន​បើ​អ្នក​ចង់។ គម្រោង​នេះ​នឹង​ត្រូវ​បាន​ដាក់​ឈ្មោះ​ថា “ម៉ាស៊ីន​មេ Outline”។

គណនី​ទូទាត់​វិក្កយបត្រ​

គម្រោង Google Cloud តម្រូវ​ឱ្យ​មាន “គណនី​ទូទាត់​វិក្កយបត្រ” ដែល​បាន​ភ្ជាប់ ដែល​កំណត់​ព័ត៌មាន​អំពី​ការទូទាត់​ប្រាក់។ នៅ​ពេល​អ្នក​ប្រើប្រាស់​ការរៀបចំ Google Cloud ដោយ​ស្វ័យប្រវត្តិ​លើក​ដំបូង អ្នក​នឹង​ត្រូវ​បាន​ស្នើ​ឱ្យ​ផ្ដល់​គណនី​ទូទាត់​វិក្កយបត្រ ដើម្បី​ភ្ជាប់​ជាមួយ​ម៉ាស៊ីន​មេ Outline របស់​អ្នក។ ជួនកាល ម៉ាស៊ីន​មេ​នឹង​ឈប់​ដំណើរការ ដោយសារ​មាន​បញ្ហា​ពាក់ព័ន្ធនឹង​គណនី​ទូទាត់​វិក្កយបត្រ។ ក្នុង​ករណី​នេះ អ្នក​គួរ​តែ​ចូល​Google Cloud Console, កំណត់​ទីតាំង​គម្រោង Google Cloud ដែល​បាន​ភ្ជាប់​ជាមួយ Outline (ឈ្មោះ​ថា “ម៉ាស៊ីន​មេ Outline”) និង​ធ្វើ​បច្ចុប្បន្នភាព​ការកំណត់​ការទូទាត់​វិក្កយបត្រ។

ការលុប​ម៉ាស៊ីន​មេ​

ប្រសិន​បើ​អ្នក​ចង់​លុប​ម៉ាស៊ីន​មេ​របស់​អ្នក​ដែល​បាន​បង្កើត​ឡើង​ដោយ​ប្រើប្រាស់​ការរៀបចំ​ដោយ​ស្វ័យប្រវត្តិ វិធី​ងាយ​បំផុត​ដើម្បី​ធ្វើ​ដូច្នោះ​គឺ​ពី​ក្នុង Outline Manager។ ទោះបី​ជា​យ៉ាង​ណា​ក៏​ដោយ ប្រសិន​បើ​អ្នក​ចង់​លុប​ម៉ាស៊ីន​មេ​ដោយ​ខ្លួន​ឯង អ្នក​អាច​ចូលGoogle Cloud Console, ស្វែងរក​គម្រោង​ដែល​ត្រូវ​បាន​បង្កើត​ក្នុង​អំឡុង​ពេល​រៀបចំ​ដំបូង (ឈ្មោះ​ថា “ម៉ាស៊ីន​មេ Outline”) រួច​លុប​ធនធាន​នៅ​ទីនោះ ឬ​បិទ​គម្រោង​នេះ។
