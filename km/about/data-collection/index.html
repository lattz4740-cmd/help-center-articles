ការប្រមូល​ព័ត៌មាន និង​ទិន្នន័យ

Outline មិន​ប្រមូល​ព័ត៌មាន​ផ្ទាល់​ខ្លួន​ទេ ប្រសិន​បើ​អ្នក​មិន​ជ្រើសរើស​ធ្វើ​ការផ្ដល់​ព័ត៌មាន​ដូច​នេះ។ Outline ក៏​មិន​ប្រមូល​ព័ត៌មាន​អំពី​គេហ​ទំព័រ​ដែល​អ្នក​ចូល​មើល ឬ​ក៏​មនុស្ស​ឬ​អ្វី​ដែល​អ្នក​ទាក់ទង​ជាមួយ​ដែរ។

ប្រសិនបើ​អ្នកកំពុង​បង្កើត ឬ​ចូលគណនី​តាម​ក្រុមហ៊ុនផ្ដល់សេវាប្រព័ន្ធ​ពពកភាគីទីបី​តាមរយៈ Outline Manager យើង​មិនទទួល​បាន​ព័ត៌មាន​ទាំងឡាយ​ដែល​អ្នកផ្ដល់ឱ្យ​ក្រុមហ៊ុនផ្ដល់សេវាប្រព័ន្ធ​ពពក​ភាគីទីបី ដូចជា​អាសយដ្ឋាន​អ៊ីមែល ឈ្មោះ ព័ត៌មាន​ទូទាត់​វិក្កយបត្រ និង​ព័ត៌មាន​លម្អិតអំពី​ការទូទាត់ប្រាក់​នោះទេ។

ព័ត៌មាន​ដែលយើង​ទទួលបាន​ដោយ​ស្វ័យប្រវត្តិ​

IP ម៉ាស៊ីនមេ Outline ត្រូវបាន​ប្រមូល​ដោយ Quay.io និង​អាចឱ្យ​យើង​ចូលប្រើ​បាន នៅពេល​ម៉ាស៊ីនមេ​ធ្វើបច្ចុប្បន្នភាព​ដោយ​ស្វ័យប្រវត្តិ​ដោយប្រើ​ការកែលម្អ​មុខងារ និង​សុវត្ថិភាព​ចុងក្រោយ​បំផុត។ IP ម៉ាស៊ីនមេ​អាច​កំណត់​ក្រុមហ៊ុនផ្ដល់សេវា​ម៉ាស៊ីនមេ​លើ​ប្រព័ន្ធ​ពពក និង​ទីក្រុង​ដែល​ម៉ាស៊ីនមេ Outline ត្រូវ​បាន​រៀបចំ ប៉ុន្តែ​មិន​ផ្ដល់​ព័ត៌មាន​អំពី​អ្នក​ដែលកំពុង​ដំណើរការ​ម៉ាស៊ីនមេ ឬ​អ្នក​ដែលកំពុង​ចូលប្រើ​ម៉ាស៊ីនមេនោះ​ឡើយ។

ព័ត៌មាន​ដែលយើង​ទទួលបាន តែនៅពេល​អ្នកជ្រើសរើស​ចែករំលែក​ប៉ុណ្ណោះ​

  1. មេទ្រិកនៃ​ការប្រើប្រាស់

ម៉ាស៊ីនមេ Outline នីមួយៗ​ប្រមូល​ដោយស្វ័យប្រវត្តិនូវ​ចំនួនបៃ​ដែលបាន​ផ្ទេរ រយៈពេលដែល​អ្នកប្រើប្រាស់​ត្រូវបាន​ភ្ជាប់ទៅ​ម៉ាស៊ីនមេ ប្រទេសនិង​ប្រព័ន្ធស្វយ័ត​ប្រភពដើម​នៃ​ព័ត៌មាន​ផ្ទៀងផ្ទាត់​ដែល​បានប្រើ និង​ថាតើមុខងារ​ទាំងឡាយ​ត្រូវបាន​បើកឬបិទ ក្នុងរយៈពេល​មួយម៉ោង​ចុងក្រោយ និង​ផ្អែកលើ​លេខកូដ​ចូលប្រើ។ ខ្លឹមសារ​ទំនាក់ទំនង និង​ទិន្នន័យ​មេតា​ទាំងឡាយដែលបញ្ជាក់​អត្តសញ្ញាណ​បុគ្គល (ឧ. ការចូលគណនី អ៊ីមែល លេខសម្គាល់​ឧបករណ៍ ។ល។) សុទ្ធតែមិន​ត្រូវបានចុះកំណត់ហេតុទេ។ មេទ្រិក​ទាំងអស់​ត្រូវ​បាន​ភ្ជាប់​ទៅ​លេខកូដសម្គាល់​ម៉ាស៊ីនមេ។ ការណែនាំ​សម្រាប់​ការផ្លាស់ប្ដូរ​លេខកូដ​សម្គាល់​ម៉ាស៊ីនមេ​អាចរកបាននៅទីនេះ។

តាម​លំនាំដើម ម៉ាស៊ីនមេ Outline មិន​ចែករំលែក​មេទ្រិក​ទាំងនេះ​ជាមួយ​ក្រុមការងារ Outline ទេ។ ប្រសិនបើ​អ្នកគ្រប់គ្រង​ម៉ាស៊ីនមេ​ជ្រើសរើសច្បាស់ៗថា​ចែករំលែក​មេទ្រិក​នៃ​ការប្រើប្រាស់ ព័ត៌មាន​នេះ​នឹង​ត្រូវ​បានផ្ញើ​ដោយ​សុវត្ថិភាព​ទៅកាន់​ក្រុមការងារ Outline ជា​រៀងរាល់​ម៉ោង។ ក្រោយ​ពេល 60 ថ្ងៃ មេទ្រិក​នៃ​ការប្រើប្រាស់​នឹង​ត្រូវ​បាន​បូកសរុបទៅ​ជាកម្រិត​ប្រទេស។ អ្នកគ្រប់គ្រង​ម៉ាស៊ីនមេ​អាច​ផ្លាស់ប្ដូរ​ចំណូល​ចិត្ត​ក្នុងការ​ចែករំលែក​មេទ្រិក​នៃ​ការប្រើប្រាស់​របស់​ពួកគេ​នៅពេលណាក៏បាន ដោយ​ចូលទៅ​កាន់​ម៉ឺនុយ ‘ការ​កំណត់’ នៅ​ក្នុង Outline Manager។
