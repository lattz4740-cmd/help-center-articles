វាក្យសព្ទ

តើ VPN គឺជាអ្វី?​

បណ្តាញ​ឯកជននិម្មិត (VPN) គឺជា​ការតភ្ជាប់​ឯកជន​រវាង​ឧបករណ៍​របស់អ្នក និង​ម៉ាស៊ីនមេ​បង្ហោះ។ នៅពេល​អ្នកប្រើប្រាស់ VPN ចរាចរណ៍​របស់អ្នក​ត្រូវបាន​លាក់​ពី​ក្រុមហ៊ុន​ផ្ដល់សេវា​អ៊ីនធឺណិត។ អ្នកប្រហែល​ចង់ប្រើប្រាស់ VPN នៅក្នុង​សេណារីយ៉ូ​ដូចខាងក្រោម៖

  • ការពារ​ទិន្នន័យ​របស់អ្នក នៅពេល​ប្រើប្រាស់​បណ្ដាញ Wi-Fi សាធារណៈ
  • រក្សា​ទិន្នន័យរុករក​របស់អ្នក​ជាឯកជន​ពី​ក្រុមហ៊ុន​ផ្ដល់សេវា​អ៊ីនធឺណិតរបស់អ្នក និងទី​ភ្នាក់ងារ​រដ្ឋាភិបាល
  • ចូលប្រើ​ខ្លឹមសារ​ដែលគ្មានការចាប់ពិរុទ្ធពី​ប្រភព​ផ្សេងៗនៅជុំវិញពិភពលោក

តើ Outline ខុសពី VPN ធម្មតា​យ៉ាងដូចម្តេច?​

ក្រុមហ៊ុនផ្តល់សេវាអ៊ីនធឺណិតអាចចាប់បាន និង​ទប់ស្កាត់ VPN ធម្មតាយ៉ាងងាយស្រួល ដោយស្គាល់ប្រូតូកូលសុវត្ថិភាពទូទៅ និង/ឬលំនាំបរិមាណចរាចរណ៍។ Outline មានលក្ខណៈធន់ជាង VPN ធម្មតា ដោយសារ​វា​ត្រូវ​បាន​បង្កើត​ឡើង​ដោយ​ប្រើប្រាស់​ប្រូតូកូល​ដែល​ត្រូវ​បាន​រចនាឡើង​ឱ្យ​គេ​ពិបាក​ចាប់​បាន ដូច្នេះកាន់​តែ​ពិបាក​ទប់ស្កាត់។ Outline ធន់នឹង​ទម្រង់​នៃ​ការចាប់​ពិរុទ្ធ​ដែល​ស្មុគស្មាញ រួមទាំង​ការទប់ស្កាត់​ផ្អែក​តាម​បណ្ដាញ និង​ការទប់ស្កាត់ IP ជាដើម។

តើម៉ាស៊ីនមេ Outline គឺជាអ្វី?​

ម៉ាស៊ីនមេ Outline ដំណើរការ VPN ដែលអ្នកប្រើប្រាស់ដែលមានការអនុញ្ញាតនឹងភ្ជាប់ទៅ។ ប្រសិនបើអ្នកកំពុងបង្កើតបណ្ដាញថ្មី អ្នកអាចប្រើម៉ាស៊ីនមេដែលមានសុវត្ថិភាពរបស់អ្នកផ្ទាល់ជាម៉ាស៊ីនមេ Outline របស់អ្នក បើមាន ឬអ្នកអាចប្រើក្រុមហ៊ុនផ្ដល់សេវាប្រព័ន្ធពពក ដូចជា៖

  • DigitalOcean
  • Google Cloud Platform (GCP)
  • Amazon Web Services (AWS)

អ្នកនឹង​រៀបចំ​ម៉ាស៊ីនមេ​របស់អ្នក​នៅក្នុង Outline Manager។

តើ​អ្នកគ្រប់គ្រង​សេវាកម្ម​សំដៅលើអ្វី?​

អ្នកគ្រប់គ្រងសេវាកម្មគឺជាអ្នកទទួលខុសត្រូវក្នុងការរៀបចំម៉ាស៊ីនមេ Outline និងចែករំលែកលេខ​កូដ​ចូលប្រើ​ជាមួយ​អ្នកប្រើប្រាស់។ ជាទូទៅ អ្នកគ្រប់គ្រងសេវាកម្មទទួលខុសត្រូវចំពោះចំណាយលើការប្រើប្រាស់ម៉ាស៊ីនមេ។

តើលេខកូដ​ចូលប្រើ​គឺជាអ្វី?​

លេខកូដ​ចូលប្រើ​ត្រូវបានប្រើ ដើម្បី​ចូលប្រើ​ម៉ាស៊ីនមេ Outline ដែលមាន​ស្រាប់ និងភ្ជាប់ទៅ VPN។ អ្នកគ្រប់គ្រង​សេវាកម្មនឹង​ផ្តល់ឱ្យអ្នក​នូវលេខកូដ​ចូលប្រើ ឬអ្នកអាចរៀបចំ​ម៉ាស៊ីនមេ Outline ដោយ​ខ្លួនឯងបាន។ នេះជា​ឧទាហរណ៍​នៃទម្រង់​លក្ខណៈ​របស់លេខកូដ​ចូលប្រើ (ជាគំរូ​តែប៉ុណ្ណោះ នឹង​មិនដំណើរការទេ)៖

តើ Outline Manager គឺជាអ្វី?​

Outline Manager គឺជា​កម្មវិធី​កុំព្យូទ័រ​ដែលអាច​ឱ្យអ្នកគ្រប់គ្រង​សេវាកម្ម​រៀបចំ​ម៉ាស៊ីនមេ Outline, បង្កើតលេខកូដ​ចូលប្រើ និង​កំណត់​ដែនកំណត់​ទិន្នន័យលើ​ការប្រើប្រាស់​សម្រាប់លេខ​កូដមួយ។ អ្នកអាច​ទាញយក​កំណែចុងក្រោយបំផុតរបស់ Outline Manager នៅទីនេះ ឬនៅទីនេះ។

តើកម្មវិធីភ្ញៀវ​សម្រាប់ Outline គឺជាអ្វី?​

កម្មវិធីភ្ញៀវសម្រាប់ Outline គឺជាកម្មវិធីដែលមានសម្រាប់កុំព្យូទ័រ និងឧបករណ៍​ចល័ត ដែលអាចឱ្យអ្នកភ្ជាប់ទៅម៉ាស៊ីនមេ Outline និង​ចូលប្រើ VPN ដោយប្រើ​លេខកូដ​ចូលប្រើ។ អ្នកអាច​ទាញយក​កំណែចុងក្រោយបំផុត​របស់​កម្មវិធីភ្ញៀវ​សម្រាប់ Outline នៅទីនេះ ឬនៅទីនេះ។

តើដែន​កំណត់​ទិន្នន័យ​គឺជាអ្វី?​

Outline Manager អាចឱ្យអ្នកគ្រប់គ្រងសេវាកម្មដាក់ដែន​កំណត់​ទិន្នន័យបង្គររយៈពេល 30 ថ្ងៃលើលេខកូដចូលប្រើ ដើម្បីជៀសវាងការប្រើប្រាស់ច្រើនជ្រុល និងជួយរក្សាឱ្យចំណាយស្ថិតក្នុងកម្រិតដែលអាចព្យាករបាន។ អ្នកគ្រប់គ្រងសេវាកម្មអាចដាក់ដែនកំណត់លំនាំដើមដែលអនុវត្តចំពោះរាល់លេខកូដ និងដាក់ដែនកំណត់ផ្សេងគ្នាលើលេខកូដណាមួយ ដើម្បីលុបពីលើដែនកំណត់លំនាំដើមផងដែរ។ នៅពេលដែលដែនកំណត់ត្រូវបានដាក់ ដែនកំណត់នោះមានប្រសិទ្ធភាពភ្លាមៗ និងត្រូវបានអនុវត្តរៀងរាល់ម៉ោង។

ប្រសិនបើអ្នកគ្រប់គ្រងសេវាកម្មជ្រើសរើសធ្វើការចែករំលែកមេទ្រិកជាមួយ Jigsaw នោះពួកគេ​គួរតែមើលគោលការណ៍​ប្រមូល​ទិន្នន័យ ដើម្បី​ទទួលបាន​ព័ត៌មាន​លម្អិត​អំពីរបៀប​ដែលការប្រើប្រាស់​ដែន​កំណត់​ទិន្នន័យ​នឹងត្រូវបាន​រាយការណ៍។
