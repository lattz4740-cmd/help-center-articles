Google Cloud ස්වයංක්‍රීය පිහිටුවීම

දළ විශ්ලේෂණය​

Outline කළමනාකරු හි Google Cloud මත ධාවනය වන සේවාදායකයක Outline සේවාදායකය ස්වයංක්‍රීයව වින්‍යාස කිරීමට ඔබට ඉඩ සලසන විශේෂාංගයක් ඇතුළත් වේ. ඔබ මෙම විශේෂාංගය භාවිතා කිරීමට තෝරා ගන්නේ නම්, Outline කළමනාකරු විසින් ඔබේ Google ගිණුම සමග පුරනය වීමට ඔබෙන් අසනු ඇත, එය ඔබේ Google Cloud ගිණුම වින්‍යාස කිරීමේ අරමුණු සඳහා Outline කළමනාකරු හි ඔබේ දේශීය ස්ථාපනය සඳහා යම් OAuth අවසර ලබා දෙනු ඇත.

ඔබ මෙම අවසර ලබා දීමට අකමැති නම්, ඔබට Google Cloud Platform මත Outline ධාවනය කිරීමට Outline කළමනාකරු හි ඇති උසස් පිහිටුවීම් උපදෙස් අනුගමනය කළ හැක.

අවසර ලබා දී ඇත​

ස්වයංක්‍රීය පිහිටුවීම් සැපයීම සඳහා, Outline කළමනාකරු හට ඔබේ Google ගිණුමෙන් පහත අවසර අවශ්‍ය වේ.

Google Cloud වේදිකාව​

  • ඔබේ Google Compute Engine සම්පත් බලන්න සහ කළමනාකරණය කරන්න
  • Google Cloud සේවා හරහා ඔබේ දත්ත බැලීම සහ ඔබේ Google ගිණුමේ ඉ-තැපැල් ලිපිනය බැලීම

මූලික ගිණුම් තතු​

  • ඔබේ Google ගිණුම් ඉ-තැපැල් ලිපිනය බැලීම
  • Google මත ඔබේ පුද්ගලික තතු සමග ඔබව ආශ්‍රිත කරන්න

අතිරේක ප්‍රවේශය​

  • ඔබේ Cloud වේදිකා ව්‍යාපෘති කළමනාකරණය කරන්න
  • ඔබේ Google Cloud වේදිකා ගෙවීම් ගිණුම් බලන්න සහ කළමනාකරණය කරන්න
  • ඔබේ Google API සේවා වින්‍යාසකරණය කළමනාකරණය කරන්න

මෙම අවසරයන් පහත ඒවා ඇතුළුව ඔබේ Outline සේවාදායකයන් කළමනාකරණය කිරීම සඳහා උසස් ක්‍රියාකාරීත්වයට සහාය වීමට අපට ඉඩ සලසයි:

  • නිවැරදි බිල්පත් ගිණුම තෝරා ගැනීමට ඔබට ඉඩ සලසයි
  • ඔබේ Outline සේවාදායක සංවිධානය කිරීමට නව ව්‍යාපෘතියක් තැනීම
  • පවතින දත්ත මධ්‍යස්ථාන ලැයිස්තුගත කිරීම
  • Outline ධාවනය කිරීමට නව අථත්‍ය යන්ත්‍ර තැනීම
  • Outline සමග නව අථත්‍ය යන්ත්‍රය වින්‍යාස කිරීම

අවසර අහෝසි කරමින්​

ඔබට මගේ ගිණුම වෙත පිවිසීමෙන් Outline කළමනාකරු සඳහා Google Cloud Platform වෙත ප්‍රවේශය අවලංගු කළ හැක. ඔබ ප්‍රවේශය අවලංගු කළහොත්, ස්වයංක්‍රීය පිහිටුවීම සමග ඔබ නිර්මාණය කර ඇති ඕනෑම සේවාදායකයක් ක්‍රියාත්මකව පවතිනු ඇති නමුත් තවදුරටත් Outline කළමනාකරු හි දිස් නොවනු ඇත. ඒවාට ප්‍රවේශය ප්‍රතිසාධනය කිරීමට, ස්වයංක්‍රීය පිහිටුවීම ප්‍රවාහය ආරම්භ කිරීමෙන් Google Cloud Platform වෙත යළි සම්බන්ධ කරන්න.

Outline ව්‍යාපෘති සංවිධානය​

Google Cloud ස්වයංක්‍රීය පිහිටුවීම් ඔබේ Outline සේවාදායක සංවිධානය කිරීමට තනි Google Cloud ව්‍යාපෘතියක් භාවිතා කරයි. ව්‍යාපෘතිය නිර්මාණය වන්නේ ස්වයංක්‍රීය පිහිටුවීමේ ප්‍රථම භාවිතයේ දී, යෝජිත ව්‍යාපෘති ID එකක් සමග ආරම්භ වන “Outline-” සහ පසුව අහඹු අනුලකුණු මාලාවක් සමගිනි. ඔබ කැමති නම් නිර්මාණයේ දී ඔබට වෙනත් ව්‍යාපෘති ID එකක් තෝරාගත හැක. ව්‍යාපෘතිය “Outline සේවාදායක” ලෙස නම් කරනු ලැබේ.

බිල්පත් ගිණුම​

Google Cloud ව්‍යාපෘති සඳහා ගෙවීම් තොරතුරු නිර්වචනය කරන සම්බන්ධිත “බිල්පත් ගිණුමක්” අවශ්‍ය වේ. ඔබ පළමුව Google Cloud ස්වයංක්‍රීය පිහිටුවීම භාවිතා කරන විට, ඔබේ Outline සේවාදායක සමග සම්බන්ධ වීමට බිල්පත් ගිණුමක් සපයන ලෙස ඔබෙන් අසනු ඇත. සමහර විට බිල්පත් ගිණුමේ ගැටලුවක් ඇති බැවින් සේවාදායකයක් ධාවනය වීම නතර වනු ඇත. මෙම අවස්ථාවේ දී, ඔබ Google Cloud Console වෙත පුරනය වී, Outline ("Outline සේවාදායක" ලෙස නම් කර ඇති) සමග සම්බන්ධ Google Cloud ව්‍යාපෘතිය සොයා ගෙන, සහ බිල්පත් සැකසීම් යාවත්කාලීන කළ යුතු වේ.

සේවාදායකයන් විනාශ කිරීම​

ස්වයංක්‍රීය පිහිටුවීම භාවිතයෙන් සාදන ලද ඔබේ සේවාදායකයන් විනාශ කිරීමට ඔබට අවශ්‍ය නම්, එය කිරීමට ඇති පහසුම ක්‍රමය වන්නේ Outline කළමනාකරු තුළිනි. කෙසේ වෙතත්, ඔබ විසින්ම සේවාදායකයන් විනාශ කිරීමට අදහස් කරන්නේ නම්, ඔබට Google Cloud Console වෙත පුරනය වී, මූලික පිහිටුවීමේ ("Outline සේවාදායක" ලෙස නම් කර ඇති) නිර්මාණය කරන ලද ව්‍යාපෘතිය සොයා ගැනීමට සහ එහි ඇති සම්පත් මකා දැමීමට හෝ ව්‍යාපෘතිය වසා දැමීමට හැක.
