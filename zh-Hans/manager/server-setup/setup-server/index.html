如何设置 Outline 服务器？

要使用 Outline，首先请设置 Outline 服务器。您需要自行设置服务器，或让您信任的人设置，以便通过 Outline 连接到开放式互联网。

准备工作​

在开始设置 Outline 服务器前，您需要满足以下条件：

  1. 有权访问您自己的服务器或云服务提供商，例如 DigitalOcean、Amazon Web Services (AWS) 或 Google Cloud Platform (GCP)。

如果您没有访问云服务器的权限，可以轻松在任意提供商网站上设置一个帐号，包括上文所列的服务提供商。您在注册时可能需要使用信用卡。 2. 拥有运行 macOS 10.9 及以上版本、Windows 7.0 及以上版本或 Linux 的桌面设备。 3. 已安装 Outline 管理器应用。

通过 DigitalOcean 进行设置​

我们提供了简单的设置步骤，您只需点击几次，即可通过 DigitalOcean 安装 Outline。在计算机上下载并安装 Outline 管理器后，您可以选择 DigitalOcean 设置选项。系统将指导您通过几个简单的屏幕完成 Outline 服务器的配置和安装。

通过其他云服务提供商进行设置​

下载并安装 Outline 管理器后，您可以选择在 AWS、GCP、DigitalOcean 或其他提供商的虚拟机上安装 Outline 服务器。由于环境各不相同，因此我们在 Outline 管理器设置流程中提供了最常见的云服务提供商的相关说明，包括在运行安装脚本以在服务器上安装 Outline 之前，该如何配置您的虚拟机。

需要更多帮助？​

请查看 Outline 服务器设置常见问题解答。
