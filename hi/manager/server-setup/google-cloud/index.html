Google Cloud में, सर्वर अपने-आप सेटअप होने की सुविधा

खास जानकारी​

Outline Manager में आपको एक ऐसी सुविधा मिलती है जिसकी मदद से, Google Cloud में चलने वाले सर्वर पर, Outline सर्वर अपने-आप कॉन्फ़िगर हो जाता है. इस सुविधा का इस्तेमाल करने के लिए, आपको Outline Manager में अपने Google खाते से साइन इन करना होगा. इससे, आपके सिस्टम पर इंस्टॉल किए गए Outline Manager को आपका Google Cloud खाता कॉन्फ़िगर करने के लिए, कुछ ज़रूरीOAuth अनुमतियां मिल जाएंगी.

अगर आपको, ये अनुमतियां दिए बिना Google Cloud Platform पर Outline इस्तेमाल करना है, तो Outline Manager में दिए गए, बेहतर तरीके से सेटअप करने के निर्देशों का पालन करें.

ज़रूरी अनुमतियां​

Outline सर्वर अपने-आप सेटअप हो सके इसके लिए, Outline Manager के पास आपके Google खाते से जुड़ी ये अनुमतियां होनी चाहिए.

Google Cloud Platform​

  • आपके Google Compute Engine के संसाधनों को देखना और उन्हें मैनेज करना
  • Google Cloud की सभी सेवाओं से जुड़ा आपका डेटा और आपके Google खाते का ईमेल पता देखना

खाते की सामान्य जानकारी​

  • आपके मुख्य Google खाते का ईमेल पता देखना
  • Google पर मौजूद आपकी निजी जानकारी को Outline Manager से जोड़ना

अन्य ऐक्सेस​

  • Cloud Platform के आपके प्रोजेक्ट मैनेज करना
  • Google Cloud Platform के आपके बिलिंग खातों को देखना और उन्हें मैनेज करना
  • Google API सेवा के लिए आपका कॉन्फ़िगरेशन मैनेज करना

इन अनुमतियों की मदद से, हम आपके Outline सर्वर को मैनेज करने के लिए बेहतर तरीकों का इस्तेमाल कर पाते हैं. जैसे:

  • आपको सही बिलिंग खाता चुनने की अनुमति देना
  • आपके Outline सर्वर को मैनेज करने के लिए नया प्रोजेक्ट बनाना
  • उपलब्ध डेटा सेंटर की सूची बनाना
  • Outline सर्वर को चलाने के लिए नई वर्चुअल मशीन बनाना
  • Outline के साथ नई वर्चुअल मशीन को कॉन्फ़िगर करना

अनुमतियां वापस लेना​

Outline Manager के लिए, Google Cloud Platform का ऐक्सेस वापस लिया जा सकता है. इसके लिए, आपकोमेरा खाता में जाना होगा. ऐक्सेस वापस लेने पर भी, अपने-आप सेटअप होने की सुविधा का इस्तेमाल करके बनाए गए सर्वर, पहले की तरह ही काम करते रहेंगे. हालांकि, Outline Manager पर वे सर्वर नहीं दिखेंगे. ऐक्सेस वापस देने के लिए, सर्वर अपने-आप सेटअप होने की सुविधा को चालू करके, Google Cloud Platform को फिर से कनेक्ट करना होगा.

Outline प्रोजेक्ट को मैनेज करना​

Google Cloud में, सर्वर अपने-आप सेटअप होने की सुविधा, आपके Outline सर्वर को मैनेज करने के लिए,Google Cloud के किसी एक प्रोजेक्ट का इस्तेमाल करती है. यह प्रोजेक्ट, सर्वर अपने-आप सेटअप होने की सुविधा का पहली बार इस्तेमाल करने के दौरान बनाया जाता है. इसके लिए, एक सुझाया गया प्रोजेक्ट आईडी भी बनता है, जिसकी शुरुआत "Outline-" से होती है और इसके बाद आने वाली स्ट्रिंग में मौजूद वर्ण किसी भी क्रम में हो सकते हैं. प्रोजेक्ट बनाते समय कोई दूसरा प्रोजेक्ट आईडी भी चुना जा सकता है. इस प्रोजेक्ट का नाम “Outline सर्वर” रखा जाएगा.

बिलिंग खाता​

Google Cloud प्रोजेक्ट को किसी "बिलिंग खाते" से लिंक करना होगा, जिसमें आपके क्रेडिट/डेबिट कार्ड की जानकारी शामिल हो. Google Cloud में, सर्वर अपने-आप सेटअप होने की सुविधा का पहली बार इस्तेमाल करने पर, आपको अपना बिलिंग खाता उपलब्ध कराना होता है, ताकि उसे आपके Outline सर्वर के साथ जोड़ा जा सके. हो सकता है कि बिलिंग खाते में कोई समस्या आने पर, सर्वर काम करना बंद कर दे. ऐसे मामले में,Google Cloud Console में लॉग इन करके, Google Cloud का वह प्रोजेक्ट ढूंढें जो Outline से जुड़ा हो और “Outline सर्वर” के नाम से मौजूद हो. इसके बाद, बिलिंग से जुड़ी सेटिंग अपडेट करें.

सर्वर बंद करना​

अपने-आप सेटअप होने की सुविधा का इस्तेमाल करके बनाए गए सर्वर को, Outline Manager में जाकर आसानी से बंद किया जा सकता है. अगर सर्वर खुद बंद करना है, तोGoogle Cloud Console में लॉग इन करें और शुरुआती सेटअप के दौरान बनाया गया प्रोजेक्ट (“Outline सर्वर”) खोजें. इसके बाद, इस प्रोजेक्ट में मौजूद संसाधनों को मिटाएं या यह प्रोजेक्ट बंद करें.
