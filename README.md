# Outline Help Center Articles

This repository contains the full export of the Outline Help Center articles, previously hosted at https://support.google.com/outline. The content was exported from the internal "Compose" tool.

## Folder Structure

-   **Help Center/**: Contains the main help center articles in HTML format.
-   **FAQs/**: Contains a smaller set of FAQ articles in HTML format.
-   **Contact forms/**: Contains contact form HTML files.
-   **FAQ Snippets/**: Contains supporting materials such as images, linked in the HTML files.
-   **Redirects/**: Contains screenshots of the redirect configurations.

The content includes texts and images for all supported languages. The folders represent the raw exported content from the "Compose" tool.
