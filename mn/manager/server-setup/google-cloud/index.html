Google Cloud-н автоматжуулсан тохируулга

Тойм​

Outline Manager-т танд Google Cloud дээр ажиллаж буй серверт Outline серверийг автоматаар тохируулахыг зөвшөөрдөг онцлог багтана. Хэрэв та энэ онцлогийг ашиглахаар сонговол Outline Manager танаас Google Бүртгэлээрээ нэвтрэхийг хүсэх бөгөөд энэ нь таны Google Cloud Бүртгэлийг тохируулах зорилгоор Outline Manager-н дотоодод суулгахад OAuth-н тодорхой зөвшөөрлийг олгоно.

Хэрэв та эдгээр зөвшөөрлийг олгохыг хүсэхгүй байвал Google Cloud платформ дээр Outline-г ажиллуулахын тулд Outline Manager-н дэвшилтэт тохируулгын зааварчилгааг дагах боломжтой.

Олгосон зөвшөөрөл​

Автоматжуулсан тохируулгаар хангахын тулд Outline Manager-т таны Google Бүртгэлээс дараах зөвшөөрөл шаардлагатай.

Google Cloud платформ​

  • Таны Google Compute Engine-н нөөцийг харах, удирдах
  • Таны өгөгдлийг Google Cloud-н үйлчилгээнүүд даяар үзэх, Google Бүртгэлийн тань имэйл хаягийг харах

Бүртгэлийн үндсэн мэдээлэл​

  • Таны Google Бүртгэлийн үндсэн имэйл хаягийг харах
  • Таныг Google дээрх хувийн мэдээлэлтэй тань холбох

Нэмэлт хандалт​

  • Таны Cloud Platform-н төслүүдийг удирдах
  • Таны Google Cloud Platform-н төлбөр тооцооны бүртгэлийг харах, удирдах
  • Таны Google API үйлчилгээний тохируулгыг удирдах

Эдгээр зөвшөөрөл нь бидэнд дараахыг оруулаад таны Outline серверүүдийг удирдахад зориулсан дэвшилтэт функцүүдийг дэмжихийг зөвшөөрдөг:

  • Танд зөв төлбөр тооцооны бүртгэл сонгохыг зөвшөөрөх
  • Outline серверүүдээ цэгцлэх шинэ төсөл үүсгэх
  • Боломжтой байгаа өгөгдлийн төвүүдийг жагсаах
  • Outline-г ажиллуулахын тулд шинэ виртуал машинууд үүсгэх
  • Шинэ виртуал машиныг Outline-тай тохируулах

Зөвшөөрөл цуцлах​

Та Outline Manager-н Google Cloud Platform-д хандах эрхийг Миний Бүртгэлд зочилж цуцлах боломжтой. Хэрэв та хандах эрх цуцалбал таны автоматжуулсан тохируулгаар үүсгэсэн аливаа сервер ажилласан хэвээр байх хэдий ч цаашид Outline Manager-т харагдахгүй. Тэдгээрт хандах эрхийг сэргээхийн тулд ердөө автоматжуулсан тохируулгын урсгалыг эхлүүлж, Google Cloud Platform-д дахин холбогдоно уу.

Outline төслийн байгууллага​

Google Cloud-н автоматжуулсан тохируулга нь ганц Google Cloud төсөлашиглан таны Outline серверүүдийг цэгцэлдэг. Төслийг автоматжуулсан тохируулгыг анх удаа ашиглах үед “Outline-”-р эхэлж, араас нь санамсаргүй тэмдэгтүүдийн мөр бүхий санал болгосон төслийн ID-ны хамт үүсгэдэг. Хэрэв та илүүд үзвэл үүсгэх үедээ төслийн өөр ID сонгох боломжтой. Төслийг “Outline серверүүд” гэж нэрлэнэ.

Төлбөр тооцооны бүртгэл​

Google Cloud төсөл нь төлбөрийн мэдээллийг тодорхойлох холбоотой “төлбөр тооцооны бүртгэл” шаарддаг. Таныг Google Cloud-н автоматжуулсан тохируулгыг анх удаа ашиглах үед танаас Outline серверүүдтэйгээ холбох төлбөрийн мэдээлэл хүлээн авах имэйл өгөхийг хүснэ. Төлбөр тооцооны бүртгэлтэй холбоотой асуудал гарсан тул заримдаа сервер ажиллахаа болино. Энэ тохиолдолд та Google Cloud Console-д нэвтэрч, Outline-тай (“Outline серверүүд” гэсэн нэртэй) холбоотой Google Cloud төслийн байршлыг тогтоон төлбөр тооцооны тохиргоог шинэчлэх хэрэгтэй.

Сервер устгах​

Хэрэв та автоматжуулсан тохируулгыг ашиглан үүсгэсэн серверүүдээ устгахыг хүсвэл Outline Manager дотроос үүнийг хийх нь хамгийн хялбар арга юм. Гэсэн хэдий ч хэрэв та серверүүдээ өөрөө устгахыг хүсвэл Google Cloud Console-д нэвтэрч, анхны тохируулгын үеэр үүсгэсэн төслийг (“Outline серверүүд” гэсэн нэртэй) олж, тэнд нөөцийг устгах эсвэл төслийг унтрааж болно.
