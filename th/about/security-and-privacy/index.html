ความปลอดภัยและความเป็นส่วนตัวขณะใช้ Outline

วิธีที่ Outline ปกป้องการสื่อสารออนไลน์​

การเข้าใช้อินเทอร์เน็ตนั้นจะมีความเสี่ยงต่อการรักษาความปลอดภัยมากที่สุดในขณะที่ข้อมูลเดินทางอยู่ในเครือข่ายในท้องถิ่นหรือระดับประเทศ

Outline จะช่วยทำให้การสื่อสารของคุณมีความเป็นส่วนตัวโดยเข้ารหัสการเข้าใช้อินเทอร์เน็ตในขณะที่ข้อมูลเดินทางภายในเครือข่ายระดับประเทศและคงการเข้ารหัสจนกว่าการสื่อสารนั้นจะถึงเซิร์ฟเวอร์ Outline เมื่อใช้ Outline เข้ารหัสการเข้าใช้ บุคคลอื่นที่สังเกตการณ์อยู่ในเครือข่ายจะตรวจสอบเว็บไซต์ที่คุณเข้าชมหรือข้อมูลที่คุณโอนไม่ได้

Outline ยังอาจช่วยให้เข้าถึงเครื่องมือการสื่อสารแบบต้นทางไปยังปลายทางที่ปลอดภัยซึ่งปกติอาจใช้งานไม่ได้ในประเทศของคุณ

มาตรฐานการเข้ารหัส​

Outline จะเข้ารหัสการสื่อสารระหว่างอุปกรณ์ของคุณกับเซิร์ฟเวอร์ Outline โดยใช้การเข้ารหัส AEAD 256-bit Chacha2020 IETF Poly 1305 การเข้ารหัส AEAD จะทำให้ฮาร์ดแวร์สมัยใหม่ทำงานได้อย่างมีประสิทธิภาพ มีความน่าเชื่อถือ สมบูรณ์แบบ และมีความถูกต้อง

การตรวจสอบความปลอดภัย​

Outline ได้รับการตรวจสอบโดย Radically Open Security และ Cure53 ในปี 2018 ซึ่งเป็นองค์กรด้านความปลอดภัยดิจิทัลอิสระทั้ง 2 แห่งที่ตรวจสอบซอฟต์แวร์กับมาตรฐานความปลอดภัยล่าสุด โดย Radically Open Security ได้ทำการตรวจสอบเพิ่มเติมในปี 2022 และ Cure53 ได้ทำการตรวจสอบ Outline SDK ในปี 2024 อ่านข้อมูลเพิ่มเติมได้ในรายงานต่อไปนี้

  • Radically Open Security Penetration Test Report (มีนาคม 2018)
  • Cure53 Pentest & Audit Report Jigsaw Outline (ธันวาคม 2018)
  • Radically Open Security Penetration Test Report (ธันวาคม 2022)
  • Cure53 Pentest Report Jigsaw Outline VPN SDK (มกราคม 2024)

เมตริกและบันทึกที่ไม่ระบุตัวตน​

Outline จะติดตามแบนด์วิดท์ที่ใช้เป็น "จำนวนไบต์ที่ถ่ายโอน" สำหรับคีย์การเข้าถึงแต่ละรายการ ข้อมูลนี้จะช่วยให้ผู้ดูแลระบบเซิร์ฟเวอร์ปรับการสมัครใช้บริการแบนด์วิดท์ที่ซื้อกับผู้ให้บริการเซิร์ฟเวอร์ระบบคลาวด์ได้ตามต้องการ แต่จะไม่อนุญาตให้เห็นข้อมูลจริงที่ส่งผ่านเซิร์ฟเวอร์ Outline

ดูข้อมูลเพิ่มเติมเกี่ยวกับการเก็บรวบรวมข้อมูลและสารสนเทศของ Outline

คำถามที่พบบ่อยเกี่ยวกับความปลอดภัยและความเป็นส่วนตัว​

Outline ทำให้ไม่มีใครรู้ตัวตนบนโลกออนไลน์ของฉันได้ใช่ไหม​

ไม่ใช่ Outline ไม่ใช่เครื่องมือปกปิดตัวตน แต่จะปกป้องความเป็นส่วนตัวจากผู้สังเกตการณ์ในเครือข่ายที่เป็นไปได้

Outline ไม่ได้ปกปิดตัวตนของคุณแบบเต็มรูปแบบเมื่อเข้าชมเว็บไซต์ เนื่องจากเว็บไซต์เหล่านั้นจะระบุตัวตนของคุณได้เมื่อเข้าสู่ระบบและผ่านทางเทคนิคต่างๆ ในบางครั้ง เช่น การใช้ลายนิ้วมือของเบราว์เซอร์ สำหรับแอปบนอุปกรณ์เคลื่อนที่ สมาร์ทโฟนรุ่นใหม่ส่วนใหญ่จะมี API ที่อนุญาตให้แอปที่ติดตั้งไว้เรียกดูตำแหน่งของคุณได้โดยไม่ต้องผ่านพร็อกซีเนื่องจากแอปเหล่านั้นใช้ GPS ในเครื่องได้

โดยทั่วไปแล้ว VPN จะเป็นด่านป้องกันที่สำคัญโดยเฉพาะจากการสอดส่องกิจกรรมบนอินเทอร์เน็ต อย่างไรก็ดีการใช้งานออนไลน์มักจะมีความเสี่ยงอยู่เสมอ ถึงแม้ว่าจะใช้ VPN แล้วก็ตาม หาก ISP รู้ถึงตัวตนของคุณและเฝ้าสังเกตการจราจรของข้อมูลในเครือข่ายได้ ISP ก็อาจจะรู้ที่อยู่ IP ของเซิร์ฟเวอร์ Outline ของคุณด้วย ซึ่งข้อมูลนี้อาจจะนำไปใช้เพื่อปิดกั้นการเข้าถึงเซิร์ฟเวอร์ Outline หรือเรียนรู้รูปแบบการใช้งาน เช่น เวลาที่คุณมักจะออนไลน์ และอาจใช้ค้นหาตำแหน่งของคุณอย่างคร่าวๆ ได้อีกด้วย

ผู้อื่นจะทราบหรือไม่ว่าฉันกำลังใช้ Outline อยู่​

อาจจะทราบ แพลตฟอร์มและบริการที่คุณเข้าถึงส่วนใหญ่อาจจะรู้ว่าการเชื่อมต่อของคุณมาจากเซิร์ฟเวอร์ระบบคลาวด์ ซึ่งก็อาจจะคาดเดาได้ในบางครั้งว่าคุณใช้ VPN แต่จะไม่เห็นเนื้อหาการเข้าใช้อินเทอร์เน็ตของคุณ

Outline จะช่วยปกป้องฉันจากภัยคุกคามทางไซเบอร์ที่อาจเกิดขึ้นทั้งหมดไหม​

ไม่ ไม่มีเครื่องมือใดจะช่วยป้องกันคุณจากภัยคุกคามทางไซเบอร์ที่อาจเกิดขึ้นทั้งหมดได้ แต่ Outline จะช่วยให้คุณใช้งานอินเทอร์เน็ตสาธารณะและเพิ่มความเป็นส่วนตัวได้โดยเข้ารหัสการเข้าใช้ของคุณ แต่เราขอแนะนำให้คุณยึดหลักปลอดภัยไว้ก่อนเพื่อป้องกันตัวคุณเองจากการโจมตีประเภทอื่นๆ เช่น มัลแวร์และฟิชชิง

หากต้องการเพิ่มประสิทธิภาพการป้องกันทางออนไลน์ โปรดทำงานร่วมกับผู้เชี่ยวชาญด้านการรักษาความมั่นคงปลอดภัยไซเบอร์ขององค์กร หรือรับคำแนะนำที่ปรับเปลี่ยนให้เหมาะกับคุณจากผู้เชี่ยวชาญอันดับต้นๆ ในด้านความปลอดภัยได้ที่ Security Planner ซึ่งเป็นเว็บไซต์ที่สร้างเพื่อช่วยให้คุณเข้าใจวิธีการต่างๆ ในการเลือกเครื่องมือเพื่อรักษาความมั่นคงปลอดภัยไซเบอร์ที่เหมาะสมกับความต้องการ

นอกจากนี้ คุณยังดูผลิตภัณฑ์ที่เกี่ยวกับการรักษาความมั่นคงปลอดภัยไซเบอร์อื่นๆ ได้จาก Jigsaw เช่น Intra, Project Shield และ Password Alert

การใช้ VPN ถูกกฎหมายไหม​

ก่อนใช้ Outline หรือแอปใดก็ตาม โปรดตรวจสอบกฎหมายและข้อบังคับในท้องถิ่นรวมถึงข้อกำหนดในการให้บริการของผู้ให้บริการคลาวด์ที่คุณวางแผนจะใช้งาน
