title: 執行 Outline 需要支付多少費用？
sidebar_label: 執行 Outline 需要支付多少費用？
---

Outline 軟件供所有人免費使用。無論你是管理 VPN 的伺服器管理員或透過 Outline 存取開放互聯網的使用者，都無需付費。

 不過，Outline 需要有雲端服務的伺服器存取權才能運作。已有伺服器存取權的伺服器管理員可直接安裝 Outline，無需支付額外費用。至於仍未有伺服器存取權的使用者，可透過雲端服務供應商 (如 [DigitalOcean](https://www.digitalocean.com/) 或 Amazon Web Services) 來設定伺服器，費用大約是每月 1 TB 資料傳輸量 $5 美元，這個流量足以讓一個伺服器支援數以百計使用者的需求。

 以下例子說明如何計算在你選擇的雲端服務供應商上運作 Outline 的費用：

| *假設每位使用者平均每月使用的資料傳輸量是 5 GB，而每月 $5 美元的方案可支援大約 200 名使用者同時使用服務，即每位使用者每月的平均費用大約 $2.5 美分。請注意，每位使用者每月可用的資料傳輸量取決於使用者活動佔用的頻寬多寡，且用量可能有大幅波動，但大部分雲端服務供應商都會有因應流量增加的彈性措施。* |
| --- |

使用者使用 Outline 時完全匿名，Jigsaw 和 Google 無法得知使用者資料。我們不會追蹤你的身分或流量，亦不會以此營利。事實上，我們與開放原始碼社群合作，確保能為使用者提供免費的軟件。進一步瞭解[我們收集的資料](https://getoutline.org/policies/data-collection)。
