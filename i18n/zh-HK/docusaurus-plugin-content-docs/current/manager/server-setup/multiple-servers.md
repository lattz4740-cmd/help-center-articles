---
title: 如何設定多個 Outline 伺服器
sidebar_label: 如何設定多個 Outline 伺服器
---

如要設定額外的 Outline 伺服器，請按一下 Outline Manager 應用程式左側導覽面板的「+」圖示。安裝其他伺服器的操作方式跟安裝第一個伺服器的步驟相同。

- 你可建立的 Outline 伺服器數量不限。
- 你建立的每個 Outline 伺服器都要有對應的虛擬機器。
- 如果建立額外的機器或 Droplet，雲端服務供應商可能會向你收取較高費用。請先與雲端服務供應商確認定價，避免超出預算。

## 在 DigitalOcean 上建立額外的 Outline 伺服器

按一下「+」圖示並選擇在 DigitalOcean 上安裝後，你需要按照設定第一個伺服器時相同的指示操作。此外，由於 Outline Manager 已與 DigitalOcean 整合，因此你無需離開 Outline Manager 應用程式介面，我們亦能直接幫你建立 Droplet。

請注意，Outline Manager 一次只支援使用一個 DigitalOcean 帳戶。如果你要透過其他 DigitalOcean 帳戶來新增或建立額外的 Outline 伺服器，可以在進階設定中新增。

## 透過 GCP、AWS 或其他雲端服務供應商建立額外的 Outline 伺服器

首先，請透過你選擇的雲端服務供應商來建立新的虛擬機器。然後開啟 Outline Manager 並完成進階安裝的操作，步驟與你第一次設定時相同。
