**如果沒有伺服器，可以使用 Outline 嗎？**

 很抱歉，不可以。Outline 軟件需要伺服器存取權才能運作。無論伺服器的管理者是你、你所屬的機構或信任的第三方都沒有問題。

## 設定 Outline 伺服器需要多少時間？

通常可在 5 分鐘內完成。我們與 DigitalOcean 合作，提供更容易使用的引導安裝程序，讓你按幾下滑鼠就能輕鬆設定伺服器，完全不需要執行指令碼。不過，你亦可在其他雲端伺服器上安裝 Outline。

如果你選用 AWS、GCP 或進階設定服務，我們亦已簡化相關伺服器安裝程序。只要執行一個指令碼，就能處理好大部分的環境設定。

## 我可在哪裡設定 Outline 伺服器？

你可透過大部分雲端供應商在其提供服務的地區設定 Outline 伺服器。

最簡單的做法是在 DigitalOcean 上設定，因為此供應商提供的伺服器遍佈阿姆斯特丹、多倫多、三藩市和新加坡等多個地區。如果你希望將 Outline 安裝在其他雲端服務供應商或自己的基礎架構上，可在 Outline Manager 應用程式中選擇 [進階模式]，然後使用設定指令碼按照安裝指示。

2. Outline 伺服器位置會影響使用者的互聯網體驗。例如，如果伺服器位於阿姆斯特丹，存取此伺服器的使用者連接互聯網時，看到的介面就會像在荷蘭上網一樣；有些網站甚至會以荷蘭文顯示。一般來說，你可使用網站的語言選擇工具來覆寫語言設定。
3. 使用者和 Outline 伺服器之間的距離可能會影響連線速度。一般來說，Outline 使用者和伺服器之間的實際距離會影響使用者的互聯網速度。在大部分情況下，你可選擇最靠近預期使用者所在地點的伺服器位置，不過你亦可查看[海底纜線圖](https://www.submarinecablemap.com/)，確認連至你國家/地區的是哪一條互聯網纜線。
4. VPN 伺服器的所在位置可能會影響法律架構。請注意，Outline 軟件不會記錄你的流量。進一步瞭解[使用 Outline 時的安全和私隱](/about/security-and-privacy)。
