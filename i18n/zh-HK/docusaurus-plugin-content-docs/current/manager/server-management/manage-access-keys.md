安裝完 Outline 伺服器後，你便可開始與他人共用及管理伺服器存取權。獲邀對象將可下載並使用 Outline 應用程式保護互聯網流量。

**共用 Outline 伺服器存取權**

 Outline 伺服器安裝完成後，系統會將你導向 Outline Manager 的伺服器詳情頁面。你可在此頁面建立存取金鑰。進一步瞭解[存取金鑰](/about/terminology)。

- 建立金鑰：按一下頁面底部的「+」小圖示，即可建立新的金鑰。
- 共用金鑰：按一下每個金鑰右側的共用圖示，即可查看邀請訊息。請複製此訊息並貼至你選擇的通訊系統。

**功能要求：在 Outline Manager 應用程式中共用存取權**

 很多伺服器管理員曾表示希望簡化邀請程序，讓他們直接在 Outline Manager 中輸入特定對象的電郵地址。

很抱歉，我們目前無法在 Outline Manager 中內建此功能。我們的其中一個核心原則是保護使用者私隱和安全，因此我們並未設計任何可插入電郵地址或聯絡資料的位置。

因此，我們要求伺服器管理員透過安全的通訊平台 (例如電郵) 或即時通訊工具，將存取邀請傳送給使用者。

**共用存取金鑰後，使用者的操作如下：**

1. 在自己的裝置上按一下安裝連結
2. 如果使用者未安裝 Outline 應用程式，系統將提示他們安裝
3. 使用者會透過邀請中隨附的專屬金鑰與你的 Outline 伺服器進行初次連線
4. 使用者現可利用「連線」或「解除連線」按鈕，管理透過你 Outline 伺服器連線互聯網的存取權

**移除使用者的 Outline 伺服器存取權**

 請前往 Outline Manager 的伺服器詳情頁面，在伺服器的每個金鑰右側找到選單，然後選取刪除金鑰的選項。請注意，刪除金鑰會一併移除對應的伺服器存取權。
