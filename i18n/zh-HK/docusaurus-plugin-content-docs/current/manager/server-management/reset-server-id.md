---
title: 如何重設伺服器 ID？
sidebar_label: 如何重設伺服器 ID？
---

伺服器 ID 是在建立 Outline 伺服器時隨機產生的伺服器端 ID。只要在「設定」介面中選擇分享匿名數據，即可看到這組 ID。如要查詢伺服器 ID，請按一下「設定」並捲動到底部，然後勾選「分享匿名數據」。

伺服器 ID 可將系統持續報告的匿名使用情況統計聯繫在一起。如要重設伺服器 ID 並取得新 ID，你需要建立新的 Outline 伺服器來取代現有伺服器。

如使用 DigitalOcean，你可前往「設定」並選取「刪除伺服器」來重設伺服器。此操作無法復原，並會清除你的憑證。系統隨後會提示你在自己選擇的位置建立新伺服器，並產生新的伺服器 ID。
