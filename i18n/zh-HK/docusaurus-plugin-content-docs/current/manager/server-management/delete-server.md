---
title: 如何刪除我的 Outline 伺服器？
sidebar_label: 如何刪除我的 Outline 伺服器？
---

大部分雲端服務供應商都能讓你輕鬆移除目前使用的虛擬機器。

如果雲端服務供應商是 DigitalOcean，你可按一下齒輪圖示並選取「刪除伺服器」來刪除現有的虛擬機器。系統隨後會提示你在自己選擇的位置建立新的虛擬機器。

Outline 伺服器一經移除便會永久刪除，且伺服器的存取金鑰亦會失效。如果想繼續讓使用者透過 Outline 存取內容，在刪除舊的伺服器前請務必[設定新的 Outline 伺服器](/manager/server-setup/setup-server)並分享存取權。
