---
title: 如何取得存取金鑰？
sidebar_label: 如何取得存取金鑰？
---

有別於需要購買存取權的 VPN 服務，Outline 是用來執行私人 VPN 伺服器並分享存取權的[工具](https://getoutline.org/#:~:text=Two%20Products%20that%20Work%20Together)。只有[服務管理員](/about/terminology#servicemanager)才能提供存取金鑰，Outline 團隊不會發佈免費或付費存取密鑰。除了為波斯文使用者提供服務的 Paskoocheh 外，並沒有其他官方的 Outline 存取金鑰合作夥伴。

 以下是取得存取金鑰的三種方法：

- 請使用者邀請你存取其伺服器：如果你認識擁有 Outline 伺服器的人，請聯絡對方並索取存取金鑰。
- [自行建立伺服器：](/manager/server-setup/setup-server)使用 Windows、Mac 或 Linux 電腦下載 [Outline Manager](https://getoutline.org/get-started/#step-1)，並自行設定私人 [Outline 伺服器](/about/terminology)。這個過程十分簡單，任何人都能輕鬆完成 (尤其是透過雲端服務供應商 DigitalOcean)。
- 使用 Outline 或 [Shadowsocks](https://zh-HK.wikipedia.org/wiki/Shadowsocks#:~:text=Shadowsocks%20is%20a%20free%20and,have%20been%20made%20available%20since.) 服務：如果是採用 Outline 或 Shadowsocks 通訊協定的第三方服務，亦可與 Outline 用戶端配搭使用。例如：
   - [nthLink](https://nthlink.com/) 使用經過修改的 Outline 用戶端版本，以 Outline 為基礎提供免費服務。
   - [ASL19](https://www.reddit.com/r/outlinevpn/comments/nwu1se/the_outline_distribution_system_is_here_to_help/) 執行經修改的 Outline 版本 (名為 [BeePass](https://beepassvpn.com/))，以及 [Telegram 聊天機械人](https://t.me/paskoochehbot)。這個機械人可為 BeePass 伺服器提供免費存取金鑰。
   - 波斯文使用者亦可向 [ASL19 的 Paskoocheh](https://outline.paskoocheh.com/) 索取 Outline 存取金鑰。

下載 Outline 用戶端應用程式後，請複製[存取金鑰](/about/terminology#accesskey)並貼至 Outline 用戶端中，即可連線至 Outline 伺服器。
