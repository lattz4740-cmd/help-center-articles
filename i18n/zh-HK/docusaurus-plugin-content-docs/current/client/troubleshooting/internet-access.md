如果你正在使用手機，可嘗試在流動數據和 Wi-Fi 連線之間切換。有時可能只有其中一種連線可以使用；如果你使用電腦，請嘗試解除寬頻連線後再重新連線。

如果仍然無法上網，可能是你的 Outline 伺服器有問題。請聯絡[服務管理員](/about/terminology)，索取其他伺服器的新存取金鑰。如果https://google-jigsaw--jigsawuat.sandbox.my.site.com/outline/s/article/Terminology [存取金鑰](/about/terminology)的數據用量超過配額，服務管理員亦可提高存取金鑰的數據用量上限。
