---
title: 如何傳送意見或建議
sidebar_label: 如何傳送意見或建議
---

感謝你協助我們改善 Outline！我們提供多種傳送意見的渠道，你可匿名提供意見；如想收到回覆，亦可透過電郵提供意見：

- **開發人員**：Outline 是開放原始碼軟件，我們將所有程式碼都寄存在 [GitHub](https://github.com/jigsaw-Code/?q=outline)。你可在 GitHub 或我們的 [Reddit](https://www.reddit.com/r/outlinevpn/) 社群分享想法。
- **使用者**：你可透過 Outline 或 Outline Manager 應用程式向我們傳送意見。請說明你的意見或留低電郵地址，以便我們回覆你。此外，為協助你解決疑難，我們亦會收集一些有關你作業環境的元數據，例如瀏覽器、作業系統和執行的軟件版本等資料。
- **透過此網站**：按一下此網站上任何位置顯示的「聯絡我們」連結，即可提供意見。
- **重大問題**：如要報告重大問題，請在電郵中詳述相關資料並傳送至 security [at] [getoutline.org](https://getoutline.org/)。

再次感謝你抽空與我們分享意見和想法。
