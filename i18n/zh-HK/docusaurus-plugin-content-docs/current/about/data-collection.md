除非你選擇提供個人資料，否則 Outline 不會收集這些資料。Outline 亦不會收集你的網站瀏覽記錄、通訊對象或通訊內容等資料。

 如果你使用 Outline Manager 透過第三方雲端服務供應商建立或登入帳戶，我們不會取得你向第三方雲端服務供應商提供的任何資料，例如你的電郵地址、姓名、帳單資料和付款資料。

## 系統自動取得的資料
 我們的系統會自動收集以下兩種資料。

 1. 伺服器 IP

 Outline 伺服器根據最新的安全性和功能改良自動更新時，[Quay.io](https://quay.io/) 會收集伺服器 IP 並提供給我們。我們可以透過伺服器 IP 辨識雲端伺服器供應商和 Outline 伺服器所在的城市，但無法得知正在執行或存取伺服器的使用者是誰。

 2. 無法用於識別個人身分的技術性資料

 當 Outline 當機、發生重大例外情況，或你透過 Outline 應用程式手動傳送意見時，系統將會報告以下資料；這些資料只會用於協助辨識和修正穩定性或效能問題。

- 國家/地區
- 語言代碼
- 發生當機/例外情況的日期和時間，以及在此之前發生的最多 100 個活動 (例如使用者開啟了「關於」部分)
- 靜態編譯的例外情況訊息
- OS 名稱和版本
- 手機型號 (如適用)
- 應用程式啟動時間
- 瀏覽器
- 架構
- Outline 版本和版本號碼

系統會透過 HTTPS 將這些資訊傳送給第三方開放原始碼錯誤追蹤供應商 Sentry ([sentry.io](https://sentry.io/))；Sentry 使用多種符合業界標準的技術和服務來防止使用者資料遺失，避免這些資料經未授權存取、披露及使用。如果你對 Sentry 的政策有任何疑問，請前往 [https://sentry.io/security/](https://sentry.io/security/) 和 [https://sentry.io/privacy/](https://sentry.io/privacy/)，或聯絡 [security@sentry.io](mailto:security@sentry.io) 瞭解詳情。所有由 Sentry 儲存的 Outline 資料都受到嚴密監管，只限 Outline 團隊成員存取。

## 我們在你選擇接受後才會取得的資料
 Outline 會在你選擇接受後向 Outline 團隊匯報以下資料。

 1. 使用情況數據

每個 Outline 伺服器均會自動收集每個存取金鑰在過去一小時的傳輸字節數量、使用者連接伺服器的時間、使用憑證的來源國家/地區和自動系統，以及是否有任何已啟用或停用的功能。系統不會記錄通訊內容或任何可識別個人身分的元數據 (例如登入資料、電郵地址、裝置 ID 等)。所有數據均會連結至伺服器 ID。你可在[這裡](/manager/server-management/reset-server-id)查看變更伺服器 ID 的指示。

 根據預設，Outline 伺服器不會與 Outline 團隊分享這些數據資料。不過如果伺服器管理員明確同意分享這些使用數據，系統就會每小時將這些資料安全地傳送給 Outline 團隊，並在 60 天後以國家/地區為單位來彙整這些使用情況數據。伺服器管理員可隨時前往 Outline Manager 的「設定」選單，變更使用數據分享偏好設定。

 我們非常感謝使用者分享伺服器使用情況的匿名數據，這有助我們評估使用趨勢和改良產品。

 例如，如果伺服器管理員選擇和我們分享使用數據，我們就能得知 ID 12345 的伺服器昨天使用了 3 個小時，分別透過在美國及加拿大的三個金鑰傳輸了共 500 MB 的資料，且已啟用數據用量上限功能。

 2. 你提交的意見內容和電郵地址

 你可透過 Outline Manager 和 Outline 應用程式向我們的團隊提交意見，但建議不要附上個人識別資料。如果你希望收到團隊成員的回覆，可在選填的電郵欄位中提供你的電郵地址。此外，我們亦會自動收集一些基本資料，以便進一步瞭解你的意見。如想知道我們還會收集哪些資料，請參閱上文「系統自動取得的資料」一節中的第 2 點說明。你亦可參閱[這篇文章](/about/security-and-privacy)，進一步瞭解 Outline 的安全性和私隱守則。

 如果你在 Android 裝置上使用 Outline 應用程式 Beta 版本，我們會透過 Google 的 [Firebase](https://firebase.google.com/) 服務收集偵錯資料，以便偵測問題並改良 Outline 的服務品質。如要進一步瞭解 Firebase 的私隱權與安全性政策，請前往 Firebase 網站：[firebase.google.com/support/privacy](https://firebase.google.com/support/privacy)。如果不想讓 Outline 透過 Firebase 傳送這些資料，請使用正式版本應用程式。
