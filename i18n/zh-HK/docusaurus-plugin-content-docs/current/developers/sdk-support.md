此支援網站為 Outline Manager 和用戶端的使用者而設。開發人員應使用 GitHub 尋求支援。如要發問，請在 SDK [討論區](https://github.com/Jigsaw-Code/outline-sdk/discussions)發佈訊息。「討論區」部分是提問、分享想法、連結試用版和支援其他使用 Outline SDK 開發人員的好地方。如想提出功能要求或報告錯誤，請改為建立[問題票證](https://github.com/Jigsaw-Code/outline-sdk/issues/new)。
