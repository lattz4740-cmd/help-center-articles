sidebar_label: "Outline клиентін неліктен Windows жүйесінде орната алмай жатырмын?"
---

Мынадай қате туралы хабар алуыңыз мүмкін: "Өкінішке қарай, Outline дұрыс орнатылмаған сияқты. Оны қайта орнатып көріңіз. Бұл қате қайталанса, [пікір жазып жіберіңіз](/about/feedback)."

Outline қолданбасын Windows жүйесінде пайдаланатын болсаңыз, кейде күтпеген қате пайда болуы мүмкін. Көп жағдайда Outline TAP адаптерін (драйверін) жойып, Outline қолданбасын қайта орнату қажет болады.

Windows операциялық жүйесінің нұсқасына байланысты орындалатын қадамдар әртүрлі болуы мүмкін. Бірақ төменде TAP адаптері мен Outline қолданбасын жойып, Outline қолданбасын қайта орнату жөніндегі жалпы қадамдар беріледі.

1. Outline қолданбасының TAP адаптерін жою үшін:
   - **"Құрылғы менеджерлері** > **Желі адаптерлері"** тармағына өтіңіз.
   - **"TAP-Windows Adapter V9"** деген файлды немесе Outline қолданбасымен байланысты TAP адаптерін іздеңіз.
   - Осы адаптерді жойыңыз. Бұл әрекет орнатылған басқа VPN қолданбаларына әсерін тигізуі мүмкін екенін ескеріңіз.
2. Outline қолданбасын жою үшін:
   - **"Бағдарламалар және функциялар** > **Бағдарламаны жою"** тармағына өтіңіз.
   - Outline клиенті қолданбасын тауып алып, оны жойыңыз
   - [Outline клиентінің соңғы нұсқасын жүктеп алыңыз да,](https://getoutline.org/get-started/#step-3) оны Windows құрылғысына қайта орнатыңыз. Жаңа орнатылған нұсқа жаңа TAP адаптерін автоматты түрде орнатуы керек.

Мәселе сонда да шешілмесе, [қолдау көрсету қызметіне хабарласыңыз](/about/feedback).
