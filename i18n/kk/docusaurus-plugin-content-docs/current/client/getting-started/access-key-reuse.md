sidebar_label: "Рұқсат кілтін бірнеше рет пайдалана аламын ба?"
---

Иә. [Рұқсат кілтіңізді](/about/terminology)құрылғыларда қалағаныңызша пайдалана аласыз, бірақ оны басқа адаммен бөліспеген жөн. Рұқсат кілтіңізді біліп алған адам барлық интернет-трафигіңізді көру рұқсатына ие болса, оны толықтай зерттеп алуы мүмкін, бұдан кейін интернетте қауіпсіздігіңіз бен құпиялылығыңыз сақталмайды.
