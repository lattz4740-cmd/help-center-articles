## Құрылғыны Outline серверіне қосу

[Құрылғыны Outline серверіне қосу үшін сервер әкімшісі сізге өз серверіне бірегей](/about/terminology)рұқсат кілтімен қосылуға шақыру жіберуі керек. Бұл шақыру арқылы мына әрекеттерді орындауға болады:

- егер сізде болмаса, Outline-ды құрылғыға жүктеп алып, орнату;
- сіз бен Outline сервері арасында қауіпсіз байланыс орнату үшін рұқсат кілтін пайдалану.

Серверге қосылғаннан кейін, Outline-ды пайдалану үшін "Қосылу" немесе "Ажырату" түймесін баса аласыз.

*Маңызды:*Outline жұмыс істеуі үшін, рұқсат кілті мен Outline сервері қажет болады. Outline қолданбасын кілтсіз жүктеп алсаңыз және орнатсаңыз, интернет трафигіңіз қорғалмайды.
