## Жалпы ақпарат

Outline серверін Google Cloud-та жұмыс істейтін серверде автоматты түрде реттеуге мүмкіндік беретін функция Outline Manager-де бар. Осы функцияны пайдаланатын болсаңыз, Outline Manager қолданбасы Google аккаунтыңызбен кіруді сұрайды. Кірген кезде, Google Cloud аккаунтын конфигурациялау мақсатында Outline Manager қолданбасын жергілікті дискіге орнату үшін белгілі бір[OAuth](https://developers.google.com/identity/protocols/oauth2) рұқсаттары беріледі.

 Бұл рұқсаттарды бергіңіз келмесе, Outline Manager қолданбасында кеңейтілген реттеу нұсқауларын орындап, Outline қолданбасын Google Cloud Platform-да іске қоса аласыз.

## Берілетін рұқсаттар

Автоматтандырылған реттеуді қамтамасыз ету үшін Outline Manager қолданбасы Google аккаунтынан келесі рұқсаттарды сұрайды.

## Google Cloud Platform

- Google Compute Engine ресурстарын көру және басқару
- Google Cloud қызметтеріндегі деректерді және Google аккаунтыңыздың электрондық мекенжайын көру.

## Негізгі аккаунт туралы ақпарат

- Google аккаунтыңыздың негізгі электрондық мекенжайын көру;
- Сізді Google-дағы жеке ақпаратыңызбен байланыстыру.

## Қосымша рұқсат

- Cloud Platform жобаларын басқару;
- Google Cloud Platform-дағы төлем аккаунттарын көру және басқару;
- Google API қызметтік конфигурациясын басқару.

Бұл рұқсаттар бізге Outline серверлерін басқарудың қосымша мүмкіндігін қолдауға, оның ішінде:

- дұрыс төлем аккаунтын таңдауға;
- жаңа жоба жасап, Outline серверлерін реттеуге;
- қолжетімді деректер орталығының тізімін жасауға;
- Outline жұмыс істейтін жаңа виртуалдық машиналарды жасауға;
- жаңа виртуалдық машиналарды Outline-мен конфигурациялауға мүмкіндік береді.

## Рұқсаттарды қайтару

[Аккаунтым](https://myaccount.google.com/permissions) бетіне өтіп, Outline Manager үшін Google Cloud Platform рұқсатын қайтара аласыз. Рұқсатты қайтарсаңыз, автоматты реттеумен жасаған барлық сервер жұмыс істей береді, бірақ Outline Manager-де бұдан былай көрсетілмейді. Рұқсаттарды қалпына келтіру үшін автоматты реттеу ағынын бастау арқылы Google Cloud Platform-ға қайта жалғасаңыз жеткілікті.

## Outline жобасын реттеу

Google Cloud автоматты реттеуі Outline серверлерін реттеуге бір[Google Cloud жобасын](https://cloud.google.com/resource-manager/docs/creating-managing-projects) пайдаланады. Жоба автоматты реттеуді алғаш пайдаланған кезде жасалады. Онда "Outline-" деп басталатын ұсынылған жоба идентификаторы, содан кейін кездейсоқ таңбалардан құрылған жол болады. Қаласаңыз, жобаны жасаған кезде, оған басқа идентификаторды таңдай аласыз. Жоба "Outline серверлері" деп аталады.

## Төлем аккаунты

Google Cloud жобалары төлем туралы ақпарат көрсетілген "төлем аккаунтымен" байланыстырылуы керек. Google Cloud автоматты реттеуін алғаш пайдаланған кезде, Outline серверлерімен байланыстыру үшін сізден төлем аккаунты сұралады. Кейде төлем аккаунтына қатысты мәселе туындаған жағдайда, сервер жұмыс істемейді. Мұндай жағдайда[Google Cloud консоліне](https://console.cloud.google.com/getting-started) кіріп, Outline-мен байланыстырылған Google Cloud жобасын ("Outline серверлері" деп аталады) тауып, төлем параметрлерін жаңартуыңыз керек.

## Серверлерді жою

Автоматты реттеу функциясымен жасалған серверлерді жоюдың ең оңай жолы – Outline Manager арқылы жою. Алайда серверлерді өзіңіз жойғыңыз келсе,[Google Cloud консоліне](https://console.cloud.google.com/getting-started) кіріп, бастапқы реттеу кезінде жасалған жобаны ("Outline серверлері" деп аталады) тауып, ол жерден ресурстарды жойыңыз немесе жобаны өшіріңіз.
