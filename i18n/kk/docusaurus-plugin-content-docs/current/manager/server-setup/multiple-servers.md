sidebar_label: Бірнеше Outline серверін реттеу жолы
---

Қосымша Outline серверлерін реттеу үшін Outline Manager қолданбасының сол жағындағы навигация панеліндегі "+" белгішесін түртіңіз. Жаңа серверді енгізу нұсқаулары біріншісін орнатқан кездегімен бірдей болады.

- Қанша Outline серверін жасай алатыныңызға шектеу қойылмайды.
- Әр жасалған Outline сервері үшін сәйкес виртуалдық машина қажет болады.
- Қосымша машиналар немесе дроплеттер жасасаңыз, бұлт қызметтері провайдеріне жіберетін төлемдеріңіз артуы мүмкін. Нені күте алатыныңызды білу үшін бұлт қызметтері провайдерінен баға пакетін нақтылаңыз.

## DigitalOcean қызметінде қосымша Outline серверін жасау

"+" белгішесін басып, DigitalOcean қызметінде орнатуды таңдағаннан кейін, бірінші серверді реттеген кезде қолданған нұсқауларды қайта орындайсыз. Сонымен қатар Outline Manager қолданбасы DigitalOcean қызметімен біріктірілгендіктен, сізді Outline manager қолданбасынан шығармай-ақ дроплет жасай аламыз.

Outline Manager бір уақытта тек бір DigitalOcean аккаунтымен жұмыс істейтінін ескеріңіз. Егер басқа DigitalOcean аккаунттарынан басқа Outline серверлерін қосқыңыз не жасағыңыз келсе, оларды кеңейтілген конфигурация ретінде қоса аласыз.

## GCP, AWS немесе басқа бұлт қызметтері провайдерінде қосымша Outline серверін жасау

Таңдаған бұлт қызметтері провайдеріңізбен жаңа виртуалдық машинаны жасаудан бастаңыз. Одан кейін Outline Manager қолданбасын ашып, кеңейтілген орнату нұсқауларын дәл алғашқысындай орындап шығыңыз.
