---
title: "Outline серверін қалай реттеуге болады?"
sidebar_label: "Outline серверін қалай реттеуге болады?"
---

Outline-ды пайдалану Outline серверін реттеуден басталады. Outline арқылы ашық интернетке қосыла алуыңыз үшін, өзіңіз немесе сенімді адам сіз үшін серверді реттеуі керек.

**Бастау алдында**

 Outline серверін реттеу алдында, сізге келесілер қажет болады:

1. DigitalOcean, Amazon Web Services (AWS) немесе Google Cloud Platform (GCP) сияқты өз серверлеріңізді немесе бұлт қызметтері провайдерін пайдалану мүмкіндігі.

 Егер бұлт серверін пайдалану рұқсатыңыз болмаса, кез келген провайдермен, соның ішінде жоғарыда аталған провайдерлермен аккаунтты оңай реттей аласыз. Тіркелу үшін несиелік карта қажет болуы мүмкін.
2. macOS 10.9+, Windows 7.0+ немесе Linux жүйесімен істейтін компьютер.
3. Outline Manager қолданбасы.

**DigitalOcean арқылы реттеу**

 Кез келген пайдаланушы Outline-ды DigitalOcean-ға бірнеше кликпен орнататындай етіп жеңілдеттік. Outline Manager бағдарламасын жүктеп алып, орнатқаннан кейін, Outline серверін орнату және конфигурациялау үшін DigitalOcean-ды реттеу опциясын таңдап, бірнеше қарапайым экраннан өте аласыз.

**Басқа бұлт қызметтері провайдерімен реттеу**

 Outline Manager бағдарламасын жүктеп алып, орнатқаннан кейін, Outline серверін AWS, GCP, DigitalOcean бар виртуалдық машинада немесе басқа провайдерде орнатуды таңдай аласыз. Әр орта әртүрлі болғандықтан, ең көп қолданылатын бұлт қызметтері провайдерлеріне арналған Outline Manager-ді реттеу процедурасына нұсқауларды енгіздік. Онда Outline-ды серверде орнату скриптісін іске қосар алдында виртуалдық машинада параметрлерді қалай конфигурациялау керектігі де түсіндіріледі.
