sidebar_label: "Outline Manager қызметі неліктен Windows жүйесіне орнатылмай жатыр?"
---

Мынадай қате туралы хабар алуыңыз мүмкін: "Өкінішке қарай, Outline дұрыс орнатылмаған сияқты. Оны қайта орнатып көріңіз. Бұл қате қайталанса, [бізге хабарласыңыз](https://support.getoutline.org/s/contactsupport?)."

Outline қолданбасын Windows жүйесінде пайдаланатын болсаңыз, кейде күтпеген қате пайда болуы мүмкін. Көп жағдайда Outline TAP адаптерін (драйверін) жойып, Outline қолданбасын қайта орнату қажет болады.

Windows операциялық жүйесінің нұсқасына байланысты орындалатын қадамдар әртүрлі болуы мүмкін. Бірақ төменде TAP адаптері мен Outline Manager қолданбасын жойып, Outline Manager қолданбасын қайта орнату жөніндегі жалпы қадамдар беріледі.

1. Outline Manager қолданбасының TAP адаптерін жою
   1. "Құрылғы менеджерлері > Желі адаптерлері" тармағына өтіңіз.
   2. "TAP-Windows Adapter V9" файлын немесе Outline қолданбасымен байланысты TAP адаптерін табыңыз.
   3. Осы адаптерді жойыңыз. Бұл әрекет орнатылған басқа VPN қолданбаларына әсерін тигізуі мүмкін екенін ескеріңіз.
2. Outline Manager қолданбасын жою
   1. "Бағдарламалар және функциялар > Бағдарламаны жою" тармағына өтіңіз.
   2. Outline Manager қолданбасын тауып, оны жойыңыз.
   3. [Outline Manager қолданбасының соңғы нұсқасын жүктеп алыңыз](https://getoutline.org/get-started/#step-1) және оны Windows құрылғысына қайта орнатыңыз. Жаңа орнатылған нұсқа жаңа TAP адаптерін автоматты түрде орнатуы керек.

Мәселе сонда да шешілмесе, [қолдау қызметіне хабарласыңыз.](https://support.getoutline.org/s/contactsupport?)
