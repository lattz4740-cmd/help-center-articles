---
title: "Outline серверлік бағдарламасын қалай жаңартуға болады?"
sidebar_label: "Outline серверлік бағдарламасын қалай жаңартуға болады?"
---

Outline серверлеріне соңғы қауіпсіздік жақсартулары автоматты түрде енгізіліп тұратындықтан, әрдайым ең жаңа Outline технологиясы қолданылады. Автоматтандырылған жаңарту процесі [Watchtower](https://github.com/v2tec/watchtower) көмегімен қосылады. Бұл ашық кодты жинақ Outline бағдарламалық құралын қамтитын Docker кескінін тұрақты түрде тексеріп, жаңартады.

Сондай-ақ Outline Manager көмегімен Outline қолданбасын орнатқан кезде, [Автоматты жаңартулар](https://wiki.debian.org/UnattendedUpgrades) (Ubuntu) арқылы сервердегі бағдарламалық құралды автоматты түрде жаңарту үшін cron тапсырмасын орнатамыз және қажет болса, оны қайта жүктейміз. Хост Outline қызметін іске қосудан басқа мақсаттарда пайдаланылатын болса, мұндай процесс ағымдағы конфигурацияны сақтау үшін Озық режимде шықпайтынын ескеріңіз.
