Outline серверін орнатып болған соң, адамдардың оны пайдалану рұқсатын бөлісе және басқара аласыз. Сізден шақыру алған адамдар өз интернет трафигін қорғауға Outline-ды пайдалану үшін Outline қолданбасын жүктеп ала алады.

**Outline серверін пайдалану рұқсатын бөлісу**

 Outline серверін орнатып болған соң, Outline Manager-де сервер мәліметтері бетіне бағытталып, онда рұқсат кілттерін жасай аласыз. [Рұқсат кілттері](/about/terminology) туралы толық ақпарат алыңыз.

- Кілттер жасау: жаңа кілттер жасау үшін беттің төменгі жағындағы кішкентай "+" белгішесін басыңыз.
- Кілттерді бөлісу: әр перненің оң жағында бөлісу белгісі бар, оны басып, шақыру ала аласыз. Бұл шақыруды сіз таңдаған хабар алмасу жүйесіне көшіріңіз және қойыңыз.

**Функция сұрауы: Outline Manager қолданбасынан пайдалану рұқсатын бөлісу**

 Көптеген сервер әкімшісі оларға әлдекімнің электрондық мекенжайын тікелей Outline Manager-ге енгізу опциясын беріп, шақыру процесін жеңілдетуді сұрайды.

Өкінішке орай, біз бұл функцияны Outline Manager-ге ендіре алмауымыз мүмкін. Негізгі принциптеріміздің бірі – пайдаланушыларымыздың құпиялығы мен қауіпсіздігін қолдау. Яғни біз электрондық пошта мекенжайларын немесе байланыс ақпаратын енгізу үшін ешқандай орын әзірлеген жоқпыз.

Сондықтан біз сервер әкімшілерінен түпкі пайдаланушыға шақыруды электрондық пошта немесе қауіпсіз чат сияқты қауіпсіз хабар алмасу платформасы арқылы жіберуді сұраймыз.

**Сіз рұқсат кілтін онымен бөліскеннен кейін, пайдаланушы үшін не өзгереді?**

1. Пайдаланушы құрылғыдан орнату сілтемесін басады.
2. Егер онда болмаса, оған Outline қолданбасын орнату ұсынылады.
3. Ол шақыруға ендірілген бірегей кілтпен Outline серверімен бастапқы қосылым орнатады.
4. Енді ол Outline серверіңіз арқылы интернетке кіруін басқару үшін қосылу/ажырату түймесін пайдалана алады.

**Outline серверіне кіру рұқсатын жою**

 Outline Manager-дегі сервер туралы мәліметтер бетінде сервердегі әр кілттің оң жағында кілтті жою опциясы бар мәзірді көресіз. Кілтті жойсаңыз, ол серверге кіре алмай қалады.
