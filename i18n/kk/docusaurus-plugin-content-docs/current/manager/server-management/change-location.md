---
title: "Outline серверінің орнын қалай өзгертуге болады?"
sidebar_label: "Outline серверінің орнын қалай өзгертуге болады?"
---

Сервер реттелгеннен кейін, оның орнын өзгерту мүмкін емес. Серверді басқа орыннан іске қосу үшін Outline серверін жойып, жаңасын жасау керек.

Балама әдіс ретінде серверлерді ауыстырып, бірдей кілттерді сақтауға мүмкіндік беретін [динамикалық кілттер](https://developer.getoutline.org/vpn/management/dynamic-access-keys/) арқылы да VPN орнын өзгертуіңізге болады. Серверлердің орны өздігінен өзгермейді.
