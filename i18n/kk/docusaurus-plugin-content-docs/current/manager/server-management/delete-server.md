---
title: "Outline серверін қалай жоюға болады?"
sidebar_label: "Outline серверін қалай жоюға болады?"
---

Бұлт қызметтері провайдерлерінің көбісі үшін сіз қолданатын нақты виртуалдық машинаны өшіру оп-оңай.

Егер бұлт қызметтері провайдері ретінде DigitalOcean пайдаланылса, тегершік түймесін басып, "Серверді жою" пәрменін таңдау арқылы қолданыстағы виртуалдық машинаны жоя аласыз. Осыдан кейін бірден сізден таңдаған жеріңізден жаңа виртуалдық машина жасау сұралады.

Егер Outline серверін өшірсеңіз, ол біржола жойылады және оның рұқсат кілттері жұмыс істемей қалады. Егер адамдардың Outline арқылы серверді пайдалануын тоқтатуын қаламасаңыз, [жаңа Outline серверін орнату](/manager/server-setup/setup-server) және ескісін жоймас бұрын, кіру рұқсатын бөлісу қажет болады.
