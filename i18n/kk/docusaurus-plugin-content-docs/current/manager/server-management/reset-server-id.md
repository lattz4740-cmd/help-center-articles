---
title: "Сервер идентификаторын қалай қайта орнатуға болады?"
sidebar_label: "Сервер идентификаторын қалай қайта орнатуға болады?"
---

Сервер идентификаторы – Outline серверін құру кезінде кездейсоқ ретпен жасалатын серверлік идентификатор. Оны "Параметрлер" интерфейсіндегі аноним көрсеткіштерді бөлісуге келіскен кезде көресіз. Сервер идентификаторын былай таба аласыз: "Параметрлер => төмен қарай айналдырыңыз => "аноним көрсеткіштерді бөлісу" ұясына белгі қойыңыз.

Сервер идентификаторы уақыт өте келе есеп берілген аноним қолданыс статистикасын біріктіреді. Cервер идентификаторын қайта орнатып, жаңасын алғыңыз келсе, қолданыстағы Outline серверін жаңасына ауыстырыңыз.

Бұлт қызметтері провайдері ретінде DigitalOcean қызметін пайдаланылып жатсаңыз, серверді қайта орнату үшін "Параметрлер" бөліміне өтіп, "Серверді жою" тармағын таңдауыңызға болады. Бұл әрекет қайтарылмайды және оның нәтижесінде тіркелу деректері жойылады. Осыдан кейін бірден сізден өзіңіз таңдаған жерде жаңа сервер құру сұралады да, жаңа сервер идентификаторы жасалады.
