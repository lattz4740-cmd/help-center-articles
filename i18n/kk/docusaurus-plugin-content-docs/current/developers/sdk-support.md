sidebar_label: "Мен әзірлеушімін. Outline SDK жиынтығын қолданбама интеграциялау бойынша көмекті қайдан таба аламын?"
---

Осы көмек көрсету веб-сайты Outline Manager және Client қолданбасының пайдаланушыларына арналған. Әзірлеушілер, көмек алу үшін GitHub сайтын пайдаланыңыз. Сұрақтарыңызды SDK [Талқылау тақтасында](https://github.com/Jigsaw-Code/outline-sdk/discussions) қойыңыз. "Талқылау тақтасы" бөлімі – сұрақ қоюға, идеяларды бөлісуге, демо нұсқаларға сілтеме қалдыруға және Outline SDK жиынтығын пайдаланатын басқа әзірлеушілерге көмек беруге арналған таптырмас орын. Ал функцияларға қатысты сұраулар немесе қате туралы есептер жіберу үшін [Мәселе](https://github.com/Jigsaw-Code/outline-sdk/issues/new) бөлімін ашыңыз.
