---
title: "Kaip galiu nustatyti „Outline“ serverį?"
sidebar_label: "Kaip galiu nustatyti „Outline“ serverį?"
---

Kad galėtumėte naudoti „Outline“, pirmiausia turite nustatyti „Outline“ serverį. Jūs (arba asmuo, kuriuo pasitikite) turite nustatyti serverį, kad galėtumėte prisijungti prie atviro interneto naudodami „Outline“.

**Prieš pradedant**

 Prieš pradedant „Outline“ serverio nustatymo procesą, reikės kelių toliau nurodytų dalykų.

1. Prieiga prie savo serverių arba debesies paslaugų teikėjo, pvz., „DigitalOcean“, „Amazon Web Services“ (AWS) arba „Google Cloud Platform“ (GCP).

 Jei iš karto neturėsite prieigos prie debesies serverio, galėsite lengvai nustatyti paskyrą naudodami bet kurį teikėją, įskaitant nurodytus anksčiau. Prisiregistruojant tikriausiai reikės kredito kortelės.
2. Stalinis kompiuteris, kuriame veikia 10.9 ar naujesnės versijos „macOS“, 7.0 ar naujesnės versijos „Windows“ arba „Linux“.
3. Programa „Outline Manager“.

**Nustatymas naudojant „DigitalOcean“**

 Naudotojai gali lengvai įdiegti „Outline“ sistemoje „DigitalOcean“ vos keliais paspaudimais. Atsisiuntę ir įdiegę „Outline Manager“ kompiuteryje, galite pasirinkti „DigitalOcean“ nustatymo parinktį ir bus pateikti veiksmai, kuriuos turėsite atlikti keliuose paprastuose ekranuose, kad sukonfigūruotumėte ir įdiegtumėte „Outline“ serverį.

**Nustatymas naudojant kitą debesies paslaugų teikėją**

 Atsisiuntę ir įdiegę „Outline Manager“, galite pasirinkti įdiegti „Outline“ serverį virtualiajame įrenginyje naudodami AWS, GCP, „DigitalOcean“ arba kitą teikėją. Kiekviena aplinka skiriasi, todėl įtraukėme dažniausiai naudojamų debesies paslaugų teikėjų taikomas „Outline Manager“ nustatymo proceso instrukcijas, įskaitant nustatymų konfigūravimą virtualiajame įrenginyje prieš paleidžiant diegimo scenarijų, norint įdiegti „Outline“ serveryje.
