sidebar_label: "Који су системски захтеви за покретање Outline клијента?"
---

Outline можете да испробате у било ком оперативном систему. У наставку су наведени минимални захтеви у погледу оперативних система:

| **Оперативни систем** | **Минимална верзија** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Желите да нам помогнете да омогућимо Outline клијент за више оперативних система? [Дајте свој допринос нашој бази кодова](https://github.com/Outline-Foundation/outline-client#platform-specific-development) на GitHub-у!
