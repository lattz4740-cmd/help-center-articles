## Преглед

Outline Manager има функцију која вам омогућава да Outline сервер аутоматски конфигуришете на серверу који је активан у Google Cloud-у. Ако одлучите да користите ову функцију, Outline Manager ће тражити да се пријавите помоћу Google налога, чиме ће локалној инсталацији Outline Manager-а бити одобрене одређене [OAuth](https://developers.google.com/identity/protocols/oauth2) дозволе ради конфигурисања Google Cloud налога.

 Ако не желите да дате ове дозволе, можете да пратите упутства за напредно подешавање у Outline Manager-у да бисте покренули Outline на Google Cloud Platform-у.

## Одобрене дозволе

Да би Outline Manager обавио аутоматско подешавање, потребне су му ове дозволе за Google налог.

## Google Cloud Platform

- Преглед Google Compute Engine ресурса и управљање њима
- Преглед података у Google Cloud услугама и имејл адресе Google налога

## Основне информације о налогу

- Преглед примарне имејл адресе Google налога
- Повезивање вас са вашим личним подацима на Google-у

## Додатни приступ

- Управљање Cloud Platform пројектима
- Преглед Google Cloud Platform налога за обрачун и управљање њима
- Управљање конфигурацијом Google API услуге

Ове дозволе нам омогућавају да подржавамо напредне функције за управљање Outline серверима, укључујући:

- Могућност да изаберете одговарајући налог за обрачун
- Прављење новог пројекта ради организовања Outline сервера
- Навођење доступних центара података
- Прављење нових виртуелних машина за покретање Outline-а
- Конфигурисање нове виртуелне машине помоћу Outline-а

## Опозивање дозвола

Приступ Google Cloud Platform-у за Outline Manager можете да опозовете ако одете на [Мој налог](https://myaccount.google.com/permissions). Ако опозовете приступ, сви сервери које сте направили помоћу аутоматског подешавања остају активни, али се више не приказују у Outline Manager-у. Да бисте вратили приступ серверима, поново се повежите са Google Cloud Platform-ом покретањем процеса аутоматског подешавања.

## Организација Outline пројекта

Аутоматско подешавање Google Cloud-а користи један[Google Cloud пројекат](https://cloud.google.com/resource-manager/docs/creating-managing-projects) за организовање Outline сервера. Пројекат се прави током првог коришћења аутоматског подешавања са предложеним ИД-ом пројекта који почиње са „Outline-“, а завршава се стрингом насумичних знакова. Ако желите, при прављењу можете да изаберете други ИД пројекта. Пројекат ће бити назван „Outline сервери“.

## Налог за обрачун

Google Cloud пројекти захтевају повезани „налог за обрачун“ који дефинише информације о плаћању. Кад први пут користите аутоматско подешавање Google Cloud-а, затражићемо да наведете налог за обрачун који ћете повезати са Outline серверима. Понекад ће сервер престати да ради јер постоји проблем са налогом за обрачун. У том случају, треба да се пријавите на[Google Cloud Console](https://console.cloud.google.com/getting-started), пронађете Google Cloud пројекат повезан са Outline-ом (под називом „Outline сервери“) и промените подешавања обрачуна.

## Уништавање сервера

Ако желите да уништите сервере направљене помоћу аутоматског подешавања, то најлакше можете да урадите у Outline Manager-у. Али, ако желите да сами уништите сервере, можете да се пријавите на [Google Cloud Console](https://console.cloud.google.com/getting-started), пронађете пројекат који сте направили током почетног подешавања (под називом „Outline сервери“) и тамо избришите ресурсе или искључите пројекат.
