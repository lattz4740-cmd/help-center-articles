---
title: "Како да ресетујем ИД сервера?"
sidebar_label: "Како да ресетујем ИД сервера?"
---

ИД сервера је ИД на страни сервера који се насумично генерише кад направите Outline сервер. Можете да га пронађете кад се сагласите да делите анонимне показатеље у интерфејсу Подешавања. ИД сервера можете да пронађете у: Подешавања => скролујте до дна => означите „делите анонимне показатеље“.

ИД сервера обједињује анонимне статистике коришћења пријављене током времена. Ако желите да ресетујете ИД сервера и добијете нов, морате да замените постојећи Outline сервер новим.

Ако користите DigitalOcean као добављача клауда, можете да ресетујете сервер тако што ћете отићи у Подешавања и изабрати Избриши сервер. Ту радњу не можете да опозовете, а тиме се бришу и акредитиви. Одмах после ове радње тражиће се од вас да направите нови сервер на локацији коју одаберете и нови ИД сервера биће генерисан.
