---
title: "Како да ажурирам Outline софтвер сервера?"
sidebar_label: "Како да ажурирам Outline софтвер сервера?"
---

Outline сервери се аутоматски ажурирају најновијим побољшањима безбедности да бисте увек користили најновију Outline технологију. Процес аутоматског ажурирања омогућава [Watchtower](https://github.com/containrrr/watchtower), библиотека отвореног кода која редовно проверава и ажурира Docker слику која садржи Outline софтвер.

Поред тога, кад инсталирате Outline помоћу Outline Manager-а, подешавамо Cron посао који аутоматски надограђује софтвер на серверу помоћу [Надоградње без надзора](https://wiki.debian.org/UnattendedUpgrades) (Ubuntu) и по потреби га рестартује. Имајте на уму да се ово не примењује у Напредном режиму да би се задржала постојећа конфигурација, под претпоставком да се хост користи за друге сврхе поред покретања Outline-а.
