---
title: "Како да избришем Outline сервер?"
sidebar_label: "Како да избришем Outline сервер?"
---

Већина добављача клауда омогућава једноставно уклањање одређене виртуелне машине коју користите.

Ако користите DigitalOcean као добављача клауда, постојећу виртуелну машину можете да избришете ако кликнете на дугме зупчаника и изаберете Избриши сервер. Одмах после тога тражиће се од вас да направите нову виртуелну машину на локацији коју одаберете.

Ако уклоните Outline сервер, он се трајно брише и његови приступни кључеви више не функционишу. Ако не желите да људи имају прекид кад приступају преко Outline-а, треба да [подесите нови Outline сервер](/manager/server-setup/setup-server) и да са њим поделите приступ пре него што избришете стари сервер.
