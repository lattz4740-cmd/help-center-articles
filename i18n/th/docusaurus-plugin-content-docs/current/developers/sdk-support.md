เว็บไซต์สนับสนุนนี้มีไว้สำหรับผู้ใช้ Outline Manager และผู้ใช้ไคลเอ็นต์ นักพัฒนาแอป โปรดใช้ GitHub เพื่อรับการสนับสนุน หากต้องการถามคำถาม โปรดโพสต์ใน[กระดานสนทนา](https://github.com/Jigsaw-Code/outline-sdk/discussions)ของ SDK ซึ่งส่วนกระดานสนทนาเป็นพื้นที่ที่เหมาะสำหรับการถามคำถาม แชร์แนวคิด โพสต์ลิงก์ไปยังเดโม และสนับสนุนนักพัฒนาแอปรายอื่นๆ ที่ใช้ Outline SDK หากต้องการส่งคำขอฟีเจอร์หรือรายงานข้อบกพร่อง โปรดเปิด[ปัญหา](https://github.com/Jigsaw-Code/outline-sdk/issues/new)แทน
