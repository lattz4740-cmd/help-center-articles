คุณสามารถทดลองใช้ Outline ได้ในระบบปฏิบัติการทุกระบบ ต่อไปนี้คือระบบปฏิบัติการขั้นต่ำที่ต้องการ

| **ระบบปฏิบัติการ** | **เวอร์ชันต่ำสุด** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

ต้องการช่วยให้ไคลเอ็นต์ Outline ใช้งานในระบบปฏิบัติการอื่นๆ หรือไม่ [ร่วมสร้างฐานของโค้ดกับเรา](https://github.com/Jigsaw-Code/outline-client#platform-specific-development)ที่ GitHub
