---

ได้ คุณสามารถใช้[คีย์การเข้าถึง](/about/terminology)ในอุปกรณ์กี่เครื่องก็ได้ แต่เราไม่แนะนำให้แชร์คีย์กับบุคคลอื่น บุคคลอื่นที่มีคีย์การเข้าถึงของคุณอาจตรวจสอบการเข้าใช้อินเทอร์เน็ตทั้งหมดได้หากมีสิทธิ์เข้าถึง ซึ่งจะทำให้การใช้งานอินเทอร์เน็ตของคุณไม่ปลอดภัยและไม่มีความเป็นส่วนตัวอีกต่อไป
