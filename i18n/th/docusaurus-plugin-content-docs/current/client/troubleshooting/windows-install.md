sidebar_label: ทำไมฉันถึงติดตั้งไคลเอ็นต์ Outline บน Windows ไม่ได้
---

คุณอาจเห็นความแสดงข้อผิดพลาดนี้ "ขออภัย ดูเหมือนว่า Outline ไม่ได้ติดตั้งอย่างถูกต้อง โปรดลองติดตั้งอีกครั้ง หากไม่ได้ผล โปรด[ส่งความคิดเห็น](/about/feedback)"

หากคุณใช้ Outline ใน Windows บางครั้งคุณอาจพบข้อผิดพลาดที่ไม่คาดคิด ในกรณีส่วนใหญ่ คุณจะต้องลบอะแดปเตอร์ (ไดรเวอร์) Outline TAP และควรติดตั้ง Outline อีกครั้ง

ขั้นตอนอาจแตกต่างกันไปตามเวอร์ชันของระบบปฏิบัติการ Windows แต่ด้านล่างนี้เป็นขั้นตอนทั่วไปในการถอนการติดตั้งอะแดปเตอร์ TAP และ Outline แล้วติดตั้ง Outline อีกครั้ง

1. ถอนการติดตั้งอะแดปเตอร์ TAP สำหรับไคลเอ็นต์ Outline
   1. ไปที่**โปรแกรมจัดการอุปกรณ์** จากนั้นไปที่**อะแดปเตอร์เครือข่าย**
   2. ค้นหาไฟล์ **TAP-Windows Adapter V9** หรืออะแดปเตอร์ TAP ที่เชื่อมโยงกับ Outline
   3. ถอนการติดตั้งหรือลบอะแดปเตอร์นี้ โปรดทราบว่าการดำเนินการนี้อาจส่งผลต่อแอป VPN อื่นๆ ที่คุณติดตั้งไว้
2. ถอนการติดตั้งไคลเอ็นต์ Outline
   1. ไปที่**โปรแกรมและฟีเจอร์** จากนั้นไปที่**ถอนการติดตั้งโปรแกรม**
   2. ค้นหาแอปไคลเอ็นต์ Outline แล้วถอนการติดตั้งแอปดังกล่าว
   3. [ดาวน์โหลดไคลเอ็นต์ Outline เวอร์ชันล่าสุด](https://getoutline.org/get-started/#step-3) แล้วติดตั้งแอปในอุปกรณ์ Windows อีกครั้ง ซึ่งการติดตั้งดังกล่าวจะทำให้ระบบติดตั้งอะแดปเตอร์ TAP ใหม่โดยอัตโนมัติ

หากยังคงพบปัญหา โปรด
