ซอฟต์แวร์ Outline เปิดให้ทุกคนใช้งานฟรี ไม่ว่าคุณจะเป็นผู้ดูแลระบบเซิร์ฟเวอร์ที่จัดการ VPN หรือผู้ที่ใช้ Outline เพื่อเข้าถึงอินเทอร์เน็ตแบบเปิด

 Outline ทำงานได้โดยไม่จำเป็นต้องเข้าถึงเซิร์ฟเวอร์ระบบคลาวด์ ผู้ดูแลระบบเซิร์ฟเวอร์ที่มีสิทธิ์เข้าถึงเซิร์ฟเวอร์อยู่แล้วจะติดตั้ง Outline ในเซิร์ฟเวอร์ได้โดยไม่มีค่าใช้จ่ายเพิ่มเติม ส่วนผู้ที่ไม่มีสิทธิ์เข้าถึงเซิร์ฟเวอร์จะเข้าถึงได้จากผู้ให้บริการระบบคลาวด์ เช่น [DigitalOcean](https://www.digitalocean.com/) หรือ Amazon Web Services โดยมีค่าใช้จ่ายราว $5 USD ต่อเดือนสำหรับการอนุญาตการโอนข้อมูลขนาด 1 เทราไบต์ ซึ่งเพียงพอที่จะรองรับผู้ใช้หลายร้อยคนในเซิร์ฟเวอร์เดียว

 ตัวอย่างของวิธีการคำนวณค่าใช้จ่ายในการใช้ Outline กับผู้ให้บริการระบบคลาวด์ที่คุณเลือก มีดังนี้

| *ในกรณีที่ผู้ใช้หนึ่งรายมีการใช้งานเพื่อโอนถ่ายข้อมูลเฉลี่ยต่อเดือนประมาณ 5 กิกะไบต์ แพ็กเกจราคา $5 USD ต่อเดือนจะอนุญาตให้ผู้ใช้ 200 รายใช้งานได้พร้อมกัน ทำให้ผู้ใช้หนึ่งรายจ่ายแค่เพียง 2.5 เซนต์ต่อเดือนเท่านั้น โปรดทราบว่าการโอนถ่ายข้อมูลที่ใช้ต่อเดือนต่อผู้ใช้หนึ่งรายจะแตกต่างกันโดยสิ้นเชิง ทั้งนี้ขึ้นอยู่ว่าผู้ใช้ทำกิจกรรมแบนด์วิดท์มากหรือน้อย แต่ผู้ให้บริการระบบคลาวด์ส่วนใหญ่จะยืดหยุ่นเพื่อรองรับการเข้าชมที่เพิ่มขึ้น* |
| --- |

ในความเป็นจริง การใช้ Outline จะทำให้ Jigsaw และ Google ระบุตัวตนไม่ได้อย่างสิ้นเชิง เราจะไม่ติดตามข้อมูลประจำตัวและการเข้าชมของคุณ และไม่มีแผนที่จะคิดค่าบริการด้วย ในทางกลับกัน เราจะทำงานร่วมกับชุมชนโอเพนซอร์สเพื่อให้มั่นใจว่าเราจะให้บริการซอฟต์แวร์แก่ผู้ใช้ได้โดยไม่มีค่าใช้จ่าย ดูข้อมูลเพิ่มเติมเกี่ยวกับข้อมูลที่เรารวบรวมได้[ที่นี่](/about/data-collection)
