หากต้องการตั้งค่าเซิร์ฟเวอร์ Outline เพิ่มเติม ให้คลิกไอคอน “+” ในแผงการนำทางด้านซ้ายของแอปพลิเคชัน Outline Manager วิธีการเพิ่มเซิร์ฟเวอร์ใหม่จะเหมือนกับวิธีที่คุณติดตั้งในครั้งแรก

- คุณจะสร้างเซิร์ฟเวอร์ Outline ได้ไม่จำกัด
- สำหรับเซิร์ฟเวอร์ Outline ทุกเครื่องที่คุณสร้าง คุณจะต้องมีเครื่องเสมือนที่ตรงกัน
- ผู้ให้บริการระบบคลาวด์อาจคิดค่าธรรมเนียมเพิ่มเติมเมื่อมีการสร้างเครื่องหรือ Droplet เพิ่ม โปรดตรวจสอบราคาของแพ็กเกจกับผู้ให้บริการระบบคลาวด์เพื่อให้แน่ใจว่าคุณจะได้ใช้งานแพ็กเกจที่ตรงกับความต้องการ

## การสร้างเซิร์ฟเวอร์ Outline เพิ่มเติมใน DigitalOcean

หลังจากคลิกไอคอน + และเลือกติดตั้งใน DigitalOcean แล้ว คุณจะต้องทำตามวิธีการเดียวกับที่เคยทำในการตั้งค่าเซิร์ฟเวอร์แรก อีกทั้งเนื่องจาก Outline Manager ผสานรวมกับ DigitalOcean เราจะสร้าง Droplet ให้กับคุณโดยที่ไม่ต้องออกจากแอป Outline Manager

 โปรดทราบว่า Outline Manager จะรองรับบัญชี DigitalOcean ครั้งละ 1 บัญชีเท่านั้น หากต้องการเพิ่มหรือสร้างเซิร์ฟเวอร์ Outline จากบัญชี DigitalOcean อื่น ให้เพิ่มเซิร์ฟเวอร์เหล่านั้นเป็นการกำหนดค่าขั้นสูงแทน

## การสร้างเซิร์ฟเวอร์ Outline เพิ่มเติมใน GCP, AWS หรือผู้ให้บริการระบบคลาวด์รายอื่น

เริ่มต้นด้วยการสร้างเครื่องเสมือนใหม่กับผู้ให้บริการระบบคลาวด์ที่ต้องการ จากนั้นเปิด Outline Manager และทำตามวิธีการติดตั้งขั้นสูงให้เสร็จสมบูรณ์ เช่นเดียวกับการดำเนินการครั้งแรก
