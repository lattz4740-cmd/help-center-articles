Outline Manager มีฟีเจอร์ที่ช่วยให้คุณกําหนดค่าเซิร์ฟเวอร์ Outline ในเซิร์ฟเวอร์ที่ทํางานใน Google Cloud ได้โดยอัตโนมัติ หากเลือกใช้ฟีเจอร์นี้ Outline Manager จะขอให้คุณลงชื่อเข้าใช้ด้วยบัญชี Google ซึ่งจะให้สิทธิ์บางอย่างกับ[OAuth](https://developers.google.com/identity/protocols/oauth2) ในการติดตั้ง Outline Manager เพื่อจุดประสงค์ในการกําหนดค่าบัญชี Google Cloud

หากไม่ต้องการให้สิทธิ์เหล่านี้ โปรดทําตามวิธีการตั้งค่าขั้นสูงใน Outline Manager เพื่อเรียกใช้ Outline ใน Google Cloud Platform

## ได้รับสิทธิ์แล้ว

Outline Manager ต้องใช้สิทธิ์ต่อไปนี้จากบัญชี Google ของคุณในการตั้งค่าอัตโนมัติ

## Google Cloud Platform

- ดูและจัดการแหล่งข้อมูล Google Compute Engine ของคุณ
- ดูข้อมูลในบริการของ Google Cloud รวมถึงดูอีเมลของบัญชี Google

## ข้อมูลบัญชีทั่วไป

- ดูอีเมลหลักของบัญชี Google
- เชื่อมโยงตัวคุณกับข้อมูลส่วนบุคคลใน Google

## การเข้าถึงเพิ่มเติม

- จัดการโครงการ Cloud Platform
- ดูและจัดการบัญชีสำหรับการเรียกเก็บเงินบน Google Cloud Platform ของคุณ
- จัดการการกำหนดค่าบริการ Google API

## สิทธิ์เหล่านี้ช่วยให้เรารองรับฟังก์ชันการทํางานขั้นสูงสําหรับการจัดการเซิร์ฟเวอร์ Outline ได้ เช่น

- ช่วยให้คุณเลือกบัญชีสําหรับการเรียกเก็บเงินที่ถูกต้อง
- สร้างโปรเจ็กต์ใหม่เพื่อจัดระเบียบเซิร์ฟเวอร์ Outline
- แสดงรายการศูนย์ข้อมูลที่มีอยู่
- การสร้างเครื่องเสมือนใหม่เพื่อเรียกใช้ Outline
- การกําหนดค่าเครื่องเสมือนใหม่ด้วย Outline

## กำลังเพิกถอนสิทธิ์

คุณเพิกถอนสิทธิ์เข้าถึง Outline Manager ใน Google Cloud Platform ได้โดยไปที่[บัญชีของฉัน](https://myaccount.google.com/permissions) หากคุณเพิกถอนสิทธิ์เข้าถึง เซิร์ฟเวอร์ที่คุณสร้างด้วยการตั้งค่าอัตโนมัติจะยังคงทํางานอยู่ แต่จะไม่ปรากฏใน Outline Manager อีกต่อไป หากต้องการคืนค่าสิทธิ์การเข้าถึง เพียงเชื่อมต่อ Google Cloud Platform อีกครั้งโดยเริ่มต้นขั้นตอนการตั้งค่าอัตโนมัติ

## องค์กรในโปรเจ็กต์ Outline

การตั้งค่าอัตโนมัติของ Google Cloud ใช้[โปรเจ็กต์ Google Cloud](https://cloud.google.com/resource-manager/docs/creating-managing-projects) รายการเดียวจัดระเบียบเซิร์ฟเวอร์ Outline ระบบจะสร้างโปรเจ็กต์ขึ้นระหว่างการใช้การตั้งค่าอัตโนมัติครั้งแรก โดยใช้รหัสโปรเจ็กต์ที่แนะนําซึ่งขึ้นต้นด้วย "Outline-" ตามด้วยสตริงอักขระแบบสุ่ม คุณจะเลือกรหัสโปรเจ็กต์อื่นขณะสร้างได้หากต้องการ โปรเจ็กต์จะมีชื่อว่า "เซิร์ฟเวอร์ Outline"

## บัญชีสำหรับการเรียกเก็บเงิน

โปรเจ็กต์ Google Cloud ต้องใช้ "บัญชีสําหรับการเรียกเก็บเงิน" ที่เชื่อมโยงอยู่และมีข้อมูลการชําระเงิน เมื่อใช้การตั้งค่าอัตโนมัติของ Google Cloud เป็นครั้งแรก ระบบจะขอให้คุณระบุบัญชีสําหรับการเรียกเก็บเงินเพื่อเชื่อมโยงกับเซิร์ฟเวอร์ Outline บางครั้งเซิร์ฟเวอร์จะหยุดทํางานเนื่องจากพบปัญหาในบัญชีสําหรับการเรียกเก็บเงิน ในกรณีนี้ คุณควรลงชื่อเข้าสู่ระบบ[Google Cloud Console](https://console.cloud.google.com/) ค้นหาโปรเจ็กต์ใน Google Cloud ที่เชื่อมโยงกับ Outline (ชื่อว่า "เซิร์ฟเวอร์ Outline") และอัปเดตการตั้งค่าการเรียกเก็บเงิน

## การทําลายเซิร์ฟเวอร์

หากต้องการทําลายเซิร์ฟเวอร์ที่สร้างขึ้นโดยใช้การตั้งค่าอัตโนมัติ วิธีที่ง่ายที่สุดคือดำเนินการจากภายใน Outline Manager แต่ถ้าต้องการทําลายเซิร์ฟเวอร์ด้วยตนเอง ให้เข้าสู่ระบบ [Google Cloud Console](https://console.cloud.google.com/) ค้นหาโปรเจ็กต์ที่สร้างระหว่างการตั้งค่าเริ่มต้น (ชื่อ "เซิร์ฟเวอร์ Outline") และลบทรัพยากรในเครื่องออกหรือปิดโปรเจ็กต์
