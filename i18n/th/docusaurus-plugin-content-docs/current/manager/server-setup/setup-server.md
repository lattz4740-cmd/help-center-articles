การตั้งค่าเซิร์ฟเวอร์ Outline เป็นขั้นตอนแรกที่ต้องดำเนินการเพื่อใช้งาน Outline โดยคุณหรือบุคคลอื่นที่คุณไว้ใจต้องตั้งค่าเซิร์ฟเวอร์เพื่อเชื่อมต่ออินเทอร์เน็ตแบบเปิดผ่าน Outline

## คำแนะนำก่อนเริ่มดำเนินการ

ก่อนที่คุณจะเริ่มตั้งค่าเซิร์ฟเวอร์ Outline คุณจะต้องมีสิ่งต่อไปนี้

1. สิทธิ์การเข้าถึงเซิร์ฟเวอร์ของตนเองหรือผู้ให้บริการระบบคลาวด์ เช่น DigitalOcean, Amazon Web Services (AWS) หรือ Google Cloud Platform (GCP)

    หากยังไม่มีสิทธิ์เข้าถึงเซิร์ฟเวอร์ระบบคลาวด์ก็ไม่ต้องกังวล เพราะคุณสร้างบัญชีกับผู้ให้บริการรายใดก็ได้ ซึ่งรวมถึงผู้ให้บริการที่กล่าวถึงไปแล้วข้างต้นด้วย โดยคุณอาจต้องใช้บัตรเครดิตในการลงชื่อสมัครใช้
2. คอมพิวเตอร์เดสก์ท็อปที่ใช้ macOS 10.9+, Windows 7.0+ หรือ Linux
3. แอปพลิเคชัน Outline Manager

## ตั้งค่ากับ DigitalOcean

ผู้ใช้ทุกคนจะตั้งค่า Outline กับ DigitalOcean ได้อย่างง่ายดายผ่านการคลิกเพียงไม่กี่ครั้ง หลังจากดาวน์โหลดและติดตั้ง Outline Manager ในคอมพิวเตอร์แล้ว ให้เลือกตัวเลือกการตั้งค่า DigitalOcean ที่จะแนะนำวิธีการกำหนดค่าและติดตั้ง Outline Server ซึ่งมีเพียงไม่กี่ขั้นตอนเท่านั้น

## ตั้งค่ากับผู้ให้บริการระบบคลาวด์รายอื่น

หลังจากดาวน์โหลดและติดตั้ง Outline Manager แล้ว คุณจะเลือกติดตั้งเซิร์ฟเวอร์ Outline ในเครื่องเสมือนกับ AWS, GCP, DigitalOcean หรือผู้ให้บริการรายอื่นได้ ขั้นตอนสำหรับผู้ให้บริการแต่ละรายนั้นแตกต่างกัน เราจึงได้รวบรวมวิธีการต่างๆ สำหรับผู้ให้บริการระบบคลาวด์ทั่วไปโดยส่วนใหญ่ไว้ในขั้นตอนการตั้งค่า Outline Manager รวมถึงวิธีกำหนดค่าการติดตั้งในเครื่องเสมือนก่อนที่จะเรียกใช้สคริปต์การติดตั้งเพื่อติดตั้ง Outline ในเซิร์ฟเวอร์
