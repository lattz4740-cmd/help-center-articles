---
title: ฉันจะรีเซ็ตรหัสเซิร์ฟเวอร์ได้อย่างไร
sidebar_label: ฉันจะรีเซ็ตรหัสเซิร์ฟเวอร์ได้อย่างไร
---

รหัสเซิร์ฟเวอร์คือรหัสที่สร้างขึ้นแบบสุ่มจากฝั่งเซิร์ฟเวอร์เมื่อคุณสร้างเซิร์ฟเวอร์ Outline คุณจะดูรหัสได้เมื่อเลือกใช้การแชร์เมตริกแบบไม่ระบุตัวตนในอินเทอร์เฟซการตั้งค่า คุณสามารถค้นหารหัสเซิร์ฟเวอร์ได้โดยไปที่ การตั้งค่า => เลื่อนไปด้านล่าง => เลือก "แชร์เมตริกแบบไม่ระบุตัวตน"

รหัสเซิร์ฟเวอร์จะรวบรวมสถิติการใช้งานที่ไม่ระบุตัวตนที่รายงานในระยะเวลาช่วงหนึ่งเข้าด้วยกัน หากต้องการรีเซ็ตรหัสเซิร์ฟเวอร์และขอรับรหัสใหม่ คุณต้องแทนที่เซิร์ฟเวอร์ Outline ที่มีอยู่ด้วยเซิร์ฟเวอร์ใหม่

หากใช้ DigitalOcean เป็นผู้ให้บริการคลาวด์ คุณจะรีเซ็ตเซิร์ฟเวอร์ได้โดยไปที่**การตั้งค่า** แล้วเลือก**ลบล้างเซิร์ฟเวอร์** การดำเนินการนี้จะยกเลิกไม่ได้และจะลบข้อมูลเข้าสู่ระบบทั้งหมด หลังจากนั้นระบบจะแจ้งให้คุณสร้างเซิร์ฟเวอร์ใหม่ในตำแหน่งที่ต้องการทันที และจะมีการสร้างรหัสเซิร์ฟเวอร์ใหม่
