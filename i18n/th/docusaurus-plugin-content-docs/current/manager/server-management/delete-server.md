--- [การนำเครื่องเสมือนที่คุณใช้ออกนั้นเป็นเรื่องที่ง่ายดายสำหรับผู้ให้บริการระบบคลาวด์ส่วนใหญ่](/manager/server-setup/setup-server)

หากใช้ DigitalOcean เป็นผู้ให้บริการคลาวด์ คุณจะลบเครื่องเสมือนที่มีอยู่ออกได้โดยคลิกที่ปุ่มรูปฟันเฟืองและเลือก**ลบล้างเซิร์ฟเวอร์** หลังจากนั้นระบบจะแจ้งให้คุณสร้างเครื่องเสมือนใหม่ในตำแหน่งที่ต้องการโดยทันที

การนำเซิร์ฟเวอร์ Outline ออกจะเป็นการลบออกอย่างถาวรและจะใช้งานคีย์การเข้าถึงไม่ได้อีกต่อไป หากไม่ต้องการให้ผู้ใช้พบปัญหาในการใช้งาน Outline คุณจะต้อง

และแชร์สิทธิ์เข้าถึงเซิร์ฟเวอร์นั้นก่อนลบเซิร์ฟเวอร์เก่า
