sidebar_label: ฉันจะอัปเดตซอฟต์แวร์ของเซิร์ฟเวอร์ Outline ได้อย่างไร
---

เซิร์ฟเวอร์ Outline จะอัปเดตระบบรักษาความปลอดภัยเวอร์ชันล่าสุดโดยอัตโนมัติเพื่อให้คุณได้ใช้งานเทคโนโลยี Outline ล่าสุดเสมอ กระบวนการอัปเดตอัตโนมัตินี้เปิดใช้งานโดยใช้ [Watchtower](https://github.com/containrrr/watchtower) ซึ่งเป็นไลบรารีโอเพนซอร์สที่ตรวจสอบและอัปเดตไฟล์อิมเมจใน Docker ที่มีซอฟต์แวร์ Outline เป็นประจำ

นอกจากนี้เมื่อติดตั้ง Outline โดยใช้ Outline Manager เราจะตั้งค่างาน Cron ให้อัปเกรดซอฟต์แวร์ในเซิร์ฟเวอร์โดยอัตโนมัติโดยใช้[การอัปเกรดโดยอัตโนมัติ](https://wiki.debian.org/UnattendedUpgrades) (Ubuntu) และรีบูตเมื่อจำเป็น โปรดทราบว่ากระบวนการนี้จะไม่เกิดขึ้นใน "โหมดขั้นสูง" เพื่อรักษาการกำหนดค่าที่มีอยู่ไว้ โดยถือว่ามีการใช้โฮสต์สำหรับจุดประสงค์อื่นนอกเหนือจากการเรียกใช้ Outline
