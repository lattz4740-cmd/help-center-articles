เมื่อติดตั้งเซิร์ฟเวอร์ Outline เสร็จสิ้นแล้ว คุณจะเริ่มการแชร์และจัดการการเข้าถึงของผู้ใช้ในเซิร์ฟเวอร์ได้ทันที ผู้ใช้ที่ได้รับคำเชิญจากคุณจะดาวน์โหลดแอป Outline เพื่อใช้ในการป้องกันการเข้าใช้อินเทอร์เน็ตได้

## แชร์สิทธิ์เข้าถึงเซิร์ฟเวอร์ Outline
 หลังจากติดตั้งเซิร์ฟเวอร์ Outline เสร็จสิ้นแล้ว ระบบจะนำคุณไปยังหน้ารายละเอียดของเซิร์ฟเวอร์ใน Outline Manager ที่ซึ่งคุณสร้างคีย์การเข้าถึงได้ ดูข้อมูลเพิ่มเติมเกี่ยวกับ[คีย์การเข้าถึง](/about/terminology)

- สร้างคีย์: คลิกไอคอน "+" เล็กๆ ที่ด้านล่างของหน้าเพื่อสร้างคีย์ใหม่
- แชร์คีย์: คลิกไอคอนแชร์เพื่อรับคำเชิญ โดยไอคอนดังกล่าวจะอยู่ทางด้านขวาของแต่ละคีย์ ให้คัดลอกและวางคำเชิญนี้ลงในแพลตฟอร์มการรับส่งข้อความที่ต้องการ

## คำขอฟีเจอร์: การแชร์การเข้าถึงจากภายในแอป Outline Manager
 ผู้ดูแลระบบเซิร์ฟเวอร์จำนวนมากขอให้เราปรับปรุงกระบวนการเชิญโดยให้ทางเลือกในการป้อนอีเมลของผู้ใช้ที่ต้องการใน Outline Manager ได้โดยตรง

น่าเสียดายที่เราอาจจะสร้างฟังก์ชันนี้ใน Outline Manager ไม่ได้ หนึ่งในหลักการสำคัญของเราคือการสนับสนุนความเป็นส่วนตัวและความปลอดภัยของผู้ใช้ ซึ่งหมายความว่าเราไม่ได้ออกแบบรูปแบบที่อนุญาตให้แทรกอีเมลหรือข้อมูลติดต่อได้

ด้วยเหตุนี้ เราจึงขอให้ผู้ดูแลระบบเซิร์ฟเวอร์ใช้แพลตฟอร์มการรับส่งข้อความที่ปลอดภัย เช่น อีเมลหรือแชทที่ปลอดภัย เพื่อส่งคำเชิญดังกล่าวไปยังผู้ใช้ปลายทาง

## สิ่งที่จะเกิดขึ้นกับผู้ใช้หลังจากคุณแชร์คีย์การเข้าถึงให้
1. ผู้ใช้จะคลิกลิงก์การติดตั้งจากอุปกรณ์ของตน
2. ระบบจะแจ้งให้ผู้ใช้ติดตั้งแอป Outline หากยังไม่มีการติดตั้ง
3. ผู้ใช้จะสร้างการเชื่อมต่อเริ่มต้นกับเซิร์ฟเวอร์ Outline ผ่านคีย์ที่ไม่ซ้ำกันที่ฝังอยู่ในคำเชิญ
4. ผู้ใช้จะใช้ปุ่มเชื่อมต่อ/ยกเลิกการเชื่อมต่อเพื่อจัดการการเข้าถึงอินเทอร์เน็ตผ่านเซิร์ฟเวอร์ Outline ได้

## นำสิทธิ์เข้าถึงเซิร์ฟเวอร์ Outline ออก
 จากหน้ารายละเอียดของเซิร์ฟเวอร์ใน Outline Manager คุณจะเห็นเมนูที่มีตัวเลือกในการลบคีย์ทางด้านขวาของทุกคีย์ในเซิร์ฟเวอร์ ซึ่งการลบคีย์จะนำสิทธิ์การเข้าถึงออกจากเซิร์ฟเวอร์ของคุณ
