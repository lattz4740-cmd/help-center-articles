title: ฉันจะเปลี่ยนตำแหน่งของเซิร์ฟเวอร์ Outline ได้อย่างไร
sidebar_label: ฉันจะเปลี่ยนตำแหน่งของเซิร์ฟเวอร์ Outline ได้อย่างไร
---

เมื่อตั้งค่าแล้ว คุณจะเปลี่ยนตำแหน่งของเซิร์ฟเวอร์ไม่ได้ คุณต้องลบเซิร์ฟเวอร์ Outline ออกและสร้างเซิร์ฟเวอร์ใหม่จึงจะเรียกใช้เซิร์ฟเวอร์จากตำแหน่งอื่นได้

อีกวิธีหนึ่งคือคุณสามารถเปลี่ยนตำแหน่งของ VPN โดยใช้[คีย์แบบไดนามิก](https://developer.getoutline.org/vpn/management/dynamic-access-keys/)ที่ให้คุณสับเปลี่ยนเซิร์ฟเวอร์ได้โดยที่ยังใช้คีย์เดิม ซึ่งวิธีนี้จะทำให้ตำแหน่งของเซิร์ฟเวอร์ไม่เปลี่ยนแปลง
