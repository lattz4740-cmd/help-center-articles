## VPN คืออะไร

เครือข่ายส่วนตัวเสมือน (VPN) คือการเชื่อมต่อส่วนตัวระหว่างอุปกรณ์ของคุณและเซิร์ฟเวอร์โฮสต์ ซึ่งจะซ่อนการรับส่งข้อมูลของคุณจากผู้ให้บริการอินเตอร์เน็ตเมื่อคุณใช้ VPN

คุณอาจเลือกใช้ VPN ในสถานการณ์ต่อไปนี้

- ปกป้องข้อมูลของคุณเมื่อใช้เครือข่าย Wi-Fi สาธารณะ
- เก็บข้อมูลการท่องเว็บของคุณให้เป็นส่วนตัวจากผู้ให้บริการอินเทอร์เน็ตและหน่วยงานรัฐบาล
- เข้าถึงเนื้อหาจากแหล่งที่มาต่างๆ ทั่วโลกโดยไม่ถูกปิดกั้น

## Outline แตกต่างจาก VPN แบบดั้งเดิมอย่างไร

ผู้ให้บริการอินเทอร์เน็ตสามารถตรวจจับและบล็อก VPN แบบดั้งเดิมได้ง่ายโดยการจดจำโปรโตคอลการรักษาความปลอดภัยทั่วไปและ/หรือรูปแบบปริมาณการรับส่งข้อมูล แต่ Outline มีความยืดหยุ่นมากกว่า VPN แบบดั้งเดิม เนื่องจากสร้างด้วยโปรโตคอลที่ออกแบบให้ตรวจพบได้ยาก ดังนั้นจึงบล็อกได้ยากขึ้น อีกทั้ง Outline ยังช่วยป้องกันการเซ็นเซอร์ขั้นสูงได้หลายรูปแบบ เช่น การบล็อกบนเครือข่าย หรือการบล็อก IP

## เซิร์ฟเวอร์ Outline คืออะไร

เซิร์ฟเวอร์ Outline จะทำหน้าที่บริหารจัดการ VPN ซึ่งผู้ใช้ที่ได้รับอนุญาตจะเชื่อมต่อได้

หากคุณต้องการสร้างเครือข่ายใหม่ คุณสามารถใช้เซิร์ฟเวอร์ที่ปลอดภัยของคุณ (หากมี) เป็นเซิร์ฟเวอร์ Outline ได้ หรือจะใช้ผู้ให้บริการระบบคลาวด์ก็ได้ เช่น

- DigitalOcean
- Google Cloud Platform (GCP)
- Amazon Web Services (AWS)

คุณจะตั้งค่าเซิร์ฟเวอร์ของคุณได้ใน Outline Manager

## ผู้ดูแลบริการคือใคร {#servicemanager}

ผู้ดูแลบริการคือบุคคลที่รับผิดชอบการตั้งค่าเซิร์ฟเวอร์ Outline และแชร์คีย์การเข้าถึงกับผู้ใช้ ซึ่งทั่วไปแล้วผู้ดูแลบริการมีหน้าที่ดูแลเรื่องค่าใช้จ่ายในการใช้งานเซิร์ฟเวอร์

## คีย์การเข้าถึงคืออะไร {#accesskey}

คีย์การเข้าถึงมีไว้เพื่อใช้เข้าถึงเซิร์ฟเวอร์ Outline ที่มีอยู่และเชื่อมต่อกับ VPN [ผู้ดูแลบริการ](#servicemanager)จะมอบคีย์การเข้าถึงให้กับคุณ หรือคุณจะ[ตั้งค่าเซิร์ฟเวอร์ Outline](/manager/server-setup/setup-server)ด้วยตนเองก็ได้

## Outline Manager คืออะไร

Outline Manager คือแอปพลิเคชันบนเดสก์ท็อปที่ช่วยให้ผู้ดูแลบริการตั้งค่าเซิร์ฟเวอร์ Outline, สร้าง[คีย์การเข้าถึง](#accesskey) และตั้งค่าขีดจำกัดการใช้ข้อมูลของแต่ละคีย์ คุณสามารถดาวน์โหลด Outline Manager เวอร์ชันล่าสุดได้[ที่นี่](https://getoutline.org/get-started/#step-1) หรือ[ที่นี่](https://www.reddit.com/r/outlinevpn/wiki/index/download_links/)

## ไคลเอ็นต์ Outline คืออะไร

ไคลเอ็นต์ Outline คือแอปพลิเคชันที่มีให้บริการในเดสก์ท็อปและอุปกรณ์เคลื่อนที่ ซึ่งจะช่วยให้คุณเชื่อมต่อกับเซิร์ฟเวอร์ Outline และเข้าถึง VPN โดยใช้คีย์การเข้าถึงได้ คุณสามารถดาวน์โหลดไคลเอ็นต์ Outline เวอร์ชันล่าสุดได้[ที่นี่](https://getoutline.org/get-started/#step-3) หรือ[ที่นี่](https://www.reddit.com/r/outlinevpn/wiki/index/download_links/)

## ขีดจำกัดของข้อมูลคืออะไร

Outline Manager ช่วยให้ผู้ดูแลบริการสามารถตั้งค่าขีดจำกัดของข้อมูลช่วงเวลาล่าสุด 30 วันในคีย์การเข้าถึง เพื่อป้องกันการใช้งานมากเกินไปและช่วยให้คาดการณ์ค่าใช้จ่ายได้ โดยผู้ดูแลบริการสามารถตั้งขีดจำกัดเริ่มต้นที่จะมีผลกับทุกคีย์ หรือจะตั้งขีดจำกัดที่แตกต่างกันให้กับคีย์ใดก็ได้เพื่อลบล้างขีดจำกัดเริ่มต้น เมื่อตั้งค่าขีดจำกัดแล้ว ขีดจำกัดจะมีผลทันทีและจะมีการบังคับใช้ทุก 1 ชั่วโมง

หากผู้ดูแลบริการเลือกแชร์เมตริกกับ Jigsaw ผู้ดูแลบริการควรตรวจสอบ[นโยบายการเก็บรวบรวมข้อมูล](/about/data-collection)เพื่อดูรายละเอียดว่าจะมีการรายงานการใช้ขีดจำกัดของข้อมูลอย่างไร
