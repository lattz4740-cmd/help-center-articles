Outline จะไม่เก็บข้อมูลส่วนบุคคล เว้นแต่คุณจะเลือกให้ข้อมูลเอง และจะไม่เก็บข้อมูลเว็บไซต์ที่คุณเข้าชม รวมถึงสิ่งที่คุณสื่อสารหรือผู้ที่คุณสื่อสารด้วย

 หากคุณสร้างบัญชีหรือเข้าสู่ระบบบัญชีที่มีอยู่กับผู้ให้บริการคลาวด์บุคคลที่สามผ่าน Outline Manager เราจะไม่เก็บข้อมูลใดๆ ที่คุณมอบให้ผู้ให้บริการคลาวด์บุคคลที่สาม ไม่ว่าจะเป็นอีเมล ชื่อ ข้อมูลสำหรับการเรียกเก็บเงิน หรือรายละเอียดการชำระเงิน

## ข้อมูลที่เราได้รับโดยอัตโนมัติ
 เราจะเก็บข้อมูล 2 ประเภทโดยอัตโนมัติ ดังนี้

 1. IP ของเซิร์ฟเวอร์

 เมื่อเซิร์ฟเวอร์ Outline มีการอัปเดตการปรับปรุงระบบรักษาความปลอดภัยและฟีเจอร์เวอร์ชันล่าสุดโดยอัตโนมัติ [Quay.io](https://quay.io/) จะเก็บข้อมูล IP ของเซิร์ฟเวอร์ Outline และทำให้เราเข้าถึงข้อมูล IP ได้ ทั้งนี้ IP ของเซิร์ฟเวอร์อาจระบุผู้ให้บริการเซิร์ฟเวอร์บนระบบคลาวด์และเมืองที่ตั้งของเซิร์ฟเวอร์ Outline ได้ แต่จะไม่ให้ข้อมูลเกี่ยวกับบุคคลที่กำลังใช้งานหรือเข้าถึงเซิร์ฟเวอร์นั้น

 2. ข้อมูลทางเทคนิคที่ระบุตัวบุคคลไม่ได้

 หาก Outline เกิดเหตุขัดข้องหรือเกิดข้อผิดพลาดร้ายแรง หรือหากคุณส่งความคิดเห็นด้วยตนเองผ่านแอป Outline ระบบจะรายงานข้อมูลด้านล่างนี้ เราจะใช้ข้อมูลนี้เพื่อช่วยระบุและแก้ไขปัญหาด้านเสถียรภาพหรือประสิทธิภาพเท่านั้น

- ประเทศ
- ภาษา
- วันที่และเวลาที่เกิดเหตุขัดข้อง/ข้อผิดพลาดและเหตุการณ์ก่อนหน้านี้ 100 รายการ เช่น เหตุการณ์ที่ผู้ใช้เปิดส่วน "เกี่ยวกับ"
- ข้อความแสดงข้อผิดพลาดที่เก็บรวบรวมเป็นสถิติ
- ชื่อและเวอร์ชันของระบบปฏิบัติการ
- รุ่นโทรศัพท์ (หากทราบ)
- เวลาเริ่มต้นใช้แอป
- เบราว์เซอร์
- สถาปัตยกรรมระบบ
- เวอร์ชันและหมายเลขบิลด์ของ Outline

ระบบจะโอนข้อมูลนี้ด้วย HTTPS ไปยัง Sentry ([sentry.io](https://sentry.io/)) ซึ่งเป็นผู้ให้บริการบุคคลที่สามสำหรับการติดตามข้อผิดพลาดแบบโอเพนซอร์ส Sentry จะใช้เทคโนโลยีและบริการระดับมาตรฐานอุตสาหกรรมที่หลากหลายเพื่อปกป้องข้อมูลของคุณจากการเข้าถึง การเปิดเผย และการใช้โดยไม่ได้รับอนุญาต รวมถึงช่วยป้องกันไม่ให้สูญหายอีกด้วย หากมีข้อสงสัยเกี่ยวกับนโยบายของ Sentry โปรดไปที่ [https://sentry.io/security/](https://sentry.io/security/) และ [https://sentry.io/privacy/](https://sentry.io/privacy/) หรือติดต่อ [security@sentry.io](mailto:security@sentry.io) ข้อมูล Outline ทั้งหมดที่จัดเก็บโดย Sentry จะจำกัดให้เฉพาะสมาชิกทีม Outline เข้าถึงได้

## ข้อมูลที่เราจะเก็บเฉพาะเมื่อมีการอนุญาต
 Outline จะรายงานข้อมูลต่อไปนี้ให้กับทีม Outline เมื่อมีการอนุญาต

 1. เมตริกการใช้งาน

 เซิร์ฟเวอร์ Outline แต่ละเซิร์ฟเวอร์จะเก็บรวบรวมจำนวนไบต์ที่ถ่ายโอน ระยะเวลาที่ผู้ใช้เชื่อมต่อกับเซิร์ฟเวอร์ ประเทศ และระบบเครือข่ายอัตโนมัติของข้อมูลเข้าสู่ระบบที่ใช้ โดยจะเก็บข้อมูลย้อนหลังไป 1 ชั่วโมงและเก็บตามคีย์การเข้าถึงแต่ละรายการโดยอัตโนมัติ รวมไปถึงข้อมูลว่ามีฟีเจอร์ใดที่เปิดหรือปิดใช้อยู่บ้าง ทั้งนี้ระบบจะไม่บันทึกเนื้อหาการสื่อสารหรือข้อมูลเมตาที่ระบุตัวบุคคลได้ (เช่น ข้อมูลเข้าสู่ระบบ อีเมล รหัสอุปกรณ์ ฯลฯ) เมตริกทั้งหมดจะเชื่อมโยงกับรหัสเซิร์ฟเวอร์ ดูวิธีการเปลี่ยนรหัสเซิร์ฟเวอร์ได้[ที่นี่](/manager/server-management/reset-server-id)

 เซิร์ฟเวอร์ Outline จะไม่แชร์เมตริกเหล่านี้กับทีม Outline โดยค่าเริ่มต้น หากผู้ดูแลระบบเซิร์ฟเวอร์เลือกแชร์เมตริกการใช้งานอย่างเปิดเผย ระบบจะส่งข้อมูลเหล่านี้ไปให้ทีม Outline ทุกๆ ชั่วโมงด้วยวิธีที่ปลอดภัย หลังจาก 60 วัน เมตริกการใช้งานจะได้รับการรวบรวมในระดับประเทศ ผู้ดูแลระบบเซิร์ฟเวอร์จะเปลี่ยนการกำหนดค่าการแชร์เมตริกการใช้งานได้ทุกเมื่อโดยไปที่เมนู "การตั้งค่า" ใน Outline Manager

 ขอขอบคุณที่แชร์เมตริกที่ไม่ระบุตัวตนเกี่ยวกับการใช้เซิร์ฟเวอร์ให้เรา เราจะใช้ข้อมูลดังกล่าวเพื่อวัดแนวโน้มการใช้งานและปรับปรุงผลิตภัณฑ์

 ตัวอย่างเช่น หากผู้ดูแลระบบเซิร์ฟเวอร์เลือกแชร์เมตริกการใช้งานให้เรา เราอาจได้รับข้อมูลที่ระบุว่ามีการใช้เซิร์ฟเวอร์รหัส 12345 เป็นเวลา 3 ชั่วโมงเมื่อวาน โดยได้โอนข้อมูลรวม 500 เมกะไบต์ มีการใช้คีย์ 3 คีย์จากในสหรัฐอเมริกาและแคนาดา และมีการเปิดฟีเจอร์จำกัดข้อมูล

 2. ความคิดเห็นและอีเมลหากคุณส่งความคิดเห็น

 แอป Outline Manager และ Outline ช่วยให้คุณส่งความคิดเห็นถึงทีมได้ เราไม่แนะนำให้ใส่ข้อมูลส่วนบุคคลที่ระบุตัวบุคคลนั้นได้ แต่คุณจะเลือกช่องทางอีเมลได้หากต้องการรับการตอบกลับจากทีม นอกจากนี้เรายังรวบรวมข้อมูลพื้นฐานบางส่วนโดยอัตโนมัติเพื่อให้เข้าใจความคิดเห็นของคุณ โปรดดูข้อมูลที่เรารวบรวมที่ข้อ 2 ข้างต้นในหัวข้อ "ข้อมูลที่เราได้รับโดยอัตโนมัติ" ดูข้อมูลเพิ่มเติมเกี่ยวกับหลักปฏิบัติเกี่ยวกับความปลอดภัยและความเป็นส่วนตัวของ Outline ได้[ที่นี่](/about/security-and-privacy)

 หากคุณกำลังใช้แอป Outline รุ่นเบต้าใน Android เราอาจใช้บริการ [Firebase](https://firebase.google.com/) ของ Google เพื่อเก็บข้อมูลการแก้ไขข้อบกพร่อง ซึ่งอาจช่วยให้เราตรวจพบปัญหาและปรับปรุง Outline ได้ ดูข้อมูลเพิ่มเติมเกี่ยวกับนโยบายด้านความเป็นส่วนตัวและความปลอดภัยของ Firebase ได้ที่เว็บไซต์ [firebase.google.com/support/privacy](https://firebase.google.com/support/privacy) หากไม่ต้องการให้ Outline ส่งข้อมูลนี้ผ่านทาง Firebase โปรดใช้แอปเวอร์ชันที่ใช้งานจริง
