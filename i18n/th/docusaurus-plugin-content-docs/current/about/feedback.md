sidebar_label: วิธีส่งความคิดเห็นหรือคำแนะนำ
---

ขอขอบคุณที่ช่วยทำให้ Outline ดีขึ้น คุณส่งความคิดเห็นถึงเราได้หลากหลายวิธี ไม่ว่าจะแบบไม่ระบุชื่อหรือแจ้งอีเมลไว้ในกรณีที่ต้องการให้เราตอบกลับ วิธีการมีดังนี้

- **สำหรับนักพัฒนาซอฟต์แวร์**: Outline เป็นซอฟต์แวร์โอเพนซอร์สและเราฝากโค้ดทั้งหมดไว้บน [GitHub](https://github.com/jigsaw-Code/?q=outline) ซึ่งคุณจะแชร์ไอเดียใน GitHub หรือในชุมชน [Reddit](https://www.reddit.com/r/outlinevpn/) ก็ได้

- **สำหรับผู้ใช้**: คุณจะส่งความคิดเห็นถึงเราผ่านแอป Outline หรือ Outline Manager ก็ได้ แจ้งให้เราทราบว่าเป็นความคิดเห็นเกี่ยวกับอะไร หรือให้ทิ้งอีเมลไว้เพื่อให้เราเขียนกลับถึงคุณได้ นอกจากนี้เรายังรวบรวมข้อมูลเมตาบางรายการเกี่ยวกับสภาพแวดล้อมของคุณ เพื่อให้เราช่วยแก้ปัญหาให้กับคุณได้ เช่น เบราว์เซอร์ ระบบปฏิบัติการ และเวอร์ชันซอฟต์แวร์ที่ใช้งานอยู่

- **ผ่านเว็บไซต์นี้**: คุณคลิกลิงก์ติดต่อเราได้ทุกที่ที่คุณเห็นภายในเว็บไซต์นี้

- **ปัญหาร้ายแรง**: หากต้องการรายงานปัญหาความปลอดภัยที่ร้ายแรง เรายินดีที่จะรับอีเมลเกี่ยวกับรายละเอียดต่างๆ ได้ที่ [security@getoutline.org](mailto:security@getoutline.org)

ขอขอบคุณอีกครั้งที่สละเวลาในการแลกเปลี่ยนความคิดกับเรา
