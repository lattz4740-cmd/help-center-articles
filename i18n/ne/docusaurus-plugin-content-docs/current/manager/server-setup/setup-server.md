Outline प्रयोग गर्न तपाईंले सर्वप्रथम Outline सर्भर सेटअप गर्नु पर्छ। तपाईं वा तपाईंले विश्वास गर्ने कुनै व्यक्तिले तपाईंका लागि सर्भर सेट अप गरेपछि तपाईं Outline मार्फत खुला इन्टरनेटमा कनेक्ट गर्न सक्नु हुने छ।

**सुरु गर्नुअघि**

 Outline सर्भर सेट अप गर्न थाल्नुअघि तपाईंलाई निम्न कुराहरू चाहिन्छ:

1. आफ्नै सर्भर वा DigitalOcean, Amazon Web Services (AWS) वा Google क्लाउड प्लेटफर्म (GCP) जस्ता क्लाउड सेवा प्रदायकको एक्सेस।

 तपाईंसँग तत्कालीन क्लाउड सर्भरको एक्सेस छैन भने तपाईं माथि सूचीकृत प्रदायकलगायतका कुनै पनि प्रदायक प्रयोग गरी सजिलैसँग खाता सेटअप गर्न सक्नुहुन्छ। साइन अप गर्न क्रेडिट कार्ड चाहिन सक्छ।
2. macOS 10.9+, Windows 7.0+ वा Linux मा चल्ने डेस्कटप कम्प्युटर।
3. Outline म्यानेजर एप।

**DigitalOcean प्रयोग गरी सेटअप गर्नुहोस्**

 हामीले जोकोहीले पनि केही पटक क्लिक गरेकै भरमा DigitalOcean मा सजिलैसँग Outline इन्स्टल गर्न सक्ने सुविधा प्रदान गरेका छौँ। आफ्नो कम्प्युटरमा Outline म्यानेजर डाउनलोड र इन्स्टल गरेपछि तपाईं DigitalOcean सेटअप गर्ने विकल्प चयन गर्न सक्नुहुन्छ। त्यसपछि तपाईंलाई आफ्नो Outline सर्भर कन्फिगर र इन्स्टल गर्न सघाउने केही स्क्रिनहरू देखाइने छन्।

**अर्कै क्लाउड प्रदायक प्रयोग गरी सेटअप गर्नुहोस्**

 Outline म्यानेजर डाउनलोड र इन्स्टल गरेपछि तपाईं AWS, GCP, DigitalOcean वा अन्य प्रदायक प्रयोग गरी भर्चुअल मेसिनमा Outline सर्भर इन्स्टल गर्ने विकल्प चयन गर्न सक्नुहुन्छ। हरेक प्लेटफर्म फरक हुन्छ, त्यसैले हामीले Outline म्यानेजर सेटअप गर्ने प्रक्रियामा सबैभन्दा बढी प्रयोग गरिने क्लाउड प्रदायकहरू प्रयोग गरी सेटअप गर्ने निर्देशनहरू समावेश गरेका छौँ। ती निर्देशनमा कुनै सर्भरमा Outline इन्स्टल गर्ने प्रयोजनका लागि इन्स्टलेसन स्क्रिप्ट प्रयोग गर्नुअघि भर्चुअल मेसिनका सेटिङ कन्फिगर गर्ने तरिका पनि समावेश गरिएको छ।
