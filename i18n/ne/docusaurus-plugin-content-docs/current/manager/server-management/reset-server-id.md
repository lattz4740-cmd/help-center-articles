---
title: "म आफ्नो सर्भर ID कसरी रिसेट गर्न सक्छु?"
sidebar_label: "म आफ्नो सर्भर ID कसरी रिसेट गर्न सक्छु?"
---

सर्भर ID भनेको तपाईंले कुनै Outline सर्भर बनाएपछि सर्भरका तर्फबाट र्‍यान्डम रूपमा सिर्जना गरिने ID हो। तपाईं सेटिङ इन्टरफेसमा अज्ञात मेट्रिकहरू सेयर गर्ने सेवामा अप्ट इन गर्दा सो ID फेला पार्न सक्नुहुन्छ। आफ्नो सर्भर ID फेला पार्न "सेटिङ => स्क्रोल गरी पुछारमा जानुहोस् => अज्ञात मेट्रिक्स सेयर गर्नुहोस्" मा जानुहोस्।

सर्भर ID ले समय समयमा रिपोर्ट गरिने अज्ञात प्रयोगसम्बन्धी तथ्याङ्कहरूलाई एकै ठाउँमा गाँस्ने काम गर्छ। तपाईं सर्भर ID रिसेट गर्न र नयाँ सर्भर प्राप्त गर्न चाहनुहुन्छ भने तपाईंले आफ्नो हालको Outline सर्भरको सट्टामा नयाँ सर्भर बनाउनु पर्ने हुन्छ।

तपाईं आफ्नो क्लाउड प्रदायकका रूपमा DigitalOcean प्रयोग गर्दै हुनुहुन्छ भने तपाईं "सेटिङ" मा गई "सर्भर नष्ट गर्नुहोस्" चयन गरेर आफ्नो सर्भर रिसेट गर्न सक्नुहुन्छ। यो कारबाही अपरिवर्तनीय हुन्छ र यसले तपाईंका क्रिडेन्सियलहरू मेटाउने छ। यो कारबाही गरेलगत्तै तपाईंले छानेको लोकेसनमा तपाईंलाई नयाँ सर्भर बनाउन लगाइने छ र सर्भरको नयाँ ID बनाइने छ।
