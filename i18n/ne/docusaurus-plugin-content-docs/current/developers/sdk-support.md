sidebar_label: "म विकासकर्ता हुँ। म आफ्नो एपमा Outline SDK इन्टिग्रेट गर्ने सम्बन्धमा कहाँबाट सहायता प्राप्त गर्न सक्छु?"
---

सहायता प्रदान गर्ने यो वेबसाइट Outline म्यानेजर र क्लाइन्टका प्रयोगकर्ताहरूका निम्ति बनाइएको हो। विकासकर्ताहरू, कृपया सहायता प्राप्त गर्न GitHub प्रयोग गर्नुहोस्। कुनै प्रश्न सोध्न चाहनुहुन्छ भने कृपया SDK को [छलफल बोर्ड](https://github.com/Jigsaw-Code/outline-sdk/discussions)मा पोस्ट गर्नुहोस्। "छलफल बोर्ड" खण्ड भनेको प्रश्नहरू सोध्ने, आइडिया तथा डेमोको लिंक सेयर गर्ने र Outline SDK प्रयोग गर्ने अन्य विकासकर्ताहरूलाई मद्दत गर्ने उत्कृष्ट ठाउँ हो। सुविधाका निम्ति अनुरोध गर्न वा त्रुटिका बारेमा रिपोर्ट गर्न कृपया कुनै [समस्या](https://github.com/Jigsaw-Code/outline-sdk/issues/new) खोल्नुहोस्।
