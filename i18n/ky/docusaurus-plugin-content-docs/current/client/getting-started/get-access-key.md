title: "Кирүү ачкычын кантип алсам болот?"
sidebar_label: "Кирүү ачкычын кантип алсам болот?"
---

Outline колдонуу үчүн акы алган кадимки VPN кызматтардай эмес; бул [курал](https://getoutline.org/#:~:text=Two%20Products%20that%20Work%20Together) менен жеке VPN серверин түзүп, башкалар менен бөлүшө аласыз. Кирүү ачкычын [кызмат башкаруучусу](/about/terminology#servicemanager) гана бере алат. Outline жамааты акысыз же төлөнүүчү кирүү ачкычтарын таратпайт. Фарс тилиндеги Paskoocheh аянтчасынан башка Outline кирүү ачкычтарын берген расмий өнөктөштөрүбүз жок.

 Төмөнкү үч жолдор менен кирүү ачкычты ала аласыз:

- Кимдир бирөөдөн сизди серверге чакырууну сураныңыз: Outline сервери бар таанышыңыз болсо, алар менен байланышып, кирүү ачкычын сураңыз.
- [Серверди өзүңүз түзүңүз:](/manager/server-setup/setup-server) Windows, Mac же Linux компьютерин колдонуп, [Outline Manager'ди](https://getoutline.org/get-started/#step-1) жүктөп алып, өз жеке [Outline сервериңизди](/about/terminology) орнотуп алыңыз. Муну аткаруу өтө оңой, айрыкча DigitalOcean булут камсыздоочусу аркылуу.
- Outline же [Shadowsocks](https://en.wikipedia.org/wiki/Shadowsocks#:~:text=Shadowsocks%20is%20a%20free%20and,have%20been%20made%20available%20since.) кызматын колдонуңуз: Outline Client колдонмосу Outline кызматын же Shadowsocks протоколун колдонгон үчүнчү тараптын кызматтары менен колдонууга болот. Мисалы:
   - [nthLink](http://nthlink.com/) өзгөртүлгөн Outline Client версиясы менен иштеген акысыз кызматын сунуштайт.
   - [ASL19](https://www.reddit.com/r/outlinevpn/comments/nwu1se/the_outline_distribution_system_is_here_to_help/) Outline кызматынын [BeePass](https://beepassvpn.com/) аттуу өзгөртүлгөн версиясын, ошондой эле BeePass серверине акысыз кирүү ачкычтарын сунуштаган [Telegram ботун](https://t.me/paskoochehbot) иштетет.
   - Фарси тилинде сүйлөгөн колдонуучулар Outline кирүү ачкычын [ASL19 уюмунун Paskoocheh аянтчасынан](https://outline.paskoocheh.com/) сурана алышат.

Outline Client колдонмосун жүктөп алгандан кийин, Outline серверине туташуу үчүн [кирүү ачкычыңызды](/about/terminology#accesskey) көчүрүп, Outline Client колдонмосуна чаптаңыз.
