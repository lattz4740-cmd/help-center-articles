Outline ସେହି VPN ସେବାଗୁଡ଼ିକ ପରି ନୁହେଁ ଯାହା ପାଇଁ ଆପଣ ଆକ୍ସେସ କ୍ରୟ କରନ୍ତି; ଏହା [ଏକ ଟୁଲ](https://getoutline.org/#:~:text=Two%20Products%20that%20Work%20Together) ଯାହା ଆପଣଙ୍କୁ ଏକ ପ୍ରାଇଭେଟ VPN ସର୍ଭର ଚଲାଇବା ଏବଂ ଆକ୍ସେସ ସେୟାର କରିବାକୁ ଦିଏ। ଜଣେ [ସେବା ପରିଚାଳକ](/about/terminology#servicemanager) ହେଉଛନ୍ତି ଏକମାତ୍ର ବ୍ୟକ୍ତି ଯିଏ ଏକ ଆକ୍ସେସ କୀ ପ୍ରଦାନ କରିପାରିବେ। Outline ଟିମ ମାଗଣା କିମ୍ବା ଦେୟଯୁକ୍ତ ଆକ୍ସେସ କୀଗୁଡ଼ିକୁ ଡିଷ୍ଟ୍ରିବ୍ୟୁଟ କରେ ନାହିଁ। ଫାର୍ସି ଭାଷାରେ Paskoocheh ବ୍ୟତୀତ ଆମର କୌଣସି ଅଫିସିଆଲ Outline ଆକ୍ସେସ କୀ ପାର୍ଟନର ନାହିଁ।

 ଏକ ଆକ୍ସେସ କୀ ପାଇବା ପାଇଁ ଏଠାରେ ତିନୋଟି ବିକଳ୍ପ ଅଛି:

- କୌଣସି ବ୍ୟକ୍ତିଙ୍କୁ ତାଙ୍କ ସର୍ଭରକୁ ଆପଣଙ୍କୁ ନିମନ୍ତ୍ରଣ କରିବାକୁ କୁହନ୍ତୁ: ଯଦି ଆପଣ Outline ସର୍ଭର ଥିବା କୌଣସି ବ୍ୟକ୍ତିଙ୍କୁ ଜାଣନ୍ତି, ତେବେ ତାଙ୍କୁ କଣ୍ଟାକ୍ଟ କରି ଏକ ଆକ୍ସେସ କୀ ମାଗନ୍ତୁ।
- [ନିଜେ ଏକ ସର୍ଭର ତିଆରି କରନ୍ତୁ:](/manager/server-setup/setup-server) ଏକ Windows, Mac କିମ୍ବା Linux କମ୍ପ୍ୟୁଟର ବ୍ୟବହାର କରି [Outline ମେନେଜର](https://getoutline.org/get-started/#step-1) ଡାଉନଲୋଡ କରନ୍ତୁ ଏବଂ ଆପଣଙ୍କ ନିଜର ପ୍ରାଇଭେଟ [Outline ସର୍ଭର](/about/terminology) ସେଟ ଅପ କରନ୍ତୁ। ଆମେ ଏହି ପ୍ରକ୍ରିୟାକୁ ସମସ୍ତଙ୍କ ପାଇଁ ସହଜ କରିଛୁ, ବିଶେଷକରି କ୍ଲାଉଡ ସେବା ପ୍ରଦାନକାରୀ DigitalOcean ମାଧ୍ୟମରେ।
- ଏକ Outline କିମ୍ବା [Shadowsocks](https://en.wikipedia.org/wiki/Shadowsocks#:~:text=Shadowsocks%20is%20a%20free%20and,have%20been%20made%20available%20since.) ସେବା ବ୍ୟବହାର କରନ୍ତୁ: Outline କ୍ଲାଏଣ୍ଟକୁ Outline କିମ୍ବା Shadowsocks ପ୍ରୋଟୋକଲ ବ୍ୟବହାର କରୁଥିବା ତୃତୀୟ-ପକ୍ଷ ସେବା ସହିତ ମଧ୍ୟ ବ୍ୟବହାର କରାଯାଇପାରିବ। ଉଦାହରଣ ସ୍ଵରୂପ:
   - [nthLink](http://nthlink.com/) Outline କ୍ଲାଏଣ୍ଟର ଏକ ପରିବର୍ତ୍ତିତ ଭର୍ସନ ସହିତ Outline ଉପରେ ଆଧାରିତ ଏକ ମାଗଣା ସେବା ଚଲାଏ।
   - [ASL19](https://www.reddit.com/r/outlinevpn/comments/nwu1se/the_outline_distribution_system_is_here_to_help/) [BeePass](https://beepassvpn.com/) ନାମକ Outlineର ଏକ ପରିବର୍ତ୍ତିତ ଭର୍ସନ ସହିତ [ଏକ Telegram ବଟ](https://t.me/paskoochehbot) ଚଲାଏ ଯାହା BeePass ସର୍ଭରଗୁଡ଼ିକୁ ମାଗଣା ଆକ୍ସେସ କୀ ପ୍ରଦାନ କରେ।
   - ଫାର୍ସି ଭାଷାର ୟୁଜରମାନେ [ASL19ର Paskoocheh](https://outline.paskoocheh.com/)ରୁ ଏକ Outline ଆକ୍ସେସ କୀ ପାଇଁ ମଧ୍ୟ ଅନୁରୋଧ କରିପାରିବେ।

Outline Client ଆପ ଡାଉନଲୋଡ କରିବା ପରେ, Outline ସର୍ଭର ସହ କନେକ୍ଟ କରିବାକୁ ଆପଣଙ୍କ [ଆକ୍ସେସ କୀ'କୁ](/about/terminology#accesskey) କପି କରି Outline Clientରେ ପେଷ୍ଟ କରନ୍ତୁ।
