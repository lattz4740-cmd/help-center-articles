---

አንዴ ከተዋቀረ፣ የአገልጋይ አካባቢ ሊቀየር አይችልም። አገልጋይዎን ከሌላ አካባቢ ለማሄድ Outline አገልጋይዎን መሰረዝ እና አዲስ መፍጠር ያስፈልግዎታል።

እንደ አማራጭ [ተለዋዋጭ ቁልፎች](https://developers.google.com/outline/docs/guides/service-providers/dynamic-access-keys) በመጠቀም የእርስዎን VPN አካባቢ መለወጥ ይችላሉ፣ ይህም አገልጋዮችን እንዲያዞሩ እና ተመሳሳይ ቁልፎችን ለማቆየት ያስችልዎታል። የአገልጋዮቹ የራሳቸው አካባቢ አይለወጥም።
