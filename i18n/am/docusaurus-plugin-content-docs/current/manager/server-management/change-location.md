sidebar_label: "የOutline አገልጋይ አካባቢን የምለውጠው እንዴት ነው?"
---

አንዴ ከተዋቀረ፣ የአገልጋይ አካባቢ ሊቀየር አይችልም። አገልጋይዎን ከሌላ አካባቢ ለማሄድ Outline አገልጋይዎን መሰረዝ እና አዲስ መፍጠር ያስፈልግዎታል።

እንደ አማራጭ [ተለዋዋጭ ቁልፎች](https://developer.getoutline.org/vpn/management/dynamic-access-keys/) በመጠቀም የእርስዎን VPN አካባቢ መለወጥ ይችላሉ፣ ይህም አገልጋዮችን እንዲያዞሩ እና ተመሳሳይ ቁልፎችን ለማቆየት ያስችልዎታል። የአገልጋዮቹ የራሳቸው አካባቢ አይለወጥም።
