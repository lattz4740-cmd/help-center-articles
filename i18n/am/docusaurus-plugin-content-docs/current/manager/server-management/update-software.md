sidebar_label: "የእኔን Outline አገልጋይ ሶፍትዌር የማዘምነው እንዴት ነው?"
---

የOutline አገልጋዮች የቅርብ ጊዜውን የOutline ቴክኖሎጂ ሁልጊዜ እንዲያሄዱ በቅርብ ጊዜ የደህንነት ማሻሻያዎች በራስ-ሰር ይዘምናሉ። ራስ-ሰር የሆነው ዝማኔ ሂደት Outline ሶፍትዌሩን የያዘውን ዶከር ምስል በመደበኛነት የሚፈትሽ እና የሚያዘምን ክፍት ምንጭ ቤተ መጽሐፍት በሆነው [Watchtower](https://github.com/containrrr/watchtower) ይነቃል።

በተጨማሪ Outline አስተዳዳሪን በመጠቀም Outline ሲጭኑ [ክትትል የማይደረግባቸው ማሻሻያዎች](https://wiki.debian.org/UnattendedUpgrades) (Ubuntu) በሚጠቀመው አገልጋይ ላይ ሶፍትዌሩን በራስ-ሰር ለማሻሻል እና አስፈላጊ ሲሆን ዳግም እንዲያስነሳው ክሮን ሥራ እናዋቅራለን። አስተናጋጁ Outlineን ከማሄድ በተጨማሪ ለሌሎች ተግባራት ጥቅም ላይ እየዋለ እንዳለ በማሰብ ነባሩን ውቅረት ለማቆየት ይህ በላቀ ሁነታ ውስጥ እንደማይከሰት ልብ ይበሉ።
