sidebar_label: "የእኔን የOutline አገልጋይ እንዴት መሰረዝ እችላለሁ?"
---

ለአብዛኞቹ የደመና አቅራቢዎች፣ የሚጠቀሙበትን የተወሰነ ምናባዊ ማሽን ማስወገድ በመጠኑ ቀላል ነው።

DigitalOceanን እንደ የደመና አቅራቢዎ እየተጠቀሙ ከሆነ፣ የእርስዎን ነባር ምናባዊ ማሽን የማርሽ አዝራሩን ጠቅ በማድረግ እና አገልጋይን አጥፋን በመምረጥ መሰረዝ ይችላሉ። ከዚያ በኋላ ወዲያውኑ፣ አዲስ ምናባዊ ማሽን በመረጡት አካባቢ እንዲፈጥሩ ይጠየቃሉ።

የOutline አገልጋይን ካስወገዱ፣ እስከመጨረሻው ይሰረዝና የመዳረሻ ቁልፎቹ ከእንግዲህ አይሰሩም። ሰዎች በOutline በኩል መዳረሻቸው ላይ መስተጓጎል እንዳይኖርባቸው የሚፈልጉ ከሆነ፣ [አዲስ የOutline አገልጋይ ማዋቀር](/manager/server-setup/setup-server) እና የድሮ አገልጋይዎን ከመሰረዝዎ በፊት ወደ አዲሱ መዳረሻን ማጋራት ይኖርብዎታል።
