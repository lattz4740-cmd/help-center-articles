የOutline አገልጋይዎን መጫን እንደጨረሱ፣ አሁን ሰዎችን ለእሱ ያላቸውን መዳረሻ ማጋራት እና ማስተዳደር ይችላሉ። ከእርስዎ ግብዣ የሚቀበሉ ሰዎች የበይነመረብ ትራፊካቸውን ለመጠበቅ Outlineን ለመጠቀም የOutline መተግበሪያን ማውረድ ይችላሉ።

## ለእርስዎ የOutline አገልጋይ መዳረሻ ያጋሩ
 የOutline አገልጋይን ከጫኑ በኋላ የመዳረሻ ቁልፎችን መፍጠር ወደሚችሉበት ወደ የአገልጋይ ዝርዝሮች ገፅ በOutline አስተዳዳሪ ይመራሉ። ስለ [የመዳረሻ ቁልፎች](/about/terminology) የበለጠ ይወቁ።

- ቁልፎችን ይፍጠሩ፦ አዲስ ቁልፎችን ለመፍጠር ከገፁ ግርጌ ላይ ትንሹን «+» አዶ ጠቅ ያድርጉ።
- የተጋሩ ቁልፎች፦ በእያንዳንዱ ቁልፍ በቀኝ በኩል፣ ግብዣ ለማግኘት ጠቅ ማድረግ የሚችሉት የአጋራ አዶ አለ። ይህን ግብዣ ወደመረጡት የመልዕክት መላላኪያ ሥርዓት ቀድተው ይለጥፉ።

## የባህሪ ጥያቄ፦ ከOutline አስተዳዳሪ መተግበሪያ ውስጥ መዳረሻን ማጋራት
 ብዙ የአገልጋይ አስተዳዳሪዎች የአንድን ሰው ኢሜይል አድራሻ በቀጥታ ወደ Outline አስተዳዳሪ እንዲያስገቡ አማራጭ በመስጠት የግብዣውን ሂደት እንድናሳልጥ ይጠይቁናል።

እንደ አለመታደል ሆኖ፣ ይህን ተግባር የOutline አስተዳዳሪ ላይ መገንባት የመቻላችን ዕድል አነስተኛ ነው። ከመርሆቻችን ውስጥ አንኳሩ የተጠቃሚዎቻችንን ግላዊነት እና ደህንነት መደገፍ ነው፣ ይህም ማለት የኢሜይል አድራሻዎችን ወይም የዕውቂያ መረጃን ማስገቢያ ምንም ቦታ አልነደፍንም።

ለዚህም ነው የአገልጋይ አስተዳዳሪዎችን ግብዣውን ለዋናው ተጠቃሚ ለመላክ እንደ ኢሜይል ወይም አስተማማኝ ውይይት ያለ ደህንነቱ የተጠበቀ የመልዕክት መላላኪያ መሠረተ ሥርዓት እንዲጠቀሙ የምንጠይቀው።

## የመዳረሻ ቁልፍ ካጋሯቸው በኋላ ተጠቃሚው ምን ተሞክሮዎች ይኖሩዋቸዋል
1. ተጠቃሚው ከመሣሪያቸው የጭነት አገናኙ ላይ ጠቅ ያደርጋሉ
2. አስቀድመው ከሌላቸው የOutline መተግበሪያን እንዲጭኑ ይጠየቃሉ
3. ግብዣው ላይ በተካተተ ልዩ ቁልፍ ከእርስዎ የOutline አገልጋይ ጋር የመጀመሪያ ግንኙነት ይመሰርታሉ
4. አሁን በOutline አገልጋይዎ በኩል የበይነመረብ መዳረሻቸውን ለማስተዳደር የአገናኝ/አቋርጥ አዝራሩን መጠቀም ይችላሉ

## የOutline አገልጋይዎን መዳረሻ ያስወግዱ
 በOutline አስተዳዳሪ ካለው የአገልጋይ ዝርዝሮች ገፅ በአገልጋዩ ላይ ካለው እያንዳንዱ ቁልፍ በስተቀኝ በኩል ቁልፍን ለመሰረዝ አማራጭ ያለው ምናሌ ይመለከታሉ። ቁልፍን መሰረዝ ወደ ለእርስዎ አገልጋይ ያላቸውን መዳረሻ ያስወግዳል።
