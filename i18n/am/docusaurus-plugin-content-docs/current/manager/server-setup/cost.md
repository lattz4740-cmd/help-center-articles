የOutline ሶፍትዌር ለሁሉም ሰው ነፃ ነው፣ VPNን የሚያስተዳዳሩ የአገልጋይ አስተዳዳሪም ሆኑ ወይም ደግሞ ክፍት በይነመረብን ለመድረስ Outlineን የሚጠቀሙ ቢሆኑ።

 Outline ለማሄድ ወደ የደመና አገልጋይ መዳረሻን ይፈልጋል። አስቀድሞ የአገልጋይ መዳረሻ ያላቸው የአገልጋይ አስተዳዳሪዎች Outlineን እሱ ላይ ያለምንም ተጨማሪ ወጪ መጫን ይችላሉ። ወደ አገልጋይ መዳረሻ የሌላቸው ከየደመና አገልግሎት አቅራቢዎች መዳረሻ ሊያገኙ ይችላሉ፣ ለምሳሌ ከ[DigitalOcean](https://www.digitalocean.com/) ወይም የAmazon የድር አገልግሎቶች፣ ለ1 ቴራባይት የውሂብ ማስተላለፍ አበል $5 የአሜሪካ ዶላር በወር — ያ በመቶዎች የሚቆጠሩ ተጠቃሚዎችን በአንድ ነጠላ አገልጋይ ለመደገፍ በቂ ነው።

 በመረጡት የደመና አቅራቢ Outlineን ለማሄድ ምን ያህል ወጪ እንደሚያወጣ ለመወሰን ሒሳቡን እንዴት መሥራት እንደሚችሉ ምሳሌ፦
