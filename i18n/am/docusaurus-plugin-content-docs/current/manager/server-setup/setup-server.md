የOutline አገልጋይ ማዋቀር Outline መጠቀም ለመቻል የመጀመሪያው ደረጃ ነው። እርስዎ ወይም እርስዎ የሚያምኑት የሆነ ሰው በOutline በኩል ከክፍት በይነመረብ ጋር መገናኘት እንዲችሉ ለእርስዎ አገልጋይ ማዋቀር አለበት።

 የOutline አገልጋይዎን ማዋቀር **ከመጀመርዎ በፊት**

 ጥቂት ነገሮች ያስፈልጉዎታል፦

1. ወደራስዎ አገልጋዮች ወይም የደመና ግልጋሎት ሰጪዎች፣ ለምሳሌ DigitalOcean፣ የAmazon የድር አገልግሎቶች (AWS) ወይም የGoogle ደመና መሰረተ ሥርዓት (GCP) መዳረሻ።

 ወደ የደመና አገልጋይ መዳረሻ ወዲያው ካላገኙ፣ ከማንኛውም አቅራቢ ከላይ የተዘረዘሩትን ጨምሮ መለያ በቀላሉ ማዋቀር ይችላሉ። ለመመዝገብ የክሬዲት ካርድ ሊያስፈልግዎ ይችላል።
2. macOS 10.9+፣ Windows 7.0+ ወይም Linux የሚያሄድ የዴስክቶፕ ኮምፒውተር።
3. የOutline አስተዳዳሪ መተግበሪያ።

**በDigitalOcean አማካኝነት ያዋቅሩ**

 ለማንኛውም ሰው DigitalOcean ላይ በጥቂት ጠቅ ማድረጎች Outlineን መጫንን ቀላል እንዲሆን አድርገናል። የOutline አስተዳዳሪን ኮምፒውተርዎ ላይ ካወረዱ እና ከጫኑ በኋላ፣ የOutline አገልጋይዎን ለማዋቀር እና ለመጫን ጥቂት ቀላል ማያ ገጾች ውስጥ ያሉትን የሚመራዎ የDigitalOcean ማዋቀሪያ አማራጭን መምረጥ ይችላሉ።

**በሌላ የደመና አቅራቢ ያዋቅሩ**

 Outline Manager ካወረዱ እና ከጫኑ በኋላ በምናባዊ ማሽን ላይ Outline አገልጋይ ለመጫን ከAWS፣ GCP፣ DigitalOcean ወይም ሌላ አቅራቢ መምረጥ ይችላሉ። እያንዳንዱ ከባቢ የተለያየ ነው፣ ስለዚህ የOutline አስተዳዳሪ ማዋቀሪያ ፍሰት ውስጥ በጣም ለተለመዱት የደመና አቅራቢዎች መመሪያዎችን አካትተናል፣ ይህም Outlineን አገልጋይ ላይ ለመጫን የጭነት ስክሪፕቱን ከማሄድዎ በፊት ቅንብሮቹን ምናባዊ ማሽኖችዎ ላይ እንዴት ማዋቀር እንደሚቻል ያካትታል።
