ተጨማሪ የOutline አገልጋዮችን ለማዋቀር፣ የOutline አስተዳዳሪ መተግበሪያዎ የግራ ጎን ላይ ያለው የአሰሳ ፓኔል ላይ «+» አዶን ጠቅ ያድርጉ። አዲስ አገልጋይ ለማከል የሚያስፈልጉት መመሪያዎች የመጀመሪያዎን እየጫኑ ቢሆን ካለው ጋር ተመሳሳይ ናቸው።

- መፍጠር የሚችሏቸው የOutline አገልጋዮች ብዛት ላይ ገደብ የለንም።
- ለሚፈጥሩት ለእያንዳንዱ የOutline አገልጋይ፣ ተዛማጅ ምናባዊ ማሽን ያስፈልግዎታል።
- ተጨማሪ ማሽን ወይም ጠብታዎች መፍጠር የደመና አቅራቢዎ ጋር ያሉብዎትን ክፍያዎች ሊጨምር ይችላል። እባክዎ ምን እንደሚጠብቁ ማወቅዎን ለማረጋገጥ የዋጋ ጥቅልዎን የደመና አቅራቢዎ ጋር ያረጋግጡ።

## DigitalOcean ላይ ተጨማሪ የOutline አገልጋይ መፍጠር

+ አዶን ጠቅ ካደረጉ እና DigitalOcean ላይ ለመጫን ከመረጡ በኋላ፣ የመጀመሪያ አገልጋይዎን ለማዋቀር የተከተሏቸውን ተመሳሳይ መመሪያዎች ይከተላሉ። እንዲሁም፣ የOutline አስተዳዳሪ ከDigitalOcean ጋር ስለሚዋሃድ፣ የOutline አስተዳዳሪ መተግበሪያን በፍጹም ሳይለቁ ጠብታውን ለእርስዎ መፍጠር እንችላለን።

የOutline አስተዳዳሪ በአንድ ጊዜ አንድ የDigitalOcean መለያ ብቻ እንደሚደግፍ ልብ ይበሉ። ከሌሎች DigitalOcean መለያዎች ላይ ሌሎች የOutline አገልጋዮችን ማከል ወይም መፍጠር ከፈለጉ፣ እንደ የላቀ ውቅረት ሊያክሏቸው ይችላሉ።

## GCP፣ AWS ወይም ሌላ የደመና ግልጋሎት ሰጪ ላይ ተጨማሪ የOutline አገልጋይ መፍጠር

በእርስዎ የተመረጠ የደመና አቅራቢ አዲስ ምናባዊ ማሽን በመፍጠር ይጀምሩ። ከዚያ የOutline አስተዳዳሪን ይክፈቱ እና ለላቀ ጭነት መመሪያዎችን ያጠናቅቁ፣ ልክ ለመጀመሪያ ጊዜ እንደሚያደርጉት።
