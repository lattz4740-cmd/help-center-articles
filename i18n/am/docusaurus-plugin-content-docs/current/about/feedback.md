Outline የተሻለ እንዲሆን ስላገዙ እናመሰግናለን! ማንነት በተሰወረበት ሁኔታ ወይም ምላሽ የሚፈልጉ ከሆነ በኢሜይልዎ ለእኛ ግብረመልስ ለመላክ የተወሰኑ መንገዶች አሉ፦

- **ለገንቢዎች**፦ Outline ክፍት ምንጭ ሶፍትዌር ነው እና ሁሉንም የእኛን ኮድ የምናስተናግደው [GitHub](https://github.com/OutlineFoundation/?q=outline) ላይ ነው። ሀሳቦችዎን GitHub ላይ ወይም በእኛ [Reddit](https://www.reddit.com/r/outlinevpn/) ማህበረሰብ ላይ ማጋራት ይችላሉ።
- **ለተጠቃሚዎች**፦ በOutline ወይም Outline አስተዳዳሪ መተግበሪያዎች በኩል ግብረመልስ ሊልኩልን ይችላሉ። ግብረመልስዎ ምን እንደሆነ እና እንደ አማራጭ ስለ እሱ መልሰን ልንጽፍልዎ እንድንችል ኢሜይል ይተዉ። እንዲሁም በመላ ፍለጋ ላይ ልናግዝዎ እንድንችል እንደ የእርስዎ አሳሽ፣ ሥርዓተ ክወና እና የትኛው የሶፍትዌር ሥሪት ላይ እንደሆኑ ያለ ስለ አካባቢዎ የተወሰነ ዲበ ውሂብ እንሰበስባለን።
- **በዚህ ጣቢያ በኩል**፦ በዚህ ጣቢያ ውስጥ ያግኙን አገናኝን በሚያዩበት ማንኛውም ቦታ ጠቅ ሊያደርጉት ይችላሉ።
- **ከባድ ችግሮች**፦ ከባድ የደህንነት ችግር ሪፖርት ማድረግ ከፈለጉ ደህንነት ላይ [getoutline.org](https://getoutline.org/) [ላይ] ኢሜይል ቢልኩልን እናመሰግናለን።

ሀሳቦችዎን ለእኛ ለማጋራት ጊዜ ስለወሰዱ በድጋሚ እናመሰግናለን።
