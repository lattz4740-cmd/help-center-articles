Outline እርስዎ መዳረሻ እንደሚገዟቸው የVPN አገልግሎቶች አይደለም፤ የግል የVPN አገልጋይ እንዲያሄዱ እና መዳረሻ እንዲያጋሩ የሚያስችል [መሣሪያ](https://getoutline.org/#:~:text=Two%20Products%20that%20Work%20Together) ነው። [የአገልግሎት አስተዳዳሪ](/about/terminology#servicemanager) የመዳረሻ ቁልፍ ማቅረብ የሚችለው ብቸኛ ሰው ነው። የOutline ቡድኑ ነፃ ወይም የሚከፈልባቸው የመዳረሻ ቁልፎችን አያከፋፍልም። በፋርሲ ውስጥ ከPaskoocheh በስተቀር ማናቸውም ይፋዊ የOutline መዳረሻ ቁልፍ አጋሮች የሉንም።

 የመዳረሻ ቁልፍ ለማግኘት ሦስት አማራጮች እነሆ፦
