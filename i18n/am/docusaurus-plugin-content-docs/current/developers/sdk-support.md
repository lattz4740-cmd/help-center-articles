ይህ የድጋፍ ድር ጣቢያ ለዝርዝር አስተዳዳሪ እና የደንበኛ ተጠቃሚዎች ነው። ገንቢዎች፣ እባካችሁ ለድጋፍ GitHub ተጠቀሙ። ጥያቄ ለመጠየቅ እባክዎ የኤስዲኬ [የንግግር ቦርድ](https://github.com/Jigsaw-Code/outline-sdk/discussions) ላይ ይለጥፉ። የንግግር ቦርድ ክፍሉ ጥያቄዎች ለመጠየቅ፣ ሐሳቦችን ለማጋራት፣ ከቅንጭብ ማሳያዎች ጋር ለመገናኘት እና የዝርዝር ኤስዲኬ የሚጠቀሙ ሌሎች ገንቢዎችን ለመደገፍ ምርጥ ቦታ ነው። ለባህሪ ጥያቄዎች ወይም የሳንካ ሪፖርቶች እባክዎ በምትኩ [ችግሮች](https://github.com/Jigsaw-Code/outline-sdk/issues/new) ይክፈቱ።
