तुम्ही कोणत्याही ऑपरेटिंग सिस्टीमवर Outline वापरून पाहू शकता. ऑपरेटिंग सिस्टीमच्या किमान आवश्यक आवृत्त्या पुढे दिल्या आहेत:

| **ऑपरेटिंग सिस्टीम** | **किमान आवृत्ती** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Outline क्लायंट ला आणखी ऑपरेटिंग सिस्टीमवर काम करण्यात मदत करायची आहे का? GitHub वर [आमच्या कोड बेसमध्ये योगदान देणे](https://github.com/Outline-Foundation/outline-client#platform-specific-development) हे करा!
