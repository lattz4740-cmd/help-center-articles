तुम्ही मोबाइल फोन वापरत असल्यास, मोबाइल डेटा आणि वाय-फाय कनेक्शन यांदरम्यान स्विच करून पहा. काही वेळा एका प्रकारचे कनेक्शन काम करते, तर दुसरे काम करत नाही. तुम्ही काँप्युटर वापरत असल्यास, ब्रॉडबँडवरून डिस्कनेक्ट करून, पुन्हा कनेक्ट करून पहा.

तुम्हाला तरीही समस्या येत राहिल्यास, समस्या तुमच्या Outline सर्व्हरशी संबंधित असण्याची शक्यता आहे. पर्यायी सर्व्हरसाठी नवीन ॲक्सेस की मिळवण्याकरिता तुमचा[सेवा व्यवस्थापक](/about/terminology) याच्याशी संपर्क साधा. कीने तिचा कोटा ओलांडला असल्यास, ते तुमच्याhttps://google-jigsaw--jigsawuat.sandbox.my.site.com/outline/s/article/Terminology [ॲक्सेस की](/about/terminology)ची डेटा मर्यादादेखील वाढवू शकतील.
