एखादा Outline सर्व्हर सेट करणे ही Outline वापरता येण्याची पहिली पायरी आहे. तुम्‍ही किंवा तुमचा विश्‍वास असलेल्या एखाद्या व्यक्तीने तुमच्‍यासाठी सर्व्हर सेट करणे आवश्‍यक आहे, जेणेकरून तुम्‍ही Outline याद्वारे मुक्त इंटरनेट कनेक्‍ट करू शकता.

## तुम्ही सुरुवात करण्यापूर्वी
 तुम्ही तुमचा Outline सर्व्हर सेट करणे सुरू करण्यापूर्वी, तुमच्याकडे पुढील काही गोष्टी असणे आवश्यक आहे:

1. तुमच्‍याकडे स्‍वत:च्‍या सर्व्हरचा किंवा DigitalOcean, Amazon वेब सेवा (AWS) किंवा Google Cloud Platform (GCP) यांसारख्या क्‍लाउड सेवा पुरवठादाराचा अ‍ॅक्सेस असणे.

 तुम्हाला क्लाउड सर्व्हरचा त्वरित अ‍ॅक्सेस मिळाला नसल्यास, वर सूचीबद्ध केलेल्या पुरवठादारांसह तुम्ही कोणताही पुरवठादार वापरून सहजपणे खाते सेट करू शकता. तुम्हाला साइन अप करण्यासाठी क्रेडिट कार्ड लागेल.
2. macOS 10.9+, Windows 7.0+ किंवा Linux रन करणारा डेस्कटॉप काँप्युटर.
3. Outline Manager अ‍ॅप्लिकेशन.

## DigitalOcean वापरून सेट अप करा
 काही क्लिकमध्ये DigitalOcean वर Outline इंस्‍टॉल करणे आम्ही सर्वांसाठी सोपे केले आहे. तुमच्या कॉंप्युटरवर Outline Manager डाउनलोड करून इंस्टॉल केल्यानंतर, तुम्ही DigitalOcean सेटअप हा पर्याय निवडू शकता, जो तुम्हाला तुमचा Outline सर्व्हर कॉन्फिगर आणि इंस्टॉल करण्यासाठी काही सोप्या स्क्रीनद्वारे मार्गदर्शन करेल.

## दुसऱ्या क्लाउड पुरवठादारासह सेट करा
 Outline Manager डाउनलोड आणि इंस्टॉल केल्यानंतर, तुम्ही AWS, GCP, DigitalOcean किंवा इतर पुरवठादारासह व्हर्च्युअल मशीनवर Outline सर्व्हर इंस्टॉल करणे निवडू शकता. तुम्ही Outline हे सर्व्हरवर इंस्टॉल करण्यासाठी इंस्टॉलेशन स्क्रिप्ट रन करण्यापूर्वी तुमच्या व्हर्च्युअल मशीनवरील सेटिंग्ज कॉंफिगर कशी करावी यासंबंधित सूचनांसह, आम्ही सर्वात सामान्य क्लाउड पुरवठादारांसाठी Outline Manager सेटअप फ्लोमध्ये सूचनांचा समावेश केला आहे, कारण प्रत्येक पद्धत वेगळी असते.
