अतिरिक्त Outline सर्व्हर सेट करण्यासाठी, तुमच्या Outline Manager अ‍ॅप्लिकेशनच्या डाव्या बाजूला असलेल्या नेव्हिगेशन पॅनलवरील “+” आयकनवर क्लिक करा. नवीन सर्व्हर जोडण्यासाठीच्या सूचना या तुम्ही तुमचा पहिला सर्व्हर इंस्टॉल केला होता त्याप्रमाणेच आहेत.

- तुम्ही किती Outline सर्व्हर तयार करू शकता यासाठी आमची कोणतीही मर्यादा नाही.
- तुम्ही तयार करता त्या प्रत्येक Outline सर्व्हरसाठी, संबंधित व्हर्चुअल मशीन आवश्यक असेल.
- अतिरिक्त मशीन किंवा ड्रॉपलेट तयार केल्याने तुमच्या क्लाउड पुरवठादाराच्या तुमच्या शुल्कांमध्ये वाढ होऊ शकते. शुल्कांच्या बाबतीत काय अपेक्षा करावी हे तुम्हाला माहीत असल्याची खात्री करण्यासाठी, कृपया तुमच्या क्लाउड पुरवठादाराकडील तुमच्या पॅकेजची किंमत पहा.

## DigitalOcean वर अतिरिक्त Outline सर्व्हर तयार करणे

+ आयकनवर क्लिक करून DigitalOcean वर इंस्टॉल करणे निवडल्यानंतर, तुमचा पहिला सर्व्हर सेट करण्यासाठी तुम्ही फॉलो केल्या होत्या त्याच सूचना फॉलो कराल. तसेच, Outline Manager हे DigitalOcean सोबत इंटिग्रेट करत असल्यामुळे, तुम्हाला कधीही Outline Manager अ‍ॅप न सोडावे लागता आम्ही तुमच्यासाठी ड्रॉपलेट तयार करू शकतो.

लक्षात घ्या, की Outline Manager हे एका वेळी फक्त एका DigitalOcean खात्याला सपोर्ट करू शकते. तुम्हाला इतर DigitalOcean खात्यांमधून इतर Outline सर्व्हर जोडायचे किंवा तयार करायचे असल्यास, तुम्ही त्यांना प्रगत कॉन्फिगरेशन म्हणून जोडू शकता.

## GCP, AWS किंवा दुसऱ्या Cloud सेवा पुरवठादारांवर अतिरिक्त Outline सर्व्हर तयार करणे

तुमच्या निवडलेल्या क्लाउड पुरवठादारासोबत नवीन व्हर्चुअल मशीन तयार करून सुरुवात करा. त्यानंतर Outline Manager उघडा आणि तुम्ही पहिल्यांदा केल्या असतील, त्याचप्रमाणे प्रगत इंस्टॉलेशनसाठीच्या सूचना पूर्ण करा.
