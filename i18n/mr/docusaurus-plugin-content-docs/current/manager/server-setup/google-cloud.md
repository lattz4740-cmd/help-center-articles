## अवलोकन

Outline Manager मध्ये असे वैशिष्‍ट्य आहे, ज्याद्वारे Google Cloud वर रन होत असलेल्या सर्व्हरवर तुम्ही Outline सर्व्हर आपोआप कॉन्फिगर करू शकता. तुम्ही हे वैशिष्‍ट्य वापरणे निवडल्यास, Outline Manager तुम्हाला तुमचे Google खाते वापरून साइन इन करण्यास सांगेल, ज्यामुळे तुमचे Google Cloud खाते कॉन्फिगर करण्याच्या उद्देशांसाठी Outline Manager च्या तुमच्या स्थानिक इंस्टॉलेशनकरिता ठरावीक [OAuth](https://developers.google.com/identity/protocols/oauth2) परवानग्या मिळतील.

 तुम्हाला या परवानग्या द्यायच्या नसल्यास, Google Cloud Platform वर Outline रन करण्यासाठी तुम्ही Outline Manager मधील सेटअपशी संबंधित प्रगत सूचना फॉलो करू शकता.

## दिल्या जाणाऱ्या परवानग्या

ऑटोमेटेड सेटअप पुरवण्यासाठी, Outline Manager ला तुमच्या Google खाते द्वारे पुढील परवानग्या आवश्यक आहेत.

## Google Cloud Platform

- तुमचे Google Compute Engine स्रोत पाहणे आणि व्यवस्थापित करणे
- सर्व Google Cloud सेवांवर तुमचा डेटा आणि तुमच्या Google खाते चा ईमेल अ‍ॅड्रेस पाहणे

## मूलभूत खाते माहिती

- तुमचा प्राथमिक Google खाते ईमेल अ‍ॅड्रेस पाहणे
- Google वरील तुमच्या वैयक्तिक माहितीशी तुम्हाला संलग्न करणे

## अतिरिक्त अ‍ॅक्सेस

- तुमचे Cloud Platform प्रोजेक्ट व्यवस्थापित करणे
- तुमची Google Cloud Platform बिलिंग खाती पाहणे आणि व्यवस्थापित करणे
- तुमच्या Google API सेवेचे कॉन्फिगरेशन व्यवस्थापित करणे

या परवानग्यांमुळे आम्हाला तुमचे Outline सर्व्हर व्यवस्थापित करण्यासाठी प्रगत कार्यक्षमतेला सपोर्ट करता येते, ज्यामध्ये पुढील गोष्टींचा समावेश आहे:

- तुम्हाला योग्य बिलिंग खाते निवडण्याची अनुमती देणे
- तुमचे Outline सर्व्हर संगतवार लावण्यासाठी नवीन प्रोजेक्ट तयार करणे
- उपलब्ध डेटा केंद्रे सूचीबद्ध करणे
- Outline रन करण्यासाठी नवीन व्हर्चुअल मशीन तयार करणे
- Outline सह नवीन व्हर्चुअल मशीन कॉन्फिगर करणे

## परवानग्या मागे घेणे

तुम्ही[माझे खाते](https://myaccount.google.com/permissions) ला भेट देऊन Outline Manager साठी Google Cloud Platform चा अ‍ॅक्सेस मागे घेऊ शकता. तुम्ही अ‍ॅक्सेस मागे घेतल्यास, ऑटोमेटेड सेटअप वापरून तयार केलेले कोणतेही सर्व्हर रन होत राहतील, पण यापुढे ते Outline Manager मध्ये दिसणार नाहीत. त्यांचा अ‍ॅक्सेस रिस्टोअर करण्यासाठी, फक्त ऑटोमेटेड सेटअप फ्लो सुरू करून Google Cloud Platform शी पुन्हा कनेक्ट करा.

## Outline प्रोजेक्ट संगतवार लावणे

तुमचे Outline सर्व्हर संगतवार लावण्यासाठी Google Cloud ऑटोमेटेड सेटअप हे एका[Google Cloud प्रोजेक्ट](https://cloud.google.com/resource-manager/docs/creating-managing-projects) चा वापर करते. ऑटोमेटेड सेटअपच्या पहिल्या वापरादरम्यान हा प्रोजेक्ट तयार केला जातो, ज्याचा सुचवलेला प्रोजेक्ट आयडी “Outline-” ने सुरू होतो आणि त्यानंतर रॅंडम वर्णांची स्ट्रिंग असते. तुम्हाला हवे असल्यास, तुम्ही प्रोजेक्ट तयार करताना वेगळा प्रोजेक्ट आयडी निवडू शकता. प्रोजेक्टला “Outline सर्व्हर” असे नाव दिले जाईल.

## बिलिंग खाते

Google Cloud प्रोजेक्टसाठी पेमेंट माहिती परिभाषित करणारे, लिंक केलेले “बिलिंग खाते” आवश्यक आहे. तुम्ही पहिल्यांदा Google Cloud ऑटोमेटेड सेटअप वापरता, तेव्हा तुमच्या Outline सर्व्हरशी संबद्ध करण्यासाठी तुम्हाला बिलिंग खाते पुरवण्यास सांगितले जाईल. काही वेळा बिलिंग खात्यामध्ये समस्या असल्यामुळे सर्व्हर रन करणे थांबवेल. अशा वेळी, तुम्ही[Google Cloud Console](https://console.cloud.google.com/getting-started) मध्ये लॉग इन करून Outline शी संलग्न (“Outline सर्व्हर” नावाचा) Google Cloud प्रोजेक्ट शोधणे आणि बिलिंग सेटिंग्ज अपडेट करणे आवश्यक आहे.

## सर्व्हर नष्ट करणे

ऑटोमेटेड सेटअप वापरून तयार केलेले तुमचे सर्व्हर तुम्हाला नष्ट करायचे असल्यास, हे करण्याचा सर्वात सोपा मार्ग म्हणजे Outline Manager मधून ते नष्ट करणे. तथापि, तुम्हाला स्वतःला ते सर्व्हर नष्ट करायचे असल्यास, तुम्ही[Google Cloud Console](https://console.cloud.google.com/getting-started) मध्ये लॉग इन करून, सुरुवातीच्या सेटअपदरम्यान तयार केलेला (“Outline सर्व्हर” नावाचा) प्रोजेक्ट शोधू शकता आणि तेथील स्रोत हटवू शकता किंवा तो प्रोजेक्ट बंद करू शकता.
