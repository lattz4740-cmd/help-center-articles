sidebar_label: "मी Windows वर Outline Manager इंस्टॉल का करू शकत नाही?"
---

तुम्हाला हा एरर मेसेज दिसू शकतो: “सॉरी, Outline योग्यरीत्या इंस्टॉल झाले नाही असे दिसते. कृपया ते पुन्हा इंस्टॉल करण्याचा प्रयत्न करा. ते काम करत नसल्यास, कृपया [फीडबॅक सबमिट करणे](/about/feedback) हे करा.”

तुम्ही Windows वर Outline वापरत असल्यास, अधूनमधून तुम्हाला अनपेक्षित एरर येऊ शकते. बहुतांश प्रकरणांमध्ये, Outline TAP अडॅप्टर (ड्रायव्हर) हटवून, Outline पुन्हा इंस्टॉल करणे आवश्यक असते.

तुमच्या Windows ऑपरेटिंग सिस्टीमच्या आवृत्तीनुसार पायऱ्या बदलू शकतात, पण TAP अडॅप्टर आणि Outline Manager कसे अनइंस्टॉल करावे व नंतर Outline Manager कसे पुन्हा इंस्टॉल करावे यासाठीच्या सामान्य पायऱ्या खाली दिल्या आहेत.

1. Outline Manager साठी TAP अडॅप्टर अनइंस्टॉल करा
   1. डिव्हाइस व्यवस्थापक, त्यानंतर नेटवर्क अडॅप्टर वर जा
   2. “TAP-Windows अडॅप्टर V9 फाइल किंवा Outline शी संलग्न TAP अडॅप्टर शोधा
   3. हा अडॅप्टर अनइंस्टॉल करा किंवा हटवा. लक्षात ठेवा, की तुम्ही इंस्टॉल केलेल्या इतर VPN अ‍ॅप्सवर याचा परिणाम होऊ शकतो.
2. Outline Manager अनइंस्टॉल करा
   1. प्रोग्राम आणि वैशिष्ट्ये, त्यानंतर प्रोग्राम अनइंस्टॉल करा वर जा
   2. Outline Manager अ‍ॅप शोधा आणि Outline Manager अनइंस्टॉल करा
   3. [Outline Manager ची नवीनतम आवृत्ती डाउनलोड करणे](https://getoutline.org/get-started/#step-1) हे करा आणि ती तुमच्या Windows डिव्हाइसवर पुन्हा इंस्टॉल करा. नवीन इंस्टॉलेशनमुळे नवीन TAP अडॅप्टर आपोआप इंस्टॉल केला जाईल.

तुम्हाला तरीही समस्या येत असल्यास, [सपोर्टशी संपर्क साधा](/about/feedback).
