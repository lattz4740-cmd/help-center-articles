तुम्ही तुमचा Outline सर्व्हर इंस्टॉल करणे पूर्ण केल्यावर, तुम्ही आता त्याचा लोकांचा ॲक्सेस शेअर करण्यास आणि व्यवस्थापित करण्यास सुरुवात करू शकता. तुमच्याकडून आमंत्रण मिळालेल्या लोकांना त्यांच्या इंटरनेट ट्रॅफिकचे संरक्षण करण्यासाठी Outline वापरण्याकरिता, Outline ॲप डाउनलोड करता येईल.

## तुमच्या Outline सर्व्हरचा ॲक्सेस शेअर करा
 तुम्ही Outline सर्व्हर इंस्टॉल करणे पूर्ण केल्यानंतर, तुम्हाला Outline Manager वरील सर्व्हरचे तपशील पेजवर निर्देशित केले जाईल, जिथे तुम्ही ॲक्सेस की तयार करू शकता. [अ‍ॅक्सेस की](/about/terminology) बद्दल अधिक जाणून घ्या.

- की तयार करणे: नवीन की तयार करण्यासाठी पेजच्या तळाशी असलेल्या छोट्या "+" आयकनवर क्लिक करा.
- की शेअर करणे: प्रत्येक कीच्या उजवीकडे, शेअर करा आयकन असतो, ज्यावर आमंत्रण मिळवण्यासाठी तुम्ही क्लिक करू शकता. तुमच्या आवडत्या मेसेजिंग सिस्टीममध्ये हे आमंत्रण कॉपी करून पेस्ट करा.

## वैशिष्ट्याची विनंती करणे: Outline Manager ॲपमध्ये ॲक्सेस शेअर करणे
 बऱ्याच सर्व्हरचे अ‍ॅडमिनिस्ट्रेटर आम्हाला एखाद्याचा ईमेल अ‍ॅड्रेस थेट Outline Manager मध्ये एंटर करण्याचा पर्याय देऊन आमंत्रण प्रक्रिया सुलभ करण्याची विनंती करतात.

दुर्दैवाने, आम्ही ही कार्यक्षमता Outline Manager मध्ये तयार करू शकत नाही. आमच्या वापरकर्त्याची गोपनीयता आणि सुरक्षेला सपोर्ट देणे हे आमच्या मुख्य तत्त्वांपैकी एक आहे, याचा अर्थ असा आहे, की आम्ही ईमेल अ‍ॅड्रेस किंवा संपर्क माहिती घालण्यासाठी कोणतीही जागा डिझाइन केलेली नाही.

म्हणूनच, आम्ही सर्व्हरच्या अ‍ॅडमिनिस्ट्रेटरना अंतिम वापरकर्त्याला आमंत्रण पाठवण्यासाठी ईमेल किंवा सुरक्षित चॅट यांसारखे सुरक्षित मेसेजिंग प्लॅटफॉर्म वापरण्याची विनंती करतो.

## तुम्ही वापरकर्त्यांसोबत ॲक्सेस की शेअर करता, तेव्हा त्यांना काय अनुभव येतो
1. वापरकर्ता त्याच्या डिव्हाइसवरून इंस्टॉलेशन लिंकवर क्लिक करेल
2. त्यांच्याकडे आधीपासून Outline ॲप नसल्यास, त्यांना ते इंस्टॉल करण्यासाठी सूचित केले जाईल
3. ते तुमच्या Outline सर्व्हरसोबत आमंत्रणामध्ये एंबेड केलेल्या युनिक कीद्वारे सुरुवातीचे कनेक्शन स्थापित करतील
4. तुमच्या Outline सर्व्हरद्वारे त्यांच्या इंटरनेटचा ॲक्सेस व्यवस्थापित करण्यासाठी ते आता कनेक्ट करा/डिस्कनेक्ट करा बटण वापरू शकतात

## तुमच्या Outline सर्व्हरचा ॲक्सेस काढून टाकणे
 Outline Manager पेजमधील सर्व्हरचे तपशीलमधील सर्व्हरवरील प्रत्येक कीच्या उजवीकडे, तुम्हाला की हटवण्याच्या पर्यायासोबत मेनू दिसेल. की हटवल्यामुळे त्यांचा तुमच्या सर्व्हरचा ॲक्सेस काढून टाकला जातो.
