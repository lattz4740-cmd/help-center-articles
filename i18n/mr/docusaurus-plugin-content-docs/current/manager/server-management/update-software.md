title: "मी माझे Outline सर्व्हर सॉफ्टवेअर कसे अपडेट करू?"
sidebar_label: "मी माझे Outline सर्व्हर सॉफ्टवेअर कसे अपडेट करू?"
---

Outline सर्व्हर हे नवीनतम सुरक्षा सुधारणांवर आपोआप अपडेट होतात, जेणेकरून तुम्ही नेहमी नवीनतम Outline तंत्रज्ञान रन करत राहाल. ऑटोमेटेड अपडेटची प्रक्रिया [वॉचटॉवर](https://github.com/containrrr/watchtower) द्वारे सुरू केली जाते. ती अशी मुक्त स्रोत लायब्ररी आहे जी नियमितपणे Outline सॉफ्टवेअर असलेली डॉकर इमेज तपासते आणि अपडेट करते.

याव्यतिरिक्त, तुम्ही Outline Manager वापरून Outline इंस्टॉल करता, तेव्हा आम्ही सर्व्हरवरील सॉफ्टवेअर आपोआप अपग्रेड करण्यासाठी [पर्यवेक्षित न केलेली अपग्रेड](https://wiki.debian.org/UnattendedUpgrades) (Ubuntu) वापरून क्रॉन जॉब सेट करू आणि आवश्यक असेल, तेव्हा रीबूट करू. लक्षात घ्या, की Outline रन करण्याव्यतिरिक्त इतर उद्देशांसाठी होस्ट वापरला जात आहे हे गृहीत धरून, सद्य कॉन्फिगरेशन राखून ठेवण्यासाठी हे प्रगत मोड मध्ये होत नाही.
