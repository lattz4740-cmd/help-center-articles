sidebar_label: "मला माझा सर्व्हर आयडी कसा रीसेट करता येईल?"
---

सर्व्हर आयडी हा सर्व्हर-साइड आयडी आहे, जो तुम्ही Outline सर्व्हर तयार केल्यावर रँडम पद्धतीने जनरेट केला जातो. सेटिंग्ज इंटरफेसमध्ये निनावी मेट्रिक शेअर करण्याची निवड करताना तुम्ही तो शोधू शकता. तुम्ही इथून तुमचा सर्व्हर आयडी शोधू शकता: सेटिंग्ज => तळाशी स्क्रोल करा => "निनावी मेट्रिक शेअर करा" हे पहा.

सर्व्हर आयडीद्वारे काळानुसार नोंदवलेली निनावी वापराविषयक आकडेवारी एकत्र केली जाते. तुम्हाला सर्व्हर आयडी रीसेट करून नवीन मिळवायचा असल्यास, तुम्ही तुमच्या सद्य Outline सर्व्हरच्या जागी नवीन सर्व्हरवर वापरणे आवश्यक आहे.

तुम्ही तुमचा क्लाउड पुरवठादार म्हणून DigitalOcean वापरत असल्यास, सेटिंग्ज वर जाऊन आणि सर्व्हर नष्ट करा निवडून तुमचा सर्व्हर रीसेट करू शकता. ही कृती पहिल्यासारखी केली जाऊ शकत नाही आणि तुमची क्रेडेंशियल मिटवेल. या कृतीनंतर लगेच, तुम्ही निवडलेल्या स्थानावर तुम्हाला नवीन सर्व्हर तयार करण्यास सूचित केले जाईल आणि नवीन सर्व्हर आयडी जनरेट केला जाईल.
