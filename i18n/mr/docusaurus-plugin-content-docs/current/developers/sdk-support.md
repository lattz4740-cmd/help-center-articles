---

ही सपोर्ट वेबसाइट Outline Manager आणि क्लायंट वापरकर्त्यांसाठी आहे. डेव्हलपर, कृपया सपोर्टसाठी GitHub वापरा. प्रश्न विचारण्यासाठी, कृपया SDK [चर्चा बोर्ड](https://github.com/Jigsaw-Code/outline-sdk/discussions) वर पोस्ट करा. Outline SDK वापरून प्रश्न विचारण्यासाठी, कल्पना शेअर करण्यासाठी, डेमो लिंक करण्यासाठी आणि इतर डेव्हलपरना सपोर्ट देण्यासाठी चर्चा बोर्ड विभाग हे उत्तम ठिकाण आहे. वैशिष्ट्याशी संबंधित विनंत्या करण्यासाठी किंवा बग रिपोर्टसाठी, कृपया त्याऐवजी [समस्या](https://github.com/Jigsaw-Code/outline-sdk/issues/new) उघडा.
