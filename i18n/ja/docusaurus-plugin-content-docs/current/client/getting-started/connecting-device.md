[ユーザーがデバイスを Outline サーバーに接続するには、一意の](/about/terminology)

が記載された招待状をサーバー管理者から受け取る必要があります。この招待状は次の役割を果たします。

- Outline をダウンロードしてデバイスにインストールするよう求める（まだインストールしていない場合）
- アクセスキーを使用して、デバイスと Outline サーバー間の接続のセキュリティを確保する

サーバーへの接続をいったん確立したら、[接続] または [切断] をクリックして Outline の使用を開始、終了できます。

:::warning[重要]
Outline はアクセスキーと Outline サーバーがなければ動作しません。Outline アプリをダウンロード、インストールしても、キーがなければ、インターネット トラフィックは保護されません。
:::
