---
title: アクセスキーを取得するにはどうすればよいですか？
sidebar_label: アクセスキーを取得するにはどうすればよいですか？
---

Outline は、VPN へのアクセス権を購入する VPN サービスなどとは異なり、独自のプライベート VPN サーバーを運用し、その VPN サーバーへのアクセスを共有するための[ツール](https://getoutline.org/#:~:text=Two%20Products%20that%20Work%20Together)です。[サービス マネージャー](/about/terminology#servicemanager)のみがアクセスキーを提供できます。Outline チームが無料または有料のアクセスキーを配布することはありません。Paskoocheh（ペルシア語）以外に、Outline 公式アクセスキー パートナーはありません。

 アクセスキーを取得するには、次の 3 つの方法があります。

- サーバーへの招待をリクエストする: Outline サーバーを利用している知人がいる場合は、その方に連絡してアクセスキーをリクエストします。
- [自分でサーバーを作成する:](/manager/server-setup/setup-server) Windows、Mac、Linux のいずれかのパソコンで [Outline マネージャー](https://getoutline.org/get-started/#step-1)をダウンロードし、独自のプライベート [Outline サーバー](/about/terminology)を設定します。誰でも簡単にこのプロセスを実施できます（特にクラウド サービス プロバイダ DigitalOcean を介する場合）。
- Outline または [Shadowsocks](https://en.wikipedia.org/wiki/Shadowsocks#:~:text=Shadowsocks%20is%20a%20free%20and,have%20been%20made%20available%20since.) サービスを使用する: Outline クライアントは、Outline または Shadowsocks のプロトコルを使用するサードパーティ サービスでも使用できます。次に例を示します。
   - [nthLink](https://nthlink.com/) では、Outline を基盤とする無料サービスを Outline クライアントの改訂バージョンで運用しています。
   - [ASL19](https://www.reddit.com/r/outlinevpn/comments/nwu1se/the_outline_distribution_system_is_here_to_help/) では、Outline の改定バージョン（[BeePass](https://beepassvpn.com/)）および BeePass サーバーに無料のアクセスキーを提供する [Telegram bot](https://t.me/paskoochehbot) を運用しています。
   - ペルシア語のユーザーの方は、[ASL19 の Paskoocheh](https://outline.paskoocheh.com/) から Outline アクセスキーをリクエストすることもできます。

Outline クライアント アプリをダウンロードした後、[アクセスキー](/about/terminology#accesskey)をコピーして Outline クライアントに貼り付けて Outline サーバーに接続します。
