title: フィードバックやご提案をお寄せいただくには
sidebar_label: フィードバックやご提案をお寄せいただくには
---

平素は Outline のサービス向上にご協力いただきありがとうございます。以下に示すとおり、いくつかのフィードバック送信方法があります。匿名でもかまいませんし、Outline チームからの返答を希望される場合はメールでご連絡いただくこともできます。

- **デベロッパー向け**: Outline はオープンソース ソフトウェアであり、そのコードはすべて [GitHub](/about/feedback) でホストされています。皆さまのアイデアを GitHub または [Reddit](/about/feedback) コミュニティにお寄せください。

- **ユーザー向け**: Outline アプリまたは Outline マネージャー アプリから、フィードバックをお寄せください。Outline チームからの返答を希望される場合は、任意でメール欄を使用できます。また、Jigsaw と Google[k] は、ユーザーが使用中の環境に関する[一部のメタデータの収集](/about/feedback)も行っており、収集した情報を、ユーザーのブラウザ、オペレーティング システム、使用中のソフトウェア バージョンなどに関するトラブルシューティングに役立てています。

- **このサイトからのフィードバック**: このサイト内に表示されているお問い合わせリンクをクリックすることもできます。

- **重大な問題**: セキュリティに関連する重大な問題を報告される場合は、詳細を記したメールを [security@getoutline.org](mailto:security@getoutline.org) まで送信していただけますと幸いです。

ご意見の共有にご協力いただき、改めて感謝いたします。
