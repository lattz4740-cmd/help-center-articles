## VPN とは

バーチャル プライベート ネットワーク（VPN）とは、デバイスとホストサーバーの間のプライベートな接続のことです。VPN を使用すると、トラフィックはインターネット プロバイダに対して非公開になります。

次のような状況では、VPN を使用することをおすすめします。

- 公共の Wi-Fi ネットワークを使用する際にデータを保護する
- 閲覧データがインターネット プロバイダや政府機関に公開されないようにする
- 世界中のさまざまな情報源にある未検閲コンテンツにアクセスする

## Outline と従来の VPN の違いとは

インターネット プロバイダは、一般的なセキュリティ プロトコルやトラフィック量のパターンを把握することで、簡単に従来の VPN を検出し、ブロックすることが可能です。Outline は検出されにくいように設計されたプロトコルを使って構築されているため、従来の VPN よりも耐性が強く、ブロックされにくくなっています。また、ネットワーク ベースのブロックや IP ブロックのような高度な検閲に対抗します。

## Outline サーバーとは

Outline サーバーは、許可されたユーザーの接続先となる VPN を実行します。

新しいネットワークを作成する場合、独自の安全なサーバーがあればそれを Outline サーバーとして使用できます。あるいは、次のようなクラウド サービス プロバイダを使用する方法もあります。

- DigitalOcean
- Google Cloud Platform（GCP）
- Amazon Web Services（AWS）

サーバーの設定は Outline マネージャーで行います。

## サービス マネージャーとは {#servicemanager}

サービス マネージャーとは、Outline サーバーの設定や、ユーザーとのアクセスキーの共有を行う責任のある人物のことです。一般的に、サービス マネージャーがサーバーの使用に関わる費用の責任を負います。

## アクセスキーとは {#accesskey}

アクセスキーは、既存の Outline サーバーにアクセスし、VPN に接続する際に使用されます。[サービス マネージャー](#servicemanager)からアクセスキーを提供してもらうか、自分で [Outline サーバーを設定](/manager/server-setup/setup-server)してください。

アクセスキーは次のような形式です（これはあくまでも例であり、実際には機能しません）。

ss://Y2hhY2hhMjAtaWV0Zi1wb2x5MTMwNTp1eXhUQ3MzemVEMTk=@XXX.XXX.4.1:39485/?outline=1

## Outline マネージャーとは

Outline マネージャーは、サービス マネージャーが Outline サーバーの設定、[アクセスキー](#accesskey)の生成、データ使用量の上限の設定（キーごと）を行う際に使用するデスクトップ アプリケーションです。最新バージョンの Outline マネージャーは、[こちら](https://getoutline.org/get-started/#step-3)または[こちら](https://www.reddit.com/r/outlinevpn/wiki/index/download_links/)からダウンロードできます。

## Outline クライアントとは

Outline クライアントは、Outline サーバーに接続し、アクセスキーを使用して VPN にアクセスする際に使用する、デスクトップおよびモバイル用のアプリケーションです。最新バージョンの Outline クライアントは、[こちら](https://getoutline.org/get-started/#step-3)または[こちら](https://www.reddit.com/r/outlinevpn/wiki/index/download_links/)からダウンロードできます。

## データの上限とは

サービス マネージャーは Outline マネージャーを使って、アクセスキーに 30 日間の合計データに上限を設定することができます。これによりデータの使いすぎを防止し、費用を見通すことが可能です。各キーに適用するデフォルトの上限を設定できるほか、任意のキーに異なる上限を設定して、デフォルトの上限より優先することも可能です。設定した上限は即座に有効になり、1 時間ごとに自動的に適用されます。

指標を Jigsaw と共有するように設定した場合は、データ使用量の上限がどのように報告されるかについて[データ収集ポリシー](https://getoutline.org/policies/data-collection)を確認しておく必要があります。
