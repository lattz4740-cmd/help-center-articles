---
title: Outline サーバーの場所を変更するにはどうすればよいですか？
sidebar_label: Outline サーバーの場所を変更するにはどうすればよいですか？
---

設定したサーバーの場所を変更することはできません。別の場所からサーバーを運用するには、Outline サーバーを削除して、新しい Outline サーバーを作成する必要があります。

または、[動的なキー](https://developers.google.com/outline/docs/guides/service-providers/dynamic-access-keys)を使用して VPN の場所を変更します。こうすると、サーバーをローテーションして同じキーを維持することができます。なお、サーバーの場所そのものは変わりません。
