---
title: Outline サーバーのソフトウェアを更新するにはどうすればよいですか？
sidebar_label: Outline サーバーのソフトウェアを更新するにはどうすればよいですか？
---

Outline サーバーは最新のセキュリティ修正に伴って自動的に更新されるため、常に最新の Outline テクノロジーが実行されています。この自動更新プロセスを有効にするために、[Watchtower](https://github.com/v2tec/watchtower) が使用されます。このオープソース ライブラリにより、Outline ソフトウェアが含まれる Docker イメージが定期的にチェックされて更新されます。

また、Outline マネージャーを使用して Outline をインストールするときは、cron ジョブが設定され、必要に応じて[無人アップグレード](https://wiki.debian.org/UnattendedUpgrades)（Ubuntu）を使用してサーバー上のソフトウェアが自動的にアップグレード、再起動されます。ただし詳細モードでは、ホストが Outline の実行のほか、別の目的にも使用されていることを前提に既存の設定が維持されるため、この自動更新は行われません。
