---
title: Outline サーバーへのアクセスを管理する（アクセスキーを使用）
sidebar_label: Outline サーバーへのアクセスを管理する（アクセスキーを使用）
---

Outline サーバーのインストールが完了すると、サーバーへのユーザーのアクセスを共有、管理できるようになります。サーバー管理者から招待状を受け取ったユーザーは、Outline アプリケーションをダウンロードし、Outline を使ってインターネット トラフィックを保護できるようになります。

**Outline サーバーへのアクセス権を共有する**

Outline サーバーのインストールを完了した管理者は、Outline マネージャーのサーバー詳細ページに誘導され、このページでアクセスキーを作成できます。詳しくは、[アクセスキー](/about/terminology)をご確認ください。

- キーを作成する: ページの下部にある小さい [+] アイコンをクリックして、新しいキーを作成します。
- キーを共有する: 各キーの右側に共有アイコンがあり、こちらをクリックすると招待状を取得できます。この招待状をコピーして、任意のメッセージング システムに貼り付けます。

**機能リクエスト: Outline マネージャー アプリ内でアクセスを共有する**

ユーザーを招待するプロセスを効率化するため、管理者がユーザーのメールアドレスを Outline マネージャーに直接入力できるようにしてほしいとのご要望を、多数のサーバー管理者からいただいております。

残念ながら、この機能を Outline マネージャーに組み込むことはできません。Outline の基本原則のひとつは、ユーザーのプライバシーとセキュリティをサポートすることです。つまり、メールアドレスや連絡先情報を入力する場所を一切設計に入れていません。

そのため、サーバー管理者の皆様には、メールやセキュリティ保護されたチャットなど、安全なメッセージング プラットフォームを使用して招待状をエンドユーザーに送信するようお願いしています。

**アクセスキーを共有した後のユーザー エクスペリエンス**

1. ユーザーが各自のデバイスからインストール リンクをクリックします。
2. Outline アプリケーションをインストールするよう求められます（まだインストールしていない場合）。
3. 招待状に埋め込まれた一意のキーを使用して、Outline サーバーへの初期接続を確立します。
4. [接続] や [切断] ボタンを使用して、Outline サーバーを介したインターネット アクセスを管理できるようになります。

**Outline サーバーへのアクセスを削除する**

Outline マネージャーのサーバー詳細ページでは、サーバー上の各キーの右側にあるメニューのオプションからキーを削除できます。キーを削除すると、サーバーへのユーザー アクセスが削除されます。
