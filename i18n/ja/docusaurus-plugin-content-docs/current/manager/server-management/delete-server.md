---
title: Outline サーバーを削除するにはどうすればよいですか？
sidebar_label: Outline サーバーを削除するにはどうすればよいですか？
---

ほとんどのクラウド プロバイダでは、使用中の特定の仮想マシンを削除するための簡単な方法が用意されています。

クラウド プロバイダとして DigitalOcean をご利用の場合、既存の仮想マシンを削除するには、歯車ボタンをクリックして [**Destroy Server**] を選択します。すると、任意の場所に新しい仮想マシンを作成するようメッセージが表示されます。

削除操作によって Outline サーバーは完全に削除され、そのアクセスキーは機能しなくなります。ユーザーの Outline を介したアクセスが中断されないようにするには、[新しい Outline サーバーを設定](https://support.google.com/outline/answer/15331530?sjid=5147938692963654551-NC)し、そのサーバーへのアクセスを共有してから古いサーバーを削除する必要があります。
