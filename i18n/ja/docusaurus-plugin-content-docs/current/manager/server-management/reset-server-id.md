title: サーバー ID をリセットするにはどうすればよいですか？

サーバー ID は、Outline サーバーの作成時にランダムに生成されるサーバー側の ID で、匿名化された指標の共有にオプトインする際に [設定] インターフェースで確認できます。サーバー ID を確認するには、[設定] に移動し、下部までスクロールして [匿名化された指標の共有] チェックボックスをオンにします。

サーバー ID は、一定期間にわたって報告される匿名の使用状況の統計をまとめるものです。サーバー ID をリセットして新しい ID を取得するには、既存の Outline サーバーを新しいサーバーに置き換える必要があります。
