## サーバーなしで Outline を使用できますか？

残念ながらできません。Outline ソフトウェアを使用するには、サーバー管理者であれ、管理者の組織であれ、信頼できる第三者であれ、誰かが管理するサーバーへのアクセスが必要になります。

## Outline サーバーの設定にはどれくらいの時間がかかりますか？

ほとんどの場合、5 分未満で終わります。Outline は任意のクラウド サーバーにインストールできますが、DigitalOcean との連携を得て、よりユーザー フレンドリーで、手順のわかりやすいインストールができるようになりました。スクリプトを使用せずに、数回のクリック操作だけでサーバーを設定できます。

 AWS や GCP、または詳細設定を選択する場合も、インストール プロセスが簡易化され、1 つのスクリプトでほとんどの環境を処理できるようになりました。

## Outline サーバーはどこで設定できますか？

Outline サーバーの設定は、ほとんどのクラウド プロバイダで、そのサーバーが運用されている場所に関係なく行うことができます。

 最も簡単な方法は DigitalOcean で設定することです。同社は、アムステルダム、トロント、サンフランシスコ、シンガポールなど、複数の場所でサーバーを運用しているからです。別のクラウド プロバイダまたは独自のインフラストラクチャにインストールする場合は、Outline マネージャー アプリケーションで [詳細モード] を選択し、設定スクリプトを使用したインストール手順を踏みます。

## Outline サーバーの設定はどこで行うべきでしょうか?

Outline サーバーの場所を選択するときは、以下のことを考慮する必要があります。

1. Outline サーバーの場所は、インターネットにおけるユーザー エクスペリエンスに影響します。 たとえば、サーバーがアムステルダムに設置されている場合、このサーバーにアクセスするユーザーは物理的にオランダにいるかのような感覚でインターネットにアクセスできます。一部のウェブサイトはオランダ語で表示される場合すらあります。一般的に、ローカルの言語はウェブサイト上の言語選択ツールを使用してオーバーライドできます。
2. ユーザーと Outline サーバー間の距離がインターネット速度に影響する場合があります。 一般に、Outline ユーザーと Outline サーバー間の物理的な距離は、ユーザーのインターネット速度に影響する可能性があります。多くの場合、対象となる Outline ユーザーにとって物理的に最も近い場所を選択できますが、自分の国や地域に接続されているインターネット ケーブルを[海底ケーブルマップ](https://www.submarinecablemap.com/)で確認することもできます。
3. VPN サーバーの設置場所によって、法的枠組みに影響する場合があります。 Outline ソフトウェアではトラフィックのログが記録されないことに留意してください。詳しくは、[Outline 使用時のセキュリティとプライバシー](/about/security-and-privacy)をご覧ください。
