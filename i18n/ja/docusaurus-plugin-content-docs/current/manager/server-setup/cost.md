title: Outline を運用するにはどのくらいの費用がかかりますか？
sidebar_label: Outline を運用するにはどのくらいの費用がかかりますか？
---

Outline ソフトウェアは誰でも無償で利用できます。VPN を管理しているサーバー管理者であれ、Outline を使用してオープンなインターネットにアクセスするユーザーであれ、コストはかかりません。

 ただし、Outline を実行するには、クラウド サーバーへのアクセス権が必要になります。サーバーへのアクセス権をすでに持っているサーバー管理者は、そのサーバーに Outline を追加コストなしでインストールできます。サーバーへのアクセス権のない管理者は、[DigitalOcean](https://www.digitalocean.com/)や Amazon Web Servicesなどのクラウド サービス プロバイダからアクセス権を取得でき、1 か月あたり約 5 米ドルで 1 TB のデータ転送が許可されます。この割り当て量は 1 台のサーバーで数百人のユーザーをサポートするのに十分な量です。

 任意のクラウド プロバイダで Outline を運用するのに、どれくらいのコストがかかるかを計算する方法の例を示します。

| *ユーザー 1 人あたりのデータ転送の平均月間使用量を 5 GB と仮定すると、1 か月あたり 5 米ドルのプランでは約 200 人の同時ユーザーに対応でき、1 ユーザーあたりの月間コストはわずか 2.5 セントになります。1 ユーザーあたりの月間のデータ転送量は、ユーザーのアクティビティが低帯域幅であるか高帯域幅であるかによって大きく異なりますが、ほとんどのクラウド プロバイダはトラフィックの増加に柔軟に対応できます。* |
| --- |

そのうえ、Outline の使用に関して、Jigsaw と Google はユーザーの匿名性を完全に確保し、ユーザーの身元やトラフィックを追跡することはありません。また、Outline の使用を有料化する計画もありません。代わりに、オープンソース コミュニティとの連携を深め、ユーザーに対してソフトウェアを無償で提供できるようにいたします。Jigsaw と Google が収集するデータについて詳しくは、[こちら](https://getoutline.org/policies/data-collection)をご覧ください。
