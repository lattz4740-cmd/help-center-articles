---
title: 複数の Outline サーバーを設定する方法
sidebar_label: 複数の Outline サーバーを設定する方法
---

追加の Outline サーバーを設定するには、Outline マネージャー アプリケーションの左側にあるナビゲーション パネルの [+] アイコンをクリックします。新しいサーバーを追加する手順は、最初のサーバーをインストールしたときの手順と同じです。

- 作成できる Outline サーバーの数に制限はありません。
- 作成する Outline サーバーごとに、それに対応する仮想マシンが必要になります。
- 追加のマシンやドロップレットを作成すると、クラウド プロバイダの料金が増える可能性があります。クラウド プロバイダの価格パッケージで料金を確認してから追加操作を行ってください。

## 追加の Outline サーバーを DigitalOcean に作成する

[+] アイコンをクリックして DigitalOcean へのインストールを選択した後は、最初のサーバーを設定したときと同じ手順を踏みます。また、Outline マネージャーは DigitalOcean と統合されているので、Outline マネージャー アプリから離れることなく、ドロップレットが作成されます。

 Outline マネージャーが一度にサポートできる DigitalOcean アカウントは 1 つだけです。他の DigitalOcean アカウントから他の Outline サーバーを追加または作成したい場合は、詳細設定として追加できます。

## 追加の Outline サーバーを GCP や AWS など、別のクラウド サービス プロバイダに作成する

最初に、選択したクラウド プロバイダに新しい仮想マシンを作成します。次に Outline マネージャーを開き、最初に行ったときと同じように、詳細インストールの手順を実施します。
