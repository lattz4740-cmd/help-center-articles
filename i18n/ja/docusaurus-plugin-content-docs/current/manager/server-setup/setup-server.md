Outline サーバーを設定することは、Outline を使用できる状態にするための最初のステップです。Outline を通じてオープンなインターネットに接続するには、サーバー管理者または信頼できる別のユーザーがサーバーを設定する必要があります。

## 始める前に

Outline サーバーの設定を開始する前に、以下に示すいくつかのことが必要になります。

1. 独自のサーバーまたはクラウド サービス プロバイダへのアクセス。後者には、DigitalOcean、Amazon Web Services（AWS）、Google Cloud Platform（GCP）などが含まれます。

 クラウド サーバーにすぐにアクセスすることができない場合は、上記のプロバイダを含め、任意のプロバイダでアカウントを簡単に設定できます。登録にはクレジット カードが必要になる可能性があります。
2. macOS 10.9 以降、Windows 7.0 以降、Linux が稼働しているデスクトップ パソコン。
3. Outline マネージャー アプリケーション。

DigitalOcean で設定する

DigitalOcean での Outline のインストールは、数回のクリックで誰でも簡単に行うことができるようになりました。Outline マネージャーをパソコンにダウンロード、インストールした後に DigitalOcean の設定オプションを選択できるので、画面に表示されるいくつかの簡単な手順に従って、Outline サーバーの設定を構成してインストールします。

## 別のクラウド プロバイダで設定する

Outline マネージャーをダウンロード、インストールした後、AWS、GCP、DigitalOcean などのプロバイダの仮想マシンに Outline をインストールすることもできます。環境がそれぞれ異なるため、Outline マネージャーの設定に関する説明には、最も一般的なクラウド プロバイダでの手順も付記してあります。たとえば、Outline をサーバーにインストールするためのインストール スクリプトを実行する前に、仮想マシンで設定を構成する方法に関する説明があります。
