こちらは、Outline マネージャーとクライアントのユーザーを対象としたサポート ウェブサイトです。開発者向けのサポートについては GitHub をご利用ください。質問がある場合は、SDK の[ディスカッション ボード](https://github.com/Jigsaw-Code/outline-sdk/discussions)に投稿してください。ディスカッション ボードは、質問の投稿やアイデアの共有、デモへのリンクの掲載、Outline SDK を使用している他の開発者のサポートに最適な場所です。機能リクエストやバグの報告を行う場合は、[[Issue](https://github.com/Jigsaw-Code/outline-sdk/issues/new)] を開きます。
