ეს მხარდაჭერის ვებსაიტი Outline Manager-ისა და Client-ის მომხმარებლებისთვისაა განკუთვნილი. დეველოპერებო, მხარდაჭერისთვის GitHub გამოიყენეთ. შეკითხვის დასასმელად გამოაქვეყნეთ SDK [Discussion-ის დაფაზე](https://github.com/Jigsaw-Code/outline-sdk/discussions). SDK Discussion-ის დაფა შესანიშნავი ადგილია, სადაც შეგიძლიათ, დასვათ კითხვები, გააზიაროთ იდეები, მიიღოთ ბმულები დემო ვერსიებზე და დაეხმაროთ სხვა დეველოპერებს Outline SDK-ის გამოყენებით. ფუნქციის მოთხოვნის ან სისტემური ხარვეზის ანგარიშებისთვის გახსენით [პრობლემა](https://github.com/Jigsaw-Code/outline-sdk/issues/new) .
