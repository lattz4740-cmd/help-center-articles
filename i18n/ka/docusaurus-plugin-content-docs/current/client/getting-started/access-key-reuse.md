დიახ. [წვდომის გასაღების](/about/terminology) გამოყენება შეგიძლიათ მოწყობილობების ნებისმიერ რაოდენობაზე, მაგრამ არ გირჩევთ გასაღების სხვა ადამიანთან გაზიარებას. მათ, ვისაც აქვთ თქვენი წვდომის გასაღები, შეუძლიათ თქვენი ინტერნეტის სრული ტრაფიკის ინსპექტირება, თუ მასზე წვდომა აქვთ, რის შედეგადაც თქვენ მიერ ინტერნეტის გამოყენება აღარაა დაცული და პირადი.
