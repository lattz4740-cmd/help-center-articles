შეიძლება შეცდომის ეს შეტყობინება იხილოთ: „სამწუხაროდ, Outline სათანადოდ ვერ დაინსტალირდა. გთხოვთ, ხელახლა სცადოთ მისი ინსტალაცია. თუ ეს ვერ დაგეხმარებათ, [https://support.getoutline.org/s/contactsupport?](https://support.getoutline.org/s/contactsupport?)გამოგვეხმაურეთ“.

თუ Outline-ს Windows-ში იყენებთ, შესაძლოა, ზოგჯერ მოულოდნელი შეცდომა მოხდეს. შემთხვევათა უმეტესობაში საჭიროა Outline TAP ადაპტერის (დრაივერი) წაშლა და Outline-ის ხელახალი ინსტალაცია.

ნაბიჯები შეიძლება განსხვავდებოდეს თქვენი Windows-ის ოპერაციული სისტემის მიხედვით, მაგრამ ქვემოთ მოცემულია ზოგადი ნაბიჯები, როგორ შეასრულოთ TAP ადაპტერისა და Outline-ის დეინსტალაცია და შემდეგ Outline-ის ხელახალი ინსტალაცია.

1. TAP ადაპტერის დეინსტალაცია Outline-ის კლიენტისთვის
   - გადადით **მოწყობილობათა მმართველებში**, შემდეგ **ქსელის ადაპტერებში**
   - იპოვეთ **TAP-Windows Adapter V9** ფაილი ან TAP ადაპტერი, რომელიც დაკავშირებულია Outline-თან
   - შეასრულეთ ამ ადაპტერის დეინსტალაცია ან წაშალეთ ის. გაითვალისწინეთ, რომ ამან შეიძლება, იმოქმედოს VPN-ის სხვა აპებზეც, რომლებიც დაინსტალირებული გაქვთ.
2. Outline-ის კლიენტის დეინსტალაცია
   - გადადით **პროგრამებსა და ფუნქციებში**, შემდეგ კი აირჩიეთ **პროგრამის დეინსტალაცია**
   - იპოვეთ Outline-ის კლიენტის აპი და შეასრულეთ Outline-ის კლიენტის დეინსტალაცია
   - [ჩამოტვირთეთ Outline-ის კლიენტის აპის უახლესი ვერსია](https://getoutline.org/get-started/#step-3) და ხელახლა დააინსტალირეთ ის თქვენს Windows მოწყობილობაზე. ახალი ინსტალაცია ავტომატურად დააინსტალირებს TAP-ის ახალ ადაპტერს.

თუ კვალავაც ეჩეხებით სირთულეს, [მხარდაჭერას დაუკავშირდით](https://support.getoutline.org/s/contactsupport?).
