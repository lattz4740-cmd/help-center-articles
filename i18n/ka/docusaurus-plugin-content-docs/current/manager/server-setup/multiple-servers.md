Outline-ის დამატებითი სერვერების დასაყენებლად დააწკაპუნეთ ხატულაზე „+“ თქვენს Outline Manager აპში მარცხნივ, ნავიგაციის არეში. ახალი სერვერის დამატების ინსტრუქცია იგივეა, რაც პირველად ინსტალაციის შემთხვევაში.

- არ არსებობს ლიმიტი, თუ Outline-ის რამდენი სერვერის შექმნა შეგიძლიათ.
- Outline-ის ყოველი სერვერისთვის, რომელსაც შექმნით, შესაბამისი ვირტუალური მანქანა დაგჭირდებათ.
- დამატებითი მანქანების ან „droplet“-ების შექმნამ შეიძლება გაგიზარდოთ საფასური თქვენი ღრუბლის პროვაიდერთან. შეამოწმეთ ფასების პაკეტები თქვენი ღრუბლის პროვაიდერთან, რათა იცოდეთ, რას ელოდოთ.

## Outline-ის დამატებითი სერვერის შექმნა DigitalOcean-ში

ხატულაზე „+“ დაწკაპუნების და DigitalOcean-ში ინსტალაციის არჩევის შემდეგ უნდა მიჰყვეთ იმავე ინსტრუქციას, რომელიც გამოიყენეთ თქვენი პირველი სერვერის დაყენებისას. აგრეთვე, რადგანაც Outline Manager ინტეგრირებულად მუშაობს DigitalOcean-თან, ჩვენ შეგვიძლია შეგიქმნათ „droplet“ ისე, რომ Outline Manager აპიდან გასვლა არ დაგჭირდეთ.

გაითვალისწინეთ, რომ Outline Manager-ს ერთჯერადად აქვს DigitalOcean-ის მხოლოდ ერთი ანგარიშის მხარდაჭერა. თუ გსურთ, დაამატოთ ან შექმნათ Outline-ის სხვა სერვერები DigitalOcean-ის სხვა ანგარიშებიდან, შეგიძლიათ დაამატოთ გაფართოებული კონფიგურაციის სახით.

## Outline-ის დამატებითი სერვერების შექმნა GCP-ზე, AWS-ზე ან ღრუბლოვანი სერვისის სხვა პროვაიდერთან

დაიწყეთ ახალი ვირტუალური მანქანის შექმნით ღრუბლის თქვენ მიერ არჩეულ პროვაიდერთან. შემდეგ გახსენით Outline Manager და ბოლომდე მიჰყევით ინსტრუქციას გაფართოებული ინსტალაციისთვის, ზუსტად ისევე, როგორც პირველად.
