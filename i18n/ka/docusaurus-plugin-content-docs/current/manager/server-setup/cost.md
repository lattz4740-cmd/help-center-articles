title: "რა ღირს Outline-ის ოპერირება?"

---

Outline-ის პროგრამული უზრუნველყოფა უფასოა ყველასთვის მიუხედავად იმისა, სერვერის ადმინისტრატორი ხართ, რომელიც VPN-ს მართავს, თუ მომხმარებელი, რომელიც Outline-ს ინტერნეტზე წვდომისთვის იყენებს.

 Outline საჭიროებს წვდომას ღრუბლოვან სერვერზე იმისთვის, რომ მისი გაშვება მოხერხდეს. სერვერის ადმინისტრატორებს, რომლებსაც უკვე აქვთ წვდომა სერვერზე, შეუძლიათ Outline-ის ინსტალაცია დამატებითი საფასურის გარეშე. ყველას, ვისაც აქვს წვდომა სერვერზე, შეუძლია წვდომის მიღება ღრუბლის პროვაიდერებისგან, როგორიცაა [DigitalOcean](http://www.digitalocean.com/) ან Amazon Web Services, დაახლოებით 5 აშშ დოლარად თვეში 1 ტერაბაიტის მოცულობის მონაცემთა გადაცემისთვის — ეს საკმარისია ასობით მომხმარებლის მხარდასაჭერად ერთ სერვერზე.

 მიერ არჩეული ღრუბლის პროვაიდერით Outline-ის გაშვების ხარჯის გამოთვლის მაგალითი:

| *ვთქვათ, მონაცემთა გადაცემის 5 გიგაბაიტი შეადგენს გამოყენების საშუალო თვიურ მაჩვენებელს ერთ მომხმარებელზე; თვეში 5 აშშ დოლარიანი გეგმა მოგცემდათ დაახლოებით 200 თანადროული მომხმარებლის დაშვების საშუალებას, ხოლო თითოეული მომხმარებლის თვიური ფასი შეადგენდა 2,5 ცენტს თვეში. გაითვალისწინეთ, რომ თვიურად გამოყენებული მონაცემთა გადაცემა ერთ მომხმარებელზე ძალიან განსხვავებული იქნება იმის მიხედვით, ასრულებენ თუ არა მომხმარებლები დაბალი თუ მაღალი გამტარუნარიანობის აქტივობებს, თუმცა ღრუბლოვანი სერვისების პროვაიდერთა უმრავლესობა გამოიჩენს მოქნილობას ტრაფიკის ზრდასთან გასამკლავებლად.* |
| --- |

ფაქტობრივად, Outline-ის გამოყენება სრულიად ანონიმურია Jigsaw-ისთვის და Google-ისთვის. ჩვენ არ ვადევნებთ თვალს თქვენ ვინაობას ან ტრაფიკს და არ არსებობს მონეტიზაციის გეგმა. ამის მაგივრად, ვთანამშრომლობთ ჩვენი ღია კოდის საზოგადოებასთან, რათა უზრუნველვყოთ პროგრამული უზრუნველყოფა საფასურის გარეშე ჩვენი მომხმარებლებისთვის. მონაცემების შესახებ, რომლებსაც ვაგროვებთ, შეიტყვეთ მეტი [აქ](/about/data-collection).
