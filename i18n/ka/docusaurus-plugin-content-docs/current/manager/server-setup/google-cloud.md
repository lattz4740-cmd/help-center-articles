## გადახედვა

Outline Manager-ს აქვს ფუნქცია, რომლითაც ავტომატურად შეგიძლიათ Outline-ის სერვერის კონფიგურაციის დაყენება სერვერზე, რომელიც გაშვებულია Google Cloud-ში. თუ ამ ფუნქციას აირჩევთ, Outline Manager გთხოვთ შესვლას თქვენს Google ანგარიშში, რომელიც მოგანიჭებთ გარკვეულ [OAuth](https://developers.google.com/identity/protocols/oauth2) ნებართვებს Outline Manager-ის თქვენს ადგილობრივ ინსტალაციაზე თქვენი Google Cloud ანგარიშის კონფიგურირების მიზნით.

 თუ ამ ნებართვების მინიჭება არ გსურთ, მიჰყევით გაფართოებული დაყენების ინსტრუქციას Outline Manager-ში, რათა Outline გაუშვათ Google Cloud Platform-ზე.

## მინიჭებული ნებართვები

ავტომატიზებული დაყენების უზრუნველსაყოფად Outline Manager საჭიროებს შემდეგ ნებართვებს თქვენი Google ანგარიშიდან.

## Google Cloud Platform

- თქვენი Google Compute Engine-ის რესურსების ნახვა და მართვა
- თქვენი მონაცემების ნახვა Google Cloud სერვისებში და თქვენი Google ანგარიშის ელფოსტის მისამართის ნახვა

## ანგარიშის საბაზისო ინფორმაცია

- თქვენი Google ანგარიშის ძირითადი ელფოსტის მისამართის ნახვა
- თქვენი დაკავშირება Google-ში არსებულ თქვენს პერსონალურ ინფორმაციასთან

## დამატებითი წვდომა

- თქვენი Cloud Platform-ის პროექტების მართვა
- თქვენი Google Cloud Platform-ის ბილინგის ანგარიშის ნახვა და მართვა
- თქვენი Google API სერვისის კონფიგურაციის მართვა

ამ ნებართვებით შეგვიძლია მხარი დავუჭიროთ გაფართოებულ ფუნქციონალობას თქვენი Outline-ის სერვერების სამართავად, მათ შორის, შემდეგს:

- თქვენთვის ნების დართვა, აირჩიოთ სწორი ბილინგის ანგარიში
- ახალი პროექტის შექმნა თქვენი Outline-ის სერვერების ორგანიზებისთვის
- ხელმისაწვდომი მონაცემთა ცენტრების ჩამონათვალის შექმნა
- ახალი ვირტუალური მანქანების შექმნა Outline-ის გასაშვებად
- ახალი ვირტუალური მანქანის კონფიგურირება Outline-ით

## ნებართვების გაუქმება

შეგიძლიათ გააუქმოთ წვდომა Google Cloud Platform-ზე Outline Manager-ისთვის [ჩემი ანგარიშის](https://myaccount.google.com/permissions) მონახულებით. თუ წვდომას გამოიხმობთ, ნებისმიერი სერვერი, რომელიც შექმენით ავტომატიზებული დაყენებით, გაშვებული დარჩება, მაგრამ აღარ გამოჩნდება Outline Manager-ში. მათთვის წვდომის აღსადგენად, უბრალოდ, ხელახლა დააკავშირეთ Google Cloud Platform-თან ავტომატიზებული დაყენების ნაკადის დაწყებით.

## Outline-ის პროექტის ორგანიზაცია

Google Cloud-ის ავტომატიზებული დაყენება იყენებს ერთ[Google Cloud პროექტს](https://cloud.google.com/resource-manager/docs/creating-managing-projects) თქვენი Outline-ის სერვერების ორგანიზებისთვის. პროექტი იქმნება ავტომატიზებული დაყენების პირველი გამოყენების დროს, პროექტის შემოთავაზებული ID-ით, რომელიც იწყება სიტყვით „Outline-“ და გრძელდება შემთხვევითი სიმბოლოებისგან შედგენილი ფრაზით. შექმნისას შეგიძლიათ აირჩიოთ სხვა პროექტის ID, თუ ასე გირჩევნიათ. პროექტს დაერქმევა „Outline-ის სერვერები“.

## ბილინგის ანგარიში

Google Cloud პროექტები საჭიროებს „ბილინგის ანგარიშს“, რომელიც გადახდის ინფორმაციას განსაზღვრავს. როდესაც პირველად იყენებთ Google Cloud-ის ავტომატიზებულ დაყენებას, მოგეთხოვებათ ბილინგის ანგარიშის მითითება Outline-ის სერვერებთან ასოცირებისთვის. ზოგჯერ სერვერის გაშვება წყდება ბილინგის ანგარიშის პრობლემის გამო. ასეთ შემთხვევაში უნდა შეხვიდეთ სისტემაში [Google Cloud კონსოლში](https://console.cloud.google.com/getting-started), მოძებნოთ Google Cloud პროექტი, დაკავშირებული Outline-თან (სახელწოდებით „Outline-ის სერვერები“) და განაახლოთ ბილინგის პარამეტრები.

## სერვერების განადგურება

თუ გსურთ ავტომატიზებული დაყენებით შექმნილი თქვენი სერვერების განადგურება, ამის გაკეთება ყველაზე ადვილია Outline Manager-იდან. თუმცა, თუ გსურთ სერვერები თვითონ გაანადგუროთ, შეგიძლიათ შეხვიდეთ სისტემაში [Google Cloud კონსოლში](https://console.cloud.google.com/getting-started), იპოვოთ პროექტი, რომელიც თავდაპირველი დაყენების დროს შეიქმნა (სახელწოდებით „Outline-ის სერვერები“) და ან წაშალოთ რესურსები მასში, ან გამორთოთ პროექტი.
