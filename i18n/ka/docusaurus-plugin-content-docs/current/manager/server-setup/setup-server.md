Outline-ის სერვერის დაყენება პირველი ნაბიჯია იმისათვის, რომ Outline-ის გამოყენება შეძლოთ. თქვენ ან ვინმემ, ვისაც ენდობით, უნდა დააყენოთ სერვერი იმისათვის, რომ დაუკავშირდეთ ღია ინტერნეტს Outline-იდან.

## დაწყებამდე
თქვენი Outline-ის სერვერის დაყენების დაწყებამდე დაგჭირდებათ რამდენიმე რაღაც:

1. წვდომა საკუთარ სერვერებზე ან Cloud სერვისების პროვაიდერზე, როგორიცაა DigitalOcean, Amazon Web Services (AWS) ან Google Cloud Platform (GCP).

    თუ არ შეგიძლიათ ღრუბლოვან სერვერზე დაუყოვნებლივ წვდომა, შეგიძლიათ ადვილად დააყენოთ ანგარიში ნებისმიერ, მათ შორის, ზემოთ ჩამოთვლილ პროვაიდერთან. რეგისტრაციისთვის, სავარაუდოდ, საკრედიტო ბარათი დაგჭირდებათ.
2. სამაგიდო კომპიუტერი, რომელზეც გაშვებულია macOS 10.9+, Windows 7.0+ ან Linux.
3. Outline Manager აპი.

## DigitalOcean-ის დახმარებით დაყენება
ჩვენ გავამარტივეთ Outline-ის რამდენიმე დაწკაპუნებით ინსტალაცია DigitalOcean-ის დახმარებით. თქვენს კომპიუტერში Outline Manager-ის ჩამოტვირთვისა და ინსტალაციის შემდეგ შეგიძლიათ აირჩიოთ DigitalOcean-ის დაყენების ვარიანტი, რომელიც გაგიძღვებათ რამდენიმე მარტივი ეკრანით, რომ Outline-ის სერვერის კონფიგურირება და ინსტალაცია შეძლოთ.

## ღრუბლის სხვა პროვაიდერით დაყენება
Outline Manager-ის ჩამოტვირთვისა და ინსტალაციის შემდეგ აირჩიეთ Outline-ის სერვერის ინსტალაცია AWS-ის, GCP-ს, DigitalOcean-ის ან სხვა პროვაიდერის დახმარებით. ყველა გარემო განსხვავებულია, ამიტომ Outline Manager-ის დაყენების ნაკადში ყველაზე გავრცელებული ღრუბლოვანი სერვისების პროვაიდერებისთვის დავამატეთ ინსტრუქცია, რომელიც მოიცავს წესებს, თუ როგორ შეასრულოთ პარამეტრების კონფიგურირება თქვენს ვირტუალურ მანქანაზე, ვიდრე გაუშვებთ საინსტალაციო სცენარს Outline-ის ინსტალაციისთვის სერვერზე.
