**შემიძლია, Outline გამოვიყენო სერვერის გარეშე?**

 სამწუხაროდ, არა. Outline-ის პროგრამული უზრუნველყოფა საჭიროებს წვდომას სერვერზე მიუხედავად იმისა, ის იმართება თქვენ მიერ, თქვენი ორგანიზაციის თუ სანდო მესამე მხარის მიერ.

## რა დრო სჭირდება Outline-ის სერვერის დაყენებას?

უმრავლეს შემთხვევაში, 5 წუთზე ნაკლები. Outline-ის ინსტალაცია შეგიძლიათ ნებისმიერ ღრუბლოვან სერვერზე, თუმცა ჩვენ ვითანამშრომლეთ DigitalOcean-თან, რათა შემოგთავაზოთ მომხმარებელზე უფრო მეტად მორგებული, ნაბიჯ-ნაბიჯ ინსტალაციის გამოცდილება, რომლითაც შეგიძლიათ დააყენოთ თქვენი სერვერი სულ რამდენიმე დაწკაპუნებით, სცენარების გარეშე.

თუ აირჩიეთ AWS, GCP ან გაფართოებული დაყენება, ჩვენ გავამარტივეთ სერვერის ინსტალაციის პროცესი ერთ სცენარამდე, რომელიც მუშაობს თითქმის ყველა გარემოში.

## სად შემიძლია Outline-ის სერვერის დაყენება?

Outline-ის სერვერის დაყენება შესაძლებელია ღრუბლოვანი სერვისის პროვაიდერების უმრავლესობაში, სადაც კი ისინი ოპერირებს.

ყველაზე მარტივია მისი დაყენება DigitalOcean-ზე, რადგანაც მას აქვს მრავალი მდებარეობა, როგორიცაა ამსტერდამი, ტორონტო, სან-ფრანცისკო და სინგაპური. თუ გირჩევნიათ მისი ინსტალაცია სხვა ღრუბლის პროვაიდერზე ან საკუთარ ინფრასტრუქტურაში, შეგიძლიათ აირჩიოთ „გაფართოებული რეჟიმი“ Outline Manager აპლიკაციაში და მიჰყვეთ ინსტალაციის ინსტრუქციას დაყენების სცენარის გამოყენებით.

## სად უნდა დავაყენო Outline-ის სერვერი?

1. როდესაც ირჩევთ მდებარეობას თქვენი Outline-ის სერვერისთვის, უნდა გაითვალისწინოთ შემდეგი ფაქტორები:
2. Outline-ის სერვერის მდებარეობა გავლენას ახდენს მომხმარებლის გამოცდილებაზე ინტერნეტში. მაგალითად, თუ სერვერი მდებარეობს ამსტერდამში, მომხმარებელი, რომელიც წვდომას იქონიებს ამ სერვერზე, ინტერნეტში მიიღებს ისეთ გამოცდილებას, თითქოს ფიზიკურად ნიდერლანდებში იმყოფებოდეს. ზოგიერთი ვებსაიტი ჰოლანდიურადაც კი შეიძლება იყოს ნაჩვენები. ჩვეულებისამებრ, შეგიძლიათ უგულებელყოთ ადგილობრივი ენა ვებსაიტზე, ენის ამომრჩევის გამოყენებით.
3. თქვენს მომხმარებლებსა და Outline-ის სერვერს შორის მანძილი შეიძლება გავლენას ახდენდეს სიჩქარეზე. ზოგადად, Outline-ის მომხმარებლებსა და სერვერს შორის ფიზიკურ მანძილს შეუძლია გავლენა მოახდინოს მომხმარებლების ინტერნეტის სიჩქარეზე. უმეტესწილად შეგიძლიათ აირჩიოთ სერვერის მდებარეობა იმ ადგილთან ყველაზე ახლოს, სადაც თქვენი მოსალოდნელი მომხმარებლები იმყოფებიან, მაგრამ შეგიძლიათ შეამოწმოთ [წყალქვეშა კაბელების რუკა](https://www.submarinecablemap.com/), რომ ნახოთ, რომელი ინტერნეტის კაბელი უკავშირდება თქვენს ქვეყანას ან რეგიონს.
4. თქვენი VPN სერვერის მდებარეობამ შეიძლება გავლენა მოახდინოს სამართლებრივ ნორმებზე. გთხოვთ, გაითვალისწინოთ, რომ Outline-ის პროგრამული უზრუნველყოფა თქვენს ტრაფიკს არ აღრიცხავს. შეიტყვეთ მეტი [Outline-ის გამოყენების დროს უსაფრთხოებისა და კონფიდენციალურობის](/about/security-and-privacy) შესახებ.
