---

შეიძლება შეცდომის ეს შეტყობინება იხილოთ: „სამწუხაროდ, Outline სათანადოდ ვერ დაინსტალირდა. გთხოვთ, ხელახლა ცადოთ მისი ინსტალაცია. [გამოგვეხმაურეთ](/about/feedback), თუ ეს ვერ დაგეხმარებათ.

თუ Outline-ს Windows-ში იყენებთ, შესაძლოა, ზოგჯერ მოულოდნელი შეცდომა მოხდეს. უმეტესწილად საჭიროა Outline TAP ადაპტერის (დრაივერი) წაშლა და Outline-ის ხელახლა ინსტალაცია.

ნაბიჯები შეიძლება განსხვავდებოდეს თქვენი Windows-ის ოპერაციული სისტემის მიხედვით, მაგრამ ქვემოთ მოცემულია ზოგადი ნაბიჯები, როგორ შეასრულოთ TAP ადაპტერისა და Outline Manager-ის დეინსტალაცია და შემდეგ ხელახლა დააყენოთ Outline Manager.

1. TAP ადაპტერის დეინსტალაცია Outline Manager-ისთვის
   1. გადადით მოწყობილობათა მმართველებში, შემდეგ — ქსელის ადაპტერებში
   2. იპოვეთ ფაილი „TAP-Windows Adapter V9“ ან TAP ადაპტერი, რომელიც დაკავშირებულია Outline-თან
   3. შეასრულეთ ამ ადაპტერის დეინსტალაცია ან წაშალეთ ის. გაითვალისწინეთ, რომ ამან შეიძლება, იმოქმედოს VPN-ის სხვა აპებზეც, რომლებიც დაინსტალირებული გაქვთ.
2. Outline Manager-ის დეინსტალაცია
   1. გადადით პროგრამებსა და ფუნქციებში, შემდეგ კი აირჩიეთ პროგრამის დეინსტალაცია
   2. იპოვეთ Outline Manager აპი და შეასრულეთ მისი დეინსტალაცია
   3. [ჩამოტვირთეთ Outline Manager აპის უახლესი ვერსია](https://getoutline.org/get-started/#step-1) და ხელახლა დააინსტალირეთ ის თქვენს Windows მოწყობილობაში. ახალი ინსტალაცია ავტომატურად დააინსტალირებს ახალ TAP ადაპტერს.

თუ პრობლემა არ აღმოიფხვრა, [დაუკავშირდით მხარდაჭერას](/about/feedback).
