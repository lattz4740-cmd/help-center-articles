---
title: "როგორ გადავაყენო ჩემი სერვერის ID?"
sidebar_label: "როგორ გადავაყენო ჩემი სერვერის ID?"
---

სერვერის ID არის შემთხვევითობის პრინციპით, თქვენ მიერ Outline სერვერის შექმნისას, სერვერის მხარეს გენერირებული ID. მას იპოვით, როდესაც დაეთანხმებით ანონიმური მეტრიკის გაზიარებას პარამეტრების ინტერფეისში. თქვენი სერვერის ID-ს დადგენა შეგიძლიათ აქ: პარამეტრები => გადადით ბოლოში => შეამოწმეთ „ანონიმური მეტრიკის გაზიარება“.

სერვერის ID, დროთა განმავლობაში, ებმება მოხსენებული ანონიმური გამოყენების სტატისტიკას. თუ გსურთ, გადააყენოთ სერვერის ID და მიიღოთ ახალი, Outline-ის არსებული სერვერი უნდა ჩაანაცვლოთ ახლით.

თუ DigitalOcean-ს იყენებთ ღრუბლის პროვაიდერად, სერვერის გადაყენება შეგიძლიათ პარამეტრებში გადასვლითა და სერვერის განადგურების არჩევით. ამ მოქმედების დაბრუნება შეუძლებელია და ის წაშლის თქვენს ავტორიზაციის მონაცემებსაც. ამ მოქმედების შესრულებისთანავე გიკარნახებთ, შექმნათ ახალი სერვერი სასურველ მდებარეობაზე, ხოლო ახალი სერვერის ID დაგენერირდება.
