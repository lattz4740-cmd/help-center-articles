title: "როგორ შევცვალო Outline-ის სერვერის მდებარეობა?"
sidebar_label: "როგორ შევცვალო Outline-ის სერვერის მდებარეობა?"
---

დაყენების შემდეგ სერვერის მდებარეობის შეცვლა შეუძლებელია. თქვენი სერვერის სხვა მდებარეობიდან გასაშვებად საჭიროა, წაშალოთ თქვენი Outline-ის სერვერი და შექმნათ ახალი.

ალტერნატივის სახით შეგიძლიათ, თქვენი VPN-ის მდებარეობის შეცვლა [დინამიკური გასაღებების](https://developers.google.com/outline/docs/guides/service-providers/dynamic-access-keys) გამოყენებით, რაც საშუალებას მოგცემთ, გადაანაცვლოთ სერვერები და შეინარჩუნოთ იგივე გასაღებები. სერვერების მდებარეობა, თავის მხრივ, არ შეიცვლება.
