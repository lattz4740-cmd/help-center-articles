თქვენი Outline-ის სერვერის ინსტალაციის დასრულების შემდეგ უკვე შეგიძლიათ დაიწყოთ მასზე ხალხის წვდომის გაზიარება და მართვა. ვინც თქვენგან მოსაწვევს მიიღებს, შეძლებს Outline აპის ჩამოტვირთვას, რათა გამოიყენოს Outline თავისი ინტერნეტის ტრაფიკის დასაცავად.

**წვდომის გაზიარება თქვენს Outline-ის სერვერზე**

 Outline-ის სერვერის ინსტალაციის დასრულების შემდეგ გადამისამართდებით სერვერის დეტალების გვერდზე Outline Manager-ში, სადაც წვდომის გასაღებების შექმნას შეძლებთ. შეიტყვეთ მეტი [წვდომის გასაღებების](/about/terminology) შესახებ.

- გასაღებების შექმნა: ახალი გასაღებების შესაქმნელად დააწკაპუნეთ პატარა „+“ ხატულაზე გვერდის ბოლოში.
- გასაღებების გაზიარება: თითოეული გასაღების მარჯვნივ არის გაზიარების ხატულა, რომელზე დაწკაპუნებაც შეგიძლიათ მოსაწვევის მისაღებად. დააკოპირეთ და ჩასვით ეს მოსაწვევი შეტყობინებების მიმოცვლის თქვენს შერჩეულ სისტემაში.

**ფუნქციის მოთხოვნა: გააზიარეთ წვდომა Outline Manager აპიდან**

 ბევრი სერვერის ადმინისტრატორი გვთხოვს მოწვევის პროცესის გამარტივებას მათთვის მომხმარებლის ელფოსტის მისამართის პირდაპირ Outline Manager-ში შეყვანის ვარიანტის მიცემით.

სამწუხაროდ, ნაკლებად მოსალოდნელია, რომ ეს ფუნქციონალობა ჩავაშენოთ Outline Manager-ში. ჩვენი ერთ-ერთი ძირითადი პრინციპია, მხარი დავუჭიროთ ჩვენი მომხმარებლების კონფიდენციალურობას და უსაფრთხოებას, რაც ნიშნავს, რომ ჩვენ არ შეგვიქმნია ადგილი, სადაც შესაძლებელია ელფოსტის მისამართების ან საკონტაქტო ინფორმაციის ჩასმა.

ამიტომ სერვერის ადმინისტრატორებს ვთხოვთ, საბოლოო მომხმარებლისთვის მოსაწვევის გასაგზავნად გამოიყენონ შეტყობინებების მიმოცვლის დაცული პლატფორმა, როგორიცაა ელფოსტა ან დაცული ჩეთი.

**როგორია მომხმარებლის გამოცდილება მას შემდეგ, როდესაც წვდომის გასაღებს გაუზიარებთ**

1. მომხმარებელი დააწკაპუნებს ინსტალაციის ბმულზე თავისი მოწყობილობიდან
2. მას ვუკარნახებთ, დააყენოს Outline აპი, თუ უკვე არ აქვს ის
3. ის დაამყარებს თავდაპირველ კავშირს თქვენს Outline-ის სერვერთან უნიკალური გასაღების მეშვეობით, რომელიც ჩაშენებულია მოსაწვევში
4. ახლა ის შეძლებს დაკავშირების/გათიშვის ღილაკის გამოყენებას თავისი წვდომის სამართავად ინტერნეტზე თქვენი Outline-ის სერვერიდან

**თქვენს Outline-ის სერვერზე წვდომის გაუქმება**

 სერვერის დეტალების გვერდიდან Outline Manager-ში, თითოეული გასაღების მარჯვნივ სერვერში, დაინახავთ მენიუს გასაღების წაშლის ვარიანტით. გასაღების წაშლა მომხმარებელს თქვენს სერვერზე წვდომას გაუუქმებს.
