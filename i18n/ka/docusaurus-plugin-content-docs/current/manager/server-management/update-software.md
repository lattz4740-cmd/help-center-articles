sidebar_label: "როგორ განვაახლო ჩემი Outline-ის სერვერის პროგრამული უზრუნველყოფა?"
---

Outline-ის სერვერები ავტომატურად განახლდება უსაფრთხოების უახლესი გაუმჯობესებებით, რათა ყოველთვის გაშვებული გქონდეთ Outline-ის უახლესი ტექნოლოგია. ავტომატიზებული განახლების პროცესი ჩართულია [Watchtower](https://github.com/containrrr/watchtower)-ის — ღია კოდის ბიბლიოთეკის — გამოყენებით, რომელიც რეგულარულად ამოწმებს და განაახლებს Outline-ის პროგრამული უზრუნველყოფის შემცველ დოკერის სურათს.

ამასთანავე, როდესაც Outline-ის დეინსტალაციას ასრულებთ Outline-ის მმართველის გამოყენებით, ჩვენ დავაყენებთ „cron job“-ს, რათა ავტომატურად განახლდეს პროგრამული უზრუნველყოფა სერვერზე [მართვადი განახლებებით](https://wiki.debian.org/UnattendedUpgrades) (Ubuntu) გადაიტვირთოს, როცა საჭიროა. გახსოვდეთ, რომ ეს არ მოხდება გაფართოებულ რეჟიმში, რათა შენარჩუნდეს არსებული კონფიგურაცია იმ დაშვებით, რომ ჰოსტი გამოიყენება Outline-ის გაშვების გარდა სხვა სერვისებისთვისაც.
