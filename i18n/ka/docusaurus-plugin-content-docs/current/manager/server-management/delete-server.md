sidebar_label: "როგორ წავშალო ჩემი Outline-ის სერვერი?"
---

ღრუბლის პროვაიდერების უმრავლესობისთვის საკმაოდ ადვილია კონკრეტული ვირტუალური მანქანის წაშლა, რომელსაც იყენებთ.

თუ DigitalOcean-ს იყენებთ ღრუბლის პროვაიდერად, შეგიძლიათ, წაშალოთ თქვენი არსებული ვირტუალური მანქანა კბილანას ღილაკზე დაწკაპუნებითა და სერვერის განადგურების არჩევით. თქვენ დაუყოვნებლივ გიკარნახებთ, შექმნათ ახალი ვირტუალური მანქანა სასურველ მდებარეობაზე.

თუ Outline-ის სერვერს ამოშლით, ის სამუდამოდ წაიშლება და მისი წვდომის გასაღებები აღარ იმუშავებს. თუ არ გსურთ, ხალხს ჰქონდეს შეფერხებები Outline-იდან წვდომისას, მოგიწევთ [Outline-ის ახალი სერვერის დაყენება](/manager/server-setup/setup-server) და მასზე წვდომის გაზიარება, ვიდრე თქვენს ძველ სერვერს წაშლიდეთ.
