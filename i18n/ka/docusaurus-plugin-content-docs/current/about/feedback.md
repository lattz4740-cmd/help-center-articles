გმადლობთ, რომ Outline-ის გაუმჯობესებაში გვეხმარებით! ჩვენთან გამოხმაურების რამდენიმე გზა არსებობს: ანონიმურად ან თქვენი ელფოსტით, თუ პასუხი გჭირდებათ:

- **დეველოპერებისთვის**: Outline ღია კოდის მქონე პროგრამული უზრუნველყოფაა და ჩვენი სრული კოდის ჰოსტინგს უზრუნველყოფს [GitHub](https://github.com/OutlineFoundation/?q=outline). შეგიძლიათ, გაგვიზიაროთ იდეები GitHub-ში ან ჩვენს [Reddit](https://www.reddit.com/r/outlinevpn/) საზოგადოებაში.
- **მომხმარებლებისთვის**: შეგიძლიათ გამოგვეხმაუროთ Outline ან Outline Manager აპებიდან. გვითხარით, რას შეეხება თქვენი გამოხმაურება და, სურვილისამებრ, დაგვიტოვეთ ელფოსტა, რომ შევძლოთ თქვენთვის პასუხის დაბრუნება ამის შესახებ. ჩვენ, ასევე, ვაგროვებთ გარკვეულ მეტამონაცემებს თქვენი გარემოს შესახებ, რომ შევძლოთ თქვენი დახმარება დეფექტების აღმოფხვრაში, მათ შორის, მონაცემებს თქვენი ბრაუზერის, ოპერაციული სისტემისა და პროგრამული უზრუნველყოფის ვერსიის შესახებ, რომელსაც იყენებთ.
- **ამ საიტიდან**: შეგიძლიათ, დააწკაპუნოთ ბმულზე „დაგვიკავშირდით“ ყველგან, სადაც კი მას დაინახავთ ამ საიტზე.
- **სერიოზული პრობლემები**: თუ გსურთ, მოგვახსენოთ უსაფრთხოების სერიოზული პრობლემის შესახებ, დაგვიკავშირდით ელფოსტით მისამართზე: security [at] [getoutline.org](https://getoutline.org/).

კიდევ ერთხელ გიხდით მადლობას გამოხმაურებისთვის.
