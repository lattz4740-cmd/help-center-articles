---
title: "Kako mogu postaviti Outline server?"
sidebar_label: "Kako mogu postaviti Outline server?"
---

Prvo morate postaviti Outline server da možete koristiti Outline. Server možete postaviti sami ili ga može postaviti neko kome vjerujete i onda se možete povezati s otvorenim internetom pomoću Outlinea.

## Prije nego što započnete
Prije nego što započnete postavljati Outline server, trebat će vam nekoliko stvari:

1. pristup vlastitim serverima ili pružaocima usluge oblaka, kao što su DigitalOcean, Amazon Web Services (AWS) ili Google Cloud Platform (GCP).

    Ako trenutno nemate pristup serveru u oblaku, možete jednostavno postaviti račun kod bilo kojeg pružaoca usluge, uključujući navedene. Za registraciju će vam vjerovatno trebati kreditna kartica
2. računar s operativnim sistemom macOS 10.9 ili noviji Windows 7.0 ili noviji ili Linux
3. aplikacija Outline Manager

## Postavite putem DigitalOceana
Olakšali smo instaliranje Outlinea na DigitalOcean tako da ga svako može postaviti u nekoliko klikova. Nakon preuzimanja i instaliranja Outline Managera na računaru možete odabrati opciju postavljanja uz DigitalOcean, koja će vas voditi kroz nekoliko jednostavnih ekrana za konfiguraciju i instaliranje Outline servera.

## Postavite putem drugog pružaoca usluge oblaka
Nakon preuzimanja i instaliranja Outline Managera možete odabrati instaliranje Outline servera na virtuelnoj mašini putem AWS-a, GCP-a, DigitalOceana ili drugog pružaoca usluge. Svako okruženje je različito, zato smo u tok postavljanja Outline Managera uključili uputstva za najčešće pružaoce usluge oblaka, uključujući postupak konfiguracije postavki na virtuelnoj mašini prije pokretanja instalacijskih skripta za instaliranje Outlinea na serveru.
