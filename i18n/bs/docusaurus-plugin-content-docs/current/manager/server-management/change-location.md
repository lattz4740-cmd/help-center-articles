---
title: "Kako promijeniti lokaciju Outline servera?"
sidebar_label: "Kako promijeniti lokaciju Outline servera?"
---

Kada se završi postavljanje servera, njegova lokacija se ne može promijeniti. Da server funkcionira s druge lokacije, morate izbrisati Outline server i kreirati novi.

Umjesto toga možete promijeniti lokaciju VPN-a pomoću [dinamičkih ključeva](https://developers.google.com/outline/docs/guides/service-providers/dynamic-access-keys) koji vam omogućavaju mijenjanje servera uz zadržavanje istih ključeva. Lokacija samih servera se neće promijeniti.
