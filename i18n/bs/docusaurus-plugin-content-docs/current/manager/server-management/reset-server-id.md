---
title: "Kako poništiti ID servera?"
sidebar_label: "Kako poništiti ID servera?"
---

ID servera je ID koji nasumično generira server kada kreirate Outline server. Možete ga pronaći prilikom uključivanja dijeljenja anonimnih pokazatelja u interfejsu Postavke. Da pronađete ID servera, idite u Postavke => kliznite na dno => označite "Dijeli anonimne pokazatelje".

ID servera međusobno povezuje anonimnu statistiku korištenja o kojoj se tokom vremena izvještava. Ako želite poništiti ID servera i pribaviti novi, morate zamijeniti postojeći Outline server novim.

Ako koristite DigitalOcean kao pružaoca usluge oblaka, možete poništiti server odlaskom u Postavke i odabirom opcije Eliminiraj server. Ova radnja je nepovratna i potpuno će izbrisati vaše akreditive. Odmah nakon ove radnje od vas će se zatražiti da kreirate novi server na lokaciji po svom odabiru i ID novog servera će se generirati.
