---
title: "Kako izbrisati Outline server?"
sidebar_label: "Kako izbrisati Outline server?"
---

Kod većine pružalaca usluge oblaka prilično je jednostavno ukloniti određenu virtuelnu mašinu koju koristite.

Ako koristite DigitalOcean kao pružaoca usluge oblaka, možete izbrisati postojeću virtuelnu mašinu klikom na dugme zupčanika i odabirom opcije Eliminiraj server. Odmah nakon toga od vas će se zatražiti da kreirate novu virtuelnu mašinu na lokaciji po svom odabiru.

Ako uklonite Outline server, on će se trajno izbrisati i njegovi pristupni ključevi više neće funkcionirati. Ako ne želite da drugi imaju prekid pristupa putem Outlinea, morate [postaviti novi Outline server](/manager/server-setup/setup-server) i podijeliti pristup njemu prije nego što izbrišete stari.
