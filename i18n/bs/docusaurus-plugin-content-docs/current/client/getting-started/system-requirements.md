Slobodno možete isprobavati Outline na bilo kojem operativnom sistemu. U nastavku slijede najniže potrebne verzije operativnih sistema:

| **Operativni sistem** | **Najniža verzija** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Želite li nam pomoći da klijent za Outline omogućimo za rad na više operativnih sistema? [Dajte svoj doprinos našoj bazi kodova](https://github.com/Jigsaw-Code/outline-client#platform-specific-development) na GitHubu!
