---
title: "Kakšne so sistemske zahteve za zagon odjemalske aplikacije za Outline?"
sidebar_label: "Kakšne so sistemske zahteve za zagon odjemalske aplikacije za Outline?"
---

Vabimo vas, da preizkusite Outline v katerem koli operacijskem sistemu. Tukaj si lahko ogledate najnižje zahtevane različice operacijskih sistemov:

| **Operacijski sistem** | **Najnižja različica** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| MacOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Želite prispevati k temu, da bo odjemalska aplikacija za Outline delovala v več operacijskih sistemih? [Prispevajte k naši zbirki kode](https://github.com/OutlineFoundation/outline-client#platform-specific-development) v storitvi GitHub.
