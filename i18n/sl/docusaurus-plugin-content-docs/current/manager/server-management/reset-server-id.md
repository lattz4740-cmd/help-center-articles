---
title: "Kako ponastavim ID strežnika?"
sidebar_label: "Kako ponastavim ID strežnika?"
---

ID strežnika je ID na strežniški strani, ki se naključno ustvari, ko ustvarite strežnik Outline. Poiščete ga lahko v vmesniku za nastavitve, ko omogočite deljenje anonimnih meritev. ID strežnika lahko poiščete v razdelku »Settings« (Nastavitve) => pomaknite se na dno => označite »share anonymous metrics« (Deli anonimne meritve).

ID strežnika povezuje anonimne statistične podatke o uporabi, javljene v nekem časovnem obdobju. Če želite ponastaviti ID strežnika in pridobiti nov ID, morate obstoječi strežnik Outline nadomestiti z novim.

Če kot ponudnika oblaka uporabljate DigitalOcean, lahko ponastavite strežnik tako, da odprete razdelek Settings (Nastavitve) in izberete Destroy Server (Uniči strežnik). Tega dejanja ni mogoče razveljaviti, pri čemer bodo izbrisane tudi vse vaše poverilnice. Takoj po tem se bo prikazal poziv, da ustvarite nov strežnik na lokaciji po svoji izbiri. Ustvaril se bo tudi nov ID strežnika.
