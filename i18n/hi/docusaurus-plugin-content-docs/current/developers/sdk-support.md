sidebar_label: "मैं एक डेवलपर हूं. मुझे अपने ऐप्लिकेशन में Outline SDK टूल को इंटिग्रेट करने के लिए सहायता कहां मिलेगी?"
---

यह सहायता वेबसाइट, Outline Manager और क्लाइंट के उपयोगकर्ताओं के लिए है. डेवलपर, मदद पाने के लिए कृपया GitHub का इस्तेमाल करें. सवाल पूछने के लिए, कृपया एसडीके टूल के [चर्चा बोर्ड](https://github.com/Jigsaw-Code/outline-sdk/discussions) पर पोस्ट करें. चर्चा बोर्ड सेक्शन एक बेहतरीन प्लैटफ़ॉर्म है. इसमें सवाल पूछने, आइडिया शेयर करने, और डेमो के लिंक देने जैसे काम किए जा सकते हैं. साथ ही, Outline SDK का इस्तेमाल करने वाले अन्य डेवलपर की मदद की जा सकती है. सुविधा का अनुरोध करने या गड़बड़ी की रिपोर्ट करने के लिए, कृपया [टिकट](https://github.com/Jigsaw-Code/outline-sdk/issues/new) ओपन करें.
