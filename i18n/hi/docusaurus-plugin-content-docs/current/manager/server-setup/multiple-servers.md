ज़्यादा Outline सर्वर सेट अप करने के लिए, Outline Manager ऐप्लिकेशन की बाईं ओर, नेविगेशन पैनल पर दिख रहे “+” आइकॉन पर क्लिक करें. नया सर्वर जोड़ने के निर्देश पहले जैसे ही हैं.

- Outline सर्वर बनाने की संख्या की कोई सीमा नहीं है.
- बनाए जाने वाले हर Outline सर्वर के लिए, आपको एक संबंधित वर्चुअल मशीन की ज़रूरत होगी.
- ज़्यादा मशीनें या ड्रॉपलेट बनाने से क्लाउड सेवा के साथ आपका शुल्क बढ़ सकता है. कृपया अपनी क्लाउड सेवा के साथ कीमतों के पैकेज को देख लें ताकि आपको कीमतों से जुड़ी पक्की जानकारी हो.

## DigitalOcean पर ज़्यादा Outline सर्वर बनाना

+ आइकॉन क्लिक करके और DigitalOcean पर इंस्टॉल करने को चुनकर, आप उन्हीं निर्देशों को पूरा करेंगे जो आपने पहला सर्वर सेट अप करते समय पूरे किए थे. साथ ही, Outline Manager, DigitalOcean के साथ मिल जाता है, इसलिए हम आपके लिए ड्रॉपलेट बना सकते हैं. इसके लिए आपको कभी भी Outline Manager ऐप्लिकेशन से बाहर नहीं निकलना पड़ता.

ध्यान रखें कि Outline Manager एक बार में सिर्फ़ एक DigitalOcean खाते के साथ काम कर सकता है. अगर आप दूसरे DigitalOcean खातों से और दूसरे Outline सर्वर बनाना या जोड़ना चाहते हैं, तो उन्हें आप बेहतर कॉन्फ़िगरेशन के तौर पर जोड़ सकते हैं.

## GCP, AWS या दूसरी क्लाउड सेवाओं पर ज़्यादा Outline सर्वर बनाना

अपनी चुनी हुई क्लाउड सेवा के साथ नई वर्चुअल मशीन बनाकर शुरू करें. इसके बाद, Outline Manager खोलें और बेहतर इंस्टॉलेशन के लिए, उसी तरह निर्देश पूरे करें जिस तरह आपने पहली बार किए होंगे.
