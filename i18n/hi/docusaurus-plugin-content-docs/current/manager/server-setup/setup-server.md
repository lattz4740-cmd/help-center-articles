Outline इस्तेमाल करने के लिए पहले Outline सर्वर सेट अप करें. Outline का इस्तेमाल करके सार्वजनिक तौर पर उपलब्ध इंटरनेट से कनेक्ट करने के लिए, आपको या आपके भरोसे के किसी व्यक्ति को आपके लिए सर्वर सेट अप करना होगा.

## शुरू करने से पहले
Outline सर्वर सेट अप करने से पहले, आपको कुछ चीज़ों की ज़रूरत होगी:

1. अपने सर्वर या क्लाउड सेवा देने वाली कंपनी का ऐक्सेस. जैसे: DigitalOcean, Amazon Web Services (AWS) या Google Cloud Platform (GCP).

    अगर आपके पास तुरंत क्लाउड सर्वर का ऐक्सेस नहीं है, तो किसी भी सेवा देने वाली कंपनी के साथ आसानी से खाता सेट अप किया जा सकता है. इनमें सेवा देने वाली वे कंपनियां शामिल हैं जो ऊपर दी गई हैं. आपको साइन अप करने के लिए, क्रेडिट कार्ड की ज़रूरत हो सकती है.
2. एक डेस्कटॉप कंप्यूटर जिस पर macOS 10.9+, Windows 7.0+ या Linux चल रहा हो.
3. Outline Manager ऐप्लिकेशन.

## DigitalOcean के साथ सेट अप करना
हमने Outline को कुछ ही क्लिक में DigitalOcean पर इंस्टॉल करना सबके लिए आसान बना दिया है. आपके कंप्यूटर पर Outline Manager डाउनलोड और इंस्टॉल करने के बाद, DigitalOcean सेटअप का विकल्प चुना जा सकता है. इससे Outline सर्वर कॉन्फ़िगर और इंस्टॉल करने की प्रक्रिया कुछ आसान चरणों में समझी जा सकती है.

## किसी दूसरे क्लाउड प्रोवाइडर के साथ सेट अप करना
Outline Manager डाउनलोड और इंस्टॉल करने के बाद, AWS, GCP, DigitalOcean या किसी अन्य प्रोवाइडर की वर्चुअल मशीन पर Outline सर्वर इंस्टॉल किया जा सकता है. हर प्लैटफ़ॉर्म अलग होता है, इसलिए हमने Outline Manager सेटअप फ़्लो में सबसे सामान्य क्लाउड सेवाओं के लिए निर्देश शामिल किए हैं. इसमें यह भी बताया गया है कि किसी सर्वर पर Outline इंस्टॉल करने के लिए इंस्टॉलेशन स्क्रिप्ट चलाने से पहले अपनी वर्चुअल मशीन पर सेटिंग कैसे कॉन्फ़िगर करनी हैं.
