sidebar_label: "मुझे Windows पर Outline Manager को इंस्टॉल करने में समस्या क्यों आ रही है?"
---

आपको गड़बड़ी का यह मैसेज दिख सकता है: “माफ़ करें, ऐसा लगता है कि Outline को ठीक से इंस्टॉल नहीं किया गया है. कृपया उसे फिर से इंस्टॉल करें. अगर इससे समस्या हल न हो, तो कृपया [शिकायत सबमिट करें](https://support.getoutline.org/s/contactsupport?).”

Windows पर Outline का इस्तेमाल करने पर आपको कभी-कभी किसी गड़बड़ी का सामना करना पड़ सकता है. ज़्यादातर मामलों में, Outline TAP अडैप्टर (ड्राइवर) को मिटाने और Outline को फिर से इंस्टॉल करने से गड़बड़ी ठीक हो जाती है.

TAP अडैप्टर और Outline Manager को अनइंस्टॉल करने और Outline Manager को फिर से इंस्टॉल करने के सामान्य चरण नीचे बताए गए हैं. आपके Windows ऑपरेटिंग सिस्टम के वर्शन के हिसाब से ये चरण अलग-अलग हो सकते हैं.

1. Outline Manager के लिए TAP अडैप्टर को अनइंस्टॉल करें
   1. सबसे पहले Device Managers में जाएं और फिर Network Adapters में जाएं
   2. अब “TAP-Windows Adapter V9 फ़ाइल या Outline से जुड़ा TAP अडैप्टर ढूंढें
   3. इस अडैप्टर को अनइंस्टॉल करें या मिटाएं. ध्यान रखें कि इससे उन दूसरे वीपीएन ऐप्लिकेशन पर असर पड़ सकता है जिन्हें आपने इंस्टॉल किया है.
2. Outline Manager को अनइंस्टॉल करें
   1. सबसे पहले Programs & Features और फिर Uninstall Program में जाएं
   2. Outline Manager ऐप्लिकेशन को ढूंढें और फिर उसे अनइंस्टॉल करें
   3. [Outline Manager का सबसे नया वर्शन डाउनलोड करें](https://getoutline.org/get-started/#step-1) और उसे अपने Windows डिवाइस पर फिर से इंस्टॉल करें. इंस्टॉल किए गए ऐप्लिकेशन से नया TAP अडैप्टर अपने-आप इंस्टॉल हो जाना चाहिए.

अगर आपको अब भी समस्या आ रही है, तो [सहायता टीम से संपर्क करें](https://support.getoutline.org/s/contactsupport?).
