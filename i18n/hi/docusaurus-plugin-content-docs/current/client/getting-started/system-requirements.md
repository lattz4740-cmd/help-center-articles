Outline को किसी भी ऑपरेटिंग सिस्टम पर इस्तेमाल किया जा सकता है. नीचे दिए गए ऑपरेटिंग सिस्टम के कम से कम ये वर्शन होने ज़रूरी हैं:

| **ऑपरेटिंग सिस्टम** | **कम से कम वर्शन** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Outline Client अन्य ऑपरेटिंग सिस्टम पर भी काम करे, क्या इसमें आपको हमारी मदद करनी है? GitHub पर [हमारे कोड बेस में योगदान दें](https://github.com/OutlineFoundation/outline-client#platform-specific-development)!
