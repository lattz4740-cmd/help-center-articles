---
title: "Jag är utvecklare. Var kan jag få support för att integrera Outline SDK i min app?"
sidebar_label: "Jag är utvecklare. Var kan jag få support för att integrera Outline SDK i min app?"
---

Den här supportwebbplatsen är avsedd för användare av Outline Manager och Client. Om du är utvecklare kan du använda GitHub för support. Om du vill ställa en fråga kan du göra det i [diskussionsforumet](https://github.com/Jigsaw-Code/outline-sdk/discussions) för SDK. I diskussionsforumet kan du ställa frågor, dela idéer, länka till demoversioner och hjälpa andra utvecklare som använder Outline SDK. Om du vill begära en ny funktion eller få felrapporter kan du skapa ett [ärende](https://github.com/Jigsaw-Code/outline-sdk/issues/new) i stället.
