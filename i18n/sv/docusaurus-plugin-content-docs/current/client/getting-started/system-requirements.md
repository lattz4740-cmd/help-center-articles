---
title: "Vilka är systemkraven för att köra Outline-klienten?"
sidebar_label: "Vilka är systemkraven för att köra Outline-klienten?"
---

Du kan testa Outline i alla operativsystem. Minimikraven för operativsystem är följande:

| **Operativsystem** | **Minimiversion** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Vill du hjälpa till att få Outline Client att fungera i fler operativsystem? [Bidra till vår kodbas](https://github.com/Outline-Foundation/outline-client#platform-specific-development) på GitHub!
