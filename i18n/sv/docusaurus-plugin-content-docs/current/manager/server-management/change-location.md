---
title: "Hur ändrar jag Outline-serverns plats?"
sidebar_label: "Hur ändrar jag Outline-serverns plats?"
---

När servern har konfigurerats går det inte att ändra dess plats. Om du vill köra din server från en annan plats måste du radera din Outline-server och skapa en ny.

Du kan även ändra platsen för VPN med [dynamiska nycklar](https://developer.getoutline.org/vpn/management/dynamic-access-keys/), som gör att du kan växla mellan servrar och behålla samma nycklar. Själva servrarna ändrar inte plats.
