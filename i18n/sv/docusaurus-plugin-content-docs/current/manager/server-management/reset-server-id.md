---
title: "Hur återställer jag mitt server-id?"
sidebar_label: "Hur återställer jag mitt server-id?"
---

Server-id:t är ett id som genereras slumpmässigt på serversidan när du skapar en Outline-server. Du hittar det när du väljer att dela anonyma mätvärden i gränssnittet för inställningarna. Du hittar server-id:t under: Inställningar => scrolla längst ned på sidan => markera Dela anonyma mätvärden.

Server-id:t sammanställer anonym användningsstatistik som rapporterats under en viss tid. Om du vill återställa server-id:t och få ett nytt måste du byta ut den befintliga Outline-servern mot en ny.

Om du använder DigitalOcean som molnleverantör kan du återställa servern genom att gå till Inställningar och välja Förstör server. Den här åtgärden kan inte ångras och alla användaruppgifter raderas. Direkt efter åtgärden blir du ombedd att skapa en ny server på valfri plats, och ett nytt server-id genereras.
