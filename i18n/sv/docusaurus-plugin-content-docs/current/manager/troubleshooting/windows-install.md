---
title: "Varför går det inte att installera Outline Manager på Windows?"
sidebar_label: "Varför går det inte att installera Outline Manager på Windows?"
---

Du kan se felmeddelandet ”Det verkar som att Outline inte har installerats korrekt. Testa att installera det igen. Om det inte fungerar kan du [skicka feedback](/about/feedback).”

Om du använder Outline på Windows kan det hända att du stöter på ett oväntat fel. I de flesta fall måste Outline TAP-adaptern (drivrutinen) raderas och Outline ominstalleras.

Hur du gör detta varierar beroende på vilken version av Windows operativsystem du använder, men nedan ser du allmänna anvisningar för hur du avinstallerar TAP-adaptern och Outline Manager och sedan ominstallerar Outline Manager.

1. Avinstallera TAP-adaptern för Outline Manager.
   1. Gå till Enhetshanterare och sedan Nätverkskort.
   2. Leta reda på filen TAP-Windows Adapter V9 eller den TAP-adapter som är kopplad till Outline.
   3. Avinstallera eller radera den här adaptern. Tänk på att det här kan påverka andra VPN-appar som du har installerat.
2. Avinstallera Outline Manager
   1. Gå till Program och funktioner och sedan till Avinstallera program.
   2. Leta reda på Outline Manager-appen och avinstallera Outline Manager.
   3. [Ladda ned den senaste versionen av Outline Manager](https://getoutline.org/get-started/#step-1) och ominstallera den på Windows-enheten. Den nya installationen ska installera en ny TAP-adapter automatiskt.

Om du fortfarande har problem kan du [kontakta support](/about/feedback).
