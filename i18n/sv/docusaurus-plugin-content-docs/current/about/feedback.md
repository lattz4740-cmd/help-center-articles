---
title: Så här skickar du feedback eller förslag
sidebar_label: Så här skickar du feedback eller förslag
---

Tack för att du hjälper oss att göra Outline bättre. Du kan skicka feedback till oss på några olika sätt, antingen anonymt eller via e-post om du vill ha ett svar:

- **För utvecklare**: Outline är en mjukvara med öppen källkod och all kod finns på [GitHub](https://github.com/Outline-Foundation/?q=outline). Du kan dela med dig av dina idéer på GitHub eller i vår [Reddit](https://www.reddit.com/r/outlinevpn/)-grupp.
- **För användare**: Du kan skicka feedback via Outline- eller Outline Manager-appen. Ange vad feedbacken handlar om och ange en e-postadress (om du vill) så att vi kan höra av oss till dig. Vi samlar även in viss metadata om miljön så att vi kan hjälpa dig med felsökningar, t.ex. om webbläsaren, operativsystemet och programvaruversionen som du använder.
- **Via den här webbplatsen**: Du kan klicka på länken Kontakta oss på den här webbplatsen.
- **Allvarliga problem**: Om du vill rapportera ett allvarligt säkerhetsproblem uppskattar vi om du skickar ett e-postmeddelande med informationen till security [snabel-a] [getoutline.org](https://getoutline.org/).

Tack för att du tar dig tid att säga vad du tycker.
