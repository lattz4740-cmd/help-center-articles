---
title: "Apakah saya diizinkan untuk menggunakan atau mereplikasi merek Outline?"
sidebar_label: "Apakah saya diizinkan untuk menggunakan atau mereplikasi merek Outline?"
---

Meskipun Outline adalah software open source gratis, merek kami adalah merek eksklusif Jigsaw dan tidak boleh disalahgunakan. Harap ikuti [panduan pengguna](https://github.com/OutlineFoundation/outline-brand/blob/main/outline_brand_user_guide.pdf) untuk memastikan Anda tidak mengajukan klaim yang berpotensi menyesatkan atau salah mengartikan hubungan Anda dengan Outline atau Jigsaw, dan menggunakan unsur merek yang disetujui dengan benar.
