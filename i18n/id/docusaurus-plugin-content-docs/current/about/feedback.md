---
title: Cara mengirim masukan atau saran
sidebar_label: Cara mengirim masukan atau saran
---

Terima kasih telah membantu meningkatkan kualitas Outline. Ada beberapa cara untuk mengirimkan masukan kepada kami, baik secara anonim maupun melalui email jika Anda memerlukan respons:

- **Untuk developer**: Outline adalah software open source. Kunjungi [GitHub](https://github.com/OutlineFoundation/?q=outline) untuk melihat semua kode yang kami hosting. Anda dapat membagikan ide Anda di GitHub atau di komunitas [Reddit](https://www.reddit.com/r/outlinevpn/) kami.
- **Untuk pengguna**: Anda dapat mengirimkan masukan kepada kami melalui aplikasi Outline atau Outline Manager. Beri tahu kami masukan Anda dan, jika perlu, tinggalkan email agar kami dapat membalasnya. Kami juga mengumpulkan beberapa metadata tentang lingkungan Anda, sehingga kami dapat membantu mengatasi masalah seperti browser, sistem operasi, dan versi software yang Anda gunakan.
- **Melalui situs ini**: Anda dapat mengklik link hubungi kami yang ada di situs ini.
- **Masalah serius**: Jika Anda ingin melaporkan masalah keamanan serius, Anda dapat mengirimkan email kepada kami dengan menyertakan detail masalah ke security [at] [getoutline.org](https://getoutline.org/).

Terima kasih Anda telah meluangkan waktu untuk menyampaikan masukan Anda kepada kami.
