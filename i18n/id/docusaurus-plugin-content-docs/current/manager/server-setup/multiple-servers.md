---
title: Cara menyiapkan beberapa server Outline
sidebar_label: Cara menyiapkan beberapa server Outline
---

Untuk menyiapkan server Outline tambahan, klik ikon "+" pada panel navigasi di sebelah kiri aplikasi Outline Manager. Petunjuk untuk menambahkan server baru sama seperti petunjuk untuk menginstal server.

- Kami tidak membatasi jumlah server Outline yang dapat Anda buat.
- Anda memerlukan mesin virtual yang sesuai untuk setiap server Outline yang dibuat.
- Membuat mesin atau droplet tambahan dapat menambah biaya langganan Anda kepada penyedia cloud. Harap tanyakan paket harga kepada penyedia cloud untuk memastikannya sesuai dengan anggaran Anda.

## Membuat server Outline tambahan di DigitalOcean

Setelah mengklik ikon + dan memilih untuk menginstal di DigitalOcean, Anda harus mengikuti petunjuk yang sama seperti saat menyiapkan server pertama. Selain itu, karena Outline Manager terintegrasi dengan DigitalOcean, kami dapat membuat droplet untuk Anda tanpa harus meninggalkan aplikasi Outline Manager.

Perlu diperhatikan bahwa Outline Manager hanya dapat mendukung satu akun DigitalOcean pada satu waktu. Jika ingin menambah atau membuat server Outline lainnya dari akun DigitalOcean yang berbeda, Anda dapat menambahkannya sebagai konfigurasi lanjutan.

## Membuat server Outline tambahan di GCP, AWS, atau penyedia layanan cloud lainnya

Mulailah dengan membuat mesin virtual baru dengan penyedia cloud yang Anda pilih. Kemudian, buka Outline Manager dan selesaikan petunjuk penginstalan lanjutan, sama seperti yang Anda lakukan pertama kali.
