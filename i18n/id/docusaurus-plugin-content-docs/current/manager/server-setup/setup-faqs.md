## Dapatkah saya menggunakan Outline tanpa server?
 Sayangnya, tidak. Software Outline memerlukan akses ke server, baik yang dikelola oleh Anda, organisasi Anda, atau pihak ketiga yang tepercaya.

## Berapa lama waktu yang dibutuhkan untuk menyiapkan server Outline?

Biasanya, hanya memerlukan waktu kurang dari 5 menit. Anda dapat menginstal Outline di server cloud mana pun, tetapi kami bekerja sama dengan DigitalOcean untuk menawarkan pengalaman penginstalan yang lebih mudah digunakan dan terpandu sehingga Anda dapat menyiapkan server hanya dengan beberapa klik—tanpa skrip.

Jika Anda memilih AWS, GCP, atau penyiapan lanjutan, kami telah menyederhanakan proses penginstalan server menjadi satu skrip yang diterapkan di sebagian besar lingkungan.

## Di mana saya dapat menyiapkan server Outline?

Anda dapat menyiapkan server Outline di sebagian besar penyedia cloud di mana pun mereka beroperasi.

Opsi termudah adalah menyiapkannya di DigitalOcean karena memiliki server di beberapa lokasi, seperti Amsterdam, Toronto, San Francisco, dan Singapura. Jika ingin menginstalnya di penyedia cloud lain atau di infrastruktur milik sendiri, Anda dapat memilih ‘Mode Lanjutan’ di aplikasi Outline Manager dan ikuti petunjuk penginstalan menggunakan skrip penyiapan.

## Di mana saya harus menyiapkan server Outline saya?

1. Ada beberapa pertimbangan yang harus Anda buat saat memilih lokasi server Outline:
2. Lokasi server Outline memengaruhi pengalaman pengguna menggunakan Internet. Misalnya, jika server berlokasi di Amsterdam, pengguna yang mengakses server ini akan merasakan mengakses internet seolah-olah sedang berada di Belanda. Beberapa situs mungkin ditampilkan dalam bahasa Belanda. Biasanya, Anda dapat mengubah bahasa lokal menggunakan pemilih bahasa yang tersedia di situs tersebut.
3. Jarak antara pengguna dan server Outline dapat memengaruhi kecepatan. Umumnya jarak fisik antara pengguna Outline dan server dapat memengaruhi kecepatan internet pengguna. Biasanya, Anda dapat memilih lokasi server yang paling dekat dengan lokasi calon pengguna, tetapi Anda dapat memeriksa [Peta Kabel Bawah Laut](https://www.submarinecablemap.com/) untuk mengetahui kabel internet mana yang terhubung dengan negara atau wilayah Anda.
4. Lokasi server VPN Anda dapat memengaruhi kerangka hukum. Perlu diperhatikan bahwa software Outline tidak menyimpan log traffic Anda. Pelajari lebih lanjut [Keamanan dan privasi saat menggunakan Outline](/about/security-and-privacy).
