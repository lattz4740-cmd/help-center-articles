---
title: "Bagaimana cara menyiapkan server Outline?"
sidebar_label: "Bagaimana cara menyiapkan server Outline?"
---

Menyiapkan server Outline adalah langkah pertama untuk dapat menggunakan Outline. Anda atau seseorang yang Anda percayai harus menyiapkan server untuk Anda agar Anda dapat terhubung ke internet terbuka melalui Outline.

## Sebelum memulai
 Sebelum mulai menyiapkan server Outline, Anda memerlukan beberapa hal:

1. Akses ke server Anda sendiri atau penyedia layanan Cloud, seperti DigitalOcean, Amazon Web Services (AWS), atau Google Cloud Platform (GCP).

 Jika belum memiliki akses langsung ke server cloud, Anda dapat dengan mudah menyiapkan akun dengan penyedia mana pun, termasuk yang tercantum di atas. Anda mungkin memerlukan kartu kredit untuk mendaftar.
2. Komputer desktop yang menjalankan macOS 10.9+, Windows 7.0+, atau Linux.
3. Aplikasi Outline Manager.

## Menyiapkan dengan DigitalOcean
 Kami memudahkan siapa saja untuk menginstal Outline di DigitalOcean hanya dengan beberapa klik. Setelah mendownload dan menginstal Outline Manager di komputer, Anda dapat memilih opsi penyiapan DigitalOcean yang akan memandu Anda melalui beberapa cara sederhana di layar untuk mengonfigurasi dan menginstal server Outline.

## Menyiapkan dengan penyedia cloud lain
 Setelah mendownload dan menginstal Outline Manager, Anda dapat memilih untuk menginstal server Outline di virtual machine dengan AWS, GCP, DigitalOcean, atau penyedia cloud lain. Setiap lingkungan memiliki perbedaan, sehingga kami menyertakan petunjuk di dalam alur penyiapan Outline Manager untuk penyedia cloud yang paling umum, termasuk cara mengonfigurasi setelan di mesin virtual sebelum Anda menjalankan skrip penginstalan untuk menginstal Outline di server.
