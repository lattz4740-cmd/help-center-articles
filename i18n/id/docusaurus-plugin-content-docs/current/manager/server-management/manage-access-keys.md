---
title: Mengelola akses ke server Outline (menggunakan kunci akses)
sidebar_label: Mengelola akses ke server Outline (menggunakan kunci akses)
---

Setelah server Outline selesai diinstal, sekarang Anda dapat mulai membagikan dan mengelola akses orang ke Outline. Orang yang menerima undangan dari Anda akan dapat mendownload aplikasi Outline dan menggunakan Outline untuk melindungi traffic internet mereka.

**Membagikan akses ke server Outline**

 Setelah server Outline selesai diinstal, Anda akan diarahkan ke halaman detail server di Outline Manager, tempat Anda dapat membuat kunci akses. Pelajari lebih lanjut [kunci akses](/about/terminology).

- Membuat kunci: Klik ikon "+" kecil di bagian bawah halaman untuk membuat kunci baru.
- Membagikan kunci: Di sebelah kanan setiap kunci, ada ikon berbagi yang dapat Anda klik untuk mendapatkan undangan. Salin dan tempel undangan ini ke sistem pesan pilihan Anda.

**Permintaan fitur: Berbagi akses dari dalam aplikasi Outline Manager**

 Banyak administrator server meminta kami untuk merampingkan proses permintaan undangan dengan memberikan opsi untuk memasukkan alamat email seseorang secara langsung ke Outline Manager.

Sayangnya, kami kemungkinan tidak dapat menambahkan fungsi ini pada Outline Manager. Salah satu prinsip inti kami adalah untuk mendukung privasi dan keamanan pengguna kami dengan tidak mendesain tempat untuk memasukkan alamat email atau informasi kontak.

Inilah alasan kami meminta administrator server untuk menggunakan platform pengiriman pesan yang aman, seperti email atau chat aman, untuk mengirimkan undangan kepada pengguna akhir.

**Langkah yang dilakukan pengguna setelah menerima kunci akses dari Anda**

1. Pengguna harus mengklik link penginstalan dari perangkatnya
2. Kemudian menginstal aplikasi Outline jika belum memilikinya
3. Pengguna harus membuat koneksi awal ke server Outline Anda melalui kunci unik yang disematkan dalam undangan
4. Sekarang tombol sambungkan/putuskan sambungan telah dapat digunakan untuk mengelola akses ke internet melalui server Outline

**Menghapus akses ke server Outline Anda**

 Dari halaman detail server di Outline Manager, di sebelah kanan setiap kunci di server, Anda akan melihat menu dengan opsi untuk menghapus kunci. Menghapus kunci akan menghapus akses mereka ke server Anda.
