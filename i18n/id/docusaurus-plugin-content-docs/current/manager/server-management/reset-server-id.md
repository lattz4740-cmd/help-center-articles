---
title: "Bagaimana cara mereset ID server?"
sidebar_label: "Bagaimana cara mereset ID server?"
---

ID server adalah ID sisi server yang dibuat secara acak saat membuat server Outline. ID ini dapat ditemukan di antarmuka Setelan saat Anda memilih ikut serta membagikan metrik anonim. Anda dapat menemukan ID server dari: Setelan => scroll ke bawah => centang "bagikan metrik anonim".

ID server mengumpulkan statistik penggunaan anonim yang dilaporkan dari waktu ke waktu. Jika ingin mereset ID server dan memperoleh ID baru, Anda harus mengganti server Outline yang ada dengan yang baru.

Jika menggunakan DigitalOcean sebagai penyedia cloud, Anda dapat mereset server dengan membuka Settings dan memilih Destroy Server. Tindakan ini tidak dapat diurungkan dan akan menghapus kredensial Anda. Setelah itu, Anda akan diminta untuk membuat server baru di lokasi yang Anda inginkan, lalu ID server baru akan dibuat.
