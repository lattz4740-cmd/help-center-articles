---
title: "Bagaimana cara mengubah lokasi server Outline?"
sidebar_label: "Bagaimana cara mengubah lokasi server Outline?"
---

Setelah disiapkan, lokasi server tidak dapat diubah. Untuk menjalankan server dari lokasi yang berbeda, Anda harus menghapus server Outline Anda yang sudah ada dan membuat server baru.

Atau, Anda dapat mengubah lokasi VPN menggunakan [kunci dinamis](https://developer.getoutline.org/vpn/management/dynamic-access-keys/), yang memungkinkan Anda merotasi server dan tetap menggunakan kunci yang sama. Lokasi server itu sendiri tidak berubah.
