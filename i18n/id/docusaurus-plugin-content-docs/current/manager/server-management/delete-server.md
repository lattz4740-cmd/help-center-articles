---
title: "Bagaimana cara menghapus server Outline?"
sidebar_label: "Bagaimana cara menghapus server Outline?"
---

Bagi sebagian besar penyedia cloud, menghapus virtual machine tertentu yang Anda gunakan dapat dilakukan dengan cukup mudah.

Jika menggunakan DigitalOcean sebagai penyedia cloud, Anda dapat menghapus virtual machine yang ada dengan mengklik tombol roda gigi dan memilih Destroy Server. Setelah itu, Anda akan diminta untuk membuat virtual machine baru di lokasi yang Anda inginkan.

Penghapusan server Outline bersifat permanen dan kunci aksesnya tidak lagi akan berfungsi. Jika Anda tidak ingin pengguna mengalami gangguan saat mengakses Outline, Anda harus [menyiapkan server Outline baru](/manager/server-setup/setup-server) dan membagikan akses ke server baru tersebut sebelum menghapus server lama.
