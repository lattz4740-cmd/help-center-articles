---
title: "Bagaimana jika kunci akses saya tidak berfungsi?"
sidebar_label: "Bagaimana jika kunci akses saya tidak berfungsi?"
---

Jika Anda menerima pesan error: “Sepertinya kunci akses Anda tidak valid. Hubungi pengelola layanan jika hal ini terjadi lagi.” Ikuti langkah-langkah di bawah ini untuk memecahkan masalah tersebut:

1. Pastikan Anda memasukkan kunci akses lengkap, termasuk lima karakter pertama, “ss://”, yang mungkin tidak otomatis tersalin ke papan klip. Berikut ini contoh tampilan kunci akses lengkap (hanya contoh; tidak dapat digunakan):

```
ss://Y2hhY2hhMjAtaWV0Zi1wb2x5MTMwNTp1eXhUQ3MzemVEMTk=@145.230.4.1:39485/?outline=1
```

1. Jika kunci akses tidak dapat disalin sama sekali ke papan klip, error tersebut mungkin disebabkan oleh platform atau aplikasi pesan Anda. Hal ini kemungkinan besar terjadi saat Anda menerima pesan dari orang yang tidak ada di daftar kontak Anda. Jika Anda menyalin kode dari suatu pesan, pastikan pengirimnya ditambahkan ke kontak Anda, lalu coba akses lagi link tersebut.
2. Jika sudah menyelesaikan langkah 1 dan 2, tetapi masih menerima pesan error, kemungkinan besar server telah diblokir atau kunci akses tidak lagi valid. Jika Anda adalah pengelola server, coba buat kunci baru secara mandiri. Atau, hubungi pengelola layanan untuk meminta kunci baru.
