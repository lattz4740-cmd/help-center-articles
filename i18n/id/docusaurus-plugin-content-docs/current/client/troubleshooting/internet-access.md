---
title: "Mengapa saya tidak dapat mengakses internet meskipun saya terhubung ke server Outline?"
sidebar_label: "Mengapa saya tidak dapat mengakses internet meskipun saya terhubung ke server Outline?"
---

Jika Anda menggunakan ponsel, coba beralih antara koneksi data seluler dan Wi-Fi. Terkadang salah satu jenis koneksi tersebut berfungsi ketika yang lain tidak berfungsi. Jika Anda menggunakan komputer, coba putuskan koneksi dari internet broadband dan hubungkan kembali.

Jika masalah ini belum teratasi, kemungkinan ada masalah pada server Outline Anda. Hubungi [pengelola layanan](/about/terminology) Anda guna mendapatkan kunci akses baru untuk server alternatif. Dia juga bisa meningkatkan batas data https://google-jigsaw--jigsawuat.sandbox.my.site.com/outline/s/article/Terminology[kunci akses](/about/terminology) Anda jika kunci tersebut telah melampaui batasannya.
