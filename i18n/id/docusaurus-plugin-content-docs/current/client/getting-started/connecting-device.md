---
title: Menghubungkan perangkat Anda ke server Outline
sidebar_label: Menghubungkan perangkat Anda ke server Outline
---

Agar dapat menghubungkan perangkat Anda ke server Outline, administrator server harus mengirimi Anda undangan untuk terhubung ke servernya dengan [kunci akses](/about/terminology) unik. Undangan ini akan:

- Meminta Anda mendownload dan menginstal Outline di perangkat Anda, jika Anda belum memilikinya
- Menggunakan kunci akses untuk membuat koneksi aman antara Anda dan server Outline

Setelah membuat koneksi ke server, Anda dapat mulai menggunakan Outline dengan mengklik "hubungkan" atau "berhenti hubungkan".

*Penting:* Outline tidak dapat berfungsi tanpa kunci akses dan server Outline. Mendownload dan menginstal aplikasi Outline tanpa kunci tidak akan melindungi traffic internet Anda.
