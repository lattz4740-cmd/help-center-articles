---
title: "Dapatkah saya menggunakan kunci akses lebih dari satu kali?"
sidebar_label: "Dapatkah saya menggunakan kunci akses lebih dari satu kali?"
---

Ya. Anda dapat menggunakan [kunci akses](/about/terminology) di beberapa perangkat, tetapi sebaiknya jangan bagikan kunci Anda kepada orang lain. Seseorang yang memiliki kunci akses Anda berpotensi memeriksa semua traffic internet Anda jika dia memiliki akses ke kunci tersebut, sehingga penggunaan internet tidak lagi akan aman atau rahasia.
