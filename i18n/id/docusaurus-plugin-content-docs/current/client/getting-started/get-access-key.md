---
title: "Bagaimana cara mendapatkan kunci akses?"
sidebar_label: "Bagaimana cara mendapatkan kunci akses?"
---

Outline tidak seperti layanan VPN yang Anda beli aksesnya. Outline adalah [suatu alat](https://getoutline.org/#:~:text=Two%20Products%20that%20Work%20Together) yang memungkinkan Anda menjalankan dan membagikan akses ke server VPN pribadi. [Pengelola layanan](/about/terminology#servicemanager) adalah satu-satunya orang yang dapat menyediakan kunci akses. Tim Outline tidak mendistribusikan kunci akses gratis atau berbayar. Kami tidak memiliki partner kunci akses Outline resmi, kecuali untuk Paskoocheh dalam bahasa Persia.

 Berikut adalah tiga opsi untuk mendapatkan kunci akses:

- Minta seseorang untuk mengundang Anda ke servernya: Jika Anda kenal seseorang yang memiliki server Outline, hubungi dan minta dia untuk mendapatkan kunci akses.
- [Buat server Anda sendiri:](/manager/server-setup/setup-server) Dengan komputer Windows, Mac, atau Linux, download [Outline Manager](https://getoutline.org/get-started/#step-1) dan siapkan [server Outline](/about/terminology) Anda sendiri. Kami membuat proses ini mudah bagi siapa saja, terutama melalui penyedia layanan cloud DigitalOcean.
- Gunakan layanan Outline atau [Shadowsocks](https://en.wikipedia.org/wiki/Shadowsocks#:~:text=Shadowsocks%20is%20a%20free%20and,have%20been%20made%20available%20since.): Aplikasi Outline juga dapat digunakan dengan layanan pihak ketiga yang menggunakan protokol Outline atau Shadowsocks. Contoh:
   - [nthLink](http://nthlink.com/) menjalankan layanan gratis berdasarkan Outline, dengan versi aplikasi Outline yang diubah.
   - [ASL19](https://www.reddit.com/r/outlinevpn/comments/nwu1se/the_outline_distribution_system_is_here_to_help/) menjalankan versi Outline yang diubah bernama [BeePass](https://beepassvpn.com/) serta [bot Telegram](https://t.me/paskoochehbot) yang menyediakan kunci akses gratis ke server BeePass.
   - Pengguna bahasa Persia juga dapat meminta kunci akses Outline dari [Paskoocheh ASL19](https://outline.paskoocheh.com/).

Setelah mendownload aplikasi Outline, salin dan tempel [kunci akses](/about/terminology#accesskey) Anda ke dalam aplikasi Outline untuk terhubung ke server Outline.
