title: "Apa saja persyaratan sistem untuk menjalankan aplikasi Outline?"
sidebar_label: "Apa saja persyaratan sistem untuk menjalankan aplikasi Outline?"
---

Anda dapat mencoba Outline di sistem operasi apa pun. Berikut ini adalah sistem operasi minimum yang diperlukan:

| **Sistem operasi** | **Versi minimum** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 10.15 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Ingin membantu Aplikasi Outline agar berfungsi di lebih banyak sistem operasi? [Berkontribusilah pada code base kami](https://github.com/Jigsaw-Code/outline-client#platform-specific-development) di GitHub.
