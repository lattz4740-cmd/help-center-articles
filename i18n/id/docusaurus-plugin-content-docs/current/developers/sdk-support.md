sidebar_label: "Saya seorang developer. Di mana saya dapat menemukan dukungan untuk mengintegrasikan Outline SDK ke dalam aplikasi?"
---

Situs dukungan ini ditujukan bagi pengguna Outline Manager dan Klien. Developer, gunakan GitHub untuk mendapatkan dukungan. Untuk mengajukan pertanyaan, silakan buat postingan di [Papan diskusi](https://github.com/Jigsaw-Code/outline-sdk/discussions) SDK. Bagian Papan diskusi merupakan tempat yang tepat untuk mengajukan pertanyaan, berbagi ide, menautkan ke demo, dan mendukung developer lain yang menggunakan Outline SDK. Untuk permintaan fitur atau laporan bug, buka [Masalah](https://github.com/Jigsaw-Code/outline-sdk/issues/new).
