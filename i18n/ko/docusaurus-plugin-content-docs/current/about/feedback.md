title: 의견 또는 제안을 보내는 방법
sidebar_label: 의견 또는 제안을 보내는 방법
---

Outline을 개선하는 데 도움을 주셔서 감사합니다. 익명으로 의견을 보내거나 응답이 필요한 경우 이메일을 통해 의견을 보내는 등의 몇 가지 방법이 있습니다.

- **개발자**: Outline은 오픈소스 소프트웨어이며 [GitHub](https://github.com/Outline-Foundation/?q=outline)에 모든 코드를 호스팅하고 있습니다. GitHub 또는 [Reddit](https://www.reddit.com/r/outlinevpn/) 커뮤니티에서 아이디어를 공유해 주세요.

- **사용자**: Outline 또는 Outline Manager 앱을 통해 의견을 보낼 수 있습니다. 어떤 부분에 관한 의견인지 알려주세요. 이메일을 남겨주시면 이메일로 회신을 드릴 수 있습니다. 또한 문제해결에 도움을 드릴 수 있도록 브라우저, 운영체제, 사용 중인 소프트웨어 버전 등 사용자의 환경과 관련된 일부 메타데이터를 수집합니다.

- **현재 사이트**: 이 사이트 내 어디에서든 찾을 수 있는 문의하기 링크를 클릭하세요.

- **심각한 문제**: 심각한 보안 문제를 신고하려는 경우 자세한 내용을 [security@getoutline.org](mailto:security@getoutline.org)에 이메일로 보내주세요.

귀중한 시간을 내어 의견을 공유해 주셔서 다시 한번 감사드립니다.
