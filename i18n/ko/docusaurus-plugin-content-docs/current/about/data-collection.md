---
title: 데이터 및 정보 수집
sidebar_label: 데이터 및 정보 수집
---

Outline에서는 사용자가 개인 정보를 제공하겠다고 선택하지 않는 한 개인 정보를 수집하지 않습니다. 또한 사용자가 방문하는 웹사이트, 통신하는 대상 또는 내용에 관한 정보도 수집하지 않습니다.

 Outline Manager에서 서드 파티 클라우드 제공업체를 통해 계정을 만들거나 계정에 로그인하는 경우, Outline에서는 이메일 주소, 이름, 청구 정보, 결제 세부정보 등 사용자가 서드 파티 클라우드 제공업체에 제공하는 정보를 수집하지 않습니다.

****Outline에서 자동으로 수집하는 정보****

 Outline에서는 두 가지 정보가 자동으로 수집됩니다.

 1. 서버 IP

 Outline 서버 IP는 [Quay.io](https://quay.io/)에 의해 수집되며, 최신 보안 및 기능 개선사항 등의 서버 자동 업데이트가 이뤄질 때 Outline에 액세스 권한이 부여됩니다. 서버 IP에서 클라우드 서버 제공업체와 Outline 서버가 설정된 도시의 식별이 가능할 수 있지만, 누가 서버를 실행 또는 액세스하는지에 대한 정보는 제공하지 않습니다.

 2. 개인 식별이 불가능한 기술 정보

 Outline이 비정상 종료되거나, 치명적인 예외가 발생하거나, 사용자가 Outline 앱을 통해 직접 의견을 보내는 경우 아래에 나열된 정보가 전송됩니다. 이 정보는 안정성 또는 성능 문제를 확인하고 해결하는 데만 사용됩니다.

- 국가
- 언어
- 비정상 종료/예외 발생 날짜 및 시간과 직전 이벤트 최대 100건(예: 사용자가 '정보' 섹션을 열어봄 등)
- 정적 컴파일된 예외 메시지
- OS 이름 및 버전
- 휴대전화 모델(해당하는 경우)
- 앱 시작 시간
- 브라우저
- 아키텍처
- Outline 버전 및 빌드 번호

이 정보는 HTTPS를 사용하여 서드 파티 오픈소스 오류 추적 제공업체인 Sentry([sentry.io](https://sentry.io/))로 전송됩니다. Sentry에서는 다양한 업계 표준 기술 및 서비스를 사용하여 무단 액세스, 공개, 사용, 손실로부터 데이터를 보호합니다. Sentry의 정책에 대해 궁금한 점이 있는 경우 [https://sentry.io/security/](https://sentry.io/security/) 및 [https://sentry.io/privacy/](https://sentry.io/privacy/)를 확인하거나 [security@sentry.io](mailto:security@sentry.io)에 문의하세요. Sentry에 저장된 모든 Outline 데이터는 Outline팀만 액세스할 수 있도록 제한됩니다.

****정보 제공 선택 시 Outline에 전송되는 정보****

 사용자가 정보 제공을 선택한 경우 Outline에서 다음과 같은 정보를 Outline팀에 전송합니다.

 1. 사용 측정항목

 각 Outline 서버에서는 지난 1시간 동안 액세스 키별로 전송된 바이트 수, 사용자가 서버에 접속한 시간, 사용된 사용자 인증 정보의 출발지 국가 및 자율 시스템, 사용 설정 또는 중지된 기능이 있는지에 관한 정보 수집이 자동으로 이뤄집니다. 통신 내용 및 개인 식별 가능 메타데이터(예: 로그인, 이메일, 기기 ID 등)는 기록되지 않습니다. 모든 측정항목은 서버 ID와 연결됩니다. 서버 ID를 변경하는 방법에 관한 안내는 [여기](/manager/server-management/reset-server-id)에서 확인할 수 있습니다.

 기본적으로 Outline 서버는 이러한 측정항목을 Outline팀과 공유하지 않습니다. 서버 관리자가 사용 측정항목 공유를 명시적으로 선택하는 경우, 해당 정보는 1시간마다 Outline팀에 안전하게 전송됩니다. 60일이 지나면 사용 측정항목이 국가 수준에서 집계됩니다. 서버 관리자는 Outline Manager의 '설정' 메뉴에서 사용 측정항목 공유 설정을 언제든지 변경할 수 있습니다.

 서버 사용에 관한 익명 처리된 측정항목의 공유는 사용 추세를 측정하고 제품을 개선하는 데 도움이 됩니다.

 예를 들어 서버 관리자가 사용 측정항목 공유를 선택하는 경우, Outline에서는 데이터 한도 기능이 사용 설정된 상태에서 ID가 12345인 서버가 어제 3시간 동안 미국과 캐나다에서 각각 3개의 키를 통해 총 500MB의 데이터를 전송했다는 정보를 받을 수 있습니다.

 2. 사용자가 의견을 제출하는 경우 의견 및 이메일

 Outline Manager 및 Outline 앱을 통해 팀에 의견을 제출할 수 있습니다. 개인 식별 정보는 포함하지 않는 것이 좋지만 팀의 답변을 받으려면 이메일 필드를 선택적으로 사용할 수 있습니다. 또한 사용자가 제출한 의견을 이해할 수 있도록 일부 기본적인 정보를 자동으로 수집합니다. 위의 'Outline에서 자동으로 수집하는 정보'의 2번 항목에서 어떤 데이터가 수집되는지 확인하세요. [여기](/about/security-and-privacy)에서 Outline의 보안 및 개인 정보 보호 관행에 대해 자세히 알아보세요.

 Android에서 Outline 앱의 베타 버전을 사용하고 있는 경우, Outline팀에서 Google의 [Firebase](https://firebase.google.com/) 서비스를 이용해 문제를 감지하고 Outline을 개선하는 데 도움이 되는 디버깅 정보를 수집할 수 있습니다. Firebase의 개인 정보 보호 및 보안 정책에 관한 자세한 내용은 [firebase.google.com/support/privacy](https://firebase.google.com/support/privacy) 웹사이트를 참고하세요. Outline이 Firebase를 통해 이 정보를 보내지 않기를 바란다면 앱의 프로덕션 버전을 사용하시기 바랍니다.
