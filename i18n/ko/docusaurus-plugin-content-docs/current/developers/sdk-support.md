---

이 지원 웹사이트는 Outline Manager 및 클라이언트 사용자를 위한 것입니다. 개발자는 GitHub에서 지원을 받으세요. 질문이 있는 경우 SDK [토론 게시판](https://github.com/Jigsaw-Code/outline-sdk/discussions)에 게시하세요. 토론 게시판 섹션은 질문하고, 아이디어를 공유하고, 데모 링크를 만들고, Outline SDK를 사용하는 다른 개발자들을 지원할 수 있는 공간입니다. 기능 요청 또는 버그 신고의 경우 [Issue](https://github.com/Jigsaw-Code/outline-sdk/issues/new)(문제)를 여세요.
