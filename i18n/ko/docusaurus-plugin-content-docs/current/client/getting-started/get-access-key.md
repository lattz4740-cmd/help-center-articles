title: "액세스 키는 어떻게 받나요?"
sidebar_label: "액세스 키는 어떻게 받나요?"
---

Outline은 액세스 권한을 구매하여 이용하는 VPN 서비스와 다릅니다. 이는 비공개 VPN 서버를 실행하고 이에 대한 액세스 권한을 공유하도록 도와주는 [도구](https://getoutline.org/#:~:text=Two%20Products%20that%20Work%20Together)입니다. [서비스 관리자](/about/terminology#servicemanager)만 액세스 키를 제공할 수 있습니다. Outline팀에서는 무료 또는 유료 액세스 키를 배포하지 않습니다. 페르시아어를 지원하는 Paskoocheh를 제외하고는 공식 Outline 액세스 키 파트너가 없습니다.

 액세스 키를 받는 방법에는 세 가지가 있습니다.

- 서버 초대 요청하기: Outline 서버 보유자를 알고 있다면 액세스 키를 요청하세요.
- [직접 서버 만들기:](/manager/server-setup/setup-server) Windows, Mac 또는 Linux 컴퓨터를 사용하여 [Outline Manager](https://getoutline.org/get-started/#step-1)를 다운로드한 후 자체 비공개 [Outline 서버](/about/terminology)를 설정하세요. 이 작업은 특히 클라우드 서비스 제공업체 DigitalOcean을 통해 누구나 쉽게 수행할 수 있습니다.
- Outline 또는 [Shadowsocks](https://ko.wikipedia.org/wiki/%EC%84%80%EB%8F%84%EC%82%AD%EC%8A%A4#:~:text=%EC%84%80%EB%8F%84%EC%82%AD%EC%8A%A4(Shadowsocks),%EB%A7%8C%EB%93%A4%EC%96%B4%EC%A1%8C%EB%8B%A4.) 서비스 사용하기: Outline 클라이언트를 Outline 또는 Shadowsocks 프로토콜을 사용하는 서드 파티 서비스와 함께 사용할 수 있습니다. 예를 들면 다음과 같습니다.
   - [nthLink](http://nthlink.com/)에서는 Outline 클라이언트의 수정된 버전을 사용하여 Outline 기반의 무료 서비스를 실행합니다.
   - [ASL19](https://www.reddit.com/r/outlinevpn/comments/nwu1se/the_outline_distribution_system_is_here_to_help/)에서는 [BeePass](https://beepassvpn.com/)라고 하는 Outline의 수정된 버전과 BeePass 서버에 대한 무료 액세스 키를 제공하는 [Telegram 봇](https://t.me/paskoochehbot)을 운영합니다.
   - 페르시아어 사용자는 [ASL19의 Paskoocheh](https://outline.paskoocheh.com/)에서 Outline 액세스 키를 요청할 수도 있습니다.

Outline 클라이언트 앱을 다운로드한 후 [액세스 키](/about/terminology#accesskey)를 복사하여 Outline 클라이언트에 붙여넣고 Outline 서버에 연결하세요.
