| **운영체제** | **최소 버전** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

더 많은 운영체제에서 Outline 클라이언트가 작동할 수 있도록 도움을 주고 싶으신가요? GitHub에서 [코드베이스에 참여](https://github.com/Outline-Foundation/outline-client#platform-specific-development)해 보세요.
