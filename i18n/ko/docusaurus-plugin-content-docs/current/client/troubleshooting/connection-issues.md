Outline 서비스에 연결할 수 없는 몇 가지 이유는 다음과 같습니다.

- **기기가**[**인터넷에 연결되어 있지 않습니다**](#Internetissues)**.**기기의 네트워크 연결이 끊어지는 경우가 있으며 네트워크 아이콘이 업데이트되는 데 약간의 시간이 걸릴 수 있습니다. 기기가 로컬 네트워크에 연결되어 있지만 인터넷이 다운되었을 수도 있습니다.
- **Outline 서버에 대한 액세스를**[**네트워크 방화벽이 차단하고 있습니다**](#FirewallIssues)**.**학교, 직장 또는 무료 무선 네트워크와 같은 공용 네트워크를 사용하는 경우 일반적인 현상입니다.
- **기기에 Outline 서버로의 액세스를 차단하는**[**방화벽 또는 바이러스 백신 소프트웨어**](#SoftwareIssues)**가 있습니다.**
- [**휴대전화 기기 설정**](#DeviceSettings)**을 변경해야 할 수도 있습니다.**
- **서비스 관리자가**[**서버를 삭제했거나 ISP에서 요청을 차단했을 수 있습니다**](#ServerIssues)**.**

## 인터넷 연결 문제 {#Internetissues}

### 테스트 방법

Outline을 사용 중지하고 인터넷 연결이 복원되었는지 확인합니다.

- 네트워크가 복원된 경우 아래의 추가 문제 해결 옵션을 참고하세요.
- 네트워크가 복원되지 않은 경우 잠시 기다렸다가 연결 설정이 자체적으로 업데이트되는지 확인하세요.

### 수정해야 할 사항

다음 단계에 따라 기기를 다시 인터넷에 연결합니다.

1. 다른 기기에서 동일한 네트워크에 연결할 수 있는지 확인합니다. 다른 장치도 인터넷에 연결할 수 없으면 네트워크가 다운되었을 수 있으므로 네트워크가 복원될 때까지 기다리거나 네트워크 관련 문제를 해결해야 합니다.
2. 다른 기기에서 동일한 네트워크에 연결할 수 있는 경우 다음 조치 중 하나 이상을 시도하여 기기를 다시 인터넷에 연결할 수 있습니다.
   1. 기기를 비행기 모드로 설정(모바일)
   2. 기기 다시 시작
   3. 기기를 종료하고 2분 동안 기다린 후 기기 다시 켜기

## 네트워크 방화벽 문제 {#FirewallIssues}

### 테스트 방법

1. 현재 Wi-Fi 또는 유선 네트워크에서 연결을 해제합니다.
2. 모바일 네트워크와 같이 다른 네트워크에 연결합니다.
3. Outline 서버에 다시 연결해 보세요.

다른 네트워크를 통해서 연결할 수 있는 경우 이 문제로 인해 오류가 발생한 것입니다.

### 수정해야 할 사항

서비스 관리자에게 문의하여 Outline 서버 액세스를 허용하거나 대신 다른 네트워크를 계속 사용하도록 요청하세요.

## 방화벽 또는 바이러스 백신 소프트웨어 문제 {#SoftwareIssues}

### 테스트 방법

다른 기기를 통해 Outline에 연결해 보세요.

참고: 다른 기기에서 Outline을 사용하려면 액세스 키와 Outline 앱이 필요합니다.

### 수정해야 할 사항

방화벽 또는 바이러스 백신 소프트웨어 설정이 VPN 및 Outline 트래픽을 통과하도록 설정되어 있는지 확인합니다.

## 기기 설정 {#DeviceSettings}

## 확인할 사항 {#ServerIssues}

Android의 경우:

1. 설정 앱을 엽니다.
2. 기기에서 **VPN 설정**을 확인합니다. VPN 설정에는 현재 휴대전화에서 액세스할 수 있는 모든 VPN 앱이 표시됩니다.
3. VPN 설정에 Outline이 표시되지 않으면 Outline을 제거하고 재설치합니다. Outline이 설치되면 기기에서 Outline에 자동으로 액세스 권한을 부여합니다.

Android 기기에 화면 오버레이 애플리케이션이 설치되어 있지 않아야 합니다. 이로 인해 Outline 권한 창이 백그라운드로 전송되어 포그라운드에 표시되지 않을 수 있습니다.

Android 기기에서 설정 > 앱 > 특수 앱 액세스로 이동합니다. 그런 다음 '다른 앱 위에 표시'를 탭합니다. 이 동작을 허용하는 모든 앱에 대한 액세스 권한을 제거할 수 있습니다.

iOS의 경우: [이 지원 도움말](https://support.apple.com/guide/deployment/vpn-settings-overview-dep2d2adb35d/web)을 읽어 보세요.

### 서버 문제

### 테스트 방법

둘 이상의 서버에 액세스할 수 있는 경우 다른 서버에 연결해 보세요.

### 수정해야 할 사항

서버가 손상되었는지 확인하려면 서비스 관리자에게 문의하세요. 이 경우 관리자에게 다른 서버에 대한 [액세스 키](/about/terminology)를 요청하세요.

서버를 설정하는 경우 Outline Manager나 [SSH](https://en.wikipedia.org/wiki/Secure_Shell)와 같은 다른 방법으로 서버에 연결합니다. 그래도 문제가 해결되지 않으면 클라우드 공급자 콘솔을 확인하여 서버가 아직 온라인 상태인지 확인해 보세요.
