sidebar_label: "Outline 서버에 연결했는데도 인터넷에 액세스할 수 없는 이유는 무엇인가요?"
---

휴대전화를 사용하는 경우 모바일 데이터와 Wi-Fi 연결 간에 전환해 보세요. 한 연결 유형이 작동할 때 다른 연결 유형이 작동하지 않는 경우도 있습니다. 컴퓨터를 사용하는 경우 광대역 연결을 해제했다가 다시 연결해 보세요.

문제가 계속 발생하면 Outline 서버에 문제가 있는 것일 수 있습니다. 대체 서버의 액세스 키는 [서비스 관리자](/about/terminology)에게 문의하세요. 액세스 키가 할당량을 초과한 경우 관리자가 [액세스 키](/about/terminology) 데이터 한도를 늘릴 수도 있습니다.
