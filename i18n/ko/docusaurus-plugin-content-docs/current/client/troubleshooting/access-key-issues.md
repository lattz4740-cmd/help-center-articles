'액세스 키가 유효하지 않은 것 같습니다. 이 문제가 다시 발생하면 서비스 관리자에게 문의해 보세요.'

문제를 해결하려면 아래 단계를 따르세요.

1. 클립보드에 자동으로 복사되지 않을 수 있는 첫 5자 'ss://'를 포함하여 전체 액세스 키를 입력해야 합니다. 다음은 전체 액세스 키의 예시입니다(샘플이므로 실제로 작동하지 않음).

ss://Y2hhY2hhMjAtaWV0Zi1wb2x5MTMwNTp1eXhUQ3MzemVEMTk=@145.230.4.1:39485/?outline=1

1. 액세스 키가 클립보드에 전혀 복사되지 않으면 메시지 앱이나 플랫폼 때문일 수 있습니다. 이는 연락처 목록에 없는 사람에게서 메시지를 받았을 때 발생할 가능성이 높습니다. 메시지에서 코드를 복사하는 경우 보낸 사람이 연락처에 추가되었는지 확인한 다음 링크에 다시 액세스해 보세요.
2. 1단계와 2단계를 완료했는데도 오류 메시지를 계속 받는 경우 서버가 차단되었거나 액세스 키가 더 이상 유효하지 않을 가능성이 높습니다. 서비스 관리자인 경우 직접 새 키를 생성해 보세요. 그렇지 않으면 서비스 관리자에게 문의해 새 키를 요청하세요.
