[대부분의 클라우드 제공업체는 사용 중인 특정 가상 머신을 쉽게 삭제할 수 있습니다.](/manager/server-setup/setup-server)

DigitalOcean을 클라우드 제공업체로 이용하는 경우, 톱니바퀴 아이콘을 클릭하고 **서버 삭제**를 선택하여 기존 가상 머신을 삭제할 수 있습니다. 그 후 즉시 원하는 위치에 새 가상 머신을 생성하라는 메시지가 표시됩니다.

Outline 서버를 삭제하면 영구적으로 삭제되며 액세스 키가 더 이상 작동하지 않습니다. 사용자의 Outline을 통한 액세스가 중단되지 않도록 하려면 기존 서버를 삭제하기 전에

하고 그에 대한 액세스 키를 공유해야 합니다.
