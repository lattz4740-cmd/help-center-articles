서버 ID란 Outline 서버를 만들 때 무작위로 생성되는 서버 측 ID입니다. 설정 인터페이스에서 익명처리된 측정항목을 공유하기로 선택하면 서버 ID를 확인할 수 있습니다. 다음 위치에서 서버 ID를 찾을 수 있습니다. 설정 => 맨 아래로 스크롤 => '익명처리된 측정항목 공유'를 선택하세요.

서버 ID는 시차를 두고 보고되는 익명처리된 사용 통계를 서로 연결합니다. 서버 ID를 재설정하고 새 ID를 받으려면 기존 Outline 서버를 새 서버로 교체해야 합니다.
