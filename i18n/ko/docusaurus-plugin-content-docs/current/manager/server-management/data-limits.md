데이터 한도를 설정하여 모든 액세스 키에 적용할 수 있습니다. 한도를 설정하려면 Outline Manager를 열고 'Settings(설정)'로 이동합니다. 'Settings(설정)'에 있는 'Data limits(데이터 한도)' 전환 버튼을 사용 설정하면 한도를 설정할 수 있습니다.

![Data limits setting in Outline Manager](/images/snippet-15787036.png)

한도가 설정되면 액세스 키 페이지에서 각 사용자가 얼마나 한도에 근접했는지 확인할 수 있습니다. 해당 페이지의 막대 그래프는 지난 30일 동안의 데이터 사용량을 보여줍니다.

![Outline Manager's Access Key page](/images/snippet-15787037.png)

모든 액세스 키에 한도를 설정할 수 있을 뿐 아니라 각각의 키에 자체 데이터 한도를 부여할 수도 있습니다. 이 설정은 사용자가 설정한 모든 기본 데이터 한도를 재정의하지만 기본 데이터 한도를 설정하지 않은 경우에도 어떤 키에든 데이터 한도를 설정할 수 있습니다. 

 키의 데이터 전송 한도를 설정하려면 Outline Manager를 열고 설정하려는 키가 포함된 'Connections(연결)' 탭으로 이동한 다음 키 행의 오른쪽에서 메뉴를 클릭합니다. 메뉴에서 'Data Limit(데이터 한도)'를 클릭합니다. 'My access key(내 액세스 키)'에서 데이터 한도를 변경하려면 데이터 한도 아이콘 ![데이터 한도 아이콘](https://lh7-us.googleusercontent.com/docsz/AD_4nXc2jByBppEN1yHPjbK2BxNuYxwmfW98eYRyJGiDmg4lSLNLxf5aav2971IntWOfqF8oJ1zhW7RVdaxJVxkdZkpsDeSgnBbJfNisidjKbcRh3FheoVjQNSZHHEgUz155B1_wRjlB2mAIa6Qfs5k7Mg_i6YJhYle80EPoZVkdl09uvBbSxUgfLvPserKL8dSCElVSLcuo7uF232qnTKFKM4gt_f0iDQ?key=oLpwwvDVb_5YbZSyjC9Agw)을 클릭합니다.

![Selecting the data limit setting icon for an individual access key](/images/snippet-15787423.png)

'Set a custom data limit(맞춤 데이터 한도 설정)'를 선택합니다. 이 체크박스를 선택하면 해당 키의 맞춤 데이터 한도를 설정할 수 있는 입력란이 표시됩니다. 완료하면 'SAVE(저장)' 버튼을 클릭하여 데이터 한도를 저장합니다.

![Setting a data limit for an individual access key](/images/snippet-15788959.png)

특정 키의 데이터 전송 한도를 저장하고 나면 기본 화면에 각 키의 지난 30일간 데이터 사용량과 함께 한도가 표시됩니다.

액세스 키에서 데이터 한도를 삭제하려면 이전과 같이 키의 'Data Limit(데이터 한도)' 대화상자로 이동하여 'Set a custom data limit(맞춤 데이터 한도 설정)' 체크박스를 선택 해제한 다음 'SAVE(저장)' 버튼을 클릭합니다.

![Removing the data limit on an individual access key](/images/snippet-15788414.png)

****데이터 한도 FAQ****

****30일 누적 데이터 한도란 무엇인가요?****

 30일 누적 데이터 한도는 지난 30일 동안 각 키에서의 데이터 사용량을 합산하고 이 기간에 대해 키의 데이터 사용량을 특정 한도 이하로 유지합니다. 키는 어떠한 30일의 기간 동안 한도를 초과할 수 없으며, 여기에는 30일 미만의 달도 포함됩니다. 사실상 이는 각 사용자가 사용할 수 있는 데이터가 31일 전에 사용한 양만큼 매일 늘어남을 의미합니다.

Outline에서 누적 한도를 사용하는 이유는 무엇인가요?

 누적 한도는 30일의 기간마다 데이터 사용량을 일정 수준으로 확실하게 유지합니다. 즉, 반복 한도(한 달 중 특정 날짜로 맞춤설정하는 등)보다 간단하게 구성할 수 있으면서도 비슷한 수준의 제어를 제공합니다. 또한 Outline에서의 데이터 사용량을 보여주는 기존 디스플레이와 분석 서비스 및 서버 통계와 같은 일반적인 도구와도 어울립니다.

**데이터 한도에 어떤 데이터가 집계되나요?**

 각 액세스 키의 서버 이그레스가 총계에 포함됩니다. 엄밀히 말하면 이는 키를 대신하여 서버 외부로 전송된 데이터 및 클라이언트로 다시 전송된 데이터를 의미합니다. 사실상 이 수치는 키에서 서버로 전송된 트래픽 및 서버에서 키로 다시 전송된 트래픽에 근접하므로, 이 수치가 사용자의 총계와 일치할 것으로 기대하고 있습니다. 설문조사를 실시한 결과 클라우드 제공업체는 이그레스에 대해 청구하므로 이그레스를 선택하였습니다.

**사용자가 데이터 한도를 초과하면 알림이 전송되나요?**

 현재로서는 아닙니다. 많은 클라우드 제공업체에서는 1개월당 1TB와 같은 한도를 두고 있으며, 이러한 방식을 사용하면 10명의 사용자가 100GB를 사용하거나 100명의 사용자가 10GB를 사용할 수 있습니다. 이는 꽤 큰 수치이며, 이 한도를 초과하는 사용자가 많지 않을 것이라고 예상합니다. 한도에 도달한 사용자는 서버 관리자에게 직접 문의하도록 할 예정입니다. 그러나 알림이 귀하의 사용 사례에 어떤 도움이 될 수 있을지에 대해 의견을 제공해 주시기 바랍니다. [여기](/about/feedback)를 통해 연락해 주세요.

**사용자가 데이터 한도에 근접하면 알림이 전송되나요?**

 데이터 한도에 가까워지는 사용자가 받게 될 새 데이터의 양은 해당 사용자의 30일 전 사용량에 따라 정해지므로 매일 다릅니다. 알림이 전송되면 최종 사용자에게 도움을 주기보다는 혼란을 야기할 수 있습니다. [여기](/about/feedback)에서 이 동작에 관한 의견을 보내주시기 바랍니다.

**사용자의 데이터 사용량을 초기화할 수 있나요?**

 아니요. 사용자의 한도에는 항상 지난 30일간의 데이터 사용이 반영됩니다. 하지만 사용자의 키 데이터 한도를 높이거나 새로운 키를 만들 수는 있습니다.

**데이터 한도를 사용 설정하자마자 일부 사용자가 액세스 권한을 잃은 이유는 무엇인가요?**

 데이터 한도는 사용자의 이전 30일간의 데이터 전송을 기반으로 하며, 30일간의 데이터 사용량은 데이터 한도 설정 여부와 관계없이 기록됩니다. 데이터 한도를 설정하기 전에 이미 해당 사용자가 한도를 초과했을 수 있습니다. 또한 하나의 키 데이터 한도를 변경하더라도 모든 데이터 한도가 시행됩니다.

**'30일당 1TB'와 같이 서버 전체 한도를 설정할 수 있나요?**

 현재로서는 설정할 수 없습니다. [여기](/about/feedback)를 통해 귀하의 사용 사례에 대해 자세히 알려 주세요.

**기본 데이터 한도와 특정 키 데이터 한도가 있는 경우 어떤 한도가 시행되나요?**

 특정 키의 데이터 한도가 사용자가 설정한 기본 데이터 한도(있는 경우)보다 우선 적용됩니다.

**기본 데이터 한도 설정 없이 특정 키에 대해서만 데이터 한도를 설정할 수 있나요?**

 예. 하나의 키에 데이터 한도를 설정하려고 할 때 기본 한도가 필요하지는 않습니다. 예를 들어 키를 통한 과도한 데이터 전송을 방지하기 위해 널리 공유될 수 있는 특정 키에만 한도를 설정할 수 있습니다.
