---
title: "Outline 서버의 위치를 변경하려면 어떻게 해야 하나요?"
sidebar_label: "Outline 서버의 위치를 변경하려면 어떻게 해야 하나요?"
---

설정한 서버 위치는 변경할 수 없습니다. 다른 위치에서 서버를 실행하려면 Outline 서버를 삭제하고 새 서버를 만들어야 합니다.

또는 서버를 순환하고 동일한 키를 유지할 수 있는 [동적 키](https://developer.getoutline.org/vpn/management/dynamic-access-keys/)를 사용하여 VPN 위치를 변경할 수 있습니다. 서버 자체의 위치는 변경되지 않습니다.
