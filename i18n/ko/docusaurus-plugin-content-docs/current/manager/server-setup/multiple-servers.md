---
title: 여러 개의 Outline 서버 설정 방법
sidebar_label: 여러 개의 Outline 서버 설정 방법
---

추가로 Outline 서버를 설정하려면 Outline Manager 애플리케이션의 왼쪽에 있는 탐색 패널에서 '+' 아이콘을 클릭합니다. 새 서버를 추가하는 방법은 처음 서버를 설치하는 방법과 동일합니다.

- 사용자가 만들 수 있는 Outline 서버의 수에는 제한이 없습니다.
- 생성하는 모든 Outline 서버에는 관련된 가상 머신이 필요합니다.
- 추가 가상 머신 또는 Droplet을 만들면 클라우드 제공업체에 지불할 수수료가 증가할 수 있습니다. 예상 수수료를 확인하려면 클라우드 제공업체의 가격 패키지를 참고하세요.

## DigitalOcean에서 추가 Outline 서버 만들기

+ 아이콘을 클릭하고 DigitalOcean에서 설치를 선택하면 처음 서버를 설정할 때와 같은 안내를 따르게 됩니다. Outline Manager는 DigitalOcean과 통합되어 있으므로 Outline Manager 앱을 나가지 않고도 Droplet을 만들 수 있습니다.

Outline Manager는 한 번에 한 개의 DigitalOcean 계정만 지원할 수 있습니다. 다른 DigitalOcean 계정으로 다른 Outline 서버를 추가하거나 만들려면 고급 구성을 통해 추가할 수 있습니다.

## GCP, AWS 또는 다른 클라우드 서비스 제공업체에 기반한 추가 Outline 서버 만들기

우선 선택한 클라우드 제공업체에서 새로운 가상 머신을 만듭니다. 그런 다음 Outline Manager를 열고 처음 서버를 설치할 때와 동일한 안내에 따라 고급 설치를 완료합니다.
