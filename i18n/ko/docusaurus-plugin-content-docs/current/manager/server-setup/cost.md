sidebar_label: "Outline을 실행하려면 비용이 얼마나 드나요?"
---

Outline 소프트웨어는 VPN을 관리하는 서버 관리자, 개방형 인터넷에 액세스할 때 Outline을 사용하는 사용자 등 누구에게나 무료로 제공되는 소프트웨어입니다.

 하지만 Outline을 사용하려면 클라우드 서버에 액세스해야 합니다. 이미 서버에 액세스할 수 있는 서버 관리자는 추가 비용 없이 Outline을 설치할 수 있습니다. 서버에 대한 액세스가 없다면, [DigitalOcean](https://www.digitalocean.com/) 또는 Amazon Web Services와 같은 클라우드 서비스 제공업체로부터 액세스 권한을 얻을 수 있습니다. 1TB 데이터를 전송하는 데 대략 월 USD $5 정도가 들며, 이는 하나의 서버를 통해 수백 명의 사용자를 지원하기에 충분한 값입니다.

 다음 예제에서 선택한 클라우드 제공업체를 통해 Outline을 실행하려면 어느 정도의 비용이 들지 예측해 보세요.

| *사용자 1명당 매월 평균적으로 5GB의 데이터를 전송한다고 가정하면, 매월 USD $5를 지불하는 요금제로 약 200명의 동시 사용자를 지원할 수 있으며 사용자 1명당 비용은 한 달에 2.5센트에 불과합니다. 사용자 1명당 월별 데이터 전송량은 사용자의 활동이 적은 대역폭을 필요로 하는지, 또는 많은 대역폭을 필요로 하는지에 따라 크게 달라질 수 있지만, 대부분의 클라우드 제공업체들은 유연하게 조정하여 트래픽 증가를 수용합니다.* |
| --- |

Outline 사용은 Jigsaw 및 Google에 완벽하게 익명으로 유지됩니다. Outline은 사용자의 신원이나 트래픽을 추적하지 않으며, 이를 통해 수익을 창출하려 하지 않습니다. 오히려 Outline은 사용자에게 무료로 소프트웨어를 제공하기 위해 오픈소스 커뮤니티와 협력하고 있습니다. [여기](https://getoutline.org/policies/data-collection)에서 Outline에서 수집하는 데이터에 관해 자세히 알아보세요.
