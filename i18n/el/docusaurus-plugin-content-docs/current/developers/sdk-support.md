Αυτός ο ιστότοπος υποστήριξης προορίζεται για χρήστες του Outline Manager και του Outline Client. Οι προγραμματιστές μπορούν να χρησιμοποιήσουν το GitHub για υποστήριξη. Για να κάνετε μια ερώτηση, δημοσιεύστε τη στο [Discussion board](https://github.com/Jigsaw-Code/outline-sdk/discussions) του SDK. Η ενότητα Discussion board είναι ένα εξαιρετικό μέρος για να κάνετε ερωτήσεις, να μοιράζεστε ιδέες, να δημοσιεύετε συνδέσμους προς επιδείξεις και να υποστηρίζετε άλλους προγραμματιστές που χρησιμοποιούν το Outline SDK. Για αιτήματα λειτουργιών ή αναφορές σφαλμάτων, ανοίξτε εναλλακτικά ένα [Πρόβλημα](https://github.com/Jigsaw-Code/outline-sdk/issues/new).
