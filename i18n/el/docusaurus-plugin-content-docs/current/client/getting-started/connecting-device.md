---
title: Σύνδεση της συσκευής σας σε έναν διακομιστή Outline
sidebar_label: Σύνδεση της συσκευής σας σε έναν διακομιστή Outline
---

Για να συνδέσετε τη συσκευή σας σε έναν διακομιστή Outline, θα πρέπει να λάβετε πρόσκληση από έναν διαχειριστή διακομιστή για να συνδεθείτε στον διακομιστή του με ένα μοναδικό [κλειδί πρόσβασης](/about/terminology). Αυτή η πρόσκληση:

- Θα σας προτρέψει να κατεβάσετε και να εγκαταστήσετε το Outline στη συσκευή σας, εάν δεν το έχετε ήδη κάνει.
- Θα χρησιμοποιήσει το κλειδί πρόσβασης για να δημιουργήσει μια ασφαλή σύνδεση ανάμεσα σε εσάς και τον διακομιστή Outline.

Όταν γίνει η σύνδεσή σας στον διακομιστή, μπορείτε να κάνετε κλικ στα κουμπιά σύνδεσης ή αποσύνδεσης για να χρησιμοποιήσετε το Outline.

:::warning[Σημαντικό]
Το Outline δεν λειτουργεί χωρίς κλειδί πρόσβασης και έναν διακομιστή Outline. Η λήψη και η εγκατάσταση της εφαρμογής Outline χωρίς κλειδί δεν προστατεύει τη διαδικτυακή κίνησή σας.
:::
