Το Outline δεν μοιάζει με τις υπηρεσίες VPN στις οποίες αγοράζετε πρόσβαση. Πρόκειται για [ένα εργαλείο](https://getoutline.org/#:~:text=Two%20Products%20that%20Work%20Together) που σας επιτρέπει να χρησιμοποιείτε και να μοιράζεστε την πρόσβαση σε έναν ιδιωτικό διακομιστή VPN. Ο [υπεύθυνος υπηρεσίας](/about/terminology#servicemanager) είναι το μόνο άτομο που μπορεί να παρέχει ένα κλειδί πρόσβασης. Η ομάδα του Outline δεν διανέμει κλειδιά πρόσβασης χωρίς χρέωση ή επί πληρωμή. Δεν έχουμε επίσημους συνεργάτες κλειδιών πρόσβασης στο Outline, εκτός από το Paskoocheh στη γλώσσα Φαρσί.

 Ακολουθούν τρεις επιλογές για την απόκτηση κλειδιού πρόσβασης:

- Ζητήστε από κάποιον να σας προσκαλέσει στον διακομιστή του. Αν γνωρίζετε κάποιον με διακομιστή Outline, επικοινωνήστε μαζί του και ζητήστε του ένα κλειδί πρόσβασης.
- [Δημιουργήστε έναν διακομιστή εσείς οι ίδιοι:](/manager/server-setup/setup-server) Χρησιμοποιώντας υπολογιστή Windows, Mac ή Linux, κατεβάστε το [Outline Manager](https://getoutline.org/get-started/#step-1) και ρυθμίστε τον δικό σας ιδιωτικό [διακομιστή Outline](/about/terminology). Κάναμε αυτή τη διαδικασία εύκολη για οποιονδήποτε, ιδίως μέσω του παρόχου υπηρεσιών cloud DigitalOcean.
- Χρησιμοποιήστε μια υπηρεσία Outline ή [Shadowsocks](https://en.wikipedia.org/wiki/Shadowsocks#:~:text=Shadowsocks%20is%20a%20free%20and,have%20been%20made%20available%20since.): Η εφαρμογή πελάτης Outline μπορεί επίσης να χρησιμοποιηθεί με υπηρεσίες τρίτων που χρησιμοποιούν το πρωτόκολλο Outline ή Shadowsocks. Για παράδειγμα:
   - Το [nthLink](https://nthlink.com/) εκτελεί μια υπηρεσία χωρίς χρέωση που βασίζεται στο Outline, με μια τροποποιημένη έκδοση της εφαρμογής πελάτη Outline.
   - Το [ASL19](https://www.reddit.com/r/outlinevpn/comments/nwu1se/the_outline_distribution_system_is_here_to_help/) εκτελεί μια τροποποιημένη έκδοση του Outline που ονομάζεται [BeePass](https://beepassvpn.com/) και ένα [Telegram bot](https://t.me/paskoochehbot) που παρέχει κλειδιά πρόσβασης χωρίς χρέωση στους διακομιστές του BeePass.
   - Οι χρήστες στη γλώσσα Φαρσί μπορούν επίσης να ζητήσουν ένα κλειδί πρόσβασης Outline από το [Paskoocheh του ASL19](https://outline.paskoocheh.com/).

Μετά τη λήψη της εφαρμογής Outline Client, αντιγράψτε και επικολλήστε το [κλειδί πρόσβασης](/about/terminology#accesskey) στην εφαρμογή Outline Client για να συνδεθείτε στον διακομιστή Outline.
