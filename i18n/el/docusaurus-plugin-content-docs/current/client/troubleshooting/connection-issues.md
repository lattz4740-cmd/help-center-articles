Υπάρχουν διάφοροι λόγοι για τους οποίους μπορεί να μην είναι δυνατή η σύνδεσή σας στην υπηρεσία Outline:

- **Η συσκευή σας**/client/troubleshooting/connection-issues#One [**έχει αποσυνδεθεί από το διαδίκτυο**](#Internetissues)[#Internetissues](#Internetissues)**.**Ορισμένες φορές η σύνδεση δικτύου της συσκευής μπορεί να διακόπτεται και να υπάρχει μικρή καθυστέρηση στην ενημέρωση των εικονιδίων δικτύου. Είναι, επίσης, πιθανό η συσκευή σας να είναι συνδεδεμένη στο τοπικό δίκτυο, αλλά να μην υπάρχει σύνδεση στο διαδίκτυο.
- **Το**/client/troubleshooting/connection-issues#Two [**τείχος προστασίας του δικτύου αποκλείει την πρόσβαση**](#FirewallIssues)[#FirewallIssues](#FirewallIssues)**[στον διακομιστή Outline](#FirewallIssues).**Αυτό συμβαίνει συχνά αν χρησιμοποιείτε ένα δημόσιο δίκτυο, όπως ένα σχολικό, επαγγελματικό ή χωρίς χρέωση ασύρματο δίκτυο.
- **Η συσκευή σας διαθέτει**/client/troubleshooting/connection-issues#Three [**τείχος προστασίας ή λογισμικό προστασίας από ιούς**](#SoftwareIssues)[#SoftwareIssues](#SoftwareIssues)**που αποκλείει την πρόσβαση στον διακομιστή Outline.**
- **Οι**[**ρυθμίσεις συσκευής τηλεφώνου**](#DeviceSettings)**μπορεί να χρειαστεί να αλλάξουν.**
- **Ο υπεύθυνος εξυπηρέτησής σας μπορεί να**[**κατέστρεψε τον διακομιστή ή ο ISP μπορεί να αποκλείει το αίτημά σας**](#ServerIssues).

## Προβλήματα σύνδεσης στο διαδίκτυο: {#Internetissues}

### Πώς να κάνετε έλεγχο:

Απενεργοποιήστε το Outline και δείτε αν θα επανέλθει η σύνδεση στο διαδίκτυο.

- Αν επανέλθει, δείτε παρακάτω μερικές ακόμη επιλογές αντιμετώπισης προβλημάτων.
- Αν δεν επανέλθει, τότε περιμένετε μερικά λεπτά για να δείτε αν θα ενημερωθούν αυτόματα οι ρυθμίσεις σύνδεσης.

### Τι να διορθώσετε:

Συνδέστε ξανά τη συσκευή στο διαδίκτυο:

1. Ελέγξτε κάποια άλλη συσκευή, για να δείτε αν μπορεί να συνδεθεί στο ίδιο δίκτυο. Αν οι άλλες συσκευές δεν μπορούν να συνδεθούν στο ίδιο δίκτυο, τότε η λειτουργία του δικτύου ενδέχεται να έχει διακοπεί και θα πρέπει να περιμένετε να επανέλθει ή να αντιμετωπίσετε το πρόβλημα.
2. Αν μπορούν να συνδεθούν στο ίδιο δίκτυο άλλες συσκευές, δοκιμάστε ένα ή περισσότερα από τα ακόλουθα βήματα για να συνδεθείτε ξανά στο διαδίκτυο:
   1. Θέστε τη συσκευή σε λειτουργία πτήσης (κινητά)
   2. Επανεκκινήστε τη συσκευή
   3. Τερματίστε τη λειτουργία της συσκευής, περιμένετε 2 λεπτά και ενεργοποιήστε ξανά τη συσκευή

## Προβλήματα με το τείχος προστασίας του δικτύου: {#FirewallIssues}

### Πώς να κάνετε έλεγχο:

1. Αποσυνδεθείτε από το τρέχον Wi-Fi ή το ενσύρματο δίκτυο.
2. Συνδεθείτε σε άλλο δίκτυο, όπως ένα δίκτυο κινητής τηλεφωνίας
3. Δοκιμάστε να επανασυνδεθείτε στον διακομιστή Outline

Αν μπορέσετε να συνδεθείτε ενώ χρησιμοποιείτε το άλλο δίκτυο, τότε το πρόβλημα βρίσκεται στη δική σας πλευρά.

### Τι να διορθώσετε:

Επικοινωνήστε με τον υπεύθυνο εξυπηρέτησης και ζητήστε του να επιτρέψει την πρόσβαση στον διακομιστή Outline ή συνεχίστε να χρησιμοποιείτε το άλλο δίκτυο.

## Προβλήματα με το τείχος προστασίας ή το λογισμικό προστασίας από ιούς: {#SoftwareIssues}
### Πώς να κάνετε έλεγχο:
 Δοκιμάστε να συνδεθείτε στο Outline από άλλη συσκευή.

Σημείωση: Να θυμάστε ότι θα χρειαστείτε ένα κλειδί πρόσβασης και την εφαρμογή Outline για να χρησιμοποιήσετε το Outline σε άλλη συσκευή.

### Τι να διορθώσετε:
Ελέγξτε τις ρυθμίσεις του τείχους προστασίας ή του λογισμικού προστασίας από ιούς για να βεβαιωθείτε ότι επιτρέπουν τη διέλευση δεδομένων VPN και Outline.

## Ρυθμίσεις συσκευής: {#DeviceSettings}

## Τι να ελέγξετε: {#ServerIssues}
Για Android:

1. Ανοίξτε την εφαρμογή Ρυθμίσεις.
2. Αναζητήστε τις **ρυθμίσεις VPN** στη συσκευή σας. (Στις ρυθμίσεις VPN θα δείτε όλες τις εφαρμογές VPN που έχουν πρόσβαση στο τηλέφωνό σας τη δεδομένη στιγμή.)
3. Αν δεν βλέπετε το Outline στις ρυθμίσεις VPN, απεγκαταστήστε το Outline και επανεγκαταστήστε το. Θα πρέπει να δοθεί αυτόματα πρόσβαση στο Outline από τη συσκευή μετά την εγκατάστασή του.

Βεβαιωθείτε ότι δεν έχει εγκατασταθεί κάποια εφαρμογή επικάλυψης οθόνης στη συσκευή Android, καθώς μπορεί να στέλνει το παράθυρο αδειών του Outline στο παρασκήνιο, με αποτέλεσμα να μην είναι ορατό στο προσκήνιο.

 Στη συσκευή Android, επιλέξτε Ρυθμίσεις > Εφαρμογές > Ειδική πρόσβαση στην εφαρμογή. Έπειτα, πατήστε Εμφάνιση πάνω σε άλλες εφαρμογές. Μπορείτε να καταργήσετε την πρόσβαση σε οποιεσδήποτε εφαρμογές που επιτρέπουν αυτή τη συμπεριφορά.

 Για iOS: Διαβάστε[αυτό το άρθρο υποστήριξης](https://support.apple.com/guide/deployment/vpn-settings-overview-dep2d2adb35d/web).

### Προβλήματα διακομιστή:

### Πώς να κάνετε έλεγχο:
Αν έχετε πρόσβαση σε περισσότερους από έναν διακομιστές, δοκιμάστε να συνδεθείτε στον άλλο.

### Τι να διορθώσετε:

Επικοινωνήστε με τον υπεύθυνο εξυπηρέτησης για να μάθετε αν έχει καταστραφεί ο διακομιστής. Αν έχει καταστραφεί, ζητήστε του ένα[κλειδί πρόσβασης](/about/terminology) για άλλον διακομιστή.

Αν ρυθμίσατε εσείς τον διακομιστή, δοκιμάστε να συνδεθείτε σε αυτόν μέσω του Outline Manager ή με κάποιον άλλο τρόπο, όπως [SSH](https://en.wikipedia.org/wiki/Secure_Shell). Αν το πρόβλημα δεν διορθωθεί, μπορείτε να ελέγξετε την κονσόλα του παρόχου cloud, αν υπάρχει, για να δείτε αν ο διακομιστής εξακολουθεί να είναι σε σύνδεση.
