Ευχαριστούμε που μας βοηθάτε να κάνουμε το Outline καλύτερο. Μπορείτε να μας στείλετε τα σχόλιά σας με διάφορους τρόπους, είτε ανώνυμα είτε αναφέροντας τη διεύθυνση ηλεκτρονικού ταχυδρομείου σας εάν θέλετε να σας απαντήσουμε.

- **Για προγραμματιστές**: Το Outline είναι ένα προϊόν λογισμικού ανοικτού κώδικα που φιλοξενείται στο [GitHub](https://github.com/OutlineFoundation/?q=outline). Μπορείτε να μοιραστείτε τις ιδέες σας στο GitHub ή στην κοινότητα [Reddit](https://www.reddit.com/r/outlinevpn/).
- **Για χρήστες**: Μπορείτε να μας στείλετε τα σχόλιά σας μέσω των εφαρμογών Outline ή Outline Manager. Πείτε μας σε τι αναφέρονται τα σχόλιά σας και, προαιρετικά, δηλώστε μια διεύθυνση ηλεκτρονικού ταχυδρομείου για να σας απαντήσουμε σχετικά. Συγκεντρώνουμε επίσης ορισμένα μεταδεδομένα σχετικά με το περιβάλλον σας, όπως πληροφορίες για το πρόγραμμα περιήγησης, το λειτουργικό σύστημα και την έκδοση λογισμικού που χρησιμοποιείτε, προκειμένου να σας βοηθήσουμε στην αντιμετώπιση προβλημάτων.
- **Μέσω αυτού του ιστοτόπου**: Μπορείτε να κάνετε κλικ στον σύνδεσμο Επικοινωνήστε μαζί μας οπουδήποτε εμφανίζεται σε αυτόν τον ιστότοπο.
- **Σοβαρά ζητήματα**: Αν θέλετε να αναφέρετε ένα σοβαρό ζήτημα ασφαλείας, στείλτε ένα μήνυμα ηλεκτρονικού ταχυδρομείου στη διεύθυνση security [at] [getoutline.org](https://getoutline.org/).

Σας ευχαριστούμε ξανά για τον χρόνο που διαθέσατε για να μοιραστείτε τις σκέψεις σας μαζί μας.
