## Τι είναι το VPN;
 Το εικονικό ιδιωτικό δίκτυο (VPN) είναι μια ιδιωτική σύνδεση ανάμεσα στις συσκευές σας και σε έναν διακομιστή κεντρικού υπολογιστή. Όταν χρησιμοποιείτε VPN, οι κινήσεις σας στο διαδίκτυο δεν αποκαλύπτονται στον πάροχο υπηρεσιών διαδικτύου. Μπορεί να θέλετε να χρησιμοποιήστε VPN στις εξής περιπτώσεις:

- Για να προστατεύσετε τα δεδομένα σας όταν χρησιμοποιείτε δημόσιο δίκτυο Wi-Fi
- Για να διατηρήσετε τα δεδομένα περιήγησής σας ιδιωτικά, ώστε να μην αποκαλυφθούν στον πάροχο υπηρεσιών διαδικτύου και σε δημόσιους φορείς
- Για να αποκτήσετε πρόσβαση σε μη λογοκριμένο περιεχόμενο από διάφορες πηγές ανά τον κόσμο

## Σε τι διαφέρει το Outline από τα παραδοσιακά VPN;
 Οι πάροχοι υπηρεσιών διαδικτύου μπορούν εύκολα να εντοπίσουν και να αποκλείσουν παραδοσιακά VPN αναγνωρίζοντας κοινά πρωτόκολλα ασφαλείας ή/και μοτίβα όγκου επισκεψιμότητας. Το Outline είναι πιο ανθεκτικό επειδή έχει δημιουργηθεί με ένα πρωτόκολλο το οποίο έχει σχεδιαστεί με τέτοιον τρόπο, ώστε να είναι δύσκολος ο εντοπισμός του και, ως εκ τούτου, να είναι πιο δύσκολος ο αποκλεισμός του. Το Outline είναι ανθεκτικό σε εξειδικευμένες μορφές λογοκρισίας, συμπεριλαμβανομένου του αποκλεισμού βάσει δικτύου και του αποκλεισμού ΙΡ.

## Τι είναι ένας διακομιστής Outline;
 Ένας διακομιστής Outline εκτελεί το VPN στο οποίο θα συνδεθούν οι χρήστες που έχουν άδεια. Αν δημιουργείτε ένα νέο δίκτυο, μπορείτε να χρησιμοποιήσετε τον δικό σας ασφαλή διακομιστή ως τον διακομιστή Outline, εφόσον έχετε έναν, ή μπορείτε να χρησιμοποιήσετε έναν πάροχο υπηρεσιών cloud, όπως οι εξής:

- DigitalOcean
- Google Cloud Platform (GCP)
- Amazon Web Services (AWS)

Θα ρυθμίσετε τον διακομιστή σας στο Outline Manager.

## Τι είναι ένας διαχειριστής υπηρεσίας; {#servicemanager}
 Ένας διαχειριστής υπηρεσίας είναι το άτομο που είναι υπεύθυνο για τη ρύθμιση του διακομιστή Outline και την παροχή κλειδιών πρόσβασης στους χρήστες. Ο διαχειριστής υπηρεσίας είναι σε γενικές γραμμές υπεύθυνος για το κόστος της χρήσης του διακομιστή. 

## Τι είναι ένα κλειδί πρόσβασης; {#accesskey}
 Ένα κλειδί πρόσβασης χρησιμοποιείται για την πρόσβαση σε έναν υπάρχοντα διακομιστή Outline και τη σύνδεση στο VPN. Ο [διαχειριστής υπηρεσίας](#servicemanager) θα σας δώσει ένα κλειδί πρόσβασης ή μπορείτε να [ρυθμίσετε έναν διακομιστή Outline](/manager/server-setup/setup-server) μόνοι σας. Ακολουθεί ένα παράδειγμα της μορφής ενός κλειδιού πρόσβασης (πρόκειται απλώς για δείγμα και δεν λειτουργεί): 

 ss://Y2hhY2hhMjAtaWV0Zi1wb2x5MTMwNTp1eXhUQ3MzemVEMTk=@XXX.XXX.4.1:39485/?outline=1

## Τι είναι το Outline Manager;
 Το Outline Manager είναι μια εφαρμογή για υπολογιστές, η οποία επιτρέπει στον διαχειριστή υπηρεσίας να ρυθμίσει έναν διακομιστή Outline, να δημιουργήσει [κλειδιά πρόσβασης](#accesskey) και να ορίσει όρια δεδομένων σχετικά με τη χρήση ανά κλειδί. Μπορείτε να κατεβάσετε τη νεότερη έκδοση του Outline Manager [εδώ](https://getoutline.org/get-started/#step-3) ή[εδώ](https://www.reddit.com/r/outlinevpn/wiki/index/download_links/).

## Τι είναι το Outline Client;
 Το Outline Client είναι μια εφαρμογή, που είναι διαθέσιμη για υπολογιστές και κινητά, η οποία σας επιτρέπει να συνδέεστε σε έναν διακομιστή Outline και να αποκτάτε πρόσβαση στο VPN χρησιμοποιώντας ένα κλειδί πρόσβασης. Μπορείτε να κατεβάσετε τη νεότερη έκδοση του Outline Client [εδώ](https://getoutline.org/get-started/#step-3) ή[εδώ](https://www.reddit.com/r/outlinevpn/wiki/index/download_links/).

## Τι είναι τα όρια δεδομένων;
 Το Outline Manager επιτρέπει στους διαχειριστές υπηρεσίας να ορίζουν ένα όριο λήξης δεδομένων 30 ημερών για τα κλειδιά πρόσβασης, το οποίο αποτρέπει την κατάχρηση και συμβάλλει στη διατήρηση του κόστους εντός των προβλεπόμενων ορίων. Οι διαχειριστές υπηρεσίας μπορούν να ορίσουν ένα προεπιλεγμένο όριο που ισχύει για κάθε κλειδί, καθώς και να ορίσουν επίσης ένα διαφορετικό όριο για κάθε κλειδί, προκειμένου να παρακάμπτει το προεπιλεγμένο όριο. Μετά τη ρύθμισή του, το όριο αποκτά άμεση ισχύ και εφαρμόζεται σε ωριαία βάση.

Αν οι διαχειριστές υπηρεσίας επιλέξουν να μοιραστούν μετρήσεις με το Jigsaw, πρέπει να διαβάσουν την[πολιτική συλλογής δεδομένων](https://getoutline.org/policies/data-collection) για λεπτομέρειες σχετικά με την αναφορά της χρήσης των ορίων δεδομένων.
