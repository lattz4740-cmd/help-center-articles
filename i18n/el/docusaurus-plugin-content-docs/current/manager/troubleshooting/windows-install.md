Μπορεί να δείτε το εξής μήνυμα σφάλματος: "Δυστυχώς, φαίνεται ότι το Outline δεν έχει εγκατασταθεί σωστά. Δοκιμάστε να το εγκαταστήσετε ξανά. Αν αυτό δεν διορθώσει το πρόβλημα [υποβάλετε σχόλια](/about/feedback)".

Αν χρησιμοποιείτε το Outline στα Windows, μπορεί μερικές φορές να αντιμετωπίσετε ένα μη αναμενόμενο σφάλμα. Στις περισσότερες περιπτώσεις, θα πρέπει να διαγράψετε τον προσαρμογέα TAP του Outline (πρόγραμμα οδήγησης) και να επανεγκαταστήσετε το Outline.

Τα βήματα μπορεί να διαφέρουν ανάλογα με την έκδοση του λειτουργικού συστήματος Windows που χρησιμοποιείτε, αλλά παρακάτω αναφέρονται τα γενικά βήματα που μπορείτε να κάνετε για να απεγκαταστήσετε τον προσαρμογέα TAP και το Outline Manager και, έπειτα, να επανεγκαταστήσετε το Outline Manager.

1. Απεγκατάσταση του προσαρμογέα TAP για το Outline Manager
   1. Επιλέξτε Διαχείριση συσκευών και, έπειτα, Προσαρμογείς δικτύου.
   2. Εντοπίστε το αρχείο TAP-Windows Adapter V9 ή τον προσαρμογέα TAP που σχετίζεται με το Outline.
   3. Απεγκαταστήστε ή διαγράψτε αυτόν τον προσαρμογέα. Λάβετε υπόψη ότι αυτή η ενέργεια μπορεί να επηρεάσει άλλες εφαρμογές VPN που έχετε εγκαταστήσει.
2. Απεγκατάσταση του Outline Manager
   1. Επιλέξτε Προγράμματα και δυνατότητες και, έπειτα, Απεγκατάσταση προγράμματος.
   2. Εντοπίστε την εφαρμογή Outline Manager και απεγκαταστήστε την.
   3. [Κατεβάστε τη νεότερη έκδοση του Outline Manager](https://getoutline.org/get-started/#step-1) και επανεγκαταστήστε την στη συσκευή Windows. Με τη νέα εγκατάσταση, θα εγκατασταθεί αυτόματα ένας νέος προσαρμογέας TAP.

Αν εξακολουθείτε να αντιμετωπίζετε πρόβλημα, [επικοινωνήστε με την ομάδα υποστήριξης.](/about/feedback)
