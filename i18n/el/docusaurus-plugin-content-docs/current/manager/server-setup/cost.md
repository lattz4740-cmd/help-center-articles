Το λογισμικό Outline είναι δωρεάν για όλους, είτε είστε ένας διαχειριστής διακομιστή που διαχειρίζεται ένα VPN είτε κάποιος που χρησιμοποιεί το Outline για την πρόσβαση στο ανοικτό διαδίκτυο.

 Ωστόσο, για να είναι δυνατή η λειτουργία του Outline, απαιτείται πρόσβαση σε διακομιστή cloud. Οι διαχειριστές διακομιστών που έχουν ήδη πρόσβαση σε έναν διακομιστή μπορούν να εγκαταστήσουν το Outline σε αυτόν τον διακομιστή χωρίς πρόσθετο κόστος. Όσοι δεν έχουν πρόσβαση σε διακομιστή μπορούν να αποκτήσουν πρόσβαση από κάποιον πάροχο υπηρεσιών cloud, όπως η [DigitalOcean](https://www.digitalocean.com/) ή η Amazon Web Services, με κόστος περίπου 5 δολάρια ΗΠΑ τον μήνα για μεταφορά δεδομένων έως 1 terabyte. Αυτός ο όγκος αρκεί για την υποστήριξη εκατοντάδων χρηστών σε έναν διακομιστή.

 Το ακόλουθο παράδειγμα παρουσιάζει τον τρόπο με τον οποίο μπορείτε να υπολογίσετε το κόστος για τη χρήση του Outline με τον πάροχο cloud της επιλογής σας:

| *Εάν υποθέσουμε ότι ο μέσος όρος μεταφοράς δεδομένων ανά χρήστη είναι 5 GB τον μήνα, ένα πακέτο των 5 δολαρίων ΗΠΑ ανά μήνα θα μπορούσε να υποστηρίξει έως και 200 χρήστες ταυτόχρονα, διαμορφώνοντας έτσι το μηνιαίο κόστος ανά χρήστη μόλις στα 2,5 σεντς. Να έχετε υπόψη ότι ο μηνιαίος όγκος μεταφερόμενων δεδομένων ανά χρήστη μπορεί να παρουσιάζει μεγάλες διακυμάνσεις ανάλογα με το εύρος ζώνης που απαιτούν οι δραστηριότητες των χρηστών. Ωστόσο, οι περισσότεροι πάροχοι μπορούν να καλύψουν τις αυξήσεις στην επισκεψιμότητα.* |
| --- |

Στην πραγματικότητα, η χρήση του Outline γίνεται εντελώς ανώνυμα στο Jigsaw και την Google. Δεν προσδιορίζουμε την ταυτότητά σας ούτε παρακολουθούμε την επισκεψιμότητά σας και δεν έχουμε κάποιο σχέδιο δημιουργίας εσόδων. Αντίθετα, συνεργαζόμαστε με την κοινότητά μας λογισμικού ανοικτού κώδικα για να εξασφαλίσουμε ότι μπορούμε να παρέχουμε το λογισμικό χωρίς κόστος στους χρήστες μας.
