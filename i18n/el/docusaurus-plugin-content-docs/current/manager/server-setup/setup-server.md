Το πρώτο βήμα για τη χρήση του Outline είναι η ρύθμιση ενός διακομιστή Outline. Ρυθμίστε ή ζητήστε από κάποιον που εμπιστεύεστε να ρυθμίσει έναν διακομιστή, ώστε να έχετε τη δυνατότητα σύνδεσης στο ανοικτό διαδίκτυο μέσω του Outline.

**Πριν ξεκινήσετε**

 Πριν ξεκινήσετε τη διαδικασία ρύθμισης του διακομιστή Outline, θα χρειαστείτε τα εξής:

1. Πρόσβαση σε δικούς σας διακομιστές ή σε έναν πάροχο υπηρεσιών cloud, όπως το DigitalOcean, το Amazon Web Services (AWS) ή το Google Cloud Platform (GCP).

 Εάν δεν έχετε άμεση πρόσβαση σε έναν διακομιστή cloud, μπορείτε εύκολα να δημιουργήσετε έναν λογαριασμό σε οποιονδήποτε πάροχο, συμπεριλαμβανομένων αυτών που αναφέρονται παραπάνω. Θα χρειαστείτε πιθανώς μια πιστωτική κάρτα για να εγγραφείτε.
2. Έναν υπολογιστή με λειτουργικό σύστημα macOS 10.9+, Windows 7.0+ ή Linux.
3. Την εφαρμογή Outline Manager.

**Ρύθμιση με το DigitalOcean**

 Έχουμε απλοποιήσει τη διαδικασία εγκατάστασης του Outline στο DigitalOcean ώστε να γίνεται με μερικά κλικ. Αφού κατεβάσετε και εγκαταστήσετε το Outline Manager στον υπολογιστή σας, μπορείτε να χρησιμοποιήσετε την επιλογή ρύθμισης του DigitalOcean που θα σας βοηθήσει να ολοκληρώσετε τη διαμόρφωση και την εγκατάσταση του διακομιστή Outline σας μέσω μερικών απλών οθονών.

**Ρύθμιση με άλλον πάροχο cloud**

 Αφού κατεβάσετε και εγκαταστήσετε το Outline Manager στον υπολογιστή σας, μπορείτε να επιλέξετε την εγκατάσταση ενός διακομιστή Outline σε μια εικονική μηχανή με το AWS, το GCP, το DigitalOcean ή κάποιον άλλο πάροχο. Κάθε περιβάλλον είναι διαφορετικό, οπότε έχουμε συμπεριλάβει οδηγίες στη ροή ρύθμισης του Outline Manager για τους πιο συνηθισμένους παρόχους cloud, συμπεριλαμβανομένων οδηγιών για να διαμορφώσετε τις ρυθμίσεις της εικονικής μηχανής σας πριν από την εκτέλεση του σεναρίου εγκατάστασης για την εγκατάσταση του Outline σε έναν διακομιστή.
