**Μπορώ να χρησιμοποιήσω το Outline χωρίς διακομιστή;**

 Δυστυχώς, όχι. Το λογισμικό Outline απαιτεί πρόσβαση σε έναν διακομιστή, είτε η διαχείρισή του γίνεται από εσάς, τον οργανισμό σας είτε από κάποιο αξιόπιστο τρίτο μέρος.

## Πόσος χρόνος χρειάζεται για τη ρύθμιση ενός διακομιστή Outline;

Στις περισσότερες περιπτώσεις, λιγότερο από 5 λεπτά. Μπορείτε να εγκαταστήσετε το Outline σε οποιονδήποτε διακομιστή cloud. Ωστόσο, έχουμε συνεργαστεί με την DigitalOcean προκειμένου να σας προσφέρουμε μια φιλική, καθοδηγούμενη διαδικασία εγκατάστασης για να ολοκληρώσετε τη ρύθμιση του διακομιστή σας μόνο με μερικά κλικ.

Εάν επιλέξατε το AWS, το GCP ή μια σύνθετη ρύθμιση, έχουμε απλοποιήσει τη διαδικασία εγκατάστασης του διακομιστή σε ένα μόνο σενάριο που χειρίζεται τα περισσότερα περιβάλλοντα.

## Πού μπορώ να ρυθμίσω έναν διακομιστή Outline;

Μπορείτε να ρυθμίσετε έναν διακομιστή Outline στους περισσότερους παρόχους cloud οπουδήποτε λειτουργούν.

Η πιο εύκολη επιλογή είναι να τον ρυθμίσετε στην DigitalOcean, αφού έχει διακομιστές σε πολλές τοποθεσίες, όπως το Άμστερνταμ, το Τορόντο, το Σαν Φρανσίσκο και η Σιγκαπούρη. Εάν προτιμάτε να τον εγκαταστήσετε σε κάποιον άλλον πάροχο cloud ή στη δική σας υποδομή, μπορείτε να επιλέξτε τη Σύνθετη λειτουργία στην εφαρμογή Outline Manager και να ακολουθήσετε τις οδηγίες εγκατάστασης χρησιμοποιώντας ένα σενάριο ρύθμισης.

## Πού πρέπει να ρυθμίσω τον διακομιστή Outline;

1. Υπάρχουν ορισμένα ζητήματα που πρέπει να εξετάσετε κατά την επιλογή μιας τοποθεσίας για τον διακομιστή Outline:
2. Η τοποθεσία του διακομιστή Outline επηρεάζει την εμπειρία των χρηστών στο διαδίκτυο. Για παράδειγμα, εάν ο διακομιστής βρίσκεται στο Άμστερνταμ, ο χρήστης που έχει πρόσβαση στον διακομιστή θα έχει την αίσθηση ότι περιηγείται στο διαδίκτυο σαν να βρισκόταν στην Ολλανδία. Ορισμένοι ιστότοποι μπορεί μάλιστα να εμφανίζονται στα ολλανδικά. Συνήθως, μπορείτε να αλλάξετε την τοπική γλώσσα χρησιμοποιώντας τον επιλογέα γλώσσας του ιστοτόπου.
3. Η απόσταση ανάμεσα στους χρήστες και τον διακομιστή Outline μπορεί να επηρεάσει την ταχύτητα. Γενικά, η φυσική απόσταση ανάμεσα στoυς χρήστες του Outline και τον διακομιστή μπορεί να επηρεάσει την ταχύτητα του διαδικτύου για τους χρήστες. Στις περισσότερες περιπτώσεις, μπορείτε να επιλέξετε μια τοποθεσία διακομιστή όσο το δυνατόν πιο κοντά στους αναμενόμενους χρήστες. Ωστόσο, μπορείτε να χρησιμοποιήσετε τον χάρτη [Submarine Cable Map](https://www.submarinecablemap.com/) για να δείτε ποια καλώδια διαδικτύου συνδέονται με τη χώρα ή την περιοχή σας.
4. Η τοποθεσία του διακομιστή VPN μπορεί να επηρεάζει το νομικό πλαίσιο. Έχετε υπόψη ότι το λογισμικό Outline δεν καταγράφει την επισκεψιμότητά σας. Μάθετε περισσότερα σχετικά με την [ασφάλεια και το απόρρητο κατά τη χρήση του Outline](/about/security-and-privacy).
