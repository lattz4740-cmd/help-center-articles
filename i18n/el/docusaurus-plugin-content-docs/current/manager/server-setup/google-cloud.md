## Επισκόπηση

Το Outline Manager περιλαμβάνει μια λειτουργία που σας επιτρέπει να διαμορφώνετε αυτόματα τον διακομιστή Outline σε έναν διακομιστή που εκτελείται στο Google Cloud. Εάν επιλέξετε να χρησιμοποιήσετε αυτή τη λειτουργία, το Outline Manager θα σας ζητήσει να συνδεθείτε με τον Λογαριασμό σας Google από τον οποίο θα εκχωρήσετε ορισμένες άδειες[OAuth](https://developers.google.com/identity/protocols/oauth2) στην τοπική εγκατάσταση του Outline Manager για σκοπούς διαμόρφωσης του λογαριασμού σας Google Cloud.

 Εάν δεν θέλετε να παράσχετε αυτές τις άδειες, μπορείτε να ακολουθήσετε τις οδηγίες σύνθετης ρύθμισης στο Outline Manager για εκτέλεση του Outline στο Google Cloud Platform.

## Εκχώρηση αδειών

Για την αυτοματοποιημένη ρύθμιση, το Outline Manager ζητάει τις παρακάτω άδειες από τον Λογαριασμό σας Google.

## Google Cloud Platform

- Προβολή και διαχείριση των πόρων σας στη μηχανή Google Compute Engine
- Προβολή των δεδομένων σας σε υπηρεσίες του Google Cloud και της διεύθυνσης ηλεκτρονικού ταχυδρομείου του Λογαριασμού σας Google

## Βασικά στοιχεία λογαριασμού

- Προβολή της κύριας διεύθυνσης ηλεκτρονικού ταχυδρομείου του Λογαριασμού σας Google
- Συσχέτισή σας με τα προσωπικά στοιχεία σας στο Google

## Επιπλέον πρόσβαση

- Διαχείριση των έργων σας στο Cloud Platform
- Προβολή και διαχείριση των λογαριασμών χρέωσής σας στο Google Cloud Platform
- Διαχείριση της διαμόρφωσης υπηρεσίας API Google

Με αυτές τις άδειες, μπορούμε να υποστηρίζουμε σύνθετες λειτουργίες για τη διαχείριση των διακομιστών Outline, όπως:

- Δυνατότητα να επιλέγετε τον σωστό λογαριασμό χρέωσης
- Δημιουργία νέου έργου για την οργάνωση των διακομιστών Outline
- Εμφάνιση διαθέσιμων κέντρων δεδομένων
- Δημιουργία νέων εικονικών μηχανών για την εκτέλεση του Outline
- Διαμόρφωση της νέας εικονικής μηχανής με το Outline

## Ανάκληση αδειών

Μπορείτε να ανακαλέσετε την πρόσβαση στο Google Cloud Platform για το Outline Manager, μεταβαίνοντας στη σελίδα[Ο λογαριασμός μου](https://myaccount.google.com/permissions). Εάν ανακαλέσετε την πρόσβαση, τυχόν διακομιστές που έχετε δημιουργήσει με την αυτοματοποιημένη ρύθμιση θα συνεχίσουν να εκτελούνται, αλλά δεν θα εμφανίζονται πλέον στο Outline Manager. Για να επαναφέρετε την πρόσβαση σε αυτούς, απλώς συνδεθείτε ξανά στο Google Cloud Platform, ξεκινώντας τη ροή αυτόματης ρύθμισης.

## Οργάνωση έργου Outline

Η αυτοματοποιημένη ρύθμιση Google Cloud χρησιμοποιεί ένα μόνο[έργο Google Cloud](https://cloud.google.com/resource-manager/docs/creating-managing-projects) για την οργάνωση των διακομιστών Outline. Το έργο δημιουργείται κατά την πρώτη χρήση της αυτοματοποιημένης ρύθμισης, με ένα προτεινόμενο αναγνωριστικό έργου που ξεκινά με το "Outline-", ακολουθούμενο από μια συμβολοσειρά τυχαίων χαρακτήρων. Εάν το προτιμάτε, μπορείτε να επιλέξετε ένα διαφορετικό αναγνωριστικό έργου κατά τη δημιουργία. Το έργο θα ονομάζεται "Διακομιστές Outline".

## Λογαριασμός χρέωσης

Τα έργα Google Cloud απαιτούν έναν συνδεδεμένο λογαριασμό χρέωσης που καθορίζει τα στοιχεία πληρωμής. Όταν χρησιμοποιήσετε την αυτοματοποιημένη ρύθμιση Google Cloud για πρώτη φορά, θα σας ζητηθεί να καταχωρίσετε έναν λογαριασμό χρέωσης για συσχέτιση με τους διακομιστές Outline. Μερικές φορές, η λειτουργία ενός διακομιστή διακόπτεται, επειδή υπάρχει πρόβλημα με τον λογαριασμό χρέωσης. Σε αυτήν την περίπτωση, θα πρέπει να συνδεθείτε στο[Google Cloud Console](https://console.cloud.google.com/getting-started), να εντοπίσετε το έργο Google Cloud που σχετίζεται με το Outline (ονομάζεται "Διακομιστές Outline") και να ενημερώσετε τις ρυθμίσεις χρέωσης.

## Καταστροφή διακομιστών

Εάν θέλετε να καταστρέψετε τους διακομιστές που δημιουργήσατε χρησιμοποιώντας την αυτοματοποιημένη ρύθμιση, ο πιο εύκολος τρόπος να το κάνετε είναι από το Outline Manager. Ωστόσο, εάν θέλετε να καταστρέψετε οι ίδιοι τους διακομιστές, μπορείτε να συνδεθείτε στο[Google Cloud Console](https://console.cloud.google.com/getting-started), να βρείτε το έργο που δημιουργήθηκε κατά την αρχική ρύθμιση (με το όνομα "Διακομιστές Outline") και είτε να διαγράψετε εκεί τους πόρους είτε να τερματίσετε το έργο.
