Για να ρυθμίσετε πρόσθετους διακομιστές Outline κάντε κλικ στο εικονίδιο + στο πλαίσιο πλοήγησης στην αριστερή πλευρά της εφαρμογής Outline Manager. Οι οδηγίες για την προσθήκη ενός νέου διακομιστή είναι οι ίδιες με αυτές που ακολουθήσατε για την προσθήκη του πρώτου σας διακομιστή.

- Δεν υπάρχει περιορισμός στον αριθμό των διακομιστών Outline που μπορείτε να δημιουργήσετε.
- Για κάθε διακομιστή Outline που δημιουργείτε, θα χρειαστείτε μια αντίστοιχη εικονική μηχανή.
- Η δημιουργία πρόσθετων μηχανών και "σταγονιδίων" (droplets) μπορεί να αυξήσει την αμοιβή του παρόχου cloud. Εξετάστε το πακέτο τιμολόγησης του παρόχου cloud για να βεβαιωθείτε τι να περιμένετε.

## Δημιουργία πρόσθετου διακομιστή Outline στο DigitalOcean

Αφού κάνετε κλικ στο εικονίδιο + και επιλέξετε να κάνετε εγκατάσταση στο DigitalOcean, θα ακολουθήσετε τις ίδιες οδηγίες που ακολουθήσατε για τη ρύθμιση του πρώτου σας διακομιστή. Επιπλέον, καθώς το Outline Manager ενσωματώνεται με το DigitalOcean, θα μπορούσαμε να δημιουργήσουμε το "σταγονίδιο" (droplet) για λογαριασμό σας, χωρίς να χρειαστεί να αφήσετε την εφαρμογή Outline Manager.

Έχετε υπόψη ότι το Outline Manager υποστηρίζει τη χρήση μόνο ενός λογαριασμού DigitalOcean κάθε φορά. Εάν θέλετε να προσθέσετε ή να δημιουργήσετε άλλους διακομιστές Outline από άλλους λογαριασμούς DigitalOcean, μπορείτε να τους προσθέσετε στο πλαίσιο μιας σύνθετης διαμόρφωσης.

## Δημιουργία πρόσθετου διακομιστή Outline στο GCP, το AWS ή έναν άλλο πάροχο υπηρεσιών cloud

Ξεκινήστε δημιουργώντας μια νέα εικονική μηχανή στον πάροχο cloud της επιλογής σας. Στη συνέχεια, ανοίξτε το Outline Manager και ακολουθήστε τις οδηγίες σύνθετης εγκατάστασης, όπως είχατε κάνει και την πρώτη φορά.
