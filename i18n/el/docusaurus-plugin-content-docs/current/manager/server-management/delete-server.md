---
title: Πώς μπορώ να διαγράψω έναν διακομιστή Outline;
sidebar_label: Πώς μπορώ να διαγράψω έναν διακομιστή Outline;
---

Για τους περισσότερους παρόχους cloud, είναι αρκετά εύκολο να καταργήσετε τη συγκεκριμένη εικονική μηχανή που χρησιμοποιείτε.

Αν χρησιμοποιείτε την DigitalOcean ως πάροχο cloud, μπορείτε να διαγράψετε την υπάρχουσα εικονική μηχανή σας κάνοντας κλικ στο κουμπί με το γρανάζι και επιλέγοντας Destroy Server (Καταστροφή διακομιστή). Αμέσως μετά, θα σας ζητηθεί να δημιουργήσετε μια νέα εικονική μηχανή σε μια τοποθεσία της επιλογής σας.

Εάν καταργήσετε έναν διακομιστή Outline, ο διακομιστής θα διαγραφεί οριστικά και τα κλειδιά πρόσβασής του θα σταματήσουν να λειτουργούν. Αν δεν θέλετε να διακοπεί η πρόσβαση των χρηστών μέσω Outline, θα πρέπει να [ρυθμίσετε έναν νέο διακομιστή Outline](/manager/server-setup/setup-server) και να μοιραστείτε την πρόσβαση σε αυτόν πριν διαγράψετε τον παλιό διακομιστή.
