Οι διακομιστές Outline ενημερώνονται αυτόματα με τις νεότερες βελτιώσεις ασφαλείας, ώστε να χρησιμοποιείτε πάντα την πιο πρόσφατη τεχνολογία Outline. Η αυτοματοποιημένη διαδικασία ενημέρωσης γίνεται από το [Watchtower](https://github.com/v2tec/watchtower), μια βιβλιοθήκη με λογισμικό ανοικτού κώδικα, η οποία ελέγχει τακτικά και ενημερώνει την εικόνα του docker που περιέχει το λογισμικό Outline.

Επιπλέον, όταν εγκαταστήσετε το Outline χρησιμοποιώντας το Outline Manager, θα ρυθμίσουμε μια εργασία cron για να γίνεται αυτόματα αναβάθμιση του λογισμικού στον διακομιστή με τις [Αναβαθμίσεις χωρίς παρακολούθηση](https://wiki.debian.org/UnattendedUpgrades) (Ubuntu) και για να επανεκκινείται όταν χρειάζεται. Λάβετε υπόψη ότι αυτό δεν γίνεται στη Σύνθετη λειτουργία, ώστε να διατηρείται η υπάρχουσα διαμόρφωση, θεωρώντας ότι ο κεντρικός υπολογιστής χρησιμοποιείται για άλλους σκοπούς εκτός από την εκτέλεση του Outline.
