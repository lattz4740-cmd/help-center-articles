---

Το αναγνωριστικό διακομιστή δημιουργείται τυχαία από την πλευρά του διακομιστή, όταν δημιουργείτε έναν διακομιστή Outline. Μπορείτε να το βρείτε αν έχετε επιλέξει να συμμετάσχετε στην κοινοποίηση ανώνυμων μετρήσεων στη διεπαφή ρυθμίσεων. Για να εντοπίσετε το αναγνωριστικό διακομιστή, μεταβείτε στις Ρυθμίσεις, κάντε κύλιση μέχρι το κάτω μέρος της οθόνης και επιλέξτε Κοινοποίηση ανώνυμων μετρήσεων.

Το αναγνωριστικό διακομιστή συνδέει τα ανώνυμα στατιστικά στοιχεία χρήσης που αναφέρονται σταδιακά. Αν θέλετε να επαναφέρετε το αναγνωριστικό διακομιστή και να αποκτήσετε ένα νέο, θα πρέπει να αντικαταστήσετε τον υπάρχοντα διακομιστή Outline με έναν νέο.

Αν χρησιμοποιείτε την DigitalOcean ως πάροχο cloud, μπορείτε να επαναφέρετε τον διακομιστή σας επιλέγοντας Settings (Ρυθμίσεις) και Destroy Server (Καταστροφή διακομιστή). Αυτή η ενέργεια δεν μπορεί να αναιρεθεί και θα έχει ως αποτέλεσμα τη διαγραφή των διαπιστευτηρίων σας. Αμέσως μετά από αυτή την ενέργεια, θα σας ζητηθεί να δημιουργήσετε έναν νέο διακομιστή σε μια τοποθεσία της επιλογής σας και θα δημιουργηθεί ένα νέο αναγνωριστικό διακομιστή.
