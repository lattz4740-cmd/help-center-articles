---
title: Πώς μπορώ να αλλάξω την τοποθεσία του διακομιστή Outline;
sidebar_label: Πώς μπορώ να αλλάξω την τοποθεσία του διακομιστή Outline;
---

Η τοποθεσία ενός διακομιστή δεν μπορεί να αλλάξει μετά τη ρύθμισή της. Αν θέλετε να λειτουργεί ο διακομιστής σας από διαφορετική τοποθεσία, πρέπει να διαγράψετε τον τρέχοντα διακομιστή σας Outline και να δημιουργήσετε έναν νέο.

Εναλλακτικά, μπορείτε να αλλάξετε την τοποθεσία του VPN σας χρησιμοποιώντας [δυναμικά κλειδιά](https://developer.getoutline.org/vpn/management/dynamic-access-keys/), τα οποία σας επιτρέπουν να εναλλάσσετε τους διακομιστές και να χρησιμοποιείτε τα ίδια κλειδιά. Η τοποθεσία των ίδιων των διακομιστών δεν θα αλλάζει.
