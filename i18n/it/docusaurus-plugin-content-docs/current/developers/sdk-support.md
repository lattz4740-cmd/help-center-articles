---
title: "Sono uno sviluppatore. Dove posso trovare assistenza per l'integrazione di Outline SDK nella mia applicazione?"
sidebar_label: "Sono uno sviluppatore. Dove posso trovare assistenza per l'integrazione di Outline SDK nella mia applicazione?"
---

Questo sito web di assistenza è rivolto agli utenti di Outline Manager e Client. Gli sviluppatori possono usare GitHub per l'assistenza. Per porre una domanda, pubblica un post nella [bacheca di discussione](https://github.com/Jigsaw-Code/outline-sdk/discussions) dell'SDK. La sezione della bacheca di discussione è un ottimo posto per porre domande, condividere idee, fornire link a demo e assistere altri sviluppatori che utilizzano Outline SDK. Per richieste di funzionalità o segnalazioni di bug, apri invece un [Problema](https://github.com/Jigsaw-Code/outline-sdk/issues/new).
