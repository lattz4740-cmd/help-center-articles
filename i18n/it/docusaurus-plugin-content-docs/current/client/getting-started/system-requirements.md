title: "Quali sono i requisiti di sistema per eseguire il client Outline?"
sidebar_label: "Quali sono i requisiti di sistema per eseguire il client Outline?"
---

Puoi provare Outline su qualsiasi sistema operativo. Di seguito sono indicati i requisiti minimi di versione:

| **Sistema operativo** | **Versione minima** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Vuoi aiutarci a far funzionare il client Outline su più sistemi operativi? [Contribuisci al nostro codebase](https://github.com/Jigsaw-Code/outline-client#platform-specific-development) su GitHub.
