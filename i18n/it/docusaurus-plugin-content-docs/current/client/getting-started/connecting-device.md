---
title: Connettere il dispositivo a un server Outline
sidebar_label: Connettere il dispositivo a un server Outline
---

Per connettere il tuo dispositivo a un server Outline, un amministratore del server deve mandarti un invito a connetterti al server con una

univoca. Questo invito:

- Ti chiederà di scaricare e installare Outline sul dispositivo, nel caso tu non lo abbia già
- Utilizzerà la chiave di accesso per generare una connessione sicura tre te e il server Outline

Una volta stabilita la connessione al server, puoi fare clic su "Connettiti" o "Disconnettiti" per utilizzare Outline.

: Outline non funziona senza una chiave di accesso e un server Outline. Scaricare e installare Outline senza disporre di una chiave non è sufficiente a proteggere il tuo traffico Internet.
