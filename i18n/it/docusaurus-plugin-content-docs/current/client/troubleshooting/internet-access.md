---
title: "Perché non posso accedere a internet anche se la connessione al server Outline è attiva?"
sidebar_label: "Perché non posso accedere a internet anche se la connessione al server Outline è attiva?"
---

Se utilizzi un cellulare, prova a passare dalla connessione Wi-Fi ai dati mobili e vice versa. A volte, un tipo di connessione funziona e l'altro no. Se utilizzi un computer, prova a disconnetterti dalla banda larga e poi a connetterti di nuovo.

Se continui a riscontrare difficoltà, è probabile che ci sia un problema con il tuo server Outline. Contatta il [gestore del servizio](/about/terminology) per una nuova chiave di accesso per un server alternativo. Potrebbe anche aumentare il limite di dati della [chiave di accesso](/about/terminology) se la chiave ha superato la propria quota.
