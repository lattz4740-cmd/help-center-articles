Il primo passo per poter utilizzare Outline è la configurazione di un server. Per poterti connettere liberamente a Internet tramite Outline devi configurare un server o farlo configurare da qualcuno di cui ti fidi.

## Prima di iniziare

Prima di iniziare a configurare il server Outline, avrai bisogno di alcune cose:

1. L'accesso ai tuoi server o a un provider di server cloud, come DigitalOcean, Amazon Web Services (AWS) o Google Cloud Platform (GCP).

    Se al momento non hai accesso a un cloud server, puoi facilmente configurare un account con qualsiasi provider, inclusi quelli sopra elencati. Probabilmente avrai bisogno di una carta di credito per registrarti.
2. Un computer desktop con macOS 10.9 o versioni successive, Windows 7.0 o versioni successive o Linux.
3. L'applicazione Outline Manager.

## Configurare il server con DigitalOcean

Abbiamo reso semplice per chiunque installare Outline su DigitalOcean in pochi clic. Dopo aver scaricato e installato Outline Manager sul tuo computer, puoi selezionare l'opzione di configurazione di DigitalOcean, che ti guiderà attraverso alcune semplici schermate per configurare e installare il server Outline.

## Configurare il server con un altro provider di soluzioni cloud

Dopo aver scaricato e installato Outline Manager, puoi scegliere di installare un server Outline su una macchina virtuale con AWS, GCP, DigitalOcean o un altro provider. Ogni ambiente è diverso, quindi abbiamo inserito istruzioni all'interno del flusso di installazione di Outline Manager per i provider di soluzioni cloud più diffusi, incluse istruzioni su come configurare le impostazioni sulla macchina virtuale prima di eseguire lo script per installare Outline su un server.
