## Posso utilizzare Outline senza un server?

Purtroppo no. Il software Outline richiede l'accesso a un server, indipendentemente dal fatto che sia gestito da te, dalla tua organizzazione o da una terza parte attendibile.

## Quanto tempo ci vuole per configurare un server Outline?

Nella maggior parte dei casi, meno di 5 minuti. Puoi installare Outline su qualsiasi server cloud, ma abbiamo collaborato con DigitalOcean per offrire un'esperienza di installazione guidata più intuitiva che permette di configurare il server in pochi clic, senza script.

Se hai scelto AWS, GCP o una configurazione avanzata, abbiamo semplificato il processo di installazione del server in un singolo script che gestisce la maggior parte degli ambienti.

## Su quale provider posso configurare un server Outline?

Puoi configurare un server Outline tramite la maggior parte dei provider di soluzioni cloud ovunque essi operino.

 L'opzione più semplice è configurarlo su DigitalOcean, in quanto dispone di server in diverse località, come Amsterdam, Toronto, San Francisco e Singapore. Se preferisci installarlo su un altro provider di soluzioni cloud o sulla tua infrastruttura, puoi scegliere la "Modalità avanzata" nell'applicazione Outline Manager e seguire le istruzioni per l'installazione utilizzando uno script per la configurazione.

## Dove dovrei configurare il mio server Outline?

Ci sono alcune considerazioni da fare quando si seleziona una località per il server Outline:

1. La scelta della località del server Outline ha un impatto sull'esperienza di navigazione degli utenti. Ad esempio, se un utente accede a Internet utilizzando un server che si trova ad Amsterdam, la sua esperienza di navigazione sarà uguale a quella degli utenti che si trovano fisicamente nei Paesi Bassi. Alcuni siti web potrebbero essere mostrati in olandese. Generalmente puoi eseguire l'override della lingua locale utilizzando il selettore della lingua del sito web.
2. La distanza tra gli utenti e il server Outline potrebbe influire sulla tua velocità. In generale, la distanza fisica tra gli utenti Outline e il server può influire sulla velocità di Internet per gli utenti. Nella maggior parte dei casi, puoi scegliere una località del server vicina a quella in cui supponi che si troveranno gli utenti, ma puoi controllare la [mappa dei cavi sottomarini](https://www.submarinecablemap.com/) per vedere quali cavi Internet si collegano al tuo paese o alla tua area geografica.
3. La località in cui si trova il tuo server VPN determina le leggi e le norme applicabili. Tieni presente che il software Outline non registra il tuo traffico. Ulteriori informazioni su [sicurezza e privacy mentre utilizzi Outline](/about/security-and-privacy).
