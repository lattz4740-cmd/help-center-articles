---
title: "Quanto costa eseguire Outline?"
sidebar_label: "Quanto costa eseguire Outline?"
---

Il software Outline è gratuito per chiunque, sia per gli amministratori dei server che gestiscono la VPN sia per gli utenti che utilizzano Outline per accedere liberamente a Internet.

 Per poter eseguire Outline, è richiesto un accesso a un cloud server. Gli amministratori dei server che hanno già accesso a un server possono installarvi Outline senza costi aggiuntivi. Chi non ha accesso a un server può ottenerlo da un provider di soluzioni cloud, come [DigitalOcean](https://www.digitalocean.com/) o Amazon Web Services, a un prezzo di circa $ 5 al mese per 1 TB di trasferimento di dati, una quantità sufficiente a supportare centinaia di utenti su un singolo server.

 Ecco un esempio di come puoi calcolare quanto costerebbe eseguire Outline con il provider di soluzioni cloud che hai scelto.

| *Supponendo un utilizzo medio mensile di 5 GB di trasferimento dati per utente, un piano di $ 5 al mese permetterebbe circa 200 utenti simultanei e il costo per ogni utente sarebbe di soli 2,5 cent al mese. Tieni presente che il trasferimento di dati utilizzato al mese da ogni utente varia notevolmente a seconda che gli utenti eseguano attività a bassa o alta larghezza di banda, ma la maggior parte dei provider di soluzioni cloud si adatterà per far fronte all'aumento del traffico.* |
| --- |

Di fatto, l'utilizzo di Outline è completamente anonimo per Jigsaw e Google. Non tracciamo la tua identità o il traffico e non esiste un piano di monetizzazione. Lavoriamo invece con la nostra comunità open source per assicurarci di poter fornire il software senza costi per i nostri utenti. Ulteriori informazioni sui dati che raccogliamo [qui](https://getoutline.org/policies/data-collection).
