---
title: Come configurare più server Outline
sidebar_label: Come configurare più server Outline
---

Per configurare altri server Outline, fai clic sull'icona "+" sul pannello di navigazione sul lato sinistro della tua applicazione Outline Manager. Le istruzioni per aggiungere un nuovo server sono uguali a quelle che hai seguito quando hai installato il primo.

- Non esiste un limite al numero di server Outline che puoi creare.
- Per ogni server Outline che crei, avrai bisogno di una macchina virtuale corrispondente.
- La creazione di macchine o droplet aggiuntive potrebbe aumentare le tariffe del provider di soluzioni cloud. Verifica i prezzi del pacchetto con il provider di soluzioni cloud per assicurarti di sapere cosa ti aspetta.

## Creare un server Outline aggiuntivo su DigitalOcean

Dopo aver fatto clic sull'icona "+" e aver selezionato l'installazione su DigitalOcean, seguirai le stesse istruzioni utilizzate per configurare il tuo primo server. Poiché Outline Manager si integra con DigitalOcean, siamo in grado di creare una droplet per te senza che tu debba uscire da Outline Manager.

 Tieni presente che Outline Manager può supportare solo un account DigitalOcean alla volta. Se vuoi aggiungere o creare altri server Outline da altri account DigitalOcean, puoi aggiungerli come configurazione avanzata.

## Creare un server Outline aggiuntivo su GCP, AWS o un altro provider di soluzioni cloud

Inizia creando una nuova macchina virtuale con il provider di soluzioni cloud che hai scelto. Quindi apri Outline Manager e completa le istruzioni per l'installazione avanzata, come hai fatto la prima volta.
