---
title: "Gestire l'accesso a un server Outline con le chiavi di accesso"
sidebar_label: "Gestire l'accesso a un server Outline con le chiavi di accesso"
---

Una volta che hai finito di installare il server Outline, puoi iniziare a condividere e gestire l'accesso degli utenti. Chi riceve il tuo invito può scaricare l'app Outline e utilizzarla per proteggere il proprio traffico internet.

**Condividere l'accesso al tuo server Outline**

 Dopo aver completato l'installazione di un server Outline, passerai alla pagina dei dettagli del server in Outline Manager, dove potrai creare le chiavi di accesso. Scopri di più sulle [chiavi di accesso](/about/terminology).

- Per creare chiavi: fai clic sulla piccola icona "+" in fondo alla pagina per creare nuove chiavi.
- Per condividere le chiavi: fai clic sull'icona di condivisione a destra di ogni chiave per generare un invito. Copia e incolla questo invito nel sistema di messaggistica che preferisci.

**Richiesta di funzionalità: condividere l'accesso direttamente dall'app Outline Manager**

 Molti amministratori di server ci chiedono di semplificare il processo di invito dando loro la possibilità di inserire un indirizzo email direttamente in Outline Manager.

Purtroppo è improbabile che svilupperemo questa funzionalità in Outline Manager. Uno dei nostri principi fondamentali è quello di supportare la privacy e la sicurezza dei nostri utenti, il che significa che non abbiamo progettato nessun campo in cui inserire indirizzi email o informazioni di contatto.

Questo è il motivo per cui chiediamo agli amministratori di server di utilizzare una piattaforma di messaggistica affidabile, come email o chat sicure, per inviare l'invito all'utente finale.

**Cosa deve fare l'utente con cui hai condiviso una chiave di accesso**

1. L'utente farà clic sul link di installazione dal proprio dispositivo.
2. Se non ha già installato Outline, gli verrà chiesto di farlo.
3. Stabilirà una connessione iniziale al tuo server Outline tramite la chiave univoca incorporata nell'invito.
4. A questo punto potrà utilizzare il pulsante Connetti/Disconnetti per gestire il proprio accesso a internet tramite il tuo server Outline.

**Rimuovere l'accesso al tuo server Outline**

 Nella pagina dei dettagli del server in Outline Manager, a destra di ogni chiave sul server vedrai un menu con l'opzione per eliminarla. Quando elimini una chiave rimuovi il suo accesso al tuo server.
