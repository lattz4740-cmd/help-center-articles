---
title: "Come faccio a modificare la località del server Outline?"
sidebar_label: "Come faccio a modificare la località del server Outline?"
---

Una volta configurata, la località del server non può essere modificata. Per gestire il server da una località diversa, devi eliminare il server Outline e crearne uno nuovo.

In alternativa, puoi modificare la località della VPN utilizzando le [chiavi dinamiche](https://developers.google.com/outline/docs/guides/service-providers/dynamic-access-keys), che ti consentono di alternare i server mantenendo le stesse chiavi. La località dei server stessi non cambierà.
