---
title: "Come faccio a eliminare il mio server Outline?"
sidebar_label: "Come faccio a eliminare il mio server Outline?"
---

Per la maggior parte dei provider di soluzioni cloud, è abbastanza facile rimuovere la macchina virtuale specifica che stai utilizzando.

Se utilizzi DigitalOcean come provider cloud, puoi eliminare la macchina virtuale esistente facendo clic sul pulsante a forma di ingranaggio e selezionando **Elimina server**. Subito dopo, ti verrà richiesto di creare una nuova macchina virtuale in una località scelta da te.

Se rimuovi un server Outline, verrà eliminato in modo permanente e le sue chiavi di accesso smetteranno di funzionare. Se non vuoi che gli utenti sperimentino un'interruzione quando accedono tramite Outline, dovrai [configurare un nuovo server Outline](/manager/server-setup/setup-server) e condividerne l'accesso prima di eliminare il server precedente.
