title: Come inviare feedback o suggerimenti
sidebar_label: Come inviare feedback o suggerimenti
---

Grazie per il tuo contributo al miglioramento di Outline. Ci sono alcuni modi per inviarci feedback, in modo anonimo o con la tua email (se hai bisogno di una risposta):

- **Per gli sviluppatori**: Outline è un software open source e i nostri codici sono tutti ospitati su [GitHub](https://github.com/Outline-Foundation/?q=outline). Puoi condividere le tue idee su GitHub o nella nostra community [Reddit](https://www.reddit.com/r/outlinevpn/).
- **Per gli utenti**: puoi inviarci feedback tramite le app Outline o Outline Manager. Lasciaci il tuo feedback e, se vuoi, inserisci un indirizzo email per permetterci di risponderti. Raccogliamo anche alcuni metadati sul tuo ambiente per poterti aiutare con la risoluzione dei problemi, ad esempio browser, sistema operativo e la versione software che stai utilizzando.
- **Tramite questo sito**: puoi fare clic su qualsiasi link Contattaci all'interno del nostro sito.
- **Problemi gravi**: se vuoi segnalarci un grave problema di sicurezza, scrivici tutti i dettagli all'indirizzo security [chiocciola] [getoutline.org](https://getoutline.org/).

Grazie ancora per aver condiviso le tue opinioni con noi.
