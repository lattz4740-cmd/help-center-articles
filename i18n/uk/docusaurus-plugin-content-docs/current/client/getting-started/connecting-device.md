## Як підключити пристрій до сервера Outline

Щоб ви могли підключити пристрій до сервера Outline, адміністратор сервера має надіслати вам запрошення на підключення за допомогою унікального [ключа доступу](/about/terminology). У цьому запрошенні буде:

- пропозиція завантажити й установити додаток Outline на ваш пристрій (якщо у вас його ще немає);
- ключ доступу, потрібний для встановлення захищеного підключення між вами й сервером Outline.

Установивши з’єднання із сервером, далі просто натискайте "Підключити" або "Відключити", щоб використовувати Outline.

*Важливо.* Додаток Outline не працює без ключа доступу й сервера Outline. Якщо ви завантажите й установите цей додаток без ключа, ваш інтернет-трафік не буде захищено.
