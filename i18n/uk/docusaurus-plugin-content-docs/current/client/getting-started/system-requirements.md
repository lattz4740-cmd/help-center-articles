sidebar_label: "Які операційні системи підтримує додаток Клієнт Outline?"
---

Ви можете запускати Outline у будь-якій операційній системі. Нижче перелічено мінімальні підтримувані версії.

| **Операційна система** | **Мінімальна версія** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Хочете, щоб додаток Клієнт Outline працював в інших операційних системах? [Долучайтесь до роботи над кодовою базою](https://github.com/OutlineFoundation/outline-client#platform-specific-development) в сервісі GitHub!
