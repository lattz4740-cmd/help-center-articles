sidebar_label: "Я розробник. Де можна отримати допомогу з інтеграцією Outline SDK у свій додаток?"
---

Цей вебсайт призначено для користувачів Диспетчера Outline і клієнтів. Розробники можуть отримати підтримку на сайті GitHub. Щоб поставити запитання, опублікуйте його на [дошці обговорень](https://github.com/Jigsaw-Code/outline-sdk/discussions) SDK. На ній можна ставити запитання, ділитись ідеями, давати посилання на демо й підтримувати інших розробників, які використовують Outline SDK. Щоб надіслати запит на додавання функції або повідомити про помилку, перейдіть у розділ [Issue (Проблема)](https://github.com/Jigsaw-Code/outline-sdk/issues/new).
