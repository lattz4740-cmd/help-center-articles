---
title: "Як змінити місцеположення сервера Outline?"
sidebar_label: "Як змінити місцеположення сервера Outline?"
---

Змінювати місцеположення сервера після його налаштування не можна. Для цього потрібно видалити сервер Outline і створити новий.

Натомість можна змінити місцеположення VPN-сервера за допомогою [динамічних ключів](https://developers.google.com/outline/docs/guides/service-providers/dynamic-access-keys). Вони дають змогу вибрати інше місцеположення, зберігши ключі. При цьому місцеположення серверів не змінюється.
