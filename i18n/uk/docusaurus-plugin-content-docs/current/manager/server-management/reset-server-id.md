---
title: "Як скинути ідентифікатор сервера?"
sidebar_label: "Як скинути ідентифікатор сервера?"
---

Ідентифікатор генерується у випадковому порядку під час створення сервера Outline. Щоб знайти цей ідентифікатор, увімкніть надсилання анонімних показників в інтерфейсі "Settings" (Налаштування). Відкрийте налаштування, прокрутіть екран униз і виберіть "share anonymous metrics" (Надати доступ до анонімної статистики).

Ідентифікатор сервера об’єднує зібрану анонімну статистику використання. Якщо ви хочете скинути ідентифікатор сервера й отримати новий, потрібно налаштувати новий сервер Outline замість наявного.

Якщо ви користуєтеся програмним забезпеченням DigitalOcean, щоб скинути сервер, виберіть Settings (Налаштування), а потім – Destroy Server (Вилучити сервер). Цю дію не можна відмінити, і всі ваші облікові дані буде стерто. Відразу після цього вам буде запропоновано створити новий сервер у вибраному вами розташуванні, після чого система згенерує новий ідентифікатор.
