---
title: "Як видалити сервер Outline?"
sidebar_label: "Як видалити сервер Outline?"
---

Більшість постачальників хмарних сервісів можуть легко вилучити певну віртуальну машину, яку ви використовуєте.

Якщо ви користуєтеся програмним забезпеченням DigitalOcean, для видалення наявної віртуальної машини натисніть кнопку шестірні й виберіть опцію Destroy Server (Вилучити сервер). Відразу після цього вам буде запропоновано створити нову віртуальну машину у вибраному вами розташуванні.

Вилучений сервер Outline видаляється назавжди, а всі ключі доступу до нього стають недійсними. Якщо ви не хочете переривати роботу користувачів із сервером Outline, тоді перш ніж видаляти його, [створіть новий сервер Outline](/manager/server-setup/setup-server) і надайте до нього доступ.
