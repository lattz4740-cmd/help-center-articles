Установивши сервер Outline, ви зможете керувати доступом до нього. Запрошені вами користувачі повинні завантажити додаток Outline, щоб використовувати цей сервер для захисту свого інтернет-трафіку.

**Як надати доступ до сервера Outline**

 Закінчивши встановлення сервера Outline, ви перейдете на його сторінку в Диспетчері Outline, де зможете створювати ключі доступу. Докладніше про [ключі доступу](/about/terminology).

- Щоб створити ключ, унизу сторінки натисніть маленький значок плюса (+).
- Щоб надіслати ключ, натисніть значок доступу праворуч від ключа. З’явиться запрошення. Скопіюйте й вставте його у вибрану вами систему обміну повідомленнями.

**Запит на додавання функції: надання доступу з додатка Диспетчер Outline**

 Багато адміністраторів серверів просять нас спростити процес запрошення, надавши можливість указувати електронні адреси користувачів безпосередньо в Диспетчері Outline.

Найімовірніше, ми не зможемо додати цю функцію в Диспетчер Outline. Гарантування конфіденційності та безпеки користувачів – один із наших основних принципів, тому ми не передбачили можливості вставлення електронних адрес чи контактної інформації.

Саме тому для надсилання запрошень кінцевим користувачам ми просимо адміністраторів серверів використовувати безпечну платформу для обміну повідомленнями (наприклад, електронну пошту чи захищений чат).

**Як діє користувач після отримання ключа доступу**

1. На своєму пристрої користувач повинен натиснути посилання для встановлення.
2. З'явиться пропозиція встановити додаток Outline (якщо користувач ще не має його).
3. За допомогою унікального ключа, вставленого в запрошення, користувач установить початкове з'єднання із сервером Outline.
4. Далі користувач зможе використовувати кнопку підключення/відключення, щоб керувати своїм доступом до Інтернету через сервер Outline.

**Як скасувати доступ до сервера Outline**

 Відкрийте сторінку сервера в Диспетчері Outline. Праворуч від кожного ключа доступу ви можете вибрати опцію "Видалити". Якщо ви видалите ключ, то втратите доступ до сервера.
