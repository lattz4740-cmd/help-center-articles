---
title: Як налаштувати кілька серверів Outline
sidebar_label: Як налаштувати кілька серверів Outline
---

Щоб налаштувати додаткові сервери Outline, на панелі навігації в лівій частині додатка Диспетчер Outline натисніть значок "+". Процедура додавання нового сервера така сама, як і для встановлення першого сервера.

- Ви можете створити будь-яку кількість серверів Outline.
- Для кожного створеного сервера Outline потрібна відповідна віртуальна машина.
- За створення додаткових машин чи дроплетів (віртуальних серверів) ваш постачальник хмарних сервісів може стягувати плату. Щоб дізнатися більше, зверніться до свого постачальника хмарних сервісів.

## Як створити додатковий сервер Outline через інфраструктуру DigitalOcean

Якщо ви натиснули значок "+" і вибрали встановлення через DigitalOcean, вам потрібно виконати ті самі вказівки, що й для налаштування першого сервера. Оскільки додаток Диспетчер Outline сумісний із програмним забезпеченням DigitalOcean, ми також можемо створити для вас дроплет прямо в Диспетчері Outline.

Зверніть увагу: у Диспетчері Outline не можна одночасно використовувати кілька облікових записів DigitalOcean. Якщо ви хочете додати або створити сервери Outline з інших облікових записів DigitalOcean, їх потрібно додати як розширену конфігурацію.

## Як створити додатковий сервер Outline через GCP, AWS або іншого постачальника хмарних послуг

Спершу створіть нову віртуальну машину, використовуючи вибраного постачальника хмарних сервісів. Потім відкрийте Диспетчер Outline і виконайте ті самі вказівки зі встановлення, що й для першого сервера.
