## Огляд

Диспетчер Outline містить функцію, яка дає змогу автоматично налаштовувати сервер Outline на сервері Google Cloud. Щоб користуватися цією функцією, потрібно ввійти в Диспетчер Outline із даними облікового запису Google. Тоді ваша локальна версія Диспетчера Outline отримає певні дозволи [OAuth](https://developers.google.com/identity/protocols/oauth2), потрібні для налаштування облікового запису Google Cloud.

 Якщо ви не хочете надавати ці дозволи, виконайте вказівки з розширеного налаштування в Диспетчері Outline, щоб запустити Outline на Google Cloud Platform.

## Які дозволи надаються

Для автоматичного налаштування Диспетчеру Outline потрібні перелічені нижче дозволи від вашого облікового запису Google.

## Google Cloud Platform

- Перегляд ресурсів Google Compute Engine і керування ними
- Перегляд ваших даних у сервісах Google Cloud, а також електронної адреси вашого облікового запису Google

## Основні дані облікового запису

- Перегляд основної електронної адреси облікового запису Google
- Зв’язування вас із вашою особистою інформацією в Google

## Додатковий доступ

- Керування проектами Cloud Platform
- Перегляд платіжних облікових записів Google Cloud Platform і керування ними
- Керування конфігурацією сервісу, що використовує Google API

Завдяки цим дозволам ми можемо підтримувати розширені функції для керування вашими серверами Outline, зокрема:

- можливість вибирати потрібний платіжний обліковий запис;
- створення нового проекту для організації серверів Outline;
- створення списку доступних центрів обробки даних;
- створення нових віртуальних машин для запуску Outline;
- налаштування нових віртуальних машин за допомогою Outline.

## Як скасувати дозволи

Ви можете скасувати доступ Диспетчера Outline до Google Cloud Platform у розділі [Мій обліковий запис](https://myaccount.google.com/permissions). Якщо ви це зробите, усі сервери, створені за допомогою автоматичного налаштування, далі працюватимуть, але більше не відображатимуться в Диспетчері Outline. Щоб відновити доступ до них, знову під’єднайтеся до Google Cloud Platform, почавши процес автоматичного налаштування.

## Як організовувати проекти Outline

Під час першого автоматичного налаштування в Google Cloud створюється єдиний [проект](https://cloud.google.com/resource-manager/docs/creating-managing-projects) для організації серверів Outline. Йому присвоюється пропонований ідентифікатор, який починається з Outline- і далі містить рядок випадкових символів. Під час створення проекту можна вибрати інший ідентифікатор. Проект називатиметься Outline servers.

## Що таке платіжний обліковий запис

Для проектів Google Cloud потрібен зв’язаний обліковий запис із платіжною інформацією. Під час першого автоматичного налаштування в Google Cloud потрібно буде вказати платіжний обліковий запис, який можна зв’язати із серверами Outline. Іноді сервер припиняє роботу через проблему з платіжним обліковим записом. У такому випадку потрібно ввійти в [Google Cloud Console](https://console.cloud.google.com/getting-started), знайти проект Google Cloud, зв’язаний з Outline (з назвою Outline servers), і оновити налаштування платежів.

## Як знищити сервери

Сервери, створені за допомогою автоматичного налаштування, найпростіше знищити в Диспетчері Outline. Однак якщо ви хочете зробити це самостійно, увійдіть у [Google Cloud Console](https://console.cloud.google.com/getting-started), знайдіть проект, створений під час початкового налаштування (з назвою Outline servers), і видаліть його ресурси або закрийте проект.
