Ez az ügyfélszolgálati webhely az Outline Manager és a kliens felhasználóinak szól. Kérjük a fejlesztőket, hogy a GitHubon keressenek támogatást. Ha kérdése van, tegye fel az SDK [Vita fórumán](https://github.com/Jigsaw-Code/outline-sdk/discussions). A Vita fórum szakasz nagyszerű hely arra, hogy kérdéseket tegyen fel, ötleteket osszon meg, demókra mutató linkeket adjon meg, és segítsen az Outline SDK-t használó többi fejlesztőnek. Funkciókérések vagy hibajelentések esetén inkább jelentsen be egy [problémát](https://github.com/Jigsaw-Code/outline-sdk/issues/new).
