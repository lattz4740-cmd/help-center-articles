sidebar_label: "Mik a rendszerkövetelmények az Outline ügyfélalkalmazás futtatásához?"
---

Az Outline-t bármilyen operációs rendszeren kipróbálhatja. Az operációs rendszerekre vonatkozó minimális követelmények a következők:

| **Operációs rendszer** | **Minimális verzió** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Szeretne segíteni abban, hogy az Outline ügyfélalkalmazás más operációs rendszereken is működjön? [Vegyen részt programkódunk fejlesztésében](https://github.com/Jigsaw-Code/outline-client#platform-specific-development) a GitHubon!
