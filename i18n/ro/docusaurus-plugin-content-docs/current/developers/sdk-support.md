title: "Sunt dezvoltator. Unde pot găsi asistență pentru integrarea Outline SDK în aplicație?"
sidebar_label: "Sunt dezvoltator. Unde pot găsi asistență pentru integrarea Outline SDK în aplicație?"
---

Acest site de asistență este destinat utilizatorilor Outline Manager și Client. Dezvoltatorii pot să folosească GitHub pentru asistență. Pentru a pune o întrebare, postați pe [Forumul de discuții](https://github.com/Jigsaw-Code/outline-sdk/discussions) SDK. Secțiunea Forum de discuții este un loc excelent pentru a pune întrebări, a comunica idei, a trimite linkuri către versiuni demonstrative și a sprijini alți dezvoltatori care folosesc Outline SDK. Pentru solicitări de funcții sau rapoarte de erori, deschideți un [Tichet](https://github.com/Jigsaw-Code/outline-sdk/issues/new).
