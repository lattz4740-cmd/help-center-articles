---
title: "Care sunt cerințele de sistem pentru a rula clientul Outline?"
sidebar_label: "Care sunt cerințele de sistem pentru a rula clientul Outline?"
---

Puteți încerca Outline pe orice sistem de operare. Următoarele sunt versiunile minime necesare pentru sistemele de operare:

| **Sistem de operare** | **Versiunea minimă** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Doriți să ajutați aplicația Outline Client să funcționeze pe mai multe sisteme de operare? [Contribuiți la baza de cod](https://github.com/Outline-Foundation/outline-client#platform-specific-development) de pe GitHub!
