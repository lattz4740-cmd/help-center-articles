---
title: "Cum șterg serverul Outline?"
sidebar_label: "Cum șterg serverul Outline?"
---

Majoritatea furnizorilor de servicii cloud pot destul de ușor să elimine mașina virtuală pe care o folosiți.

Dacă folosiți DigitalOcean ca furnizor de servicii cloud, puteți șterge mașina virtuală existentă dând clic pe butonul roată și selectând Distrugeți serverul. Imediat după aceea, vi se oferă opțiunea să creați o mașină virtuală nouă, într-o locație aleasă de dvs.

Dacă eliminați un server Outline, acesta se șterge definitiv, iar cheile sale de acces nu vor mai funcționa. Dacă nu doriți ca utilizatorilor să le fie întrerupt accesul prin Outline, va trebui [să configurați un server Outline nou](/manager/server-setup/setup-server) și să permiteți accesul la el înainte să ștergeți serverul vechi.
