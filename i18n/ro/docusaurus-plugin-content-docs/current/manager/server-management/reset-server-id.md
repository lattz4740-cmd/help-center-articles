---
title: "Cum resetez ID-ul serverului?"
sidebar_label: "Cum resetez ID-ul serverului?"
---

ID-ul serverului este un ID la nivel de server, generat aleatoriu când creați un server Outline. Îl puteți găsi când optați pentru trimiterea de valori anonime în interfața Setări. Puteți găsi ID-ul serverului în: Setări => derulați în jos => bifați opțiunea Trimiteți valori anonime.

ID-ul serverului adună statistici anonime de utilizare, raportate de-a lungul timpului. Dacă vreți să resetați ID-ul serverului și să obțineți unul nou, trebuie să înlocuiți serverul Outline existent cu unul nou.

Dacă folosiți DigitalOcean ca furnizor de servicii cloud, puteți să resetați serverul accesând Setări și selectând Destroy Server (Distrugeți serverul). Această acțiune este ireversibilă și va șterge datele dvs. de conectare. Imediat după aceea, vi se va cere să creați un server nou într-o locație aleasă de dvs. și va fi generat un nou ID al serverului.
