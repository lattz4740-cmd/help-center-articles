---
title: "De ce nu pot să instalez Outline Manager pe Windows?"
sidebar_label: "De ce nu pot să instalez Outline Manager pe Windows?"
---

Se poate afișa acest mesaj de eroare: „Se pare că Outline nu este instalat corect. Încercați să instalați din nou. Dacă nu funcționează, [trimiteți feedback](/about/feedback).”

Dacă folosiți Outline în Windows, este posibil să apară ocazional o eroare neașteptată. În majoritatea cazurilor, adaptorul (driverul) Outline TAP trebuie șters și Outline trebuie reinstalat.

Pașii pot varia în funcție de versiunea sistemului de operare Windows. Mai jos, găsiți pașii generali pentru dezinstalarea adaptorului TAP și a aplicației Outline Manager și apoi reinstalarea Outline Manager.

1. Dezinstalați adaptorul TAP pentru Outline Manager
   1. Accesați Manageri de dispozitive, apoi Adaptori de rețea.
   2. Găsiți fișierul „TAP-Windows Adapter V9” sau adaptorul TAP asociat cu Outline.
   3. Dezinstalați sau ștergeți adaptorul. Rețineți că această acțiune poate afecta alte aplicații VPN pe care le-ați instalat.
2. Dezinstalați Outline Manager
   1. Accesați Programe și funcții, apoi Dezinstalați programul.
   2. Găsiți aplicația Outline Manager și dezinstalați Outline Manager.
   3. [Descărcați cea mai recentă versiune a aplicației Outline Manager](https://getoutline.org/get-started/#step-1) și reinstalați-o pe dispozitivul Windows. Când instalați din nou, ar trebui să se instaleze automat un nou adaptor TAP.

Dacă încă întâmpinați probleme, [contactați asistența](/about/feedback).
