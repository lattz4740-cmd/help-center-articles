---
title: Cum să configurați mai multe servere Outline
sidebar_label: Cum să configurați mai multe servere Outline
---

Dacă doriți să configurați servere Outline suplimentare, dați clic pe pictograma „+” din panoul de navigare aflat în partea stângă a aplicației Outline Manager. Instrucțiunile pentru adăugarea unui server nou sunt aceleași ca pentru instalarea primului server.

- Nu există un număr limită de servere Outline pe care le puteți crea.
- Pentru fiecare server Outline creat, aveți nevoie de o mașină virtuală corespunzătoare.
- În cazul în care creați mașini sau medii virtuale, taxele pentru furnizorul de servicii cloud pot crește. Verificați pachetul tarifar al furnizorului de servicii cloud pentru a ști la ce costuri să vă așteptați.

## Crearea unui server suplimentar Outline în DigitalOcean

După ce dați clic pe pictograma + și selectați instalarea în DigitalOcean, urmați aceleași instrucțiuni pe care le-ați folosit pentru configurarea primului server. Întrucât Outline Manager se integrează cu DigitalOcean, putem și să creăm un mediu virtual pentru dvs. fără să fie necesar să ieșiți din aplicația Outline Manager.

Rețineți că Outline Manager poate accepta numai un cont DigitalOcean simultan. Dacă doriți să adăugați sau să creați alte servere Outline din alte conturi DigitalOcean, le puteți adăuga drept o configurație avansată.

## Crearea unui server suplimentar Outline pe GCP, AWS sau alt furnizor de servicii cloud

Începeți cu crearea unei mașini virtuale noi prin furnizorul de servicii cloud ales de dvs. Apoi, deschideți Outline Manager și finalizați instrucțiunile pentru instalarea avansată, la fel cum ați procedat prima dată.
