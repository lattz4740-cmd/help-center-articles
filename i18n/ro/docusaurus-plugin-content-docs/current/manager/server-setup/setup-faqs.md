## Pot folosi Outline fără un server?
 Nu. Software-ul Outline necesită acces la un server, fie că este administrat de dvs., de organizația din care faceți parte sau de o terță parte.

## Cât timp durează configurarea unui server Outline?

Mai puțin de 5 minute, în majoritatea cazurilor. Puteți instala Outline pe orice server cloud, însă am colaborat cu DigitalOcean pentru a oferi o experiență de instalare cu îndrumări și ușor de folosit, prin care puteți configura serverul din câteva clicuri, fără să fie nevoie de scripturi.

Dacă ați ales AWS, GCP sau o configurare avansată, am simplificat procesul de instalare a serverului la un singur script care gestionează majoritatea mediilor.

## Unde pot să configurez un server Outline?

Puteți configura un server Outline în majoritatea furnizorilor de servicii cloud, oriunde funcționează aceștia.

Cea mai simplă opțiune este configurarea în DigitalOcean, deoarece are servere în mai multe locații, precum Amsterdam, Toronto, San Francisco și Singapore. Dacă preferați să instalați la un alt furnizor de servicii cloud sau în propria infrastructură, puteți să alegeți Modul Avansat în aplicația Outline Manager și să urmați instrucțiunile de instalare folosind un script de configurare.

2. locația serverului Outline influențează modul în care utilizatorii folosesc internetul. De exemplu, dacă serverul se află în Amsterdam, utilizatorul care accesează acest server va utiliza internetul ca și cum s-ar afla fizic în Țările de Jos. Este posibil ca unele site-uri să se afișeze în limba olandeză. În mod normal, puteți modifica limba locală folosind selectorul de pe site.
3. distanța dintre utilizatorii dvs. și serverul Outline poate afecta viteza. În general, distanța fizică dintre utilizatorii Outline și server poate afecta viteza de utilizare a internetului. În majoritatea cazurilor, puteți alege o locație pentru server cât mai aproape de locul în care se află utilizatorii preconizați sau puteți consulta [Harta cablurilor submarine](https://www.submarinecablemap.com/) pentru a vedea ce cabluri de internet sunt conectate cu țara sau regiunea dvs.
4. locația serverului VPN poate afecta cadrul legal. Rețineți faptul că software-ul Outline nu vă înregistrează traficul. Aflați mai multe despre [securitate și confidențialitate când folosiți Outline](/about/security-and-privacy).
