---
title: "Cum pot să configurez un server Outline?"
sidebar_label: "Cum pot să configurez un server Outline?"
---

Configurarea unui server Outline este primul pas către utilizarea Outline. Dvs. sau o persoană de încredere trebuie să vă configurați un server pentru a vă conecta la internetul liber prin Outline.

## Înainte de a începe
 Înainte de a începe configurarea serverului Outline, aveți nevoie de câteva lucruri.

1. Acces la propriile servere sau la un furnizor de servicii cloud, de exemplu, DigitalOcean, Amazon Web Services (AWS) sau Google Cloud Platform (GCP).

 Dacă nu aveți acces imediat la un server cloud, puteți configura cu ușurință un cont la orice furnizor, inclusiv cei menționați mai sus. Probabil, veți avea nevoie de un card de credit pentru a vă înscrie.
2. Un computer desktop care rulează macOS 10.9, Windows 7.0 sau versiunile ulterioare, ori Linux.
3. Aplicația Outline Manager.

## Configurați cu DigitalOcean
 Am simplificat instalarea Outline în DigitalOcean la doar câteva clicuri. După ce descărcați și instalați Outline Manager pe computer, puteți selecta opțiunea de configurare DigitalOcean care vă va ghida prin câteva ecrane simple pentru configurarea și instalarea serverului Outline.

## Configurați cu alt furnizor de servicii cloud
 După ce descărcați și instalați Outline Manager, puteți selecta să instalați un server Outline pe o mașină virtuală folosind AWS, GCP, DigitalOcean sau alt furnizor. Fiecare mediu este diferit, așa că am inclus instrucțiuni în cadrul fluxului de configurare Outline Manager pentru cei mai frecvenți furnizori de servicii cloud, inclusiv modul de configurare a setărilor pe mașina dvs. virtuală, înainte de a rula scriptul de instalare pentru a instala Outline pe un server.
