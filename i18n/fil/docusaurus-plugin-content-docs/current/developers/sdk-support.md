---
title: "Isa akong developer. Saan ako makakahanap ng suporta sa pag-integrate ng Outline SDK sa application ko?"
sidebar_label: "Isa akong developer. Saan ako makakahanap ng suporta sa pag-integrate ng Outline SDK sa application ko?"
---

Para sa mga Outline Manager at Client user ang website na ito ng suporta. Para sa mga developer, gamitin ang GitHub para sa suporta. Para magtanong, mag-post sa [Discussion board](https://github.com/Jigsaw-Code/outline-sdk/discussions) ng SDK. Magandang seksyon ang Discussion board para sa pagtatanong, pagbabahagi ng mga ideya, pag-link sa mga demo, at pagsuporta sa iba pang developer na gumagamit ng Outline SDK. Para sa mga request sa feature o ulat ng bug, magbukas na lang ng [Isyu](https://github.com/Jigsaw-Code/outline-sdk/issues/new).
