---
title: "Bakit hindi ko ma-install ang Outline Manager sa Windows?"
sidebar_label: "Bakit hindi ko ma-install ang Outline Manager sa Windows?"
---

Puwede mong makita ang mensahe ng error na ito: “Paumanhin, mukhang hindi na-install nang maayos ang Outline. Pakisubukang i-install ulit ito. Kung hindi iyon gagana, [magsumite ng feedback](https://support.getoutline.org/s/contactsupport?).”

Kung ginagamit mo ang Outline sa Windows, paminsan-minsan, puwede kang makaranas ng hindi inaasahang error. Kadalasan, kailangang i-delete ang Outline TAP adapter (driver) at dapat i-install ulit ang Outline.

Posibleng magkakaiba ang mga hakbang batay sa iyong bersyon ng operating system ng Windows, pero nasa ibaba ang mga pangkalahatang hakbang sa kung paano i-uninstall ang TAP adapter at Outline Manager at pagkatapos ay i-install ulit ang Outline Manager.

1. I-uninstall ang TAP adapter para sa Outline Manager
   1. Pumunta sa Device Managers, pagkatapos ay pumunta sa Network Adapters
   2. Hanapin ang file na “TAP-Windows Adapter V9 o ang TAP adapter na nauugnay sa Outline
   3. I-uninstall o i-delete ang adapter na ito. Tandaang posibleng maapektuhan nito ang iba pang VPN app na na-install mo.
2. I-uninstall ang Outline Manager
   1. Pumunta sa Programs & Features, pagkatapos ay pumunta sa Uninstall Program
   2. Hanapin ang Outline Manager app at i-uninstall ang Outline Manager
   3. [I-download ang pinakabagong bersyon ng Outline Manager](https://getoutline.org/get-started/#step-1) at i-install ulit ito sa Windows device mo. Awtomatikong mag-i-install ng bagong TAP adapter ang bagong pag-install.

Kung nagkakaproblema ka pa rin, [makipag-ugnayan sa suporta](https://support.getoutline.org/s/contactsupport?).
