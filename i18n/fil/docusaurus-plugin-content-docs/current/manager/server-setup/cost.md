---
title: "Magkano magpagana ng Outline?"
sidebar_label: "Magkano magpagana ng Outline?"
---

Libre para sa lahat ang Outline software, isa ka mang administrator ng server na pinapamahalaan ang VPN o isa ka mang taong ginagamit ang Outline para i-access ang malayang internet.

 Gayunpaman, kinakailangan ng Outline ng access sa isang cloud server para gumana. Ang mga administrator ng server na may access na sa isang server ay puwedeng mag-install dito ng Outline nang walang karagdagang gastusin. Ang mga walang access sa isang server ay puwedeng magkaroon ng access mula sa isang provider ng mga serbisyo sa cloud, tulad ng [DigitalOcean](https://www.digitalocean.com/) o Amazon Web Services, sa halagang humigit-kumulang $5 USD kada buwan para sa allowance na 1 terabyte ng paglilipat ng data — sapat na iyon para suportahan ang daan-daang user sa isang server.

 Isang halimbawa ng kung paano mo magagawa ang kalkulasyon para malaman kung magkano magpagana ng Outline sa pamamagitan ng napili mong cloud provider:

| *Ipagpalagay ang isang average na buwanang paggamit na 5 gigabyte na paglilipat ng data kada user, ang isang plan na $5 USD kada buwan ay makakapagbigay-daan sa humigit-kumulang 200 magkakasabay na user, kaya naman 2.5 sentimo lang ang gastusin kada user kada buwan. Tandaang ang paglilipat ng data na ginagamit kada buwan kada user ay lubos na mag-iiba-iba depende kung nagsasagawa ang mga user ng mga aktibidad na mahina o malakas gumamit ng bandwidth, pero aangkop ang karamihan ng mga cloud provider para matugunan ang mga pagtaas sa trapiko.* |
| --- |

Sa katunayan, ganap na anonymous sa Jigsaw at Google ang paggamit ng Outline. Hindi namin sinusubaybayan ang iyong pagkakakilanlan o trapiko at walang plan sa pag-monetize. Sa halip, nakikipagtulungan kami sa aming komunidad ng open source para masiguradong maibibigay namin ang software nang walang ginagastos ang aming mga user. Matuto pa tungkol sa data na kinokolekta namin [dito](/about/data-collection).
