---
title: "Paano mag-set up ng Outline server?"
sidebar_label: "Paano mag-set up ng Outline server?"
---

Ang pag-set up ng Outline server ay ang unang hakbang para magamit ang Outline. Kailangan mo o ng isang taong pinagkakatiwalang mo na mag-set up ng server para sa iyo para makakonekta ka sa malayang internet sa pamamagitan ng Outline.

## Bago ka magsimula
Bago mo simulang i-set up ang iyong Outline server, may kailangan kang ilang bagay:

1. Access sa iyong sariling mga server o sa provider ng mga serbisyo sa Cloud, tulad ng DigitalOcean, Amazon Web Services (AWS), o Google Cloud Platform (GCP).

    Kung wala kang agarang access sa isang cloud server, walang kahirap-hirap kang makakapag-set up ng account sa anumang provider, kabilang ang mga nakalista sa itaas. Malamang na kakailanganin mo ng credit card para makapag-sign up.
2. Isang desktop computer na nagpapatakbo ng macOS 10.9+, Windows 7.0+, o Linux.
3. Ang Outline Manager application.

## Pag-set up sa DigitalOcean
Pinadali namin para sa lahat na i-install ang Outline sa DigitalOcean sa ilang pag-click lang. Pagkatapos i-download at i-install ang Outline Manager sa iyong computer, puwede mong piliin ang opsyon sa pag-set up sa DigitalOcean na gagabay sa iyo sa ilang simpleng screen para i-configure at i-install ang Outline Server mo.

## Pag-set up sa iba pang cloud provider
Pagkatapos i-download at i-install ang Outline Manager, puwede mong piliing mag-install ng Outline server sa isang virtual machine sa pamamagitan ng AWS, GCP, DigitalOcean, o iba pang provider. Iba ang bawat environment kaya naglagay kami ng mga tagubilin sa proseso ng pag-set up sa Outline Manager para sa mga pinakakaraniwang cloud provider, kabilang kung paano i-configure ang mga setting sa iyong virtual machine bago mo patakbuhin ang script sa pag-install para ma-install ang Outline sa isang server.
