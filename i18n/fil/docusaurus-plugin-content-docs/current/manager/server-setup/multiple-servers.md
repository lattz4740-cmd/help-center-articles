---
title: "Paano mag-set up ng maraming Outline server"
sidebar_label: "Paano mag-set up ng maraming Outline server"
---

Para mag-set up ng mga karagdagang Outline Server, mag-click sa icon na "+" sa panel ng navigation sa kaliwang bahagi ng iyong Outline Manager application. Ang mga tagubilin sa pagdaragdag ng bagong server ay pareho lang sa pag-install ng una mong server.

- Wala kaming limitasyon sa bilang ng mga Outline server na puwede mong gawin.
- Para sa bawat Outline server na ginagawa mo, kakailanganin mo ng kaukulang virtual machine.
- Kapag gumawa ng mga karagdagang machine o droplet, puwedeng madagdagan ang iyong mga bayarin sa cloud provider mo. Pakitingnan ang iyong package ng pagpepresyo sa iyong cloud provider para matiyak na alam mo ang dapat asahan.

## Gumawa ng karagdagang Outline server sa DigitalOcean

Pagkatapos i-click ang icon na + at piliing mag-install sa DigitalOcean, susundin mo ang parehong mga tagubiling ginawa mo para i-set up ang iyong unang server. Bukod pa rito, dahil naka-integrate ang Outline Manager sa DigitalOcean, magagawa namin ang droplet para sa iyo nang hindi ka lumalabas sa Outline Manager app.

Tandaang isang DigitalOcean account lang ang puwedeng suportahan ng Outline Manager sa bawat pagkakataon. Kung gusto mong magdagdag o gumawa ng iba pang Outline server mula sa iba pang DigitalOcean account, puwede mong idagdag ang mga ito bilang isang advanced na configuration.

## Paggawa ng karagdagang Outline server sa GCP, AWS, o isa pang cloud service provider

Magsimula sa pamamagitan ng paggawa ng bagong virtual machine sa pamamagitan ng iyong napiling cloud provider. Pagkatapos ay buksan ang Outline Manager at gawin ang mga tagubilin para sa advanced na pag-install, tulad lang ng ginawa mo noong una.
