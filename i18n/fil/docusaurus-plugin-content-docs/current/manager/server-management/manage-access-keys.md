---
title: Pamahalaan ang access sa isang Outline server (sa pamamagitan ng mga access key)
sidebar_label: Pamahalaan ang access sa isang Outline server (sa pamamagitan ng mga access key)
---

Kapag na-install mo na ang iyong Outline server, puwede mo nang simulang ibahagi at pamahalaan ang access dito ng mga tao. Magagawa ng mga taong makakatanggap ng imbitasyon mula sa iyo na i-download ang Outline app para magamit ang Outline para maprotektahan ang kanilang internet traffic.

**Magbahagi ng access sa iyong Outline server**

 Pagkatapos mong mag-install ng Outline server, ididirekta ka sa page ng mga detalye ng server sa Outline Manager kung saan ka puwedeng gumawa ng mga access key. Matuto pa tungkol sa [mga access key](/about/terminology).

- Gumawa ng mga key: I-click ang maliit na icon na "+" sa ibaba ng page para gumawa ng mga bagong key.
- Magbahagi ng mga key: Sa kanan ng bawat key, may icon ng pagbabahagi na puwede mong i-click para makatanggap ng imbitasyon. Kopyahin at i-paste ang imbitasyong ito sa system ng pagmemensahe na pipiliin mo.

**Request sa feature: Pagbabahagi ng access mula sa loob ng Outline Manager app**

 Maraming administrator ng server ang humihiling sa amin na i-streamline ang proseso ng pag-iimbita sa pamamagitan ng pagbibigay sa kanila ng opsyong ilagay nang direkta sa Outline Manager ang email address ng isang tao.

Sa kasamaang-palad, malamang na hindi namin magagawa ang functionality na ito sa Outline Manager. Isa sa aming mga pangunahing prinsipyo ay ang suportahan ang privacy at seguridad ng aming mga user, na nangangahulugang wala kaming ginawang anumang disenyo kung saan makakapaglagay ng mga email address o ng impormasyon sa pakikipag-ugnayan.

Ito ang dahilan kung bakit namin hinihiling sa mga administrator ng server na gumamit ng secure na platform ng pagmemensahe, tulad ng email o secure na chat para maipadala ang imbitasyon sa end user.

**Ang nararanasan ng user pagkatapos mong magbahagi sa kanya ng access key**

1. Sa device ng user, iki-click niya ang link sa pag-install
2. Ipo-prompt siyang i-install ang Outline app kung wala pa siya nito
3. Gagawa siya ng inisyal na koneksyon sa iyong Outline server sa pamamagitan ng natatanging key na naka-embed sa imbitasyon
4. Magagamit na niya ang button na connect/disconnect para mapamahalaan ang kanyang access sa internet sa pamamagitan ng iyong Outline server

**Mag-alis ng access sa iyong Outline server**

 Sa page ng mga detalye ng server sa Outline Manager, sa kanan ng bawat key sa server, may makikita kang menu na may opsyong mag-delete ng key. Kapag nag-delete ng key, mawawalan siya ng access sa iyong server.
