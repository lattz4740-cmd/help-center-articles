---
title: "Paano ko ire-reset ang server ID ko?"
sidebar_label: "Paano ko ire-reset ang server ID ko?"
---

Ang server ID ay isang server-side ID na random na binubuo kapag gumawa ka ng Outline server. Mahahanap mo ito kapag nag-opt in sa pagbabahagi ng mga anonymous na sukatan sa Settings na interface. Makikita mo ang iyong server ID sa: Mga Setting => mag-scroll hanggang sa ibaba => lagyan ng check ang "magbahagi ng mga anonymous na sukatan."

Pinagsasama-sama ng server ID ang mga anonymous na istatistika sa paggamit na iniuulat sa paglipas ng panahon. Kung gusto mong i-reset ang server ID at kumuha ng panibago, kailangan mong palitan ng panibago ang kasalukuyan mong Outline server.

Kung DigitalOcean ang ginagamit mo bilang iyong cloud provider, puwede mong i-reset ang iyong server sa pamamagitan ng pagpunta sa Mga Setting at pagpili sa I-destroy ang Server. Hindi na mababawi ang aksyong ito at buburahin nito ang mga kredensyal mo. Pagkatapos na pagkatapos ng aksyong ito, ipo-prompt kang gumawa ng bagong server sa isang lokasyong pipiliin mo, at may bubuuing bagong server ID.
