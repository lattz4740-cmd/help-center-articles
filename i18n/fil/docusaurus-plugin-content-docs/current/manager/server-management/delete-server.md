---
title: "Paano ko ide-delete ang Outline server ko?"
sidebar_label: "Paano ko ide-delete ang Outline server ko?"
---

Para sa karamihan ng cloud provider, medyo madaling alisin ang partikular na virtual machine na ginagamit mo.

Kung DigitalOcean ang ginagamit mo bilang iyong cloud provider, puwede mong i-delete ang kasalukuyan mong virtual machine sa pamamagitan ng pag-click sa button na gear at pagpili sa I-destroy ang Server. Pagkatapos na pagkatapos nito, ipo-prompt kang gumawa ng bagong virtual machine sa lokasyong pipiliin mo.

Kung mag-aalis ka ng Outline server, permanente itong made-delete at hindi na gagana ang mga access key nito. Kung ayaw mong maputol ang access ng mga tao sa pamamagitan ng Outline, kailangan mong [mag-set up ng bagong Outline server](/manager/server-setup/setup-server) at ibahagi ang access dito bago i-delete ang luma mong server.
