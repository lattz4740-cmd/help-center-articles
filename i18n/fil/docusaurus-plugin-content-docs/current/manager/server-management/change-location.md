---
title: "Paano ko mababago ang lokasyon ng Outline server?"
sidebar_label: "Paano ko mababago ang lokasyon ng Outline server?"
---

Kapag na-set up na, hindi na mababago ang lokasyon ng server. Para paganahin ang iyong server mula sa ibang lokasyon, kailangan mong i-delete ang Outline server mo at gumawa ng panibago.

Puwede mo ring baguhin ang lokasyon ng VPN mo gamit ang [mga dynamic na key](https://developer.getoutline.org/vpn/management/dynamic-access-keys/), na nagbibigay-daan sa iyo na mag-rotate ng mga server at panatilihin ang mga parehong key. Hindi mababago ang lokasyon ng mismong mga server.
