## Pagkonekta ng iyong device sa isang Outline server

Para maikonekta ang iyong device sa isang Outline server, kailangang padalhan ka ng isang administrator ng server ng imbitasyong kumonekta sa server nila sa pamamagitan ng natatanging [access key](/about/terminology). Ang imbitasyong ito ay:

- Magpo-prompt sa iyo na i-download at i-install ang Outline sa iyong device kung wala ka pa nito
- Gagamit ng access key para makagawa ng secure na koneksyon sa pagitan mo at ng Outline server

Kapag nakakonekta ka na sa server, puwede mong i-click ang "kumonekta" o "magdiskonekta" para gamitin ang Outline.

*Mahalaga:* Hindi gagana ang Outline kung walang access key at Outline server. Hindi mapoprotektahan ang internet traffic mo kapag na-download at na-install ang Outline app nang walang key.
