title: "Ano ang mga requirement sa system para mapagana ang Outline client?"
sidebar_label: "Ano ang mga requirement sa system para mapagana ang Outline client?"
---

Puwede mong subukan ang Outline sa anumang operating system. Ang mga sumusunod ay ang mga minimum na required na operating system:

| **Operating system** | **Minimum na bersyon** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Gusto mo bang tumulong na mapagana ang Outline Client sa higit pang operating system? [Mag-ambag sa aming code base](https://github.com/Jigsaw-Code/outline-client#platform-specific-development) sa GitHub!
