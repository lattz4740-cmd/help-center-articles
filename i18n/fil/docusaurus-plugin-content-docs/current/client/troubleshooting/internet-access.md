title: "Bakit hindi ko ma-access ang internet kahit nakakonekta na ako sa Outline server?"
sidebar_label: "Bakit hindi ko ma-access ang internet kahit nakakonekta na ako sa Outline server?"
---

Kung gumagamit ka ng mobile phone, subukang magpalipat-lipat sa mobile data at Wi-Fi na koneksyon. Minsan, gumagana ang isang uri ng koneksyon habang hindi naman gumagana ang kabila. Kung computer ang gamit mo, subukang magdiskonekta mula sa broadband at kumonekta ulit.

Kung magpapatuloy pa rin ang problema, malamang na may problema sa Outline server mo. Makipag-ugnayan sa[service manager](/about/terminology) mo para sa bagong access key para sa alternatibong server.
