---
title: "Paano kung hindi gumana ang access key ko?"
sidebar_label: "Paano kung hindi gumana ang access key ko?"
---

Kung matatanggap mo ang mensahe ng error na: “Mukhang hindi valid ang iyong access key. Kung mangyayari ulit ito, makipag-ugnayan sa manager ng serbisyo mo.” Sundin ang mga hakbang sa ibaba para i-troubleshoot ang isyu:

1. Siguraduhing inilalagay mo ang buong access key, kabilang ang unang limang “ss://” na character, na posibleng hindi awtomatikong makopya sa clipboard. Narito ang isang halimbawa ng hitsura ng kumpletong access key (halimbawa lang; hindi ito gagana):

```
ss://Y2hhY2hhMjAtaWV0Zi1wb2x5MTMwNTp1eXhUQ3MzemVEMTk=@145.230.4.1:39485/?outline=1
```

1. Kung hindi talaga makopya sa iyong clipboard ang access key mo, posibleng dahil ito sa app o platform mo sa pagmemensahe. Malamang na mangyari ito kapag nakatanggap ka ng mensahe mula sa isang taong wala sa listahan ng contact mo. Kung kinokopya mo ang code mula sa isang mensahe, siguraduhing nasa mga contact mo ang sender, pagkatapos ay subukang i-access ulit ang link.
2. Kung nagawa mo na ang hakbang 1 at 2 at natatanggap mo pa rin ang mensahe ng error, malamang na na-block ang server o hindi na valid ang access key. Kung ikaw ang manager ng serbisyo, subukang gumawa ng bagong key para sa sarili mo. Kung hindi naman ikaw ang manager ng serbisyo, makipag-ugnayan sa manager ng serbisyo mo para sa panibagong key.
