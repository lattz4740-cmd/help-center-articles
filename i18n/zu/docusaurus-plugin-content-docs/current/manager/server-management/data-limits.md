Ungasetha umkhawulo wedatha ozosebenza kokhiye bokufinyelela konke. Ukuze usethe umkhawulo, vula Umphathi Wesendlalelo uphinde ufune Kumasethingi. Lapho uzobona ukuthi imikhawulo Yedatha iyakuguqula lokho, uma isetshenzisiwe, ikuvumela ukuthi usethe umkhawulo.

![Data limits setting in Outline Manager](/images/snippet-15787036.png)

Uma ususethe umkhawulo, ungabona ukuthi umsebenzisi ngamunye useduze kangakanani nomkhawulo ekhasini lokhiye wokufinyelela, lapho igrafu yebha ibonisa khona ukusetshenziswa kwedatha ezinsukwini zokugcina ezingama-30.

![Outline Manager's Access Key page](/images/snippet-15787037.png)

Ngaphezu kokwazi ukusetha umkhawulo wabo bonke okhiye bakho bokufinyelela, unganikeza ukhiye ngamunye umkhawulo wawo wedatha. Leli sethingi lizokhipha noma imuphi umkhawulo ozenzakalelayo wedatha owusethile, kepha uma ungazange usethe umkhawulo wedatha ozenzakalelayo, usengasetha umkhawulo wedatha wanoma imuphi ukhiye. 

 Ukuze usethe umkhawulo wokhiye wokudlulisela idatha, vula Umphathi Wesendlalelo, funa ngokuya kuthebhu Yokuxhumana efaka ukhiye ofuna ukuwusetha, uphinde uchofoze kumenyu ekuhlangothi olungakwesokudla komcibisholo wokhiye. Kusukela lapho, chofoza Kumkhawulo Wedatha. Khetha okuthi Setha umkhawulo wedatha yomuntu ngamunye. Uma usukhethe leli bhokisi likaqhwi, inkambu izovela lapho ungasetha khona umkhawulo wedatha yomuntu ngamunye kulowo khiye. Chofoza inkinobho yokuthi LONDOLOZA uma usuqedile ukulondoloza umkhawulo wedatha.

![Setting a data limit for an individual access key](/images/snippet-15788959.png)

Uma usulondoloze umkhawulo wakho wokudlulisela idatha kukhiye okhethiwe, umkhawulo uzoboniswa kusikrini esikhulu, ngokuhambisana nokusetshenziswa kwedatha (ngaphezu kwezinsuku ezingama-30 ezedlule) kukhiye ngamunye.

Ukuze ususe umkhawulo wedatha kusukela kukhiye wokufinyeleleka, funa ngokuya kudayalogi yokhiye Yomkhawulo Wedatha njengaphambilini, susa ukumaka ibhokisi elinelebula ethi Setha umkhawulo wedatha yokomuntu ngamunye, uphinde uchofoze inkinobho ethi LONDOLOZA.

****Imibuzo Evamile Yomkhawulo Wedatha****

****Uyini umkhawulo wedatha olandelayo ngemuva wezinsuku ezingama-30?****

 Umkhawulo wedatha olandelayo wezinsuku ezingama-30 uzofingqa ukusetshenziswa kokhiye ngamunye ezinsukwini ezingama-30 ezedlule uphinde ugcine ukusetshenziswa kokhiye kuleso sikhathi ngaphansi komkhawulo. Umthelela ukuthi ukhiye awukwazi ukudlula umkhawulo esikhathini sanoma iziphi izinsuku ezingama-30, okufaka izinyanga zekhalenda zezinsuku ezingama-30 noma ngaphansi. Empeleni, lokhu kusho ukuthi idatha etholakalayo yomsebenzisi ngamunye izokhuphuka njalo ngosuku ngenani abalisebenzise ezinsukwini ezingama-31 ezedlule.

**Kungani Isendlalelo sisebenzisa imikhawulo elandelayo?**

 Imikhawulo elandelayo inikeza iziqinisekiso esikhathini esingaphezu kwezinsuku ezingama-30, okusho ukuthi zilungiselelwa kalula kunomkhawulo ophindayo (ofana nosuku olungaqanjwa ngokwabahlinzekelwayo lwenyanga) ngenkathi inikeza iziqinisekiso ngokusemthethweni ezifanayo. Iphinda ifane nokuboniswa okukhona kokusetshenziswa kwedatha Yesendlalelo, kanye namathuluzi ajwayelekile afana namasevisi okuhlaziya nezibalo zeseva.

**Iyiphi idatha ebalwa emkhawulweni wedatha?**

 Ukhiye ngamunye wokufinyelela ophuma kuseva ufakwa esibalweni. Ngokuqondile lokhu kusho idatha ethunyelelwe ukhiye kusukela kuseva, nebuyiselwa kuklayenti. Empeleni, lokhu kufanele kuhambisane eduze nethrafikhi ethunyelwe kusukela kukhiye ukuya kuseva nangemuva, ngakho sethemba ukuthi izofana nezibalo zabasebenzisi bakho. Sikhethe ukuphuma njengoba lokho kube okukhokhiswa abahlinzeki be-cloud esiye sabahlola.

**Ingabe abasebenzisi bazokwaziswa uma sebedlule kumkhawulo wabo wedatha?**

 Hhayi okwamanje. Iningi labahlinzeki be-cloud bafaka umkhawulo ofana ne-1TB ngenyanga egcwele, ongasekela abasebenzisi abayi-10 ngo-100GB noma abasebenzisi abayi-100 ngo-10 GB. Lezi izinombolo ezinkulu kakhulu, futhi asilindele ukuthi abasebenzisi abaningi bazofinyelela kuzo. Sithemba ukuthi abasebenzisi bazoxhumana nabaphathi beseva uma sebafike kumkhawulo wabo. Kodwa, sizolibonga ulwazi lwakho lokuthi izaziso zingasiza kanjani esimweni sakho sokusetshenziswa, futhi ungaxhumana nathi[lapha](/about/feedback).

**Ingabe abasebenzisi bazokwaziswa uma sebasondele emkhawulweni wabo wedatha?**

 Inani ledatha entsha yokuthi umsebenzisi usondele emkhawulweni wakhe elizotholwa lizohluka ezinsukwini ezihlukile ngoba lisuselwa ekusetshenzisweni kwabo kwezinsuku ezingama-30 ezedlule. Sicabanga ukuthi isexwayoso kungenzeka kakhulu sidide abasebenzisi kunokuba sibasize. Singayijabulela impendulo yakho kulokhu kuziphatha[lapha](/about/feedback).

**Ngingakwazi yini ukusetha kabusha ukusetshenziswa kwedatha yomsebenzisi?**

 Cha, umkhawulo womsebenzisi uhlala ufake ukusetshenziswa kwedatha kwezinsuku ezingama-30 ezedlule. Kodwa, ungaphakamisa umkhawulo wedatha yabo engukhiye noma ubasungulele ukhiye omusha.

**Kungani abanye abasebenzisi bami baye balahlekelwa ukufinyelela ngemuva nje kokuthi ngisebenzise imikhawulo yedatha?**

 Imikhawulo yedatha isuselwa ezinsukwini ezingama-30 zangaphambili zabasebenzisi zokudlulisela idatha, eqoshwa noma kusetshenziswe noma ingasetshenzisiwe imikhawulo yedatha. Kungenzeka ukuthi abasebenzisi okukhulunywa nabo sebavele badlule kumkhawulo ngaphambi kokuthi ubekwe. Futhi yazi ukuthi yonke imikhawulo yedatha iyaphoqelelwa, nanoma ushintsha umkhawulo wedatha wokhiye owodwa.

**Ngingakwazi yini ukusetha umkhawulo obanzi kuseva, ofana “ne-1 TB njalo ezinsukwini ezingama-30”?**

 Hhayi okwamanje. Singathanda ukuzwa okuningi mayelana nesimo sakho sokusetshenziswa[lapha](/about/feedback).

**Uma kukhona umkhawulo wedatha ozenzakalelayo kanye nomkhawulo wedatha kukhiye othile, iyiphi ezophoqelelwa?**

 Umkhawulo wedatha ethile yokhiye uzokhipha noma imuphi umkhawulo wedatha ozenzakalelayo (uma ukhona) owusethile.

**Ngingakwazi yini ukusetha umkhawulo wedatha wokhiye othile ngaphandle kokuba nomkhawulo wedatha ozenzakalelayo osethiwe?**

 Yebo. Awudingi umkhawulo ozenzakalelayo ochaziwe ukuze usethe umkhawulo wedatha kukhiye owodwa. Isibonelo, ungasetha umkhawulo kukhiye owodwa ocabanga ukuthi uzokwabiwa ngokusabalala ukuze uzivikele kusukela ekudluliseni idatha okweqile ngalowo khiye.
