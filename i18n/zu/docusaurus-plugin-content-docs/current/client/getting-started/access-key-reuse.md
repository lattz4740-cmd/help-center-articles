title: "Ngingakwazi yini ukusebenzisa ukhiye wokufinyelela izikhathi ezingaphezu kwesisodwa?"
sidebar_label: "Ngingakwazi yini ukusebenzisa ukhiye wokufinyelela izikhathi ezingaphezu kwesisodwa?"
---

Yebo. Ungasebenzisa [ukhiye wakho wokufinyelela](/about/terminology) kunoma yiliphi inani lamadivayisi akho, kodwa asincomi ukuthi wabelane ngokhiye wakho nomunye umuntu. Othile onokhiye wakho wokufinyelela angase ahlole yonke ithrafikhi yakho ye-inthanethi uma ekwazi ukuyifinyelela, okwenza ukuthi ukusebenzisa kwakho i-inthanethi kungabe kusaba okuvikelekile noma okuyimfihlo.
