Աջակցման ծառայության այս կայքը նախատեսված է Outline Manager և Outline Client հավելվածների օգտատերերի համար։ Իսկ ծրագրավորողներին առաջարկում ենք օգտվել GitHub-ից, եթե աջակցման կարիք ունենան։ Հարց ունենալու դեպքում խնդրում ենք այն հրապարակել SDK [քննարկումների հարթակում](https://github.com/Jigsaw-Code/outline-sdk/discussions)։ Քննարկումների հարթակը հարցեր տալու, մտքեր փոխանակելու, հղումներով կիսվելու, Outline SDK-ից օգտվող մյուս ծրագրավորողներին աջակցություն ցուցաբերելու հիանալի վայր է։ Գործառույթների հետ կապված հարցումների կամ վրիպակների մասին հաղորդումների համար խնդրում ենք [հայտ](https://github.com/Jigsaw-Code/outline-sdk/issues/new) բացել։
