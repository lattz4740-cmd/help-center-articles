---

Շնորհակալություն, որ օգնում եք բարելավել Outline-ը։ Կարծիք հայտնելու մի քանի եղանակ կա, ընդ որում՝ կարող եք դա անել անանուն կերպով կամ էլ․ հասցեի նշմամբ (եթե ուզում եք պատասխան ստանալ)՝

- **Ծրագրավորողների համար**․ Outline-ը բաց կոդով ծրագրակազմ է, որը տեղակայված է [GitHub-ում](https://github.com/jigsaw-Code/?q=outline)։ Դուք կարող եք կիսվել ձեր գաղափարներով GitHub-ում կամ [Reddit-ի](https://www.reddit.com/r/outlinevpn/) մեր համայնքում։
- **Օգտատերերի համար**․ դուք կարող եք կարծիք ուղարկել Outline կամ Outline Manager հավելվածների միջոցով։ Կիսվեք մեզ հետ ձեր մտքերով և ցանկության դեպքում ներառեք ձեր էլ․ հասցեն, որպեսզի կարողանանք ձեզ պատասխանել։ Մենք նաև հավաքում ենք որոշ մետատվյալներ ձեր միջավայրի մասին, ուստի կարող ենք օգնել ձեզ վերացնել ձեր օգտագործած դիտարկիչի, օպերացիոն համակարգի և ծրագրակազմի տարբերակի հետ կապված անսարքությունները։
- **Այս կայքի միջոցով**․ սեղմեք «Կապվել մեզ հետ» հղումը կայքի ցանկացած բաժնում։
- **Լուրջ խնդիրներ**․ եթե ուզում եք հաղորդել անվտանգության հետ կապված լուրջ խնդրի մասին, խնդրում ենք մանրամասներով նամակ ուղարկել security [at] [getoutline.org](https://getoutline.org/) հասցեին։

Եվս մեկ անգամ ուզում ենք շնորհակալություն հայտնել ձեզ, որ ժամանակ հատկացրիք կարծիք հայտնելու համար։
