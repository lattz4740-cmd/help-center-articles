Outline-ի սերվերի կարգավորումը Outline-ից օգտվելու առաջին քայլն է։ Դուք կամ որևէ մեկը, ում վստահում եք, պետք է սերվեր կարգավորի, որպեսզի կարողանաք Outline-ի միջոցով ազատ մուտք ունենալ դեպի ինտերնետ։

**Նախքան սկսելը**

 Նախքան Outline-ի սերվերը կարգավորելը դուք պետք է ունենաք՝

1. Ձեր սեփական սերվերների կամ որևէ ամպային ծառայության, օրինակ՝ DigitalOcean-ի, Amazon Web Services-ի (AWS) կամ Google Cloud Platform-ի (GCP) հասանելիություն։

 Եթե հասանելիություն չունեք որևէ ամպային սերվերի, հեշտությամբ կարող եք հաշիվ ստեղծել նման ծառայություններ մատուցող ցանկացած ընկերության հարթակում, այդ թվում՝ վերոնշյալ ծառայություններում։ Գրանցվելու համար, ամենայն հավանականությամբ, ձեզ հարկավոր կլինի վարկային քարտ։
2. MacOS 10.9 կամ ավելի նոր տարբերակով, Windows 7.0 կամ ավելի նոր տարբերակով կամ Լինուքս օպերացիոն համակարգով աշխատող համակարգիչ։
3. Outline Manager հավելվածը։

**Սերվերի կարգավորում DigitalOcean ամպային ծառայությունում**

 Outline-ը կարելի է տեղադրել DigitalOcean-ում ընդամենը մի քանի սեղմումով։ Outline Manager-ը ձեր համակարգչում ներբեռնելուց և տեղադրելուց հետո կարող եք ընտրել DigitalOcean ամպային ծառայությունում տեղադրման տարբերակը, այնուհետև հետևել ցուցումներին և մի քանի պարզ քայլ կատարելով՝ տեղադրել և կարգավորել Outline-ի սերվերը։

**Սերվերի կարգավորում այլ ամպային ծառայություններում**

 Outline Manager-ը ձեր համակարգչում ներբեռնելուց և տեղադրելուց հետո կարող եք Outline-ի սերվերը տեղադրել AWS, GCP, DigitalOcean կամ մեկ այլ ամպային ծառայության վիրտուալ մեքենայում։ Յուրաքանչյուր միջավայր իր յուրահատկություններն ունի, ուստի ամենատարածված ամպային ծառայություններում Outline Manager-ի տեղադրման գործընթացում մենք ներառել ենք ցուցումներ, այդ թվում՝ թե ինչպես կարգավորել պարամետրերը վիրտուալ մեքենայում՝ նախքան սերվերում Outline-ի տեղադրման հրահանգաշարը գործարկելը։
