Outline-ի լրացուցիչ սերվերներ կարգավորելու համար սեղմեք Outline Manager-ի ձախ կողմում գտնվող նավիգացիայի վահանակի վրայի «+» պատկերակի վրա։ Նոր սերվեր ավելացնելու ցուցումները նույնն են, ինչ առաջին սերվերի տեղադրման ցուցումները։

- Դուք կարող եք Outline-ի անսահմանափակ քանակի սերվերներ ստեղծել։
- Outline-ի՝ ձեր ստեղծած յուրաքանչյուր սերվերի համար անհրաժեշտ է ստեղծել համապատասխան վիրտուալ մեքենա։
- Լրացուցիչ վիրտուալ մեքենաների կամ դրոփլեթների ստեղծումը կարող է մեծացնել ամպային ծառայությունների հետ կապված ծախսերը։ Ստուգեք ամպային ծառայության ձեր սակագնային պլանը՝ լրացուցիչ ծախսերի մասին իմանալու համար։

## Ինչպես ստեղծել Outline-ի լրացուցիչ սերվեր DigitalOcean-ում

Այն բանից հետո, երբ սեղմեք «+» պատկերակի վրա և որպես տեղադրման վայր ընտրեք DigitalOcean-ը, դուք պետք է հետևեք նույն ցուցումներին, ինչ ձեր առաջին սերվերը կարգավորելիս։ Բացի այդ՝ քանի որ Outline Manager-ը ինտեգրված է DigitalOcean-ի հետ, մենք ձեզ համար կարող ենք դրոփլետ ստեղծել, որպեսզի ստիպված չլինեք դուրս գալ Outline Manager-ից։

Նկատի ունեցեք, որ Outline Manager-ը միաժամանակ կարող է աջակցել միայն մեկ DigitalOcean հաշիվ։ Եթե ձեզ անհրաժեշտ է ավելացնել կամ ստեղծել Outline-ի այլ սերվերներ DigitalOcean-ի այլ հաշիվներում, ավելացրեք դրանք որպես ընդլայնված կազմաձև։

## Ինչպես ստեղծել Outline-ի լրացուցիչ սերվեր GCP-ում, AWS-ում կամ մեկ այլ ամպային ծառայությունում

Նախ ստեղծեք նոր վիրտուալ մեքենա ձեր ընտրած ամպային ծառայությունում։ Այնուհետև բացեք Outline Manager-ը և հետևեք ընդլայնված տեղադրման ցուցումներին (հնարավոր է, որ դրանք արդեն կատարել եք առաջին կարգավորման ժամանակ)։
