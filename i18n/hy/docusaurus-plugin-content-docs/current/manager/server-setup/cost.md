Outline-ի ծրագրակազմն անվճար է բոլորի համար՝ ինչպես սերվերի ադմինիստրատորների, որոնք կառավարում են VPN ցանցերը, այնպես էլ օգտատերերի համար, որոնք օգտագործում են Outline-ը՝ ինտերնետին ազատ մուտք ունենալու համար։

 Այդուհանդերձ, Outline-ի աշխատանքի համար պահանջվում է ամպային սերվերի հասանելիություն։ Սերվերի ադմինիստրատորները, որոնց արդեն հասանելի է որևէ սերվեր, կարող են տեղադրել Outline-ը առանց լրացուցիչ ծախսերի։ Եթե սերվերի հասանելիություն չունեք, կարող եք ստանալ այն՝ բաժանորդագրվելով ամպային ծառայություններից մեկին, օրինակ՝ [DigitalOcean-ին](https://www.digitalocean.com/) կամ Amazon Web Services-ին՝ վճարելով ամսական մոտավորապես 5 ԱՄՆ դոլար 1 տերաբայթ թրաֆիկի փաթեթի համար։ Այս ծավալը բավարար է՝ մեկ սերվերում հարյուրավոր օգտատերերի աջակցելու համար։

 Ստորև բերված է ընտրված ամպային ծառայությունում Outline-ի օգտագործման արժեքի հաշվարկման օրինակ․

| *Դիցուք յուրաքանչյուր օգտատեր ամսական միջինում սպառում է 5 ԳԲ թրաֆիկ։ Այս դեպքում ամսական 5 ԱՄՆ դոլար արժողությամբ սակագնային պլանը թույլ կտա միաժամանակ ապահովել մոտ 200 օգտատերերի աշխատանքը։ Ընդ որում, մեկ օգտատիրոջ հաշվարկով ծախսը կկազմի ամսական ընդամենը 2,5 ցենտ։ Նկատի ունեցեք, որ ամսական օգտագործվող թրաֆիկի ծավալը կարող է զգալիորեն տարբերվել՝ կախված բարձր կամ ցածր թողունակությունից, սակայն թրաֆիկի ավելացման դեպքում ամպային ծառայություններ մատակարարող ընկերությունների մեծամասնությունը կիրառում է ծառայությունների արժեքը կարգավորելու ճկուն համակարգ։* |
| --- |

Outline-ի օգտագործումը Jigsaw-ի և Google-ի օգտատերերի համար լիովին անանուն է։ Մենք չենք հետագծում ձեր անձնական տվյալները կամ թրաֆիկը և չենք առաջարկում որևէ դրամայնացման պլան։ Փոխարենը մենք համագործակցում ենք բաց կոդով ծրագրակազմի մշակողների համայնքի հետ, որպեսզի կարողանանք օգտատերերին անվճար ծրագրեր տրամադրել։ Լրացուցիչ տեղեկություններ այն մասին, թե ինչ տվյալներ ենք մենք հավաքում, կարող եք գտնել [այստեղ](https://getoutline.org/policies/data-collection)։
