## Ընդհանուր տեղեկություններ

Outline Manager-ը հնարավորություն է տալիս ավտոմատ կերպով կարգավորելու Outline-ի սերվերը, որը տեղակայված է Google Cloud-ում։ Այս գործառույթից օգտվելու համար ձեր Google հաշվով մուտք գործեք Outline Manager։ Այդպիսով սարքում տեղադրված հավելվածը կստանա որոշակի [OAuth](https://developers.google.com/identity/protocols/oauth2) թույլտվություններ, որոնք անհրաժեշտ են Google Cloud հաշիվ կարգավորելու համար։

 Եթե չեք ուզում հավելվածին տրամադրել այս թույլտվությունները, ապա հետևեք Outline Manager-ի ընդլայնված ցուցումներին՝ Outline-ը Google Cloud Platform-ում գործարկելու համար։

## Թույլտվությունների տրամադրում

Սերվերի ավտոմատ կարգավորման գործառույթից օգտվելու համար դուք պետք է Outline Manager-ին տրամադրեք հետևյալ թույլտվությունները։

## Google Cloud Platform

- Դիտել և կառավարել Google Compute Engine-ի ձեր ռեսուրսները
- Դիտել ձեր տվյալները Google Cloud-ի ծառայություններում և տեսնել ձեր Google հաշվի էլ․ հասցեն

## Հաշվի հիմնական տվյալներ

- Տեսնել ձեր Google հաշվի հիմնական էլ․ հասցեն
- Կապել ձեզ Google-ում ձեր անձնական տվյալների հետ

## Մուտքի ընդլայնված իրավունքներ

- Կառավարել Cloud Platform-ի ձեր նախագծերը
- Դիտել և կառավարել Google Cloud Platform-ի ձեր վճարային օգտահաշիվները
- Կառավարել ձեր Google API ծառայության կազմաձևը

Այս թույլտվությունները տրամադրելով՝ ձեզ հասանելի կդառնան Outline-ի սերվերների կառավարման լրացուցիչ հնարավորություններ, այդ թվում՝

- ճիշտ վճարային օգտահաշիվն ընտրելու հնարավորություն,
- Outline-ի սերվերների կազմակերպման համար նոր նախագծի ստեղծման հնարավորություն,
- տվյալների մշակմամբ զբաղվող հասանելի կենտրոնների ցանկի ստեղծման հնարավորություն,
- Outline-ի գործարկման համար նոր վիրտուալ մեքենաների ստեղծման հնարավորություն,
- Outline-ը նոր վիրտուալ մեքենաներում կարգավորելու հնարավորություն։

## Թույլտվությունների չեղարկում

Դուք կարող եք չեղարկել Google Cloud Platform-ի հասանելիությունը Outline Manager-ի համար [Իմ հաշիվը](https://myaccount.google.com/permissions)բաժնում։ Երբ չեղարկեք թույլտվությունները, ավտոմատ կարգավորման միջոցով ստեղծված բոլոր սերվերները կշարունակեն նախկինի պես աշխատել, սակայն այլևս չեն հայտնվի Outline Manager-ում։ Թույլտվությունները վերականգնելու համար անհրաժեշտ է նորից միանալ Google Cloud Platform-ին՝ սկսելով ավտոմատ կարգավորման գործընթացը։

## Սերվերների կազմակերպում Outline-ի նախագծի օգնությամբ

Google Cloud-ի ավտոմատ կարգավորումն օգտագործում է մեկ [Google Cloud նախագիծ](https://cloud.google.com/resource-manager/docs/creating-managing-projects)՝ Outline-ի սերվերները կազմակերպելու համար։ Նախագիծը ստեղծվում է ավտոմատ կարգավորման գործառույթի առաջին օգտագործման ժամանակ։ Դրան հատկացվում է ID, որը բաղկացած է «Outline-» նախածանցից և պատահական նիշերի տողից։ Նախագծի ստեղծման ընթացքում դուք կարող եք փոխել ID-ն։ Ըստ կանխադրման՝ նախագիծը կպահվի «Outline servers» անվանումով։

## Վճարային օգտահաշիվ

Google Cloud նախագծերի համար անհրաժեշտ է նշել որևէ կապված «վճարային օգտահաշիվ»։ Երբ Google Cloud-ի ավտոմատ կարգավորման գործառույթն առաջին անգամ օգտագործեք, համակարգը ձեզնից կխնդրի տրամադրել վճարային օգտահաշիվ, որը պետք է կապվի Outline-ի սերվերների հետ։ Եթե վճարային օգտահաշվի հետ կապված խնդիրների պատճառով սերվերի աշխատանքն ընդհատվել է, մտեք [Google Cloud Console](https://console.cloud.google.com/getting-started), գտեք Outline-ի հետ կապված «Outline servers» անվանումով նախագիծը և թարմացրեք վճարային կարգավորումները։

## Սերվերների հեռացում

Ավտոմատ կարգավորման միջոցով ստեղծված սերվերները հեռացնելու ամենահեշտ եղանակը Outline Manager-ի միջոցով դա անելն է։ Եթե ուզում եք սերվերներն ինքնուրույն հեռացնել, մտեք [Google Cloud Console](https://console.cloud.google.com/getting-started), գտեք «Outline servers» անվանումով նախագիծը, որը ստեղծվել է սկզբնական կարգավորման ժամանակ, և հեռացրեք դրանից ռեսուրսները կամ անջատեք նախագիծը։
