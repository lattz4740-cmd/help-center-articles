---

Դուք կարող եք տեսնել սխալի մասին այս հաղորդագրությունը․ «Կարծես թե Outline-ը ճիշտ չէ տեղադրված։ Փորձեք նորից տեղադրել այն։ Եթե դա չօգնի, ապա [կարծիք ուղարկեք](https://support.getoutline.org/s/contactsupport?)»։

Եթե դուք Outline-ը օգտագործում եք Windows-ով աշխատող սարքում, կարող եք անսպասելի սխալի բախվել։ Նման դեպքերում անհրաժեշտ է հեռացնել Outline-ի TAP ադապտերը (դրայվերը) և նորից տեղադրել հավելվածը։ Հիմնականում դա օգնում է։

Ստորև կգտնեք ընդհանուր ցուցումներ՝ TAP ադապտերն ու Outline Manager-ը ապատեղադրելու և հավելվածը նորից տեղադրելու համար։ Այս գործողությունները կարող են տարբեր լինել՝ կախված Windows-ի ձեր օգտագործած տարբերակից։

1. Ապատեղադրեք Outline Manager-ի TAP ադապտերը։
   1. Անցեք «Սարքերի կառավարիչ», ապա «Ցանցային ադապտերներ»
   2. Գտեք «TAP-Windows Adapter V9» ֆայլը կամ Outline-ի հետ կապված TAP ադապտերը։
   3. Ապատեղադրեք կամ ջնջեք այս ադապտերը։ Նկատի ունեցեք, որ այս գործողությունը կարող է ազդել ձեր տեղադրած այլ VPN հավելվածների վրա։
2. Ապատեղադրեք Outline Manager-ը։
   1. Անցեք «Ծրագրեր և գործառույթներ», ապա «Ծրագրի ապատեղադրում»
   2. Գտեք Outline Manager հավելվածը և ապատեղադրեք այն
   3. [Ներբեռնեք Outline Manager-ի նոր տարբերակը](https://getoutline.org/get-started/#step-1) և նորից տեղադրեք այն ձեր Windows սարքում։ Նոր տեղադրման ընթացքում ավտոմատ կտեղադրվի նաև նոր TAP ադապտեր։

Եթե խնդիրը միևնույն է չի լուծվել, [դիմեք աջակցման ծառայություն](https://support.getoutline.org/s/contactsupport?)։
