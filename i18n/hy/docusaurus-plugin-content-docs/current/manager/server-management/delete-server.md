---

Ամպային ծառայությունների մատակարարների մեծ մասի պարագայում որոշակի վիրտուալ մեքենա հեռացնելը բավականին հեշտ է։

Եթե որպես ձեր ամպային ծառայությունների մատակարար օգտագործում եք DigitalOcean-ը, կարող եք ջնջել գոյություն ունեցող վիրտուալ մեքենան՝ սեղմելով ատամնանիվի կոճակը և ընտրելով «Destroy Server» (ջնջել սերվերը)։ Դրանից անմիջապես հետո ձեզ կառաջարկվի ստեղծել նոր վիրտուալ մեքենա և ընտրել դրա տեղակայման վայրը։

Եթե հեռացնեք Outline-ի սերվերը, այն ընդմիշտ կջնջվի, և դրա մուտքի բանալիներն այլևս վավեր չեն լինի։ Եթե չեք ուզում, որ օգտատերերը ժամանակավորապես կորցնեն Outline-ի հասանելիությունը, նախքան հին սերվերը ջնջելը [ստեղծեք Outline-ի նոր սերվեր](/manager/server-setup/setup-server) և հասանելի դարձրեք այն ձեր օգտատերերին։
