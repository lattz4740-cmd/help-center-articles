sidebar_label: "Ինչպե՞ս թարմացնել Outline-ի սերվերային ծրագրակազմը"
---

Անվտանգության թարմացումներն ավտոմատ տեղադրվում են Outline-ի սերվերներում [Watchtower](https://github.com/v2tec/watchtower) բաց կոդով դարանի օգնությամբ, որը պարբերաբար ստուգում է Outline-ի ծրագրակազմը պարունակող Docker պատկերը։

Բացի այդ՝ երբ դուք Outline-ը տեղադրում եք Outline Manager-ի միջոցով, ծրագիրը կարգավորում է Cron առաջադրանք՝ սերվերի ծրագիրը [Unattended Upgrades](https://wiki.debian.org/UnattendedUpgrades) (Ubuntu) գործառույթի միջոցով ավտոմատ նորացնելու և անհրաժեշտության դեպքում այն վերագործարկելու համար։ Նկատի ունեցեք, որ այս գործառույթը չի աշխատում ընդլայնված ռեժիմում՝ գոյություն ունեցող կարգավորումները պահպանելու համար (ենթադրվում է, որ խնամորդն օգտագործվում է այլ նպատակների համար)։
