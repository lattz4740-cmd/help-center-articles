Outline-ի սերվերի տեղադրումն ավարտելուց հետո դուք կարող եք այն հասանելի դարձնել օգտատերերին և կառավարել հասանելիությունը։ Ձեզնից հրավեր ստացած օգտատերերը կկարողանան ներբեռնել Outline հավելվածը, որպեսզի Outline-ի օգնությամբ պաշտպանեն իրենց ինտերնետ թրաֆիկը։

**Ինչպես հասանելի դարձնել Outline-ի ձեր սերվերը**

 Երբ Outline-ի սերվերի տեղադրումն ավարտվի, դուք կվերահղվեք սերվերի մանրամասների էջ Outline Manager-ում, որտեղ կարող եք ստեղծել մուտքի բանալիներ։ Իմացեք ավելին [մուտքի բանալիների մասին](/about/terminology)։

- Բանալիներ ստեղծելու համար էջի ներքևի հատվածում սեղմեք փոքր «+» պատկերակի վրա։
- Բանալիներով կիսվելու համար ստեղծեք հրավեր՝ սեղմելով յուրաքանչյուր բանալու աջ կողմում գտնվող կիսվելու պատկերակի վրա։ Պատճենեք և տեղադրեք այդ հրավերը հաղորդագրման ձեր համակարգում։

**Նոր գործառույթի հարցում․ հասանելիության տրամադրում Outline Manager հավելվածից**

 Սերվերների շատ ադմինիստրատորներ խնդրել են մեզ պարզեցնել հրավերների տրամադրման գործընթացը՝ հնարավորություն տալով մուտքագրել օգտատիրոջ էլ. հասցեն անմիջապես Outline Manager-ում։

Ցավոք, ամենայն հավանականությամբ մենք չենք ավելացնի այդ հնարավորությունը Outline Manager-ում։ Մեր հիմնական սկզբունքներից մեկը օգտատերերի գաղտնիության և անվտանգության պահպանումն է, ինչը նշանակում է, որ մենք դաշտեր չենք ավելացնում մեր ծառայություններում՝ էլ․ հասցեներ կամ կոնտակտային տվյալներ մուտքագրելու համար։

Ահա թե ինչու ենք մենք խնդրում սերվերի ադմինիստրատորներին, որ վերջնական օգտագործողներին հրավեր ուղարկելու համար օգտագործեն հաղորդագրման անվտանգ հարթակ, ինչպիսին է էլփոստը կամ պաշտպանված զրույցը։

**Օգտատերերի գործողությունները մուտքի բանալի ստանալուց հետո**

1. Օգտատերը կսեղմի հղումը՝ ծառայությունը սարքում տեղադրելու համար։
2. Նրան կառաջարկվի տեղադրել Outline հավելվածը, եթե նա արդեն դա չի արել։
3. Հրավերում զետեղված եզակի բանալու օգնությամբ օգտատերը սկզբնական կապ կհաստատի Outline-ի սերվերի հետ։
4. Դրանից հետո նա կկարողանա օգտագործել միացման/անջատման կոճակը՝ Outline-ի ձեր սերվերի միջոցով ինտերնետի հասանելիությունը կառավարելու համար։

**Ինչպես հեռացնել Outline-ի ձեր սերվերից օգտվելու թույլտվությունը**

 Outline Manager-ում, սերվերի մանրամասների էջում սերվերի յուրաքանչյուր բանալու աջ կողմում կա ընտրացանկ, որտեղ կգտնեք բանալին ջնջելու տարբերակը։ Երբ ջնջեք որևէ բանալի, այդ բանալու միջոցով սերվերից օգտվելու թույլտվությունը կհեռացվի։
