title: "Ինչպե՞ս զրոյացնել սերվերի ID-ն"
sidebar_label: "Ինչպե՞ս զրոյացնել սերվերի ID-ն"
---

Սերվերի ID-ն ստեղծվում է պատահական սկզբունքով, երբ դուք ստեղծում եք Outline-ի սերվեր։ Այս պարամետրը կարելի է գտնել այն կարգավորումներում, որոնք թույլ են տալիս միացնել անանուն վիճակագրության ուղարկումը։ Բացեք Կարգավորումները, իջեք ներքև և ընտրեք «share anonymous metrics» (կիսվել անանուն վիճակագրությամբ)։

Սերվերի ID-ն միավորում է հավաքված անանուն վիճակագրական տվյալները։ ID-ն զրոյացնելու և մեկ ուրիշը ստանալու համար Outline-ի ընթացիկ սերվերը փոխարինեք նորով։

Եթե որպես ձեր ամպային ծառայությունների մատակարար օգտագործում եք DigitalOcean-ը, կարող եք զրոյացնել ձեր սերվերը՝ անցնելով Կարգավորումներ և ընտրելով «Destroy Server» (ջնջել սերվերը)։ Այս գործողությունը հնարավոր չէ չեղարկել, և ձեր մուտքի բոլոր տվյալները կջնջվեն։ Այս գործողությունից անմիջապես հետո ձեզ կառաջարկվի ստեղծել նոր սերվեր ձեր ընտրած տեղակայման վայրում, որից հետո կստեղծվի սերվերի նոր ID։
