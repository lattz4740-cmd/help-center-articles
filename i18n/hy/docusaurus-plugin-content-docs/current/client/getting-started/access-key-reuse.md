Այո։ Դուք կարող եք օգտագործել ձեր [մուտքի բանալին](/about/terminology) մի քանի սարքերում, սակայն խորհուրդ չենք տալիս այն տրամադրել կողմնակի անձանց։ Օգտատերը, ում տրամադրվել է ձեր մուտքի բանալին, կարող է ստուգել ձեր ողջ ինտերնետ թրաֆիկը, եթե մուտք ունենա այն ամենին, ինչը ձեր ինտերնետի օգտագործման անվտանգ կամ անձնական լինելը դնում է կասկածի տակ։
