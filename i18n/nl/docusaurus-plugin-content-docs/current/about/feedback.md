title: Feedback of suggesties sturen
sidebar_label: Feedback of suggesties sturen
---

Bedankt dat je ons helpt Outline te verbeteren! Je kunt op verschillende manieren feedback sturen. Dit kan anoniem, maar als je een reactie wilt, moet je je e-mailadres toevoegen:

- **Voor ontwikkelaars**: Outline is opensource-software. Alle code wordt gehost op [GitHub](https://github.com/Outline-Foundation/?q=outline). Je kunt je ideeën delen op GitHub of via onze [Reddit](https://www.reddit.com/r/outlinevpn/)-community.
- **Voor gebruikers**: Je kunt ons via de Outline- of Outline Manager-app feedback sturen. Vul je feedback in en voeg optioneel je e-mailadres toe, zodat we je een bericht terug kunnen sturen. We verzamelen ook bepaalde metadata over je omgeving, zoals welke browser, welk besturingssysteem en welke softwareversie je gebruikt. Met deze informatie kunnen we je helpen om problemen op te lossen.
- **Via deze site**: Klik op de link Contact opnemen, die je op verschillende plekken op deze site vindt.
- **Ernstige problemen**: Als je een ernstig beveiligingsprobleem wilt melden, vragen we je meer informatie per e-mail te sturen naar security [apenstaartje] [getoutline.org](https://getoutline.org/).

Nogmaals bedankt dat je de tijd neemt om je ideeën met ons te delen.
