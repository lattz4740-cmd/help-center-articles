---
title: "Welke systeemvereisten zijn nodig voor de Outline-client?"
sidebar_label: "Welke systeemvereisten zijn nodig voor de Outline-client?"
---

Je kunt Outline proberen op elk besturingssysteem. De volgende besturingssystemen zijn minimaal vereist:

| **Besturingssysteem** | **Minimumversie** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Wil je de Outline-client op meer besturingssystemen laten werken? [Draag dan bij aan onze codebase](https://github.com/Jigsaw-Code/outline-client#platform-specific-development) op GitHub!
