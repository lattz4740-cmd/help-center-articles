---
title: "Kan ik een toegangssleutel meerdere keren gebruiken?"
sidebar_label: "Kan ik een toegangssleutel meerdere keren gebruiken?"
---

Ja. Je kunt je [toegangssleutel](/about/terminology) op zo veel apparaten gebruiken als je wilt. We raden je wel aan de sleutel niet met anderen te delen. Iemand met je toegangssleutel kan al je internetverkeer inspecteren als diegene er toegang toe heeft. Je internetgebruik is dan niet meer beveiligd of privé.
