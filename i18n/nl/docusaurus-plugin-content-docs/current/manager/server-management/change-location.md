---
title: "Hoe wijzig ik de locatie van de Outline-server?"
sidebar_label: "Hoe wijzig ik de locatie van de Outline-server?"
---

Als je een server eenmaal hebt ingesteld, kun je de locatie niet meer wijzigen. Als je je Outlook-server wilt uitvoeren vanaf een andere locatie, moet je de server verwijderen en een nieuwe maken.

Je kunt ook de locatie van je VPN wijzigen met [dynamische sleutels](https://developer.getoutline.org/vpn/management/dynamic-access-keys/). Je kunt dan servers roteren en dezelfde sleutels blijven gebruiken. De locatie van de servers zelf blijft hetzelfde.
