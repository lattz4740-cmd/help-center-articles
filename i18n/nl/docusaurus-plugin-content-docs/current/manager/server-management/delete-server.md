---
title: "Hoe verwijder ik mijn Outline-server?"
sidebar_label: "Hoe verwijder ik mijn Outline-server?"
---

Bij de meeste cloudproviders kun je makkelijk de specifieke virtuele machine verwijderen die je gebruikt.

Als je DigitalOcean gebruikt als cloudprovider, kun je de bestaande virtuele machine verwijderen door op het tandwielicoon te klikken en **Destroy Server** (Server vernietigen) te selecteren. Meteen daarna wordt je gevraagd een nieuwe virtuele machine te maken in een locatie naar keuze.

Als je een Outline-server verwijdert, wordt deze definitief verwijderd en werken de toegangssleutels niet meer. Als je wilt dat mensen ononderbroken toegang blijven houden tot Outline, moet je [een nieuwe Outline-server instellen](/manager/server-setup/setup-server) en de toegang tot die server delen voordat je de oude server verwijdert.
