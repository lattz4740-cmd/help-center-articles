---
title: "Hoe reset ik de server-ID?"
sidebar_label: "Hoe reset ik de server-ID?"
---

De server-ID is een ID aan de serverzijde die willekeurig wordt gegenereerd als je een Outline-server maakt. Je krijgt de ID als je je aanmeldt om anonieme statistieken te delen in de interface Settings (Instellingen). Je vindt de server-ID als volgt: Settings (Instellingen) => scroll naar onderen => vink het vakje aan voor Anonieme statistieken delen.

De server-ID wordt gebruikt om anonieme gebruiksstatistieken van een bepaalde periode samen te voegen. Als je de server-ID wilt resetten en een nieuwe wilt krijgen, moet je je bestaande Outline-server vervangen door een nieuwe.

Als je DigitalOcean gebruikt als cloudprovider kun je de server resetten door naar

(Instellingen) te gaan en

(Server vernietigen) te selecteren. Je kunt deze actie niet ongedaan maken en hierbij worden je inloggegevens gewist. Meteen nadat je deze actie uitvoert, wordt je gevraagd een nieuwe server te maken in een locatie naar keuze en krijg je een nieuwe server-ID.
