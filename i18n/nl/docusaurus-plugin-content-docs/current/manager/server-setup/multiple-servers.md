Als je aanvullende Outline-servers wilt instellen, klik je in het navigatievenster links in de Outline Manager-app op de plus. Je voegt een nieuwe server op dezelfde manier toe als de eerste server.

- Er is geen limiet aan het aantal Outline-servers dat je kunt maken.
- Voor elke Outline-server die je maakt, moet je een virtuele machine hebben.
- Als je aanvullende machines of droplets maakt, moet je wellicht meer betalen bij je cloudprovider. Bekijk de prijzen bij je cloudprovider om te zien wat je kunt verwachten.

## Een aanvullende Outline-server maken bij DigitalOcean

Nadat je op de plus hebt geklikt en hebt geselecteerd dat je de server wilt installeren bij DigitalOcean, volg je dezelfde instructies als toen je de eerste server instelde. Omdat Outline Manager is geïntegreerd met DigitalOcean, kan de droplet rechtstreeks in de Outline Manager-app voor je worden gemaakt.

 In Outline Manager kan slechts één DigitalOcean-account tegelijk worden gebruikt. Als je andere Outline-servers wilt toevoegen of maken vanuit andere DigitalOcean-accounts, kun je deze toevoegen als geavanceerde configuraties.

## Een aanvullende Outline-server maken bij GCP, AWS of een andere cloudserviceprovider

Maak eerst een nieuwe virtuele machine bij je cloudprovider. Open vervolgens Outline Manager en doorloop de instructies voor de geavanceerde installatie, net zoals je wellicht bij de eerste installatie hebt gedaan.
