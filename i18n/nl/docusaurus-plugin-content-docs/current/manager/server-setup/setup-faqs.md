## Kan ik Outline gebruiken zonder server?

Helaas niet. De Outline-software moet toegang hebben tot een server, of deze nu door jou, je organisatie of een vertrouwde derde partij wordt beheerd.

## Hoelang duurt het om een Outline-server in te stellen?

In de meeste gevallen duurt dit niet meer dan vijf minuten. Je kunt Outline installeren op elke cloudserver, maar we hebben samen met DigitalOcean een gebruiksvriendelijke, begeleide installatie ontwikkeld. Zo kun je je server met enkele muisklikken instellen, zonder scripts te hoeven gebruiken.

 Als je hebt gekozen voor installatie via AWS, GCP of de geavanceerde installatie, bestaat de installatie uit één eenvoudig script dat in de meeste omgevingen kan worden gebruikt.

## Waar kan ik een Outline-server instellen?

Je kunt een Outline-server instellen bij de meeste cloudproviders, waar deze zich ook bevinden.

 De eenvoudigste optie is om de server in te stellen bij DigitalOcean, omdat dit bedrijf servers op meerdere locaties heeft, zoals in Amsterdam, Toronto, San Francisco en Singapore. Als je de Outline-server wilt installeren bij een andere cloudprovider of op je eigen infrastuctuur, kies je de 'Geavanceerde modus' in de Outline Manager-app en volg je de installatie-instructies met een installatiescript.

## Waar moet ik de Outline-server instellen?

Je moet een paar overwegingen maken wanneer je bepaalt waar je de Outline-server gaat instellen:

1. De locatie van de Outline-server bepaalt de gebruikerservaring op internet. Als de server zich bijvoorbeeld in Parijs bevindt, zien gebruikers die verbinding maken via deze server het internet alsof ze zich fysiek in Frankrijk bevinden. Sommige websites worden zelfs in het Frans weergegeven. Je kunt de taal meestal wijzigen met een taalselector op de website.
2. De afstand tussen je gebruikers en de Outline-server kan invloed hebben op de internetsnelheid. Over het algemeen heeft de fysieke afstand tussen Outline-gebruikers en de server invloed op de internetsnelheid van de gebruikers. In de meeste gevallen kun je de serverlocatie kiezen die het dichtst ligt bij waar je verwacht dat je gebruikers zijn, maar je kunt ook de [Submarine Cable Map](https://www.submarinecablemap.com/) (Kaart met onderzeese kabels) bekijken om te zien welke internetkabels er lopen naar je land of regio.
3. De locatie van je VPN-server kan invloed hebben op welke wetten en regelgevingen er voor je gelden. De Outline-software slaat je verkeer niet op. Meer informatie over [beveiliging en privacy bij het gebruik van Outline](/about/security-and-privacy).
