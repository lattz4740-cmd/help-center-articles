sidebar_label: "Hoe stel ik een Outline-server in?"
---

Voordat je Outline kunt gaan gebruiken, moet je als eerste een Outline-server instellen. Jij of iemand die je vertrouwt moet de server voor je instellen, zodat je via Outline verbinding kunt maken met het open internet.

## Voordat je begint

Je hebt het volgende nodig om de Outline-server in te stellen:

1. Toegang tot je eigen servers of een provider van cloudservices, zoals DigitalOcean, Amazon Web Services (AWS) of Google Cloud Platform (GCP).

 Als je niet meteen toegang hebt tot een cloudserver, kun je eenvoudig een account instellen bij een provider, zoals de providers die hierboven zijn genoemd. Je hebt waarschijnlijk een creditcard nodig om je aan te melden.
2. Een desktop met macOS 10.9+, Windows 7.0+ of Linux.
3. De Outline Manager-app.

## Instellen bij DigitalOcean

We hebben het heel eenvoudig gemaakt om Outline met enkele muisklikken te installeren bij DigitalOcean. Nadat je Outline Manager hebt gedownload en geïnstalleerd op je computer, kun je de installatieoptie 'DigitalOcean' selecteren. Je wordt dan in enkele schermen door de stappen geleid om je Outline-server te configureren en installeren.

## Instellen bij een andere cloudprovider

Nadat je Outline Manager hebt gedownload en geïnstalleerd, kun je de optie selecteren om een Outline-server op een virtuele machine te installeren via AWS, GCP, DigitalOcean of een andere provider. Elke omgeving is anders. In de installatieflow van Outline Manager vind je instructies voor de meestgebruikte cloudproviders. Daarin staat bijvoorbeeld hoe je de instellingen op de virtuele machine moet configureren voordat je het installatiescript uitvoert om Outline op een server te installeren.
