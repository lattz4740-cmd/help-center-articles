sidebar_label: "Ik ben een ontwikkelaar. Waar kan ik support krijgen om de Outline SDK te integreren in mijn app?"
---

Deze supportwebsite is bedoeld voor gebruikers van Outline Manager en Outline-client. Ontwikkelaars, gebruik GitHub voor support. Als je een vraag wilt stellen, kun je deze toevoegen aan het SDK-[discussiebord](https://github.com/Jigsaw-Code/outline-sdk/discussions). Het discussiebord is de perfecte plek om vragen te stellen en ideeën te delen. Ook kun je hierop linken naar demo's en andere ontwikkelaars helpen die ook de Outline SDK gebruiken. Voor functieverzoeken of bugrapporten open je een [Issue](https://github.com/Jigsaw-Code/outline-sdk/issues/new) (Probleem).
