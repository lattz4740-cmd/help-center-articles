Outline એ VPN સેવાઓ જેવું નથી જેનો તમે ઍક્સેસ ખરીદો છો; તે [એવું ટૂલ](https://getoutline.org/#:~:text=Two%20Products%20that%20Work%20Together) છે જે તમને કોઈ ખાનગી VPN સર્વરનો ઍક્સેસ ચલાવવાની અને શેર કરવાની મંજૂરી છે. ફક્ત [સેવાના મેનેજર](/about/terminology#servicemanager) ઍક્સેસ કી પ્રદાન કરી શકે છે. Outline ટીમ મફત અથવા સશુલ્ક ઍક્સેસ વિતરિત કરતી નથી. અમે કોઈ આધિકારિક Outline ઍક્સેસ કી પાર્ટનર ધરાવતા નથી, સિવાય કે ફારસીમાં Paskoocheh.

 આ રહ્યાં ઍક્સેસ મેળવવાના ત્રણ વિકલ્પો:

- તેમના સર્વર પર તમને આમંત્રિત કરવા માટે કોઈને કહો: જો તમે Outline સર્વર ધરાવતી કોઈ વ્યક્તિને ઓળખતા હો, તો તેમનો સંપર્ક કરો અને તેમને ઍક્સેસ કી માટે પૂછો.
- [તમારી પોતાની જાતે સર્વર બનાવો:](/manager/server-setup/setup-server) Windows, Mac અથવા Linux કમ્પ્યૂટરનો ઉપયોગ કરીને [Outline Manager](https://getoutline.org/get-started/#step-1) ડાઉનલોડ કરો અને તમારા પોતાના ખાનગી [Outline સર્વર](/about/terminology)નું સેટઅપ કરો. કોઈપણ વ્યક્તિ કરી શકે તે માટે અમે આ પ્રક્રિયાને સરળ બનાવી છે, ખાસ કરીને ક્લાઉડ સેવા પ્રદાતા DigitalOcean મારફતે.
- Outline અથવા [Shadowsocks](https://en.wikipedia.org/wiki/Shadowsocks#:~:text=Shadowsocks%20is%20a%20free%20and,have%20been%20made%20available%20since.) સેવાનો ઉપયોગ કરો: Outline ક્લાયન્ટનો ઉપયોગ ત્રીજા પક્ષની સેવાઓ સાથે પણ કરી શકાય છે, જે Outline અથવા Shadowsocks પ્રોટોકૉલનો ઉપયોગ કરતી હોય. ઉદાહરણ તરીકે:
   - [nthLink](http://nthlink.com/) Outline ક્લાયન્ટના ફેરફાર કરેલા વર્ઝન સાથે Outline પર આધારિત મફત સેવા ચલાવે છે.
   - [ASL19](https://www.reddit.com/r/outlinevpn/comments/nwu1se/the_outline_distribution_system_is_here_to_help/) Outline [BeePass](https://beepassvpn.com/) નામક ફેરફાર કરેલું વર્ઝન તેમજ [Telegram બૉટ](https://t.me/paskoochehbot) ચલાવે છે, જે BeePass સર્વરની મફત ઍક્સેસ કી પ્રદાન કરે છે.
   - ફારસી ભાષાના વપરાશકર્તાઓ [ASL19’s Paskoocheh](https://outline.paskoocheh.com/)માંથી પણ Outlineની ઍક્સેસ કીની વિનંતી કરી શકે છે.

Outline Client ઍપ ડાઉનલોડ કર્યા પછી, Outline સર્વર સાથે કનેક્ટ કરવા માટે Outline Clientમાં તમારી [ઍક્સેસ કી](/about/terminology#accesskey) કૉપિ પેસ્ટ કરો.
