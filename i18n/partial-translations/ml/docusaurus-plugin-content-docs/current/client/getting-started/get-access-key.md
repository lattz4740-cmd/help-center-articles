നിങ്ങൾ സെർവറിലേക്ക് ആക്‌സസ് വാങ്ങുന്ന മറ്റ് VPN സേവനങ്ങൾ പോലെയല്ല Outline ആപ്പ്; നിങ്ങളുടെ സ്വകാര്യ VPN സെർവർ റൺ ചെയ്യാനും ആക്സസ് പങ്കിടാനും നിങ്ങളെ അനുവദിക്കുന്ന ഒരു [ടൂളാണ്](https://getoutline.org/#:~:text=Two%20Products%20that%20Work%20Together) ഇത്. ആക്സസ് കീ നൽകാൻ കഴിയുന്ന ഒരേ ഒരു വ്യക്തിയാണ് [സേവന മാനേജർ](/about/terminology#servicemanager). Outline ടീം, നിരക്കില്ലാത്തതോ പണമടച്ചുള്ളതോ ആയ ആക്സസ് കീകൾ വിതരണം ചെയ്യുന്നില്ല. ഫാർസിയിലെ Paskoocheh ഒഴികെ, ഞങ്ങൾക്ക് ഔദ്യോഗിക Outline ആക്‌സസ് കീ പങ്കാളികളൊന്നുമില്ല.

 ആക്സസ് കീ നേടാൻ മൂന്ന് ഓപ്ഷനുകൾ ഇതാ:

- ആരോടെങ്കിലും അവരുടെ സെർവറിലേക്ക് നിങ്ങളെ ക്ഷണിക്കാൻ ആവശ്യപ്പെടുക: Outline സെർവറുള്ള ആരെയെങ്കിലും നിങ്ങൾക്ക് പരിചയമുണ്ടെങ്കിൽ, അവരെ ബന്ധപ്പെടുകയും ഒരു ആക്സസ് കീ ആവശ്യപ്പെടുകയും ചെയ്യുക.
- [സ്വയം ഒരു സെർവർ സൃഷ്ടിക്കുക:](/manager/server-setup/setup-server) Windows, Mac, അല്ലെങ്കിൽ Linux കമ്പ്യൂട്ടർ ഉപയോഗിച്ച്, [ഔട്ട്‌ലൈൻ മാനേജർ](https://getoutline.org/get-started/#step-1) ഡൗൺലോഡ് ചെയ്ത് നിങ്ങളുടേതായ സ്വകാര്യ [Outline സെർവർ](/about/terminology) സജ്ജീകരിക്കുക. എല്ലാ ഉപയോക്താക്കൾക്കും, പ്രത്യേകിച്ച് ഞങ്ങളുടെ ക്ലൗഡ് സേവന ദാതാക്കളായ DigitalOcean മുഖേന, ഞങ്ങൾ ഈ പ്രക്രിയ എളുപ്പമാക്കിയിട്ടുണ്ട്.
- Outline അല്ലെങ്കിൽ [Shadowsocks](https://en.wikipedia.org/wiki/Shadowsocks#:~:text=Shadowsocks%20is%20a%20free%20and,have%20been%20made%20available%20since.) സേവനം ഉപയോഗിക്കുക: Outline അല്ലെങ്കിൽ Shadowsocks പ്രോട്ടോക്കോൾ ഉപയോഗിക്കുന്ന മൂന്നാം കക്ഷി സേവനങ്ങളിലും Outline Client ഉപയോഗിക്കാനാകും. ഉദാഹരണത്തിന്:
   - Outline Client-ന്റെ പരിഷ്കരിച്ച പതിപ്പ് ഉപയോഗിച്ച്, Outline അടിസ്ഥാനമാക്കിയുള്ള ഒരു സൗജന്യ സേവനമാണ് [nthLink](http://nthlink.com/) നടത്തുന്നത്.
   - [ASL19](https://www.reddit.com/r/outlinevpn/comments/nwu1se/the_outline_distribution_system_is_here_to_help/), [BeePass](https://beepassvpn.com/) എന്ന് അറിയപ്പെടുന്ന Outline-ന്റെ പരിഷ്‌കരിച്ച പതിപ്പും BeePass സെർവറുകളിലേക്ക് സൗജന്യ ആക്സസ് കീകൾ നൽകുന്ന [Telegram ബോട്ടും](https://t.me/paskoochehbot) റൺ ചെയ്യുന്നു.
   - ഫാർസി ഭാഷാ ഉപയോക്താക്കൾക്ക് [ASL19-ന്റെ Paskoocheh](https://outline.paskoocheh.com/)-യിൽ നിന്ന് ഔട്ട്‌ലൈൻ ആക്സസ് കീ അഭ്യർത്ഥിക്കുകയും ചെയ്യാം.

Outline Client ആപ്പ് ഡൗൺലോഡ് ചെയ്തതിന് ശേഷം, Outline സെർവറിലേക്ക് കണക്റ്റ് ചെയ്യാൻ Outline Client-ലേക്ക് നിങ്ങളുടെ [ആക്സസ് കീ](/about/terminology#accesskey) പകർത്തി ഒട്ടിക്കുക.
