---
title: "Ṣé mo lè lo kọ́kọ́rọ́ ìwọlé kan ju ẹ̀ẹ̀kan lọ?"
sidebar_label: "Ṣé mo lè lo kọ́kọ́rọ́ ìwọlé kan ju ẹ̀ẹ̀kan lọ?"
---

Bẹ́ẹ̀ ni. O lè lo [kọ́kọ́rọ́ ìwọlé](/outline-faq/ìdáhùn/15330920) rẹ lóríi èyíkéyìí iye àwọn ẹ̀rọ rẹ, ṣùgbọ́n a kò dábàá kí o pín kọ́kọ́rọ́ rẹ pẹ̀lú ẹlòmíràn. Ẹni tó bá ní kọ́kọ́rọ́ ìwọlé rẹ lọ́wọ́ lè ṣe àyẹ̀wò gbogbo lílọ-bíbọ̀ orí ìtàkùn ayélujára rẹ tí wọ́n bá rí àyè wọlé síi, èyí tí kò ní jẹ́ kí ààbò wà mọ́ lóríi lílo ìtàkùn ayélujára rẹ tàbí kí ó má jẹ́ kí ó wà ní ìkọ̀kọ̀ mọ́.
