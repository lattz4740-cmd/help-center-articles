---

I-Outline ayifani namasevisi e-VPN othenga ukufinyelela kuwo; [iyithuluzi](https://getoutline.org/#:~:text=Two%20Products%20that%20Work%20Together) elikuvumela ukuthi usebenzise futhi wabelane ngokufinyelela kuseva ye-VPN egodliwe. [Umphathi wesevisi](/about/terminology#servicemanager) nguye kuphela umuntu onganikeza ukhiye wokufinyelela. Ithimba le-Outline alibasabalalisi okhiye bokufinyelela bamahhala noma abakhokhelwayo. Asinabo ozakwethu bokhiye bokufinyelela be-Outline, ngaphandle kwePaskoocheh ngesiFarsi.

 Nakhu okungakhethwa kukho okuthathu kokuthola ukhiye wokufinyelela:

- Cela othile ukuthi akumemele kuseva yakhe: Uma wazi othile oneseva ye-Outline, xhumana naye futhi umcele ukhiye wokufinyelela.
- [Sungula iseva ngokwakho:](/manager/server-setup/setup-server) Usebenzisa ikhompyutha yeWindows, yeMac, noma yeLinux, dawuniloda [i-Outline Manager](https://getoutline.org/get-started/#step-1) futhi usethe [iseva ye-Outline](/about/terminology) yakho egodliwe. Senze le nqubo yaba lula kunoma ngubani ukuba ayenze, ikakhulukazi ngomhlinzeki wesevisi ye-cloud iDigitalOcean.
- Sebenzisa isevisi ye-Outline noma [yeShadowsocks](https://zu.wikipedia.org/wiki/Shadowsocks#:~:text=Shadowsocks%20is%20a%20free%20and,have%20been%20made%20available%20since.): I-Outline Client ingasetshenziswa namasevisi ezinkampani zangaphandle asebenzisa iphrothokholi ye-Outline noma yeShadowsocks. Ngokwesibonelo:
   - [InthLink](http://nthlink.com/) isebenzisa isevisi yamahhala esekelwe ku-Outline, enohlobo olulungisiwe lweklayenti ye-Outline.
   - [I-ASL19](https://www.reddit.com/r/outlinevpn/comments/nwu1se/the_outline_distribution_system_is_here_to_help/) isebenzisa uhlobo oluguquliwe lwe-Outline olubizwa [ngeBeePass](https://beepassvpn.com/) kanye [ne-bot yeTelegram](https://t.me/paskoochehbot) enikeza okhiye bokufinyelela mahhala kumaseva eBeePass.
   - Abasebenzisi bolimi lwesiFarsi bangaphinda bacele ukhiye wokufinyelela we-Outline [ku-ASL19’s Paskoocheh](https://outline.paskoocheh.com/).

Ngemva kokudawuniloda i-app ye-Outline Client, kopisha futhi unamathisele [ukhiye wakho wokufinyelela](/about/terminology#accesskey) ku-Outline Client ukuze uxhume kuseva ye-Outline.
