Ukuvikeleka nobumfihlo lapho usebenzisa Isendlalela

## Indlela Isendlalela esivikela ngayo ukuxhumana kwakho ne-inthanethi

Ithrafikhi ye-inthanethi igadwa kakhulu lapho ihamba kunethiwethi yendawo okuyo noma kwekazwelonke.

Isendlalela sisiza ekugcineni ukuxhuma kwakho kuyimfihlo ngokubethela ithrafikhi ye-inthanethi yakho lapho ihamba kunethiwekhi yezwe okulo futhi siyigcina ebitheliwe ize ifike kuseva yeSendlelela. Uma ithrafikhi ibethelwe ngeSendlalela, ababuke inethiwekhi abakwazi ukuhlola amawebhusayithi owavakashele, noma imininingwane oyidlulisile.

Isendlalela singaphinde sikusize ukwazi ukubuyelwa ukufinyelela emathuluzini okuxhumana avikelekile okungenzeka awafinyeleleki ezweni okulo.

## Izindlela zokubethela ezijwayelekile

Isendlalela sibethela ukuxhumana phakathi kwedivayisi yakho neSeva Yesendlalela sisebenzisa icipher eyi-AEAD 256-bit Chacha2020 IETF Poly 1305. Amacipher ayi-AEAD aqinisekisa ubumfihlo, ubuqotho, nobuqiniso, futhi enza ihadiwe yesimanje isebenze ngendlela enhle kakhulu.

## Ukuhlola ukuvikeleka

Ngo-2018, Isendlalela sahlolwa iRadically Open Security neCure53, okuyizinhlangano ezimbili ezizimele zezokuphepha kwedijithali ezibuyekeza isofthiwe ziyiqhathanise nokuvikeleka kwamuva okujwayelekile. IRadically Open Security yenza okunye ukuhlola amabhuku kwango-2022 kwathi iCure53 yahlola i-SDK Yesendlalela ngo-2024. Ungawufunda lapha umbiko:

- [Umbiko Wokuhlola Kokubholayo WeRadically Open Security (Mashi 2018)](https://getoutline.org/reports/ros-report.pdf)
- [Umbiko WeCure53 Wokuhlola Kokubholayo Nokuhlola Amabhuku Isendlalela SeJigsaw (Disemba 2018)](https://getoutline.org/reports/cure53-report.pdf)
- [Umbiko Wokuhlola Kokubholayo WeRadically Open Security (Disemba 2022)](https://getoutline.org/reports/ros-report-2022.pdf)
- [Umbiko WeCure53 Wokuhlola Kokubholayo Isendlalela SeJigsaw VPN SDK (Januwari 2024)](https://getoutline.org/reports/cure53-report-SDK-2024.pdf)

## Amametric namalogu enziwe angaziwa

Isendlalela sithrekha umkhawulo-kudonsa osetshenzisiwe, "njengamabhayithi adlulisiwe" ngokhiye ngamunye wokufinyelela. Le mininingwane ivumela abalawuli bamaseva ukuba balungise imikhawulo-kudonsa yababhalise kubo ukuze ivumelane neyabahlinzeki beseva yabo yecloud uma kudingeka, kodwa ayibavumeli ukuba babone imininigwane engokoqobo edlule kuseva yeSendlalela.

Funda kabanzi [ngokuqoqwa kwedatha nemininingwane](https://getoutline.org/policies/data-collection) yeSendlalela.

## Imibuzo Evamile yokuvikeleka nobumfihlo

## Isendlalela singakwazi yini ukungenza ngingaziwa ku-inthanethi?

Cha, Isendlalela asilona ithuluzi elingakwenza ungaziwa. Isendlalela sivikela ubumfihlo bakho kubantu abangase babuke inethiwekhi.

Isendlalela asikwazi ukukwenza ungaziwa ngokuphelele kumawebhusayithi owavakashelayo, ngoba asengakwazi ukukubona lapho ungena ngemvume futhi ngezinye izikhathi esebenzisa amaqhinga athile, njengesigxivizo somunwe sebhrawuza. Kuma-app eselula, amasmathifoni amaningi esimanje anama-API avumela ama-app afakiwe ukuba aveze indawo okuyo engahlangene nommeleli wakho njengoba encike ku-GPS eshumekiwe.

Ngokuvamile ama-VPN ahlinzeka ngezivikelo ezibalulekile, ikakhulukazi ukugadwa ku-inthanethi, nokho zihlezi zikhona izingozi lapho kusetshenziswa i-inthanethi. Ngisho noma une-VPN, uma i-ISP isikwazi kakade ukuthi ungubani futhi iyibona ithrafikhi yakho yethiwekhi, ingakwazi ukuthola ikheli le-IP yeSendlalela seseva yakho. Le mininingwane ingasetshenziselwa ukuvimba ukufinyelela kuseva yeSendlalela noma ukufunda amaphethini endlela osebenza ngayo, njengalapho uvame ukusebenzisa khona i-inthanethi, futhi mhlawumbe nendawo okuyo.

## Abantu bayakwazi yini ukubona ukuthi ngisebenzisa Isendlalela?

Kungenzeka. Izinkundla namasevisi okwazi ukuwafinyelela cishe ayobona ukuthi indlela oxhume ngayo ivela kuseva yecloud. Ngezikhathi ezithile, ayoqaphela ukuthi usebenzisa i-VPN, kodwa ngeke akwazi ukubona okuqukethwe ithrafikhi ye-inthanethi yakho.

## Isendlalela siyakwazi yini ukungivikela kuzo zonke izingozi ezihlobene necyber?

Cha. Alikho ithuluzi elilodwa elingakuvikela kuzo zonke izingozi ezihlobene necyber. Isendlalela sikuvumela ukuba ufinyelele ku-inthanethi evulekile futhi sandisa ubumfihlo bakho ngokubethela ithrafikhi yakho, kodwa esikuncomayo ukuba uthathe izinyathelo ezengeziwe zokuzivikela kwezinye izinhlobo zokuhlaselwa, njengohlelo olungayilungele ikhophyutha nobugebengu bokweba imininingwane ebucayi.

Ukuze uqinise izivikelo zakho lapho usebenzisa i-inthanethi, sicela ucabangele ukusebenzisana nongoti wecybersecurity enhlanganweni yakho. Kungenjalo, ungathola isiqondiso esiqondene nawe siqu kongoti abahamba phambili kwezokuvikeleka [kuSecurity Planner](https://securityplanner.org/), okuyiwebhusayithi eyakhelwe ukukuhlinzeka ngemiyalelo yokukhetha amathuluzi afanele ecybersecurity ngokukukhathazayo.

Ungaphinde uhlole eminye imikhiqizo yecybersecurity [kuJigsaw](https://jigsaw.google.com/), [njenge-Intra](https://getintra.org/), [iProject Shield](https://g.co/shield), kanye [nePhasiwedi Alert](https://chrome.google.com/webstore/detail/password-alert/noondiphcddnnabmjcihcjfbhfklnnep?).

## Kusemthethweni yini ukusebenzisa i-VPN?

Sicela ubheke imithetho, imithetho-nqubo, neMigomo Yesevisi yomhlinzeki wecloud ohlela ukuyisebenzisa endaweni ohlala kuyo ngaphambi kokusebenzisa Isendlalela noma ukusebenzisa i-app.
