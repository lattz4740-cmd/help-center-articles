---

Esate kviečiami išbandyti „Outline“ bet kurioje operacinėje sistemoje. Toliau nurodyti minimalūs operacinių sistemų reikalavimai.

| **Operacinė sistema** | **Minimali versija** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | 20.04 versijos „Ubuntu“ |

Norite padėti, kad „Outline“ kliento programa veiktų daugiau operacinių sistemų? [Bendradarbiaukite padėdami kurti mūsų kodo bazę](https://github.com/Jigsaw-Code/outline-client#platform-specific-development) sistemoje „GitHub“!
