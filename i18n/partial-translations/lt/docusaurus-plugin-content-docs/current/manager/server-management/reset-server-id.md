---
title: "Kaip iš naujo nustatyti serverio ID?"
sidebar_label: "Kaip iš naujo nustatyti serverio ID?"
---

Serverio ID – tai atsitiktinai serverio sugeneruotas serverio ID, kuris sukuriamas sukūrus „Outline“ serverį. Jį rasite pasirinkę bendrinti anoniminę metriką „Nustatymų“ sąsajoje. Jei norite rasti serverio ID: eikite į Nustatymai => slinkite iki apačios => pažymėkite „bendrinti anoniminę metriką“.

Serverio ID susieja per laiką ataskaitose pateiktą anoniminę naudojimo statistiką. Jei norite iš naujo nustatyti serverio ID ir gauti naują, turite pakeisti esamą „Outline“ serverį nauju.

Jei kaip debesų paslaugos teikėją naudojate „DigitalOcean“, galite iš naujo nustatyti serverį nuėję į „Nustatymus“ ir pasirinkę „Naikinti serverį“. Šio veiksmo anuliuoti negalima ir jį atlikus bus ištrinti visi prisijungimo duomenys. Iškart po šio veiksmo būsite paraginti sukurti naują serverį pasirinktoje vietoje ir bus sugeneruotas naujo serverio ID.
