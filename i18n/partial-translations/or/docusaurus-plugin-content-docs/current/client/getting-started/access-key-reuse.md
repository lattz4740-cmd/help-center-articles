sidebar_label: "ମୁଁ ଏକ ଆକ୍ସେସ କୀ ଏକାଧିକ ଥର ବ୍ୟବହାର କରିପାରିବି?"
---

ହଁ। ଆପଣଙ୍କର ଏକାଧିକ ଡିଭାଇସରେ ଆପଣ ଆପଣଙ୍କ [ଆକ୍ସେସ କୀ](/about/terminology) ବ୍ୟବହାର କରିପାରିବେ, କିନ୍ତୁ ଆପଣଙ୍କ କୀ ଅନ୍ୟ କୌଣସି ବ୍ୟକ୍ତିଙ୍କ ସହ ସେୟାର କରନ୍ତୁ ବୋଲି ଆମେ ସୁପାରିଶ କରୁନାହୁଁ। ଯଦି ଆପଣଙ୍କ ଆକ୍ସେସ କୀ ଥିବା କୌଣସି ବ୍ୟକ୍ତିଙ୍କର ଏହାକୁ ଆକ୍ସେସ ଅଛି, ତେବେ ସେ ସମ୍ଭବତଃ ଆପଣଙ୍କ ସମସ୍ତ ଇଣ୍ଟର୍ନେଟ ଟ୍ରାଫିକକୁ ନିରୀକ୍ଷଣ କରିପାରନ୍ତି, ଯାହା ଆଉ ଆପଣଙ୍କ ଇଣ୍ଟର୍ନେଟ ବ୍ୟବହାରକୁ ସୁରକ୍ଷିତ କିମ୍ବା ପ୍ରାଇଭେଟ ରଖେ ନାହିଁ।
