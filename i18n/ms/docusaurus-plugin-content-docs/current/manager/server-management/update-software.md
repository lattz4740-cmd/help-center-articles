---
title: "Bagaimanakah cara mengemaskinikan perisian pelayan Outline saya?"
sidebar_label: "Bagaimanakah cara mengemaskinikan perisian pelayan Outline saya?"
---

Pelayan Outline dikemaskinikan secara automatik dengan peningkatan keselamatan terkini supaya anda dapat menjalankan teknologi Outline yang terkini pada setiap masa. Proses pengemaskinian automatik ini didayakan menggunakan [Watchtower](https://github.com/v2tec/watchtower), pustaka sumber terbuka yang menyemak dan mengemaskinikan imej docker yang mengandungi perisian Outline secara berkala.

Selain itu, apabila anda memasang Outline menggunakan Outline Manager, kami akan menyediakan tugas kron untuk meningkatkan perisian pada pelayan secara automatik menggunakan [Peningkatan Tanpa Seliaan](https://wiki.debian.org/UnattendedUpgrades) (Ubuntu) dan mengebut semula mengikut keperluan. Harap maklum bahawa hal ini tidak berlaku dalam Mod Lanjutan untuk memelihara konfigurasi yang sedia ada, dengan andaian bahawa hos sedang digunakan untuk tujuan lain selain menjalankan Outline.
