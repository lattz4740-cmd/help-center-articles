---
title: "Bagaimanakah cara menetapkan semula ID pelayan saya?"
sidebar_label: "Bagaimanakah cara menetapkan semula ID pelayan saya?"
---

ID pelayan ialah ID pihak pelayan yang dijana secara rawak apabila anda membuat pelayan Outline. Anda boleh menemui ID ini apabila memilih untuk berkongsi metrik awanama dalam antara muka Tetapan. Anda boleh mencari ID pelayan anda daripada: Tetapan => tatal ke bawah => tandai "kongsi metrik awanama".

ID pelayan mengikat perangkaan penggunaan awanama yang dilaporkan dari semasa ke semasa. Jika anda mahu menetapkan semula ID pelayan dan memperoleh ID yang baharu, anda perlu menggantikan pelayan Outline anda yang sedia ada dengan pelayan yang baharu.

Jika anda menggunakan DigitalOcean sebagai penyedia awan, anda boleh menetapkan semula pelayan anda dengan mengakses Tetapan dan memilih Musnahkan Pelayan. Tindakan ini tidak boleh disongsangkan dan akan memadamkan kesemua bukti kelayakan anda. Selepas tindakan ini, anda akan digesa untuk membuat pelayan yang baharu dengan serta-merta pada lokasi pilihan anda dan ID pelayan baharu akan dijana.
