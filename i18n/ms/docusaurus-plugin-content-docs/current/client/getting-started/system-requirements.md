---
title: "Apakah keperluan sistem untuk menjalankan klien Outline?"
sidebar_label: "Apakah keperluan sistem untuk menjalankan klien Outline?"
---

Anda boleh cuba menggunakan Outline pada mana-mana sistem pengendalian. Yang berikut ialah keperluan minimum sistem pengendalian :

| **Sistem pengendalian** | **Versi minimum** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Mahu membantu Klien Outline berfungsi pada lebih banyak sistem pengendalian? [Berikan sumbangan kepada asas kod kami](https://github.com/Outline-Foundation/outline-client#platform-specific-development) pada GitHub!
