sidebar_label: "Mengapakah saya tidak boleh mengakses Internet walaupun saya disambungkan kepada pelayan Outline?"
---

Jika anda menggunakan telefon mudah alih, cuba beralih antara data mudah alih dengan sambungan Wi-Fi. Kadangkala hanya satu jenis sambungan berfungsi pada satu-satu masa. Jika anda menggunakan komputer, cuba putuskan sambungan daripada jalur lebar dan buat sambungan semula.

Jika anda terus mengalami kesukaran, kemungkinan terdapat masalah dengan pelayan Outline anda. Hubungi [pengurus perkhidmatan](/about/terminology) anda untuk mendapatkan kunci akses baharu bagi pelayan alternatif.
