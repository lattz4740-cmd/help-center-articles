Laman web sokongan ini adalah untuk Outline Manager dan Pengguna klien. Sila gunakan GitHub untuk mendapatkan sokongan bagi pembangun. Untuk mengajukan pertanyaan, sila siarkan pada [Papan perbincangan](https://github.com/Jigsaw-Code/outline-sdk/discussions) SDK. Bahagian Papan perbincangan merupakan tempat yang terbaik untuk mengajukan pertanyaan, berkongsi idea dan pautan kepada demo serta menyokong pembangun lain menggunakan Outline SDK. Untuk permintaan ciri atau laporan pepijat, sila buka [Masalah](https://github.com/Jigsaw-Code/outline-sdk/issues/new) .
