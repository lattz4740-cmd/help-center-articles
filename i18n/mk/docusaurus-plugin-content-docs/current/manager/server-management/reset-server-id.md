---
title: "Како да го ресетирам мојот ID на сервер?"
sidebar_label: "Како да го ресетирам мојот ID на сервер?"
---

ID на серверот е ID од страна на серверот што се генерира по случаен избор при создавањето сервер на Outline. Може да го најдете при прифаќањето да се споделуваат анонимни метрички податоци во интерфејсот на „Поставки“. Вашиот ID на сервер може да го најдете од: „Поставки“ => лизгајте до дното => штиклирајте „споделување анонимна метрика“.

ID на серверот се поврзува со анонимната статистика за користење што се пријавува со текот на времето. Ако сакате да го ресетирате вашиот ID на серверот и да добиете нов, ќе треба да го замените постојниот сервер на Outline со нов.

Ако користите DigitalOcean како ваш оператор на облак, може да го ресетирате вашиот сервер така што ќе одите во „Поставките“ и ќе изберете „Избриши го серверот“. Дејствово е неповратно и ќе ги избрише вашите акредитиви. Веднаш потоа, системот ќе ви понуди да создадете нов сервер на локација по ваш избор и ќе се генерира нов ID на сервер.
