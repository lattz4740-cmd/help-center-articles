Добре дојдени сте да го испробате Outline на кој било оперативен систем. Во продолжение се наведени минималните барања за оперативните системи:

| **Оперативен систем** | **Минимална верзија** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 10.15 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Сакате да помогнете клиентот Outline да функционира на повеќе оперативни системи? [Придонесете кон нашата база на кодови](https://github.com/OutlineFoundation/outline-client#platform-specific-development) на GitHub!
