---
title: Cómo configurar varios servidores de Outline
sidebar_label: Cómo configurar varios servidores de Outline
---

Para configurar servidores de Outline adicionales, haz clic en el ícono "+" en el panel de navegación que se encuentra sobre la izquierda de tu app de Outline Manager. Las instrucciones para agregar un nuevo servidor son las mismas que debes seguir para instalar el primero.

- No tenemos un límite con respecto a la cantidad de servidores de Outline que puedes crear.
- Para cada servidor de Outline que crees, necesitarás una máquina virtual correspondiente.
- Si creas máquinas o entornos de programación adicionales, es posible que aumenten las tarifas de tu proveedor de nube. Verifica tu paquete de precios junto con tu proveedor de nube a fin de estar seguro de cuáles serán las consecuencias.

## Cómo crear un servidor de Outline adicional en DigitalOcean

Luego de hacer clic en el ícono "+" y seleccionar la opción de instalar en DigitalOcean, deberás seguir las mismas instrucciones que seguiste para configurar tu primer servidor. Además, dado que Outline Manager se integra con DigitalOcean, podemos crear el entorno de programación por ti sin que tengas que salir de la app de Outline Manager.

 Ten en cuenta que Outline Manager solo puede admitir una cuenta de DigitalOcean a la vez. Si deseas agregar o crear otros servidores de Outline desde otras cuentas de DigitalOcean, puedes agregarlos como una configuración avanzada.

## Cómo crear un servidor de Outline adicional en GCP, AWS o algún otro proveedor de servicios en la nube

Para comenzar, crea una máquina virtual nueva con el proveedor de nube que desees. Luego, abre Outline Manager y sigue las instrucciones para la instalación avanzada del mismo modo en que posiblemente lo hiciste la primera vez.
