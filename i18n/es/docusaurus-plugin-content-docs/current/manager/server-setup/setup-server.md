Para poder usar Outline, el primer paso consiste en configurar un servidor de Outline. Tú o alguien de confianza deben configurar un servidor para que puedas conectarte a la Internet abierta por medio de Outline.

## Antes de comenzar

Antes de comenzar a configurar tu servidor de Outline, necesitarás algunas cosas:

1. Acceso a tus propios servidores o un proveedor de servicios en la nube, como DigitalOcean, Amazon Web Services (AWS) o Google Cloud Platform (GCP).

    Si no tienes acceso inmediato a un servidor en la nube, puedes configurar una cuenta fácilmente con cualquier proveedor, incluidos los que se mencionaron anteriormente. Es probable que necesites una tarjeta de crédito para poder registrarte.
2. Una computadora de escritorio que ejecute macOS 10.9 o superior, Windows 7.0 o superior, o Linux.
3. La app de Outline Manager.

## Cómo realizar la configuración con DigitalOcean

Permitimos que todos puedan instalar Outline fácilmente en DigitalOcean con unos pocos clics. Luego de descargar e instalar Outline Manager en tu computadora, podrás seleccionar la opción de configuración de DigitalOcean, la cual te guiará a lo largo de algunas pantallas simples para que puedas configurar y luego instalar tu servidor de Outline.

## Cómo realizar la configuración con otro proveedor de nube

Luego de descargar e instalar Outline Manager, podrás optar por instalar un servidor de Outline en una máquina virtual con AWS, GCP, DigitalOcean o algún otro proveedor. Dado que cada entorno es diferente, incluimos instrucciones dentro del flujo de configuración de Outline Manager para los proveedores de nube más populares, incluidas las instrucciones sobre cómo definir la configuración en tu máquina virtual antes de ejecutar la secuencia de comandos de instalación para instalar Outline en un servidor.
