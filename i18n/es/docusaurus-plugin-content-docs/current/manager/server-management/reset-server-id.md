---
title: "¿Cómo puedo cambiar el ID de servidor?"
sidebar_label: "¿Cómo puedo cambiar el ID de servidor?"
---

El ID de servidor es un identificador en el servidor que se genera de forma aleatoria cuando creas un servidor de Outline. Puedes encontrarlo en la interfaz Ajustes, cuando elijas compartir métricas anónimas. Para encontrar tu ID de servidor, ve a Ajustes, deslízate hasta la parte inferior y marca "Compartir métricas anónimas".

El ID de servidor permite agregar estadísticas de uso anónimas recogidas a lo largo del tiempo. Si quieres cambiar el ID de servidor y obtener uno nuevo, deberás sustituir tu servidor de Outline actual por uno nuevo.
