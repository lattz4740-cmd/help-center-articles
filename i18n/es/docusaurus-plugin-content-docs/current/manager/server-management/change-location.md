---
title: "¿Cómo puedo cambiar la ubicación del servidor de Outline?"
sidebar_label: "¿Cómo puedo cambiar la ubicación del servidor de Outline?"
---

Después de configurar la ubicación de un servidor, no se puede cambiar. Para ejecutar tu servidor desde una ubicación distinta, primero debes eliminar tu servidor de Outline y crear otro.

También puedes cambiar la ubicación de tu VPN usando [claves dinámicas](https://developer.getoutline.org/vpn/management/dynamic-access-keys/), que te permiten rotar los servidores y conservar las mismas claves. La ubicación de los servidores no cambiará.
