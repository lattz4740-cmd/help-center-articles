---
title: "¿Tengo permiso para usar o replicar la marca Outline?"
sidebar_label: "¿Tengo permiso para usar o replicar la marca Outline?"
---

Aunque Outline es software libre y su uso es gratuito, nuestra marca es propiedad de Jigsaw y no debería hacerse un uso inadecuado de ella. Sigue la [guía de usuario](https://github.com/Outline-Foundation/outline-brand/blob/main/outline_brand_user_guide.pdf) para evitar hacer posibles afirmaciones engañosas o una definición incorrecta de tu relación con Outline o Jigsaw, así como para asegurarte de que usas los elementos de marca aprobados adecuadamente.
