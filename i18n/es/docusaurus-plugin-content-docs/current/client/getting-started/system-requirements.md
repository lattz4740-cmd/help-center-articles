sidebar_label: "¿Qué sistemas operativos ejecutan el cliente de Outline?"
---

Te invitamos a probar Outline en cualquier sistema operativo. Estos son los requisitos mínimos que debe cumplir el sistema operativo que elijas:

| **Sistema operativo** | **Versión mínima** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

¿Quieres ayudar para que el cliente de Outline funcione en más sistemas operativos? [Aporta tu granito de arena en nuestro código base](https://github.com/Jigsaw-Code/outline-client#platform-specific-development) a través de GitHub.
