title: "Me dedico al desarrollo. ¿Dónde puedo encontrar ayuda para integrar el SDK de Outline en mi aplicación?"
sidebar_label: "Me dedico al desarrollo. ¿Dónde puedo encontrar ayuda para integrar el SDK de Outline en mi aplicación?"
---

Este sitio web de asistencia está dirigido a los usuarios de Administrador de Outline y del cliente de Outline. Los desarrolladores pueden obtener asistencia a través de GitHub. Puedes publicar las preguntas que tengas en el [panel de debate](https://github.com/Jigsaw-Code/outline-sdk/discussions) del SDK. El panel de debate es un lugar ideal para plantear dudas, compartir ideas, aportar enlaces a demos y ayudar a otros desarrolladores que utilizan el SDK de Outline. Para las solicitudes de funciones o informes de errores, abre un [problema](https://github.com/Jigsaw-Code/outline-sdk/issues/new) en su lugar.
