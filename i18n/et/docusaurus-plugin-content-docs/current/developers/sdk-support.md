sidebar_label: "Olen arendaja. Kust saada tuge Outline’i SDK oma rakendusse integreerimiseks?"
---

See tugisait on mõeldud Outline Manageri ja Outline'i kliendi kasutajatele. Arendajad saavad tuge GitHubilt. Küsimusi saab esitada SDK [arutelufoorumis](https://github.com/Jigsaw-Code/outline-sdk/discussions). Arutelufoorumis saate esitada küsimusi, jagada ideid, lisada linke demodele ja toetada teisi arendajaid, kasutades Outline’i SDK-d. Funktsioonitaotluste või veaaruannete esitamiseks avage jaotis [Probleem](https://github.com/Jigsaw-Code/outline-sdk/issues/new).
