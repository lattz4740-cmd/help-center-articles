sidebar_label: "Millised on Outline’i kliendi käitamise süsteeminõuded?"
---

Teil on võimalik proovida Outline'i mis tahes operatsioonisüsteemis. Operatsioonisüsteemide miinimumnõuded on järgmised.

| **Operatsioonisüsteem** | **Miinimumversioon** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Kas soovite anda oma panuse, et Outline’i klienti saaks kasutada rohkemates operatsioonisüsteemides? [Panustage meie koodibaasi](https://github.com/Outline-Foundation/outline-client#platform-specific-development) GitHubis!
