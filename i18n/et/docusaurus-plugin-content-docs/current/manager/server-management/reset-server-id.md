---
title: "Kuidas saan oma serveri ID lähtestada?"
sidebar_label: "Kuidas saan oma serveri ID lähtestada?"
---

Serveri ID on serveripoolne ID, mis luuakse Outline'i serveri loomisel juhuslikult. Leiate selle, kui lubate liideses Seaded anonüümsete mõõdikute jagamise. Serveri ID leidmiseks tehke järgmist: valige Seaded => kerige alla => märkige ruut „anonüümsete mõõdikute jagamine“.

Serveri ID-d kasutatakse aja jooksul esitatud anonüümse kasutusstatistika liitmiseks. Kui soovite lähtestada serveri ID ja hankida uue, tuleb teil olemasolev Outline'i server uuega asendada.

Kui kasutate pilveteenuse pakkujana DigitalOceanit, saate serveri lähtestamiseks avada Seaded ja valida seejärel käsu Hävita server. Toimingut ei saa tagasi võtta ja selle käigus kustutatakse kõik teie mandaadid. Teil palutakse kohe pärast seda toimingut luua uus server teie soovitud asukohas, misjärel luuakse uus serveri ID.
