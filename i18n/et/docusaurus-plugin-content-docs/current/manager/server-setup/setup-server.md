---
title: "Kuidas Outline'i serverit seadistada?"
sidebar_label: "Kuidas Outline'i serverit seadistada?"
---

Outline'i kasutuselevõtmiseks tuleb esmalt seadistada Outline'i server. Seadistage server ise või laske seda teha kellelgi usaldusväärsel inimesel, et saaksite Outline'i kaudu avatud internetiga ühenduse luua.

## Enne alustamist
 Enne kui alustate Outline'i serveri seadistamist, vajate järgmist.

1. Juurdepääsu isiklikele serveritele või pilveteenuste pakkujale, nagu DigitalOcean, Amazon Web Services (AWS) või Google Cloud Platform (GCP).

 Kui teil ei ole praegu juurdepääsu pilveserverile, saate mis tahes teenusepakkuja, sealhulgas ülal loetletud teenusepakkujate juures hõlpsasti konto luua. Tõenäoliselt vajate registreerumiseks krediitkaarti.
2. Lauaarvutit, milles töötab macOS 10.9 või uuem, Windows 7.0 või uuem või Linux.
3. Outline Manageri rakendust.

## Seadistamine DigitalOceani abil
 DigitalOceanis saab igaüks vaid mõne klõpsuga hõlpsasti Outline'i installida. Pärast arvutis Outline Manageri allalaadimist ja installimist võite valida DigitalOceani seadistamise valiku, mis aitab teil mõnel lihtsal kuval Outline'i serveri seadistada ja installida.

## Seadistamine mõne muu pilveteenuse pakkuja abil
 Pärast Outline Manageri allalaadimist ja installimist võite installida Outline'i serveri virtuaalmasinasse AWS-i, GCP, DigitalOceani või muu teenusepakkuja abil. Iga keskkond on erinev, seega lisasime Outline Manageri seadistusvoogu juhised sageli kasutatavate pilveteenuste pakkujate jaoks. Sealhulgas selgitame, kuidas seadistada virtuaalmasina seadeid, enne kui käitate installiskripti, et Outline serverisse installida.
