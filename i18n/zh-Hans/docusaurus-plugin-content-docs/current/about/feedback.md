---
title: 如何发送反馈或建议
sidebar_label: 如何发送反馈或建议
---

感谢您帮助我们完善 Outline！您可以通过几种方式向我们发送反馈。您可以匿名发送，也可以提供您的电子邮件地址以便我们应您的要求进行回复。

- **针对开发者**：Outline 是开放源代码软件。我们将所有代码托管在 [GitHub](https://github.com/OutlineFoundation/?q=outline)。您可以在 GitHub 或者我们的 [Reddit](https://www.reddit.com/r/outlinevpn/) 社区分享您的想法。

- **针对用户**：您可以通过 Outline 应用或 Outline 管理器应用向我们发送反馈。请告诉我们反馈内容。您也可以选择提供电子邮件地址，以便我们回复您的反馈。我们还会收集与您的环境相关的部分元数据，例如您所使用的浏览器、操作系统和软件的版本，用于帮助您排查问题。

- **通过此网站**：您可以点击您在此网站任何位置看到的“联系我们”的链接。

- **严重问题**：如果您要报告严重的安全问题，请将详细信息通过电子邮件发送到 [security@getoutline.org](mailto:security@getoutline.org)。

再次感谢您与我们分享您的想法。
