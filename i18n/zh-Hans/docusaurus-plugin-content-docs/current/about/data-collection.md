---
title: 数据和信息收集
sidebar_label: 数据和信息收集
---

Outline 不会收集个人信息，除非您选择提供这类信息。Outline 也不会收集您访问的网站、交流对象或交流内容的相关信息。

在您通过 Outline 管理器创建或登录账号来使用第三方云服务提供商的服务时，我们不会获取您向第三方云服务提供商提供的任何信息，例如您的电子邮件地址、姓名、结算信息和支付明细。

****我们自动获取的信息****

我们会自动收集两类信息。

1. 服务器 IP

当服务器进行自动更新以应用最新的安全和功能改进时，[Quay.io](https://quay.io/) 会收集 Outline 服务器 IP，并允许我们访问此信息。服务器 IP 可能被用于识别云服务提供商以及 Outline 服务器所在的城市，但并不会提供有关服务器的运行者和访问者的信息。

2. 无法用于识别个人身份的技术信息

如果 Outline 崩溃或发生严重异常情况，或者您手动通过 Outline 应用发送反馈，则系统会报告以下信息。我们只会将此信息用于帮助识别和解决稳定性或性能问题。

- 国家/地区
- 语言区域
- 崩溃/异常发生的日期和时间，以及问题发生前的最多 100 个事件，例如用户打开了“关于”部分
- 静态编译的异常消息
- 操作系统名称和版本
- 手机型号（如果适用）
- 应用启动时间
- 浏览器
- 架构
- Outline 版本和版本号

我们会使用 HTTPS 将此信息传输到 Sentry ([sentry.io](https://sentry.io/))。Sentry 是一家第三方开放源代码错误跟踪服务提供商，他们使用各种符合业界标准的技术和服务来确保您的数据安全，防止数据遭到未经授权的访问、披露和使用，并避免数据丢失。如果您对 Sentry 的政策有任何疑问，请访问 [https://sentry.io/security/](https://sentry.io/security/) 和 [https://sentry.io/privacy/](https://sentry.io/privacy/)，或者联系 [security@sentry.io](mailto:security@sentry.io)。仅 Outline 团队成员才能访问Sentry 存储的所有 Outline 数据。

****我们仅获取您选择披露的信息****

Outline 只有在您选择同意后才会将以下信息报告给 Outline 团队。

1. 用量指标

每个 Outline 服务器会自动收集过去一小时内通过每个访问密钥传输的字节数、用户与服务器保持连接的时长、所用凭据来源所在的国家/地区和相应的自治系统，以及是否启用或停用了任何功能。系统既不会记录通讯内容，也不会记录任何可用于识别个人身份的元数据（例如登录信息、电子邮件地址、设备 ID 等）。所有指标都会与服务器 ID 相关联。您可以在[此处](/manager/server-management/reset-server-id)找到有关更改服务器 ID 的说明。

默认情况下，Outline 服务器不会与 Outline 团队分享这些指标。如果服务器管理员明确选择分享使用情况指标，则系统每隔一小时便会将这些信息安全地发送给 Outline 团队。60 天后，这些使用情况指标将会在国家/地区一级进行汇总。服务器管理员可以随时访问 Outline 管理器中的“设置”菜单，更改使用情况指标分享偏好设置。

我们希望您可以与我们分享有关您服务器使用情况的匿名指标，以便我们衡量使用情况趋势，并改进产品。

举例来说，如果服务器管理员选择与我们分享使用情况指标，我们就可能会收到表明以下情况的信息：ID 为 12345 的服务器在昨天被使用了 3 个小时，通过分别在美国和加拿大使用的 3 个密钥传输了共 500 MB 的数据，同时启用了流量上限功能。

2. 您的评论和电子邮件地址（如果您提交了反馈）

Outline 管理器和 Outline 应用允许您向 Outline 团队提交反馈。我们建议您不要添加个人身份信息，但如果您希望收到 Outline 团队的回复，可以选择填写电子邮件地址字段。我们还会自动收集一些基本信息，以便理解您反馈的内容。请查看上文“我们自动获取的信息”下的第 2 项，了解我们会收集哪些数据。点击[此处](/about/security-and-privacy)即可了解 Outline 的安全和隐私权规范。

如果您在 Android 设备上使用 Outline 应用 Beta 版，我们可能会使用 Google 的 [Firebase](https://firebase.google.com/) 服务收集调试信息，以便检测问题并改进 Outline。您可以通过 Firebase 的网站 [firebase.google.com/support/privacy](https://firebase.google.com/support/privacy) 详细了解 Firebase 的隐私权和安全政策。如果您不希望 Outline 通过 Firebase 发送此信息，请使用 Outline 应用正式版。
