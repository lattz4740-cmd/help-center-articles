## 如果没有服务器，可以使用 Outline 吗？

抱歉，不可以。Outline 软件要求访问服务器。该服务器可由您自己、您的单位或可信的第三方管理。

## 设置 Outline 服务器需要花费多少时间？

大多情况下，5 分钟之内可以完成。您可以在任意云服务器上安装 Outline。不过，我们与 DigitalOcean 协作提供了更方便用户使用、指示更明确的安装体验。您只需点击几次就能完成服务器设置，而无需运行脚本。

 如果您选择了 AWS、GCP 或高级设置，我们已经将服务器安装流程简化到一个简单的脚本，且适用于大多数环境。

## 我可以在何处设置 Outline 服务器？

您可以使用大多数云服务提供商的服务设置 Outline 服务器。

 最简单的方式是在 DigitalOcean 上进行设置。DigitalOcean 提供的服务器位于阿姆斯特丹、多伦多、旧金山和新加坡等多个地点。如果您选择在其他云服务提供商或您自己的基础架构上安装 Outline，可以在 Outline 管理器应用中选择“高级模式”，然后按照安装说明使用设置脚本。

## 我应该在何处设置 Outline 服务器？

选择 Outline 服务器的位置时，您需要考虑以下情况：

1. Outline 服务器位置会影响用户的互联网访问体验。 例如，如果服务器位于阿姆斯特丹，那么用户通过此服务器访问互联网时，就可以像在荷兰境内一样访问互联网。一些网站甚至可能使用荷兰语显示内容。通常情况下，您可以使用相应网站的语言选择器覆盖本地语言。
2. 您的用户和 Outline 服务器之间的距离可能会影响您的速度。 一般而言，Outline 用户和 Outline 服务器之间的物理距离会影响用户的互联网连接速度。大多情况下，请选择距离您的预期用户最近的服务器地址，不过您可以查看[海底光缆分布图](https://www.submarinecablemap.com/)，了解与您的国家或地区连接的是哪些互联网光缆。
3. VPN 服务器的位置可能对法律框架有影响。 请记住，Outline 软件不会记录您的流量。详细了解如何[在使用 Outline 时确保安全性和隐私性](/about/security-and-privacy)。
