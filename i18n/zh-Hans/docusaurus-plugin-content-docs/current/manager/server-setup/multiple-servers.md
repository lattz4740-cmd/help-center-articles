---
title: 如何设置多个 Outline 服务器
sidebar_label: 如何设置多个 Outline 服务器
---

要设置更多 Outline 服务器，请在 Outline 管理器应用左侧的导航面板中点击“+”图标。添加新服务器的方法与设置第一个服务器相同。

- 我们不限制您可以创建的 Outline 服务器的数量。
- 对于您创建的每一个 Outline 服务器，您都需要一个相应的虚拟机。
- 创建更多虚拟机可能会增加您需要向云服务提供商支付的费用。请查看云服务提供商的价格套餐，确保您知道创建更多虚拟机后的费用变化。

## 通过 DigitalOcean 创建更多 Outline 服务器

点击“+”图标并选择在 DigitalOcean 上安装服务器后，您需要按照设置第一个服务器的相同说明进行操作。此外，由于 Outline 管理器与 DigitalOcean 集成，您无需离开 Outline 管理器应用，我们就能为您创建虚拟机。

 请注意，Outline 管理器一次只能支持一个 DigitalOcean 帐号。如果您想通过其他 DigitalOcean 帐号添加或创建更多 Outline 服务器，您可以在高级配置中进行添加。

## 通过 GCP、AWS 或其他云服务提供商创建更多 Outline 服务器

首先，您需要在您所选择的云服务提供商处创建新的虚拟机。接下来，打开 Outline 管理器并按照高级安装说明完成操作，就像第一次创建一样。
