不论您是管理 VPN 的服务器管理员，还是使用 Outline 访问开放式互联网的普通用户，任何人都可以免费使用 Outline 软件。

不过，Outline 需要访问云服务器才能运行。已经拥有某个服务器访问权限的服务器管理员可以在该服务器上安装 Outline，而无需支付额外费用。没有服务器访问权限的用户可以从云服务提供商处获取权限，例如 [或 Amazon Web Services，每月只需约 5 美元即可使用 1 TB 数据流量。这足以支持数百名用户同时使用一个服务器。](http://www.digitalocean.com/)

| *假设每位用户每月平均使用 5 GB 流量用于数据传输，那么每月 5 美元的套餐可允许 200 位用户同时使用，平均每位用户每月仅花费 2.5 美分。请注意，每位用户每月用于数据传输的流量可能大幅变化，具体取决于用户活动占用的带宽高低。但是，大多数云服务提供商均可灵活适应流量增长。* |
