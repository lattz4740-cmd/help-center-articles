---
title: 如何删除 Outline 服务器？
sidebar_label: 如何删除 Outline 服务器？
---

对于大多数云服务提供商，您可以轻松移除正在使用的特定虚拟机。

如果您使用 DigitalOcean 作为云服务提供商，可以点击齿轮按钮，然后选择**销毁服务器**以删除您现有的虚拟机。您删除后，系统会立即提示您重新选择位置创建新的虚拟机。

如果您移除 Outline 服务器，该服务器将被永久删除，且访问密钥也将失效。如果您不希望用户遇到 Outline 访问中断的情况，则需要[设置一个新的 Outline 服务器](https://support.google.com/outline/answer/15331530?sjid=5147938692963654551-NC)并分享其访问权限，然后再删除旧服务器。
