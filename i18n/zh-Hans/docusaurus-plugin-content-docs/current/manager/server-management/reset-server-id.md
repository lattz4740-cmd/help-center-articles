---
title: 如何重置服务器 ID？
sidebar_label: 如何重置服务器 ID？
---

服务器 ID 是在创建 Outline 服务器时随机生成的服务器端 ID，您在“设置”界面选择分享匿名指标后即可看到。您可以在以下位置找到服务器 ID：“设置”=> 滚动到底部 => 选中“共享匿名指标”。

服务器 ID 可将不断报告的匿名使用情况统计信息联系起来。如果您要重置服务器 ID 并获取新 ID，则需要更换现有的 Outline 服务器。

如果您使用 DigitalOcean 作为云服务提供商，可以点击**设置**，然后选择**销毁服务器**，以重置服务器。此操作不可逆，还将清除您的凭据。您完成此操作后，系统会立即提示您选择位置创建新的服务器，并生成一个新的服务器 ID。
