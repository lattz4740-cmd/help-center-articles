title: 管理对 Outline 服务器的访问（通过访问密钥）

---

安装完 Outline 服务器后，您就可以开始分享和管理对服务器的访问权限。收到您的邀请的用户可以下载 Outline 应用，使用 Outline 保护他们的网络流量。

**共享对 Outline 服务器的访问权限**

 安装完 Outline 服务器后，您将被定向到 Outline 管理器的服务器详细信息页面，您可以在此处创建访问密钥。详细了解[访问密钥](/about/terminology)。

- 创建密钥：点击页面底部的“+”小图标即可创建新密钥。
- 分享密钥：点击各个密钥右侧的分享按钮即可生成邀请。复制该邀请并粘贴到您所选择的即时通讯系统。

**功能请求：在 Outline 管理器应用内分享访问权限**

 许多服务器管理员希望我们简化邀请流程，即通过在 Outline 管理器中添加一个选项，供他们直接输入用户的电子邮件地址。

遗憾的是，我们不会向 Outline 管理器添加此功能。我们的核心原则之一就是保护用户的隐私和安全。也就是说，我们不会设计任何选项来插入电子邮件地址或联系信息。

这就是为什么我们要求管理员使用安全的即时通讯平台（例如电子邮件或安全的聊天工具）来向最终用户发送邀请。

**您向用户分享访问密钥后，他们会有什么体验**

1. 用户将在自己的设备上点击相应安装链接
2. 系统将提示他们安装 Outline 应用（如果尚未安装）
3. 他们将通过邀请中嵌入的唯一的密钥，首次连接到您的 Outline 服务器。
4. 之后，他们就可以使用连接/断开按钮来管理是否通过您的 Outline 服务器连接到互联网

**移除对您的 Outline 服务器的访问权限**

 在 Outline 管理器的服务器详细信息页面上，您会看到服务器的每个密钥的右侧都有一个菜单，其中包含删除相应密钥的选项。删除密钥会移除其对您的服务器的访问权限。
