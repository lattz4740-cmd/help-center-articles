title: 运行 Outline 客户端对系统有何要求？
sidebar_label: 运行 Outline 客户端对系统有何要求？
---

您可以在任何操作系统上试用 Outline。以下是对操作系统的最低要求：

| **操作系统** | **最低版本** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

想协助 Outline 客户端在更多操作系统上运行？请访问 GitHub [帮助我们扩充代码库](https://github.com/OutlineFoundation/outline-client#platform-specific-development)！
