[为了将设备连接到 Outline 服务器，服务器管理员必须邀请您使用唯一的](/about/terminology)

连接到他们的服务器。该邀请将：

- 提示您在自己的设备上下载并安装 Outline（如果您尚未安装）
- 使用访问密钥在您和 Outline 服务器之间建立安全连接

您的设备和服务器建立连接后，您可以点击“连接”或“断开”来使用 Outline。

:::warning
如果没有访问密钥和 Outline 服务器，您将无法使用 Outline。下载并安装 Outline 应用，但没有获取密钥，这会导致您的互联网流量不受保护。
:::
