---
title: 如何获取访问密钥？
sidebar_label: 如何获取访问密钥？
---

Outline 不同于您需要购买访问权限才能使用的 VPN 服务，它是帮助您运行自己的专用 VPN 服务器并管理其访问权限的[一款工具](https://getoutline.org/#:~:text=Two%20Products%20that%20Work%20Together)。只有[服务管理员](/about/terminology#servicemanager)可以提供访问密钥。Outline 团队不会分发免费或付费的访问密钥。除了波斯语的 Paskoocheh 之外，我们没有任何官方 Outline 访问密钥合作伙伴。

 以下是获取访问密钥的三个可选方式：

- 让他人邀请您访问其服务器：如果您认识有 Outline 服务器的人，可以联系他们，请他们提供访问密钥。
- [自行创建服务器：](/manager/server-setup/setup-server)使用 Windows、Mac 或 Linux 计算机，下载 [Outline 管理器](https://getoutline.org/get-started/#step-1)并设置您自己的专用[Outline 服务器](/about/terminology)。这个过程十分简单，任何人均可轻松完成，通过云服务提供商 DigitalOcean 进行创建就更简单了。
- 使用 Outline 或 [Shadowsocks](https://en.wikipedia.org/wiki/Shadowsocks#:~:text=Shadowsocks%20is%20a%20free%20and,have%20been%20made%20available%20since.) 服务：Outline 客户端还可以与使用了 Outline 或 Shadowsocks 协议的第三方服务一起使用。例如：
   - [nthLink](https://nthlink.com/) 通过一个修改版的 Outline 客户端运行基于 Outline 的免费服务。
   - [ASL19](https://www.reddit.com/r/outlinevpn/comments/nwu1se/the_outline_distribution_system_is_here_to_help/) 运行一款名为 [BeePass](https://beepassvpn.com/) 的 Outline 修改版，以及一个为 BeePass 服务器提供免费访问密钥的 [Telegram 机器人程序](https://t.me/paskoochehbot)。
   - 波斯语用户还可以请求从 [ASL19 的 Paskoocheh](https://outline.paskoocheh.com/) 获取 Outline 访问密钥。

下载 Outline 客户端应用后，将[访问密钥](/about/terminology#accesskey)复制并粘贴到 Outline 客户端以连接 Outline 服务器。
