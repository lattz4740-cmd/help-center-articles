此支持网站面向的是 Outline 管理器和客户端用户。开发者请移步 GitHub 获取支持。如需提问，请在 SDK [讨论区](https://github.com/Jigsaw-Code/outline-sdk/discussions)中发帖。讨论区是提问、分享想法、链接到演示版以及为其他使用 Outline SDK 的开发者提供支持的好地方。如需提出功能请求或报告 bug，请改为提交[问题](https://github.com/Jigsaw-Code/outline-sdk/issues/new)。
