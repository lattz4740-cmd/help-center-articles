---
title: "Ako nastavím server Outline?"
sidebar_label: "Ako nastavím server Outline?"
---

Ak chcete používať službu Outline, najprv je potrebné nastaviť si server Outline. Môžete to spraviť vy alebo niekto, komu dôverujete. Až potom sa budete môcť cez Outline pripojiť k otvorenému internetu.

## Skôr než začnete
 Pred nastavením servera Outline:

1. Potrebujete prístup k vlastným serverom alebo poskytovateľovi cloudových služieb, ako je DigitalOcean, Amazon Web Services (AWS) alebo Google Cloud Platform (GCP).

 Ak nemáte priamy prístup ku cloudovému serveru, môžete si jednoducho vytvoriť účet u ktoréhokoľvek poskytovateľa vrátane tých uvedených vyššie. Na registráciu budete zrejme potrebovať kreditnú kartu.
2. Potrebujete počítač so systémom macOS 10.9 alebo novším, Windows 7.0 alebo novším alebo Linux.
3. Potrebujete aplikáciu Správca Outline.

## Nastavenie u poskytovateľa DigitalOcean
 Outline si v službe DigitalOcean niekoľkými kliknutiami bez problémov inštaluje ktokoľvek. Po stiahnutí a inštalácii Správcu Outline v počítači si môžete vybrať možnosť nastavenia v službe DigitalOcean, kde na niekoľkých jednoduchých obrazovkách konfigurujete a inštalujete server Outline.

## Nastavenie u iného poskytovateľa cloudu
 Po stiahnutí a inštalácii Správcu Outline môžete server Outline inštalovať vo virtuálnom počítači u poskytovateľa AWS, GCP, DigitalOcean, prípadne iného. Každé prostredie je iné, takže sme do postupu nastavenia Správcu Outline zahrnuli pokyny platné pri najčastejších poskytovateľoch cloudu. Zahŕňajú tiež návod na konfiguráciu nastavení vo virtuálnom počítači pred tým, ako spustíte inštalačný skript na inštaláciu služby Outline na serveri.
