---
title: "Ako zmením umiestnenie servera Outline?"
sidebar_label: "Ako zmením umiestnenie servera Outline?"
---

Umiestnenie servera sa po nastavení nedá zmeniť. Ak chcete server spúšťať z iného umiestnenia, musíte server Outline odstrániť a vytvoriť nový.

V opačnom prípade môžete zmeniť umiestnenie svojej siete VPN pomocou [dynamických kľúčov](https://developers.google.com/outline/docs/guides/service-providers/dynamic-access-keys), ktoré vám umožňujú striedať servery a ponechať si pritom rovnaké kľúče. Umiestnenie príslušných serverov sa nezmení.
