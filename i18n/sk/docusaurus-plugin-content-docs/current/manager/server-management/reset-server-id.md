---
title: "Ako resetujem identifikátor servera?"
sidebar_label: "Ako resetujem identifikátor servera?"
---

Identifikátor servera je serverový identifikátor, ktorý je náhodne vygenerovaný, keď vytvárate server Outline. Nájdete ho v rozhraní nastavení, keď sa prihlasujete na zdieľanie anonymných metrík. Identifikátor servera nájdete prejdením do Nastavení => posunutím sa dole => začiarknutím políčka Zdieľať anonymné metriky.

Identifikátor servera spája anonymné štatistiky používania nahlasované v priebehu času. Ak ho chcete resetovať a získať nový, musíte svoj existujúci server Outline nahradiť novým.

Ak používate poskytovateľa cloudu DigitalOcean, môžete server resetovať tak, že prejdete do Nastavení a vyberiete Zničiť server. Táto akcia je nezvratná a vymažete ňou všetky poverenia. Po tejto akcii sa ihneď zobrazí výzva, aby ste vytvorili nový server v umiestnení podľa vlastného výberu, a vygeneruje sa nový identifikátor servera.
