---
title: "Ako odstránim server Outline?"
sidebar_label: "Ako odstránim server Outline?"
---

V prípade väčšiny poskytovateľov cloudu je pomerne jednoduché odstrániť konkrétny virtuálny počítač, ktorý používate.

Ak používate poskytovateľa cloudu DigitalOcean, môžete svoj existujúci virtuálny počítač odstrániť tak, že kliknete na tlačidlo ozubeného kolieska a vyberiete Zničiť server. Okamžite po tom sa zobrazí výzva, aby ste vytvorili nový virtuálny počítač v umiestnení podľa vlastného výberu.

Ak odstránite server Outline, bude odstránený natrvalo a jeho prístupové kľúče už nebudú fungovať. Ak nechcete, aby bol prístup ľudí prostredníctvom služby Outline prerušený, budete musieť [vytvoriť nový server Outline](/manager/server-setup/setup-server) a zdieľať prístup k nemu ešte pred odstránením starého.
