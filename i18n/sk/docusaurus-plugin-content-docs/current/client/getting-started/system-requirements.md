---
title: "Aké sú systémové požiadavky na spustenie klienta Outline?"
sidebar_label: "Aké sú systémové požiadavky na spustenie klienta Outline?"
---

Outline môžete vyskúšať v akomkoľvek operačnom systéme. Tu sú minimálne požadované operačné systémy:

| **Operačný systém** | **Minimálna verzia** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Chcete pomôcť, aby aplikácia Outline Client fungovala v ďalších operačných systémoch? [Prispejte do našej základne kódov](https://github.com/Jigsaw-Code/outline-client#platform-specific-development) v službe GitHub.
