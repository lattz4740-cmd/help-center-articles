---
title: "Ako získam prístupový kľúč?"
sidebar_label: "Ako získam prístupový kľúč?"
---

Outline nie je ako služby VPN, do ktorých si kupujete prístup. Ide o [nástroj](https://getoutline.org/#:~:text=Two%20Products%20that%20Work%20Together), ktorý vám umožňuje prevádzkovať súkromný server služieb VPN a zdieľať k nemu prístup. [Správca služieb](/about/terminology#servicemanager) je jediná osoba, ktorá môže poskytnúť prístupový kľúč. Tím Outline nedistribuuje bezplatné ani platené prístupové kľúče. Okrem trhoviska Paskoocheh v perzštine nemáme oficiálnych partnerov pre prístupové kľúče Outline.

 Tu sú tri možnosti, ako získať prístupový kľúč:

- Požiadajte niekoho, aby vás pozval na svoj server: ak poznáte osobu so serverom Outline, kontaktujte ju so žiadosťou o prístupový kľúč.
- [Vytvorte si server:](/manager/server-setup/setup-server) v počítači so systémom Windows alebo Linux, prípadne v Macu, si stiahnite [Správcu Outline](https://getoutline.org/get-started/#step-1) a nastavte vlastný súkromný [server Outline](/about/terminology). Tento proces sme vytvorili tak, aby bol ľahký pre všetkých. Predovšetkým pre tých, ktorí využívajú poskytovateľa cloudových služieb DigitalOcean.
- Použite službu Outline alebo [Shadowsocks](https://en.wikipedia.org/wiki/Shadowsocks#:~:text=Shadowsocks%20is%20a%20free%20and,have%20been%20made%20available%20since.): klient Outline môžete používať aj so službami tretích strán využívajúcich protokol Outline alebo Shadowsocks. Príklad:
   - [nthLink](https://nthlink.com/) prevádzkuje bezplatnú službu založenú na softvéri Outline s upravenou verziou klienta Outline.
   - [ASL19](https://www.reddit.com/r/outlinevpn/comments/nwu1se/the_outline_distribution_system_is_here_to_help/) prevádzkuje upravenú verziu softvéru Outline s názvom [BeePass](https://beepassvpn.com/), ale aj [robota Telegram](https://t.me/paskoochehbot), ktorý poskytuje bezplatné prístupové kľúče serverom BeePass.
   - Používatelia ovládajúci perzštinu môžu požiadať o prístupový kľúč Outline z trhoviska [Paskoocheh od skupiny ASL19](https://outline.paskoocheh.com/).

Po stiahnutí aplikácie Outline Client skopírujte svoj [prístupový kľúč](/about/terminology#accesskey) a prilepte ho do aplikácie Outline Client, aby ste sa pripojili k serveru Outline.
