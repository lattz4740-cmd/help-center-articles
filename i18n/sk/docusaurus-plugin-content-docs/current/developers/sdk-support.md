Tento web podpory je určený pre používateľov aplikácie Správca Outline a klientskej aplikácie. Podporu pre vývojárov získate pomocou služby GitHub. Ak máte otázku, uverejnite ju na [Diskusnom fóre](https://github.com/Jigsaw-Code/outline-sdk/discussions) SDK. Sekcia Diskusné fórum je skvelým miestom, kde môžete klásť otázky, zdieľať nápady, pripojiť sa k demám a poskytovať podporu ostatným vývojárom používajúcim súpravu Outline SDK. Ak chcete požiadať o funkciu alebo nahlásiť chybu, otvorte [Problém](https://github.com/Jigsaw-Code/outline-sdk/issues/new).
