---
title: 如何傳送意見回饋或建議
sidebar_label: 如何傳送意見回饋或建議
---

感謝您協助我們改善 Outline！我們提供多種傳送意見回饋的管道，您可以匿名提供意見；如想收到回覆，也可以透過電子郵件提供意見：

- **開發人員**：Outline 是開放原始碼軟體，我們將所有程式碼都託管於 [GitHub](https://github.com/jigsaw-Code/?q=outline)。您可以在 GitHub 或我們的 [Reddit](https://www.reddit.com/r/outlinevpn/) 社群分享您的想法。

- **使用者**：您可以透過 Outline 或 Outline Manager 應用程式傳送意見回饋給我們。請說明您的意見回饋，或者留下您的電子郵件，方便我們回覆您。此外，為了協助您排解問題，我們也會收集一些有關您作業環境的中繼資料，例如您的瀏覽器、作業系統和執行的軟體版本等資訊。

- **透過這個網站**：按一下這個網站上任何位置顯示的「與我們聯絡」連結，即可提供意見回饋。

- **重大問題**：如要回報重大問題，請在電子郵件中詳述相關資訊並傳送至 security [at] [getoutline.org](https://getoutline.org/)。

再次感謝您撥空與我們分享您的意見與想法。
