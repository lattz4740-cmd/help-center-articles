除非你選擇提供，否則 Outline 不會收集個人資訊，也不會收集你造訪的網站、通訊對象或內容等資訊。

 如果你使用 Outline Manager 透過第三方雲端服務供應商建立或登入帳戶，我們不會取得你提供給第三方雲端服務供應商的任何資料，例如你的電子郵件地址、姓名、帳單資訊和付款資料。

## 系統自動取得的資訊
 我們的系統會自動收集以下兩種資訊。

 1. 伺服器 IP

 Outline 伺服器的 IP 會由 [Quay.io](https://quay.io/) 收集。當伺服器自動更新以套用最新的安全性和功能改進時，我們就能取得這組 IP。伺服器 IP 或許會透露出雲端伺服器供應商和 Outline 伺服器所在的城市，但不會提供營運者或存取者的身分資訊。

 2. 無法用於識別個人身分的技術資訊

 如果 Outline 當機或發生重大例外狀況，或者你透過 Outline 應用程式手動傳送意見回饋，系統將回報下列資訊。這些資訊只會用於協助辨識和修正穩定性或效能問題。

- 國家/地區
- 語言代碼
- 發生當機/例外狀況的日期和時間，以及在此之前發生的最多 100 個事件 (例如使用者開啟了「關於」部分)
- 靜態編譯的例外狀況訊息
- OS 名稱和版本
- 手機型號 (如適用)
- 應用程式啟動時間
- 瀏覽器
- 架構
- Outline 版本和版本號碼

這些資訊會透過 HTTPS 傳送給第三方開放原始碼錯誤追蹤供應商 Sentry ([sentry.io](https://sentry.io/))。Sentry 會用多種符合業界標準的技術和服務來確保資料安全，防止資料遭到未經授權存取、揭露及使用，並避免資料遺失。如對 Sentry 的政策有任何疑問，請前往 [https://sentry.io/security/](https://sentry.io/security/) 和 [https://sentry.io/privacy/](https://sentry.io/privacy/)，或聯絡 [security@sentry.io](mailto:security@sentry.io)。所有交由 Sentry 儲存的 Outline 資料都受到嚴密控管，僅限 Outline 團隊成員存取。

## 我們在徵得使用者同意後收集的資訊
 只要使用者同意分享，Outline 就會向 Outline 團隊回報以下資訊。

 1. 使用指標
每部 Outline 伺服器都會以存取金鑰為單位，自動收集過去一小時內傳輸的位元組數、使用者與伺服器連線的時間、所用憑證的來源國家/地區和自治系統，以及是否已啟用或停用任何功能。系統不會記錄通訊內容，或是登入資訊、電子郵件、裝置 ID 等任何可識別個人身分的中繼資料。所有指標資訊都會與伺服器 ID 連結，如需變更伺服器 ID 的操作說明，請參閱[這篇文章](/manager/server-management/reset-server-id)。

 根據預設，Outline 伺服器不會將這些指標資訊分享給 Outline 團隊。不過如果伺服器管理員明確同意分享這些使用指標，系統每小時都會將這些資訊安全傳送給 Outline 團隊，並在 60 天後以國家/地區為單位來匯總這些使用情形指標。伺服器管理員可隨時前往 Outline Manager 的「設定」選單，變更使用指標分享偏好設定。

 我們非常感謝使用者分享伺服器使用情形的匿名指標，協助我們評估使用趨勢和改良產品。

 舉例來說，如果伺服器管理員選擇分享使用指標，我們就能得知 ID 12345 的伺服器昨天使用了 3 個小時，分別透過在美國與加拿大使用的三組金鑰傳輸了共 500 MB 的資料，並已啟用數據用量上限功能。

 2. 你提交的意見回饋內容和電子郵件地址

 Outline Manager 和 Outline 應用程式都有意見回饋功能，使用時建議不要附上個人識別資訊，但如果想收到回覆，可以在電子郵件欄位留下資料。此外，我們也會自動收集一些基本資訊，以便進一步瞭解您的意見回饋。如想知道我們還會收集哪些資料，請參閱上文「系統自動取得的資訊」一節中的第 2 點說明。另請參閱[這篇文章](/about/security-and-privacy)，進一步瞭解 Outline 的安全性和隱私權實務規範。

 如果你在 Android 裝置上使用 Outline 應用程式 Beta 版，我們會運用 Google 的 [Firebase](https://firebase.google.com/) 服務收集偵錯資訊，從而偵測問題並提升 Outline 的服務品質。如要進一步瞭解 Firebase 的隱私權與安全性政策，請前往 Firebase 網站：[firebase.google.com/support/privacy](https://firebase.google.com/support/privacy)。如果不想讓 Outline 透過 Firebase 傳送這些資訊，請使用正式版應用程式。
