安裝完 Outline 伺服器後，你便可開始與他人共用及管理伺服器存取權。收到邀請的對象將能下載並使用 Outline 應用程式保護網路流量。

## 共用 Outline 伺服器存取權
 Outline 伺服器安裝完畢後，系統會將你導向 Outline Manager 的伺服器詳細資料頁面。你可以在這個頁面建立存取金鑰。進一步瞭解[存取金鑰](/about/terminology)。

- 建立金鑰：點選頁面底部的「+」小圖示，即可建立新的金鑰。
- 共用金鑰：點選每個金鑰右側的共用圖示，即會檢視邀請訊息。請複製這個訊息並貼到你選擇的通訊系統中。

## 功能要求：在 Outline Manager 應用程式中共用存取權
 許多伺服器管理員曾表示希望簡化邀請流程，讓他們直接在 Outline Manager 中輸入特定對象的電子郵件地址。

然而很抱歉，我們目前無法在 Outline Manager 中內建這項功能。我們的其中一個核心原則是保護使用者的隱私和安全性，因此我們不能設計任何可插入電子郵件地址或聯絡資訊的位置。

正因為如此，我們要求伺服器管理員傳送邀請給使用者時，必須使用安全的通訊平台 (例如電子郵件) 或即時通訊工具。

## 取得共用的存取金鑰後，使用者須執行以下操作
1. 在自己的裝置上按一下安裝連結
2. 如果使用者未安裝 Outline 應用程式，系統將提示他們安裝
3. 使用者會透過邀請中隨附的專屬金鑰與您的 Outline 伺服器進行初次連線
4. 隨後，使用者便可以利用「連線」或「中斷連線」按鈕，管理透過您 Outline 伺服器連線網際網路的存取權

## 移除使用者的 Outline 伺服器存取權
 請前往 Outline Manager 的伺服器詳細資料頁面，在伺服器的每個金鑰右側找到選單，然後選取刪除金鑰的選項。請注意，刪除金鑰會一併移除對應的伺服器存取權。
