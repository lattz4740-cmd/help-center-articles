---
title: 如何重設伺服器 ID？
sidebar_label: 如何重設伺服器 ID？
---

伺服器 ID 是在建立 Outline 伺服器時，隨機產生的伺服器端 ID。只要在「設定」介面中選擇分享匿名指標，即可看到這組 ID。如要查詢伺服器 ID，請點選「設定」，捲動到底部，然後勾選「分享匿名指標」。

伺服器 ID 可統整系統持續回報的匿名使用統計資料。如要重設伺服器 ID 並取得新 ID，則必須建立新的 Outline 伺服器來取代現有伺服器。

如果你的雲端服務供應商是 DigitalOcean，只要前往「設定」並選取「刪除伺服器」，就能重設伺服器。這項操作無法復原，還會清除你的憑證。系統隨後會提示你在自己選擇的位置建立新伺服器，並產生新的伺服器 ID。
