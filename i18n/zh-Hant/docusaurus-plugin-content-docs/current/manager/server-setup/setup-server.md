如要使用 Outline，第一步得先設定 Outline 伺服器。請親自或是由您信任的人來設定伺服器，完成之後才能透過 Outline 連線至開放的網際網路。

## 事前準備

開始設定 Outline 伺服器之前，您必須具備：

1. 您專屬伺服器的存取權或雲端服務供應商 (例如 DigitalOcean、Amazon Web Services (AWS) 或 Google Cloud Platform (GCP)) 的存取權。

 如果您目前還無法存取任何雲端伺服器，可選擇任何供應商 (包括上述名單中的供應商)，輕鬆設定帳戶；不過您可能需要有信用卡才能完成註冊。
2. 執行 macOS 10.9 以上版本、Windows 7.0 以上版本或 Linux 的桌上型電腦。
3. Outline Manager 應用程式。

## 透過 DigitalOcean 進行設定

我們將設定步驟設計得非常簡單，使用者只要按幾下滑鼠，就能在 DigitalOcean 上安裝 Outline。在您的電腦下載並安裝 Outline Manager 後，您可以選取 DigitalOcean 設定選項，接著系統會顯示簡單的操作畫面，引導您設定及安裝 Outline 伺服器。

## 透過其他雲端服務供應商進行設定

下載並安裝 Outline Manager 後，您可以選擇使用 AWS、GCP、DigitalOcean 或其他供應商的服務來將 Outline 安裝到虛擬機器。每種環境的步驟都不相同，因此我們在 Outline Manager 設定流程中納入幾間常見服務供應商的操作說明，包括如何在虛擬機器上完成設定並執行安裝指令碼，以在伺服器上安裝 Outline。
