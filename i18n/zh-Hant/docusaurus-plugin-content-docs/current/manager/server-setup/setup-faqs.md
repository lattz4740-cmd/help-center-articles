## 如果沒有伺服器，可以使用 Outline 嗎？

很抱歉，不可以。Outline 軟體需要有伺服器存取權才能運作；伺服器由您、您的機構組織或信任的第三方代管皆可。

## 設定 Outline 伺服器需要多久時間？

通常可以在 5 分鐘以內完成。我們與 DigitalOcean 合作，提供更容易使用的引導安裝程序，讓您按幾下滑鼠就能輕鬆設定伺服器，完全不需要執行指令碼。不過，您也可以在其他雲端伺服器上安裝 Outline。

 如果您選用 AWS、GCP 或進階設定服務，我們也已將伺服器的安裝程序簡化為只要執行一個指令碼，就能處理好大部分的環境設定。

## 我可以在哪裡設定 Outline 伺服器？

您可以透過大部分雲端供應商在其提供服務的地區設定 Outline 伺服器。

最簡單的做法是在 DigitalOcean 上設定，因為這間供應商提供的伺服器遍布阿姆斯特丹、多倫多、舊金山和新加坡等多個地區。如果您希望將 Outline 安裝在其他雲端服務供應商或自己的基礎架構上，可以在 Outline Manager 應用程式中選擇 [進階模式]，然後使用設定指令碼按照安裝說明操作。

## 我應該將 Outline 伺服器設定在哪裡？

為您的 Outline 伺服器挑選設定地點時，不妨考量以下幾點：

1. Outline 伺服器位置會影響使用者的網際網路體驗。 舉例來說，假設伺服器位於阿姆斯特丹，存取這台伺服器的使用者連線網際網路時，看到的介面就會像在荷蘭上網一樣；有些網站甚至會顯示位於荷蘭。一般來說，您可以使用網站的語言選擇工具來覆寫語言設定。
2. 使用者和 Outline 伺服器之間的距離可能會影響連線速度。 一般而言，Outline 使用者和伺服器之間的實際距離會影響使用者的網際網路速度。在大部分情況下，您可以為最靠近預期使用者所在地的伺服器選擇位置，不過您也可以查看[海底纜線圖](https://www.submarinecablemap.com/)，確認連到您國家/地區的是哪一條網際網路纜線。
3. VPN 伺服器的所在位置可能會影響法律架構。 請注意，Outline 軟體不會記錄你的流量。進一步瞭解「[使用 Outline 的安全性和隱私權](/about/security-and-privacy)」。
