---
title: 如何設定多台 Outline 伺服器
sidebar_label: 如何設定多台 Outline 伺服器
---

如要設定更多台 Outline 伺服器，請按一下 Outline Manager 應用程式左側導覽面板的「+」圖示。新增伺服器的操作方式，和安裝第一台伺服器相同。

- 您可建立的 Outline 伺服器數量不限。
- 您建立的每台 Outline 伺服器都要有對應的虛擬機器。
- 如果建立額外的機器或 Droplet，雲端服務供應商向您收取的費用可能會隨之增加。請先與您的雲端服務供應商確認定價，以免超過您的預算。

## 在 DigitalOcean 上建立額外的 Outline 伺服器

按一下「+」圖示並選取在 DigitalOcean 上安裝後，請按照設定第一台伺服器的說明操作。此外，由於 Outline Manager 已與 DigitalOcean 整合，因此即使未離開 Outline Manager 應用程式介面，也能直接建立 Droplet。

請注意，Outline Manager 一次只支援使用一個 DigitalOcean 帳戶。如果您要透過其他 DigitalOcean 帳戶來新增或建立額外的 Outline 伺服器，可以在進階設定中新增。

## 透過 GCP、AWS 或其他雲端服務供應商建立額外的 Outline 伺服器

首先，請選擇雲端服務供應商來建立新的虛擬機器。接著開啟 Outline Manager，按照操作說明完成進階安裝，步驟與第一次設定相同。
