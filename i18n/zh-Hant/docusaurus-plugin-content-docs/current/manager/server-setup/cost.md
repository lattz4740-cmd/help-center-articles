title: 執行 Outline 需要支付多少費用？
sidebar_label: 執行 Outline 需要支付多少費用？
---

Outline 軟體提供所有人免費使用，不管您是管理 VPN 的伺服器管理員或透過 Outline 來存取開放網際網路的使用者，都不用付費。

 不過，Outline 需要有雲端服務的伺服器存取權才能運作。已有伺服器存取權的伺服器管理員可以直接安裝 Outline，不須支付額外費用。至於還沒有伺服器存取權的使用者，可透過雲端服務供應商 (如 [DigitalOcean](https://www.digitalocean.com/) 或 Amazon Web Services) 來設定伺服器，費用大約是每月 1 TB 資料傳輸量 $5 美元，這個流量足以讓一台伺服器支援上百名使用者的需求。

 以下舉例說明如何計算在您選擇的雲端服務供應商上運作 Outline 的費用：

| *假設每位使用者平均每月使用的資料傳輸量是 5 GB，而每月 $5 美元的方案可支援大約 200 名同時使用的使用者，換算下來，每位使用者每月的平均費用約為 $2.5 美分。請注意，每名使用者每月可用的資料傳輸量取決於使用者活動佔用的頻寬多寡，且用量可能有大幅波動，但大部分雲端服務供應商都會有因應流量爆增的彈性措施。* |
| --- |

使用者使用 Outline 時完全匿名，Jigsaw 和 Google 無法得知使用者資料。我們不會追蹤您的身分識別或流量，且也不會實施任何營利方案。事實上，我們與開放原始碼社群合作，確保能為使用者提供免費的軟體。進一步瞭解[我們收集的資料](https://getoutline.org/policies/data-collection)。
