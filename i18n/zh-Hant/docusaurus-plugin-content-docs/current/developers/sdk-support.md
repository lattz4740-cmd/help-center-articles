本支援網站適用於 Outline Manager 和 Outline 用戶端使用者。開發人員請前往 GitHub 尋求支援。如要提問，請在 SDK [討論區](https://github.com/Jigsaw-Code/outline-sdk/discussions)發布貼文，這是提出問題、分享想法和連結至試用版的絕佳管道，你也能在該處支援使用 Outline SDK 的其他開發人員。如要查看功能要求或錯誤報告，請改為建立[問題](https://github.com/Jigsaw-Code/outline-sdk/issues/new)。
