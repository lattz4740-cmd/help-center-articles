sidebar_label: "Какви са системните изисквания за работа на клиента за Outline?"
---

Можете да изпробвате Outline на която и да е операционна система. Минималните изисквани версии на операционните системи са следните:

| **Операционна система** | **Минимална версия** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Искате ли да помогнете клиентът за Outline да работи на повече операционни системи? [Дайте приноса си към кода](https://github.com/Outline-Foundation/outline-client#platform-specific-development) ни в GitHub!
