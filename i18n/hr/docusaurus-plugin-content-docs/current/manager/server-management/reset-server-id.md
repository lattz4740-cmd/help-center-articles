---
title: "Kako mogu poništiti ID poslužitelja?"
sidebar_label: "Kako mogu poništiti ID poslužitelja?"
---

ID poslužitelja jest ID na strani poslužitelja koji se nasumično generira pri izradi Outline poslužitelja. Možete ga pronaći ako na sučelju Postavke uključite dijeljenje anonimnih mjernih podataka. ID poslužitelja možete pronaći ovako: Postavke => pomaknite se na dno => označite "dijeljenje anonimnih mjernih podataka".

ID poslužitelja povezuje anonimnu statistiku upotrebe koja se prijavljuje tijekom vremena. Ako želite poništiti ID poslužitelja i dobiti novi, postojeći Outline poslužitelj trebate zamijeniti novim.

Ako je vaš davatelj usluga u oblaku DigitalOcean, svoj poslužitelj možete poništiti tako da otvorite Postavke i odaberete Uništi poslužitelj. Ta se radnja ne može poništiti i njome se brišu vaše vjerodajnice. Odmah nakon toga prikazat će se uputa da izradite novi poslužitelj na lokaciji koju odaberete i generirat će se novi ID poslužitelja.
