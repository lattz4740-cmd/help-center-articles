Et convidem a provar Outline amb qualsevol sistema operatiu. Aquests són els sistemes operatius mínims necessaris:

| **Sistema operatiu** | **Versió mínima** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Vols ajudar perquè el client d'Outline funcioni en més sistemes operatius? [Contribueix a la nostra base de codi](https://github.com/OutlineFoundation/outline-client#platform-specific-development) a GitHub!
