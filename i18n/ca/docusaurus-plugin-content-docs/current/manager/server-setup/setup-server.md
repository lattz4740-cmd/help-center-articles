Configurar un servidor d'Outline és el primer pas que s'ha de dur a terme per poder utilitzar Outline. Cal que o bé tu o bé una persona en qui confiïs configureu un servidor que et permeti connectar-te a la Internet oberta amb Outline.

## Abans de començar
 Abans de començar a configurar el servidor d'Outline, necessites unes quantes coses:

1. Accés als teus servidors o a un proveïdor de serveis en núvol, com ara DigitalOcean, Amazon Web Services (AWS) o Google Cloud Platform (GCP).

 Si no tens accés a cap servidor al núvol, pots crear un compte fàcilment amb qualsevol proveïdor, inclosos els que s'indiquen més amunt. És probable que necessitis una targeta de crèdit per registrar-t'hi.
2. Un ordinador amb macOS 10.9 o versions posteriors, Windows 7.0 o versions posteriors, o Linux.
3. L'aplicació Gestor d'Outline.

## Configurar el servidor amb DigitalOcean
 Hem simplificat la instal·lació d'Outline a DigitalOcean perquè es pugui fer amb uns quants clics. Després de baixar i d'instal·lar el Gestor d'Outline a l'ordinador, pots seleccionar l'opció de configuració DigitalOcean, que et guiarà per una sèrie de pantalles senzilles per configurar i instal·lar el servidor d'Outline.

## Configurar el servidor amb un altre proveïdor de serveis al núvol
 Després de baixar i d'instal·lar el Gestor d'Outline, pots optar per instal·lar un servidor d'Outline en una màquina virtual amb AWS, GCP, DigitalOcean o un altre proveïdor. Cada entorn és diferent i, per això, hem inclòs instruccions per als proveïdors al núvol més habituals a l'auxiliar de configuració del Gestor d'Outline, que inclouen el procediment per configurar les opcions a la màquina virtual abans d'executar l'script d'instal·lació per instal·lar Outline en un servidor.
