---
title: "Com es configuren diversos servidors d'Outline"
sidebar_label: "Com es configuren diversos servidors d'Outline"
---

Per configurar més servidors d'Outline, fes clic a la icona "+" que hi ha al tauler de navegació situat a l'esquerra de l'aplicació Gestor d'Outline. Per afegir un altre servidor, segueix les mateixes instruccions que per instal·lar el primer.

- No hi ha cap límit en el nombre de servidors d'Outline que pots crear.
- Per a cada servidor d'Outline que creïs, necessitaràs una màquina virtual corresponent.
- Crear altres màquines o droplets pot augmentar la tarifa del proveïdor de serveis en núvol. Consulta'n el paquet de preus per fer les previsions pertinents.

## Crear un altre servidor d'Outline a DigitalOcean

Després de fer clic a la icona "+" i de seleccionar la instal·lació a DigitalOcean, hauràs de seguir les mateixes instruccions que per configurar el primer servidor. A més, com que el Gestor d'Outline s'integra a DigitalOcean, podem crear-te el droplet sense que hagis de sortir en cap moment de l'aplicació Gestor d'Outline.

Tingues en compte que el Gestor d'Outline només admet un compte de DigitalOcean a la vegada. Si vols afegir o crear altres servidors d'Outline des d'altres comptes de DigitalOcean, pots afegir-los en una configuració avançada.

## Crear un altre servidor d'Outline a GCP, AWS o en un altre proveïdor de serveis en núvol

Per començar, crea una altra màquina virtual amb el proveïdor de serveis en núvol escollit. A continuació, obre el Gestor d'Outline i segueix les instruccions per a la instal·lació avançada, tal com vas fer la primera vegada.
