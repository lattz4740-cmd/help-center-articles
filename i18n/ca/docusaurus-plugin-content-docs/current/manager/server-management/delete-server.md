---
title: "Com puc suprimir el servidor d'Outline?"
sidebar_label: "Com puc suprimir el servidor d'Outline?"
---

Per a la majoria dels proveïdors de serveis al núvol, és bastant fàcil suprimir la màquina virtual específica que fas servir.

Si DigitalOcean és el teu proveïdor de serveis al núvol, pots suprimir la màquina virtual existent fent clic al botó d'engranatge i seleccionant Suprimeix el servidor. Just després, se't demanarà que creïs una màquina virtual nova en la ubicació que triïs.

Si suprimeixes un servidor d'Outline, se suprimirà permanentment i les seves claus d'accés ja no funcionaran. Si no vols que s'interrompi l'accés dels usuaris a Outline, caldrà que [configuris un servidor d'Outline nou](/manager/server-setup/setup-server) i que comparteixis l'accés a aquest servidor nou abans de suprimir l'antic.
