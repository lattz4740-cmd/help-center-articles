---
title: Com es poden enviar suggeriments
sidebar_label: Com es poden enviar suggeriments
---

Gràcies per ajudar-nos a millorar Outline. Tens diverses maneres d'enviar-nos suggeriments, ja sigui de manera anònima o des de la teva adreça electrònica si vols rebre una resposta:

- **Per a desenvolupadors**: Outline és un programari de codi obert que té tot el codi allotjat a [GitHub](https://github.com/Outline-Foundation/?q=outline). Pots compartir la teva opinió a GitHub o a la nostra comunitat de [Reddit](https://www.reddit.com/r/outlinevpn/).
- **Per a usuaris**: ens pots enviar suggeriments des de les aplicacions Outline o Gestor d'Outline. Explica'ns quin tipus de suggeriments vols plantejar i, si vols, indica'ns la teva adreça electrònica perquè et puguem respondre. També recollim algunes metadades sobre el teu entorn, com ara el navegador, el sistema operatiu i la versió de programari que fas servir, per poder-te ajudar a solucionar problemes.
- **A través d'aquest lloc web**: pots fer clic a l'enllaç Contacta amb nosaltres que trobaràs en aquest lloc web.
- **Problemes importants**: si vols informar d'un problema de seguretat important, envia'ns un correu electrònic amb els detalls corresponents a security[arrova][getoutline.org](https://getoutline.org/).

Gràcies una vegada més per compartir les teves opinions amb nosaltres.
