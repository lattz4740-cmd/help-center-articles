## តើ VPN គឺជាអ្វី?
បណ្តាញ​ឯកជននិម្មិត (VPN) គឺជា​ការតភ្ជាប់​ឯកជន​រវាង​ឧបករណ៍​របស់អ្នក និង​ម៉ាស៊ីនមេ​បង្ហោះ។ នៅពេល​អ្នកប្រើប្រាស់ VPN ចរាចរណ៍​របស់អ្នក​ត្រូវបាន​លាក់​ពី​ក្រុមហ៊ុន​ផ្ដល់សេវា​អ៊ីនធឺណិត។ អ្នកប្រហែល​ចង់ប្រើប្រាស់ VPN នៅក្នុង​សេណារីយ៉ូ​ដូចខាងក្រោម៖

- ការពារ​ទិន្នន័យ​របស់អ្នក នៅពេល​ប្រើប្រាស់​បណ្ដាញ Wi-Fi សាធារណៈ
- រក្សា​ទិន្នន័យរុករក​របស់អ្នក​ជាឯកជន​ពី​ក្រុមហ៊ុន​ផ្ដល់សេវា​អ៊ីនធឺណិតរបស់អ្នក និងទី​ភ្នាក់ងារ​រដ្ឋាភិបាល
- ចូលប្រើ​ខ្លឹមសារ​ដែលគ្មានការចាប់ពិរុទ្ធពី​ប្រភព​ផ្សេងៗនៅជុំវិញពិភពលោក

## តើ Outline ខុសពី VPN ធម្មតា​យ៉ាងដូចម្តេច?
 ក្រុមហ៊ុនផ្តល់សេវាអ៊ីនធឺណិតអាចចាប់បាន និង​ទប់ស្កាត់ VPN ធម្មតាយ៉ាងងាយស្រួល ដោយស្គាល់ប្រូតូកូលសុវត្ថិភាពទូទៅ និង/ឬលំនាំបរិមាណចរាចរណ៍។ Outline មានលក្ខណៈធន់ជាង VPN ធម្មតា ដោយសារ​វា​ត្រូវ​បាន​បង្កើត​ឡើង​ដោយ​ប្រើប្រាស់​ប្រូតូកូល​ដែល​ត្រូវ​បាន​រចនាឡើង​ឱ្យ​គេ​ពិបាក​ចាប់​បាន ដូច្នេះកាន់​តែ​ពិបាក​ទប់ស្កាត់។ Outline ធន់នឹង​ទម្រង់​នៃ​ការចាប់​ពិរុទ្ធ​ដែល​ស្មុគស្មាញ រួមទាំង​ការទប់ស្កាត់​ផ្អែក​តាម​បណ្ដាញ និង​ការទប់ស្កាត់ IP ជាដើម។

## តើម៉ាស៊ីនមេ Outline គឺជាអ្វី?
 ម៉ាស៊ីនមេ Outline ដំណើរការ VPN ដែលអ្នកប្រើប្រាស់ដែលមានការអនុញ្ញាតនឹងភ្ជាប់ទៅ។ ប្រសិនបើអ្នកកំពុងបង្កើតបណ្ដាញថ្មី អ្នកអាចប្រើម៉ាស៊ីនមេដែលមានសុវត្ថិភាពរបស់អ្នកផ្ទាល់ជាម៉ាស៊ីនមេ Outline របស់អ្នក បើមាន ឬអ្នកអាចប្រើក្រុមហ៊ុនផ្ដល់សេវាប្រព័ន្ធពពក ដូចជា៖

- DigitalOcean
- Google Cloud Platform (GCP)
- Amazon Web Services (AWS)

អ្នកនឹង​រៀបចំ​ម៉ាស៊ីនមេ​របស់អ្នក​នៅក្នុង Outline Manager។
