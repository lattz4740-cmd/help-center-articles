សូមអរគុណសម្រាប់ការជួយធ្វើឱ្យ Outline កាន់តែប្រសើរឡើង! មានវិធីមួយចំនួនក្នុងការផ្ញើមតិកែលម្អមកយើង ដោយអនាមិក ឬតាមអ៊ីមែលរបស់អ្នក ប្រសិនបើអ្នកត្រូវការការឆ្លើយតប៖

- **សម្រាប់​អ្នក​អភិវឌ្ឍន៍**៖ Outline គឺជា​កម្មវិធីកូដ​ចំហ ហើយយើង​បង្ហោះ​កូដទាំងអស់​របស់យើងនៅលើ [GitHub](https://github.com/OutlineFoundation/?q=outline)។ អ្នកអាច​ចែករំលែក​គំនិត​របស់អ្នក​នៅលើ GitHub ឬ​នៅលើសហគមន៍ [Reddit](https://www.reddit.com/r/outlinevpn/) របស់យើង។
- **សម្រាប់​អ្នកប្រើប្រាស់**៖ អ្នក​អាចផ្ញើ​មតិកែលម្អ​មកយើង​តាមរយៈ​កម្មវិធី Outline ឬ Outline Manager។ ប្រាប់យើងអំពីខ្លឹមសារនៃមតិកែលម្អរបស់អ្នក ហើយជាជម្រើស ផ្ដល់អ៊ីមែល ដើម្បីឱ្យយើងអាចសរសេរតបទៅអ្នកវិញបានទាក់ទងនឹងមតិកែលម្អនោះ។ យើងក៏​ប្រមូល​ទិន្នន័យមេតា​មួយចំនួន​អំពី​មជ្ឈដ្ឋាន​របស់អ្នក ដើម្បី​ឱ្យយើង​អាចជួយអ្នក​ក្នុងការ​ដោះស្រាយ​បញ្ហា ដូចជា​ប្រព័ន្ធ​ប្រតិបត្តិការ កម្មវិធីរុករក​តាមអ៊ីនធឺណិត​របស់អ្នក និងកំណែ​កម្មវិធី​ដែលអ្នកកំពុងប្រើ​ផងដែរ។
- **តាមរយៈ​គេហទំព័រនេះ**៖ អ្នកអាច​ចុចលើ​តំណ "ទាក់ទង​មកយើង" នៅគ្រប់ទីកន្លែង​ដែលអ្នក​ឃើញវា​នៅក្នុង​គេហទំព័រនេះ។
- **បញ្ហា​ធ្ងន់ធ្ងរ**៖ ប្រសិនបើ​អ្នកចង់​រាយការណ៍​អំពី​បញ្ហា​សុវត្ថិភាពធ្ងន់ធ្ងរ សូមផ្ញើ​អ៊ីមែល​មកយើង​ដោយផ្ដល់​ព័ត៌មាន​លម្អិត​តាមរយៈ security [at] [getoutline.org](https://getoutline.org/)។

សូមអរគុណជាថ្មីម្តងទៀតសម្រាប់ការចំណាយពេលចែករំលែកគំនិតរបស់អ្នកជាមួយ​យើង។
