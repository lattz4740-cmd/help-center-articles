អ្នក​អាចមើលឃើញ​សារបញ្ហា​នេះ៖ “សូម​អភ័យទោស Outline ហាក់​ដូចជា​មិនត្រូវ​បានដំឡើង​ត្រឹមត្រូវទេ។ សូម​សាកល្បង​ដំឡើង​វា​ម្ដង​ទៀត។ ប្រសិនបើ​ការធ្វើបែបនោះ​មិនមាន​ប្រសិទ្ធភាពទេ សូម[ដាក់បញ្ជូន​មតិកែលម្អ](/about/feedback)។”

ប្រសិនបើអ្នកកំពុងប្រើ Outline នៅលើ Windows អ្នកអាចជួបបញ្ហាដែលមិនបានរំពឹងទុកម្ដងម្កាល។ ក្នុងករណី​ភាគច្រើន ចាំបាច់ត្រូវលុប​អាដាប់ទ័រ TAP (ដ្រាយវើ) របស់ Outline ហើយ Outline គួរតែត្រូវបានដំឡើងឡើងវិញ។

ជំហាន​អាចប្រែប្រួល​ដោយ​ផ្អែកលើ​កំណែប្រព័ន្ធ​ប្រតិបត្តិការ Windows របស់អ្នក ប៉ុន្តែ​ខាងក្រោមនេះ​គឺជាជំហាន​ទូទៅ​ទាក់ទងនឹង​របៀបលុប​អាដាប់ទ័រ TAP និង Outline Manager រួច​ដំឡើង Outline Manager ឡើងវិញ។

1. លុប​អាដាប់ទ័រ TAP សម្រាប់ Outline Manager
   1. ចូលទៅកាន់ "កម្មវិធី​គ្រប់គ្រង​ឧបករណ៍" បន្ទាប់មក "អាដាប់ទ័រ​បណ្ដាញ"
   2. ស្វែងរក​ឯកសារ “TAP-Windows Adapter V9” ឬអាដាប់ទ័រ TAP ដែលភ្ជាប់ជាមួយ Outline
   3. លុបអាដាប់ទ័រនេះ។ សូម​ចងចាំថា ការធ្វើបែបនេះ​អាចប៉ះពាល់​ដល់កម្មវិធី VPN ផ្សេងទៀត​ដែលអ្នក​បានដំឡើង។
2. លុប Outline Manager
   1. ចូលទៅកាន់ "កម្មវិធី និងមុខងារ" បន្ទាប់មក "លុបកម្មវិធី"
   2. ស្វែងរក​កម្មវិធី Outline Manager ហើយលុប Outline Manager
   3. [ទាញយក​កំណែចុងក្រោយបំផុត​របស់ Outline Manager](https://getoutline.org/get-started/#step-1) រួចដំឡើងវាឡើងវិញ​នៅលើ​ឧបករណ៍ Windows របស់អ្នក។ ការដំឡើងថ្មី​គួរតែ​ដំឡើង​អាដាប់ទ័រ TAP ថ្មី​ដោយស្វ័យប្រវត្តិ។

ប្រសិន​បើអ្នក​នៅតែមានបញ្ហា​ទៀត សូម[ទាក់ទង​ទៅផ្នែកជំនួយ](/about/feedback)។
