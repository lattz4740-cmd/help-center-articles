ដើម្បីរៀបចំម៉ាស៊ីនមេ Outline បន្ថែម សូមចុចលើរូបតំណាង “+” នៅលើផ្ទាំងរុករកនៅផ្នែកខាងឆ្វេងនៃកម្មវិធី Outline Manager របស់អ្នក។ ការណែនាំក្នុងការបញ្ចូលម៉ាស៊ីនមេថ្មីគឺដូចគ្នានឹងករណីដែលអ្នកកំពុងដំឡើងម៉ាស៊ីនមេដំបូងរបស់អ្នកដែរ។

- យើងមិនមានដែនកំណត់លើចំនួនម៉ាស៊ីនមេ Outline ដែលអ្នកអាចបង្កើតទេ។
- ចំពោះរាល់ម៉ាស៊ីនមេ Outline ដែលអ្នកបង្កើត អ្នកនឹងត្រូវការម៉ាស៊ីននិម្មិតដែលត្រូវគ្នា។
- ការបង្កើតម៉ាស៊ីន ឬម៉ាស៊ីននិម្មិតបន្ថែមអាចបង្កើនថ្លៃសេវារបស់អ្នកជាមួយក្រុមហ៊ុនផ្ដល់សេវាប្រព័ន្ធ​ពពករបស់អ្នក។ សូមផ្ទៀងផ្ទាត់កញ្ចប់តម្លៃរបស់អ្នកជាមួយក្រុមហ៊ុនផ្ដល់សេវាប្រព័ន្ធ​ពពករបស់អ្នក ដើម្បីប្រាកដថាអ្នកដឹងអំពីអ្វីដែលត្រូវរំពឹងទុក។

## ការបង្កើតម៉ាស៊ីនមេ Outline បន្ថែមនៅលើ DigitalOcean

បន្ទាប់ពីចុចលើរូបតំណាង + និងជ្រើសរើសដំឡើងនៅលើ DigitalOcean អ្នកនឹងធ្វើតាមការណែនាំដែលដូចគ្នានឹងការណែនាំដែលអ្នកបានអនុវត្តក្នុងការរៀបចំម៉ាស៊ីនមេដំបូងរបស់អ្នកដែរ។ ទន្ទឹមនឹងនេះ ដោយសារ Outline Manager រួមបញ្ចូលជាមួយ DigitalOcean យើងអាចបង្កើតម៉ាស៊ីននិម្មិតជូនអ្នក ដោយមិនចាំបាច់ចាកចេញពីកម្មវិធី Outline Manager ឡើយ។

សូមចំណាំថា Outline Manager អាចឱ្យគណនី DigitalOcean តែមួយប៉ុណ្ណោះប្រើបានក្នុងមួយលើក។ ប្រសិនបើអ្នកចង់បញ្ចូល ឬបង្កើតម៉ាស៊ីនមេ Outline ផ្សេងទៀតពីគណនី DigitalOcean ផ្សេងទៀត អ្នកអាចបញ្ចូលម៉ាស៊ីនមេទាំងនោះជាការកំណត់រចនាសម្ព័ន្ធកម្រិតខ្ពស់។

## ការបង្កើតម៉ាស៊ីនមេ Outline បន្ថែមនៅលើ GCP, AWS ឬក្រុមហ៊ុនផ្ដល់សេវាប្រព័ន្ធពពកផ្សេងទៀត

ចាប់ផ្តើមដោយបង្កើតម៉ាស៊ីននិម្មិតថ្មីតាមរយៈក្រុមហ៊ុនផ្ដល់សេវាប្រព័ន្ធ​ពពកដែលអ្នកបានជ្រើសរើស។ បន្ទាប់មកបើក Outline Manager រួចអនុវត្តតាមការណែនាំសម្រាប់ការដំឡើងកម្រិតខ្ពស់ ដូចដែលអ្នកប្រហែលបានអនុវត្តនៅលើកដំបូងដូច្នោះដែរ។
