## តើខ្ញុំអាចប្រើប្រាស់ Outline ដោយគ្មានម៉ាស៊ីនមេបានទេ?
 គួរឱ្យសោកស្ដាយ អ្នកមិនអាចទេ។ កម្មវិធី Outline តម្រូវឱ្យមានសិទ្ធិចូលប្រើម៉ាស៊ីនមេ មិនថាសិទ្ធិនោះត្រូវបានគ្រប់គ្រងដោយអ្នក ស្ថាប័នរបស់អ្នក ឬភាគីទីបីដែលអាចទុកចិត្តបាននោះទេ។

## តើត្រូវចំណាយពេលយូរប៉ុនណា ដើម្បីរៀបចំម៉ាស៊ីនមេ Outline?

ក្នុងករណីភាគច្រើន តិចជាង 5 នាទី។ អ្នកអាចដំឡើង Outline នៅលើម៉ាស៊ីនមេលើប្រព័ន្ធពពកណាក៏បាន ប៉ុន្តែយើងបានសហការជាមួយ DigitalOcean ដើម្បីផ្ដល់ជូននូវបទពិសោធដំឡើងតាមការណែនាំដែលកាន់តែងាយស្រួលសម្រាប់អ្នកប្រើប្រាស់ ហើយអ្នកអាចរៀបចំម៉ាស៊ីនមេរបស់អ្នកដោយគ្រាន់តែចុចពីរបីដងប៉ុណ្ណោះ ដោយមិនប្រើស្គ្រីប។

ប្រសិនបើអ្នកបានជ្រើសរើស AWS, GCP ឬការរៀបចំកម្រិតខ្ពស់ យើងបានសម្រួលដំណើរការដំឡើងម៉ាស៊ីនមេទៅជាស្គ្រីបតែមួយដែលដំណើរការក្នុងមជ្ឈដ្ឋានភាគច្រើន។

## តើខ្ញុំអាច​រៀបចំ​ម៉ាស៊ីនមេ Outline បាននៅឯណា?
