ការរៀបចំម៉ាស៊ីនមេ Outline គឺជាជំហានដំបូងដែលផ្ដល់លទ្ធភាពឱ្យអ្នកប្រើប្រាស់ Outline បាន។ អ្នក ឬនរណាម្នាក់ដែលអ្នកជឿទុកចិត្តចាំបាច់ត្រូវរៀបចំម៉ាស៊ីនមេជូនអ្នក ដើម្បីឱ្យអ្នកភ្ជាប់អ៊ីនធឺណិតបើកចំហតាមរយៈ Outline។

## មុនពេល​អ្នកចាប់ផ្ដើម
មុនពេល​អ្នកចាប់ផ្ដើម​រៀបចំ​ម៉ាស៊ីនមេ Outline របស់អ្នក អ្នកនឹង​ត្រូវធ្វើ​កិច្ចការ​មួយចំនួន៖

1. ចូលប្រើ​ម៉ាស៊ីនមេរបស់អ្នកផ្ទាល់ ឬក្រុមហ៊ុនផ្ដល់សេវាលើប្រព័ន្ធពពក ដូចជា DigitalOcean, Amazon Web Services (AWS) ឬ Google Cloud Platform (GCP) ជាដើម។

    ប្រសិនបើ​អ្នកមិនមាន​សិទ្ធិចូលប្រើ​ម៉ាស៊ីនមេ​លើប្រព័ន្ធ​ពពកភ្លាមៗទេ អ្នកអាច​រៀបចំ​គណនី​បានយ៉ាង​ងាយស្រួល​តាមរយៈ​ក្រុមហ៊ុន​ផ្ដល់សេវា​ណាមួយ រួមទាំង​ក្រុមហ៊ុន​ដែលបាន​រៀបរាប់​ខាងលើ​ផងដែរ។ អ្នកទំនងជានឹងត្រូវការកាតឥណទាន ដើម្បីចុះឈ្មោះ។
2. កុំព្យូទ័រលើតុដែលដំណើរការ macOS 10.9+, Windows 7.0+ ឬ Linux។
3. កម្មវិធី Outline Manager។

## រៀបចំ​តាមរយៈ DigitalOcean
យើង​បានបង្កភាពងាយ​ស្រួលដល់អ្នកគ្រប់គ្នាក្នុង​ការដំឡើង Outline នៅលើ DigitalOcean ដោយ​គ្រាន់តែ​ចុចពីរបីដង​ប៉ុណ្ណោះ។ បន្ទាប់ពីទាញយក និងដំឡើង Outline Manager នៅលើកុំព្យូទ័ររបស់អ្នក អ្នកអាចជ្រើសរើសជម្រើសរៀបចំ DigitalOcean ដែលនឹងណែនាំអ្នកតាមរយៈអេក្រង់សាមញ្ញពីរបី ដើម្បីកំណត់រចនាសម្ព័ន្ធ និងដំឡើងម៉ាស៊ីនមេ Outline របស់អ្នក។

## រៀបចំ​តាមរយៈ​ក្រុមហ៊ុនផ្ដល់សេវាប្រព័ន្ធ​ពពកផ្សេងទៀត
បន្ទាប់ពីទាញយក និងដំឡើង Outline Manager អ្នកអាចជ្រើសរើសដំឡើងម៉ាស៊ីនមេ Outline នៅលើម៉ាស៊ីននិម្មិតតាមរយៈ AWS, GCP, DigitalOcean ឬក្រុមហ៊ុន​ផ្ដល់សេវាផ្សេងទៀត។ រាល់មជ្ឈដ្ឋានសុទ្ធតែខុសគ្នា ដូច្នេះយើងបានរួមបញ្ចូលការណែនាំនៅក្នុងដំណើរការរៀបចំ Outline Manager សម្រាប់ក្រុមហ៊ុនផ្ដល់សេវាប្រព័ន្ធ​ពពកទូទៅបំផុត រួមទាំងរបៀបកំណត់រចនាសម្ព័ន្ធការកំណត់នៅលើម៉ាស៊ីននិម្មិតរបស់អ្នក មុនពេលអ្នកដំណើរការស្គ្រីបដំឡើង ដើម្បីដំឡើង Outline នៅលើម៉ាស៊ីនមេ។
