នៅពេលដែលអ្នកបានបញ្ចប់ការដំឡើងម៉ាស៊ីនមេ Outline របស់អ្នក ឥឡូវនេះអ្នកអាចចាប់ផ្តើមចែករំលែក និងគ្រប់គ្រង​សិទ្ធិចូលប្រើ​ម៉ាស៊ីនមេពី​អ្នកប្រើប្រាស់បានហើយ។ អ្នកដែលទទួលបានការអញ្ជើញពីអ្នកនឹងអាចទាញយកកម្មវិធី Outline ដើម្បីប្រើ Outline សម្រាប់​ការពារ​ចរាចរណ៍អ៊ីនធឺណិត​របស់ពួកគេ។

## ចែករំលែក​សិទ្ធិចូលប្រើ​ម៉ាស៊ីនមេ Outline របស់អ្នក
 បន្ទាប់ពី​អ្នកបាន​បញ្ចប់​ការដំឡើង​ម៉ាស៊ីនមេ Outline អ្នកនឹង​ត្រូវបាន​បញ្ជូនទៅ​ទំព័រ​ព័ត៌មាន​លម្អិត​របស់​ម៉ាស៊ីនមេ​នោះ​នៅលើ Outline Manager ដែល​អ្នកអាច​បង្កើត​លេខកូដ​ចូលប្រើ​បាន។ ស្វែងយល់​បន្ថែម​អំពី[លេខកូដ​ចូលប្រើ](/about/terminology)។

- បង្កើត​លេខកូដ៖ ចុច​រូបតំណាង "+" តូច​នៅផ្នែក​ខាងក្រោម​នៃទំព័រ ដើម្បី​បង្កើត​លេខកូដ​ថ្មីៗ។
- ចែករំលែក​លេខកូដ៖ នៅខាងស្តាំ​នៃលេខកូដ​នីមួយៗ មានរូបតំណាង​ចែករំលែក​ដែលអ្នក​អាចចុច​ដើម្បីយក​ការអញ្ជើញ។ ចម្លង និង​ដាក់​ការអញ្ជើញនេះចូលទៅក្នុងប្រព័ន្ធផ្ញើសារតាមជម្រើសរបស់អ្នក។

## សំណើ​មុខងារ៖ ការចែករំលែក​សិទ្ធិចូលប្រើ​ពីក្នុង​កម្មវិធី Outline Manager
 អ្នកគ្រប់គ្រង​ម៉ាស៊ីនមេ​ជាច្រើន​ស្នើឱ្យយើង​សម្រួល​ដំណើរការ​នៃការអញ្ជើញ​ដោយផ្តល់ឱ្យ​ពួកគេ​នូវជម្រើស​ក្នុងការ​បញ្ចូល​អាសយដ្ឋាន​អ៊ីមែល​របស់​នរណាម្នាក់​ដោយផ្ទាល់​ទៅក្នុង Outline Manager។

គួរឱ្យសោកស្តាយ យើងទំនងជាមិនបង្កើតមុខងារនេះក្នុង Outline Manager ទេ។ គោលការណ៍ស្នូលមួយរបស់យើងគឺគាំទ្រដល់ឯកជនភាព និងសុវត្ថិភាពអ្នកប្រើប្រាស់របស់យើង ដែលមានន័យថាយើងមិនបានបង្កើតកន្លែងណាមួយ ដើម្បីបញ្ចូលអាសយដ្ឋានអ៊ីមែល ឬព័ត៌មានទំនាក់ទំនងនោះទេ។

ហេតុនេះ យើង​ស្នើ​ឱ្យ​អ្នក​គ្រប់គ្រង​ម៉ាស៊ីន​មេ​ប្រើប្រព័ន្ធ​ផ្ញើ​សារដែលមាន​សុវត្ថិភាព ដូចជា​អ៊ីមែល ឬ​ការ​ជជែកដែល​មានសុវត្ថិភាព ដើម្បី​ផ្ញើ​ការអញ្ជើញ​ទៅ​អ្នកប្រើប្រាស់ចុងក្រោយ។

## បទពិសោធដែល​អ្នកប្រើប្រាស់​នឹងឆ្លងកាត់ បន្ទាប់ពី​អ្នកចែករំលែក​លេខកូដ​ចូលប្រើ​ជាមួយ​គាត់
1. អ្នកប្រើប្រាស់នឹងចុចលើតំណដំឡើងពីឧបករណ៍របស់គាត់
2. គាត់នឹងត្រូវបានប្រាប់ឱ្យដំឡើងកម្មវិធី Outline ប្រសិនបើគាត់មិនទាន់មានកម្មវិធីនេះទេ
3. គាត់នឹងបង្កើតការតភ្ជាប់ដំបូងទៅម៉ាស៊ីនមេ Outline របស់អ្នកតាមរយៈលេខកូដខុសប្លែកពីគេដែលបានបង្កប់នៅក្នុងការអញ្ជើញ
4. ឥឡូវនេះ គាត់អាចប្រើប៊ូតុងភ្ជាប់/ផ្តាច់ ដើម្បីគ្រប់គ្រងសិទ្ធិចូលប្រើ​អ៊ីនធឺណិត​របស់គាត់​តាមរយៈ​ម៉ាស៊ីនមេ Outline របស់អ្នក

## ដកសិទ្ធិ​ចូលប្រើ​ម៉ាស៊ីនមេ Outline របស់អ្នក
 ពីទំព័រ​ព័ត៌មាន​លម្អិត​របស់ម៉ាស៊ីនមេ​នៅក្នុង Outline Manager នៅខាងស្តាំ​នៃរាល់​លេខកូដ​នៅលើ​ម៉ាស៊ីនមេ អ្នកនឹង​ឃើញម៉ឺនុយ​ដែលមាន​ជម្រើស​លុបលេខកូដ។ ការលុប​លេខកូដ​ដកសិទ្ធិ​ចូលប្រើ​ម៉ាស៊ីនមេ​របស់អ្នក​ពីអ្នកប្រើប្រាស់។
