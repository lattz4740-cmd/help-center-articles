ម៉ាស៊ីនមេ Outline ដំឡើងកំណែដោយស្វ័យប្រវត្តិ ដោយមានការកែលម្អសុវត្ថិភាពចុងក្រោយបំផុត ដូច្នេះអ្នកតែងតែដំណើរការបច្ចេកវិទ្យា Outline ចុងក្រោយបំផុត។ ដំណើរការ​ដំឡើងកំណែ​ដោយស្វ័យ​ប្រវត្តិ​ត្រូវបាន​បើកដោយ [Watchtower](https://github.com/v2tec/watchtower) ដែលជា​បណ្ណាល័យ​កូដចំហ​ដែល​ពិនិត្យមើល និង​ធ្វើបច្ចុប្បន្នភាព​ជាប្រចាំ​នូវរូបភាព docker ដែលមាន​កម្មវិធី Outline។

លើសពី​នេះ នៅពេលអ្នក​ដំឡើង Outline ដោយប្រើ Outline Manager យើងនឹង​រៀបចំ​ការងារ​ជាប្រចាំ ដើម្បី​ដំឡើងកំណែ​កម្មវិធីនេះ​ដោយស្វ័យប្រវត្តិ​នៅលើ​ម៉ាស៊ីនមេ​ដោយប្រើ [Unattended Upgrades](https://wiki.debian.org/UnattendedUpgrades) (Ubuntu) និង​ចាប់ផ្ដើមវា​ឡើងវិញ​នៅពេល​ចាំបាច់។ សូម​ចំណាំថា ករណីនេះ​មិនកើតឡើង​នៅក្នុង​មុខងារ​កម្រិតខ្ពស់ទេ ដើម្បីរក្សា​ការកំណត់រចនាសម្ព័ន្ធ​ដែលមាន​ស្រាប់ ដោយ​សន្មតថា​ម៉ាស៊ីន​កំពុងត្រូវបាន​ប្រើប្រាស់​សម្រាប់​គោលបំណង​ផ្សេងទៀត បន្ថែម​ពីលើ​ការដំណើរការ Outline។
