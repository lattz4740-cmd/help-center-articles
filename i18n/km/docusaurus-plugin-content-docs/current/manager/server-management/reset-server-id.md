លេខកូដ​សម្គាល់​ម៉ាស៊ីនមេ​គឺជា​លេខកូដ​សម្គាល់​ខាងម៉ាស៊ីនមេ​ដែលត្រូវបាន​បង្កើតដោយ​ចៃដន្យ នៅពេលអ្នក​បង្កើត​ម៉ាស៊ីនមេ Outline។ អ្នកអាច​រកឃើញ​លេខសម្គាល់​នោះ នៅពេលជ្រើសរើស​ចែករំលែក​មេទ្រិក​អនាមិក​នៅក្នុងផ្ទៃការ​កំណត់។ អ្នកអាច​កំណត់ទីតាំង​លេខកូដ​សម្គាល់​ម៉ាស៊ីនមេ​របស់អ្នក​ពី៖ ការកំណត់ => រំកិលទៅ​ខាងក្រោម => ធីក "ចែករំលែក​មេទ្រិក​អនាមិក"។

លេខកូដ​សម្គាល់​ម៉ាស៊ីនមេ​ភ្ជាប់​ស្ថិតិ​ប្រើប្រាស់​អនាមិក​ដែលបាន​រាយការណ៍​ទៅតាមពេលវេលា​ជាមួយគ្នា។ ប្រសិន​បើអ្នក​ចង់កំណត់​លេខកូដ​សម្គាល់​ម៉ាស៊ីនមេ​ឡើងវិញ និង​ទទួលបាន​លេខកូដ​សម្គាល់​ថ្មីមួយ អ្នកត្រូវ​ជំនួស​ម៉ាស៊ីនមេ Outline ដែលមានស្រាប់​របស់អ្នក​ដោយ​ម៉ាស៊ីនមេថ្មី។
