សម្រាប់​ក្រុមហ៊ុន​ផ្ដល់សេវាប្រព័ន្ធ​ពពក​ភាគច្រើន ការដក​ម៉ាស៊ីន​និម្មិត​ជាក់លាក់​ដែលអ្នក​កំពុង​ប្រើប្រាស់​ចេញ ពិតជាងាយស្រួល។

ប្រសិន​បើអ្នក​កំពុងប្រើប្រាស់ DigitalOcean ជា​ក្រុមហ៊ុនផ្ដល់សេវាប្រព័ន្ធ​ពពក​របស់អ្នក អ្នកអាច​លុប​ម៉ាស៊ីន​និម្មិត​ដែលមានស្រាប់​របស់អ្នក​ដោយចុច​លើប៊ូតុង​ស្ពឺ រួច​ជ្រើសរើស "លុប​ម៉ាស៊ីនមេ"។ ភ្លាមៗ​បន្ទាប់ពី​នោះ អ្នកនឹង​ត្រូវបាន​ប្រាប់​ឱ្យបង្កើត​ម៉ាស៊ីន​និម្មិតថ្មី​នៅក្នុង​ទីតាំង​ដែលអ្នក​ជ្រើសរើស។

ប្រសិនបើអ្នកដកម៉ាស៊ីនមេ Outline ចេញ ម៉ាស៊ីនមេនោះនឹងត្រូវបានលុបជាអចិន្ត្រៃយ៍ ហើយលេខកូដចូលប្រើរបស់ម៉ាស៊ីនមេនោះនឹងមិនដំណើរការទៀតទេ។ ប្រសិន​បើអ្នក​មិនចង់ឱ្យ​មានមនុស្ស​រងការរំខានក្នុងការចូលប្រើ​របស់​ពួកគេ​តាមរយៈ Outline ទេ អ្នក​នឹងត្រូវ[រៀបចំ​ម៉ាស៊ីនមេ Outline ថ្មី](/manager/server-setup/setup-server) និង​ចែករំលែក​សិទ្ធិចូលប្រើ​ម៉ាស៊ីនមេថ្មី​នោះ មុនពេល​លុប​ម៉ាស៊ីនមេ​ចាស់​របស់អ្នក។
