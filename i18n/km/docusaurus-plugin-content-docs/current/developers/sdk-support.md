គេហទំព័រជំនួយនេះគឺសម្រាប់អ្នកប្រើប្រាស់កម្មវិធីភ្ញៀវ និង Outline Manager។ អ្នក​អភិវឌ្ឍន៍ សូមប្រើប្រាស់ GitHub ដើម្បីទទួលបានជំនួយ។ ដើម្បីសួរសំណួរ សូមបង្ហោះនៅលើ[ផ្ទាំងពិភាក្សា](https://github.com/Jigsaw-Code/outline-sdk/discussions) SDK។ ផ្នែកផ្ទាំងពិភាក្សាគឺជាកន្លែង​ដ៏ប្រសើរ​សម្រាប់សួរសំណួរ ចែករំលែក​គំនិត ភ្ជាប់ទៅ​គំរូបង្ហាញ និង​ជួយដល់​អ្នកអភិវឌ្ឍន៍​ផ្សេងទៀតក្នុងការប្រើប្រាស់ Outline SDK។ សម្រាប់​សំណើ​សុំមុខងារ ឬ​របាយការណ៍អំពី​បញ្ហា សូមបើក[បញ្ហា](https://github.com/Jigsaw-Code/outline-sdk/issues/new)ជំនួសវិញ។
