បាទ/ចាស។ អ្នកអាច​ប្រើ[កូដ​ចូលប្រើ](/about/terminology)របស់អ្នកនៅលើ​ឧបករណ៍​ប៉ុន្មាន​ក៏បាន ប៉ុន្តែ​យើងមិនណែនាំ​ឱ្យអ្នក​ចែករំលែក​កូដ​របស់អ្នក​ជាមួយ​អ្នកផ្សេងទេ។ បុគ្គល​ដែលមាន​កូដ​ចូលប្រើ​របស់អ្នក​អាចត្រួត​ពិនិត្យ​ចរាចរណ៍អ៊ីនធឺណិត​ទាំងអស់​របស់អ្នក ប្រសិនបើ​គាត់មានសិទ្ធិ​ចូលប្រើកូដនេះ ដែល​ធ្វើឱ្យការប្រើប្រាស់​អ៊ីនធឺណិត​របស់អ្នក​លែងមាន​សុវត្ថិភាព ឬ​ឯកជន​ទៀតហើយ។
