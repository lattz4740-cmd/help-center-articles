---

អ្នក​អាចមើលឃើញ​សារបញ្ហា​នេះ៖ “សូម​អភ័យទោស Outline ហាក់​ដូចជា​មិនត្រូវ​បានដំឡើង​ត្រឹមត្រូវទេ។ សូម​សាកល្បង​ដំឡើង​វា​ម្ដង​ទៀត។ ប្រសិនបើ​ការធ្វើបែបនោះ​មិនមាន​ប្រសិទ្ធភាពទេ សូម[ដាក់បញ្ជូន​មតិកែលម្អ](https://support.getoutline.org/s/contactsupport?)។”

ប្រសិនបើអ្នកកំពុងប្រើ Outline នៅលើ Windows អ្នកអាចជួបបញ្ហាដែលមិនបានរំពឹងទុកម្ដងម្កាល។ ក្នុងករណីភាគច្រើន ចាំបាច់ត្រូវលុបអាដាប់ទ័រ TAP (ដ្រាយវើ) របស់ Outline ហើយ Outline គួរតែត្រូវបានដំឡើងឡើងវិញ។

ជំហាន​អាចប្រែប្រួល​ដោយ​ផ្អែកលើ​កំណែប្រព័ន្ធ​ប្រតិបត្តិការ Windows របស់អ្នក ប៉ុន្តែ​ខាងក្រោមនេះ​គឺជាជំហាន​ទូទៅ​ទាក់ទងនឹង​របៀបលុប​អាដាប់ទ័រ TAP និង Outline រួចហើយ​ដំឡើង Outline ឡើងវិញ។

1. លុប​អាដាប់ទ័រ TAP នៃ​កម្មវិធីភ្ញៀវ​សម្រាប់ Outline
   - ចូល​ទៅកាន់ **"កម្មវិធី​គ្រប់គ្រង​ឧបករណ៍"** បន្ទាប់មក **"អាដាប់ទ័រ​បណ្ដាញ"**
   - ស្វែងរក​ឯកសារ **TAP-Windows Adapter V9** ឬអាដាប់ទ័រ TAP ដែលភ្ជាប់​ជាមួយ Outline
   - លុបអាដាប់ទ័រនេះ។ សូម​ចងចាំថា ការធ្វើបែបនេះ​អាចប៉ះពាល់​ដល់កម្មវិធី VPN ផ្សេងទៀត​ដែលអ្នក​បានដំឡើង។
2. លុប​កម្មវិធីភ្ញៀវ​សម្រាប់ Outline
   - ចូល​ទៅកាន់ **"កម្មវិធី និង​មុខងារ"** បន្ទាប់មក **"លុប​កម្មវិធី"**
   - ស្វែងរក​កម្មវិធីភ្ញៀវ​សម្រាប់ Outline ហើយ​លុប​កម្មវិធីភ្ញៀវ​សម្រាប់ Outline
   - [ទាញយក​កំណែចុងក្រោយបំផុត​របស់​កម្មវិធីភ្ញៀវ​សម្រាប់ Outline](https://getoutline.org/get-started/#step-3) រួចដំឡើងវាឡើងវិញ​នៅលើ​ឧបករណ៍ Windows របស់អ្នក។ ការដំឡើងថ្មី​គួរតែ​ដំឡើង​អាដាប់ទ័រ TAP ថ្មី​ដោយស្វ័យប្រវត្តិ។

ប្រសិនបើអ្នក​នៅតែ​មានបញ្ហា​ទៀត សូម[ទាក់ទងទៅ​ផ្នែកជំនួយ](https://support.getoutline.org/s/contactsupport?)។
