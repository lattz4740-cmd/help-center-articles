title: اگر میری رسائی کلید کام نہیں کرتی ہے تو کیا ہوگا؟
sidebar_label: اگر میری رسائی کلید کام نہیں کرتی ہے تو کیا ہوگا؟
---

اگر آپ کو خرابی کا پیغام موصول ہوتا ہے: "ایسا لگتا ہے کہ آپ کی رسائی کی کلید درست نہیں ہے۔ اگر ایسا دوبارہ ہوتا ہے تو براہ کرم اپنے سروس مینیجر سے رابطہ کریں۔" تو مسئلہ حل کرنے کے لیے درج ذیل اقدامات کی پیروی کریں:

1. یقینی بنائیں کہ آپ رسائی کی مکمل کلید درج کر رہے ہیں، بشمول پہلے پانچ حروف ‎“ss://”‎، جو خودکار طور پر کلپ بورڈ پر کاپی نہیں ہو سکتے۔ رسائی کی ایک مکمل کلید کیسی نظر آتی ہے، یہ رہی اس کی ایک مثال (صرف نمونہ کے لیے؛ کام نہیں کرے گی):

```
ss://Y2hhY2hhMjAtaWV0Zi1wb2x5MTMwNTp1eXhUQ3MzemVEMTk=@145.230.4.1:39485/?outline=1
```

1. اگر آپ کی رسائی کلید آپ کے کلپ بورڈ پر بالکل بھی کاپی نہیں ہوگی تو ایسا آپ کی پیغام رسانی ایپ یا پلیٹ فارم کی وجہ سے ہو سکتا ہے۔ زیادہ تر ایسا تب ہوتا ہے جب آپ کو کسی ایسے شخص کی طرف سے پیغام موصول ہوتا ہے جو آپ کے رابطوں کی فہرست میں نہیں ہے۔ اگر آپ کسی پیغام سے کوڈ کاپی کر رہے ہیں تو یقینی بنائیں کہ ارسال کنندہ آپ کے رابطوں میں شامل ہے، پھر دوبارہ لنک تک رسائی کی کوشش کریں۔
2. اگر آپ کو مرحلہ 1 اور 2 مکمل کرنے کے بعد بھی خرابی کا پیغام موصول ہوتا ہے تو غالب امکان ہے کہ سرور مسدود ہو یا رسائی کلید اب مزید درست نہ ہو۔ اگر آپ سروس مینیجر ہیں تو اپنے لیے ایک نئی کلید تخلیق کرنے کی کوشش کریں۔ بصورت دیگر، نئی کلید کے لیے اپنے سروس مینیجر سے رابطہ کریں۔
