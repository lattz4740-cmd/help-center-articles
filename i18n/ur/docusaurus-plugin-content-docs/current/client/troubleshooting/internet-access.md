اگر آپ موبائل فون استعمال کر رہے ہیں تو موبائل ڈیٹا اور Wi-Fi کنکشنز کے درمیان سوئچ کرنے کی کوشش کریں۔ بعض اوقات ایک کنکشن کی قسم کام کرتی ہے جب دوسری نہیں کرتی ہے۔ اگر آپ کمپیوٹر استعمال کر رہے ہیں تو براڈبینڈ سے رابطہ غیر منسلک کرنے اور دوبارہ منسلک کرنے کی کوشش کریں۔

اگر آپ مسلسل مشکلات کا سامنا کر رہے ہیں تو امکان ہے کہ آپ کے Outline سرور میں کوئی مسئلہ ہو۔ متبادل سرور کے لیے نئی رسائی کلید کے لیے اپنے [سروس مینیجر](/about/terminology) سے رابطہ کریں۔ اگر کلید اپنے کوٹہ سے تجاوز کر گئی ہے تو وہ آپ کیhttps://google-jigsaw--jigsawuat.sandbox.my.site.com/outline/s/article/Terminology [رسائی کلید](/about/terminology) کے ڈیٹا کی حد کو بھی بڑھا سکتے ہیں۔
