‫Outline کو بہتر بنانے میں مدد کرنے کے لیے شکریہ! ہمارے پاس تاثرات بھیجنے کے چند طریقے ہیں، چاہے تو گمنام طور پر بھیج سکتے ہیں یا اگر آپ جواب چاہتے ہیں تو اپنی ای میل سے بھیج سکتے ہیں:

- **ڈویلپرز کے لیے**: Outline اوپن سورس سافٹ ویئر ہے اور ہم اپنے تمام کوڈ کی [GitHub](https://github.com/OutlineFoundation/?q=outline) پر میزبانی کرتے ہیں۔ آپ GitHub پر یا ہماری [Reddit](https://www.reddit.com/r/outlinevpn/) کمیونٹی پر اپنے آئیڈیاز کا اشتراک کر سکتے ہیں۔
- **صارفین کے لیے**: آپ ہمیں Outline یا Outline مینیجر ایپس کے ذریعے تاثرات بھیج سکتے ہیں۔ ہمیں بتائیں کہ آپ کے تاثرات کن چیزوں کے بارے میں ہیں اور، اختیاری طور پر، ایک ای میل بھیجیں تاکہ ہم اس کے بارے میں آپ کو جواب لکھ سکیں۔ ہم آپ کے ماحول کے بارے میں کچھ میٹا ڈیٹا بھی جمع کرتے ہیں، تاکہ ہم آپ کے براؤزر، آپریٹنگ سسٹم، اور آپ کون سا سافٹ ویئر ورژن استعمال کر رہے ہیں جیسے ٹربل شوٹنگ کے سلسلے میں آپ کی مدد کر سکیں۔
- **اس سائٹ کے ذریعے**: آپ "ہم سے رابطہ کریں" کے لنک پر کلک کر سکتے ہیں جہاں بھی آپ اسے اس سائٹ پر دیکھتے ہیں۔
- **سنگین مسائل**: اگر آپ کو سیکیورٹی کے ایک اہم مسئلے کی اطلاع دینے کی ضرورت ہے تو براہ کرم سیکیورٹی [at] [getoutline.org](https://getoutline.org/) پر تفصیلات کے ساتھ ہمیں ای میل کریں۔

ہمارے ساتھ اپنے خیالات کا اشتراک کرنے کی خاطر وقت نکالنے کے لیے آپ کا دوبارہ شکریہ۔
