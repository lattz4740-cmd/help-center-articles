## کیا میں سرور کے بغیر Outline کو استعمال کر سکتا ہوں؟
 بدقسمتی سے، نہیں۔ Outline سافٹ ویئر کو سرور تک رسائی کی ضرورت ہوتی ہے، چاہے یہ آپ، آپ کی تنظیم یا کسی معتبر فریق ثالث کے زیر انتظام ہو۔

## ‫Outline سرور کو ترتیب دینے میں کتنا وقت لگتا ہے؟

اکثر حالات میں، 5 منٹ سے کم۔ آپ Outline کو کسی بھی کلاؤڈ سرور پر انسٹال کر سکتے ہیں، لیکن ہم نے DigitalOcean کے ساتھ کام کر کے مزید صارف دوست، رہنمائی والا انسٹالیشن کا تجربہ پیش کیا ہے جہاں آپ چند کلکس میں اپنا سرور ترتیب دے سکتے ہیں، کسی اسکرپٹ کی ضرورت نہیں ہے۔

اگر آپ نے AWS، ‏GCP یا جدید ترین سیٹ اپ کو منتخب کیا ہے تو ہم نے ایسے واحد اسکرپٹ پر سرور کے انسٹالیشن کی کارروائی کو آسان بنا دیا ہے جو زیادہ تر ماحولوں کو ہینڈل کرتی ہے۔

## میں کہاں Outline سرور کو ترتیب دے سکتا ہوں؟

آپ Outline سرور کو زیادہ تر کلاؤڈ فراہم کنندگان پر ہر اس جگہ ترتیب دے سکتے ہیں جہاں وہ آپریٹ کرتے ہیں۔

سب سے آسان اختیار اسے DigitalOcean پر ترتیب دینا ہے، کیونکہ اس کے سرورز متعدد مقامات میں ہیں، جیسے ایمسٹرڈم، ٹورنٹو، سان فرانسسکو اور سنگاپور۔ اگر آپ کسی دوسرے کلاؤڈ فراہم کنندہ یا اپنے ذاتی انفراسٹرکچر پر انسٹال کرنے کو ترجیح دیتے ہیں تو آپ Outline مینیجر ایپلیکیشن میں ’جدید ترین موڈ‘ منتخب کر سکتے اور سیٹ اپ اسکرپٹ کو استعمال کر کے انسٹالیشن کی ہدایات پر عمل کر سکتے ہیں۔

## مجھے اپنا Outline سرور کہاں ترتیب دینا چاہیے؟

1. چند قابل غور باتیں ہیں جن کو اپنے Outline سرور کے لیے مقام کا انتخاب کرتے وقت آپ کو ملحوظ رکھنا چاہیے:
2. Outline سرور کے مقام سے صارفین کے انٹرنیٹ تجربہ کے طریقہ پر اثر پڑتا ہے۔ مثلاً، اگر سرور ایمسٹرڈم میں ہے تو اس سرور تک رسائی حاصل کرنے والے صارف کو انٹرنیٹ کا تجربہ ویسے ہی ہوگا جیسے اگر وہ لوگ جسمانی طور پر نیدرلینڈز میں موجود ہوتا ہے۔ کچھ ویب سائٹس ڈچ میں بھی دکھائی دے سکتی ہیں۔ عام طور پر، آپ ویب سائٹ پر زبان منتخب کنندہ کا استعمال کر کے مقامی زبان کو اوور رائیڈ کر سکتے ہیں۔
3. آپ کے صارفین اور Outline کے درمیان موجود مسافت سے آپ کی اسپیڈز پر اثر پڑ سکتا ہے۔ عام طور پر، Outline صارفین اور سرور کے درمیان فزیکل مسافت سے صارفین کی انٹرنیٹ اسپیڈز پر اثر پڑ سکتا ہے۔ زیادہ تر معاملات میں، آپ سرور کے قریب ترین مقام کا انتخاب کر سکتے ہیں جہاں آپ کے متوقع صارفین ہوں گے، لیکن آپ [سب میرین کیبل کا نقشہ](https://www.submarinecablemap.com/) چیک کر سکتے ہیں یہ دیکھنے کے لیے کہ کون سی انٹرنیٹ کیبل آپ کے ملک یا علاقے سے منسلک ہے۔
4. آپ کے VPN سرور کے مقام سے قانونی فریم ورک پر اثر پڑ سکتا ہے۔ براہ کرم نوٹ کریں کہ Outline سافٹ ویئر آپ کی ٹریفک کو لاگ نہیں کرتا ہے۔ [Outline استعمال کرتے وقت سیکیورٹی اور رازداری](/about/security-and-privacy) کے بارے میں مزید جانیں۔
