اضافی Outline سرورز کو ترتیب دینے کے لیے، اپنی Outline مینیجر ایپلیکیشن کے بائیں جانب نیویگیشن پینل پر ”+“ آئیکن پر کلک کریں۔ نیا سرور شامل کرنے کی ہدایات وہی ہیں جیسا کہ آپ نے پہلی بار سرور انسٹال کر رہے تھے۔

- ان Outline سرورز کی تعداد کی ہماری کوئی حد نہیں ہے جنہیں آپ بنا سکتے ہیں۔
- آپ کے بنائے ہوئے ہر Outline سرور کے لیے، آپ کو متعلقہ ورچوئل مشین کی ضرورت ہوگی۔
- اضافی مشینیں یا ڈراپلیٹس بنانے سے آپ کے کلاؤڈ فراہم کنندہ کے ساتھ آپ کی فیس میں اضافہ ہو سکتا ہے۔ براہ کرم اپنے کلاؤڈ فراہم کنندہ کے ساتھ اپنی قیمت بندی کے پیکیج کو چیک کر کے یقینی بنائیں کہ آپ کو معلوم ہے کہ کس چیز کی توقع کرنی ہے۔

## DigitalOcean پر اضافی Outline سرور بنانا

+ آئیکن پر کلک کرنے اور DigitalOcean پر انسٹال کرنے کا انتخاب کرنے کے بعد، آپ انہی ہدایات پر عمل کریں گے جن پر آپ نے اپنا پہلا سرور ترتیب دینے کے لیے عمل کیا تھا۔ نیز، چونکہ Outline مینیجر DigitalOcean کے ساتھ ضم ہو جاتا ہے، ہم کبھی بھی آپ کے Outline مینیجر ایپ کو چھوڑے بغیر آپ کے لیے ڈراپلیٹ بنا سکتے ہیں۔

نوٹ کریں کہ Outline مینیجر ایک وقت میں صرف ایک DigitalOcean اکاؤنٹ کو سپورٹ کر سکتی ہے۔ اگر دوسرے DigitalOcean اکاؤنٹس سے دوسرے Outline سرورز شامل کرنا یا بنانا چاہتے ہیں تو آپ انہیں جدید ترین کنفیگریشن کے بطور شامل کر سکتے ہیں۔

## GCP، ‏AWS یا کلاؤڈ کے کسی دوسرے سروس فراہم کنندہ پر اضافی Outline سرور بنانا

اپنے منتخب کردہ کلاؤڈ فراہم کنندہ کے ساتھ نئی ورچوئل مشین بنا کر شروعات کریں۔ پھر Outline مینیجر کو کھولیں اور جدید ترین انسٹالیشن کے لیے ہدایات کو مکمل کریں، بالکل ویسے ہی جیسے شاید آپ نے پہلی بار کیا تھا۔
