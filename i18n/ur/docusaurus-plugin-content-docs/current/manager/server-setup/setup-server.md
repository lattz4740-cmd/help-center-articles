‫Outline سرور کو ترتیب دینا Outline کو استعمال کرنے کا اہل ہونے کا پہلا مرحلہ ہے۔ چاہے آپ کو یا آپ کے معتبر کسی شخص کو آپ کے لیے سرور ترتیب دینا ہوتا ہے تاکہ آپ Outline کے ذریعے کھلے انٹرنیٹ سے منسلک ہو سکیں۔

## اس سے پہلے کہ آپ شروع کریں
اس سے پہلے کہ آپ اپنے Outline سرور کو ترتیب دینے کی شروعات کریں، آپ کو چند چیزوں کی ضرورت ہوگی:

1. آپ کے اپنے سرورز یا کلاؤڈ خدمات کے فراہم کنندہ، جیسے DigitalOcean, ‏Amazon ویب سروسز (AWS) یا Google Cloud Platform ‏(GCP) تک رسائی۔

    اگر آپ کو فوری طور پر کلاؤڈ سرور تک رسائی نہیں ہے تو بشمول مذکورہ بالا آپ کسی بھی فراہم کنندہ کے ساتھ اکاؤنٹ ترتیب دے سکتے ہیں۔ سائن اپ کرنے کے لیے آپ کو ممکنہ طور پر کریڈٹ کارڈ کی ضرورت پڑے گی۔
2. ایک ڈیسک ٹاپ کمپیوٹر جس پر macOS 10.9+‎، ‏Windows 7.0+‎ یا Linux چل رہا ہو۔
3. ‫Outline مینیجر ایپلیکیشن۔

## ‫DigitalOcean کی مدد سے سیٹ اپ کریں
ہم نے چند کلکس میں DigitalOcean پر Outline انسٹال کرنے کو ہر شخص کے لیے آسان بنا دیا ہے۔ اپنے کمپیوٹر پر Outline مینیجر کو ڈاؤن لوڈ اور انسٹال کرنے کے بعد، آپ DigitalOcean سیٹ اپ اختیار کو منتخب کر سکتے ہیں جو آپ کے Outline سرور کو کنفیگر اور انسٹال کرنے میں چند آسان اسکرینوں کے ذریعے آپ کی رہنمائی کرے گا۔

## دوسرے کلاؤڈ فراہم کنندہ کے ساتھ سیٹ اپ کریں
‫Outline مینیجر کو ڈاؤن لوڈ اور انسٹال کرنے کے بعد، آپ AWS, GCP, DigitalOcean یا کسی دوسرے فراہم کنندہ کے ساتھ ورچوئل مشین پر Outline سرور انسٹال کرنے کا انتخاب کر سکتے ہیں۔ ہر ماحول مختلف ہوتا ہے، اس لیے ہم نے سب سے زیادہ عام کلاؤڈ فراہم کنندگان کے لیے Outline مینیجر کے سیٹ اپ فلو کے اندر ہی ہدایات کو شامل کر دیا ہے، جن میں کسی سرور پر Outline کو انسٹال کرنے کے لیے انسٹالیشن اسکرپٹ کو چلانے سے پہلے آپ کی ورچوئل مشین پر ترتیبات کو کنفیگر کرنے کا طریقہ شامل ہے۔
