## مجموعی جائزہ

Outline مینیجر میں ایک خصوصیت شامل ہے جس سے آپ Google Cloud پر چلنے والے سرور پر Outline سرور کو خودکار طور پر کنفیگر کر سکتے ہیں۔ اگر آپ اس خصوصیت کو استعمال کرنے کا انتخاب کرتے ہیں تو Outline مینیجر آپ کو اپنے Google اکاؤنٹ کے ساتھ سائن ان کرنے کے لیے کہے گا، جو آپ کے Google Cloud اکاؤنٹ کو کنفیگر کرنے کے مقاصد کے لیے Outline مینیجر کی مقامی انسٹالیشن کو کچھ [OAuth](https://developers.google.com/identity/protocols/oauth2) کی اجازتیں دے گا۔

 اگر آپ ان اجازتوں کو فراہم نہیں کرنا چاہتے تو آپ Google Cloud Platform فارم پر Outline چلانے کے لیے Outline مینیجر میں جدید ترین سیٹ اپ کی ہدایات پر عمل کر سکتے ہیں۔

## اجازتیں عطا کی گئیں

خودکار سیٹ اپ فراہم کرنے کے لیے، Outline مینیجر کو آپ کے Google اکاؤنٹ سے درج ذیل اجازتوں کی ضرورت ہے۔

## Google Cloud Platform

- ‫Google Compute Engine کے آپ کے وسائل دیکھنے اور ان کا نظم کرنے کی اجازت
- Google کلاؤڈ سروسز پر آپ کا ڈیٹا ملاحظہ کرنے اور اپنے Google اکاؤنٹ کا ای میل پتہ دیکھنے کی اجازت

## اکاؤنٹ کی بنیادی معلومات

- آپ کے بنیادی Google اکاؤنٹ کا ای میل پتہ دیکھنے کی اجازت
- Google پر آپ کو آپ کی ذاتی معلومات سے وابستہ کرنے کی اجازت

## اضافی رسائی

- آپ کے Cloud Platform پروجیکٹس کا نظم کرنے کی اجازت
- آپ کے Google Cloud Platform کے بلنگ اکاؤنٹس کو دیکھنے اور ان کا نظم کرنے کی اجازت
- آپ کی Google API سروس کنفیگریشن کا نظم کرنے کی اجازت

یہ اجازتیں ہمیں آپ کے Outline سرورز کا نظم کرنے کے لیے اعلی درجے کی فعالیت کی حمایت کرنے کی اجازت دیتی ہیں جن میں درج ذیل شامل ہیں:

- آپ کو درست بلنگ اکاؤنٹ منتخب کرنے کی اجازت دینا
- آپ کے Outline سرورز کو منظم کرنے کے لیے ایک نیا پروجیکٹ بنانا
- دستیاب ڈیٹا سنٹرز کی فہرست بنانا
- Outline کو چلانے کے لیے نئی ورچوئل مشینیں تخلیق کرنا
- Outline کے ساتھ نئی ورچوئل مشین کو کنفیگر کرنا

## اجازتیں کالعدم کرنا

آپ [میرا اکاؤنٹ](https://myaccount.google.com/permissions) ملاحظہ کر کے Outline مینیجر کے لیے Google Cloud Platform تک رسائی کو کالعدم کر سکتے ہیں۔ اگر آپ رسائی کو کالعدم کرتے ہیں تو کوئی بھی سرور جو آپ نے خودکار سیٹ اپ کے ساتھ تخلیق کیا ہے وہ چلتا رہے گا لیکن مزید Outline مینیجر میں ظاہر نہیں ہوگا۔ ان تک رسائی کو بحال کرنے کے لیے ، خودکار سیٹ اپ فلو شروع کر کے صرف Google Cloud Platform فارم سے دوبارہ رابطہ کریں۔

## Outline پروجیکٹ آرگنائزیشن

Google Cloud خودکار سیٹ اپ آپ کے Outline سرورز کا نظم کرنے کے لیے واحد [Google Cloud پروجیکٹ](https://cloud.google.com/resource-manager/docs/creating-managing-projects) کا استعمال کرتا ہے۔ یہ پروجیکٹ خودکار سیٹ اپ کے پہلے استعمال کے دوران ایک تجویز کردہ پروجیکٹ ID کے ساتھ تخلیق کیا جاتا ہے جس کا آغاز "Outline" سے ہوتا بے جس کے بعد بے ترتیب حروف کی اسٹرنگ ہوتی ہے۔ اگر آپ چاہیں تو آپ تخلیق کے وقت ایک مختلف پروجیکٹ ID منتخب کر سکتے ہیں۔ اس پروجیکٹ کو "Outline سرورز" کا نام دیا جائے گا۔

## بلنگ اکاؤنٹ

‫Google Cloud پروجیکٹس کو ایک لنک کردہ "بلنگ اکاؤنٹ" درکار ہوتا ہے جو ادائیگی کی معلومات کی وضاحت کرتا ہے۔ جب آپ پہلی بار Google Cloud خودکار سیٹ اپ استعمال کرتے ہیں تو آپ سے کہا جائے گا کہ آپ اپنے Outline سرورز کے ساتھ وابستہ ہونے کے لیے ایک بلنگ اکاؤنٹ فراہم کریں۔ بعض اوقات سرور چلنا بند ہو جاتا ہے کیونکہ بلنگ اکاؤنٹ میں ایک مسئلہ ہے۔ اس صورت میں، آپ کو [Google Cloud Console](https://console.cloud.google.com/getting-started) میں لاگ ان ہونا چاہیے، Outline (جس کا نام "Outline سرورز" ہے) سے وابستہ Google Cloud پروجیکٹ کا پتہ لگائیں اور بلنگ کی ترتیبات کو اپ ڈیٹ کریں۔

## سرورز کو حذف کرنا

اگر آپ خودکار سیٹ اپ کا استعمال کرتے ہوئے تخلیق کئے گئے اپنے سرورز کو حذف کرنا چاہتے ہیں تو ایسا کرنے کا سب سے آسان طریقہ Outline مینیجر کے اندر سے ہے۔ تاہم، اگر آپ خود سرورز کو حذف کرنا چاہتے ہیں تو آپ [Google Cloud Console](https://console.cloud.google.com/getting-started) میں لاگ ان ہو سکتے ہیں، ابتدائی سیٹ اپ کے دوران تخلیق کیا گیا پروجیکٹ تلاش کر سکتے ہیں (جسے "Outline سرورز" کہا جاتا ہے) اور یا تو وہاں موجود وسائل کو حذف کر دیں یا پروجیکٹ کو بند کر دیں۔
