---

سرور ID ایک سرور سائیڈ ID ہے جو تصادفی طور پر اس وقت تیار ہوتی ہے جب آپ Outline سرور بناتے ہیں۔ یہ آپ کو ترتیبات کے انٹرفیس میں گمنام میٹرکس کے اشتراک میں آپٹ ان کرتے ہوئے مل سکتی ہے۔ آپ اپنی سرور ID یہاں سے تلاش کر سکتے ہیں: ترتیبات => نیچے تک سکرول کریں => "گمنام میٹرکس کا اشتراک کریں" کو چیک کریں۔

سرور ID ایک عرصۂ وقت میں رپورٹ کردہ گمنام استعمال کے اعداد وشمار کو آپس میں جوڑتا ہے۔ اگر آپ سرور ID کو دوبارہ ترتیب دینا اور ایک نئی حاصل کرنا چاہتے ہیں تو آپ کو اپنے Outline سرور کو ایک نئے سرور کے ساتھ تبدیل کرنے کی ضرورت ہوگی۔

اگر آپ DigitalOcean کو اپنے کلاؤڈ فراہم کنندہ کے طور پر استعمال کر رہے ہیں تو آپ ترتیبات میں جا کر اور سرور کو تلف کریں کو منتخب کر کے اپنے سرور کو ری سیٹ کرنا سکتے ہیں۔ یہ عمل ناقابل واپسی ہے اور آپ کی اسناد کو مٹا دے گا۔ اس کارروائی کے فوراً بعد، آپ کو اپنی پسند کے مقام پر ایک نیا سرور بنانے کے لیے پرامپٹ کیا جائے گا اور ایک نئی سرور ID تیار کی جائے گی۔
