---

زیادہ تر کلاؤڈ فراہم کنندگان کے لیے آپ جو مخصوص ورچوئل مشین استعمال کر رہے ہیں اسے ہٹانا کافی آسان ہے۔

اگر آپ DigitalOcean کو اپنے کلاؤڈ فراہم کنندہ کے طور پر استعمال کر رہے ہیں تو آپ گیئر بٹن پر کلک کر کے اور سرور کو تلف کریں کو منتخب کر کے اپنی موجودہ ورچوئل مشین کو حذف کر سکتے ہیں۔ اس کے فوراً بعد، آپ کو اپنی پسند کے مقام پر ایک نئی ورچوئل مشین بنانے کے لیے پرامپٹ کیا جائے گا۔

اگر آپ Outline سرور کو ہٹا دیتے ہیں تو یہ مستقل طور پر حذف ہو جائے گا اور اس کی رسائی والی کلیدیں مزید کام نہیں کریں گی۔ اگر آپ نہیں چاہتے ہیں کہ لوگوں کو Outline کے ذریعے ان کی رسائی میں رکاوٹ پیدا ہو تو آپ کو اپنا پرانا سرور حذف کرنے سے پہلے ایک [نیا Outline سرور سیٹ اپ](/manager/server-setup/setup-server) کرنا اور اس تک رسائی کا اشتراک کرنا ہوگا۔
