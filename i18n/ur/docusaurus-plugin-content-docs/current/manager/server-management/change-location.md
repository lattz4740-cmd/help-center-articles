---
title: میں Outline سرور کا مقام کیسے تبدیل کروں؟
sidebar_label: میں Outline سرور کا مقام کیسے تبدیل کروں؟
---

سیٹ اپ ہو جانے کے بعد، سرور کا مقام تبدیل نہیں کیا جا سکتا۔ اپنے سرور کو کسی مختلف مقام سے چلانے کے لیے، آپ کو اپنا Outline سرور حذف کر کے ایک نیا سرور بنانا ہوگا۔

متبادل طور پر، آپ [ڈائنیمک کیز](https://developers.google.com/outline/docs/guides/service-providers/dynamic-access-keys) کا استعمال کرتے ہوئے اپنے VPN کا مقام تبدیل کر سکتے ہیں، جو آپ کو سرورز کو گھمانے اور وہی کیز برقرار رکھنے کی اجازت دیتی ہیں۔ سرورز کا مقام خود تبدیل نہیں ہوگا۔
