sidebar_label: میں اپنا Outline سرور سافٹ ویئر کیسے اپ ڈیٹ کروں؟

‫Outline سرورز تازہ ترین سیکیورٹی کی اصلاحات کے ساتھ خودکار طور پر اپ ڈیٹ ہو جاتے ہیں تاکہ آپ ہمیشہ تازہ ترین Outline ٹیکنالوجی استعمال کریں۔ خودکار اپ ڈیٹ کا عمل [Watchtower](https://github.com/v2tec/watchtower)، ایک اوپن سورس لائبریری کے ذریعے فعال کیا گیا ہے جو Outline سافٹ ویئر پر مشتمل ڈاکر تصویر کو باقاعدگی سے چیک اور اپ ڈیٹ کرتی ہے۔

مزید برآں، جب آپ Outline مینیجر کا استعمال کرتے ہوئے Outline کو انسٹال کرتے ہیں تو ہم [غیر حاضر اپ گریڈز](https://wiki.debian.org/UnattendedUpgrades) (Ubuntu) کا استعمال کرتے ہوئے سرور پر سافٹ ویئر کو خودکار طور پر اپ گریڈ کرنے کے لیے ایک کرون جاب ترتیب دیں گے اور ضرورت پڑنے پر اسے دوبارہ بوٹ کریں گے۔ نوٹ کریں کہ یہ موجودہ کنفیگریشن کو محفوظ رکھنے کے لیے ایڈوانسڈ موڈ میں نہیں ہوتا ہے، اس مفروضے کے تحت کہ ہوسٹ کو Outline چلانے کے علاوہ دیگر مقاصد کے لیے بھی استعمال کیا جا رہا ہے۔
