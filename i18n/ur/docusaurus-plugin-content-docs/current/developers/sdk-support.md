sidebar_label: ميں ايک ڈویلپر ہوں مجھے اپنی درخواست میں Outline SDK کو ضم کرنے کے لیے سپورٹ کہاں سے مل سکتا ہے؟
---

یہ سپورٹ ویب سائٹ Outline مینیجر اور کلائنٹ صارفین کے لیے ہے۔ ڈویلپرز، براہ کرم مدد کے لیے GitHub استعمال کریں۔ کوئی سوال پوچھنے کے لیے، براہ کرم SDK [مباحثہ بورڈ](https://github.com/Jigsaw-Code/outline-sdk/discussions) پر پوسٹ کریں۔ مباحثہ بورڈ سیکشن سوال پوچھنے، آئیڈیاز کا اشتراک کرنے، ڈیموز سے لنک کرنے اور Outline SDK کا استعمال کرتے ہوئے دوسرے ڈویلپرز کی مدد کرنے کے لیے ایک بہترین جگہ ہے۔ خصوصیت کی درخواستوں یا بگ رپورٹس کے لیے، براہ کرم اس کی بجائے ایک [شمارہ](https://github.com/Jigsaw-Code/outline-sdk/issues/new) کھولیں۔
