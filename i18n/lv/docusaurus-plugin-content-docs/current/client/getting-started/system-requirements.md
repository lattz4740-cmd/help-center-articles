Varat izmēģināt programmatūru Outline jebkurā operētājsistēmā. Tālāk ir norādītas minimālās prasības dažādām operētājsistēmām.

| **Operētājsistēma** | **Minimālā versija** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |
