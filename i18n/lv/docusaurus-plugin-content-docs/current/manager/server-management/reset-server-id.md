---
title: "Kā atiestatīt savu servera ID?"
sidebar_label: "Kā atiestatīt savu servera ID?"
---

Servera ID ir no servera puses nejauši ģenerēts ID, kas tiek izveidots reizē ar Outline servera izveidi. Varat to atrast iestatījumu saskarnē, izvēloties anonīmu rādītāju kopīgošanu. Lai atrastu savu servera ID, atveriet sadaļu Iestatījumi => ritiniet līdz apakšdaļai => skatiet sadaļu “Anonīmu rādītāju kopīgošana”.

Servera ID tiek izmantots, lai apkopotu anonīmu lietojuma statistiku, par kuru laika gaitā ir ziņots. Ja vēlaties atiestatīt servera ID un iegūt jaunu ID, esošais Outline serveris ir jāaizstāj ar jaunu serveri.

Ja izmantojat mākoņpakalpojumu sniedzēju DigitalOcean, varat atiestatīt serveri, atverot sadaļu Iestatījumi un atlasot opciju Iznīcināt serveri. Šo darbību nevar atsaukt, un ar to tiks izdzēsti jūs akreditācijas dati. Tūlīt pēc šīs darbības paveikšanas saņemsiet uzvedni ar aicinājumu izveidot jaunu serveri brīvi izvēlētā atrašanās vietā, un pēc tam tiks ģenerēts jauns servera ID.
