---
title: "Kā izdzēst Outline serveri?"
sidebar_label: "Kā izdzēst Outline serveri?"
---

Lielākā daļa mākoņpakalpojumu sniedzēju nodrošina samērā vienkāršu iespēju noņemt konkrētu virtuālo mašīnu, ko izmantojat.

Ja izmantojat DigitalOcean mākoņpakalpojumus, esošo virtuālo mašīnu varat izdzēst, noklikšķinot uz zobrata pogas un atlasot vienumu Iznīcināt serveri. Tūlīt pēc šīs darbības paveikšanas saņemsiet uzvedni ar aicinājumu izveidot virtuālo mašīnu brīvi izvēlētā atrašanās vietā.

Ja noņemsiet Outline serveri, tas tiks neatgriezeniski dzēsts, un tā piekļuves atslēgas vairs nedarbosies. Ja nevēlaties, lai tiktu pārtraukta lietotāju piekļuve Outline serverim, jums [jāiestata jauns Outline serveris](/manager/server-setup/setup-server) un jākopīgo piekļuve tam, pirms izdzēšat iepriekšējo serveri.
