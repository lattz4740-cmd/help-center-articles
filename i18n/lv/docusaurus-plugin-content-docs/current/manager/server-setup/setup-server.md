---
title: "Kā iestatīt Outline serveri?"
sidebar_label: "Kā iestatīt Outline serveri?"
---

Outline servera iestatīšana ir pirmā darbība, kas jāveic, lai varētu izmantot Outline programmatūru. Jums vai personai, kurai uzticaties, ir jāiestata serveris, lai varētu izveidot savienojumu ar atvērto internetu, izmantojot Outline.

## Pirms darba sākšanas
 Pirms Outline servera iestatīšanas nepieciešams nodrošināt tālāk minētās lietas.

1. Piekļuve saviem serveriem vai mākoņpakalpojumu sniedzējam, piemēram, DigitalOcean, Amazon Web Services (AWS) vai Google Cloud Platform (GCP).

 Ja jums nav tūlītējas piekļuves mākoņserverim, varat izveidot kontu jebkura pakalpojumu sniedzēja, tostarp iepriekš uzskaitīto, platformā. Lai reģistrētos, jums, iespējams, būs nepieciešama kredītkarte.
2. Galddators, kurā darbojas operētājsistēma macOS 10.9+, Windows 7.0+ vai Linux.
3. Lietojumprogramma Outline pārvaldnieks.

## Iestatīšana, izmantojot DigitalOcean
 Outline instalēšanu mākoņpakalpojumu sniedzēja DigitalOcean platformā var veikt ar dažu klikšķu palīdzību. Pēc lietotnes Outline pārvaldnieks lejupielādes un instalēšanas datorā varat atlasīt DigitalOcean iestatīšanas opciju, kurā tiks sniegti vienkārši norādījumi Outline servera konfigurēšanai un instalēšanai.

## Iestatīšana, izmantojot citu mākoņpakalpojumu sniedzēju
 Pēc lietotnes Outline pārvaldnieks lejupielādes un instalēšanas datorā varat atlasīt Outline servera instalēšanas opciju virtuālajā mašīnā ar AWS, GCP, DigitalOcean vai citu pakalpojumu sniedzēju. Katra vide ir atšķirīga, tāpēc esam iekļāvuši norādījumus lietotnes Outline pārvaldnieks iestatīšanas plūsmā visbiežāk lietotajiem mākoņpakalpojumu sniedzējiem, tostarp norādījumus iestatījumu konfigurēšanai virtuālajā mašīnā pirms instalēšanas skripta palaišanas, lai instalētu Outline serverī.
