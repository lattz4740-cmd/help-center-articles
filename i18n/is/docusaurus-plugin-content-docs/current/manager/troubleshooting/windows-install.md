title: "Hvers vegna get ég ekki sett Outline Manager upp í Windows?"
sidebar_label: "Hvers vegna get ég ekki sett Outline Manager upp í Windows?"
---

Þú gætir séð þessi villuboð: „Því miður lítur út fyrir að Outline sé ekki sett rétt upp. Prófaðu að setja það upp aftur. Ef það virkar ekki skaltu [senda inn ábendingu](/about/feedback).“

Ef þú notar Outline í Windows gæti óvænt villa komið upp við og við. Í flestum tilfellum þarf að eyða TAP-tengi (rekli) Outline og setja Outline svo upp aftur.

Skrefin kunna að vera mismunandi eftir stýrikerfisútgáfu Windows en hér fyrir neðan eru almennar leiðbeiningar um að fjarlægja TAP-tengið og Outline Manager og setja svo Outline Manager upp aftur.

1. Fjarlægja TAP-tengi fyrir Outline Manager
   1. Opnaðu „Tækjastjórnun“ og síðan „Nettengi“
   2. Finndu skrána „TAP-Windows Adapter V9“ eða TAP-tengið sem tengist Outline
   3. Fjarlægðu tengið eða eyddu því. Hafðu í huga að þetta gæti haft áhrif á önnur VPN-forrit sem þú hefur sett upp.
2. Að fjarlægja Outline Manager
   1. Farðu í „Forrit og eiginleikar“ og síðan „Fjarlægja forrit“
   2. Finndu Outline Manager-forritið og fjarlægðu það
   3. [Sæktu nýjustu útgáfu af Outline Manager](https://getoutline.org/get-started/#step-1) og settu forritið aftur upp í Windows-tækinu. Nýja uppsetningin ætti að setja upp nýtt TAP-tengi sjálfkrafa.

Ef þú ert enn í vandræðum skaltu [hafa samband við þjónustudeildina](/about/feedback).
