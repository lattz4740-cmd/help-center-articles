---
title: "Hverjar eru kerfiskröfurnar til að keyra Outline Client?"
sidebar_label: "Hverjar eru kerfiskröfurnar til að keyra Outline Client?"
---

Þú getur prófað Outline í hvaða stýrikerfi sem er. Eftirfarandi eru lágmarkskröfur fyrir stýrikerfi:

| **Stýrikerfi** | **Lágmarksútgáfa** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Viltu hjálpa okkur að fá Outline Client til að virka í fleiri stýrikerfum? [Leggðu þitt af mörkum til kóðagrunnsins](https://github.com/Outline-Foundation/outline-client#platform-specific-development) á GitHub!
