---

Þetta stuðningsvefsvæði er fyrir notendur Outline Manager og Client. Forritarar ættu að nota GitHub til að fá aðstoð. Til að spyrja spurningar skaltu birta færslu á [Umræðuborði](https://github.com/Jigsaw-Code/outline-sdk/discussions) forritunarverkfæra. Umræðuborðið er frábær staður til að spyrja spurninga, deila hugmyndum, tengja á prufuútgáfur og styðja aðra forritara sem nota forritunarverkfæri Outline. Fyrir beiðnir um eiginleika eða villutilkynningar skaltu opna [Vandamál](https://github.com/Jigsaw-Code/outline-sdk/issues/new) í staðinn.
