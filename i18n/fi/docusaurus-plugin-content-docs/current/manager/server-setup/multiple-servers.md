---

Voit ottaa käyttöön lisää Outline-palvelimia klikkaamalla +-kuvaketta Outline Manager ‑sovelluksen vasemmassa reunassa olevasta navigaatiopaneelista. Uuden palvelimen lisäämiseen sovelletaan samoja ohjeita kuin ensimmäisenkin palvelimen asentamiseen.

- Emme rajoita luomiesi Outline-palvelimien määrää.
- Tarvitset jokaista Outline-palvelinta kohden vastaavan virtuaalisen koneen.
- Lisäkoneiden luominen voi nostaa pilvipalveluntarjoajan veloittamaa hintaa. Tarkista pilvipalvelupakettisi hinnat, jotta osaat varautua.

## Toisen Outline-palvelimen luominen DigitalOceanin avulla

Kun olet klikannut +-kuvaketta ja valinnut asennustavaksi DigitalOceanin, voit seurata samoja ohjeita kuin ensimmäistä palvelinta määrittäessäsi. Outline Managerin DigitalOcean-integroinnin ansiosta voimme luoda sinulle lisäkoneen ilman, että sinun tarvitsee kertaakaan poistua Outline Manager ‑sovelluksesta.

Huomaa, että Outline Manager tukee vain yhtä DigitalOcean-tiliä kerrallaan. Jos haluat lisätä tai luoda Outline-palvelimia muilta DigitalOcean-tileiltä, voit lisätä ne edistyneenä määrityksenä.

## Toisen Outline-palvelimen luominen GCP:llä, AWS:llä tai muulla pilvipalvelulla

Aloita luomalla uusi virtuaalikone valitsemassasi pilvipalvelussa. Avaa sitten Outline Manager ja seuraa edistyneen asennuksen ohjeita, kuten ehkä teit ensimmäiselläkin kerralla.
