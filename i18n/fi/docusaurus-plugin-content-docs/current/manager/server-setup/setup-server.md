Outlinen käyttö alkaa Outline-palvelimen käyttöönotolla. Sinun tai jonkun luotettavan käyttäjän on otettava palvelin käyttöön, jotta voit muodostaa yhteyden avoimeen internetiin Outlinen kautta.

## Ennen aloittamista
 Ennen kuin aloitat Outline-palvelimen käyttöönoton, tarvitset

1. pääsyn omille palvelimillesi tai pilvipalveluntarjoajaan, kuten DigitalOceaniin, Amazon Web Servicesiin (AWS) tai Google Cloud Platformiin (GCP)

 (jos sinulla ei ole pääsyä pilvipalvelimelle, voit helposti luoda tilin haluamaasi pilvipalveluun, esimerkiksi johonkin edellä mainituista – rekisteröityminen edellyttää todennäköisesti credit-korttia)
2. tietokoneen, jonka käyttöjärjestelmä on macOS 10.9 tai uudempi, Windows 7.0 tai uudempi tai Linux
3. Outline Manager ‑sovelluksen.

## Käyttöönotto DigitalOceanilla
 Voit asentaa Outlinen DigitalOceaniin muutamalla klikkauksella. Kun olet ladannut ja asentanut Outline Managerin tietokoneellesi, voit valita DigitalOcean-asennusvaihtoehdon. Näkyviin tulee muutama yksinkertainen näyttö, joiden avulla voit ottaa käyttöön ja asentaa Outline-palvelimen.

## Käyttöönotto toisella pilvipalveluntarjoajalla
 Kun olet ladannut ja asentanut Outline Managerin, voit asentaa Outline-palvelimen esimerkiksi AWS:ää, GCP:tä tai DigitalOceania tukevalle virtuaalikoneelle. Ympäristöt poikkeavat toisistaan, minkä vuoksi Outline Managerin käyttöönotto sisältää yleisimpiä pilvipalveluntarjoajia koskevat ohjeet. Ne auttavat sinua mm. valitsemaan virtuaalikoneen asetukset ennen kuin asennat Outlinen palvelimelle asennusskriptillä.
