---
title: "Miten poistan Outline-palvelimen?"
sidebar_label: "Miten poistan Outline-palvelimen?"
---

Useimpien pilvipalveluntarjoajien tapauksessa käytössä olevan virtuaalikoneen voi poistaa helposti.

Jos pilvipalveluntarjoaja on DigitalOcean, voit poistaa käytössäsi olevan virtuaalikoneen klikkaamalla rataspainiketta ja valitsemalla "Tuhoa palvelin". Näet heti tämän jälkeen kehotteen, jonka kautta voit luoda uuden virtuaalikoneen valitsemaasi sijaintiin.

Jos poistat Outline-palvelimen, se poistetaan pysyvästi eivätkä sen pääsyavaimet enää toimi. Jos et halua, että muiden käyttäjien yhteys Outlinen kautta keskeytyy, [ota käyttöön uusi Outline-palvelin](/manager/server-setup/setup-server) ja jaa sen pääsyoikeudet käyttäjille ennen vanhan palvelimen poistamista.
