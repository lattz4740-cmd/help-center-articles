---
title: "Miten nollaan palvelimen tunnuksen?"
sidebar_label: "Miten nollaan palvelimen tunnuksen?"
---

Palvelimen tunnus on satunnainen merkkijono, joka luodaan Outline-palvelimen luonnin yhteydessä. Saat palvelimen tunnuksen, kun hyväksyt anonyymien tietojen jakamisen Asetukset-kohdasta. Löydät palvelimen tunnuksen valitsemalla "Asetukset" ja vierittämällä sivun loppuun. Tunnus on kohdassa "Jaa anonyymeja mittaritietoja".

Ajan mittaan kerätyt anonyymit tilastolliset käyttötilastot voidaan koota käyttämällä palvelimen tunnusta. Jos haluat luoda uuden tunnuksen palvelimelle, sinun on vaihdettava käytössäsi oleva Outline-palvelin uuteen palvelimeen.

Jos pilvipalveluntarjoaja on DigitalOcean, voit nollata palvelimen valitsemalla "Asetukset" ja "Tuhoa palvelin". Tätä toimintoa ei voi kumota, ja kirjautumistietosi poistetaan samalla. Näet heti tämän jälkeen kehotteen, jonka kautta voit luoda uuden palvelimen valitsemaasi sijaintiin. Palvelimelle luodaan samalla uusi tunnus.
