---
title: "Mitkä ovat Outline-asiakassovelluksen järjestelmävaatimukset?"
sidebar_label: "Mitkä ovat Outline-asiakassovelluksen järjestelmävaatimukset?"
---

Outlinen käyttöä voi kokeilla millä tahansa käyttöjärjestelmällä. Käyttöjärjestelmän vähimmäisvaatimukset:

| **Käyttöjärjestelmä** | **Vähimmäisversio** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Haluatko, että Outline-asiakassovellus olisi käytettävissä useammilla käyttöjärjestelmillä? [Lisää sisältöä koodikantaan](https://github.com/Jigsaw-Code/outline-client#platform-specific-development) GitHubissa.
