---
title: "Jakie są wymagania systemowe pozwalające na uruchomienie klienta Outline?"
sidebar_label: "Jakie są wymagania systemowe pozwalające na uruchomienie klienta Outline?"
---

Możesz spróbować uruchomić Outline w dowolnym systemie operacyjnym. Oto lista minimalnych wymaganych systemów operacyjnych:

| **System operacyjny** | **Wersja minimalna** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Chcesz mieć swój udział w tym, aby klient Outline działał w innych systemach operacyjnych? [Opublikuj coś w naszej bazie kodu](https://github.com/Jigsaw-Code/outline-client#platform-specific-development) na GitHubie!
