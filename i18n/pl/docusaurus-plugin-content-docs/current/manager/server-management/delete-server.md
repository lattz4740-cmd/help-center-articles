---
title: "Jak usunąć serwer Outline?"
sidebar_label: "Jak usunąć serwer Outline?"
---

Większość platform usług chmurowych umożliwia łatwe usuwanie poszczególnych maszyn wirtualnych.

Jeśli Twoim dostawcą chmury jest DigitalOcean, możesz usunąć obecnie używaną maszynę wirtualną, klikając ikonę koła zębatego i wybierając **Zlikwiduj serwer**. Od razu pojawi się monit dotyczący utworzenia nowej maszyny wirtualnej w wybranej przez Ciebie lokalizacji.

Serwery Outline są usuwane trwale. Po usunięciu serwera klucze dostępu przestają działać. Jeśli nie chcesz narażać użytkowników na przerwy w dostępie do Outline, musisz przed usunięciem serwera [skonfigurować nowy serwer Outline](https://support.google.com/outline/answer/15331530?sjid=5147938692963654551-NC) i go udostępnić.
