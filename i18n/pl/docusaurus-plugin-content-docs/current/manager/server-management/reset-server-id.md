---
title: "Jak zresetować identyfikator serwera?"
sidebar_label: "Jak zresetować identyfikator serwera?"
---

Identyfikator serwera jest generowany losowo po stronie serwera po utworzeniu serwera Outline. Można go znaleźć, włączając udostępnianie anonimowych danych w interfejsie ustawień. Aby zlokalizować identyfikator serwera, otwórz Ustawienia => przewiń w dół => zaznacz „Udostępniaj anonimowe dane”.

Identyfikator serwera służy do łączenia anonimowych statystyk użytkowania zgromadzonych w danym okresie. Aby go zresetować i uzyskać kolejny identyfikator, musisz zastąpić dotychczasowy serwer Outline nowym.
