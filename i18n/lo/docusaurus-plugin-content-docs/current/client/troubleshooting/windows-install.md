sidebar_label: "ເປັນຫຍັງຂ້ອຍຈຶ່ງບໍ່ສາມາດຕິດຕັ້ງລູກຂ່າຍ Outline ໃນ Windows ໄດ້?"
---

ທ່ານອາດເຫັນຂໍ້ຄວາມສະແດງຂໍ້ຜິດພາດນີ້: “ຂໍອະໄພ, ເບິ່ງຄືວ່າ Outline ບໍ່ໄດ້ຮັບການຕິດຕັ້ງຢ່າງຖືກຕ້ອງ. ກະລຸນາລອງຕິດຕັ້ງອີກຄັ້ງ. ຫາກບໍ່ໄດ້ຜົນ, ກະລຸນາ [ສົ່ງຄຳຕິຊົມ](/about/feedback)”.

ຫາກທ່ານໃຊ້ Outline ໃນ Windows, ບາງຄັ້ງທ່ານອາດພົບຂໍ້ຜິດພາດທີ່ບໍ່ຄາດຄິດ. ໃນກໍລະນີສ່ວນໃຫຍ່, ທ່ານຈະຕ້ອງລຶບອະແດັບເຕີ (ໄດຣເວີ) Outline TAP ແລະ ຄວນຕິດຕັ້ງ Outline ຄືນໃໝ່.

ຂັ້ນຕອນອາດແຕກຕ່າງກັນໄປຕາມເວີຊັນຂອງລະບົບປະຕິບັດການ Windows ຂອງທ່ານ, ແຕ່ທາງລຸ່ມນີ້ແມ່ນຂັ້ນຕອນທົ່ວໄປສຳລັບວິທີຖອນການຕິດຕັ້ງອະແດັບເຕີ TAP ແລະ Outline, ຈາກນັ້ນຈຶ່ງຕິດຕັ້ງ Outline ຄືນໃໝ່.

1. ຖອນການຕິດຕັ້ງອະແດັບເຕີ TAP ສຳລັບລູກຂ່າຍ Outline
   - ເຂົ້າໄປ **ຕົວຈັດການອຸປະກອນ**, ຈາກນັ້ນເຂົ້າໄປ **ອະແດັບເຕີເຄືອຂ່າຍ**
   - ຊອກຫາໄຟລ໌ **TAP-Windows Adapter V9** ຫຼື ອະແດັບເຕີ TAP ທີ່ເຊື່ອມໂຍງກັບ Outline
   - ຖອນການຕິດຕັ້ງ ຫຼື ລຶບອະແດັບເຕີນີ້. ກະລຸນາຮັບຊາບວ່າການດຳເນີນການນີ້ອາດສົ່ງຜົນຕໍ່ແອັບ VPN ອື່ນໆທີ່ທ່ານຕິດຕັ້ງໄວ້.
2. ຖອນການຕິດຕັ້ງລູກຂ່າຍ Outline
   - ເຂົ້າໄປ **ໂປຣແກຣມ ແລະ ຄຸນສົມບັດ**, ຈາກນັ້ນເຂົ້າໄປ **ຖອນການຕິດຕັ້ງໂປຣແກຣມ**
   - ຊອກຫາແອັບລູກຂ່າຍ Outline ແລະ ຖອນການຕິດຕັ້ງແອັບດັ່ງກ່າວ
   - [ດາວໂຫຼດລູກຂ່າຍ Outline ເວີຊັນຫຼ້າສຸດ](https://getoutline.org/get-started/#step-3) ແລ້ວຕິດຕັ້ງຄືນໃໝ່ໃນອຸປະກອນ Windows ຂອງທ່ານ. ເຊິ່ງການຕິດຕັ້ງດັ່ງກ່າວຈະເຮັດໃຫ້ລະບົບຕິດຕັ້ງອະແດັບເຕີ TAP ໃໝ່ໂດຍອັດຕະໂນມັດ.

ຫາກທ່ານຍັງປະສົບບັນຫາຢູ່, ກະລຸນາ [ຕິດຕໍ່ທີມງານຊ່ວຍເຫຼືອ](/about/feedback).
