ບັນຫາຂອງ firewall ທີ່ທ່ານອາດພົບມີ 3 ຢ່າງດັ່ງນີ້:

## ທ່ານອາດຖືກບລັອກໂດຍ firewall ຂອງເຄືອຂ່າຍ.

ຫາກທ່ານກຳລັງພະຍາຍາມຕິດຕັ້ງ Outline ໃນລະຫວ່າງທີ່ເຊື່ອມຕໍ່ກັບເຄືອຂ່າຍທີ່ມີ firewall ເຊັ່ນ: ຢູ່ໂຮງຮຽນ ຫຼື ໃນບ່ອນເຮັດວຽກຂອງທ່ານ, ໃຫ້ລອງຕິດຕັ້ງໂດຍໃຊ້ເຄືອຂ່າຍອື່ນ.

ຫາກບໍ່ໄດ້ຜົນ, ກະລຸນາຕິດຕໍ່ຜູ້ເບິ່ງແຍງລະບົບເຄືອຂ່າຍຂອງທ່ານເພື່ອອະນຸຍາດການເຊື່ອມຕໍ່ລະຫວ່າງເຄືອຂ່າຍທີ່ມີ firewall ກັບເຊີບເວີ Outline ຂອງທ່ານ. ທ່ານຈະຕ້ອງຮູ້ທີ່ຢູ່ IP ຂອງເຊີບເວີ Outline ຂອງທ່ານ ແລະ ຜອດທີ່ Outline ນຳໃຊ້, ເຊິ່ງມີການລະບຸໄວ້ຢູ່ໃນຕອນທ້າຍຂອງສະຄຣິບການຕິດຕັ້ງ.

**ທ່ານອາດຖືກບລັອກໂດຍ firewall ຂອງອຸປະກອນ**.

ຫາກທ່ານມີຊອບແວຢູ່ອຸປະກອນທີ່ບລັອກການເຊື່ອມຕໍ່ຂາອອກໃນຜອດທີ່ບໍ່ແມ່ນແບບມາດຕະຖານ ຫຼື ຊອບແວທີ່ບໍ່ຮູ້ຈັກ, (ZoneAlarm ຂອງ CheckPoint), ກະລຸນາອ່ານຄູ່ມືຂອງອຸປະກອນ ຫຼື ຊອບແວຂອງທ່ານເພື່ອສຶກສາວິທີສ້າງຂໍ້ຍົກເວັ້ນສຳລັບ Outline.

## ທ່ານອາດຖືກບລັອກໂດຍ firewall ຂອງເຊີບເວີ.

ຜູ້ໃຫ້ບໍລິການຄລາວທີ່ທ່ານເລືອກອາດກຳນົດໃຫ້ທ່ານຕ້ອງສ້າງຂໍ້ຍົກເວັ້ນໃນ firewall ຂອງເຊີບເວີຂອງທ່ານດ້ວຍຕົນເອງ, ເພື່ອເປີດຜອດທີ່ Outline ນຳໃຊ້ຢູ່. ຫຼັງຈາກທີ່ທ່ານແລ່ນສະຄຣິບການຕິດຕັ້ງ, ທ່ານຄວນຖືກນໍາສະເໜີດ້ວຍສອງຜອດທີ່ເລືອກແບບສຸ່ມທີ່ Outline ກຳລັງແລ່ນຢູ່ໃນເຊີບເວີຂອງທ່ານ. ການເປີດທັງສອງຜອດນີ້ຄວນຈະພຽງພໍແລ້ວ.

 ເພື່ອສ້າງຂໍ້ຍົກເວັ້ນໃນ firewall ຂອງເຊີບເວີຂອງທ່ານ, ພວກເຮົາຂໍແນະນຳໃຫ້ທ່ານອ່ານເອກະສານສຳລັບ 'ufw' ແລະ 'iptables' ດັ່ງນີ້:

- UFW: [https://help.ubuntu.com/community/UFW](https://help.ubuntu.com/community/UFW)
- Iptables: [https://help.ubuntu.com/community/IptablesHowTo](https://help.ubuntu.com/community/IptablesHowTo)
