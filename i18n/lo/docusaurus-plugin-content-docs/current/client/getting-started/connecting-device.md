sidebar_label: ການເຊື່ອມຕໍ່ອຸປະກອນຂອງທ່ານກັບເຊີບເວີ Outline
---

ເພື່ອເຊື່ອມຕໍ່ອຸປະກອນຂອງທ່ານກັບເຊີບເວີ Outline, ຜູ້ເບິ່ງແຍງລະບົບເຊີບເວີຕ້ອງສົ່ງຄຳເຊີນໃຫ້ທ່ານເພື່ອເຊື່ອມຕໍ່ກັບເຊີບເວີຂອງເຂົາເຈົ້າດ້ວຍ [ກະແຈການເຂົ້າເຖິງ](/about/terminology) ທີ່ບໍ່ຊ້ຳກັນ. ຄຳເຊີນນີ້ຈະດຳເນີນການດັ່ງນີ້:

- ແຈ້ງໃຫ້ທ່ານດາວໂຫຼດ ແລະ ຕິດຕັ້ງ Outline ໃນອຸປະກອນຂອງທ່ານຫາກທ່ານຍັງບໍ່ມີການຕິດຕັ້ງ
- ໃຊ້ກະແຈການເຂົ້າເຖິງເພື່ອເຮັດໃຫ້ການເຊື່ອມຕໍ່ລະຫວ່າງທ່ານກັບເຊີບເວີ Outline ມີຄວາມປອດໄພ

ເມື່ອທ່ານສ້າງການເຊື່ອມຕໍ່ຂອງທ່ານກັບເຊີບເວີແລ້ວ, ທ່ານສາມາດຄລິກ "ເຊື່ອມຕໍ່" ຫຼື "ຍົກເລີກການເຊື່ອມຕໍ່" ເພື່ອໃຊ້ Outline.

*ສຳຄັນ:* Outline ຈະບໍ່ເຮັດວຽກຫາກບໍ່ມີກະແຈການເຂົ້າເຖິງ ແລະ ເຊີບເວີ Outline. ການດາວໂຫຼດ ແລະ ຕິດຕັ້ງແອັບ Outline ໂດຍບໍ່ມີກະແຈຈະເຮັດໃຫ້ທຣາບຟິກອິນເຕີເນັດຂອງທ່ານບໍ່ໄດ້ຮັບການປົກປ້ອງ.
