ທ່ານສາມາດທົດລອງໃຊ້ Outline ໃນລະບົບປະຕິບັດການໃດກໍໄດ້. ລະບົບປະຕິບັດການຂັ້ນຕ່ຳທີ່ກຳນົດມີດັ່ງນີ້:

| **ລະບົບປະຕິບັດການ** | **ເວີຊັນຂັ້ນຕ່ຳ** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |
