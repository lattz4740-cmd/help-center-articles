sidebar_label: "ຂ້ອຍສາມາດໃຊ້ກະແຈເຂົ້າເຖິງຫຼາຍກວ່າໜຶ່ງເທື່ອໄດ້ບໍ?"
---

ໄດ້. ທ່ານສາມາດໃຊ້ [ກະແຈການເຂົ້າເຖິງ](/about/terminology) ຂອງທ່ານໃນອຸປະກອນຈັກເຄື່ອງກໍໄດ້, ແຕ່ພວກເຮົາບໍ່ແນະນຳໃຫ້ທ່ານແບ່ງປັນກະແຈຂອງທ່ານກັບບຸກຄົນອື່ນ. ບາງຄົນທີ່ມີກະແຈເຂົ້າເຖິງຂອງທ່ານອາດກວດສອບທຣາບຟິກອິນເຕີເນັດທັງໝົດຂອງທ່ານໄດ້ຫາກເຂົາເຈົ້າມີສິດເຂົ້າເຖິງມັນ, ເຊິ່ງບໍ່ໄດ້ເຮັດໃຫ້ການນຳໃຊ້ອິນເຕີເນັດຂອງທ່ານປອດໄພ ຫຼື ເປັນສ່ວນຕົວອີກຕໍ່ໄປ.
