ເວັບໄຊຊ່ວຍເຫຼືອນີ້ມີໄວ້ສຳລັບຜູ້ໃຊ້ Outline Manager ແລະ ຜູ້ໃຊ້ລູກຂ່າຍ. ນັກພັດທະນາ, ກະລຸນາໃຊ້ GitHub ເພື່ອຮັບຄວາມຊ່ວຍເຫຼືອ. ເພື່ອຖາມຄຳຖາມ, ກະລຸນາໂພສຢູ່ [ກະດານສົນທະນາ](https://github.com/Jigsaw-Code/outline-sdk/discussions) ຂອງ SDK. ເຊິ່ງພາກສ່ວນກະດານສົນທະນາເປັນພື້ນທີ່ເໝາະສົມໃນການຖາມຄຳຖາມ, ແບ່ງປັນແນວຄິດ, ລິ້ງໄປຫາເດໂມ ແລະ ຊ່ວຍເຫຼືອນັກພັດທະນາຄົນອື່ນໆທີ່ໃຊ້ Outline SDK. ສຳລັບຄຳຮ້ອງຂໍກ່ຽວກັບຄຸນສົມບັດ ຫຼື ລາຍງານຂໍ້ຜິດພາດ, ກະລຸນາເປີດ [ບັນຫາ](https://github.com/Jigsaw-Code/outline-sdk/issues/new) ແທນ.
