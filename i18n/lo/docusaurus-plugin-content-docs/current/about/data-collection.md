Outline ຈະບໍ່ຮວບຮວມຂໍ້ມູນສ່ວນຕົວ ເວັ້ນແຕ່ວ່າທ່ານຈະເລືອກໃຫ້ຂໍ້ມູນເອງ. ນອກຈາກນີ້, Outline ຈະບໍ່ຮວບຮວມຂໍ້ມູນກ່ຽວກັບເວັບໄຊທີ່ທ່ານເຂົ້າເບິ່ງ ຮວມທັງສິ່ງທີ່ທ່ານສື່ສານ ຫຼື ຜູ້ຄົນທີ່ທ່ານສື່ສານນຳ.

 ຫາກທ່ານສ້າງບັນຊີ ຫຼື ເຂົ້າສູ່ລະບົບບັນຊີທີ່ມີຢູ່ກັບຜູ້ໃຫ້ບໍລິການຄລາວພາກສ່ວນທີສາມຜ່ານ Outline Manager, ພວກເຮົາຈະບໍ່ເກັບຂໍ້ມູນໃດໆທີ່ທ່ານມອບໃຫ້ກັບຜູ້ໃຫ້ບໍລິການຄລາວພາກສ່ວນທີສາມຂອງທ່ານ ເຊັ່ນ: ທີ່ຢູ່ອີເມວ, ຊື່, ຂໍ້ມູນໃບບິນ ແລະ ລາຍລະອຽດການຈ່າຍເງິນຂອງທ່ານ.

## ຂໍ້ມູນທີ່ພວກເຮົາໄດ້ຮັບໂດຍອັດຕະໂນມັດ
 ພວກເຮົາຈະຮວບຮວມຂໍ້ມູນ 2 ປະເພດໂດຍອັດຕະໂນມັດ.

 1. IP ຂອງເຊີບເວີ

 ເມື່ອເຊີບເວີ Outline ມີການອັບເດດການປັບປຸງລະບົບຮັກສາຄວາມປອດໄພ ແລະ ຄຸນສົມບັດເວີຊັນຫຼ້າສຸດໂດຍລະບົບອັດຕະໂນມັດ, [Quay.io](https://quay.io/)ຈະຮວບຮວມຂໍ້ມູນ IP ຂອງເຊີບເວີ Outline ແລະ ເຮັດໃຫ້ພວກເຮົາເຂົ້າເຖິງຂໍ້ມູນ IP ໄດ້. IP ຂອງເຊີບເວີອາດລະບຸຜູ້ໃຫ້ບໍລິການເຊີບເວີຢູ່ລະບົບຄລາວ ແລະ ເມືອງທີ່ມີການຕັ້ງຄ່າເຊີບເວີ Outline ໄດ້, ແຕ່ຈະບໍ່ໃຫ້ຂໍ້ມູນກ່ຽວກັບບຸກຄົນທີ່ກຳລັງເອີ້ນໃຊ້ ຫຼື ເຂົ້າເຖິງເຊີບເວີນັ້ນ.

 2. ຂໍ້ມູນທາງເທັກນິກທີ່ບໍ່ສາມາດລະບຸຕົວຕົນບຸກຄົນໄດ້

 ຫາກ Outline ຫຼົ້ມ ຫຼື ເກີດຂໍ້ຜິດພາດຮ້າຍແຮງ ຫຼື ຫາກທ່ານສົ່ງຄຳຕິຊົມດ້ວຍຕົນເອງຜ່ານແອັບ Outline, ລະບົບຈະລາຍງານຂໍ້ມູນລຸ່ມນີ້. ພວກເຮົາຈະໃຊ້ຂໍ້ມູນນີ້ເພື່ອຊ່ວຍລະບຸ ແລະ ແກ້ໄຂບັນຫາດ້ານຄວາມສະຖຽນ ຫຼື ປະສິດທິພາບເທົ່ານັ້ນ.

- ປະເທດ
- ຄ່າພາສາ
- ວັນທີ ແລະ ເວລາຂອງການຂັດຂ້ອງ / ຂໍ້ຍົກເວັ້ນ ແລະ ເຫດການກ່ອນໜ້າສູງສຸດ 100 ລາຍການ, ເຊັ່ນ: ຜູ້ໃຊ້ເປີດພາກສ່ວນ 'ກ່ຽວກັບ'
- ຂໍ້ຄວາມຂໍ້ຍົກເວັ້ນທີ່ຮວບຮວມສະຖິຕິ
- ຊື່ OS ແລະ ເວີຊັນ
- ຮຸ່ນໂທລະສັບ (ຖ້າມີ)
- ເວລາເລີ່ມຕົ້ນຂອງແອັບ
- ໂປຣແກຣມທ່ອງເວັບ
- ສະຖາປັດຕະຍະກຳ
- ເວີຊັນ ແລະ ໝາຍເລກຮຸ່ນຂອງ Outline

ລະບົບຈະໂອນຂໍ້ມູນນີ້ດ້ວຍ HTTPS ໄປຫາ Sentry ([sentry.io](https://sentry.io/)), ເຊິ່ງເປັນຜູ້ໃຫ້ບໍລິການພາກສ່ວນທີສາມສຳລັບການຕິດຕາມຂໍ້ຜິດພາດແບບໂອເພນຊອດ. Sentry ຈະໃຊ້ເທັກໂນໂລຢີ ແລະ ບໍລິການລະດັບມາດຕະຖານອຸດສາຫະກຳທີ່ຫຼາກຫຼາຍເພື່ອປົກປ້ອງຂໍ້ມູນຂອງທ່ານຈາກການເຂົ້າເຖິງ, ການເປີດເຜີຍ, ການນຳໃຊ້ໂດຍບໍ່ໄດ້ຮັບອະນຸຍາດ ຮວມທັງຊ່ວຍປ້ອງກັນບໍ່ໃຫ້ສູນຫາຍນຳ. ຫາກທ່ານມີຄຳຖາມໃດໆກ່ຽວກັບນະໂຍບາຍຂອງ Sentry, ກະລຸນາເຂົ້າເບິ່ງ [https://sentry.io/security/](https://sentry.io/security/) ແລະ [https://sentry.io/privacy/](https://sentry.io/privacy/) ຫຼື ຕິດຕໍ່ [security@sentry.io](mailto:security@sentry.io). ຂໍ້ມູນ Outline ທັງໝົດທີ່ຈັດເກັບໂດຍ Sentry ຈະຈຳກັດໃຫ້ສະເພາະສະມາຊິກທີມ Outline ເຂົ້າເຖິງໄດ້.

## ຂໍ້ມູນທີ່ພວກເຮົາຈະເກັບສະເພາະເມື່ອມີການອະນຸຍາດ
 Outline ຈະລາຍງານຂໍ້ມູນຕໍ່ໄປນີ້ໃຫ້ກັບທີມ Outline ເມື່ອມີການອະນຸຍາດ.

 1. ການວັດແທກການນຳໃຊ້

 ເຊີບເວີ Outline ແຕ່ລະເຊີບເວີຈະຮວບຮວມຈຳນວນໄບຕ໌ທີ່ໂອນຍ້າຍ, ໄລຍະເວລາທີ່ຜູ້ໃຊ້ເຊື່ອມຕໍ່ກັບເຊີບເວີ, ປະເທດ ແລະ ລະບົບເຄືອຂ່າຍອັດຕະໂນມັດຂອງຂໍ້ມູນເຂົ້າສູ່ລະບົບທີ່ໃຊ້, ໂດຍຈະຮວບຮວມຂໍ້ມູນຍ້ອນຫຼັງໄປ 1 ຊົ່ວໂມງ ແລະ ຮວບຮວມຕາມກະແຈການເຂົ້າເຖິງແຕ່ລະລາຍການໂດຍອັດຕະໂນມັດ, ຮວມທັງຂໍ້ມູນວ່າມີຄຸນສົມບັດໃດທີ່ເປີດການນຳໃຊ້ ຫຼື ປິດການນຳໃຊ້ຢູ່ແດ່. ລະບົບຈະບໍ່ບັນທຶກເນື້ອຫາການສື່ສານ ຫຼື ເມຕາເດຕາທີ່ສາມາດລະບຸຕົວຕົນບຸກຄົນໄດ້ (ເຊັ່ນ: ຂໍ້ມູນເຂົ້າສູ່ລະບົບ, ອີເມວ, ID ອຸປະກອນ ແລະ ອື່ນໆ). ການວັດແທກທັງໝົດທີ່ເຊື່ອມໂຍງກັບ ID ເຊີບເວີ. ເບິ່ງຄຳແນະນຳໃນການປ່ຽນ ID ເຊີບເວີໄດ້ [ບ່ອນນີ້](/manager/server-management/reset-server-id).

 ເຊີບເວີ Outline ຈະບໍ່ແບ່ງປັນການວັດແທກເຫຼົ່ານີ້ກັບທີມ Outline ໂດຍຄ່າເລີ່ມຕົ້ນ. ຫາກຜູ້ເບິ່ງແຍງລະບົບເຊີບເວີເລືອກແບ່ງປັນການວັດແທກການນຳໃຊ້ຢ່າງເປີດເຜີຍ, ລະບົບຈະສົ່ງຂໍ້ມູນນີ້ໄປໃຫ້ທີມ Outline ທຸກໆຊົ່ວໂມງດ້ວຍວິທີທີ່ປອດໄພ. ຫຼັງຈາກ 60 ມື້, ຕົວວັດແທກການນໍາໃຊ້ຈະຖືກຮວບຮວມເຂົ້າກັບລະດັບປະເທດ. ຜູ້ເບິ່ງແຍງລະບົບເຊີບເວີສາມາດປ່ຽນຄ່າກຳນົດການແບ່ງປັນການວັດແທກການນຳໃຊ້ຂອງເຂົາເຈົ້າໄດ້ທຸກເວລາໂດຍການເຂົ້າເບິ່ງເມນູ ‘ການຕັ້ງຄ່າ’ ໃນ Outline Manager.

 ພວກເຮົາຂໍຂອບໃຈທີ່ທ່ານແບ່ງປັນການວັດແທກທີ່ບໍ່ເປີດເຜີຍຕົວຕົນກ່ຽວກັບການນຳໃຊ້ເຊີບເວີຂອງທ່ານໃຫ້ກັບພວກເຮົາ, ພວກເຮົາຈະໃຊ້ຂໍ້ມູນດັ່ງກ່າວເພື່ອວັດແທກແນວໂນ້ມການນຳໃຊ້ ແລະ ປັບປຸງຜະລິດຕະພັນ.

 ຕົວຢ່າງ: ຫາກຜູ້ເບິ່ງແຍງລະບົບເຊີບເວີເລືອກແບ່ງປັນການວັດແທກການນຳໃຊ້ໃຫ້ກັບພວກເຮົາ, ພວກເຮົາອາດໄດ້ຮັບຂໍ້ມູນທີ່ລະບຸວ່າມີການໃຊ້ເຊີບເວີ ID 12345 ເປັນເວລາ 3 ຊົ່ວໂມງມື້ວານນີ້, ໂດຍໄດ້ໂອນຂໍ້ມູນຮວມ 500 ເມກະໄບຕ໌, ມີການໃຊ້ກະແຈ 3 ກະແຈຈາກໃນສະຫະລັດອາເມລິກາ ແລະ ຄານາດາ, ຮວມທັງມີການເປີດການນຳໃຊ້ຄຸນສົມບັດຂີດຈຳກັດຂອງຂໍ້ມູນ.

 2. ຄຳເຫັນ ແລະ ອີເມວຂອງທ່ານຫາກທ່ານສົ່ງຄຳຕິຊົມ

 ແອັບ Outline Manager ແລະ Outline ຊ່ວຍໃຫ້ທ່ານສາມາດສົ່ງຄຳຕິຊົມຫາທີມງານໄດ້. ພວກເຮົາບໍ່ແນະນຳໃຫ້ໃສ່ຂໍ້ມູນລະບຸຕົວຕົນບຸກຄົນນັ້ນໄດ້, ແຕ່ທ່ານສາມາດເລືອກຊ່ອງທາງອີເມວໄດ້ຫາກທ່ານຕ້ອງການຮັບການຕອບກັບຈາກທີມງານ. ພວກເຮົາຍັງຮວບຮວມຂໍ້ມູນພື້ນຖານບາງຢ່າງໂດຍອັດຕະໂນມັດ, ສະນັ້ນພວກເຮົາສາມາດເຂົ້າໃຈຄໍາຕິຊົມຂອງທ່ານ. ກະລຸນາເບິ່ງຂໍ້ 2 ຂ້າງເທິງ, ພາຍໃຕ້ “ຂໍ້ມູນທີ່ພວກເຮົາໄດ້ຮັບໂດຍອັດຕະໂນມັດ”, ເພື່ອເບິ່ງຂໍ້ມູນທີ່ພວກເຮົາຮວບຮວມ. ສຶກສາເພີ່ມເຕີມກ່ຽວກັບຂໍ້ປະຕິບັດກ່ຽວກັບຄວາມປອດໄພ ແລະ ຄວາມເປັນສ່ວນຕົວຂອງ Outline ໄດ້ [ບ່ອນນີ້](/about/security-and-privacy).
