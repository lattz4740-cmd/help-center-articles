**ການຕິດຕັ້ງເຊີບເວີ**

 ​ເຖິງແມ່ນວ່າການຕິດຕັ້ງ Outline ອາດເບິ່ງຄືງ່າຍ, ແຕ່ຄວາມຈິງແລ້ວມີຂັ້ນຕອນທີ່ຊັບຊ້ອນເກີດຂຶ້ນຢູ່ເບື້ອງຫຼັງຫຼາຍຢ່າງໃນການຕິດຕັ້ງເຊີບເວີຂອງທ່ານ. ເມື່ອໃດກໍຕາມທີ່ມີການຕິດຕັ້ງ Outline, ສະຄຣິບການຕິດຕັ້ງຈະເອີ້ນໃຊ້ຂັ້ນຕອນຕໍ່ໄປນີ້:

- ລະບົບຈະດຶງຂໍ້ມູນ ແລະ ນຳເຂົ້າຮູບ Shadowbox ເວີຊັນສະຖຽນໂດຍໃຊ້ Docker. ລະບົບຈະຝາກຮູບດັ່ງກ່າວໄວ້ຢູ່ [Quay.io](https://quay.io/), ໃນ [https://quay.io/repository/outline/shadowbox?tab=tags](https://quay.io/repository/outline/shadowbox?tab=tags). ຮູບນີ້ຈະປະກອບດ້ວຍເຊີບເວີ Outline ແລະ API ການຈັດການເຊິ່ງແອັບພລິເຄຊັນການຈັດການເຊີບເວີ Outline ຈະນຳໄປໃຊ້ໃນພາຍຫຼັງເພື່ອສ້າງ ແລະ ລຶບກະແຈການເຂົ້າເຖິງອອກ, ເລືອກໃຊ້/ບໍ່ໃຊ້ການລາຍງານການວັດແທກທີ່ບໍ່ລະບຸຕົວຕົນ ແລະ ອື່ນໆ.
- [Watchtower](https://github.com/v2tec/watchtower) ຈະໄດ້ຮັບການຕິດຕັ້ງ ແລະ ຕັ້ງຄ່າເພື່ອກວດສອບການອັບເດດຮູບທຸກໆຊົ່ວໂມງເພື່ອໃຫ້ໝັ້ນໃຈໄດ້ວ່າເຊີບເວີ Outline ທຸກເຄື່ອງຈະໄດ້ຮັບການອັບເດດຄຸນສົມບັດ ແລະ ການປັບປຸງການຮັກສາຄວາມປອດໄພເວີຊັນຫຼ້າສຸດຢູ່ສະເໝີ.
- ເວັບເຊີບເວີທີ່ໃຊ້ເຂົ້າເຖິງ API ການຈັດການຈະເລີ່ມຕົ້ນເຮັດວຽກໃນຜອດແບບສຸ່ມໃນເສັ້ນທາງລັບ ແລະ ສຸ່ມ.
- ລະບົບຈະສ້າງ [ໃບຮັບຮອງ SSL ແບບເຊັນດ້ວຍຕົນເອງ](https://en.wikipedia.org/wiki/Self-signed_certificate) ຂຶ້ນເພື່ອໃຫ້ສາມາດເຂົ້າລະຫັດການຈັດການເຊີບເວີ Outline ໄດ້ໂດຍໃຊ້ TLS ເຖິງແມ່ນວ່າຈະບໍ່ມີຊື່ໂດເມນກໍຕາມ. ນອກຈາກນີ້, ລະບົບຍັງຈະສ້າງລາຍນິ້ວມືທີ່ບໍ່ຊ້ຳກັນຂອງໃບຮັບຮອງນີ້ ແລະ ຈັດເກັບໄວ້ໃນແອັບພລິເຄຊັນ Outline Manager, ເຊິ່ງຊ່ວຍປ້ອງກັນຈາກການໂຈມຕີແບບ MITM.

ເມື່ອຕິດຕັ້ງ Outline ແລ້ວບໍ່ຈຳເປັນຕ້ອງຕັ້ງຄ່າໃດໆຫຼັງຈາກການຕິດຕັ້ງ.

**ຄວາມປອດໄພຂອງເຊີບເວີ**

 ຊອບແວ Outline ເປັນຊອບແວໂອເພນຊອດ, ເຊິ່ງໝາຍຄວາມວ່າທຸກຄົນສາມາດເຫັນ ແລະ ປັບປຸງໂຄດໄດ້ຫາກພົບຊ່ອງຫວ່າງໃດໆ. ເຊິ່ງພວກເຮົາຝາກໂຄດໄວ້ຢູ່ [GitHub](https://github.com/search?q=org%3AJigsaw-Code+outline&unscoped_q=outline).

 ນອກຈາກນີ້, ເຊີບເວີ Outline ທີ່ຕິດຕັ້ງທັງໝົດຈະໄດ້ຮັບການອັບເດດໂດຍອັດຕະໂນມັດທຸກເທື່ອທີ່ມີການເປີດໂຕເວີຊັນໃໝ່ເພື່ອໃຫ້ໝັ້ນໃຈໄດ້ວ່າຈະບໍ່ມີເຊີບເວີ Outline ໃດໃຊ້ຊອບແວເວີຊັນເກົ່າ.

 ແອັບພລິເຄຊັນ Outline Manager ຈະໂຕ້ຕອບກັບບໍລິການການຈັດການໃນເຊີບເວີ Outline ເພື່ອຈັດການກະແຈການເຂົ້າເຖິງໃນເຊີບເວີດັ່ງກ່າວ. ໂດຍບໍລິການການຈັດການຈະເຮັດວຽກໃນຜອດແບບສຸ່ມ ຮວມທັງໃນເສັ້ນທາງລັບ ແລະ ບໍ່ຊ້ຳກັນ. ບໍລິການການຈັດການແມ່ນມີຄວາມຕ້ານທານຕໍ່ການເຈາະຂໍ້ມູນ ເນື່ອງຈາກມັນບໍ່ຕອບສະໜອງຕໍ່ການສອບຖາມເວັ້ນເສຍແຕ່ໄດ້ກໍານົດເສັ້ນທາງລັບທີ່ເໝາະສົມໄວ້ແລ້ວ. ສຸດທ້າຍ, ການສື່ສານທັງໝົດກັບບໍລິການການຈັດການຈະໄດ້ຖືກເຂົ້າລະຫັດດ້ວຍ [ໃບຮັບຮອງ SSL ແບບເຊັນດ້ວຍຕົນເອງ](https://en.wikipedia.org/wiki/Self-signed_certificate).

 ນອກຈາກນີ້, ເຊີບເວີ Outline ຈະບໍ່ຈັດເກັບບັນທຶກໃດໆ, ດັ່ງນັ້ນເຖິງແມ່ນວ່າຈະຖືກຮຸກຮານແຕ່ກໍຈະບໍ່ມີການເປີດເຜີຍຂໍ້ມູນຜູ້ໃຊ້. ສຶກສາເພີ່ມເຕີມໄດ້ [ບ່ອນນີ້](/about/security-and-privacy). Outline ໄດ້ຮັບການກວດສອບໂດຍ [Radically Open Security](https://radicallyopensecurity.com/) ແລະ [Cure53](https://cure53.de/) ໃນປີ 2018. ເບິ່ງລາຍງານໄດ້ [ບ່ອນນີ້](/about/security-and-privacy).

**ການຈັດການການຮັບສົ່ງຂໍ້ມູນ UDP**

 Outline ສາມາດນຳໃຊ້ໄດ້ໃນຮູບແບບ VPN ທົ່ວທັງລະບົບ, ເຊິ່ງໝາຍຄວາມວ່າການຮັບສົ່ງຂໍ້ມູນ UDP ທັງໝົດຈະສົ່ງຜ່ານເຊີບເວີ Outline.

**ການຮັບສົ່ງຂໍ້ມູນ DNS**

Outline ຈະດຳເນີນການຊອກຫາ DNS ທັງໝົດຜ່ານເຊີບເວີ Outline ແລະ ປົກປ້ອງການຊອກຫາເຫຼົ່ານັ້ນໂດຍໃຊ້ການເຂົ້າລະຫັດແບບດຽວກັນກັບທີ່ໃຊ້ໃນການເຄື່ອນໄຫວເຄືອຂ່າຍອື່ນໆທັງໝົດ. ລະບົບຈະສົ່ງຄຳຊອກຫາ DNS ຂອງທ່ານໄປຫາ Dyn Internet Guide, OpenDNS, Cloudflare DNS ຫຼື Quad9 DNS ໂດຍຜ່ານເຊີບເວີ Outline. Outline ຈະບໍ່ບັນທຶກການຊອກຫາ DNS ຂອງທ່ານ.
