## VPN ແມ່ນຫຍັງ?
 ເຄືອຂ່າຍສ່ວນຕົວສະເໝືອນ (VPN) ແມ່ນການເຊື່ອມຕໍ່ແບບສ່ວນຕົວລະຫວ່າງອຸປະກອນຂອງທ່ານ ແລະ ເຊີບເວີໂຮສ. ເມື່ອທ່ານໃຊ້ VPN, ການຮັບສົ່ງຂໍ້ມູນຂອງທ່ານຈາກຜູ້ໃຫ້ບໍລິການອິນເຕີເນັດຈະຖືກເຊື່ອງໄວ້. ທ່ານອາດຕ້ອງການໃຊ້ VPN ໃນສະຖານະການຕໍ່ໄປນີ້:

- ປົກປ້ອງຂໍ້ມູນຂອງທ່ານເມື່ອໃຊ້ເຄືອຂ່າຍ Wi-Fi ສາທາລະນະ
- ຮັກສາຂໍ້ມູນການທ່ອງເວັບຂອງທ່ານໃຫ້ເປັນແບບສ່ວນຕົວຈາກຜູ້ໃຫ້ບໍລິການອິນເຕີເນັດຂອງທ່ານ ແລະ ໜ່ວຍງານລັດຖະບານ
- ເຂົ້າເຖິງເນື້ອຫາຈາກແຫຼ່ງທີ່ມາຕ່າງໆທົ່ວໂລກໂດຍບໍ່ມີການເຊັນເຊີ

## Outline ແຕກຕ່າງຈາກ VPN ແບບດັ້ງເດີມແນວໃດ?
 ຜູ້ໃຫ້ບໍລິການອິນເຕີເນັດສາມາດກວດຈັບ ແລະ ບລັອກ VPN ແບບດັ້ງເດີມໄດ້ຢ່າງງ່າຍດາຍໂດຍການຈື່ໂປຣໂຕຄໍການຮັກສາຄວາມປອດໄພທົ່ວໄປ ແລະ/ຫຼື ຮູບແບບປະລິມານການຮັບສົ່ງຂໍ້ມູນ. ແຕ່ Outline ມີຄວາມຍືດຍຸ່ນຫຼາຍກວ່າ VPN ແບບດັ້ງເດີມເນື່ອງຈາກສ້າງດ້ວຍໂປຣໂຕຄໍທີ່ຖືກອອກແບບມາໃຫ້ກວດຈັບໄດ້ຍາກ ແລະ ຈຶ່ງເຮັດໃຫ້ບລັອກໄດ້ຍາກຂຶ້ນ. Outline ຊ່ວຍປ້ອງກັນການເຊັນເຊີຂັ້ນສູງໄດ້ຫຼາຍຮູບແບບ ເຊິ່ງຮວມທັງການບລັອກໂດຍອີງຕາມເຄືອຂ່າຍ ແລະ ການບລັອກ IP.

## ເຊີບເວີ Outline ແມ່ນຫຍັງ?
 ເຊີບເວີ Outline ຈະເອີ້ນໃຊ້ VPN ເຊິ່ງຜູ້ໃຊ້ທີ່ໄດ້ຮັບອະນຸຍາດຈະເຊື່ອມຕໍ່ໄດ້. ຫາກທ່ານຕ້ອງການສ້າງເຄືອຂ່າຍໃໝ່, ທ່ານສາມາດໃຊ້ເຊີບເວີທີ່ປອດໄພຂອງທ່ານ (ຫາກມີ) ເປັນເຊີບເວີ Outline ຂອງທ່ານໄດ້ ຫຼື ທ່ານສາມາດໃຊ້ຜູ້ໃຫ້ບໍລິການລະບົບຄລາວກໍໄດ້ ເຊັ່ນ:

- DigitalOcean
- Google Cloud Platform (GCP)
- Amazon Web Services (AWS)

ທ່ານຈະຕັ້ງຄ່າເຊີບເວີຂອງທ່ານໄດ້ໃນ Outline Manager.

## ຜູ້ຈັດການບໍລິການແມ່ນໃຜ? {#servicemanager}
 ຜູ້ຈັດການບໍລິການແມ່ນບຸກຄົນທີ່ຮັບຜິດຊອບການຕັ້ງຄ່າເຊີບເວີ Outline ແລະ ແບ່ງປັນກະແຈການເຂົ້າເຖິງໃຫ້ກັບຜູ້ໃຊ້. ໂດຍທົ່ວໄປຜູ້ຈັດການບໍລິການມີໜ້າທີ່ຮັບຜິດຊອບຄ່າໃຊ້ຈ່າຍໃນການນຳໃຊ້ເຊີບເວີ.

## Outline Manager ແມ່ນຫຍັງ?
 Outline Manager ແມ່ນແອັບພລິເຄຊັນຢູ່ເດັສທັອບທີ່ຊ່ວຍໃຫ້ຜູ້ຈັດການບໍລິການຕັ້ງຄ່າເຊີບເວີ Outline, ສ້າງ [ກະແຈການເຂົ້າເຖິງ](#accesskey) ແລະ ຕັ້ງຄ່າຂີດຈຳກັດຂອງການນຳໃຊ້ຂໍ້ມູນຂອງແຕ່ລະກະແຈ. ທ່ານສາມາດດາວໂຫຼດ Outline Manager ເວີຊັນຫຼ້າສຸດໄດ້[ບ່ອນນີ້](https://getoutline.org/get-started/#step-3) ຫຼື[ບ່ອນນີ້](https://www.reddit.com/r/outlinevpn/wiki/index/download_links/).

## ລູກຂ່າຍ Outline ແມ່ນຫຍັງ?
 ລູກຂ່າຍ Outline ແມ່ນແອັບພລິເຄຊັນ, ທີ່ມີໃຫ້ບໍລິການຢູ່ເດັສທັອບ ແລະ ໂທລະສັບມືຖື, ເຊິ່ງຊ່ວຍໃຫ້ທ່ານເຊື່ອມຕໍ່ກັບເຊີບເວີ Outline ແລະ ເຂົ້າເຖິງ VPN ໂດຍໃຊ້ກະແຈໄດ້. ທ່ານສາມາດດາວໂຫຼດລູກຂ່າຍ Outline ເວີຊັນຫຼ້າສຸດໄດ້[ບ່ອນນີ້](https://getoutline.org/get-started/#step-3) ຫຼື[ບ່ອນນີ້](https://www.reddit.com/r/outlinevpn/wiki/index/download_links/).

## ຂີດຈຳກັດຂອງຂໍ້ມູນແມ່ນຫຍັງ?
 Outline Manager ຊ່ວຍໃຫ້ຜູ້ຈັດການບໍລິການສາມາດຕັ້ງຄ່າຂີດຈຳກັດຂອງຂໍ້ມູນຊ່ວງເວລາຫຼ້າສຸດ 30 ມື້ໃນກະແຈການເຂົ້າເຖິງເພື່ອປ້ອງກັນການນຳໃຊ້ຫຼາຍເກີນໄປ ແລະ ຊ່ວຍໃຫ້ຄາດເດົາຄ່າໃຊ້ຈ່າຍໄດ້. ຜູ້ຈັດການບໍລິການສາມາດຕັ້ງຄ່າຂີດຈຳກັດເລີ່ມຕົ້ນທີ່ຈະມີຜົນກັບທຸກໆກະແຈ ແລະ ຍັງສາມາດຕັ້ງຄ່າຂີດຈຳກັດທີ່ແຕກຕ່າງກັນໃຫ້ກັບກະແຈໃດກໍໄດ້ເພື່ອຍົກເລີກຂີດຈຳກັດເລີ່ມຕົ້ນ. ເມື່ອຕັ້ງຄ່າຂີດຈຳກັດແລ້ວ, ຂີດຈຳກັດຈະມີຜົນນຳໃຊ້ທັນທີ ແລະ ຈະມີການບັງຄັບໃຊ້ທຸກໆ 1 ຊົ່ວໂມງ.

ຫາກຜູ້ຈັດການບໍລິການເລືອກແບ່ງປັນການວັດແທກກັບ Jigsaw, ເຂົາເຈົ້າຄວນກວດສອບ[ນະໂຍບາຍການຮວບຮວມຂໍ້ມູນ](/about/data-collection) ສຳລັບລາຍລະອຽດກ່ຽວກັບວິທີລາຍງານຂີດຈຳກັດຂອງການນຳໃຊ້ຂໍ້ມູນ.
