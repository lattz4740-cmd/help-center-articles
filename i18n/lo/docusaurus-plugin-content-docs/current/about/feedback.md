ຂໍຂອບໃຈທີ່ຊ່ວຍເຮັດໃຫ້ Outline ດີຂຶ້ນ! ທ່ານສາມາດສົ່ງຄຳຕິຊົມໃຫ້ພວກເຮົາໄດ້ຫຼາຍວິທີ, ບໍ່ວ່າຈະເປັນແບບບໍ່ລະບຸຕົວຕົນ ຫຼື ແຈ້ງອີເມວຂອງທ່ານໄວ້ໃນກໍລະນີທີ່ຕ້ອງການໃຫ້ພວກເຮົາຕອບກັບດັ່ງຕໍ່ໄປນີ້:

- **ສຳລັບນັກພັດທະນາ**: Outline ແມ່ນຊອບແວໂອເພນຊອດ ແລະ ພວກເຮົາໂຮສລະຫັດທັງໝົດຂອງພວກເຮົາຢູ່ [GitHub](https://github.com/jigsaw-Code/?q=outline). ທ່ານສາມາດແບ່ງປັນແນວຄິດຂອງທ່ານຢູ່ GitHub ຫຼື ຢູ່ຊຸມຊົນ [Reddit](https://www.reddit.com/r/outlinevpn/) ຂອງພວກເຮົາກໍໄດ້.
- **ສຳລັບຜູ້ໃຊ້**: ທ່ານສາມາດສົ່ງຄຳຕິຊົມໃຫ້ພວກເຮົາຜ່ານແອັບ Outline ຫຼື Outline Manager ກໍໄດ້. ແຈ້ງໃຫ້ພວກເຮົາຮູ້ວ່າຄຳຕິຊົມຂອງທ່ານກ່ຽວກັບຫຍັງ ຫຼື ຖິ້ມອີເມວໄວ້ເພື່ອໃຫ້ພວກເຮົາສາມາດຂຽນກັບຫາທ່ານໄດ້. ນອກຈາກນີ້, ພວກເຮົາຍັງຮວບຮວມເມຕາເດຕາບາງລາຍການກ່ຽວກັບສະພາບແວດລ້ອມຂອງທ່ານ, ເພື່ອໃຫ້ພວກເຮົາສາມາດຊ່ວຍທ່ານແກ້ບັນຫາໄດ້ ເຊັ່ນ: ໂປຣແກຣມທ່ອງເວັບ, ລະບົບປະຕິບັດການຂອງທ່ານ ແລະ ເວີຊັນຊອບແວທີ່ທ່ານກຳລັງໃຊ້ຢູ່.
- **ຜ່ານເວັບໄຊນີ້**: ທ່ານສາມາດຄລິກລິ້ງຕິດຕໍ່ພວກເຮົາໄດ້ທຸກບ່ອນທີ່ທ່ານເຫັນພາຍໃນເວັບໄຊນີ້.
- **ບັນຫາຮ້າຍແຮງ**: ຫາກທ່ານຕ້ອງການລາຍງານບັນຫາດ້ານຄວາມປອດໄພທີ່ຮ້າຍແຮງ, ພວກເຮົາຍິນດີທີ່ຈະຮັບອີເມວກ່ຽວກັບລາຍລະອຽດຕ່າງໆຈາກທ່ານຢູ່ security [at] [getoutline.org](https://getoutline.org/).

ຂໍຂອບໃຈອີກຄັ້ງສຳລັບການສະລະເວລາໃນການແບ່ງປັນຄວາມຄິດຂອງທ່ານກັບພວກເຮົາ.
