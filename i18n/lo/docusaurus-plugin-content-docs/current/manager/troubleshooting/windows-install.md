sidebar_label: "ເປັນຫຍັງຂ້ອຍຈຶ່ງບໍ່ສາມາດຕິດຕັ້ງ Outline Manager ຢູ່ Windows ໄດ້?"
---

ທ່ານອາດເຫັນຂໍ້ຄວາມສະແດງຂໍ້ຜິດພາດນີ້: “ຂໍອະໄພ, ເບິ່ງຄືວ່າ Outline ບໍ່ໄດ້ຮັບການຕິດຕັ້ງຢ່າງຖືກຕ້ອງ. ກະລຸນາລອງຕິດຕັ້ງອີກຄັ້ງ. ຫາກບໍ່ໄດ້ຜົນ, ກະລຸນາ [ສົ່ງຄຳຕິຊົມ](https://support.getoutline.org/s/contactsupport?)”.

ຫາກທ່ານໃຊ້ Outline ໃນ Windows, ບາງຄັ້ງທ່ານອາດພົບຂໍ້ຜິດພາດທີ່ບໍ່ຄາດຄິດ. ໃນກໍລະນີສ່ວນໃຫຍ່, ທ່ານຈະຕ້ອງລຶບອະແດັບເຕີ (ໄດຣເວີ) Outline TAP ແລະ ຄວນຕິດຕັ້ງ Outline ຄືນໃໝ່.

ຂັ້ນຕອນອາດແຕກຕ່າງກັນໄປຕາມເວີຊັນຂອງລະບົບປະຕິບັດການ Windows ຂອງທ່ານ, ແຕ່ທາງລຸ່ມນີ້ແມ່ນຂັ້ນຕອນທົ່ວໄປສຳລັບວິທີຖອນການຕິດຕັ້ງອະແດັບເຕີ TAP ແລະ Outline Manager, ຈາກນັ້ນຈຶ່ງຕິດຕັ້ງ Outline Manager ຄືນໃໝ່.

1. ຖອນການຕິດຕັ້ງອະແດັບເຕີ TAP ສຳລັບ Outline Manager
   1. ເຂົ້າໄປຕົວຈັດການອຸປະກອນ, ຈາກນັ້ນເຂົ້າໄປອະແດັບເຕີເຄືອຂ່າຍ
   2. ຊອກຫາ “ໄຟລ໌ TAP-Windows Adapter V9 ຫຼື ອະແດັບເຕີ TAP ທີ່ເຊື່ອມໂຍງກັບ Outline
   3. ຖອນການຕິດຕັ້ງ ຫຼື ລຶບອະແດັບເຕີນີ້. ກະລຸນາຮັບຊາບວ່າການດຳເນີນການນີ້ອາດສົ່ງຜົນຕໍ່ແອັບ VPN ອື່ນໆທີ່ທ່ານຕິດຕັ້ງໄວ້.
2. ຖອນການຕິດຕັ້ງ Outline Manager
   1. ເຂົ້າໄປໂປຣແກຣມ ແລະ ຄຸນສົມບັດ, ຈາກນັ້ນເຂົ້າໄປຖອນການຕິດຕັ້ງໂປຣແກຣມ
   2. ຊອກຫາແອັບ Outline Manager ແລະ ຖອນການຕິດຕັ້ງແອັບດັ່ງກ່າວ
   3. [ດາວໂຫຼດ Outline Manager ເວີຊັນຫຼ້າສຸດ](https://getoutline.org/get-started/#step-1) ແລ້ວຕິດຕັ້ງຄືນໃໝ່ໃນອຸປະກອນ Windows ຂອງທ່ານ. ເຊິ່ງການຕິດຕັ້ງດັ່ງກ່າວຈະເຮັດໃຫ້ລະບົບຕິດຕັ້ງອະແດັບເຕີ TAP ໃໝ່ໂດຍອັດຕະໂນມັດ.

ຫາກທ່ານຍັງປະສົບບັນຫາຢູ່, ກະລຸນາ [ຕິດຕໍ່ທີມງານຊ່ວຍເຫຼືອ](https://support.getoutline.org/s/contactsupport?).
