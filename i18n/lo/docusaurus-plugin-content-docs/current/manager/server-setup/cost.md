ຊອບແວ Outline ເປີດໃຫ້ທຸກຄົນນຳໃຊ້ໂດຍບໍ່ມີຄ່າໃຊ້ຈ່າຍ, ບໍ່ວ່າທ່ານຈະເປັນຜູ້ເບິ່ງແຍງລະບົບເຊີບເວີທີ່ຈັດການ VPN ຫຼື ຜູ້ທີ່ໃຊ້ Outline ເພື່ອເຂົ້າເຖິງອິນເຕີເນັດແບບເປີດ.

 Outline ຕ້ອງການສິດເຂົ້າເຖິງເຊີບເວີຄລາວເພື່ອດຳເນີນການ. ຜູ້ເບິ່ງແຍງລະບົບເຊີບເວີທີ່ມີສິດເຂົ້າເຖິງເຊີບເວີຢູ່ກ່ອນແລ້ວສາມາດຕິດຕັ້ງ Outline ໃນເຊີບເວີໄດ້ໂດຍບໍ່ມີຄ່າໃຊ້ຈ່າຍເພີ່ມເຕີມ. ສ່ວນຜູ້ທີ່ບໍ່ມີສິດເຂົ້າເຖິງເຊີບເວີສາມາດຮັບສິດເຂົ້າເຖິງໄດ້ຈາກຜູ້ໃຫ້ບໍລິການຄລາວ ເຊັ່ນ: [DigitalOcean](http://www.digitalocean.com/) ຫຼື Amazon Web Services, ໂດຍມີຄ່າໃຊ້ຈ່າຍປະມານ $5 USD ຕໍ່ເດືອນສຳລັບການອະນຸຍາດການໂອນຍ້າຍຂໍ້ມູນຂະໜາດ 1 ເທີຣາໄບຕ໌ — ເຊິ່ງພຽງພໍທີ່ຈະຮອງຮັບຜູ້ໃຊ້ຫຼາຍຮ້ອຍຄົນໃນເຊີບເວີດຽວ.

 ຕົວຢ່າງຂອງວິທີການຄຳນວນຄ່າໃຊ້ຈ່າຍໃນການໃຊ້ Outline ກັບຜູ້ໃຫ້ບໍລິການຄລາວທີ່ທ່ານເລືອກມີດັ່ງນີ້:

| *ໃນກໍລະນີທີ່ຜູ້ໃຊ້ 1 ຄົນມີການນຳໃຊ້ເພື່ອໂອນຍ້າຍຂໍ້ມູນສະເລ່ຍຕໍ່ເດືອນປະມານ 5 Gigabyte, ແພັກເກດລາຄາ $5 USD ຕໍ່ເດືອນຈະອະນຸຍາດໃຫ້ຜູ້ໃຊ້ປະມານ 200 ຄົນນຳໃຊ້ໄດ້ພ້ອມກັນ, ເຊິ່ງເຮັດຜູ້ໃຊ້ 1 ຄົນຈ່າຍພຽງແຕ່ 2.5 ເຊັນຕໍ່ເດືອນເທົ່ານັ້ນ. ກະລຸນາຮັບຊາບວ່າການໂອນຍ້າຍຂໍ້ມູນທີ່ໃຊ້ຕໍ່ເດືອນຕໍ່ຜູ້ໃຊ້ 1 ຄົນຈະແຕກຕ່າງກັນຢ່າງຫຼວງຫຼາຍໂດຍຂຶ້ນກັບວ່າຜູ້ໃຊ້ເຮັດກິດຈະກຳແບນວິດຕ່ຳ ຫຼື ສູງ, ແຕ່ຜູ້ໃຫ້ບໍລິການຄລາວສ່ວນໃຫຍ່ຈະຍືດຍຸ່ນເພື່ອຮອງຮັບການເຂົ້າເບິ່ງທີ່ເພີ່ມຂຶ້ນ.* |

ໃນຄວາມເປັນຈິງ, ການໃຊ້ Outline ຈະບໍ່ເປີດເຜີຍຕົວຕົນຕໍ່ Jigsaw ແລະ Google. ພວກເຮົາບໍ່ໄດ້ຕິດຕາມຕົວຕົນ ຫຼື ການເຂົ້າເບິ່ງຂອງທ່ານ ແລະ ບໍ່ມີແຜນທີ່ຈະເກັບຄ່າບໍລິການນຳ. ໃນທາງກົງກັນຂ້າມ, ພວກເຮົາຈະເຮັດວຽກຮ່ວມກັບຊຸມຊົນໂອເພນຊອດຂອງພວກເຮົາເພື່ອໃຫ້ໝັ້ນໃຈວ່າພວກເຮົາຈະໃຫ້ບໍລິການຊອບແວແກ່ຜູ້ໃຊ້ຂອງພວກເຮົາໄດ້ໂດຍບໍ່ມີຄ່າໃຊ້ຈ່າຍ. ສຶກສາເພີ່ມເຕີມກ່ຽວກັບຂໍ້ມູນທີ່ພວກເຮົາຮວບຮວມໄດ້ [ບ່ອນນີ້](/about/data-collection).
