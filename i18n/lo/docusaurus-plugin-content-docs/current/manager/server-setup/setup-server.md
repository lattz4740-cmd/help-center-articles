ການຕັ້ງຄ່າເຊີບເວີ Outline ເປັນຂັ້ນຕອນທຳອິດທີ່ຕ້ອງດຳເນີນການເພື່ອນຳໃຊ້ Outline. ທ່ານ ຫຼື ໃຜກໍຕາມທີ່ທ່ານເຊື່ອຖືຈະຕ້ອງຕັ້ງຄ່າເຊີບເວີໃຫ້ກັບທ່ານເພື່ອໃຫ້ທ່ານເຊື່ອມຕໍ່ອິນເຕີເນັດແບບເປີດຜ່ານ Outline ໄດ້.

## ກ່ອນທີ່ທ່ານຈະເລີ່ມຕົ້ນ
 ກ່ອນທີ່ທ່ານຈະເລີ່ມຕັ້ງຄ່າເຊີບເວີ Outline ຂອງທ່ານ, ທ່ານຈະຕ້ອງມີສິ່ງຕໍ່ໄປນີ້:

1. ສິດເຂົ້າເຖິງເຊີບເວີຂອງຕົນເອງ ຫຼື ຜູ້ໃຫ້ບໍລິການຄລາວ ເຊັ່ນ: DigitalOcean, Amazon Web Services (AWS) ຫຼື Google Cloud Platform (GCP).

 ຫາກທ່ານບໍ່ມີສິດເຂົ້າເຖິງເຊີບເວີຄລາວໄດ້ແບບທັນທີ, ທ່ານສາມາດຕັ້ງຄ່າບັນຊີກັບຜູ້ໃຫ້ບໍລິການໃດກໍໄດ້, ຮວມທັງຜູ້ໃຫ້ບໍລິການທີ່ລະບຸໄວ້ຂ້າງເທິງນຳ. ໂດຍທ່ານອາດຕ້ອງໃຊ້ບັດເຄຣດິດໃນການລົງທະບຽນ.
2. ຄອມພິວເຕີຕັ້ງໂຕະທີ່ໃຊ້ macOS 10.9+, Windows 7.0+ ຫຼື Linux.
3. ແອັບພລິເຄຊັນ Outline Manager.

## ຕັ້ງຄ່າດ້ວຍ DigitalOcean
 ຜູ້ໃຊ້ທຸກຄົນຈະຕັ້ງຄ່າ Outline ກັບ DigitalOcean ໄດ້ຢ່າງງ່າຍດາຍດ້ວຍການຄລິກພຽງສອງສາມເທື່ອ. ຫຼັງຈາກດາວໂຫຼດ ແລະ ຕິດຕັ້ງ Outline Manager ໃນຄອມພິວເຕີຂອງທ່ານແລ້ວ, ທ່ານສາມາດເລືອກຕົວເລືອກການຕັ້ງຄ່າ DigitalOcean ເຊິ່ງຈະແນະນຳວິທີໃຫ້ທ່ານຜ່ານໜ້າຈໍງ່າຍໆສອງສາມຂັ້ນຕອນເພື່ອຕັ້ງຄ່າ ແລະ ຕິດຕັ້ງ Outline Server ຂອງທ່ານ.

## ຕັ້ງຄ່າກັບຜູ້ໃຫ້ບໍລິການຄລາວລາຍອື່ນ
 ຫຼັງຈາກດາວໂຫຼດ ແລະ ຕິດຕັ້ງ Outline Manager ແລ້ວ, ທ່ານສາມາດເລືອກຕິດຕັ້ງເຊີບເວີ Outline ໃນເຄື່ອງສະເໝືອນກັບ AWS, GCP, DigitalOcean ຫຼື ຜູ້ໃຫ້ບໍລິການອື່ນໄດ້. ຂັ້ນຕອນສຳລັບແຕ່ລະຜູ້ໃຫ້ບໍລິການນັ້ນແຕກຕ່າງກັນ, ພວກເຮົາຈຶ່ງໄດ້ຮວບຮວມຄຳແນະນຳໄວ້ໃນຂັ້ນຕອນການຕັ້ງຄ່າ Outline Manager ສຳລັບຜູ້ໃຫ້ບໍລິການຄລາວທົ່ວໄປໂດຍສ່ວນໃຫຍ່, ຮວມທັງວິທີກຳນົດການຕັ້ງຄ່າໃນເຄື່ອງສະເໝືອນຂອງທ່ານກ່ອນທີ່ທ່ານຈະເອີ້ນໃຊ້ສະຄຣິບການຕິດຕັ້ງເພື່ອຕິດຕັ້ງ Outline ໃນເຊີບເວີ.
