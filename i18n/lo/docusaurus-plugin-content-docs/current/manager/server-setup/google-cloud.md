## ພາບຮວມ

Outline Manager ມີຄຸນສົມບັດທີ່ຊ່ວຍໃຫ້ທ່ານຕັ້ງຄ່າເຊີບເວີ Outline ໃນເຊີບເວີທີ່ເຮັດວຽກໃນ Google Cloud ໄດ້ໂດຍອັດຕະໂນມັດ. ຫາກທ່ານເລືອກທີ່ຈະໃຊ້ຄຸນສົມບັດນີ້, Outline Manager ຈະຂໍໃຫ້ທ່ານເຂົ້າສູ່ລະບົບດ້ວຍບັນຊີ Google ຂອງທ່ານ, ເຊິ່ງຈະໃຫ້ສິດ[OAuth](https://developers.google.com/identity/protocols/oauth2) ບາງຢ່າງໃນການຕິດຕັ້ງ Outline Manager ລົງໃນເຄື່ອງເພື່ອຈຸດປະສົງໃນການຕັ້ງຄ່າບັນຊີ Google Cloud ຂອງທ່ານ.

 ຫາກທ່ານບໍ່ຕ້ອງການໃຫ້ການອະນຸຍາດເຫຼົ່ານີ້, ທ່ານສາມາດປະຕິບັດຕາມຄຳແນະນຳໃນການຕັ້ງຄ່າຂັ້ນສູງໃນ Outline Manager ເພື່ອເອີ້ນໃຊ້ Outline ໃນ Google Cloud Platform ໄດ້.

## ໃຫ້ການອະນຸຍາດແລ້ວ

ເພື່ອສະໜອງໃຫ້ການຕັ້ງຄ່າແບບອັດຕະໂນມັດ, ຕົວຈັດການ Outline ຕ້ອງການການອະນຸຍາດຕໍ່ໄປນີ້ຈາກບັນຊີ Google ຂອງທ່ານ.

## Google Cloud Platform

- ເບິ່ງ ແລະ ຈັດການຊັບພະຍາກອນ Google Compute Engine ຂອງທ່ານ
- ເບິ່ງຂໍ້ມູນຂອງທ່ານໃນບໍລິການ Google Cloud ແລະ ເບິ່ງທີ່ຢູ່ອີເມວຂອງບັນຊີ Google ຂອງທ່ານ

## ຂໍ້ມູນບັນຊີພື້ນຖານ

- ເບິ່ງທີ່ຢູ່ອີເມວບັນຊີ Google ຫຼັກຂອງທ່ານ
- ເຊື່ອມໂຍງທ່ານກັບຂໍ້ມູນສ່ວນຕົວຂອງທ່ານໃນ Google

## ການເຂົ້າເຖິງເພີ່ມເຕີມ

- ຈັດການໂຄງການ Cloud Platform ຂອງທ່ານ
- ເບິ່ງ ແລະ ຈັດການບັນຊີການຮຽກເກັບເງິນ Google Cloud Platform ຂອງທ່ານ
- ຈັດການການຕັ້ງຄ່າບໍລິການ Google API ຂອງທ່ານ

ການອະນຸຍາດເຫຼົ່ານີ້ອະນຸຍາດໃຫ້ພວກເຮົາສະໜັບສະໜຸນການຄຳນວນຂັ້ນສູງສໍາລັບການຈັດການເຊີບເວີ Outline ຂອງທ່ານຮວມທັງ:

- ອະນຸຍາດໃຫ້ທ່ານເລືອກບັນຊີການຮຽກເກັບເງິນທີ່ຖືກຕ້ອງ
- ກຳລັງສ້າງໂຄງການໃໝ່ເພື່ອຈັດລະບຽບເຊີບເວີ Outline ຂອງທ່ານ
- ລາຍຊື່ສູນຂໍ້ມູນທີ່ມີຢູ່
- ການສ້າງເຄື່ອງສະເໝືອນໃໝ່ເພື່ອແລ່ນ Outline
- ການຕັ້ງຄ່າເຄື່ອງສະເໝືອນໃໝ່ດ້ວຍ Outline

## ກຳລັງຖອດຖອນການອະນຸຍາດ

ທ່ານສາມາດຖອດຖອນສິດເຂົ້າເຖິງ Outline Manager ໃນ Google Cloud Platform ໄດ້ໂດຍເຂົ້າໄປ[ບັນຊີຂອງຂ້ອຍ](https://myaccount.google.com/permissions). ຖ້າທ່ານຖອນການເຂົ້າເຖິງ, ເຊີບເວີໃດໆທີ່ທ່ານສ້າງຂຶ້ນດ້ວຍການຕັ້ງຄ່າອັດຕະໂນມັດຈະຍັງຄົງດຳເນີນຢູ່ ແຕ່ຈະບໍ່ປາກົດຢູ່ໃນຕົວຈັດການ Outline ອີກຕໍ່ໄປ. ເພື່ອກູ້ຄືນສິດເຂົ້າເຖິງ Outline Manager, ພຽງເຊື່ອມຕໍ່ Google Cloud Platform ຄືນໃໝ່ໂດຍເລີ່ມຂັ້ນຕອນການຕັ້ງຄ່າອັດຕະໂນມັດ.

## ອົງກອນໃນໂຄງການ Outline

ການຕັ້ງຄ່າອັດຕະໂນມັດຂອງ Google Cloud ໃຊ້[ໂຄງການ Google Cloud](https://cloud.google.com/resource-manager/docs/creating-managing-projects) ລາຍການດຽວເພື່ອຈັດລະບຽບເຊີບເວີ Outline ຂອງທ່ານ. ໂຄງການດັ່ງກ່າວໄດ້ຖືກສ້າງຂຶ້ນໃນລະຫວ່າງການນໍາໃຊ້ຄັ້ງທໍາອິດຂອງການຕັ້ງຄ່າອັດຕະໂນມັດ, ດ້ວຍ ID ໂຄງການທີ່ແນະນໍາທີ່ເລີ່ມຕົ້ນດ້ວຍ "Outline-" ຕໍ່ດ້ວຍສະຕຣິງຂອງຕົວອັກສອນແບບສຸ່ມ. ທ່ານສາມາດເລືອກ ID ໂຄງການທີ່ແຕກຕ່າງກັນໃນການສ້າງຖ້າທ່ານຕ້ອງການ. ໂຄງການດັ່ງກ່າວຈະມີຊື່ວ່າ “ເຊີບເວີ Outline”.

## ບັນຊີການຮຽກເກັບເງິນ

ໂຄງການ Google Cloud ຕ້ອງໃຊ້ “ບັນຊີການຮຽກເກັບເງິນ” ທີ່ລິ້ງຢູ່ເຊິ່ງກຳນົດຂໍ້ມູນການຈ່າຍເງິນ. ເມື່ອທ່ານໃຊ້ການຕັ້ງຄ່າອັດຕະໂນມັດ Google Cloud ທໍາອິດ, ທ່ານຈະຖືກຂໍໃຫ້ສະໜອງບັນຊີການຮຽກເກັບເງິນເພື່ອເຊື່ອມໂຍງກັບເຊີບເວີ Outline ຂອງທ່ານ. ບາງຄັ້ງເຊີບເວີຈະຢຸດເຮັດວຽກເນື່ອງຈາກມີບັນຫາກັບບັນຊີການຮຽກເກັບເງິນ. ໃນກໍລະນີນີ້, ທ່ານຄວນເຂົ້າສູ່ລະບົບ[Google Cloud Console](https://console.cloud.google.com/getting-started), ຊອກຫາໂຄງການ Google Cloud ທີ່ເຊື່ອມໂຍງກັບ Outline (ຊື່ວ່າ “ເຊີບເວີ Outline”) ແລະ ອັບເດດການຕັ້ງຄ່າການຮຽກເກັບເງິນ.

## ການລຶບລ້າງເຊີບເວີ

ຫາກທ່ານຕ້ອງການລຶບລ້າງເຊີບເວີຂອງທ່ານທີ່ສ້າງຂຶ້ນໂດຍໃຊ້ການຕັ້ງຄ່າອັດຕະໂນມັດ, ວິທີທີ່ງ່າຍທີ່ສຸດແມ່ນດຳເນີນການຈາກພາຍໃນ Outline Manager. ແນວໃດກໍຕາມ, ຫາກທ່ານຕ້ອງການລຶບລ້າງເຊີບເວີດ້ວຍຕົນເອງ, ໃຫ້ເຂົ້າສູ່ລະບົບ[Google Cloud Console](https://console.cloud.google.com/getting-started), ຊອກຫາໂຄງການທີ່ສ້າງຂຶ້ນໃນລະຫວ່າງການຕັ້ງຄ່າເລີ່ມຕົ້ນ (ຊື່ວ່າ “ເຊີບເວີ Outline servers”) ແລະ ລຶບຊັບພະຍາກອນໃນເຄື່ອງ ຫຼື ປິດໂຄງການ.
