## ຂ້ອຍຈະໃຊ້ Outline ໂດຍບໍ່ມີເຊີບເວີໄດ້ບໍ?
 ບໍ່ໄດ້, ຂໍອະໄພ. ຊອບແວ Outline ຕ້ອງໃຊ້ເຂົ້າເຖິງເຊີບເວີ, ບໍ່ວ່າຈະເປັນເຊີບເວີທີ່ທ່ານ, ອົງກອນຂອງທ່ານ ຫຼື ພາກສ່ວນທີສາມທີ່ເຊື່ອຖືໄດ້ເປັນຜູ້ຈັດການກໍຕາມ.

## ຈະໃຊ້ເວລາໃນການຕັ້ງຄ່າເຊີບເວີ Outline ເທົ່າໃດ?

ໃນກໍລະນີສ່ວນໃຫຍ່, ຈະໃຊ້ເວລາໜ້ອຍກວ່າ 5 ນາທີ. ທ່ານສາມາດຕິດຕັ້ງ Outline ໃນເຊີບເວີຄລາວໃດກໍໄດ້, ແຕ່ພວກເຮົາໄດ້ເຮັດວຽກຮ່ວມກັບ DigitalOcean ເພື່ອມອບປະສົບການໃນການຕິດຕັ້ງແບບມີຄຳແນະນຳທີ່ເໝາະກັບຜູ້ໃຊ້ຫຼາຍຂຶ້ນ, ເຊິ່ງທ່ານສາມາດຕັ້ງຄ່າເຊີບເວີຂອງຕົນເອງໄດ້ດ້ວຍການຄລິກພຽງສອງສາມເທື່ອແບບບໍ່ມີສະຄຣິບ.

ຫາກທ່ານເລືອກ AWS, GCP ຫຼື ການຕັ້ງຄ່າຂັ້ນສູງ, ພວກເຮົາໄດ້ປັບປຸງຂະບວນການຕິດຕັ້ງເຊີບເວີເປັນສະຄຣິບດຽວທີ່ຮອງຮັບຜູ້ໃຫ້ບໍລິການສ່ວນໃຫຍ່.

## ຂ້ອຍຈະຕັ້ງຄ່າເຊີບເວີ Outline ໄດ້ຢູ່ໃສ?

ທ່ານສາມາດຕັ້ງຄ່າເຊີບເວີ Outline ໃນສະຖານທີ່ທີ່ຜູ້ໃຫ້ບໍລິການຄລາວສ່ວນໃຫຍ່ດຳເນີນການຢູ່ໄດ້.

ທາງເລືອກທີ່ງ່າຍທີ່ສຸດແມ່ນການຕັ້ງຄ່າໃນ DigitalOcean, ເນື່ອງຈາກ DigitalOcean ມີເຊີບເວີຢູ່ໃນສະຖານທີ່ຫຼາຍແຫ່ງ ເຊັ່ນ: ອາມສະເຕີດາມ, ໂຕຣອນໂຕ, ຊານຟຣານຊິສໂກ ແລະ ສິງກະໂປ. ຫາກທ່ານຕ້ອງການຕິດຕັ້ງກັບຜູ້ໃຫ້ບໍລິການຄລາວລາຍອື່ນ ຫຼື ຢູ່ໂຄງສ້າງພື້ນຖານຂອງທ່ານເອງ, ໃຫ້ເລືອກ ‘ໂໝດຂັ້ນສູງ’ ໃນແອັບພລິເຄຊັນ Outline Manager ແລະ ປະຕິບັດຕາມຄຳແນະນຳໃນການຕິດຕັ້ງໂດຍໃຊ້ສະຄິບການຕັ້ງຄ່າ.

## ຂ້ອຍຄວນຕັ້ງຄ່າເຊີບເວີ Outline ຂອງຂ້ອຍຢູ່ໃສ?

1. ຂໍ້ຄວນພິຈາລະນາສອງສາມຢ່າງທີ່ທ່ານຄວນຄຳນຶງເມື່ອຕັດສິນໃຈເລືອກສະຖານທີ່ສຳລັບເຊີບເວີ Outline ຂອງທ່ານມີດັ່ງນີ້:
2. ສະຖານທີ່ເຊີບເວີ Outline ມີຜົນກະທົບແນວໃດຕໍ່ປະສົບການຜູ້ໃຊ້ອິນເຕີເນັດ. ຕົວຢ່າງ: ຖ້າເຊີບເວີຕັ້ງຢູ່ໃນອາມສະເຕີດາມ, ຜູ້ໃຊ້ທີ່ເຂົ້າເຖິງເຊີບເວີນີ້ຈະມີປະສົບການອິນເຕີເນັດຄືກັບວ່າເຂົາເຈົ້າຕັ້ງຢູ່ໃນປະເທດເນເທີແລນ. ບາງເວັບໄຊອາດຈະສະແດງເປັນພາສາດັຊ. ໂດຍປົກກະຕິແລ້ວ, ທ່ານສາມາດຍົກເລີກພາສາທ້ອງຖິ່ນໄດ້ໂດຍໃຊ້ຕົວເລືອກພາສາໃນເວັບໄຊ.
3. ໄລຍະຫ່າງລະຫວ່າງຜູ້ໃຊ້ຂອງທ່ານ ແລະ ເຊີບເວີ Outline ອາດສົ່ງຜົນຕໍ່ຄວາມໄວຂອງທ່ານ. ໂດຍທົ່ວໄປ, ໄລຍະຫ່າງທາງກາຍະພາບລະຫວ່າງຜູ້ໃຊ້ Outline ແລະ ເຊີບເວີສາມາດສົ່ງຜົນກະທົບຕໍ່ຄວາມໄວອິນເຕີເນັດຂອງຜູ້ໃຊ້. ໃນກໍລະນີສ່ວນໃຫຍ່, ທ່ານສາມາດເລືອກສະຖານທີ່ຂອງເຊີບເວີໃຫ້ໃກ້ກັບສະຖານທີ່ທີ່ຄາດວ່າຜູ້ໃຊ້ຈະອາໄສຢູ່ຫຼາຍທີ່ສຸດ, ແຕ່ທ່ານສາມາດກວດສອບ [Submarine Cable Map](https://www.submarinecablemap.com/) ເພື່ອເບິ່ງການເຊື່ອມຕໍ່ສາຍອິນເຕີເນັດໃນປະເທດ ຫຼື ພາກພື້ນຂອງທ່ານກໍໄດ້ເຊັ່ນກັນ.
4. ສະຖານທີ່ຂອງເຊີບເວີ VPN ຂອງທ່ານອາດສົ່ງຜົນຕໍ່ຂອບກົດໝາຍ. ກະລຸນາຮັບຊາບວ່າຊອບແວ Outline ບໍ່ໄດ້ບັນທຶກການສັນຈອນຂໍ້ມູນຂອງທ່ານ. ສຶກສາເພີ່ມເຕີມກ່ຽວກັບ [ຄວາມປອດໄພ ແລະ ຄວາມເປັນສ່ວນຕົວໃນຂະນະທີ່ໃຊ້ Outline](/about/security-and-privacy).
