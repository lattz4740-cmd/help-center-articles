sidebar_label: ວິທີການຕັ້ງຄ່າເຊີບເວີ Outline ຫຼາຍອັນ
---

ເພື່ອຕັ້ງຄ່າເຊີບເວີ Outline ເພີ່ມເຕີມ, ໃຫ້ຄລິກໃສ່ໄອຄອນ "+" ໃນແຜງນໍາທາງຢູ່ເບື້ອງຊ້າຍຂອງແອັບພລິເຄຊັນຕົວຈັດການ Outline ຂອງທ່ານ. ຄໍາແນະນໍາໃນການເພີ່ມເຊີບເວີໃໝ່ແມ່ນເຮັດຄືກັນກັບຕອນທີ່ທ່ານກໍາລັງຕິດຕັ້ງເທື່ອທໍາອິດຂອງທ່ານ.

- ພວກເຮົາບໍ່ມີຂໍ້ຈໍາກັດກ່ຽວກັບຈໍານວນຂອງເຊີບເວີ Outline ທີ່ທ່ານສາມາດສ້າງ.
- ສໍາລັບທຸກໆເຊີບເວີ Outline ທີ່ທ່ານສ້າງ, ທ່ານຈະຕ້ອງມີເຄື່ອງສະເໝືອນທີ່ສອດຄ່ອງກັນ.
- ການສ້າງເຄື່ອງຈັກເພີ່ມເຕີມ ຫຼື droplets ອາດຈະເພີ່ມຄ່າບໍລິການຂອງທ່ານກັບຜູ້ໃຫ້ບໍລິການຄລາວຂອງທ່ານ. ກະລຸນາກວດເບິ່ງແພັກເກດລາຄາຂອງທ່ານກັບຜູ້ໃຫ້ບໍລິການຄລາວເພື່ອໃຫ້ແນ່ໃຈວ່າທ່ານຮູ້ວ່າຈະຄາດຫວັງຫຍັງ.

## ການສ້າງເຊີບເວີ Outline ເພີ່ມເຕີມໃນ DigitalOcean

ຫຼັງຈາກການຄລິກໃສ່ໄອຄອນ + ແລະ ການເລືອກທີ່ຈະຕິດຕັ້ງໃນ DigitalOcean, ທ່ານຈະປະຕິບັດຕາມຄໍາແນະນໍາດຽວກັນທີ່ທ່ານໄດ້ຕັ້ງຄ່າເຊີບເວີທໍາອິດຂອງທ່ານ. ນອກຈາກນັ້ນ, ນັບຕັ້ງແຕ່ຕົວຈັດການ Outline ປະສົມປະສານກັບ DigitalOcean, ພວກເຮົາສາມາດສ້າງ droplet ສໍາລັບທ່ານໂດຍບໍ່ຈໍາເປັນຕ້ອງອອກຈາກແອັບຕົວຈັດການ Outline.

ໃຫ້ສັງເກດວ່າຕົວຈັດການ Outline ສາມາດຮອງຮັບບັນຊີ DigitalOcean ໄດ້ເທື່ອລະອັນ. ຖ້າຕ້ອງການເພີ່ມ ຫຼື ສ້າງເຊີບເວີ Outline ອື່ນຈາກບັນຊີ DigitalOcean ອື່ນ, ທ່ານສາມາດເພີ່ມພວກມັນເປັນການຕັ້ງຄ່າຂັ້ນສູງໄດ້.

## ການສ້າງເຊີບເວີ Outline ເພີ່ມເຕີມໃນ GCP, AWS ຫຼື ຜູ້ໃຫ້ບໍລິການຄລາວອື່ນ

ເລີ່ມຕົ້ນດ້ວຍການສ້າງເຄື່ອງສະເໝືອນໃໝ່ກັບຜູ້ໃຫ້ບໍລິການຄລາວທີ່ທ່ານເລືອກ. ຈາກນັ້ນໃຫ້ເປີດຕົວຈັດການ Outline ແລະ ເຮັດສໍາເລັດຄໍາແນະນໍາສໍາລັບການຕິດຕັ້ງຂັ້ນສູງ, ພຽງແຕ່ເຮັດຄືກັນກັບຕອນທີ່ທ່ານມີຄັ້ງທໍາອິດ.
