sidebar_label: "ຂ້ອຍຈະອັບເດດຊອບແວສຳລັບເຊີເວີ Outline ຂອງຂ້ອຍແນວໃດ?"
---

ເຊີບເວີຂອງ Outline ຈະອັບເດດການປັບປຸງການຮັກສາຄວາມປອດໄພເວີຊັນຫຼ້າສຸດໂດຍອັດຕະໂນມັດເພື່ອໃຫ້ທ່ານໄດ້ນຳໃຊ້ເທັກໂນໂລຢີ Outline ຫຼ້າສຸດຢູ່ສະເໝີ. ຂະບວນການອັບເດດອັດຕະໂນມັດນີ້ເປີດການນຳໃຊ້ໂດຍ [Watchtower](https://github.com/v2tec/watchtower), ເຊິ່ງເປັນຫ້ອງສະໝຸດແບບໂອເພນຊອດທີ່ກວດສອບ ແລະ ອັບເດດຮູບໃນ Docker ທີ່ມີຊອບແວ Outline ເປັນປະຈຳ.

ນອກຈາກນີ້, ເມື່ອທ່ານຕິດຕັ້ງ Outline ໂດຍໃຊ້ Outline Manager, ພວກເຮົາຈະຕັ້ງຄ່າວຽກ Cron ໃຫ້ອັບເກຣດຊອບແວໃນເຊີບເວີໂດຍອັດຕະໂນມັດໂດຍໃຊ້ [ການອັບເກຣດໂດຍອັດຕະໂນມັດ](https://wiki.debian.org/UnattendedUpgrades) (Ubuntu) ແລະ ປິດເປີດໃໝ່ເມື່ອຈຳເປັນ. ກະລຸນາຮັບຊາບວ່າຂະບວນການນີ້ຈະບໍ່ເກີດຂຶ້ນໃນໂໝດຂັ້ນສູງເພື່ອຮັກສາການຕັ້ງຄ່າທີ່ມີຢູ່ໄວ້, ໂດຍຖືວ່າມີການໃຊ້ໂຮສສຳລັບຈຸດປະສົງອື່ນໆນອກເໜືອຈາກການເອີ້ນໃຊ້ Outline.
