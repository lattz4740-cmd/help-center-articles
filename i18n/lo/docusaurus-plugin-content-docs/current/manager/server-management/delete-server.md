sidebar_label: "ຂ້ອຍຈະລຶບເຊີບເວີ Outline ຂອງຂ້ອຍແນວໃດ?"
---

ການລຶບເຄື່ອງສະເໝືອນທີ່ທ່ານກຳລັງໃຊ້ຢູ່ອອກນັ້ນເປັນສິ່ງທີ່ງ່າຍດາຍສຳລັບຜູ້ໃຫ້ບໍລິການຄລາວສ່ວນໃຫຍ່.

ຫາກທ່ານກຳລັງໃຊ້ DigitalOcean ເປັນຜູ້ໃຫ້ບໍລິການຄລາວຂອງທ່ານ, ທ່ານສາມາດລຶບເຄື່ອງສະເໝືອນທີ່ມີຢູ່ຂອງທ່ານອອກໄດ້ໂດຍຄລິກໃສ່ປຸ່ມຮູບຟັນເຟືອງ ແລະ ເລືອກລຶບລ້າງເຊີບເວີ. ຫຼັງຈາກນັ້ນ, ລະບົບຈະແຈ້ງໃຫ້ທ່ານສ້າງເຄື່ອງສະເໝືອນໃໝ່ໃນສະຖານທີ່ທີ່ທ່ານຕ້ອງການໂດຍທັນທີ.

ຫາກທ່ານລຶບເຊີບເວີ Outline ອອກ, ລະບົບຈະລຶບເຊີບເວີດັ່ງກ່າວອອກຢ່າງຖາວອນ ແລະ ກະແຈການເຂົ້າເຖິງຈະໃຊ້ບໍ່ໄດ້ອີກຕໍ່ໄປ. ຫາກທ່ານບໍ່ຕ້ອງການໃຫ້ຜູ້ໃຊ້ພົບບັນຫາໃນການນຳໃຊ້ Outline, ທ່ານຈະຕ້ອງ [ຕັ້ງຄ່າເຊີບເວີ Outline ໃໝ່](/manager/server-setup/setup-server) ແລະ ແບ່ງປັນສິດເຂົ້າເຖິງເຊີບເວີນັ້ນກ່ອນທີ່ຈະລຶບເຊີບເວີເກົ່າຂອງທ່ານ.
