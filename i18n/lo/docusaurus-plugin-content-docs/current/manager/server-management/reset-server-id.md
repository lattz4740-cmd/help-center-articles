title: "ຂ້ອຍຈະຣີເຊັດ ID ເຊີບເວີຂອງຂ້ອຍໄດ້ແນວໃດ?"
sidebar_label: "ຂ້ອຍຈະຣີເຊັດ ID ເຊີບເວີຂອງຂ້ອຍໄດ້ແນວໃດ?"
---

ID ເຊີບເວີແມ່ນ ID ທີ່ສ້າງຂຶ້ນແບບສຸ່ມຈາກຝັ່ງເຊີບເວີເມື່ອທ່ານສ້າງເຊີບເວີ Outline. ທ່ານສາມາດຊອກຫາ ID ໄດ້ເມື່ອເລືອກໃຊ້ການແບ່ງປັນການວັດແທກແບບບໍ່ລະບຸຕົວຕົນໃນສ່ວນຕິດຕໍ່ການຕັ້ງຄ່າ. ທ່ານສາມາດຊອກຫາ ID ເຊີບເວີຂອງທ່ານໄດ້ຈາກ: ການຕັ້ງຄ່າ => ເລື່ອນໄປລຸ່ມສຸດ => ເລືອກ "ແບ່ງປັນການວັດແທກແບບບໍ່ລະບຸຕົວຕົນ".

ID ເຊີບເວີຈະຮວບຮວມສະຖິຕິການນຳໃຊ້ແບບບໍ່ລະບຸຕົວຕົນທີ່ລາຍງານໃນໄລຍະເວລາໜຶ່ງເຂົ້ານຳກັນ. ຫາກທ່ານຕ້ອງການຣີເຊັດ ID ເຊີບເວີ ແລະ ຂໍຮັບ ID ໃໝ່, ທ່ານຕ້ອງປ່ຽນແທນເຊີບເວີ Outline ທີ່ມີຢູ່ດ້ວຍເຊີບເວີໃໝ່.

ຫາກທ່ານກຳລັງໃຊ້ DigitalOcean ເປັນຜູ້ໃຫ້ບໍລິການຄລາວຂອງທ່ານ, ທ່ານຈະສາມາດຣີເຊັດເຊີບເວີຂອງທ່ານໄດ້ໂດຍເຂົ້າໄປການຕັ້ງຄ່າແລ້ວເລືອກລຶບລ້າງເຊີບເວີ. ການດຳເນີນການນີ້ຈະບໍ່ສາມາດຍົກເລີກໄດ້ ແລະ ຈະລຶບຂໍ້ມູນການເຂົ້າສູ່ລະບົບຂອງທ່ານ. ຫຼັງຈາກນັ້ນ, ລະບົບຈະແຈ້ງໃຫ້ທ່ານສ້າງເຊີບເວີໃໝ່ໃນສະຖານທີ່ທີ່ທ່ານຕ້ອງການທັນທີ ແລະ ຈະມີການສ້າງ ID ເຊີບເວີໃໝ່.
