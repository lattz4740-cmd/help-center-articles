sidebar_label: ຈັດການສິດເຂົ້າເຖິງເຊີບເວີ Outline (ດ້ວຍກະແຈການເຂົ້າເຖິງ)
---

ເມື່ອທ່ານຕິດຕັ້ງເຊີບເວີ Outline ຂອງທ່ານສຳເລັດແລ້ວ, ທ່ານຈະເລີ່ມການແບ່ງປັນ ແລະ ຈັດການສິດເຂົ້າເຖິງເຊີບເວີຂອງຜູ້ໃຊ້ໄດ້. ຜູ້ໃຊ້ທີ່ໄດ້ຮັບຄຳເຊີນຈາກທ່ານຈະສາມາດດາວໂຫຼດແອັບ Outline ເພື່ອໃຊ້ Outline ໃນການປົກປ້ອງທຣາບຟິກອິນເຕີເນັດຂອງຕົນເອງໄດ້.

**ແບ່ງປັນສິດເຂົ້າເຖິງເຊີບເວີ Outline ຂອງທ່ານ**

 ຫຼັງຈາກທີ່ທ່ານຕິດຕັ້ງເຊີບເວີ Outline ສຳເລັດແລ້ວ, ລະບົບຈະນຳທ່ານໄປຫາໜ້າລາຍລະອຽດຂອງເຊີບເວີໃນ Outline Manager, ເຊິ່ງທ່ານສາມາດສ້າງກະແຈການເຂົ້າເຖິງໄດ້. ສຶກສາເພີ່ມເຕີມກ່ຽວກັບ [ກະແຈການເຂົ້າເຖິງ](/about/terminology).

- ສ້າງກະແຈ: ຄລິກໄອຄອນ "+" ນ້ອຍໆຢູ່ລຸ່ມສຸດຂອງໜ້າເພື່ອສ້າງກະແຈໃໝ່.
- ແບ່ງປັນກະແຈ: ຢູ່ເບື້ອງຂວາຂອງແຕ່ລະກະແຈ, ຈະມີໄອຄອນແບ່ງປັນທີ່ທ່ານສາມາດຄລິກເພື່ອຮັບຄຳເຊີນໄດ້. ສຳເນົາ ແລະ ວາງຄຳເຊີນນີ້ໃສ່ໃນລະບົບການຮັບສົ່ງຂໍ້ຄວາມທີ່ທ່ານເລືອກ.

**ຄຳຮ້ອງຂໍຄຸນສົມບັດ: ການແບ່ງປັນສິດເຂົ້າເຖິງຈາກພາຍໃນແອັບ Outline Manager**

 ຜູ້ເບິ່ງແຍງລະບົບເຊີບເວີຈຳນວນຫຼາຍຂໍໃຫ້ພວກເຮົາປັບປຸງຂະບວນການສົ່ງຄຳເຊີນໂດຍໃຫ້ຕົວເລືອກແກ່ເຂົາເຈົ້າໃນການໃສ່ທີ່ຢູ່ອີເມວຂອງໃຜກໍໄດ້ໃນ Outline Manager ໂດຍກົງ.

ຂໍອະໄພ, ພວກເຮົາອາດຈະສ້າງຟັງຊັນນີ້ໃສ່ໃນ Outline Manager ບໍ່ໄດ້. ໜຶ່ງໃນຫຼັກການຫຼັກຂອງພວກເຮົາແມ່ນເພື່ອຊ່ວຍເຫຼືອຄວາມເປັນສ່ວນຕົວ ແລະ ຄວາມປອດໄພຂອງຜູ້ໃຊ້ຂອງພວກເຮົາ, ເຊິ່ງໝາຍຄວາມວ່າພວກເຮົາບໍ່ໄດ້ອອກແບບສະຖານທີ່ໃດໆເພື່ອໃສ່ທີ່ຢູ່ອີເມວ ຫຼື ຂໍ້ມູນການຕິດຕໍ່.

ດ້ວຍເຫດນີ້, ພວກເຮົາຈຶ່ງຂໍໃຫ້ຜູ້ເບິ່ງແຍງລະບົບເຊີບເວີໃຊ້ແພລດຟອມການຮັບສົ່ງຂໍ້ຄວາມທີ່ປອດໄພ ເຊັ່ນ: ອີເມວ ຫຼື ການສົນທະນາທີ່ປອດໄພ, ເພື່ອສົ່ງຄຳເຊີນດັ່ງກ່າວໄປຫາຜູ້ໃຊ້ປາຍທາງ.

**ສິ່ງທີ່ຈະເກີດຂຶ້ນກັບຜູ້ໃຊ້ຫຼັງຈາກທີ່ທ່ານແບ່ງປັນກະແຈການເຂົ້າເຖິງກັບເຂົາເຈົ້າ**

1. ຜູ້ໃຊ້ຈະຄລິກລິ້ງການຕິດຕັ້ງຈາກອຸປະກອນຂອງຕົນເອງ
2. ເຂົາເຈົ້າຈະຖືກເຕືອນໃຫ້ຕິດຕັ້ງແອັບ Outline ຖ້າເຂົາເຈົ້າບໍ່ທັນມີມັນເທື່ອ
3. ເຂົາເຈົ້າຈະສ້າງການເຊື່ອມຕໍ່ເລີ່ມຕົ້ນກັບເຊີບເວີ Outline ຂອງທ່ານໂດຍຜ່ານກະແຈທີ່ເປັນເອກະລັກທີ່ຝັງຢູ່ໃນຄໍາເຊີນ
4. ຕອນນີ້ເຂົາເຈົ້າສາມາດໃຊ້ປຸ່ມເຊື່ອມຕໍ່/ຍົກເລີກການເຊື່ອມຕໍ່ເພື່ອຈັດການການເຂົ້າເຖິງອິນເຕີເນັດຂອງເຂົາເຈົ້າຜ່ານເຊີບເວີ Outline ຂອງທ່ານໄດ້ແລ້ວ

**ລຶບສິດເຂົ້າເຖິງເຊີບເວີ Outline ຂອງທ່ານອອກ**

 ຈາກໜ້າລາຍລະອຽດຂອງເຊີບເວີໃນ Outline Manager, ທ່ານຈະເຫັນເມນູພ້ອມຕົວເລືອກໃນການລຶບກະແຈທາງເບື້ອງຂວາຂອງທຸກໆກະແຈຢູ່ເຊີບເວີ. ເຊິ່ງການລຶບກະແຈຈະເປັນການລຶບສິດຂອງເຂົາເຈົ້າໃນການເຂົ້າເຖິງເຊີບເວີຂອງທ່ານອອກ.
