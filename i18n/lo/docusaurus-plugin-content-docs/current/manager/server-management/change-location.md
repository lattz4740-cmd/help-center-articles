sidebar_label: "ຂ້ອຍຈະປ່ຽນສະຖານທີ່ຂອງເຊີບເວີ Outline ແນວໃດ?"
---

ເມື່ອຕັ້ງຄ່າແລ້ວ, ຕຳແໜ່ງຂອງເຊີບເວີຈະບໍ່ສາມາດປ່ຽນແປງໄດ້. ເພື່ອເອີ້ນໃຊ້ເຊີບເວີຂອງທ່ານຈາກສະຖານທີ່ອື່ນ, ທ່ານຈະຕ້ອງລຶບເຊີບເວີ Outline ຂອງທ່ານ ແລະ ສ້າງເຊີບເວີໃໝ່ກ່ອນ.

ຫຼື ທ່ານສາມາດປ່ຽນສະຖານທີ່ຂອງ VPN ຂອງທ່ານໂດຍໃຊ້ [ກະແຈແບບໄດນາມິກ](https://developer.getoutline.org/vpn/management/dynamic-access-keys/), ເຊິ່ງອະນຸຍາດໃຫ້ທ່ານສັບປ່ຽນເຊີບເວີໄດ້ໂດຍທີ່ຍັງໃຊ້ກະແຈເກົ່າ. ໂດຍສະຖານທີ່ຂອງເຊີບເວີຈະບໍ່ປ່ຽນແປງ.
