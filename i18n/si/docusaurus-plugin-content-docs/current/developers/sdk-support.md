මෙම සහාය වෙබ් අඩවිය Outline Manager සහ සේවාලාභීයා භාවිතා කරන්නන් සඳහා වේ. සංවර්ධකයින්, සහාය සඳහා GitHub භාවිතා කරන්න. ප්‍රශ්නයක් ඇසීමට, SDK [සාකච්ඡා පුවරුවේ](https://github.com/Jigsaw-Code/outline-sdk/discussions) පළ කරන්න. සාකච්ඡා පුවරු කොටස ප්‍රශ්න ඇසීමට, අදහස් බෙදා ගැනීමට, ආදර්ශන වෙත සබැඳි කිරීමට සහ Outline SDK භාවිතා කරන අනෙකුත් සංවර්ධකයන්ට සහාය වීමට කදිම ස්ථානයකි. විශේෂාංග ඉල්ලීම් හෝ දෝෂ වාර්තා සඳහා, ඒ වෙනුවට [ගැටලුවක්](https://github.com/Jigsaw-Code/outline-sdk/issues/new) විවෘත කරන්න.
