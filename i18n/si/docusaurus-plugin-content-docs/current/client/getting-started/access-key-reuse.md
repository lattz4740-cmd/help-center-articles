sidebar_label: "මට ප්‍රවේශ යතුර එක් වරකට වඩා භාවිතා කළ හැකි ද?"
---

ඔව්. ඔබට ඔබේ ඕනෑම උපාංග ගණනක ඔබේ [ප්‍රවේශ යතුර](/about/terminology) භාවිතා කළ හැකි නමුත්, ඔබේ යතුර වෙනත් පුද්ගලයෙකු සමග බෙදා ගැනීමට අපි නිර්දේශ නොකරමු. ඔබේ ප්‍රවේශ යතුර ඇති කෙනෙකුට එයට ප්‍රවේශය තිබේ නම්, ඔබේ සියලු අන්තර්ජාල ගමනාගමනය පරීක්ෂා කළ හැක, එය තවදුරටත් ඔබේ අන්තර්ජාල භාවිතය සුරක්ෂිත හෝ පෞද්ගලික නොකරයි.
