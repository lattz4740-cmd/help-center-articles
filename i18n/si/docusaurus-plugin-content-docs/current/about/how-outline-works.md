**සේවාදායක ස්ථාපනය**

 ​Outline ස්ථාපනය සරල බවක් පෙනෙන්නට තිබුණත්, ඔබේ සේවාදායකය ස්ථාපනය කිරීමට තිරය පිටුපස සිදුවෙමින් පවතින සංකීර්ණ පියවර මාලාවක් ඇත. Outline ස්ථාපනය කරන සෑම විටම, ස්ථාපන ස්ක්‍රිප්ට් එකක් පහත පියවරයන් ධාවනය කරයි:

- Shadowbox රූපයෙහි ස්ථායී අනුවාදය Docker භාවිතයෙන් ලබා ගෙන ආයාත කරනු ලැබේ. රූපය [Quay.io](https://quay.io/) මත, [https://quay.io/repository/outline/shadowbox?tab=tags](https://quay.io/repository/outline/shadowbox?tab=tags) හි සත්කාරකත්වය දරයි. මෙම රූපයේ Outline සේවාදායකය සහ කළමනාකරණ API අඩංගු වන අතර එය Outline සේවාදායක කළමනාකරණ යෙදුම මගින් ප්‍රවේශ යතුරු තැනීමට සහ ඉවත් කිරීමට, නිර්නාමික මිතික වාර්තා කිරීම ඇතුළු/ඉවත් වීම යනාදිය භාවිතා කරයි.
- [Watchtower](https://github.com/v2tec/watchtower) සෑම පැයකම රූප යාවත්කාලීන කිරීම් සඳහා පරීක්ෂා කිරීමට ස්ථාපනය කර වින්‍යාස කර ඇති අතර, සෑම Outline සේවාදායකයක්ම නවතම විශේෂාංග සහ ආරක්ෂක වැඩි දියුණු කිරීම් සමග නිරන්තරයෙන් යාවත්කාලීන බව සහතික කිරීමට උදවු වේ.
- කළමනාකරණ API වෙත ප්‍රවේශ වීම සඳහා භාවිතා කරන වෙබ් සේවාදායකයක්, රහසිගත සහ අහඹු මාර්ගයක අහඹු පෝටයක් මත ආරම්භ වේ.
- [ස්වයං අත්සන් කළ SSL සහතිකය](https://en.wikipedia.org/wiki/Self-signed_certificate) වසම් නාමයක් නොමැති වුවද Outline සේවාදායකයේ කළමනාකරණය TLS භාවිතයෙන් සංකේතනය කළ හැකි වන පරිදි ස්වයං-අත්සන සහිත SSL සහතිකයක් තනනු ලැබේ. මෙම සහතිකයේ අනන්‍ය වූ ඇඟිලි සලකුණක් ද උත්පාදනය කර Outline කළමනාකරු යෙදුම තුළ ගබඩා කර ඇති අතර, MITM ප්‍රහාර වළක්වා ගැනීමට උදවු වේ.

ස්ථාපනය කිරීමෙන් පසු Outline ස්ථාපනයට කිසිදු වින්‍යාසයක් අවශ්‍ය නොවේ.

**සේවාදායක ආරක්ෂාව**

 Outline මෘදුකාංගය විවෘත මූලාශ්‍රයකි, එයින් අදහස් කරන්නේ ඕනෑම කෙනෙකුට කේතය දැකගත හැකි අතර කිසියම් අනාවරණය වූ දුර්වලතා තිබේ නම් එය වැඩි දියුණු කළ හැකි බවයි. අපගේ කේතය [GitHub](https://github.com/search?q=org%3AJigsaw-Code+outline&unscoped_q=outline) හි සත්කාරකත්වය දරයි.

 තවද, ස්ථාපනය කර ඇති සියලු Outline සේවාදායකයන් නව අනුවාදයක් නිකුත් කරන සෑම විටම ස්වයංක්‍රීයව යාවත්කාලීන වන අතර, මෘදුකාංගයේ පැරණි අනුවාදවල කිසිදු Outline සේවාදායකයක් ඉතිරි නොවන බව සහතික කරයි.

 සේවාදායකයේ ප්‍රවේශ යතුරු කළමනාකරණය කිරීම සඳහා, Outline කළමනාකරු යෙදුම Outline සේවාදායකයේ කළමනාකරණ සේවාවක් සමග අන්තර්ක්‍රියා කරයි. කළමනාකරණ සේවාව අහඹු පෝටයක් මත සහ රහසිගත සහ අනන්‍ය වූ මාර්ගයක ධාවනය වේ. සුදුසු රහස් මාර්ගය සඳහන් කර නොමැති නම්, විමසුම්වලට ප්‍රතිචාර නොදක්වන බැවින් කළමනාකරණ සේවාවම ප්‍රතිරෝධී වේ. අවසාන වශයෙන්, කළමනාකරණ සේවාව වෙත සියලු සන්නිවේදනයන් [ස්වයං අත්සන් කළ SSL සහතිකයක්](https://en.wikipedia.org/wiki/Self-signed_certificate) සමග සංකේතනය කර ඇත.

 එසේම, Outline සේවාදායකය කිසිදු ලොගයක් ගබඩා නොකරයි, එබැවින් එය සම්මුතියකට ලක් වුවද, පරිශීලක දත්ත කිසිවක් අනාවරණය නොවේ. [මෙතැනින්](/about/security-and-privacy) තව දැන ගන්න. Outline 2018 දී [Radically Open Security](https://radicallyopensecurity.com/) සහ [Cure53](https://cure53.de/) විසින් විගණනය කරන ලදි. [මෙහි](/about/security-and-privacy) වාර්තා බලන්න.

**UDP ගමනාගමනය හැසිරවීම**

Outline හට පද්ධතිය පුරා VPN ලෙස ක්‍රියා කිරීමට හැකි වේ, එනම් සියලු UDP ගමනාගමනය Outline සේවාදායකය හරහා උමංගත කර ඇති බවයි.

**DNS ගමනාගමනය**

Outline සියලු DNS සෙවීම් Outline සේවාදායකය හරහා සිදු කරයි, සහ අනෙකුත් සියලු ජාල ක්‍රියාකාරකම් සඳහා භාවිතා කරන එකම සංකේතනය භාවිතයෙන් ඒවා ආරක්ෂා කරයි. ඔබේ DNS විමසුම් Outline සේවාදායකය හරහා Dyn අන්තර්ජාල මාර්ගෝපදේශය, OpenDNS, Cloudflare DNS හෝ Quad9 DNS වෙත යයි. Outline කිසිවිටෙක ඔබේ DNS සෙවීම් ලොග් නොකරයි.
