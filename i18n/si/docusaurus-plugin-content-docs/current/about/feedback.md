Outline වඩා හොඳ කිරීමට උදවු කිරීම ගැන ස්තූතියි! ඔබට ප්‍රතිචාරයක් අවශ්‍ය නම්, නිර්නාමිකව හෝ ඔබේ ඉ-තැපෑලෙන් අපට ප්‍රතිපෝෂණ එවීමට ක්‍රම කිහිපයක් තිබේ:

- **සංවර්ධකයින් සඳහා**: Outline යනු විවෘත මූල මෘදුකාංග වන අතර අපි අපගේ සියලුම කේත [GitHub](https://github.com/Outline-Foundation/?q=outline) මත සංග්‍රාහක කරන්නෙමු. ඔබට GitHub මත හෝ අපගේ [Reddit](https://www.reddit.com/r/outlinevpn/) ප්‍රජාව මත ඔබේ අදහස් බෙදා ගත හැක.
- **පරිශීලකයින් සඳහා**: ඔබට Outline හෝ Outline Manager යෙදුම් හරහා අපට ප්‍රතිපෝෂණ එවිය හැක. ඔබේ ප්‍රතිපෝෂණය කුමක් ගැන දැයි අපට පවසා, විකල්පයක් ලෙස, ඉ-තැපෑලක් එවන්න එවිට අපට ඒ ගැන ඔබට නැවත ලිවිය හැක. අපට ඔබේ බ්‍රව්සරය, මෙහෙයුම් පද්ධතිය, සහ ඔබ සිටින මෘදුකාංග අනුවාදය වැනි දෝෂාවේක්ෂ සඳහා ඔබට උදවු කිරීමට හැකි වන පරිදි, අපි ඔබේ පරිසරය පිළිබඳ පාර-දත්ත කිහිපයක් ද රැස් කරමු.
- **මෙම වෙබ් අඩවිය හරහා**: මෙම වෙබ් අඩවිය තුළ ඔබ දකින ඕනෑම තැනක අප අමතන්න සබැඳිය ක්ලික් කළ හැක.
- **බරපතල ගැටලු**: ඔබට බරපතල ආරක්‍ෂක ගැටලුවක් වාර්තා කිරීමට අවශ්‍ය නම්, security [at] [getoutline.org](https://getoutline.org/) වෙත විස්තර සහිතව ඔබ අපට ඉ-තැපැල් කිරීම අපි අගය කරන්නෙමු.

ඔබේ අදහස් අප සමග බෙදා ගැනීමට කාලය ගත කිරීම ගැන නැවතත් ස්තූතියි.
