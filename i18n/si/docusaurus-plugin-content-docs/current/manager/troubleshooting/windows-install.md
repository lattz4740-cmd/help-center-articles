ඔබට මෙම දෝෂ පණිවිඩය දැකිය හැක: “කණගාටුයි, දළ සටහන් නිසි ලෙස ස්ථාපනය කර නැති බව පෙනේ. එය නැවත ස්ථාපන කිරීමට උත්සාහ කරන්න. එය ක්‍රියා නොකරන්නේ නම්, [ප්‍රතිපෝෂණ ඉදිරිපත් කරන්න](https://support.getoutline.org/s/contactsupport?).”

ඔබ Windows හි Outline භාවිත කරන්නේ නම්, ඉඳහිට, ඔබට අනපේක්ෂිත දෝෂයක් ඇති විය හැක. බොහෝ අවස්ථාවල දී, Outline TAP ඇඩැප්ටරය (ධාවක) මකා දැමීමට අවශ්‍ය වන අතර Outline නැවත ස්ථාපනය කළ යුතු වේ.

ඔබේ Windows මෙහෙයුම් පද්ධති අනුවාදය මත පදනම්ව පියවර වෙනස් විය හැකි නමුත්, TAP ඇඩැප්ටරය සහ Outline කළමනාකරු අස්ථාපනය කර Outline කළමනාකරු යළි ස්ථාපනය කරන්නේ කෙසේ ද යන්න සඳහා පොදු පියවර පහත දැක්වේ.

1. Outline සඳහා TAP ඇඩැප්ටරය අස්ථාපනය කරන්න
   1. උපාංග කළමනාකරු, පසුව ජාල ඇඩැප්ටර වෙත යන්න
   2. “TAP-Windows Adapter V9 ගොනුව හෝ Outline සමග සම්බන්ධ TAP ඇඩැප්ටරය සොයන්න
   3. මෙම ඇඩප්ටරය අස්ථාපනය කරන්න හෝ මකන්න. මෙය ඔබ ස්ථාපනය කර ඇති අනෙකුත් VPN යෙදුම්වලට බලපාන බව මතක තබා ගන්න.
2. Outline Manager අස්ථාපනය කරන්න
   1. වැඩසටහන් සහ විශේෂාංග, පසුව වැඩසටහන අස්ථාපනය කරන්න වෙත යන්න
   2. Outline කළමනාකරු යෙදුම සොයාගෙන Outline කළමනාකරු අස්ථාපනය කරන්න
   3. [Outline කළමනාකරු හි නවතම අනුවාදය බාගත කර](https://getoutline.org/get-started/#step-1) එය ඔබේ Windows උපාංගයෙහි යළි ස්ථාපනය කරන්න. නව ස්ථාපනය ස්වයංක්‍රීයව නව TAP ඇඩප්ටරයක් ​​ස්ථාපනය කළ යුතු ය.

ඔබට තවමත් ගැටලු තිබේ නම්, [සහය සම්බන්‍ධ කර ගන්න](https://support.getoutline.org/s/contactsupport?).
