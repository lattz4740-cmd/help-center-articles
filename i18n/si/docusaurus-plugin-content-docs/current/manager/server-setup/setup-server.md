Outline සේවාදායකයක් පිහිටුවීම Outline භාවිතා කිරීමට හැකි වීමේ පළමු පියවරයි. ඔබට Outline හරහා විවෘත අන්තර්ජාලය සම්බන්ධ කිරීම සඳහා ඔබ හෝ ඔබ විශ්වාස කරන කෙනෙකු ඔබ වෙනුවෙන් සේවාදායකයක් සැකසිය යුතු වේ.

**ඔබ ආරම්භ කිරීමට පෙර**

 ඔබ ඔබේ Outline සේවාදායකය පිහිටුවීම ආරම්භ කිරීමට පෙර, ඔබට කරුණු කිහිපයක් අවශ්‍ය වනු ඇත:

1. DigitalOcean, Amazon Web Services (AWS), හෝ Google Cloud Platform (GCP) වැනි ඔබේම සේවාදායක හෝ Cloud සේවා සපයන්නෙකු වෙත ප්‍රවේශය.

 ඔබට වහාම ක්ලවුඩ් සේවාදායකයක් වෙත ප්‍රවේශය නොමැති නම්, ඔබට ඉහත ලැයිස්තුගත කර ඇති ඒවා ඇතුළුව ඕනෑම සැපයුම්කරුවෙකු සමග පහසුවෙන් ගිණුමක් පිහිටුවිය හැක. ලියාපදිංචි වීමට ඔබට ණය කාඩ්පතක් අවශ්‍ය වනු ඇත.
2. macOS 10.9+, Windows 7.0+ හෝ Linux ධාවනය වන ඩෙස්ක්ටොප් පරිගණකයක්.
3. Outline කළමනාකරු යෙදුම.

**DigitalOcean සමග පිහිටුවන්න**

 අපි ඕනෑම කෙනෙකුට ක්ලික් කිරීම් කිහිපයකින් DigitalOcean මත Outline ස්ථාපනය කිරීම පහසු කළෙමු. ඔබේ පරිගණකයේ Outline Manager බාගත කර ස්ථාපනය කිරීමෙන් පසුව, ඔබට ඔබේ Outline Server වින්‍යාස කිරීමට සහ ස්ථාපනය කිරීමට සරල තිර කිහිපයක් හරහා ඔබට මඟ පෙන්වන DigitalOcean පිහිටුවීම් විකල්පය තෝරා ගත හැක.

**වෙනත් ක්ලවුඩ් සපයන්නෙකු සමග පිහිටුවන්න**

 Outline කළමනාකරු බාගත කර ස්ථාපනය කිරීමෙන් පසුව, ඔබට AWS, GCP, DigitalOcean හෝ වෙනත් සැපයුම්කරුවෙකු සමග අතථ්‍ය යන්ත්‍රයක Outline සේවාදායකයක් ස්ථාපනය කිරීමට තෝරාගත හැක. සෑම පරිසරයක්ම වෙනස් වේ, එබැවින් අපි ඔබ සේවාදායකයක Outline ස්ථාපනය කිරීමට ස්ථාපන ස්ක්‍රිප්ට් ධාවනය කිරීමට පෙර ඔබේ අතථ්‍ය යන්ත්‍රයේ සැකසීම් වින්‍යාස කරන්නේ කෙසේ ද යන්න ඇතුළුව, වඩාත් පොදු ක්ලවුඩ් සපයන්නන් සඳහා Outline Manager පිහිටුවීම් ප්‍රවාහය තුළ උපදෙස් ඇතුළත් කර ඇත.
