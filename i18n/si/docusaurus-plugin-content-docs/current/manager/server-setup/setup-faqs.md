**මට සේවාදායකයක් නොමැතිව Outline භාවිතා කළ හැකි ද?**

 අවාසනාවකට, නැත. Outline මෘදුකාංගය ඔබ, ඔබේ සංවිධානය, හෝ විශ්වාසවන්ත තෙවන පාර්ශ්වයක් විසින් කළමනාකරණය කළත්, සේවාදායකයකට ප්‍රවේශය අවශ්‍ය වේ.

## Outline සේවාදායකයක් පිහිටුවීමට කොපමණ කාලයක් ගනී ද?

බොහෝ අවස්ථාවල දී, විනාඩි 5කට වඩා අඩුයි. ඔබට ඕනෑම ක්ලවුඩ් සේවාදායකයක් මත Outline ස්ථාපනය කළ හැකි නමුත්, අපි DigitalOcean සමග වඩාත් පරිශීලක-හිතකාමී, මාර්ගෝපදේශක ස්ථාපන අත්දැකීමක් ලබා දීමට කටයුතු කළෙමු—එහි දී ඔබට ක්ලික් කිරීම් කිහිපයකින් ස්ක්‍රිප්ට් නොමැතිව ඔබේ සේවාදායකය සැකසිය හැක.

ඔබ AWS, GCP හෝ උසස් සැකසුම තෝරා ගත්තේ නම්, අපි බොහෝ පරිසරයන් හසුරුවන තනි ස්ක්‍රිප්ට් එකකට සේවාදායක ස්ථාපන ක්‍රියාවලිය සරල කර ඇත.

## මට Outline සේවාදායකයක් පිහිටුවිය හැක්කේ කොතැනින් ද?
