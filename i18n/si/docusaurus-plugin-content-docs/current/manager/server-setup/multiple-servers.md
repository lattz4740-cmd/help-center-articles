අතිරේක Outline සේවාදායක පිහිටුවීමට, ඔබේ Outline කළමනාකරු යෙදුමේ වම් පැත්තේ ඇති සංචාලන පැනලයේ “+” නිරූපකය මත ක්ලික් කරන්න. නව සේවාදායකයක් එක් කිරීමට උපදෙස් ඔබ ඔබේ පළමු ස්ථාපනය කළ ආකාරයටම වේ.

- ඔබට තැනීමට හැකි Outline සේවාදායක ගණනේ සීමාවක් අපට නැත.
- ඔබ තනන සෑම Outline සේවාදායකයක් සඳහාම, ඔබට අනුරූප අථත්‍ය යන්ත්‍රයක් අවශ්‍ය වනු ඇත.
- අතිරේක යන්ත්‍ර හෝ බිඳිති තැනීම ඔබේ ක්ලවුඩ් සපයන්නා සමග ඔබේ ගාස්තු වැඩි කළ හැක. ඔබ අපේක්ෂා කළ යුතු දේ දැන ගැනීමට ඔබේ ක්ලවුඩ් සපයන්නා සමග ඔබේ මිල පැකේජය පරීක්ෂා කරන්න.

## DigitalOcean මත අතිරේක Outline සේවාදායකයක් තැනීම

+ නිරූපකය ක්ලික් කර DigitalOcean මත ස්ථාපනය කිරීමට තේරීමෙන් පසු, ඔබ ඔබේ පළමු සේවාදායකය පිහිටුවීමට කළ උපදෙස්ම අනුගමනය කරනු ඇත. එසේම, Outline කළමනාකරු DigitalOcean සමග ඒකාබද්ධ වන බැවින්, ඔබ කිසි විටෙක Outline කළමනාකරු යෙදුම හැර යාමකින් තොරව ඔබට බිඳිති තැනීමට අපට හැකි වේ.

Outline කළමනාකරු හට වරකට සහාය දිය හැක්කේ එක් DigitalOcean ගිණුමක් පමණක් බව සලකන්න. වෙනත් DigitalOcean ගිණුම්වලින් වෙනත් Outline සේවාදායක එක් කිරීමට හෝ තැනීමට අවශ්‍ය නම්, ඔබට ඒවා උසස් වින්‍යාසයක් ලෙස එක් කළ හැක.

## GCP, AWS, හෝ වෙනත් ක්ලවුඩ් සේවා සපයන්නෙකු මත අතිරේක Outline සේවාදායකයක් තැනීම

ඔබ තෝරන ලද ක්ලවුඩ් සපයන්නා සමග නව අතථ්‍ය යන්ත්‍රයක් තැනීමෙන් ආරම්භ කරන්න. ඉන්පසු Outline කළමනාකරු විවෘත කර ඔබට පළමු වරට ඇති ආකාරයටම උසස් ස්ථාපනය සඳහා උපදෙස් සම්පූර්ණ කරන්න.
