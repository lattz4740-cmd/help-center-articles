---

පිහිටුවීමෙන් පසු, සේවාදායක ස්ථානය වෙනස් කළ නොහැක. ඔබේ සේවාදායකය වෙනස් ස්ථානයක සිට ධාවනය කිරීමට, ඔබ ඔබේ Outline සේවාදායකය මකා දමා නව එකක් තැනීමට අවශ්‍ය වේ.

විකල්පයක් ලෙස, ඔබට [ගතික යතුරු](https://developers.google.com/outline/docs/guides/service-providers/dynamic-access-keys) භාවිතයෙන් ඔබේ VPN පිහිටීම වෙනස් කළ හැකි අතර, එමඟින් ඔබට සේවාදායකයන් කරකැවීමට සහ එකම යතුරු තබා ගැනීමට ඉඩ සලසයි. සේවාදායකයන්ගේ ස්ථානය වෙනස් නොවනු ඇත.
