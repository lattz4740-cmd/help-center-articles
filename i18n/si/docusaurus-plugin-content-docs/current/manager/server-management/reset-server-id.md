sidebar_label: "මගේ සේවාදායක ID නැවත සකසන්නේ කෙසේද?"

සේවාදායක ID යනු ඔබ දළ සටහන් සේවාදායකයක් සාදන විට අහඹු ලෙස ජනනය වන සේවාදායක පැත්තේ ID එකකි. සැකසීම් අතුරුමුහුණත තුළ නිර්නාමික මාත්‍රික බෙදා ගැනීමට තේරීමේ දී ඔබට එය සොයා ගත හැක. ඔබට ඔබේ සේවාදායක ID මෙතැනින් සොයාගත හැක: සැකසීම් => පහළට අනුචලනය කරන්න => "නිර්නාමික මිතික බෙදාගන්න" පරීක්ෂා කරන්න.

සේවාදායක ID කාලයත් සමග වාර්තා කරන ලද නිර්නාමික භාවිත සංඛ්‍යාලේඛන එකට සම්බන්ධ කරයි. ඔබට සේවාදායක ID නැවත සකස් කර අලුත් එකක් ලබා ගැනීමට අවශ්‍ය නම්, ඔබට ඔබේ පවතින දළ සටහන් සේවාදායකය නව එකක් සමග ප්‍රතිස්ථාපනය කිරීමට අවශ්‍ය වේ.

ඔබ ඔබේ ක්ලවුඩ් සපයන්නා ලෙස DigitalOcean භාවිත කරන්නේ නම්, ඔබට සැකසීම් වෙත ගොස් Destroy Server තේරීමෙන් ඔබේ සේවාදායකය නැවත සැකසිය හැක. මෙම ක්‍රියාව ආපසු හැරවිය නොහැකි අතර ඔබගේ අක්තපත්‍ර මකනු ඇත. මෙම ක්‍රියාව අනුගමනය කළ වහාම, ඔබ තෝරා ගන්නා ස්ථානයක නව සේවාදායකයක් සෑදීමට ඔබෙන් විමසනු ඇති අතර, නව සේවාදායක ID එකක් ජනනය වනු ඇත.
