ඔබ සැම විටම නවතම Outline තාක්ෂණය ධාවනය වන පරිදි නවතම ආරක්ෂක වැඩි දියුණු කිරීම් සමග Outline සේවාදායක ස්වයංක්‍රීයව යාවත්කාලීන වේ. Outline මෘදුකාංගය අඩංගු ඈඳන රූපය නිතිපතා පරීක්ෂා කර යාවත්කාලීන කරන විවෘත මූලාශ්‍ර පුස්තකාලයක් වන [Watchtower](https://github.com/containrrr/watchtower) භාවිතයෙන් ස්වයංක්‍රීය යාවත්කාලීන ක්‍රියාවලිය සබල කර ඇත.

මීට අමතරව, ඔබ Outline කළමනාකරු භාවිතයෙන් Outline ස්ථාපනය කරන විට, [අවධානයෙන් තොර උත්ශ්‍රේණි කිරීම්](https://wiki.debian.org/UnattendedUpgrades) (Ubuntu) භාවිතයෙන් සේවාදායකයේ මෘදුකාංග ස්වයංක්‍රීයව උත්ශ්‍රේණි කිරීමට සහ අවශ්‍ය විට දී එය නැවත ආරම්භ කිරීමට අපි ක්‍රෝන් කාර්යයක් පිහිටුවන්නෙමු. ධාරකය Outline ධාවනය කිරීමට අමතරව වෙනත් අරමුණු සඳහා භාවිතා කරයි යන උපකල්පනය යටතේ, පවතින වින්‍යාසය සුරැකීමට මෙය උසස් ප්‍රකාරයේ දී සිදු නොවන බව සලකන්න.
