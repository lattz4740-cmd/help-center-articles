බොහෝ ක්ලවුඩ් සපයන්නන් සඳහා, ඔබ භාවිතා කරන විශේෂිත අථත්‍ය යන්ත්‍රය ඉවත් කිරීම තරමක් පහසු වේ.

ඔබ ඔබේ ක්ලවුඩ් සපයන්නා ලෙස DigitalOcean භාවිතා කරන්නේ නම්, ගියර් බොත්තම ක්ලික් කර සේවාදායකය විනාශ කරන්න තේරීමෙන් ඔබට දැනට පවතින අතථ්‍ය යන්ත්‍රය මකා දැමිය හැක. ඉක්බිතිව, ඔබ තෝරා ගන්නා ස්ථානයක නව අථත්‍ය යන්ත්‍රයක් තැනීමට ඔබෙන් විමසනු ඇත.

ඔබ Outline සේවාදායකයක් ඉවත් කළහොත්, එය ස්ථිරවම මකා දමන අතර එහි ප්‍රවේශ යතුරු තවදුරටත් ක්‍රියා නොකරනු ඇත. Outline හරහා පුද්ගලයින්ට ඔවුන්ගේ ප්‍රවේශයට බාධාවක් ඇති කර ගැනීමට ඔබට අවශ්‍ය නැතිනම්, ඔබේ පැරණි මකා දැමීමට පෙර ඔබට [නව Outline සේවාදායකයක් පිහිටුවා](/manager/server-setup/setup-server) එයට ප්‍රවේශය බෙදා ගැනීමට අවශ්‍ය වනු ඇත.
