sidebar_label: "எனது Outline சேவையகத்தை எப்படி நீக்குவது?"
---

பெரும்பாலான கிளவுடு வழங்குநர்களைப் பொறுத்தவரை, நீங்கள் பயன்படுத்தும் குறிப்பிட்ட விர்ச்சுவல் மெஷினை அகற்றுவது மிகவும் எளிது.

கிளவுடு வழங்குநராக DigitalOceanனைப் பயன்படுத்துகிறீர்கள் என்றால் கியர் பட்டனைக் கிளிக் செய்து ‘சேவையகத்தை அழி’ என்பதைத் தேர்ந்தெடுப்பதன் மூலம் உங்கள் தற்போதைய விர்ச்சுவல் மெஷினை நீக்கலாம். அதன்பிறகு உடனடியாக, நீங்கள் தேர்ந்தெடுக்கும் இருப்பிடத்தில் புதிய விர்ச்சுவல் மெஷினை உருவாக்கும்படி கேட்கப்படும்.

நீங்கள் Outline சேவையகத்தை அகற்றினால் அது நிரந்தரமாக நீக்கப்படும். அதன் அணுகல் விசைகளும் வேலை செய்யாது. Outline மூலமான அணுகலில் யாருக்கும் குறுக்கீடு ஏற்படுவதை நீங்கள் விரும்பவில்லை என்றால் பழைய சேவையகத்தை நீக்கும் முன் ஒரு [புதிய Outline சேவையகத்தை அமைத்து,](/manager/server-setup/setup-server) அதற்கான அணுகலைப் பகிர வேண்டும்.
