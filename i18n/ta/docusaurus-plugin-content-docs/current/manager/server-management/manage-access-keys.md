Outline சேவையகத்தை நிறுவியதும், அதைப் பிறர் பயன்படுத்தும் வகையில் பகிரலாம், அவர்களின் அணுகலை நிர்வகிக்கலாம். உங்களிடமிருந்து அழைப்பைப் பெறுபவர்கள், Outline மூலம் தங்களின் இன்டர்நெட் டிராஃபிக்கைப் பாதுகாக்க Outline ஆப்ஸைப் பதிவிறக்கலாம்.

## Outline சேவையகத்திற்கான அணுகலைப் பகிர்தல்
 Outline சேவையகத்தை நிறுவியபிறகு, அணுகல் குறியீடுகளை உருவாக்க சேவையக விவரங்கள் இருக்கும் Outline Manager பக்கத்திற்குத் திருப்பிவிடப்படுவீர்கள். [அணுகல் குறியீடுகள்](/about/terminology) குறித்து மேலும் தெரிந்துகொள்ளுங்கள்.

- குறியீடுகளை உருவாக்குதல்: குறியீடுகளைப் புதிதாக உருவாக்க பக்கத்தின் கீழே உள்ள சிறிய "+" ஐகானைக் கிளிக் செய்யவும்.
- குறியீடுகளைப் பகிர்தல்: ஒவ்வொரு குறியீட்டின் வலதுபுறத்திலும், பகிர்வதற்கான ஐகான் ஒன்று இருக்கும். அதைக் கிளிக் செய்தால் அழைப்புக்கான இணைப்பைப் பெறலாம். அதை நகலெடுத்து, நீங்கள் விரும்பும் மெசேஜிங் ஆப்ஸில் ஒட்டி பிறருக்கு அனுப்பலாம்.

## அம்சக் கோரிக்கை: Outline Manager ஆப்ஸில் இருந்து அணுகலைப் பகிர்தல்
 ஒருவரின் மின்னஞ்சல் முகவரியை Outline Manager ஆப்ஸில் நேரடியாக டைப் செய்து அழைப்பை அனுப்பும் விருப்பத்தைச் சேர்க்கும்படி சேவையக நிர்வாகிகளில் பலர் எங்களிடம் கேட்கிறார்கள்.

எதிர்பாராதவிதமாக, இந்தச் செயல்பாட்டை Outline Managerரில் கொண்டு வருவது சாத்தியமில்லை. எங்கள் பயனர்களின் தனியுரிமை மற்றும் பாதுகாப்பை ஆதரிப்பதே எங்கள் அடிப்படைக் கொள்கைகளில் ஒன்றாகும், அதாவது மின்னஞ்சல் முகவரிகள் அல்லது தொடர்புத் தகவலை எந்த இடத்திலும் சேர்க்கும் வகையில் நாங்கள் இதை வடிவமைக்கவில்லை.

இதனால்தான், இறுதிப் பயனருக்கு அழைப்பை அனுப்ப மின்னஞ்சல், உரையாடல் போன்ற பாதுகாப்பான மெசேஜிங் சேவைகளைப் பயன்படுத்துபடி சேவையக நிர்வாகிகளைக் கேட்டுக்கொள்கிறோம்.

## அணுகல் குறியீடு கிடைத்தபிறகு பயனர் செய்யக்கூடியது என்ன?
1. பயனர் தனது சாதனத்திலிருந்து நிறுவல் இணைப்பைக் கிளிக் செய்வார்
2. அவர்கள் ஏற்கனவே Outline ஆப்ஸை நிறுவவில்லை என்றால், அதை நிறுவும்படி கேட்கப்படுவார்கள்
3. அழைப்பில் உட்பொதிக்கப்பட்ட தனித்துவமான குறியீட்டின் மூலம் உங்கள் Outline சேவையகத்துடன் ஆரம்ப இணைப்பை அவர்கள் நிறுவுவார்கள்
4. உங்கள் Outline சேவையகம் மூலம் தங்களுக்கான இணைய அணுகலை நிர்வகிக்க அவர்கள் இப்போது இணைப்பதற்கான அல்லது துண்டிப்பதற்கான பட்டனைப் பயன்படுத்தலாம்

## உங்கள் Outline சேவையகத்திற்கான அணுகலை அகற்றுதல்
 Outline Managerரில் உள்ள சேவையக விவரங்கள் பக்கத்தில், சேவையகத்தில் உள்ள ஒவ்வொரு குறியீட்டின் வலதுபுறத்திலும் அதை நீக்குவதற்கான விருப்பம் அடங்கிய மெனு காட்டப்படும். அந்தக் குறியீட்டை நீக்கினால் உங்கள் சேவையகத்திற்கான அணுகல் நீக்கப்படும்.
