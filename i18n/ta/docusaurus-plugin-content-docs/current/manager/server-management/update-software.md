sidebar_label: "Outline சர்வர் மென்பொருளை எப்படிப் புதுப்பிப்பது?"
---

சமீபத்திய பாதுகாப்பு மேம்பாடுகளுடன் Outline சேவையகங்கள் தானாகவே புதுப்பிக்கப்படும். இதனால், நீங்கள் எப்போதும் சமீபத்திய Outline தொழில்நுட்பத்தைப் பயன்படுத்தலாம். தானியங்குப் புதுப்பித்தல் செயல்முறை [Watchtower](https://github.com/containrrr/watchtower) என்ற ஓப்பன் சோர்ஸ் லைப்ரரி மூலம் இயக்கப்படுகிறது. இது Outline மென்பொருள் இருக்கும் டாக்கர் படத்தைத் தொடர்ந்து சரிபார்த்துப் புதுப்பிக்கிறது.

கூடுதலாக, Outline Managerரைப் பயன்படுத்தி Outlineனை நிறுவும்போது, [Unattended Upgrades](https://wiki.debian.org/UnattendedUpgrades) (Ubuntu) அம்சத்தைப் பயன்படுத்தி சேவையகத்தில் தானாகவே மென்பொருளை மேம்படுத்தவும் தேவைப்படும்போது மறுதொடக்கம் செய்யவும் நாங்கள் Cron பணியை அமைப்போம். கவனத்திற்கு: Outlineனை இயக்குவதுடன் கூடுதலாக வேறு காரணங்களுக்காகவும் ஹோஸ்ட் பயன்படுத்தப்படுகிறது எனும் அனுமானத்தின்படி, ஏற்கெனவே உள்ள உள்ளமைவைத் தக்கவைப்பதற்காக மேம்பட்ட பயன்முறையில் இது நடக்காது.
