sidebar_label: "Outline சேவையகத்தின் இருப்பிடத்தை எப்படி மாற்றுவது?"
---

சேவையக இருப்பிடத்தை ஒருமுறை அமைத்தபிறகு மாற்ற முடியாது. வேறொரு இருப்பிடத்தில் இருந்து உங்கள் சேவையகத்தை இயக்க, உங்கள் Outline சேவையகத்தை நீக்கிவிட்டு புதிதாக ஒன்றை உருவாக்க வேண்டும்.

மாறாக, [டைனமிக் குறியீடுகளைப்](https://developers.google.com/outline/docs/guides/service-providers/dynamic-access-keys) பயன்படுத்தி VPN இருப்பிடத்தை மாற்றலாம். இதன் மூலம் அதே குறியீடுகளைப் பயன்படுத்திக் கொண்டே சுழற்சி முறையில் சேவையகங்களைப் பயன்படுத்த முடியும். சேவையகங்களின் இருப்பிடம் மாறாது.
