sidebar_label: "எனது சேவையக ஐடியை எப்படி ரீசெட் செய்வது?"
---

சேவையக ஐடி என்பது ஒரு Outline சேவையகத்தை உருவாக்கும்போது சேவையகத் தரப்பில் ரேண்டமாக உருவாக்கப்படும் ஐடியாகும். அமைப்புகள் இடைமுகத்தில் அடையாளம் நீக்கிச் செயலாக்கப்பட்ட அளவீடுகளைப் பகிர்வதைத் தேர்ந்தெடுக்கும்போது அந்த ஐடியைக் கண்டறியலாம். சேவையக ஐடியைக் கண்டறியும் முறை: அமைப்புகள் என்பதற்குச் சென்று => கீழ்ப்பகுதிக்கு நகர்த்தி => "அடையாளம் நீக்கிச் செயலாக்கப்பட்ட அளவீடுகளைப் பகிர்" என்பதைத் தேர்வுசெய்யவும்.

குறிப்பிட்ட காலகட்டத்திற்கான அறிக்கைகளில் உள்ள அடையாளம் நீக்கிச் செயல்படுத்தப்பட்ட பயன்பாட்டுப் புள்ளிவிவரங்களுடன் சேவையக ஐடி ஒன்றாக இணைக்கப்பட்டுள்ளது. சேவையக ஐடியை ரீசெட் செய்து புதிய ஐடியைப் பெற விரும்பினால், ஏற்கெனவே உள்ள Outline சேவையகத்திற்குப் பதிலாகப் புதிய ஐடியைச் சேர்க்க வேண்டும்.

கிளவுடு வழங்குநராக DigitalOceanனைப் பயன்படுத்தினால் அமைப்புகளுக்குச் சென்று ‘சேவையகத்தை அழி’ என்பதைத் தேர்ந்தெடுப்பதன் முலம் உங்கள் சேவையகத்தை ரீசெட் செய்யலாம். இந்தச் செயலை மீண்டும் மாற்ற முடியாது என்பதுடன் உங்கள் அனுமதிச் சான்றுகளும் அழிக்கப்பட்டுவிடும். இந்தச் செயலுக்குப் பிறகு உடனடியாக, நீங்கள் தேர்வுசெய்யும் இருப்பிடத்தில் புதிய சேவையகத்தை உருவாக்கும்படி கேட்கப்படும். புதிய சேவையக ஐடி உருவாக்கப்படும்.
