கூடுதல் Outline சேவையகங்களை அமைக்க, உங்கள் Outline Manager ஆப்ஸின் இடது பக்கத்தில் உள்ள வழிகாட்டல் பேனலில் "+" ஐகானைக் கிளிக் செய்யவும். புதிய சேவையகத்தைச் சேர்ப்பதற்கான வழிமுறைகள் நீங்கள் முதலில் நிறுவியதைப் போலவே இருக்கும்.

- நீங்கள் எத்தனை Outline சேவையகங்களை உருவாக்கலாம் என்பதற்கு வரம்பு எதுவும் இல்லை.
- நீங்கள் உருவாக்கும் ஒவ்வொரு Outline சேவையகத்திற்கும் ஒரு விர்ச்சுவல் மெஷின் தேவைப்படும்.
- கூடுதல் மெஷின்கள் அல்லது ட்ராப்லெட்களை உருவாக்கினால் உங்கள் கிளவுட் வழங்குநருக்குச் செலுத்த வேண்டிய கட்டணம் அதிகமாகலாம். உங்கள் கிளவுட் வழங்குநருடன் உங்கள் விலையிடல் தொகுப்பைச் சரிபார்த்து, என்ன எதிர்பார்க்கலாம் என்பதை உறுதிப்படுத்திக்கொள்ளவும்.

## DigitalOceanனில் கூடுதல் Outline சேவையகத்தை உருவாக்குதல்

+ ஐகானைக் கிளிக் செய்து, DigitalOceanனில் நிறுவுவதைத் தேர்ந்தெடுத்த பிறகு, உங்கள் முதல் சேவையகத்தை அமைக்க நீங்கள் பின்பற்றிய அதே வழிமுறைகளைப் பின்பற்ற வேண்டும். அதுமட்டுமின்றி DigitalOcean உடன் Outline Manager ஒருங்கிணைப்பட்டுள்ளதால் உங்களுக்காக ட்ராப்லெட்டை நாங்கள் உருவாக்க முடியும். நீங்கள் Outline Manager ஆப்ஸை விட்டு வெளியேற வேண்டியதில்லை.

Outline Manager ஒரு நேரத்தில் ஒரு DigitalOcean கணக்கை மட்டுமே ஆதரிக்க முடியும் என்பதை நினைவில் கொள்ளவும். மற்ற DigitalOcean கணக்குகளிலிருந்து மற்றொரு Outline சேவையகத்தைச் சேர்க்க அல்லது உருவாக்க விரும்பினால் அவற்றை மேம்பட்ட உள்ளமைவாகச் சேர்க்கலாம்.

## GCP, AWS அல்லது மற்றொரு கிளவுட் சேவை வழங்குநரில் கூடுதல் Outline சேவையகத்தை உருவாக்குதல்

நீங்கள் தேர்ந்தெடுத்த கிளவுட் வழங்குநருடன் புதிய விர்ச்சுவல் மெஷினை உருவாக்குவதன் மூலம் தொடங்கவும். பின்னர் Outline Managerரைத் திறந்து, மேம்பட்ட நிறுவலுக்கான வழிமுறைகளை நீங்கள் முதல் முறையாகப் பெறுவதைப் போலவே முடிக்கவும்.
