Outline சேவையகத்தை அமைப்பது என்பது Outlineனைப் பயன்படுத்துவதற்கான முதல் படியாகும். திறந்த இணையத்தை Outline மூலம் அணுக, நீங்களோ நீங்கள் நம்பும் ஒருவரோ உங்களுக்காக ஒரு சேவையகத்தை அமைக்க வேண்டும்.

## தொடங்கும் முன்பு
 Outline சேவையகத்தை அமைக்கத் தொடங்கும் முன்பு, உங்களுக்குச் சில விஷயங்கள் தேவைப்படும்:

1. DigitalOcean, Amazon Web Services (AWS), Google Cloud Platform (GCP) போன்ற நீங்கள் பயன்படுத்தும் சேவையகங்கள் அல்லது கிளவுடு சேவை வழங்குநருக்கான அணுகல்.

 உங்களிடம் உடனடியாகக் கிளவுடு சேவையகத்திற்கான அணுகல் இல்லையென்றால், மேலே குறிப்பிடப்பட்டுள்ள வழங்குநர்கள் போன்ற ஒரு வழங்குநரின் மூலம் எளிதாகக் கணக்கை அமைக்கலாம். பதிவு செய்ய அநேகமாக உங்களுக்குக் கிரெடிட் கார்டு விவரங்கள் தேவைப்படும்.
2. macOS 10.9+, Windows 7.0+ அல்லது Linux தளத்தில் இயங்கும் ஒரு டெஸ்க்டாப் கம்ப்யூட்டர்.
3. Outline Manager ஆப்ஸ்.

## DigitalOcean ஆப்ஸ் மூலம் அமைத்தல்
 யார் வேண்டுமானாலும் சில கிளிக்குகளில் DigitalOceanனில் Outlineனை எளிதாக நிறுவலாம். உங்கள் கம்ப்யூட்டரில் Outline Managerரைப் பதிவிறக்கி நிறுவியபிறகு, DigitalOcean அமைவு விருப்பத்தை நீங்கள் தேர்ந்தெடுக்கலாம். சில எளிய வழிமுறைகள் மூலம் உங்கள் Outline சேவையகத்தை உள்ளமைக்கவும் நிறுவவும் இது உங்களுக்கு வழிகாட்டும்.

## வேறொரு கிளவுடு வழங்குநர் மூலம் அமைத்தல்
 Outline Managerரைப் பதிவிறக்கி நிறுவியபிறகு, AWS, GCP, DigitalOcean அல்லது வேறொரு வழங்குநரின் மூலம் விர்ச்சுவல் மெஷினில் Outline சேவையகத்தை நிறுவத் தேர்ந்தெடுக்கலாம். ஒவ்வொரு சூழலும் வித்தியாசமானது, எனவே சேவையகத்தில் Outlineனை நிறுவுவதற்காக நிறுவல் ஸ்கிரிப்டை இயக்கும் முன், பொதுவான கிளவுடு வழங்குநர்களுக்கான வழிமுறைகளையும் Outline Manager அமைவுச் செயல்முறையில் சேர்த்துள்ளோம். உதாரணத்திற்கு, உங்கள் விர்ச்சுவல் மெஷினில் அமைப்புகளை எப்படி உள்ளமைப்பது என்பதற்கான வழிமுறைகள்.
