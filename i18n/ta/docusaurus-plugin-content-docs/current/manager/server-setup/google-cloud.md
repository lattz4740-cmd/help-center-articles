## அறிமுகம்

Google Cloudல் இயங்கும் சேவையகத்தில் Outline சேவையகத்தைத் தானாக உள்ளமைக்க உதவும் அம்சம் Outline Managerரில் சேர்க்கப்பட்டுள்ளது. இந்த அம்சத்தைப் பயன்படுத்தத் தேர்வுசெய்தால், உங்கள் Google கணக்கில் உள்நுழையும்படி Outline Manager உங்களிடம் கேட்கும். உள்நுழைவதன் மூலம், உங்கள் Google Cloud கணக்கை உள்ளமைக்கும் நோக்கங்களுக்காக உங்கள் சாதனத்தில் Outline Managerரை நிறுவுவதற்கான குறிப்பிட்ட [OAuth](https://developers.google.com/identity/protocols/oauth2) அனுமதிகள் அதற்கு வழங்கப்படும்.

 இந்த அனுமதிகளை நீங்கள் வழங்க விரும்பவில்லை என்றால், Google Cloud Platformமில் Outlineனை இயக்க, Outline Managerரில் உள்ள மேம்பட்ட அமைவு வழிமுறைகளைப் பின்பற்றலாம்.

## வழங்கப்படும் அனுமதிகள்

தானியங்கு அமைவை வழங்க, Outline Managerக்கு உங்கள் Google கணக்கிலிருந்து பின்வரும் அனுமதிகள் தேவைப்படுகின்றன.

## Google Cloud Platform

- உங்கள் Google Compute Engine ஆதாரங்களைக் கண்டு நிர்வகிக்கலாம்
- Google Cloud சேவைகள் எல்லாவற்றிலும் உங்கள் தரவைப் பார்த்தல், உங்கள் Google கணக்கின் மின்னஞ்சல் முகவரியைப் பார்த்தல்

## அடிப்படைக் கணக்குத் தகவல்

- உங்கள் முதன்மை Google கணக்கின் மின்னஞ்சல் முகவரியைப் பார்த்தல்
- Googleளில் உள்ள உங்கள் தனிப்பட்ட தகவலுடன் உங்களைத் தொடர்புபடுத்துதல்

## கூடுதல் அணுகல்

- உங்கள் Cloud Platform திட்டப்பணிகளை நிர்வகித்தல்
- உங்கள் Google Cloud Platform பில்லிங் கணக்குகளைப் பார்த்தல், நிர்வகித்தல்
- உங்கள் Google API சேவை உள்ளமைவை நிர்வகித்தல்

உங்கள் Outline சேவையகங்களை நிர்வகிப்பதற்கான மேம்பட்ட வசதிகளை நாங்கள் வழங்க இந்த அனுமதிகள் உதவுகின்றன:

- சரியான பில்லிங் கணக்கைத் தேர்ந்தெடுக்க உங்களை அனுமதிக்கிறது
- உங்கள் Outline சேவையகங்களை ஒழுங்கமைக்க புதிய திட்டப்பணியை உருவாக்குதல்
- கிடைக்கக்கூடிய தரவு மையங்களைப் பட்டியலிடுதல்
- Outlineனை இயக்கப் புதிய விர்ச்சுவல் மெஷின்களை உருவாக்குதல்
- Outlineனில் புதிய விர்ச்சுவல் மெஷினை உள்ளமைத்தல்

## அனுமதிகளைத் திரும்பப் பெறுதல்

[எனது கணக்கு](https://myaccount.google.com/permissions) பக்கத்திற்குச் சென்று Outline Managerருக்கான Google Cloud Platform அணுகலை நீங்கள் திரும்பப் பெறலாம். நீங்கள் அணுகலைத் திரும்பப் பெற்றால், தானியங்கு அமைவின் மூலம் நீங்கள் உருவாக்கிய எந்தச் சேவையகங்களும் தொடர்ந்து இயங்கும், ஆனால் Outline Managerரில் தோன்றாது. அவற்றுக்கான அணுகலை மீட்டெடுக்க, தானியங்கு அமைவுச் செயல்முறையைத் தொடங்குவதன் மூலம் Google Cloud Platform உடன் அவற்றை மீண்டும் இணைக்கவும்.

## Outline திட்டப்பணி ஒழுங்கமைப்பு

உங்கள் Outline சேவையகங்களை ஒழுங்கமைக்க ஓர் ஒற்றை [Google Cloud திட்டப்பணியை](https://cloud.google.com/resource-manager/docs/creating-managing-projects) Google Cloud தானியங்கு அமைவு பயன்படுத்துகிறது. தானியங்கு அமைவை முதலில் பயன்படுத்தும் போது, திட்டப்பணி உருவாக்கப்படுகிறது. இது "Outline-" எனத் தொடங்கி ரேண்டமான எழுத்துகளைக் கொண்ட திட்டப்பணி ஐடியைக் கொண்டிருக்கும். நீங்கள் விரும்பினால், திட்டப்பணியை உருவாக்கும் போது அதற்கு வேறொரு திட்டப்பணி ஐடியைக் கொடுக்கலாம். திட்டப்பணிக்கு "Outline சேவையகங்கள்" என்று பெயரிடப்படும்.

## பில்லிங் கணக்கு

கட்டணத் தகவலை வரையறுக்கக் கூடிய இணைக்கப்பட்ட “பில்லிங் கணக்கு” Google Cloud திட்டப்பணிகளுக்குத் தேவை. நீங்கள் முதலில் Google கிளவுட் தானியங்கு அமைவைப் பயன்படுத்தும்போது, உங்கள் Outline சேவையகங்களுடன் இணைக்க பில்லிங் கணக்கை வழங்கும்படி கேட்கப்படுவீர்கள். சில நேரங்களில் பில்லிங் கணக்கில் சிக்கல் இருப்பதால், சேவையகம் இயங்குவதை நிறுத்திவிடும். இந்தச் சூழலில், நீங்கள் [Google Cloud Consoleலில்](https://console.cloud.google.com/getting-started) உள்நுழைந்து, Outline உடன் தொடர்புடைய Google Cloud திட்டப்பணியை ("Outline சேவையகங்கள்" எனப் பெயரிடப்பட்டது) கண்டறிந்து, பில்லிங் அமைப்புகளை மாற்ற வேண்டும்.

## சேவையங்களை அழித்தல்

தானியங்கு அமைவைப் பயன்படுத்தி உருவாக்கப்பட்ட உங்கள் சேவையகங்களை அழிக்க விரும்பினால், Outline Managerரில் இருந்து அதைச் செய்வதுதான் மிகவும் எளிதான வழி. [எனினும், உங்கள் சேவையகங்களை நீங்களே அழிக்க விரும்பினால்,](https://console.cloud.google.com/getting-started)Google Cloud Consoleலில் உள்நுழைந்து, ஆரம்ப அமைவின்போது உருவாக்கப்பட்ட திட்டப்பணியை ("Outline சேவையகங்கள்" எனப் பெயரிடப்பட்டது) கண்டறிந்து அங்குள்ள தகவல்களை நீக்கலாம் அல்லது திட்டப்பணியை முடக்கலாம்.
