---

நீங்கள் VPNனை நிர்வகிக்கும் சேவையக நிர்வாகியாக இருந்தாலும் திறந்த இணையத்தை அணுக Outlineனைப் பயன்படுத்துபவராக இருந்தாலும் எல்லோருக்கும் Outline மென்பொருள் இலவசம்.

 இருப்பினும், Outline இயங்க ஏதேனும் ஒரு கிளவுடு சேவையகத்தை அது அணுக வேண்டும். ஏற்கெனவே ஒரு சேவையகத்திற்கான அணுகலை வைத்திருக்கும் சேவையக நிர்வாகிகள் கூடுதல் செலவில்லாமல் Outlineனை நிறுவலாம். சேவையகத்திற்கான அணுகல் இல்லாதவர்கள், மாதத்திற்கு $5 USD கட்டணத்தில் [DigitalOcean](https://www.digitalocean.com/), Amazon Web Services போன்ற கிளவுடு சேவை வழங்குநரிடமிருந்து 1 டெராபைட் தரவுப் பரிமாற்ற வரம்புக்கு அணுகலைப் பெறலாம். ஒரே சேவையகத்தை நூற்றுக்கணக்கான பயனர்களுக்கு வழங்க இது போதுமானது.

 உங்களுக்கு விருப்பமான கிளவுடு வழங்குநரின் மூலம் Outlineனை இயக்க எவ்வளவு செலவாகும் என்பதைத் தீர்மானிக்க எப்படிக் கணக்கிடுவது என்பதற்கான எடுத்துக்காட்டு:

| *ஒரு பயனருக்கு சராசரியாக 5 ஜிகாபைட்டுகள் தரவுப் பரிமாற்றத்தைப் பயன்படுத்தினால், ஒரு மாதத்திற்கு $5 USD திட்டத்தை ஒரே நேரத்தில் சுமார் 200 பயனர்கள் பயன்படுத்தலாம். ஒரு பயனருக்கு மாதத்திற்கு 2.5 சென்ட்டுகள் மட்டுமே செலவாகும். கவனத்திற்கு: பயனர்கள் மேற்கொள்ளும் குறைவான அல்லது அதிகமான இணைய வேகச் செயல்பாடுகளைப் பொறுத்து ஒரு பயனருக்கு ஒரு மாதத்திற்குப் பயன்படுத்தப்படும் தரவுப் பரிமாற்றம் பெரிதும் மாறுபடும். ஆனால், பெரும்பாலான கிளவுடு வழங்குநர்கள் டிராஃபிக்கின் அதிகரிப்புக்கு ஈடுகொடுக்கும் வகையிலான சேவையை வழங்குகின்றனர்.* |
| --- |

உண்மையில், Outlineனைப் பயன்படுத்தும்போது Jigsaw, Google ஆகிய இரு தரப்புக்கும் உங்கள் அடையாளம் வெளிப்படுத்தப்படாது. உங்கள் அடையாளத்தையோ டிராஃபிக்கையோ நாங்கள் கண்காணிக்கவில்லை, வருமானம் ஈட்டும் திட்டமும் எதுவும் இல்லை. மாறாக, எங்கள் பயனர்களுக்கு எந்தக் கட்டணமும் இல்லாமல் மென்பொருளை வழங்க முடியும் என்பதை உறுதிசெய்ய, எங்கள் ஓப்பன் சோர்ஸ் சமூகத்துடன் இணைந்து செயல்படுகிறோம். நாங்கள் சேகரிக்கும் தரவு குறித்து [இங்கே](/about/data-collection) மேலும் தெரிந்துகொள்ளுங்கள்.
