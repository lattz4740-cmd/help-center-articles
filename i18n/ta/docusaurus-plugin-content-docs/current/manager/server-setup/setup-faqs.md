## சேவையகம் இல்லாமலே Outlineனைப் பயன்படுத்த முடியுமா?
 முடியாது. Outline மென்பொருளுக்கு ஏதேனும் ஒரு சேவையகத்திற்கான அணுகல் தேவை. நீங்களோ உங்கள் நிறுவனமோ நீங்கள் நம்பும் மூன்றாம் தரப்பினரோ நிர்வகிக்கும் சேவையகமாக அது இருக்கலாம்.

## Outline சேவையகத்தை அமைக்க எவ்வளவு நேரம் ஆகும்?

பெரும்பாலான சந்தர்ப்பங்களில் 5 நிமிடங்களுக்கும் குறைவாகவே ஆகும். எந்தவொரு கிளவுடு சேவையகத்திலும் Outlineனை நிறுவலாம். எனினும், நாங்கள் DigitalOcean உடன் இணைந்து பயனருக்கேற்ற, வழிகாட்டப்பட்ட நிறுவல் அனுபவத்தை வழங்குகிறோம். ஸ்கிரிப்ட்டுகள் இல்லாமலேயே சில கிளிக்குகளில் அங்கு உங்கள் சேவையகத்தை நீங்கள் அமைக்கலாம்.

நீங்கள் AWS, GCP அல்லது மேம்பட்ட அமைவைத் தேர்வுசெய்தால், பெரும்பாலான சூழல்களைக் கையாளும் ஒரே ஸ்கிரிப்டாகச் சேவையக நிறுவல் செயல்முறையை எளிதாக்கியுள்ளோம்.

## Outline சேவையகத்தை நான் எங்கே அமைக்கலாம்?

பெரும்பாலான கிளவுடு வழங்குநர்கள் செயல்படும் இடங்களில் நீங்கள் Outline சேவையகத்தை அமைக்கலாம்.

ஆம்ஸ்டர்டாம், டொராண்டோ, சான் பிரான்சிஸ்கோ, சிங்கப்பூர் போன்ற பல இடங்களில் சேவையகங்களை வைத்திருப்பதால், DigitalOceanனில் அமைப்பதே எளிதான வழி. வேறொரு கிளவுடு வழங்குநரில் அல்லது உங்கள் சொந்த உள்கட்டமைப்பில் நிறுவ விரும்பினால், Outline Manager ஆப்ஸில் 'மேம்பட்ட பயன்முறை' என்பதைத் தேர்வுசெய்து, அமைவு ஸ்கிரிப்டைப் பயன்படுத்தி நிறுவல் வழிமுறைகளைப் பின்பற்றலாம்.

## எனது Outline சேவையகத்தை நான் எங்கே அமைக்க வேண்டும்?

1. உங்கள் Outline சேவையகத்திற்கான இடத்தைத் தேர்ந்தெடுக்கும்போது நீங்கள் கவனிக்க வேண்டியவை:
2. Outline சேவையக இருப்பிடம் பயனர்கள் இணையத்தைப் பயன்படுத்தும் அனுபவத்தைப் பாதிக்கிறது. எடுத்துக்காட்டாக, சேவையகம் ஆம்ஸ்டர்டாமில் அமைந்திருந்தால், இந்த சேவையகத்தை அணுகும் பயனர் நெதர்லாந்தில் உள்ளதைப் போல இணையத்தை அனுபவிப்பார். சில இணையதளங்கள் டச்சு மொழியிலும் காட்டப்படலாம். பொதுவாக, இணையதளத்தில் உள்ள மொழித் தேர்வியைப் பயன்படுத்தி உள்ளூர் மொழியை நீங்கள் மாற்றலாம்.
3. உங்கள் பயனர்களுக்கும் Outline சேவையகத்திற்கும் இடையிலான தூரம் உங்கள் வேகங்களைப் பாதிக்கலாம். பொதுவாக, Outline பயனர்களுக்கும் சேவையகத்திற்கும் இடையிலான உண்மையான தூரம் பயனர்களின் இணைய வேகத்தைப் பாதிக்கலாம். பெரும்பாலான சந்தர்ப்பங்களில், நீங்கள் எதிர்பார்க்கும் பயனர்கள் இருக்கும் இடத்திற்கு மிக அருகில் உள்ள சேவையக இருப்பிடத்தை நீங்கள் தேர்வு செய்யலாம். ஆனாலும், உங்கள் நாடு அல்லது பிராந்தியத்துடன் எந்த இன்டர்நெட் கேபிள்கள் இணைக்கப்பட்டுள்ளன என்பதைத் தெரிந்துகொள்ள, [நீர்மூழ்கிக் கேபிள் வரைபடத்தைப்](https://www.submarinecablemap.com/) பார்க்கலாம்.
4. உங்கள் VPN சேவையகம் எங்குள்ளது என்பது சட்டக் கட்டமைப்பைப் பாதிக்கலாம். Outline மென்பொருள் உங்கள் டிராஃபிக்கைப் பதிவு செய்யாது என்பதை நினைவில் கொள்ளவும். [Outline பயன்படுத்தும்போதான பாதுகாப்பு மற்றும் தனியுரிமை](/about/security-and-privacy) குறித்து மேலும் தெரிந்துகொள்ளுங்கள்.
