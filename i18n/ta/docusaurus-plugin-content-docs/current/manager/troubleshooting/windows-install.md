---

இந்தப் பிழைச் செய்தியை நீங்கள் பார்க்கலாம்: “மன்னிக்கவும், Outline சரியாக நிறுவப்படாதது போல் தெரிகிறது. மீண்டும் நிறுவ முயலவும். அப்போதும் பிழை ஏற்பட்டால் [கருத்தைச் சமர்ப்பிக்கவும்](/about/feedback).”

நீங்கள் Windowsஸில் Outlineனைப் பயன்படுத்தினால், எதிர்பாராத பிழையை எப்போதாவது சந்திக்க நேரிடலாம். பெரும்பாலான சந்தர்ப்பங்களில், Outline TAP அடாப்டரை (டிரைவர்) நீக்கிவிட்டு Outlineனை மீண்டும் நிறுவ வேண்டியிருக்கும்.

உங்கள் Windows ஆப்ரேட்டிங் சிஸ்டத்தின் பதிப்பைப் பொறுத்து வழிமுறைகள் மாறுபடலாம். ஆனாலும், TAP அடாப்டர், Outline Manager ஆகியவற்றை நிறுவல் நீக்கிவிட்டு Outline Managerரை மீண்டும் நிறுவுவதற்கான பொதுவான வழிமுறைகள் கீழே கொடுக்கப்பட்டுள்ளன.

1. Outline Managerருக்கான TAP அடாப்டரை நிறுவல் நீக்குதல்
   1. சாதன நிர்வாகிகள் என்பதற்குச் சென்று, நெட்வொர்க் அடாப்டர்கள் என்பதற்குச் செல்லவும்
   2. "TAP-Windows Adapter V9" ஃபைல் அல்லது Outlineனுடன் தொடர்புடைய TAP அடாப்டரைக் கண்டறியவும்
   3. இந்த அடாப்டரை நிறுவல் நீக்கவும் அல்லது நீக்கவும். கவனத்திற்கு: இது நீங்கள் நிறுவியுள்ள பிற VPN ஆப்ஸைப் பாதிக்கலாம்.
2. Outline Managerரை நிறுவல் நீக்குதல்
   1. நிரல்களும் அம்சங்களும் என்பதற்குச் சென்று, நிரலை நிறுவல் நீக்கு என்பதற்குச் செல்லவும்
   2. Outline Manager ஆப்ஸைக் கண்டறிந்து அதை நிறுவல் நீக்கவும்
   3. [Outline Managerரின் சமீபத்திய பதிப்பைப் பதிவிறக்கவும்](https://getoutline.org/get-started/#step-1), அதை உங்கள் Windows சாதனத்தில் மீண்டும் நிறுவவும். புதிய நிறுவல் செயல்முறை தானாகவே புதிய TAP அடாப்டரை நிறுவும்.

சிக்கல் தொடர்ந்தால் [உதவி மையத்தைத்](/about/feedback) தொடர்புகொள்ளுங்கள்.
