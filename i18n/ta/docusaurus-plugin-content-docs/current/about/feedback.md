Outlineனைச் சிறப்பாக்க உதவுவதற்கு நன்றி! அடையாளத்தை வெளிப்படுத்தாமலோ பதிலைப் பெறுவதற்காக உங்கள் மின்னஞ்சல் முகவரியைச் சேர்த்தோ எங்களுக்குக் கருத்தை அனுப்புவதற்கான சில வழிகள்:

- **டெவெலப்பர்களுக்கு**: Outline என்பது ஓப்பன் சோர்ஸ் மென்பொருளாகும், எங்கள் குறியீடு முழுவதையும் [GitHubல்](https://github.com/OutlineFoundation/?q=outline) ஹோஸ்ட் செய்கிறோம். உங்கள் யோசனைகளை GitHubல் அல்லது எங்களது [Reddit](https://www.reddit.com/r/outlinevpn/) சமூகத்தில் பகிரலாம்.
- **பயனர்களுக்கு**: Outline அல்லது Outline Manager ஆப்ஸ் மூலம் எங்களுக்கு நீங்கள் கருத்துகளை அனுப்பலாம். உங்கள் கருத்து என்னவென்று சொல்லுங்கள். எங்களிடமிருந்து பதிலைப் பெற விரும்பினால் மின்னஞ்சல் முகவரியை வழங்குங்கள். உங்கள் சூழல் குறித்த சில தரவுத்தகவலையும் நாங்கள் சேகரிப்போம். அதாவது, உங்கள் பிரவுசர், ஆப்ரேட்டிங் சிஸ்டம், மென்பொருள் பதிப்பு போன்றவை. இதனால், பிழையறிந்து திருத்த உங்களுக்கு எங்களால் உதவ முடியும்.
- **இந்தத் தளத்தின் மூலம்**: இந்தத் தளத்தில் ‘எங்களைத் தொடர்புகொள்க’ என்ற இணைப்பை நீங்கள் எங்கு பார்த்தாலும் அதைக் கிளிக் செய்யலாம்.
- **தீவிரமான சிக்கல்கள்**: தீவிரமான பாதுகாப்புச் சிக்கலைப் புகாரளிக்க விரும்பினால், விவரங்களை security [at] [getoutline.org](https://getoutline.org/) என்ற முகவரிக்கு மின்னஞ்சல் அனுப்பும்படி கேட்டுக்கொள்கிறோம்.

உங்கள் கருத்துகளை எங்களுடன் பகிர்ந்துகொள்ள நேரம் ஒதுக்குவதற்கு மீண்டும் நன்றி.
