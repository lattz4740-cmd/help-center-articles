## VPN என்றால் என்ன?
 விர்ச்சுவல் பிரைவேட் நெட்வொர்க் (VPN) என்பது உங்கள் சாதனங்களுக்கும் ஹோஸ்ட் சேவையகத்திற்கும் இடையிலான தனிப்பட்ட இணைப்பாகும். VPNனைப் பயன்படுத்தும்போது உங்கள் டிராஃபிக் இணையச் சேவை வழங்குநரிடமிருந்து மறைக்கப்படுகிறது. பின்வரும் சூழல்களில் நீங்கள் VPNனைப் பயன்படுத்த விரும்பலாம்:

- பொது வைஃபை நெட்வொர்க்கைப் பயன்படுத்தும்போது உங்கள் தரவைப் பாதுகாத்தல்
- உங்கள் இணையச் சேவை வழங்குநரிடமிருந்தும் அரசாங்க அமைப்புகளிடமிருந்தும் உங்கள் பிரவுசிங் தரவைத் தனிப்பட்டதாக வைத்திருத்தல்
- உலகெங்கும் உள்ள பல்வேறு ஆதாரங்களில் இருந்து தணிக்கை செய்யப்படாத உள்ளடக்கத்தைப் பயன்படுத்துதல்

## வழக்கமான VPNகளில் இருந்து Outline எப்படி வேறுபடுகிறது?
 பொதுவான பாதுகாப்பு நெறிமுறைகள் மற்றும்/அல்லது டிராஃபிக் அளவு பேட்டர்ன்களைக் கண்டறிவதன் மூலம் இணைய வழங்குநர்களால் வழக்கமான VPNகளை எளிதில் கண்டறிந்து தடுக்க முடியும். வழக்கமான VPNகளைவிட Outline மிகவும் வலுவானது. ஏனெனில், கண்டறியப்படுவதைக் கடினமாக்கும் நெறிமுறையைப் பயன்படுத்தி அது கட்டமைக்கப்பட்டுள்ளது. எனவே, அதைத் தடுப்பதும் கடினம். நெட்வொர்க் அடிப்படையிலான தடுப்பு, IP தடுப்பு போன்ற மேம்பட்ட தணிக்கை முறைகளை Outlineனால் எதிர்கொள்ள முடியும்.

## Outline சேவையகம் என்றால் என்ன?
 அனுமதிக்கப்படும் பயனர்கள் இணையும் VPNனை Outline சேவையகம் இயக்குகிறது. புதிய நெட்வொர்க்கை உருவாக்குகிறீர்கள் என்றால் உங்களுக்குச் சொந்தமான ஒரு பாதுகாப்பான சேவையகம் இருந்தால் அதை உங்கள் Outline சேவையகமாகப் பயன்படுத்தலாம். இல்லையென்றால் இது போன்ற கிளவுடு சேவை வழங்குநர்களைப் பயன்படுத்தலாம்:

- DigitalOcean
- Google Cloud Platform (GCP)
- Amazon Web Services (AWS)

Outline Managerரில் உங்கள் சேவையகத்தை அமைப்பீர்கள்.

## சேவை நிர்வாகி என்றால் என்ன? {#servicemanager}
 சேவை நிர்வாகி என்பவர் Outline சேவையகத்தை அமைப்பதற்கும் அணுகல் குறியீடுகளைப் பயனர்களுடன் பகிர்வதற்கும் பொறுப்பாவார். பொதுவாக, சேவை நிர்வாகிதான் சேவையகப் பயன்பாட்டின் செலவிற்குப் பொறுப்பாவார்.

## Outline Manager என்றால் என்ன?
 Outline Manager என்பது Outline சேவையகத்தை அமைக்கவும் [அணுகல் குறியீடுகளை](#accesskey) உருவாக்கவும், ஒவ்வொரு குறியீட்டையும் பயன்படுத்துவதற்கான தரவு வரம்புகளை அமைக்கவும் சேவை நிர்வாகியை அனுமதிக்கின்ற டெஸ்க்டாப் ஆப்ஸ் ஆகும். Outline Managerரின் சமீபத்திய பதிப்பை[இங்கே](https://getoutline.org/get-started/#step-3) அல்லது[இங்கே](https://www.reddit.com/r/outlinevpn/wiki/index/download_links/) பதிவிறக்கலாம்.

## Outline Client என்றால் என்ன?
 Outline Client என்பது அணுகல் குறியீட்டின் மூலம் Outline சேவையகத்துடன் இணைக்கவும் VPNனை அணுகவும் உங்களை அனுமதிக்கும் ஆப்ஸாகும். இதை டெஸ்க்டாப்பிலும் மொபைலிலும் பயன்படுத்தலாம். Outline Clientடின் சமீபத்திய பதிப்பை[இங்கே](https://getoutline.org/get-started/#step-3) அல்லது[இங்கே](https://www.reddit.com/r/outlinevpn/wiki/index/download_links/) பதிவிறக்கலாம்.

## தரவு வரம்புகள் என்றால் என்ன?
 அணுகல் குறியீடுகளுக்கான 30 நாள் டிரெய்லிங் தரவு வரம்பை அமைக்க சேவை நிர்வாகிகளை Outline Manager அனுமதிக்கிறது. அதிகப்படியான பயன்பாட்டைத் தடுக்கவும், உங்கள் செலவுகளைக் கணிக்கக்கூடியதாக வைத்திருக்கவும் இது உதவுகிறது. ஒவ்வொரு குறியீட்டுக்கும் பொருந்தக்கூடிய இயல்பான வரம்பைச் சேவை நிர்வாகிகள் அமைக்கலாம். மேலும் இயல்பு வரம்பை மீறிச் செயல்பட எந்தக் குறியீட்டிலும் வெவ்வேறு வரம்புகளை அமைக்கலாம். வரம்பை நிர்ணயித்ததும் உடனடியாக நடைமுறைக்கு வந்து ஒவ்வொரு மணிநேரத்திற்கும் அமலாக்கப்படும்.

Jigsaw உடன் அளவீடுகளைப் பகிர சேவை நிர்வாகிகள் ஒப்புதல் அளித்தால், தரவு வரம்புகளின் பயன்பாடு எப்படி அறிக்கையிடப்படும் என்பது பற்றிய விவரங்களைத் தெரிந்துகொள்ள[தரவுச் சேகரிப்புக் கொள்கையை](/about/data-collection) அவர்கள் பார்க்க வேண்டும்.
