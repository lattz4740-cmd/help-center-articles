---

உதவி பெறுவதற்கான இந்த இணையதளம் Outline Manager மற்றும் Outline Client பயனர்களுக்கானது. டெவெலப்பர்கள் உதவி பெறுவதற்கு GitHub ஐப் பயன்படுத்தலாம். கேள்விகளை SDK [கலந்துரையாடல் போர்டில்](https://github.com/Jigsaw-Code/outline-sdk/discussions) பதிவிடுங்கள். ‘கலந்துரையாடல் போர்டு’ பிரிவு கேள்விகளைக் கேட்கவும், யோசனைகளைப் பகிரவும், டெமோக்களுக்கான இணைப்புகளைப் பெறவும், Outline SDKவைப் பயன்படுத்தி பிற டெவெலப்பர்களுக்கு உதவவும் ஒரு சிறந்த இடமாகும். அம்சங்களுக்கான கோரிக்கைகள் அல்லது பிழை அறிக்கைகளுக்கு, ஒரு [சிக்கலைத்](https://github.com/Jigsaw-Code/outline-sdk/issues/new) தெரிவிக்கவும்.
