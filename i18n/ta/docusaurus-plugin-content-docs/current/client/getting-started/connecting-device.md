## Outline சேவையகத்துடன் உங்கள் சாதனத்தை இணைத்தல்

Outline சேவையகத்துடன் உங்கள் சாதனத்தை இணைக்க, ஒரு சேவையக நிர்வாகி ஒரு தனிப்பட்ட [அணுகல் குறியீடு](/about/terminology) மூலம் தங்கள் சேவையகத்துடன் இணைக்க உங்களுக்கு அழைப்பை அனுப்ப வேண்டும். இந்த அழைப்பு:

- உங்கள் சாதனத்தில் ஏற்கெனவே Outline இல்லையென்றால், அதைப் பதிவிறக்கி நிறுவும்படி கேட்கும்
- உங்கள் சாதனத்திற்கும் Outline சேவையகத்திற்கும் இடையே பாதுகாப்பான இணைப்பை உருவாக்க அணுகல் குறியீட்டைப் பயன்படுத்தும்

சேவையகத்துடன் இணைப்பை உருவாக்கியதும், Outline ஆப்ஸைப் பயன்படுத்த "இணை" அல்லது "இணைப்பைத் துண்டி" என்பதைக் கிளிக் செய்யலாம்.

*முக்கியம்:* அணுகல் குறியீடும் Outline சேவையகமும் இல்லாமல் Outline வேலை செய்யாது. குறியீடு இல்லாமல் Outline ஆப்ஸைப் பதிவிறக்கி நிறுவுவது உங்கள் இன்டர்நெட் டிராஃபிக்கைப் பாதுகாக்காது.
