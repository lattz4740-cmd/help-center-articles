sidebar_label: "ஓர் அணுகல் கீயை ஒருமுறைக்கு மேல் பயன்படுத்தலாமா?"
---

பயன்படுத்தலாம். உங்கள் [அணுகல் கீயை](/about/terminology) எத்தனை சாதனங்களில் வேண்டுமானாலும் பயன்படுத்தலாம். ஆனால், உங்கள் கீயை வேறொருவருடன் பகிர்வதை நாங்கள் பரிந்துரைப்பதில்லை. உங்கள் அணுகல் கீயை வைத்திருப்பவருக்கு உங்கள் இணைய டிராஃபிக்கிற்கான அணுகலும் இருந்தால் அவரால் அது அனைத்தையும் ஆய்வு செய்ய முடியும். அதன் பிறகு உங்கள் இணைய உபயோகம் பாதுகாப்பாகவோ தனிப்பட்டதாகவோ இருக்கும் என்று நிச்சயமில்லை.
