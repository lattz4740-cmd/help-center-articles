நீங்கள் Outlineனை எந்தவொரு ஆப்ரேட்டிங் சிஸ்டத்திலும் பயன்படுத்திப் பார்க்கலாம். பின்வருபவை குறைந்தபட்சமாகத் தேவைப்படும் ஆப்ரேட்டிங் சிஸ்டங்கள்:

| **ஆப்ரேட்டிங் சிஸ்டம்** | **குறைந்தபட்சப் பதிப்பு** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Outline கிளையண்ட்டை இன்னும் பல ஆப்ரேட்டிங் சிஸ்டங்களில் இயங்க வைப்பதற்கு உதவ விரும்புகிறீர்களா? [GitHubல்](https://github.com/Outline-Foundation/outline-client#platform-specific-development) எங்கள் குறியீட்டுத் தொகுப்பிற்குப் பங்களியுங்கள்!
