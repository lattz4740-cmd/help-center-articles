sidebar_label: "Windowsஸில் Outline கிளையண்ட்டை ஏன் நிறுவ முடியவில்லை?"
---

“மன்னிக்கவும், Outline சரியாக நிறுவப்படாதது போல் தெரிகிறது என்ற பிழைச் செய்தி காட்டப்படலாம். மீண்டும் நிறுவ முயலவும். அப்போதும் பிழை ஏற்பட்டால் [கருத்தைச் சமர்ப்பிக்கவும்](https://support.getoutline.org/s/contactsupport?).”

நீங்கள் Windowsஸில் Outlineனைப் பயன்படுத்தினால், எதிர்பாராத பிழையை எப்போதாவது சந்திக்க நேரிடலாம். பெரும்பாலான சந்தர்ப்பங்களில் Outline TAP அடாப்டரை (டிரைவர்) நீக்கிவிட்டு Outlineனை மீண்டும் நிறுவ வேண்டும்.

உங்கள் Windows ஆப்ரேட்டிங் சிஸ்டம் பதிப்பின் அடிப்படையில் வழிமுறைகள் மாறுபடலாம். TAP அடாப்டர், Outline ஆகியவற்றை நிறுவல் நீக்குவது எப்படி, Outlineனை மீண்டும் நிறுவுவது எப்படி என்பதற்கான பொதுவான வழிமுறைகள் கீழே கொடுக்கப்பட்டுள்ளன.

1. Outlineனுக்கான TAP அடாப்டரை நிறுவல் நீக்குதல்
   - **சாதன நிர்வாகிகள்** என்பதற்குச் செல்லவும், பின்னர் **நெட்வொர்க் அடாப்டர்கள்** என்பதற்குச் செல்லவும்
   - **TAP-Windows Adapter V9** ஃபைல் அல்லது Outlineனுடன் தொடர்புடைய TAP அடாப்டரைக் கண்டறியவும்
   - இந்த அடாப்டரை நிறுவல் நீக்கவும் அல்லது நீக்கவும். கவனத்திற்கு: இது நீங்கள் நிறுவியுள்ள பிற VPN ஆப்ஸைப் பாதிக்கலாம்.
2. Outline கிளையண்ட்டை நிறுவல் நீக்குதல்
   - **நிரல்கள் மற்றும் அம்சங்கள்** என்பதற்குச் செல்லவும், பின்னர் **நிரலை நிறுவல் நீக்கு** என்பதற்குச் செல்லவும்
   - Outline கிளையண்ட் ஆப்ஸைக் கண்டறிந்து அதை நிறுவல் நீக்கவும்
   - [Outline கிளையண்ட்டின் சமீபத்திய பதிப்பைப் பதிவிறக்கி](https://getoutline.org/get-started/#step-3) அதை உங்கள் Windows சாதனத்தில் மீண்டும் நிறுவவும். புதிய நிறுவல் தானாகவே புதிய TAP அடாப்டரை நிறுவும்.

சிக்கல் தொடர்ந்தால் [உதவி மையத்தைத்](https://support.getoutline.org/s/contactsupport?) தொடர்புகொள்ளுங்கள்.
