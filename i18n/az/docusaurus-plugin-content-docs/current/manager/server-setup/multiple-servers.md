---
title: Çoxsaylı Outline serverlərini necə quraşdırmaq olar
sidebar_label: Çoxsaylı Outline serverlərini necə quraşdırmaq olar
---

Əlavə Outline Serverləri quraşdırmaq üçün Outline Manager tətbiqinizin sol naviqasiya panelindəki "+" ikonuna klikləyin. Yeni server əlavə etmək üçün təlimatlar ilk quraşdırdığınız server ilə eynidir.

- Yarada biləcəyiniz Outline serverlərinin sayında limit yoxdur.
- Yaratdığınız hər Outline serveri üçün müvafiq virtual cihaz lazımdır.
- Əlavə cihaz və ya virtual server yaratmaq bulud provayderiniz üzrə ödənişlərinizi artıra bilər. Ödəniş məbləğindən əmin olmaq üçün qiymət paketinizi bulud provayderinizlə dəqiqləşdirin.

## DigitalOcean-da əlavə Outline serverinin yaradılması

+ ikonuna kliklədikdən və DigitalOcean-da quraşdırmağı seçdikdən sonra ilk serverinizi quraşdırmaq üçün yerinə yetirdiyiniz eyni təlimatlara əməl etməlisiniz. Həmçinin Outline Manager ilə DigitalOcean inteqrasiya edildiyinə görə Outline Manager tətbiqindən çıxmadan sizin üçün virtual server yarada bilərik.

Nəzərə alın ki, Outline Manager eyni anda yalnız bir DigitalOcean hesabını dəstəkləyə bilər. Digər DigitalOcean hesablarından başqa Outline serverləri əlavə etmək və ya yaratmaq istəyirsinizsə, onları təkmil konfiqurasiya kimi əlavə edə bilərsiniz.

## GCP, AWS və ya digər bulud xidməti provayderində əlavə Outline serverinin yaradılması

Seçdiyiniz bulud provayderi ilə yeni virtual cihaz yaratmaqla başlayın. Sonra Outline Manager-i açıb ilk dəfə etdiyiniz qaydada təkmil quraşdırma üzrə təlimatları yerinə yetirin.
