title: "Outline serverini necə quraşdıra bilərəm?"

---

Outline serverinin quraşdırılması Outline-dan istifadə edə bilmək üçün ilk addımdır. Outline vasitəsilə azad internetə qoşulmağınız üçün siz və ya etibar etdiyiniz şəxs sizin üçün server quraşdırmalıdır.

## Başlamazdan əvvəl
 Outline serverinizi quraşdırmağa başlamazdan əvvəl aşağıdakılar lazımdır:

1. Öz serverlərinizə, yaxud DigitalOcean, Amazon Web Services (AWS) və ya Google Cloud Platform (GCP) kimi Bulud xidmətləri provayderinə giriş.

 Bulud serverinə dərhal giriş edə bilmirsinizsə, yuxarıda qeyd edilənlər daxil olmaqla istənilən provayder vasitəsilə asanlıqla hesab quraşdıra bilərsiniz. Çox güman ki, qeydiyyatdan keçmək üçün kredit kartına ehtiyacınız olacaq.
2. macOS 10.9+, Windows 7.0+ və ya Linux sistemləri ilə işləyən masaüstü kompüter.
3. Outline Manager tətbiqi.

## DigitalOcean ilə quraşdırın
 Hər kəs üçün DigitalOcean-da bir neçə kliklə Outline-nın quraşdırılmasını asanlaşdırdıq. Outline Manager tətbiqini kompüterinizə endirdikdən və quraşdırdıqdan sonra Outline Serverini konfiqurasiya etmək və quraşdırmaq üçün bir neçə sadə ekran təlimatı ilə DigitalOcean quraşdırma seçimini edə bilərsiniz.

## Digər bulud provayderi ilə quraşdırın
 Outline Manager tətbiqini endirdikdən və quraşdırdıqdan sonra AWS, GCP, DigitalOcean və ya digər provayder ilə virtual cihazda Outline serverini quraşdırmağı seçə bilərsiniz. Hər mühit fərqlidir, bu səbəblə ən çox istifadə olunan bulud provayderləri üçün Outline Manager quraşdırma prosesinə təlimatlar daxil etmişik. Bu təlimatlara Outline-ı serverdə quraşdırmaq üçün quraşdırma skriptini işə salmazdan əvvəl virtual cihazınızdakı ayarları konfiqurasiya etmək qaydası da daxildir.
