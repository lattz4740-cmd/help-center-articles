## Outline-ı server olmadan istifadə edə bilərəm?
 Təəssüf ki, xeyr. Outline proqram təminatı üçün sizin, təşkilatınızın və ya etibarlı üçüncü tərəfin idarə etməyindən asılı olmayaraq, serverə giriş tələb edilir.

## Outline serverini quraşdırmaq üçün nə qədər vaxt lazımdır?

Əksər hallarda 5 dəqiqədən az vaxt aparır. Outline-ı istənilən bulud serverində quraşdıra bilərsiniz, lakin istifadəçilərə daha səmərəli və addım-addım təlimatlı quraşdırma təcrübəsi təqdim etmək üçün DigitalOcean ilə əməkdaşlıq edirik. Bununla serverinizi skript olmadan sadəcə bir neçə kliklə quraşdıra bilərsiniz.

AWS, GCP və ya təkmil quraşdırma seçiminizdən asılı olmayaraq, əksər konfiqurasiyalarda istifadə edilən vahid skript ilə server quraşdırma prosesini sadələşdirdik.

## Outline serverini harada quraşdıra bilərəm?

Outline serverini əksər bulud provayderlərinin işlədiyi hər yerdə quraşdıra bilərsiniz.

Ən asan seçim onu Amsterdam, Toronto, San-Fransisko və Sinqapur kimi bir çox bölgədə serveri olan DigitalOcean-da quraşdırmaqdır. Başqa bulud provayderində və ya öz infrastrukturunuzda quraşdırmaq istəyirsinizsə, Outline Manager tətbiqində "Təkmil Rejim" seçimini edib quraşdırma skriptinin köməyi ilə quraşdırma təlimatlarını yerinə yetirə bilərsiniz.

## Outline serverimi harada quraşdırmalıyam?

1. Outline Serveriniz üçün məkan seçərkən diqqət etməli olduğunuz bir neçə məqam var:
2. Outline Serverinin məkanı istifadəçilərin internetdən istifadə təcrübəsinə təsir göstərir. Məsələn, server Amsterdamda quraşdırılıbsa, bu serverə daxil olan istifadəçi sanki internetdən fiziki məkan olaraq Niderlandda istifadə edirmiş kimi görünəcək. Hətta bəzi veb-saytlar Niderland dilində göstərilə bilər. Bir qayda olaraq, veb-saytdakı dil seçicisindən istifadə edərək yerli dili dəyişə bilərsiniz.
3. İstifadəçilərinizin yaşadığı yer və Outline Serverinin məkanı arasındakı məsafə internet sürətinə təsir edə bilər. Ümumiyyətlə, Outline istifadəçiləri ilə server arasındakı fiziki məsafə istifadəçilərin internet sürətinə təsir edə bilər. Əksər hallarda istifadəçilərinizin olacağı əraziyə ən yaxın server məkanını seçə bilərsiniz, lakin [Submarine Cable Map](https://www.submarinecablemap.com/) vasitəsilə ölkəniz və ya bölgənizdə hansı internet kabellərindən istifadə olunduğuna baxa bilərsiniz.
4. VPN serverinizin quraşdırıldığı yer xüsusi qanunlara təsir edə bilər. Nəzərə alın ki, Outline proqram təminatında trafikiniz qeydə alınmır. [Outline istifadə edərkən təhlükəsizlik və məxfilik](/about/security-and-privacy) haqqında ətraflı məlumat əldə edin.
