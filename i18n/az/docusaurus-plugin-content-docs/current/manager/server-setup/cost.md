---
title: "Outline-ı işə salmaq üçün ödəniş nə qədərdir?"
sidebar_label: "Outline-ı işə salmaq üçün ödəniş nə qədərdir?"
---

VPN idarə edən server administratoru, yaxud Outline vasitəsilə azad internetə daxil olan istifadəçi olmağınızdan asılı olmayaraq, Outline proqram təminatı hər kəs üçün ödənişsizdir.

 Lakin, Outline-ı işə salmaq üçün bulud serverinə giriş tələb olunur. Serverə girişi olan server administratorları əlavə ödəniş etmədən ona Outline quraşdıra bilər. Serverə girişi olmayanlar [DigitalOcean](https://www.digitalocean.com/) və ya Amazon Web Services kimi bulud xidmətləri provayderindən 1 terabayt datanın ötürülməsi üçün aylıq 5$ ödəniş etməklə giriş əldə edə bilərlər. Bu, bir serverdə yüzlərlə istifadəçini dəstəkləmək üçün kifayətdir.

 Seçdiyiniz bulud provayderi ilə Outline-ı işə salmağın nə qədər ödəniş tələb edəcəyini hesablamaq üçün nümunə:

| *Hər bir istifadəçi üçün datanın ötürülməsi üzrə aylıq ortalama 5 giqabayt istifadə edildiyini fərz etsək, 5$ məbləğində aylıq plan eyni anda təxminən 200 istifadəçini təmin edər və hər istifadəçiyə düşən xərc ayda cəmi 2,5 sent təşkil edər. Qeyd edək ki, hər bir istifadəçi üçün datanın ötürülməsi üzrə aylıq ortalama istifadə edilən miqdar istifadəçilərin aşağı və ya yüksək ötürmə qabiliyyəti fəaliyyətləri ilə məşğul olub-olmamasından asılı olaraq çox dəyişir, lakin əksər bulud provayderləri trafik artımına uyğunlaşır.* |
| --- |

Outline istifadəsi faktiki olaraq Jigsaw və Google üçün tamamilə anonimdir. Kimliyiniz və ya trafikiniz izlənilmir, həmçinin monetizasiya planı yoxdur. Bunun əvəzinə proqram təminatını istifadəçilərimizə heç bir ödəniş etmədən təqdim etmək üçün açıq mənbə icmamızla işləyirik. Topladığımız data haqqında [burada](/about/data-collection)ətraflı məlumat əldə edin.
