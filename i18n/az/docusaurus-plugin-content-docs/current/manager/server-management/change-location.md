---
title: "Outline serverinin yerini necə dəyişə bilərəm?"
sidebar_label: "Outline serverinin yerini necə dəyişə bilərəm?"
---

Quraşdırıldıqdan sonra serverin yerini dəyişmək mümkün deyil. Serveri fərqli yerdən işə salmaq üçün Outline serverinizi silib yenisini yaratmalısınız.

Alternativ olaraq, serverləri dəyişdirməyə və eyni açarları saxlamağa imkan verən [dinamik açarlardan](https://developers.google.com/outline/docs/guides/service-providers/dynamic-access-keys) istifadə edərək VPN məkanını dəyişə bilərsiniz. Serverlərin yeri dəyişməyəcək.
