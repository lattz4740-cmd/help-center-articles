---
title: "Outline serverimi necə silə bilərəm?"
sidebar_label: "Outline serverimi necə silə bilərəm?"
---

Əksər bulud provayderləri üçün istifadə etdiyiniz xüsusi virtual cihazı silmək olduqca asandır.

Bulud provayderi kimi DigitalOcean istifadə edirsinizsə, cihaz düyməsinə klikləyərək və Serveri silin seçimini edərək mövcud virtual cihazınızı silə bilərsiniz. Bundan sonra seçdiyiniz yerdə yeni virtual cihaz yaratmağınız təklif olunacaq.

Outline serverini silsəniz, o, həmişəlik silinəcək və giriş açarları artıq işləməyəcək. İstifadəçilərin Outline vasitəsilə girişində kəsinti olmasını istəmirsinizsə, köhnə serverinizi silməzdən əvvəl [yeni Outline serveri quraşdırmalı](/manager/server-setup/setup-server) və serverə girişi paylaşmalısınız.
