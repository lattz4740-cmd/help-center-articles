---
title: Outline serverinə girişi idarə edin (giriş açarları ilə)
sidebar_label: Outline serverinə girişi idarə edin (giriş açarları ilə)
---

Outline serverinizin quraşdırılmasını tamamladıqda girişi insanlarla paylaşmağa və idarə etməyə başlaya bilərsiniz. Sizdən dəvət alan şəxslər öz internet trafikini qorumaq məqsədilə Outline-dan istifadə etmək üçün Outline tətbiqini endirə biləcək.

**Outline serverinizə girişi paylaşın**

 Outline serverinin quraşdırılmasını tamamladıqda Outline Manager-dəki server məlumatları səhifəsinə yönləndiriləcək və burada giriş açarları yarada biləcəksiniz. [Giriş açarları](/about/terminology) haqqında ətraflı məlumat əldə edin.

- Açarlar yaradın: Yeni açarlar yaratmaq üçün səhifənin aşağısındakı kiçik "+" ikonuna klikləyin.
- Açarları paylaşın: Hər açarın sağ tərəfində dəvət üçün klikləyə biləcəyiniz paylaşım ikonu var. Bu dəvəti kopyalayıb seçdiyiniz mesajlaşma sisteminə əlavə edin.

**Funksiya sorğusu: Girişin Outline Manager tətbiqindən paylaşılması**

 Bir çox server administratoru başqa şəxsin e-poçt ünvanını birbaşa Outline Manager-ə daxil etmək imkanı verməklə dəvət prosesini sadələşdirməyimizi tələb edir.

Təəssüf ki, bu funksiyanı Outline Manager-ə daxil edə bilmərik. Əsas prinsiplərimizdən biri istifadəçilərimizin məxfiliyini və təhlükəsizliyini dəstəkləməkdir, bu səbəblə e-poçt ünvanlarını və ya əlaqə məlumatlarını daxil etmək üçün heç bir yer planlaşdırılmayıb.

Buna görə də server administratorlarından dəvəti son istifadəçiyə göndərmək üçün e-poçt və ya etibarlı çat kimi təhlükəsiz mesajlaşma platformalarından istifadə etmələrini istəyirik.

**Giriş açarını paylaşdığınız istifadəçi bundan sonra nə etməlidir**

1. İstifadəçi öz cihazından quraşdırma keçidinə klikləyir
2. Outline tətbiqi yoxdursa, quraşdırmaq üçün yönləndirilir
3. Dəvətə daxil edilmiş unikal açar vasitəsilə Outline serverinizlə ilkin əlaqə yaradır
4. O, artıq Outline serveriniz vasitəsilə internetə girişini idarə etmək üçün "qoşulun/bağlantını kəsin" düyməsindən istifadə edə bilər

**Outline serverinizə girişi ləğv edin**

 Outline Manager-dəki server məlumatları səhifəsində serverdəki hər bir açarın sağ tərəfində açarı silmək seçimi olan menyu görəcəksiniz. Açarın silinməsi istifadəçinin serverinizə girişini ləğv edir.
