---
title: "Server ID-mi necə sıfırlaya bilərəm?"
sidebar_label: "Server ID-mi necə sıfırlaya bilərəm?"
---

Server ID-si Outline serverini yaratdığınız zaman təsadüfi yaradılan serveryönlü ID-dir. Onu Ayarlar interfeysində anonim göstəriciləri paylaşmağı seçdiyiniz zaman görə bilərsiniz. Server ID-nizi buradan tapa bilərsiniz: Ayarlar => aşağıya sürüşdürün => "anonim göstəriciləri paylaşın" xanasını işarələyin.

Server ID-si zamanla bildirilən anonim istifadə statistikasını birləşdirir. Server ID-sini sıfırlamaq və yenisini əldə etmək istəyirsinizsə, mövcud Outline serverinizi yenisi ilə əvəz etməlisiniz.

Bulud provayderi kimi DigitalOcean istifadə edirsinizsə, Ayarlar bölməsinə daxil olub "Serveri silin" seçimini edərək serverinizi sıfırlaya bilərsiniz. Bu əməliyyatı geri qaytarmaq mümkün deyil və bütün giriş məlumatlarınız silinəcək. Bu əməliyyatdan dərhal sonra seçdiyiniz yerdə yeni server yaratmağınız təklif olunacaq və yeni server ID-si yaradılacaq.
