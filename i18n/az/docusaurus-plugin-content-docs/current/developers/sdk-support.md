Bu dəstək veb-saytı Outline Manager və Client istifadəçiləri üçün nəzərdə tutulmuşdur. Tərtibatçıların dəstək üçün GitHub-dan istifadə etmələri xahiş olunur. Sual vermək üçün SDK [Müzakirə panelində](https://github.com/Jigsaw-Code/outline-sdk/discussions) paylaşım edin. Müzakirə paneli bölməsi suallar vermək, fikirləri bölüşmək, demo keçidləri paylaşmaq və Outline SDK istifadə edən digər tərtibatçılara dəstək olmaq üçün ideal yerdir. Funksiya sorğuları və ya baq hesabatları üçün əvəzində [Sorğu](https://github.com/Jigsaw-Code/outline-sdk/issues/new) açın.
