---

Outline-ı istənilən əməliyyat sistemində sınaya bilərsiniz. Aşağıda əməliyyat sistemlərinin tələb olunan minimum versiyaları verilmişdir:

| **Əməliyyat sistemi** | **Minimum versiya** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Outline Client tətbiqinin daha çox əməliyyat sistemində işləməsinə kömək etmək istəyirsiniz? GitHub-da [kod bazamıza töhfə verin](https://github.com/OutlineFoundation/outline-client#platform-specific-development)!
