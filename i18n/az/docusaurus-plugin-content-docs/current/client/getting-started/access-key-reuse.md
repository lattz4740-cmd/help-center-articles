sidebar_label: "Giriş açarından bir neçə dəfə istifadə edə bilərəm?"
---

Bəli. [Giriş açarınızı](/about/terminology) istənilən sayda cihazda istifadə edə bilərsiniz, lakin açarınızı başqa şəxslə paylaşmaq tövsiyə edilmir. Giriş açarınızdan istifadə edən hər hansı şəxs girişi varsa, bütün internet trafikinizi potensial olaraq yoxlaya bilir, bu halda isə daha internetdən təhlükəsiz və ya məxfi şəkildə istifadə edə bilmirsiniz.
