title: "Giriş açarım işləməsə, nə etməliyəm?"
sidebar_label: "Giriş açarım işləməsə, nə etməliyəm?"
---

Bu xəta mesajını alsanız: "Görünür, giriş açarınız etibarlı deyil. Bu hal təkrarlanarsa, xidmət meneceriniz ilə əlaqə saxlayın." Problemi aradan qaldırmaq üçün aşağıdakı addımları yerinə yetirin:

1. İlk beş simvol "ss://" daxil olmaqla giriş açarını tam şəkildə daxil edin. Həmin simvollar avtomatik olaraq mübadilə buferinə kopyalanmaya bilər. Giriş açarının tam formasına aid nümunə aşağıda verilmişdir (yalnız nümunədir, işləməyəcək):

```
ss://Y2hhY2hhMjAtaWV0Zi1wb2x5MTMwNTp1eXhUQ3MzemVEMTk=@145.230.4.1:39485/?outline=1
```

1. Giriş açarınız heç bir halda mübadilə buferinə kopyalanmırsa, bunun səbəbi mesajlaşma tətbiqi və ya platforması ilə bağlı ola bilər. Bu, əksər hallarda kontakt siyahınızda olmayan hər hansı şəxsdən mesaj aldığınız zaman baş verir. Kodu mesajdan kopyalayırsınızsa, göndərənin kontaktlarınızda olduğuna əmin olduqdan sonra keçidə yenidən daxil olmağa cəhd edin.
2. 1 və 2-ci addımları yerinə yetirdikdən sonra hələ də xəta mesajı alırsınızsa, böyük ehtimalla server bloklanıb və ya giriş açarı artıq etibarlı deyil. Xidmət menecerisinizsə, özünüz üçün yeni açar yaradın. Əks halda yeni açar üçün xidmət meneceriniz ilə əlaqə saxlayın.
