Mobil telefondan istifadə edirsinizsə, mobil data və Wi-Fi bağlantıları arasında keçid etməyi sınayın. Bəzən bir bağlantı növü işlədiyi halda digər biri işləməyə bilər. Kompüterdən istifadə edirsinizsə, genişzolaqlı internet ilə əlaqəni kəsib yenidən qoşulmağı sınayın.

Nasazlıq hələ də davam edərsə, çox güman ki, Outline serverinizdə problem var. Alternativ server üzrə yeni giriş açarı əldə etmək üçün[xidmət meneceriniz](/about/terminology) ilə əlaqə saxlayın.
