title: "কোনও 'অ্যাক্সেস কী' কি একবারের বেশি ব্যবহার করা যায়?"
sidebar_label: "কোনও 'অ্যাক্সেস কী' কি একবারের বেশি ব্যবহার করা যায়?"
---

হ্যাঁ। আপনি যতগুলি খুশি ডিভাইসে [অ্যাক্সেস কী](/about/terminology) ব্যবহার করতে পারবেন, তবে আপনার 'কী' অন্য কোনও ব্যক্তির সাথে শেয়ার করার সাজেশন আমরা দিই না। আপনার 'অ্যাক্সেস কী' যার কাছে থাকবে, সেই ব্যক্তির কাছে ইন্টারনেট ট্রাফিকের অ্যাক্সেস থাকলে, তিনি আপনার সব ট্রাফিক হয়ত পরীক্ষা করে দেখতে পারবেন এবং এর ফলে আপনার ইন্টারনেট ব্যবহার আর সুরক্ষিত বা গোপনীয় থাকবে না।
