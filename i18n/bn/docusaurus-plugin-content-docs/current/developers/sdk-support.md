sidebar_label: "আমি একজন ডেভেলপার। আমার অ্যাপ্লিকেশনে Outline SDK ইন্টিগ্রেট করা সংক্রান্ত সহায়তা আমি কোথায় পাবো?"
---

এই সহায়তা ওয়েবসাইট আমাদের Outline ম্যানেজার এবং ক্লায়েন্ট ব্যবহারকারীদের জন্য। ডেভেলপার, সহায়তার জন্য GitHub ব্যবহার করুন। প্রশ্ন করতে, SDK [আলোচনা বোর্ডে](https://github.com/Jigsaw-Code/outline-sdk/discussions) পোস্ট করুন। আলোচনা বোর্ড বিভাগটি এমন একটি দারুণ জায়গা যেখানে আপনি প্রশ্ন জিজ্ঞাসা করা, আইডিয়া শেয়ার করা, ডেমো প্রোজেক্টের সাথে লিঙ্ক করার পাশাপাশি Outline SDK ব্যবহার করে অন্যান্য ডেভেলপারকেও সাহায্য করতে পারবেন। এর পরিবর্তে ফিচার করার অনুরোধ বা সমস্যার ব্যাপারে অভিযোগ জানাতে, [সমস্যা](https://github.com/Jigsaw-Code/outline-sdk/issues/new) খুলুন।
