sidebar_label: "আমি Windows-এ কেন Outline Manager ইনস্টল করতে পারছি না?"
---

আপনি সমস্যা সংক্রান্ত এই মেসেজ দেখতে পেতে পারেন: "মনে হচ্ছে, Outline সঠিকভাবে ইনস্টল করা হয়নি। এটি আবার ইনস্টল করে দেখুন। এটি কাজ না করলে, [মতামত জমা দিন](https://support.getoutline.org/s/contactsupport?) বিকল্প বেছে নিন।”

Windows ডিভাইসে Outline ব্যবহার করলে, আপনি কখনও কখনও অপ্রত্যাশিত সমস্যার সম্মুখীন হতে পারেন। বেশিরভাগ ক্ষেত্রে, Outline TAP অ্যাডাপ্টার (ড্রাইভার) মুছে ফেলতে এবং Outline আবার ইনস্টল করতে হবে।

Windows অপারেটিং সিস্টেমের ভার্সন অনুযায়ী, ধাপগুলি আলাদা আলাদা হতে পারে, তবে TAP অ্যাডাপ্টার ও Outline কীভাবে আনইনস্টল করে আবার ইনস্টল করা যায়, সেই সংক্রান্ত সাধারণ ধাপগুলি নিচে দেখানো হল।

1. Outline Manager-এর জন্য TAP অ্যাডাপ্টার আনইনস্টল করুন
   1. ডিভাইস ম্যানেজার টুলে গিয়ে নেটওয়ার্ক অ্যাডাপ্টার বিকল্প দেখুন
   2. TAP-Windows Adapter V9 ফাইল বা Outline-এর সাথে যুক্ত TAP অ্যাডাপ্টার খুঁজে নিন
   3. এই অ্যাডাপ্টার আনইনস্টল করুন বা মুছে ফেলুন। মনে রাখবেন যে, এটি আপনার ইনস্টল করা অন্যান্য VPN অ্যাপের উপর প্রভাব ফেলতে পারে।
2. Outline Manager আনইনস্টল করুন
   1. প্রোগ্রাম ও ফিচার বিকল্পে গিয়ে 'প্রোগ্রাম আনইনস্টল করুন' বিকল্প বেছে নিন
   2. Outline Manager অ্যাপ খুঁজে নিয়ে Outline Manager আনইনস্টল করুন
   3. [Outline Manager-এর লেটেস্ট ভার্সন ডাউনলোড করুন](https://getoutline.org/get-started/#step-1) এবং আপনার Windows ডিভাইসে আবার ইনস্টল করুন। নতুন করে ইনস্টল করলে, এর সাথে নতুন TAP অ্যাডাপ্টার অটোমেটিক ইনস্টল হবে।

এখনও সমস্যা হলে, [সহায়তা টিমের](https://support.getoutline.org/s/contactsupport?) সাথে যোগাযোগ করুন।
