Outline ব্যবহারের উপযুক্ত হওয়ার প্রথম ধাপ হল, একটি Outline সার্ভার সেট-আপ করা। Outline-এর মাধ্যমে ওপেন ইন্টারনেটে কানেক্ট করতে আপনি অথবা আপনার বিশ্বস্ত কাউকে আপনার হয়ে সার্ভার সেট-আপ করতে হবে।

## শুরু করার আগে
আপনার Outline সার্ভার সেট-আপ শুরু করার আগে, আপনার কয়েকটি জিনিসের প্রয়োজন হতে পারে:

1. আপনার নিজস্ব সার্ভার বা ক্লাউড পরিষেবা প্রদানকারী, যেমন DigitalOcean, Amazon Web Services (AWS) বা Google Cloud Platform (GCP) অ্যাক্সেস করুন।

    কোনও ক্লাউড সার্ভারে আপনার তৎক্ষণাৎ অ্যাক্সেস না থাকলে, আপনি উপরে উল্লেখ করা ক্লাউড পরিষেবা প্রদানকারী সহ অন্যান্য কোনও ক্লাউড পরিষেবা প্রদানকারী মাধ্যমে সহজেই অ্যাকাউন্ট সেট-আপ করতে পারবেন। সাইন-আপ করার জন্য ক্রেডিট কার্ডের প্রয়োজন হতে পারে।
2. macOS 10.9+, Windows 7.0+ অথবা Linux সিস্টেমে চলা ডেস্কটপ কম্পিউটার।
3. Outline Manager অ্যাপ্লিকেশন।

## DigitalOcean-এর মাধ্যমে সেট-আপ করা
আমরা DigitalOcean-এ Outline ইনস্টল করার কাজ এখন সহজ করেছি এবং এটি যেকেউ কয়েকটি ক্লিকেই করে ফেলতে পারবে। কম্পিউটারে Outline Manager ডাউনলোড ও ইনস্টল করার পর আপনি DigitalOcean সেট-আপ বিকল্পটি বেছে নিলে আপনাকে স্ক্রিনে সহজ কয়েকটি ধাপ দেখানো হবে যা কাজে লাগিয়ে আপনি নিজের Outline সার্ভার ইনস্টল ও কনফিগার করতে পারবেন।

## অন্য কোনও ক্লাউড প্রদানকারীর মাধ্যমে সেট-আপ করা
Outline Manager ডাউনলোড ও ইনস্টল করার পর আপনি AWS, GCP, DigitalOcean অথবা অন্য কোনও পরিষেবা প্রদানকারীর মাধ্যমে কোনও ভার্চুয়াল মেশিনে Outline সার্ভার ইনস্টল করার বিকল্প বেছে নিতে পারেন। প্রতিটি এনভায়রনমেন্ট আলাদা হওয়ার ফলে আমরা সাধারণ ক্লাউড প্রদানকারীদের জন্য Outline Manager সেট-আপ ফ্লোয়ের মধ্যে নির্দেশাবলী যুক্ত করেছি, এবং আপনি সার্ভারে Outline ইনস্টল করার জন্য ইনস্টলেশন স্ক্রিপ্ট রান করানোর আগে ভার্চুয়াল মেশিনে কীভাবে সেটিংস কনফিগার করবেন ইত্যাদি তথ্য এতে দেওয়া রয়েছে।
