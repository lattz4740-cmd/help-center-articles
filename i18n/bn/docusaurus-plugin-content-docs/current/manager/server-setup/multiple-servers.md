অতিরিক্ত Outline সার্ভার সেট-আপ করতে, Outline Manager অ্যাপ্লিকেশনের বাঁদিকে থাকা নেভিগেশন প্যানেলে “+” আইকনে ক্লিক করুন। আপনি প্রথম সার্ভারটি যেভাবে ইনস্টল করেছিলেন, নতুন সার্ভারও সেই একই নির্দেশাবলী অনুসরণ করে করতে হবে।

- আপনি কতগুলি Outline সার্ভার তৈরি করতে পারেন সে সম্পর্কে আমরা কোনও সীমা স্থির করিনি।
- আপনার তৈরি করা প্রতিটি Outline সার্ভারের জন্য একটি করে সংশ্লিষ্ট ভার্চুয়াল মেশিনের প্রয়োজন হবে।
- অতিরিক্ত মেশিন বা ড্রপলেট তৈরি করলে আপনার ক্লাউড পরিষেবা প্রদানকারী আপনাকে বেশি ফি চার্জ করতে পারে। চার্জ কত হতে পারে তা নিশ্চিত করতে আপনার ক্লাউড পরিষেবা প্রদানকারীর কাছে দামের প্যাকেজ চেক করুন।

## DigitalOcean-এ বাড়তি Outline সার্ভার তৈরি করা

আপনি + আইকনে ক্লিক করে DigitalOcean-এ ইনস্টল করার জন্য বেছে নেওয়ার পর প্রথম সার্ভার যেভাবে সেট করেছেন সেই একই নির্দেশাবলী অনুসরণ করুন। এছাড়াও, Outline Manager, DigitalOcean-এর সাথে ইন্টিগ্রেট হওয়ার ফলে আমরা Outline Manager অ্যাপ থেকে না বেরিয়েই আপনার জন্য ড্রপলেট তৈরি করতে পেরেছি।

মনে রাখবেন, Outline Manager একই সময়ে কেবলমাত্র একটিই DigitalOcean অ্যাকাউন্টে কাজ করতে পারবে। আপনি অন্য DigitalOcean অ্যাকাউন্ট থেকে অন্য Outline সার্ভার যোগ বা তৈরি করতে চাইলে সেগুলিকে উন্নত কনফিগারেশন হিসেবে যোগ করতে পারেন।

## GCP, AWS অথবা অন্য ক্লাউড পরিষেবা প্রদানকারীর মাধ্যমে অতিরিক্ত Outline সার্ভার তৈরি করা

আপনার বেছে নেওয়া ক্লাউড পরিষেবা প্রদানকারীর মাধ্যমে একটি নতুন ভার্চুয়াল মেশিন তৈরি করে শুরু করুন। এরপর Outline Manager অ্যাপ খুলুন ও উন্নত ইনস্টলেশন সম্পূর্ণ করুন, ঠিক যেমনটি প্রথমবার করেছিলেন প্রায় সেরকমই।
