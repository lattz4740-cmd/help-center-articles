sidebar_label: "আমার সার্ভার আইডি আমি কীভাবে রিসেট করতে পারব?"
---

সার্ভার আইডি হল একটি 'সার্ভার-সাইড আইডি' যা কোনও Outline সার্ভার তৈরি করার সময় র‌্যান্ডমভাবে তৈরি করা হয়। 'সেটিংস' ইন্টারফেসে পরিচয় গোপন করা মেট্রিকে শেয়ার করার বিকল্প বেছে নেওয়ার সময় আপনি এটি খুঁজে পেতে পারবেন। আপনি এখান থেকে সার্ভার আইডির লোকেশন খুঁজে পেতে পারবেন: সেটিংস => নিচের দিকে স্ক্রল করুন => "পরিচয় গোপন করা মেট্রিক শেয়ার করুন" বিকল্প চেক করুন।

সময়ের সাথে সাথে রিপোর্ট করা হয়েছে এমন পরিচয় গোপন করা ব্যবহারকারীর পরিসংখ্যান, সার্ভার আইডি একসাথে যোগ করে দেখায়। সার্ভার আইডি রিসেট করে একটি নতুন আইডি পেতে চাইলে, আপনাকে বর্তমান Outline সার্ভারের জায়গায় একটি নতুন সার্ভার তৈরি করতে হবে।

ক্লাউড পরিষেবা প্রদানকারী হিসেবে, DigitalOcean ব্যবহার করলে, 'সেটিংস' মেনুতে গিয়ে 'সার্ভার মুছে দিন' বিকল্প বেছে নিয়ে আপনার সার্ভার রিসেট করতে পারবেন। এই অ্যাকশনটি একবার করলে তাকে আর পুরনো অবস্থায় ফেরানো যায় না এবং ক্রেডেনশিয়াল মুছে দেওয়া হবে। এই অ্যাকশনের পরেই অবিলম্বে আপনার বেছে নেওয়া লোকেশনে একটি নতুন সার্ভার তৈরি করার জন্য প্রম্পট পাঠানো এবং একটি নতুন সার্ভার আইডি তৈরি করা হবে।
