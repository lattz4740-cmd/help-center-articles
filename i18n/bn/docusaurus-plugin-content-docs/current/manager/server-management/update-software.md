sidebar_label: "Outline সার্ভার সফ্টওয়্যার আমি কীভাবে আপডেট করতে পারি?"
---

Outline সার্ভারে নিরাপত্তা সংক্রান্ত লেটেস্ট উন্নতি অটোমেটিক আপডেট করা হয়, যাতে আপনি সব সময় Outline-এর লেটেস্ট প্রযুক্তি রান করাতে পারেন। [Watchtower](https://github.com/containrrr/watchtower)-এর মাধ্যমে অটোমেটিক আপডেট প্রক্রিয়া চালু করা হয়। এটি একটি ওপেন সোর্স লাইব্রেরি, যা নিয়মিতভাবে Outline সফ্টওয়্যার থাকা 'ডকার' ছবি চেক ও আপডেট করে।

এছাড়াও, আপনি Outline Manager ব্যবহার করে Outline ইনস্টল করলে, [অসম্পূর্ণ আপগ্রেড](https://wiki.debian.org/UnattendedUpgrades) (Ubuntu) ব্যবহার করে, আমরা সার্ভারে অটোমেটিক আপগ্রেড করার জন্য একটি ক্রোন জব সেট-আপ করব এবং প্রয়োজনমতো রিবুট করব। মনে রাখবেন, বর্তমান কনফিগারেশন বজায় রাখতে, এটি উন্নত মোডে হয় না। এক্ষেত্রে এটি মনে করা হয় যে Outline রান করা ছাড়াও, হোস্টের ব্যবহার অন্য কোনও উদ্দেশ্যেও ব্যবহার করা হচ্ছে।
