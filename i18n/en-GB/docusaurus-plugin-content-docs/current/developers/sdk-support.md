title: "I'm a developer. Where can I find support for integrating the Outline SDK into my application?"
sidebar_label: "I'm a developer. Where can I find support for integrating the Outline SDK into my application?"
---

This support website is for Outline Manager and Client users. Developers, please use GitHub for support. To ask a question, please post on the SDK [Discussion board](https://github.com/Jigsaw-Code/outline-sdk/discussions). The Discussion board section is a great place to ask questions, share ideas, link to demos and support other developers using Outline SDK. For feature requests or bug reports, please open an [Issue](https://github.com/Jigsaw-Code/outline-sdk/issues/new) instead.
