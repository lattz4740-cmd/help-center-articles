title: "What are the system requirements to run the Outline client?"
sidebar_label: "What are the system requirements to run the Outline client?"
---

You are welcome to try Outline on any operating system. The following are the minimum required operating systems:

| **Operating system** | **Minimum version** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Want to help Outline client work on more operating systems? [Contribute to our code base](https://github.com/Outline-Foundation/outline-client#platform-specific-development) on GitHub!
