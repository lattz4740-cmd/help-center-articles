---
title: "How can I get an access key?"
sidebar_label: "How can I get an access key?"
---

Outline isn't like VPN services that you buy access to; it's [a tool](https://getoutline.org/#:~:text=Two%20Products%20that%20Work%20Together) that lets you run and share access to a private VPN server. A [service manager](/about/terminology#servicemanager) is the only person that can provide an access key. The Outline team does not distribute free or paid access keys. We do not have any official Outline access key partners, except for Paskoocheh in Farsi.

 Here are three options for getting an access key:

- Ask someone to invite you to their server: If you know someone with an Outline server, contact them and ask them for an access key.
- [Create a server yourself:](/manager/server-setup/setup-server) Using a Windows, Mac or Linux computer, download [Outline Manager](https://getoutline.org/get-started/#step-1) and set up your own private [Outline server](/about/terminology). We've made this process easy for anyone to complete, particularly through cloud service provider DigitalOcean.
- Use an Outline or [Shadowsocks](https://en.wikipedia.org/wiki/Shadowsocks#:~:text=Shadowsocks%20is%20a%20free%20and,have%20been%20made%20available%20since.) service: The Outline client can also be used with third-party services that use Outline or the Shadowsocks protocol. For example:
   - [nthLink](https://nthlink.com/) runs a free service based on Outline, with a modified version of the Outline client.
   - [ASL19](https://www.reddit.com/r/outlinevpn/comments/nwu1se/the_outline_distribution_system_is_here_to_help/) runs a modified version of Outline called [BeePass](https://beepassvpn.com/), as well as [a Telegram bot](https://t.me/paskoochehbot) that provides free access keys to BeePass servers.
   - Farsi language users can also request an Outline access key from [ASL19's Paskoocheh](https://outline.paskoocheh.com/).

After downloading the Outline Client app, copy and paste your [access key](/about/terminology#accesskey) into Outline Client to connect to the Outline server.
