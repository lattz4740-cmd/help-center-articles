title: "How do I reset my server ID?"
sidebar_label: "How do I reset my server ID?"
---

The server ID is a server-side ID that's randomly generated when you create an Outline server. You can find it when opting in to sharing anonymous metrics in the Settings interface. You can locate your server ID from: Settings > scroll to bottom > tick 'Share anonymous metrics'.

The server ID ties together anonymous usage statistics reported over time. If you want to reset the server ID and obtain a new one, you'll need to replace your existing Outline server with a new one.
