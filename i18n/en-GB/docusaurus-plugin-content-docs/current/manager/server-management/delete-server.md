---
title: "How do I delete my Outline server?"
sidebar_label: "How do I delete my Outline server?"
---

For most cloud providers, it’s fairly easy to remove the specific virtual machine you are using.

If you are using DigitalOcean as your cloud provider, you can delete your existing virtual machine by clicking on the gear button and selecting Destroy Server. Immediately afterwards, you’ll be prompted to create a new virtual machine in a location of your choosing.

If you remove an Outline server, it will be permanently deleted and its access keys will no longer work. If you do not want people to have an interruption in their access through Outline, you will need to [set up a new Outline server](/manager/server-setup/setup-server) and share access to it before deleting your old server.
