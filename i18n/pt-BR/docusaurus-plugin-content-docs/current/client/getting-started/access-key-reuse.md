---
title: "Posso usar uma chave de acesso mais de uma vez?"
sidebar_label: "Posso usar uma chave de acesso mais de uma vez?"
---

Sim. Você pode usar a [chave de acesso](/about/terminology) nos seus dispositivos, mas não recomendamos compartilhá-la com outra pessoa. Alguém com essa chave pode inspecionar todo o seu tráfego da Internet se tiver acesso a ele. Isso significa que seu uso da rede não será mais seguro nem particular.
