sidebar_label: "Quais são os requisitos do sistema para executar o app cliente do Outline?"
---

É possível testar o Outline em qualquer sistema operacional. Abaixo estão listadas as versões mínimas necessárias:

| **Sistema operacional** | **Versão mínima** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Quer ajudar na expansão do app cliente do Outline para mais sistemas operacionais? [Contribua com nossa base de código](https://github.com/Jigsaw-Code/outline-client#platform-specific-development) no GitHub.
