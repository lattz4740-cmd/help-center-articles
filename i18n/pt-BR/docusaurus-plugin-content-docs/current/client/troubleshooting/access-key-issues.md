---
title: "E se minha chave de acesso não funcionar?"
sidebar_label: "E se minha chave de acesso não funcionar?"
---

“Sua chave de acesso não é válida. Se isso ocorrer novamente, entre em contato com o gerente de serviço.”

Siga as etapas abaixo para solucionar o problema:

1. Insira a chave de acesso completa, inclusive os cinco primeiros caracteres, “ss://”, que talvez não sejam copiados automaticamente para a área de transferência. Este é um exemplo de uma chave de acesso total (é apenas uma amostra e não é funcional):

ss://Y2hhY2hhMjAtaWV0Zi1wb2x5MTMwNTp1eXhUQ3MzemVEMTk=@145.230.4.1:39485/?outline=1

1. Se a chave de acesso não for copiada para a área de transferência, talvez seja devido ao app ou plataforma de mensagens. Isso é mais provável quando você recebe uma mensagem de alguém que não está na sua lista de contatos. Se você copiou o código de uma mensagem, verifique se o remetente está adicionado aos seus contatos e tente acessar o link de novo.
2. Se você concluiu as etapas 1 e 2 e ainda recebe uma mensagem de erro, é provável que o servidor esteja bloqueado ou a chave de acesso não seja mais válida. Se você for o gerente de serviço, gere uma nova chave. Caso contrário, entre em contato com o gerente de serviço para receber uma nova chave.
