---
title: "Como redefinir o código do servidor?"
sidebar_label: "Como redefinir o código do servidor?"
---

Esse código é uma identificação do lado do servidor, gerada aleatoriamente quando ele é criado. Ele estará disponível se você aceitar compartilhar métricas anônimas na interface de configurações. Localize-o em: Configurações => role até o fim => marque "Compartilhar métricas anônimas".

O código do servidor associa estatísticas de uso anônimas relatadas ao longo do tempo. Se você quiser redefini-lo e receber um novo, precisará substituir o servidor do Outline atual por um novo.

. Essa ação é irreversível e limpará suas credenciais. Após essa ação, será solicitada a criação de um servidor em um local da sua escolha e um novo código do servidor será gerado.
