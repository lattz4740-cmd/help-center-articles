---
title: "Como excluir o servidor do Outline?"
sidebar_label: "Como excluir o servidor do Outline?"
---

Na maioria dos provedores de nuvem, é fácil remover a máquina virtual que você está usando.

Se você usa a DigitalOcean como o provedor de nuvem, clique no botão de engrenagem e selecione **Destruir servidor** para excluir a máquina virtual em uso. Em seguida, você terá a opção de criar uma máquina virtual onde preferir.

Se você remover um servidor do Outline, ele será excluído permanentemente, e as chaves de acesso dele não funcionarão mais. Se você não quiser que o acesso pelo Outline seja interrompido, será necessário [configurar um novo servidor do Outline](https://support.google.com/outline/answer/15331530?sjid=5147938692963654551-NC) e compartilhar o acesso a ele antes de excluir o antigo.
