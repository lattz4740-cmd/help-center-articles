Após instalar o servidor do Outline, comece a compartilhar e gerenciar o acesso a ele. Quem receber um convite seu poderá fazer o download do app Outline e usá-lo para proteger o tráfego da Internet.

## Compartilhar o acesso ao seu servidor do Outline
 Após instalar um servidor do Outline, a página de detalhes do servidor no Outline Manager será aberta. Lá, você poderá criar chaves de acesso. Saiba mais sobre [esse tipo de chave](/about/terminology).

- Criar chaves: para fazer isso, clique no ícone "+" na parte de baixo da página.
- Compartilhar chaves: à direita de cada chave há um ícone de compartilhamento em que você pode clicar para gerar um convite. Copie e cole o convite no sistema de mensagens que preferir.

## Solicitação de recurso: compartilhar o acesso pelo app Outline Manager
 Muitos administradores de servidores nos pedem para simplificar o processo de convite de modo que eles possam inserir um endereço de e-mail diretamente no Outline Manager.

Essa funcionalidade não será criada. Um dos nossos princípios básicos é aumentar a privacidade e a segurança dos usuários, por isso não criamos um local para endereços de e-mail ou informações de contato.

Portanto, pedimos aos administradores de servidores que usem uma plataforma de mensagens segura, como e-mail ou bate-papo seguro, para enviar o convite ao usuário final.

## Como é a experiência do usuário depois que você compartilha uma chave de acesso com ele
1. O usuário clica no link de instalação do dispositivo.
2. Ele precisa instalar o app Outline, se ainda não tiver.
3. Ele estabelece uma conexão inicial com o servidor do Outline pela chave exclusiva incorporada ao convite.
4. Agora ele pode usar o botão "conectar/desconectar" para gerenciar o acesso à Internet pelo servidor do Outline.

## Remover o acesso ao seu servidor do Outline
 Na página de detalhes do servidor no Outline Manager, à direita de todas as chaves, você vai encontrar um menu com a opção de excluir. A exclusão de uma chave remove o acesso dela ao servidor.
