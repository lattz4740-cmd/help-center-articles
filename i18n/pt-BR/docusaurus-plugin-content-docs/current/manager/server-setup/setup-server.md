Configurar um servidor do Outline é o primeiro passo para usá-lo. Para se conectar à Internet aberta pelo Outline, você ou alguém de sua confiança precisam configurar um servidor.

## Antes de começar

Antes de começar a configurar o servidor do Outline, você precisa ter o seguinte:

1. Acesso aos seus próprios servidores ou a um provedor de serviços de nuvem, como a DigitalOcean, a Amazon Web Services (AWS) ou o Google Cloud Platform (GCP).

 Se você não tiver acesso imediato a um servidor na nuvem, poderá configurar facilmente uma conta com qualquer provedor, inclusive os listados acima. Provavelmente você precisará de um cartão de crédito para se inscrever.
2. Um computador desktop com o macOS 10.9 ou versão posterior, o Windows 7.0 ou versão posterior ou o Linux.
3. O aplicativo Outline Manager.

## Configurar com a DigitalOcean

Agora qualquer pessoa pode instalar o Outline facilmente na DigitalOcean com alguns cliques. Após fazer o download do Outline Manager e instalá-lo no computador, selecione a opção de configuração da DigitalOcean, que apresentará algumas telas simples para configuração e instalação do servidor do Outline.

## Configurar com outro provedor de nuvem

Após fazer o download e a instalação do Outline Manager, você pode instalar um servidor do Outline em uma máquina virtual com a AWS, o GCP, a DigitalOcean ou outro provedor. Cada ambiente é único, por isso, apresentamos instruções no fluxo de configuração do Outline Manager para os provedores de nuvem mais comuns, inclusive como definir as configurações na máquina virtual antes de executar o script de instalação para instalar o Outline em um servidor.
