## Posso usar o Outline sem um servidor?

Não, o software Outline requer acesso a um servidor, seja ele gerenciado por você, pela organização ou por um terceiro confiável.

## Quanto tempo é necessário para configurar um servidor do Outline?

Na maioria dos casos, menos de cinco minutos. Você pode instalar o Outline em qualquer servidor na nuvem, mas trabalhamos com a DigitalOcean para proporcionar uma experiência guiada mais fácil de usar, em que é possível configurar o servidor com poucos cliques, sem scripts.

 Se você escolheu a AWS, o GCP ou uma configuração avançada, simplificamos o processo de instalação do servidor para um único script que abrange a maioria dos ambientes.

## Onde configuro um servidor do Outline?

É possível configurar um servidor do Outline na maioria dos provedores de nuvem, seja qual for a localização deles.

 A opção mais fácil é configurá-lo na DigitalOcean, que tem servidores em vários locais, como Amsterdã, Toronto, São Francisco e Singapura. Se preferir instalar em outro provedor de nuvem ou na sua própria infraestrutura, escolha o "Modo avançado" no aplicativo Outline Manager e siga as instruções de instalação usando um script de configuração.

## Onde configuro o servidor do Outline?

É necessário considerar alguns aspectos ao selecionar um local para o servidor do Outline:

1. O local do servidor do Outline afeta a experiência dos usuários na Internet. Por exemplo, se o servidor estiver em Amsterdã, o usuário que acessá-lo navegará pela Internet como se estivesse localizado fisicamente na Holanda. Alguns sites podem até ser exibidos em holandês. Em geral, é possível modificar o idioma local usando o seletor de idiomas do site.
2. A distância entre os usuários e o servidor do Outline pode afetar a velocidade. Em geral, a distância física entre os usuários do Outline e o servidor pode afetar a velocidade da Internet para os usuários. Na maioria dos casos, é possível escolher um local de servidor mais próximo de onde os usuários estão, mas verifique o [mapa de cabos submarinos](https://www.submarinecablemap.com/) para ver quais se conectam com seu país ou região.
3. A localização do servidor VPN pode afetar a estrutura legal. Observe que o software Outline não registra o tráfego. Saiba mais sobre [segurança e privacidade ao usar o Outline](/about/security-and-privacy).
