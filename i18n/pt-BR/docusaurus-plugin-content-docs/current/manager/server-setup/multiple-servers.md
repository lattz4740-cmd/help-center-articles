---
title: Como configurar vários servidores do Outline
sidebar_label: Como configurar vários servidores do Outline
---

Para configurar outros servidores do Outline, clique no ícone "+" no painel de navegação no lado esquerdo do aplicativo Outline Manager. As instruções para adicionar um novo servidor são as mesmas da instalação inicial.

- Não há um limite de número de servidores do Outline que você pode criar.
- Para cada servidor do Outline criado, você precisará de uma máquina virtual correspondente.
- Se você criar outras máquinas ou droplets, as taxas do provedor de nuvem poderão aumentar. Verifique seu pacote de preços com o provedor para saber o que esperar.

## Criar um servidor do Outline adicional na DigitalOcean

Depois de clicar no ícone + e selecionar a instalação na DigitalOcean, siga as mesmas instruções de configuração do primeiro servidor. Além disso, como o Outline Manager faz a integração com a DigitalOcean, podemos criar o droplet sem que você precise sair do app Outline Manager.

Observe que o Outline Manager só oferece suporte a uma conta da DigitalOcean por vez. Se você quiser adicionar ou criar outros servidores do Outline usando outras contas da DigitalOcean, adicione-os como uma configuração avançada.

## Criar um servidor adicional do Outline no GCP, na AWS ou em outro provedor de serviços de nuvem

Comece criando uma nova máquina virtual com o provedor de nuvem escolhido. Em seguida, abra o Outline Manager e siga as instruções de instalação avançada, assim como na primeira vez.
