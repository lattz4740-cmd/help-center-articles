---
title: "Quanto custa executar o Outline?"
sidebar_label: "Quanto custa executar o Outline?"
---

O software Outline é gratuito para qualquer pessoa, seja um administrador de servidores que gerencia a VPN ou alguém que usa o Outline para acessar a Internet aberta.

 No entanto, é preciso ter acesso a um servidor na nuvem para executar o programa. Os administradores de servidores que já têm acesso a um servidor podem instalar o Outline nele sem custo adicional. Quem não tem acesso a um servidor pode adquiri-lo com um provedor de serviços de nuvem, como a [DigitalOcean](https://www.digitalocean.com/) ou a Amazon Web Services, por cerca de USD 5 por mês com transferência de dados de 1 terabyte. Isso é suficiente para atender a centenas de usuários em um único servidor.

 Veja como fazer as contas para saber quanto custa executar o Outline com o provedor de nuvem que você preferir:

| *Supondo a utilização média mensal de 5 gigabytes de transferência de dados por usuário, um plano de USD 5 por mês permitirá 200 usuários simultâneos, ou seja, o custo será de apenas 2,5 centavos por usuário ao mês. Observe que a transferência de dados por usuário ao mês varia muito de acordo com a largura de banda usada nas atividades dos usuários, mas a maioria dos provedores de nuvem acomoda os aumentos no tráfego.* |
| --- |

Na verdade, o uso do Outline é completamente anônimo para a Jigsaw e o Google. Não rastreamos sua identidade ou tráfego, e não há um plano de monetização. Em vez disso, trabalhamos com nossa comunidade de código aberto para fornecer o software sem custo para os usuários. Saiba mais sobre os [dados que coletamos](https://getoutline.org/policies/data-collection).
