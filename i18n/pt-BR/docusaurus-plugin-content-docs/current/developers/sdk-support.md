title: "Sou desenvolvedor. Onde posso encontrar suporte para integrar o SDK Outline ao meu app?"
sidebar_label: "Sou desenvolvedor. Onde posso encontrar suporte para integrar o SDK Outline ao meu app?"
---

Este site de suporte é destinado aos usuários do Outline Manager e do Outline Client. Os desenvolvedores podem usar o GitHub para receber suporte. Para fazer uma pergunta, publique no [fórum de discussão](https://github.com/Jigsaw-Code/outline-sdk/discussions) do SDK. O fórum de discussão é um ótimo lugar para tirar dúvidas, compartilhar ideias, publicar links de demonstrações e oferecer suporte a outros desenvolvedores que usam o SDK Outline. Para solicitar recursos ou relatar bugs, abra um [Issue](https://github.com/Jigsaw-Code/outline-sdk/issues/new) (Problema).
