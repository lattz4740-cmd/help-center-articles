---
title: Como enviar feedback ou sugestões
sidebar_label: Como enviar feedback ou sugestões
---

Agradecemos seu feedback para melhorar o Outline. Você pode enviar comentários de diferentes maneiras: anonimamente ou com seu e-mail, se quiser receber a resposta:

- **Para desenvolvedores**: o Outline é um software de código aberto, que está hospedado no GitHub. Você pode dar sua opinião no GitHub ou na nossa comunidade no Reddit.

- **Para usuários**: você pode enviar feedback pelos apps Outline ou Outline Manager. Diga sobre o que é seu feedback e, se quiser, deixe um e-mail para enviarmos a resposta. Para ajudá-lo a solucionar problemas, também coletamos alguns metadados sobre seu ambiente, como o navegador, o sistema operacional e a versão do software em uso.

- **Neste site**: você pode clicar no link para contato em qualquer lugar neste site.

- **Problemas graves**: se você quiser relatar um problema grave de segurança, envie um e-mail com detalhes para [security@getoutline.org](mailto:security@getoutline.org).

Sua opinião é muito importante.
