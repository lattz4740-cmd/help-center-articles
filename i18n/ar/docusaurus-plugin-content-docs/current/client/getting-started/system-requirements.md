title: "ما هي متطلبات النظام لتشغيل تطبيق \"عميل Outline\"؟"
sidebar_label: "ما هي متطلبات النظام لتشغيل تطبيق \"عميل Outline\"؟"
---

يمكنك محاولة تشغيل Outline على أي نظام تشغيل. إليك قائمة بالحد الأدنى من إصدارات أنظمة التشغيل المطلوبة:

| **نظام التشغيل** | **الحد الأدنى للإصدار** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

هل تهمّك المساعدة في توسيع نطاق عمل تطبيق "عميل Outline" ليشمل مزيدًا من أنظمة التشغيل؟ [يمكنك المساهمة في قاعدة الرموز](https://github.com/Outline-Foundation/outline-client#platform-specific-development) على GitHub.
