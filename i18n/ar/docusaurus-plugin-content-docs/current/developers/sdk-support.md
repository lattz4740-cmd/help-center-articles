هذا الموقع الإلكتروني مخصّص لدعم مستخدمي "مدير Outline" و"عميل Outline". يُرجى من المطورين استخدام GitHub للحصول على الدعم. لطرح سؤال، يُرجى نشره على [لوحة مناقشة](https://github.com/Jigsaw-Code/outline-sdk/discussions) حزمة تطوير البرامج (SDK). يُشكّل قسم "لوحة المناقشة" مكانًا رائعًا لطرح الأسئلة ومشاركة الأفكار وإضافة روابط تنقل إلى عروض توضيحية وتقديم الدعم للمطوّرين الآخرين الذين يستخدمون حزمة تطوير البرامج Outline SDK. لطلب الميزات أو إرسال تقارير الأخطاء، يُرجى فتح [مشكلة](https://github.com/Jigsaw-Code/outline-sdk/issues/new) بدلاً من ذلك.
