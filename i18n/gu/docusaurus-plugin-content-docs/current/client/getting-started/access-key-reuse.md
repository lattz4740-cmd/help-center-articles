sidebar_label: "શું હું એક કરતાં વધુ વખત ઍક્સેસ કીનો ઉપયોગ કરી શકું?"
---

હા. તમે તમારા કેટલા પણ ડિવાઇસ પર તમારી [ઍક્સેસ કી](/about/terminology) વાપરી શકો છો, પણ અમે તમને તમારી કી અન્ય લોકો સાથે શેર કરવાનો સુઝાવ આપતા નથી. જો તમારી ઍક્સેસ કી ધરાવતી કોઈ વ્યક્તિ પાસે તેનો ઍક્સેસ હોય, તો તે વ્યક્તિ સંભવિત રીતે તમારા બધા ઇન્ટરનેટ ટ્રાફિકની તપાસ કરી શકે છે, જેનાથી તમારો ઇન્ટરનેટનો વપરાશ સુરક્ષિત કે ખાનગી રહેતો નથી.
