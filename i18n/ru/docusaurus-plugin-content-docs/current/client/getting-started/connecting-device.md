---
title: Подключение устройства к серверу Outline
sidebar_label: Подключение устройства к серверу Outline
---

Чтобы подключить устройство к серверу Outline, администратор сервера должен отправить вам приглашение для подключения сервера с помощью уникального [. С помощью этого приглашения вы сможете выполнить следующие действия](/about/terminology):

- скачать и установить Outline на вашем устройстве, если вы ещё не сделали этого;
- использовать ключ доступа для установления безопасного подключения между вашим устройством и сервером Outline.

После подключения к серверу вы сможете нажимать кнопки подключения или отключения для использования Outline.

:::warning
Outline не работает без ключа доступа и сервера Outline. Если вы скачаете и установите приложение Outline, не получив ключ, ваш интернет-трафик не будет защищен.
:::
