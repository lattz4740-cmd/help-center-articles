---
title: "Можно ли использовать ключ доступа более одного раза?"
sidebar_label: "Можно ли использовать ключ доступа более одного раза?"
---

Да, вы можете использовать [ключ доступа](/about/terminology) на любом количестве устройств, однако мы рекомендуем не делиться им с другими пользователями. Пользователь, у которого есть ваш ключ, получит доступ ко всему вашему интернет-трафику. В результате использование интернета перестанет быть безопасным и конфиденциальным для вас.
