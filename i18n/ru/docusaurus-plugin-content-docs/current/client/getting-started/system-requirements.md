Outline поддерживается большинством операционных систем. Ниже приведены минимальные версии ОС, необходимые для работы с этим приложением.

| **Операционная система** | **Минимальная версия** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Хотите помочь нам расширить список ОС, которые поддерживают клиент Outline? [Примите участие в разработке проекта](https://github.com/OutlineFoundation/outline-client#platform-specific-development) на GitHub.
