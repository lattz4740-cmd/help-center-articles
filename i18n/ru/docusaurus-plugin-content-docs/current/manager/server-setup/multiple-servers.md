---
title: Как настроить несколько серверов Outline
sidebar_label: Как настроить несколько серверов Outline
---

Чтобы настроить дополнительные серверы Outline, нажмите на значок "+" на панели навигации в левой части Менеджера Outline. Инструкции по добавлению нового сервера не отличаются от инструкций по установке первого.

- Количество серверов Outline, которые вы можете создать, не ограничено.
- Для каждого созданного сервера Outline необходимо создать соответствующую виртуальную машину.
- Создание дополнительных машин или дроплетов может повысить расходы на оплату услуг облачного сервиса. Проверьте свой тарифный пакет облачного сервиса, чтобы узнать о дополнительных затратах.

## Как создать дополнительный сервер Outline в DigitalOcean

Нажав на значок "+" и выбрав установку в DigitalOcean, выполните те же инструкции, что и для установки первого сервера. Кроме того, поскольку Менеджер Outline интегрирован с DigitalOcean, мы можем создать для вас дроплет так, чтобы вам не пришлось выходить из Менеджера Outline.

 Обратите внимание, что Менеджер Outline поддерживает только один аккаунт DigitalOcean за раз. Если вам нужно добавить или создать другие серверы Outline в других аккаунтах DigitalOcean, добавьте их как расширенную конфигурацию.

## Как создать дополнительный сервер в GCP, AWS или другом облачном сервисе

Сначала создайте новую виртуальную машину в выбранном облачном сервисе. Затем откройте Менеджер Outline и следуйте инструкциям по расширенной установке (возможно, вы уже выполняли их при первой настройке).
