---
title: "Сколько стоит использование сервиса Outline?"
sidebar_label: "Сколько стоит использование сервиса Outline?"
---

Программное обеспечение Outline является бесплатным для всех – как для администраторов сервера, управляющих VPN, так и для пользователей, использующих Outline для доступа в открытый Интернет.

 Однако для работы Outline требуется доступ к облачному сервису. Администраторы сервера, у которых уже есть доступ к серверу, могут установить Outline без дополнительных затрат. Если у вас нет доступа, вы можете получить его, оформив подписку на один из облачных сервисов, например [DigitalOcean](https://www.digitalocean.com/) или Amazon Web Services, стоимостью примерно 5 долларов США в месяц с пакетом трафика на 1 ТБ. Этого объема хватит для поддержки сотен пользователей на одном сервере.

 Ниже приведен пример расчета стоимости использования Outline с выбранным облачным сервисом.

| *Предположим, каждый пользователь в среднем расходует 5 ГБ трафика в месяц. В таком случае тарифный план на 5 долларов США в месяц позволит одновременно поддерживать работу около 200 пользователей. При этом расходы на каждого пользователя составят всего 2,5 цента в месяц. Обратите внимание, что использованный за месяц объем трафика может сильно отличаться в зависимости от высокой или низкой пропускной способности, однако большинство облачных сервисов применяют гибкую систему регулирования стоимости услуг при повышении трафика.* |
| --- |

Использование Outline является полностью анонимным для Jigsaw и Google. Мы не отслеживаем ваши персональные данные или трафик и не предлагаем план монетизации. Вместо этого мы сотрудничаем с сообществом разработчиков ПО с открытым исходным кодом, чтобы предоставлять пользователям бесплатное программное обеспечение.
