---
title: "Как изменить местоположение сервера Outline?"
sidebar_label: "Как изменить местоположение сервера Outline?"
---

После настройки сервера изменить его местоположение невозможно. Для этого вам потребуется удалить сервер Outline и создать новый.

Вместо этого можно изменить местоположение VPN-сервера с помощью [динамических ключей](https://developers.google.com/outline/docs/guides/service-providers/dynamic-access-keys). Они позволяют выбрать другое местоположение, сохранив ключи. Местоположение самих серверов при этом не изменяется.
