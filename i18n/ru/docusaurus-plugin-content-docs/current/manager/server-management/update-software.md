---
title: "Как обновить серверное ПО Outline?"
sidebar_label: "Как обновить серверное ПО Outline?"
---

Обновления безопасности устанавливаются на серверы Outline автоматически с помощью [Watchtower](https://github.com/v2tec/watchtower) – библиотеки с открытым исходным кодом, которая регулярно проверяет образ Docker, содержащий ПО Outline.

Кроме того, при установке с помощью Менеджера Outline программа настраивает задание Cron для автоматического обновления ПО и его перезагрузки, если она потребуется. Обновление выполняется с помощью функции [Unattended Upgrades](https://wiki.debian.org/UnattendedUpgrades) в Ubuntu. Обратите внимание, что эта функция не работает в расширенном режиме, чтобы сохранить заданные настройки, если хост также используется для других целей, помимо запуска Outline.
