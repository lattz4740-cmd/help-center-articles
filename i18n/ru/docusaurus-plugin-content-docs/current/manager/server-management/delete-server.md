---
title: "Как удалить сервер Outline?"
sidebar_label: "Как удалить сервер Outline?"
---

Большинство поставщиков облачных сервисов позволяют легко удалить определенную виртуальную машину, которую вы используете.

Если вы используете DigitalOcean, для удаления виртуальной машины нужно нажать на значок шестеренки и выбрать **Destroy Server (Удалить сервер)**. После этого вам будет предложено создать новую виртуальную машину и выбрать ее местоположение.

Обратите внимание, что сервер Outline будет безвозвратно удален, а его ключи доступа перестанут действовать. Чтобы не прерывать работу пользователей с сервером Outline, прежде чем удалять его,

и предоставьте доступ к нему.
