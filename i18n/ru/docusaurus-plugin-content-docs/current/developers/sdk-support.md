Этот справочный сайт предназначен для пользователей клиента и Менеджера Outline. Информацию для разработчиков вы найдете на GitHub. Чтобы получить помощь, опубликуйте свой вопрос на [доске обсуждений](https://github.com/Jigsaw-Code/outline-sdk/discussions) для Outline SDK. На ней можно задавать вопросы и отвечать на них, обмениваться идеями и делиться ссылками на демоверсии. Чтобы отправить отчет об ошибке или запрос на добавление функции, зарегистрируйте [проблему](https://github.com/Jigsaw-Code/outline-sdk/issues/new).
