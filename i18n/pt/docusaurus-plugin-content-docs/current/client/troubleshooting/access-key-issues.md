---
title: "E se a minha chave de acesso não funcionar?"
sidebar_label: "E se a minha chave de acesso não funcionar?"
---

Se lhe for apresentada a seguinte mensagem de erro: "A sua chave de acesso parece ser inválida. Se este problema ocorrer novamente, contacte a pessoa que lhe deu a chave de acesso". Siga os passos abaixo para resolver o problema:

1. Certifique-se de que insere a chave de acesso completa, incluindo os primeiros cinco carateres, "ss://", que podem não ser copiados automaticamente para a área de transferência. Segue-se um exemplo de uma chave de acesso completa (trata-se apenas de um exemplo; não funciona):

```
ss://Y2hhY2hhMjAtaWV0Zi1wb2x5MTMwNTp1eXhUQ3MzemVEMTk=@145.230.4.1:39485/?outline=1
```

1. A chave de acesso pode não ser copiada para a área de transferência devido à sua plataforma ou app de mensagens. É muito provável que isto aconteça quando recebe uma mensagem de alguém que não está na sua lista de contactos. Se copiar o código de uma mensagem, certifique-se de que o remetente está nos seus contactos e, em seguida, tente aceder novamente ao link.
2. Se concluiu os passos 1 e 2 e continua a receber a mensagem de erro, é provável que o servidor esteja bloqueado ou que a chave de acesso já não seja válida. Se for o gestor do serviço, tente gerar uma nova chave para si. Caso contrário, contacto o gestor do serviço para receber uma chave nova.
