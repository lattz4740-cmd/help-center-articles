title: "Quais são os requisitos de sistema para executar a aplicação cliente Outline?"
sidebar_label: "Quais são os requisitos de sistema para executar a aplicação cliente Outline?"
---

Pode experimentar o Outline em qualquer sistema operativo. As versões mínimas dos sistemas operativos necessárias são as seguintes:

| **Sistema operativo** | **Versão mínima** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Quer que a aplicação cliente Outline funcione em mais sistemas operativos? [Contribua para a nossa base de código](https://github.com/Jigsaw-Code/outline-client#platform-specific-development) no GitHub!
