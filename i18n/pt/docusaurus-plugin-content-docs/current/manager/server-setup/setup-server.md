A configuração de um servidor do Outline é o primeiro passo para poder usar o Outline. O utilizador ou alguém da sua confiança tem de configurar um servidor para que possa aceder à Internet aberta através do Outline.

## Antes de começar
 Antes de começar a configurar o servidor do Outline, precisa de alguns elementos:

1. Acesso aos seus próprios servidores ou a um fornecedor de serviços na nuvem, como o DigitalOcean, os serviços Web da Amazon (AWS) ou a Google Cloud Platform (GCP).

 Se não tiver imediatamente acesso a um servidor na nuvem, pode configurar facilmente uma conta com qualquer fornecedor, incluindo os indicados acima. É provável que precise de um cartão de crédito para se inscrever.
2. Um computador desktop com macOS 10.9 ou superior, Windows 7.0 ou superior ou Linux.
3. A aplicação Gestor Outline.

## Configure com o DigitalOcean
 Facilitámos a instalação do Outline no DigitalOcean com apenas alguns cliques. Depois de transferir e instalar o Gestor Outline no computador, pode selecionar a opção de configuração do DigitalOcean, que lhe dá orientações através de alguns ecrãs simples para configurar e instalar o seu servidor Outline.

## Configure com outro fornecedor de nuvem
 Depois de transferir e instalar o Gestor Outline, pode optar por instalar um servidor do Outline numa máquina virtual com AWS, GCP, DigitalOcean ou outro fornecedor. Cada ambiente é diferente. Por isso, incluímos instruções no fluxo de configuração do Gestor Outline para os fornecedores de nuvem mais comuns, incluindo como configurar as definições na sua máquina virtual antes de executar o script de instalação para instalar o Outline num servidor.
