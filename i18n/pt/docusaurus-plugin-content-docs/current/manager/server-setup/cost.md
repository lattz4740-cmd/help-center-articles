---
title: "Quanto custa executar o Outline?"
sidebar_label: "Quanto custa executar o Outline?"
---

O software Outline é gratuito para qualquer pessoa, quer seja um administrador de servidor que gere a VPN ou alguém que usa o Outline para aceder à Internet aberta.

 No entanto, o Outline requer acesso a um servidor na nuvem para ser executado. Os administradores de servidores que já têm acesso a um servidor podem instalar o Outline no mesmo sem custos adicionais. As pessoas sem acesso a um servidor podem receber acesso a partir de um fornecedor de serviços na nuvem, como o [DigitalOcean](https://www.digitalocean.com/) ou os serviços Web da Amazon, por cerca de 5 USD por mês para 1 terabyte de limite de transferência de dados, o que é suficiente para suportar centenas de utilizadores num único servidor.

 Um exemplo de como pode fazer os cálculos para determinar o custo de execução do Outline com o seu fornecedor de nuvem escolhido:

| *Assumindo uma utilização mensal média de 5 gigabytes de transferência de dados por utilizador, um plano de 5 USD por mês permitiria manter cerca de 200 utilizadores simultâneos, o que corresponde a um custo por utilizador de apenas 2,5 cêntimos por mês. Tenha em atenção que a transferência de dados usada por mês por utilizador varia bastante consoante os utilizadores estarem a fazer atividades que precisam de largura de banda baixa ou elevada, mas a maioria dos fornecedores de nuvem vai adaptar-se para acomodar os aumentos no tráfego.* |
| --- |

Na verdade, a utilização do Outline é totalmente anónima para o Jigsaw e a Google. Não monitorizamos a sua identidade nem o tráfego, e não existe um plano de rentabilização. Em alternativa, trabalhamos com a nossa comunidade de código aberto para garantir que podemos fornecer o software sem custo financeiro aos nossos utilizadores. Saiba mais acerca dos dados que recolhemos [aqui](https://getoutline.org/policies/data-collection).
