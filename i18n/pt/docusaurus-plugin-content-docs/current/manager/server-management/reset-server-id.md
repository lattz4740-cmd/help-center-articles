---
title: "Como posso repor o ID do servidor?"
sidebar_label: "Como posso repor o ID do servidor?"
---

O ID do servidor é um ID do lado do servidor gerado aleatoriamente quando cria um servidor do Outline. Pode encontrá-lo se optar por partilhar métricas anónimas na interface Definições. Pode encontrar o seu ID de servidor em: Definições => desloque a página para baixo => selecione "Partilhe métricas anónimas".

O ID do servidor combina as estatísticas de utilização anónimas comunicadas ao longo do tempo. Se quiser repor o ID do servidor e gerar um novo, tem de substituir o seu servidor do Outline atual por um novo.

Se estiver a usar o DigitalOcean como fornecedor de nuvem, pode repor o servidor acedendo a Definições e selecionando a opção Destruir servidor. Esta ação é irreversível e apaga as suas credenciais. Após esta ação, é-lhe pedido que crie um novo servidor numa localização à sua escolha e, em seguida, é gerado um novo ID do servidor.
