---
title: "Sou programador. Onde posso encontrar apoio técnico para integrar o Outline SDK na minha aplicação?"
sidebar_label: "Sou programador. Onde posso encontrar apoio técnico para integrar o Outline SDK na minha aplicação?"
---

Este Website de apoio técnico destina-se a utilizadores do Outline Manager e Outline Client. Os programadores devem usar o GitHub para receber apoio técnico. Para fazer uma pergunta, faça uma publicação no [fórum de discussão](https://github.com/Jigsaw-Code/outline-sdk/discussions) do SDK. A secção do fórum de discussão é um excelente local para fazer perguntas, partilhar ideias, publicar links para demonstrações e oferecer apoio técnico a outros programadores que usam o Outline SDK. Para enviar pedidos de funcionalidades ou relatórios de erros, use a opção [Problema](https://github.com/Jigsaw-Code/outline-sdk/issues/new).
