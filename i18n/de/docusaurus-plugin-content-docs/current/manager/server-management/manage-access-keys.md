---
title: "Zugriff auf einen Outline-Server (mithilfe von Zugriffsschlüsseln)"
sidebar_label: "Zugriff auf einen Outline-Server (mithilfe von Zugriffsschlüsseln)"
---

Nach der Einrichtung des Outline-Servers können Sie den Nutzerzugriff darauf verwalten. Personen, denen Sie eine Einladung senden, können die Outline App installieren und so ihren Internettraffic schützen.

**Zugriff auf Ihren Outline-Server freigeben**

 Sobald Sie einen Outline-Server eingerichtet haben, werden Sie im Outline-Manager zur Seite mit den Serverdetails weitergeleitet, wo Sie Zugriffsschlüssel erstellen können. [Weitere Informationen zu Zugriffsschlüsseln](/about/terminology)

- Schlüssel erstellen: Klicken Sie unten auf der Seite auf das kleine Symbol „+“.
- Schlüssel freigeben: Rechts neben jedem Schlüssel befindet sich ein Freigabesymbol, über das Sie Einladungen verwalten können. Kopieren Sie eine Einladung und fügen Sie sie in ein Nachrichtentool Ihrer Wahl ein.

**Funktionsanfrage: Zugriff direkt aus der App „Outline-Manager“ ermöglichen**

 Viele Serveradministratoren hätten gerne die noch einfachere Möglichkeit, Einladungen direkt im Outline-Manager an bestimmte E‑Mail-Adressen verschicken zu können.

Eines unserer Kernziele ist Datenschutz und Sicherheit für unsere Nutzer. Deshalb haben wir im Outline-Manager kein Feld für eine E-Mail-Adresse oder Kontaktdaten eingebaut.

Bitte verwenden Sie als Serveradministrator einen sicheren Kommunikationsweg, z. B. E-Mails oder einen Chat, um Nutzern die Einladung zu senden.

**Ablauf, nachdem ein Nutzer einen Zugrifssschlüssel erhalten hat**

1. Der Nutzer klickt auf seinem Gerät auf den Installationslink.
2. Er wird aufgefordert, die Outline App zu installieren, falls sie noch nicht auf dem Gerät vorhanden ist.
3. Er stellt über den einmaligen Schlüssel aus der Anleitung eine erste Verbindung mit Ihrem Outline-Server her.
4. Nun kann der Nutzer den Internetzugriff über den Outline-Server mithilfe der Schaltflächen „Verbinden“ und „Verbindung trennen“ steuern.

**Zugriff auf den Outline-Server entziehen**

 Auf der Seite „Serverdetails“ im Outline-Manager haben Sie über ein Menü rechts neben jedem Schlüssel für den Server die Möglichkeit, den Schlüssel zu löschen. Wenn Sie das tun, besteht mit ihm kein Zugriff mehr auf den Server.
