---
title: "Wie setze ich meine Server-ID zurück?"
sidebar_label: "Wie setze ich meine Server-ID zurück?"
---

Wenn Sie einen Outline-Server erstellen, erhält er eine Server-ID, die serverseitig nach dem Zufallsprinzip generiert wird. Wie sie lautet, sehen Sie, wenn Sie in den Einstellungen die Freigabe anonymer Messwerte aktivieren. So finden Sie die Server-ID: Einstellungen > scrollen Sie nach unten > wählen Sie „Anonymisierte Messwerte freigeben“ aus.

Unter der ID sind anonymisierte Nutzungsstatistiken zusammenfassend dargestellt. Sie können die ID nur zurücksetzen, wenn Sie den Outline-Server durch einen neuen ersetzen.

Bei DigitalOcean rufen Sie die Einstellungen auf und wählen „Destroy Server“ (Server löschen) aus. Achtung: Diese Entscheidung lässt sich nicht rückgängig machen und es werden auch alle Anmeldedaten gelöscht. Unmittelbar danach wird angeboten, einen neuen Server an einem beliebigen Standort zu erstellen. Dabei wird auch eine neue Server-ID generiert.
