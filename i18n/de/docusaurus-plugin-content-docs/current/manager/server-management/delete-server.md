---
title: "Wie lösche ich den Outline-Server?"
sidebar_label: "Wie lösche ich den Outline-Server?"
---

Bei den meisten Cloud-Anbietern lässt sich eine einzelne virtuelle Maschine recht einfach löschen.

Bei DigitalOcean klicken Sie dazu auf das Zahnrad und wählen „Destroy Server“ (Server löschen) aus. Unmittelbar danach wird angeboten, eine neue virtuelle Maschine an einem beliebigen Standort zu erstellen.

Wenn Sie einen Outline-Server entfernen, wird er endgültig gelöscht und die dazugehörigen Zugriffsschlüssel funktionieren nicht mehr. Wenn Sie möchten, dass Nutzer ohne Unterbrechung weiter über Outline zugreifen können, müssen Sie erst einen [neuen Outline-Server einrichten](/manager/server-setup/setup-server) und den Zugriff darauf teilen, bevor Sie den alten löschen.
