---
title: "Mehrere Outline-Server einrichten"
sidebar_label: "Mehrere Outline-Server einrichten"
---

Wenn Sie zusätzliche Outline-Server einrichten möchten, klicken Sie im Navigationsbereich auf der linken Seite des Outline-Managers auf „+“. Die weiteren Schritte sind identisch mit denen beim Erstellen des ersten Servers.

- Sie können beliebig viele Outline-Server erstellen.
- Für jeden Outline-Server benötigen Sie eine entsprechende virtuelle Maschine.
- Zusätzliche Maschinen („Droplets“ bei DigitalOcean) können zu höheren Gebühren bei Ihrem Cloud-Anbieter führen. Bitte klären Sie dies mit ihm ab, um zu wissen, was auf Sie zukommt.

## Zusätzlichen Outline-Server erstellen (DigitalOcean)

Nachdem Sie auf "+" geklickt und sich für die Installation bei DigitalOcean entschieden haben, gehen Sie genauso vor wie bei der Einrichtung des ersten Servers. Da der Outline-Manager in DigitalOcean integriert ist, müssen Sie zum Erstellen des Droplets nicht einmal die Anwendung wechseln.

In Outline werden jedoch nicht mehrere DigitalOcean-Konten gleichzeitig unterstützt. Wenn Sie über andere DigitalOcean-Konten Outline-Server erstellen bzw. hinzufügen möchten, müssen Sie die Option für die erweiterte Konfiguration verwenden.

## Zusätzlichen Outline-Server erstellen (über die GCP, AWS, usw.)

Zuerst erstellen Sie eine neue virtuelle Maschine beim gewünschten Cloud-Anbieter. Anschließend öffnen Sie den Outline-Manager und gehen für die erweiterte Installation genauso vor wie bei der Einrichtung des ersten Servers.
