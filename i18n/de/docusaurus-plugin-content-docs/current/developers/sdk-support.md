title: "Ich entwickle Software. Wo finde ich Unterstützung bei der Integration des Outline SDK in meine Anwendung?"
sidebar_label: "Ich entwickle Software. Wo finde ich Unterstützung bei der Integration des Outline SDK in meine Anwendung?"
---

Diese Supportwebsite richtet sich an Nutzer von Outline Manager und Outline Client. Entwickler erhalten Support über GitHub. Wenn Sie eine Frage stellen möchten, posten Sie diese bitte im [SDK-Diskussionsforum](https://github.com/Jigsaw-Code/outline-sdk/discussions). Im SDK-Diskussionsforum können Sie Fragen stellen, Ideen austauschen, Links zu Demos veröffentlichen und anderen Entwicklern mit ihren Problemen helfen. Erstellen Sie für Funktionsanfragen oder Fehlerberichte bitte stattdessen ein [Issue](https://github.com/Jigsaw-Code/outline-sdk/issues/new).
