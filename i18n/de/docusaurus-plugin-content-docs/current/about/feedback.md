sidebar_label: Feedback senden und Vorschläge machen
---

Danke, dass Sie uns helfen möchten, Outline zu verbessern. Sie haben verschiedene Möglichkeiten, uns Feedback zu senden, entweder anonym oder, falls Sie eine Antwort erhalten möchten, unter Angabe Ihrer E-Mail-Adresse:

- **Für Entwickler**: Outline ist eine Open-Source-Software und der gesamte Code liegt auf [GitHub](https://github.com/jigsaw-Code/?q=outline). Sie können Ihre Ideen auf GitHub oder in der [Reddit](https://www.reddit.com/r/outlinevpn/)-Community mit anderen teilen.

- **Für Nutzer**: Sie haben die Möglichkeit, uns Feedback über die Outline Apps oder über den Outline-Manager zu senden. Geben Sie dabei Ihre E-Mail-Adresse an, damit wir Ihnen antworten können. Zusätzlich erheben wir Metadaten über Ihre Umgebung, z. B. über Ihren Browser, das verwendete Betriebssystem und die Version der Software, um Ihnen bei der Lösung von Problemen zu helfen.

- **Über diese Website**: Klicken Sie einfach auf dieser Website auf den Link "Kontakt".

- **Schwere Fehler**: Bei schweren Fehlern bitten wir Sie, direkt eine E-Mail mit Details an security[at][getoutline.org](https://getoutline.org/) zu senden.

Nochmals vielen Dank dafür, dass Sie uns Ihre Ideen mitteilen.
