---
title: "Welche Systemanforderungen gelten für die Ausführung des Outline-Clients?"
sidebar_label: "Welche Systemanforderungen gelten für die Ausführung des Outline-Clients?"
---

Sie können Outline auf jedem Betriebssystem ausführen. Im Folgenden finden Sie die Mindestanforderungen an das Betriebssystem:

| **Betriebssystem** | **Mindestversion** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Möchten Sie dazu beitragen, dass Outline-Client auf noch mehr Betriebssystemen verfügbar ist? [Dann teilen Sie uns Ihre Codebasis auf GitHub mit](https://github.com/Jigsaw-Code/outline-client#platform-specific-development).
