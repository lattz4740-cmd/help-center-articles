---
title: "Wieso kann ich den Outline-Client nicht unter Windows installieren?"
sidebar_label: "Wieso kann ich den Outline-Client nicht unter Windows installieren?"
---

Dieses Problem wird durch eine Fehlermeldung wie die folgende angezeigt: „Outline wurde anscheinend nicht korrekt installiert. Bitte versuchen Sie es noch einmal. Falls das Problem weiterhin besteht, [senden Sie uns Feedback über die App](https://support.getoutline.org/s/contactsupport?).“

Wenn Sie Outline unter Windows verwenden, kann ein unerwarteter Fehler auftreten. In den meisten Fällen muss dann der TAP-Adapter für Outline (Treiber) gelöscht und Outline neu installiert werden.

Die genauen Schritte unterscheiden sich je nach Version Ihres Windows-Betriebssystems. Unten finden Sie jedoch eine allgemeine Anleitung, mit der Sie den TAP-Adapter und Outline deinstallieren und dann neu installieren können.

1. Den TAP-Adapter für den Outline-Client deinstallieren
   1. Rufen Sie **Geräte-Manager**und dann **Netzwerkadapter** auf.
   2. Suchen Sie die Datei **TAP-Windows Adapter V9** oder den mit Outline verknüpften TAP-Adapter.
   3. Deinstallieren oder löschen Sie den Adapter. Denken Sie daran, dass dies Auswirkungen auf andere installierte VPN-Apps haben kann.
2. Outline-Client deinstallieren
   1. Rufen Sie **Programme und Funktionen** und dann **Programm deinstallieren** auf.
   2. Suchen Sie die Outline-Client-App und deinstallieren Sie sie.
   3. [Laden Sie](https://getoutline.org/get-started/#step-3)die aktuelle Version des Outline-Clients herunter und installieren Sie sie noch einmal auf Ihrem Windows-Gerät. Damit sollte automatisch ein neuer TAP-Adapter installiert werden.
