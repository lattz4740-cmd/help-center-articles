---
title: "Warum kann ich nicht auf das Internet zugreifen, obwohl ich mit dem Outline-Server verbunden bin?"
sidebar_label: "Warum kann ich nicht auf das Internet zugreifen, obwohl ich mit dem Outline-Server verbunden bin?"
---

Falls Sie ein Smartphone verwenden, können Sie es mit einer anderen Verbindung versuchen, d. h. von den mobilen Daten zum WLAN wechseln oder umgekehrt. Manchmal funktioniert nur eines von beidem. Wenn Sie den Zugriff über einen Computer herstellen, trennen Sie am besten die Breitbandinternetverbindung und verbinden Sie neu.

Wenn dieses Problem weiterhin auftritt, kann es an Ihrem Outline-Server liegen. Fordern Sie dann von Ihrem [Administrator](/about/terminology) einen neuen Schlüssel für einen anderen Server an. Sie können ihn auch bitten, dass Datenlimit Ihres [Zugriffsschlüssels](/about/terminology) zu prüfen und es zu erhöhen, falls eine Kontingentüberschreitung vorliegt.
