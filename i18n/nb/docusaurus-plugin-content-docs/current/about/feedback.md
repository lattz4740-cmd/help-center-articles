title: Slik sender du tilbakemeldinger eller forslag
sidebar_label: Slik sender du tilbakemeldinger eller forslag
---

Takk for at du hjelper oss med å gjøre Outline enda bedre. Du kan sende tilbakemeldinger på flere måter. Oppgi e-postadressen din hvis du trenger svar, eller skriv anonymt:

- **For utviklere**: Outline er programvare med åpen kildekode, og all koden vår ligger på [GitHub](https://github.com/OutlineFoundation/?q=outline). Du kan dele ideene dine på GitHub eller i [Reddit](https://www.reddit.com/r/outlinevpn/)-fellesskapet vårt.
- **Brukere**: Du kan sende oss tilbakemelding via Outline- eller Outline-administrator-appen. Fortell oss hva tilbakemeldingen dreier seg om, og oppgi eventuelt e-postadressen din slik at vi kan svare deg. Vi samler også inn noen metadata, blant annet om operativsystemet ditt og nettleseren og programvareversjonen din, slik at vi kan hjelpe deg med feilsøking.
- **På dette nettstedet**: Du kan klikke på kontaktlinken der du ser den på dette nettstedet.
- **Alvorlige problemer**: Hvis du vil melde fra om et alvorlig sikkerhetsproblem, er det fint om du kan sende en e-post med detaljert informasjon til security [at] [getoutline.org](https://getoutline.org/).

Vi er takknemlige for at du tok deg tid til å dele tilbakemeldingen din med oss.
