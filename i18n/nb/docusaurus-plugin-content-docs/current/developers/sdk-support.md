---
title: "Jeg er en utvikler. Hvor kan jeg få hjelp med å integrere Outline SDK i appen min?"
sidebar_label: "Jeg er en utvikler. Hvor kan jeg få hjelp med å integrere Outline SDK i appen min?"
---

Dette brukerstøttenettstedet er for Outline-administratorer og -klientbrukere. Utviklere kan få brukerstøtte via GitHub. Hvis du har spørsmål, kan du legge ut et innlegg på [SDK-diskusjonsforumet](https://github.com/Jigsaw-Code/outline-sdk/discussions). I diskusjonsforumet kan du stille spørsmål, dele ideer, legge ut linker til demoer og støtte andre utviklere som bruker Outline SDK. For funksjonsforespørsler eller feilrapporter bør du opprette et [problem](https://github.com/Jigsaw-Code/outline-sdk/issues/new) i stedet.
