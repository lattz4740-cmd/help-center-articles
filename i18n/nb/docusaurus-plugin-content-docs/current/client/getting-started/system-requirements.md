---
title: "Hva er systemkravene for bruk av Outline-klienten?"
sidebar_label: "Hva er systemkravene for bruk av Outline-klienten?"
---

Outline fungerer på de fleste operativsystemer. Her ser du de laveste tillatte versjonene for hvert operativsystem:

| **Operativsystem** | **Laveste tillatte versjon** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| MacOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Vil du hjelpe til med å få Outline-klienten til å fungere på flere operativsystemer? [Bidra til kodebasen vår](https://github.com/Outline-Foundation/outline-client#platform-specific-development) på GitHub.
