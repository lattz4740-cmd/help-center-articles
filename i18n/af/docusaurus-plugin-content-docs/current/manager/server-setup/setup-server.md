title: "Hoe kan ek ’n Outline-bediener opstel?"
sidebar_label: "Hoe kan ek ’n Outline-bediener opstel?"
---

Opstel van ’n Outline-bediener is die eerste stap in die gebruik van Outline. Jyself, of iemand wat jy vertrou, moet ’n bediener vir jou opstel sodat jy deur Outline aan die oop internet kan koppel.

**Voordat jy begin**

 Jy sal ’n paar goed nodig hê voordat jy begin om jou Outline-bediener op te stel:

1. Toegang tot jou eie bedieners of ’n wolkdiensverskaffer, soos DigitalOcean, Amazon Web Services (AWS) of Google Cloud Platform (GCP).

 As jy nie onmiddellik toegang tot ’n wolkbediener het nie, kan jy maklik ’n rekening opstel met enige verskaffer, insluitend dié wat hier bo gelys word. Jy sal bes moontlik ’n kredietkaart benodig om aan te sluit.
2. ’n Rekenaar wat werk met macOS 10.9+, Windows 7.0+ of Linux.
3. Die Outline Manager-app.

**Stel op met DigitalOcean**

 Ons het dit maklik gemaak vir enigiemand om Outline met ’n paar klikke op DigitalOcean te installeer. Nadat jy Outline Manager op jou rekenaar afgelaai en geïnstalleer het, kan jy die DigitalOcean-opstellingopsie kies wat jou sal lei deur ’n paar eenvoudige skerms om jou Outline-bediener op te stel en te installeer.

**Stel met ’n ander wolkverskaffer op**

 Nadat jy Outline Manager afgelaai en geïnstalleer het, kan jy kies om ’n Outline-bediener op ’n virtuele masjien te installeer met AWS, GCP, DigitalOcean, of ’n ander verskaffer. Elke omgewing is anders, en dus het ons instruksies ingesluit binne die Outline Manager-opstellingsvloei vir die mees algemene wolkdiensverskaffers, insluitend hoe om die instellings op jou virtuele masjien op te stel voordat jy die installeringskrip laat loop om Outline op ’n bediener te installeer.
