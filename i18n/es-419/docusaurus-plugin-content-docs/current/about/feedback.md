---
title: Cómo enviar comentarios o sugerencias
sidebar_label: Cómo enviar comentarios o sugerencias
---

Gracias por ayudarnos a mejorar Outline. Hay distintas maneras de enviar comentarios, ya sea de forma anónima o con tu dirección de correo electrónico, si es que necesitas recibir una respuesta:

- **Para desarrolladores**: Outline es software de código abierto, y todo nuestro código se encuentra en [GitHub](https://github.com/jigsaw-Code/?q=outline). Puedes compartir tus ideas en GitHub o en nuestra comunidad de [Reddit](https://www.reddit.com/r/outlinevpn/).
- **Para usuarios**: Puedes enviarnos comentarios a través de Outline o las apps de Outline Manager. Cuéntanos de qué se tratan tus comentarios y, si lo deseas, agrega una dirección de correo electrónico para que podamos responderte. También recopilamos algunos metadatos de tu entorno (como el navegador, el sistema operativo y la versión de software) para ayudarte a solucionar problemas.
- **En este sitio**: Puedes hacer clic en el vínculo de contacto en cualquier parte que lo veas en este sitio.
- **Problemas graves**: Si quieres informarnos de un problema de seguridad grave, puedes enviarnos un correo electrónico con los detalles a security [arroba] [getoutline.org](https://getoutline.org/).

Gracias por tomarte el tiempo para compartir tus opiniones con nosotros.
