---
title: "Soy desarrollador. ¿Dónde puedo encontrar asistencia para integrar el SDK de Outline en mi aplicación?"
sidebar_label: "Soy desarrollador. ¿Dónde puedo encontrar asistencia para integrar el SDK de Outline en mi aplicación?"
---

Este sitio web de asistencia está destinado a usuarios de Outline Manager y de clientes. Los desarrolladores deben usar GitHub para obtener asistencia. Para hacer una pregunta, publícala en el [tablero de debate](https://github.com/Jigsaw-Code/outline-sdk/discussions) del SDK. La sección del tablero de debate es una excelente herramienta para formular preguntas, compartir ideas, vincular a demostraciones y apoyar a otros desarrolladores que usan el SDK de Outline. Para enviar solicitudes de funciones o informes de errores, abre un ticket para el [problema](https://github.com/Jigsaw-Code/outline-sdk/issues/new).
