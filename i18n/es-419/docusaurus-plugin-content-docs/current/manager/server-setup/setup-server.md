Para poder usar Outline, el primer paso consiste en configurar un servidor de Outline. Tú o alguien de confianza deben configurar el servidor para que puedas conectarte a Internet abierta a través de Outline.

## Antes de comenzar
 Antes de comenzar a configurar tu servidor de Outline, necesitarás lo siguiente:

1. Acceso a tus propios servidores o un proveedor de servicios en la nube, como DigitalOcean, Amazon Web Services (AWS) o Google Cloud

 Si no tienes acceso inmediato a un servidor en la nube, es fácil configurar una cuenta con cualquier proveedor, incluidos los que se mencionaron anteriormente. Es probable que necesites una tarjeta de crédito para poder registrarte.
2. Una computadora que ejecute macOS 10.9 (o una versión posterior), Windows 7 (o una versión posterior) o Linux
3. La app de Outline Manager

## Cómo configurar Outline con DigitalOcean
 Permitimos que todas las personas puedan instalar Outline fácilmente en DigitalOcean con unos pocos clics. Luego de descargar e instalar Outline Manager en tu computadora, podrás seleccionar la opción de configuración de DigitalOcean, la cual te guiará a lo largo de algunas pantallas simples para que puedas configurar e instalar tu servidor de Outline.

## Cómo configurar Outline con otro proveedor de servicios en la nube
 Después de que descargues e instales Outline Manager, puedes instalar un servidor de Outline en una máquina virtual con AWS, Google Cloud, DigitalOcean o cualquier otro proveedor. Todos los entornos son diferentes, por lo que incluimos instrucciones en el flujo de configuración de Outline Manager para los proveedores de servicios en la nube más populares, incluidas instrucciones para definir la configuración en la máquina virtual antes de ejecutar la secuencia de comandos para instalar Outline en un servidor.
