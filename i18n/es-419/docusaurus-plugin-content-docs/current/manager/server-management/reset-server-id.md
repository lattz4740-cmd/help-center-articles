---
title: "¿Cómo puedo restablecer el ID de mi servidor?"
sidebar_label: "¿Cómo puedo restablecer el ID de mi servidor?"
---

Cuando creas un servidor de Outline, este genera su propio ID de forma aleatoria. Podrás encontrarlo cuando aceptes el uso compartido de métricas anónimas en la interfaz de configuración. Para encontrar el ID del servidor, ve a Configuración, desplázate hasta el final y marca "Compartir métricas anónimas".

El ID del servidor vincula las estadísticas de uso anónimas que se informan con el paso del tiempo. Si quieres restablecer el ID del servidor y obtener otro, debes reemplazar el servidor de Outline existente por uno nuevo.

Si usas DigitalOcean como proveedor de servicios en la nube, puedes restablecer el servidor visitando Configuración y seleccionando Destruir servidor. Esta acción es irreversible y borrará todas tus credenciales. Inmediatamente después, se te solicitará que crees un servidor nuevo en una ubicación de tu preferencia y se generará un nuevo ID de servidor.
