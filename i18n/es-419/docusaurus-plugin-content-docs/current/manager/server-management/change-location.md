---
title: "¿Cómo cambio la ubicación del servidor de Outline?"
sidebar_label: "¿Cómo cambio la ubicación del servidor de Outline?"
---

La ubicación del servidor no puede cambiarse una vez configurada. Para ejecutar el servidor desde otra ubicación, bórralo y crea uno nuevo.

Como alternativa, puedes cambiar la ubicación de la VPN con las [claves dinámicas](https://developer.getoutline.org/vpn/management/dynamic-access-keys/), que te permiten rotar servidores y conservar las mismas claves. No se modificará la ubicación de los servidores.
