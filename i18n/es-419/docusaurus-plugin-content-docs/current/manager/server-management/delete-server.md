---
title: "¿Cómo borro mi servidor de Outline?"
sidebar_label: "¿Cómo borro mi servidor de Outline?"
---

Para la mayoría de los proveedores de servicios en la nube es bastante sencillo quitar la máquina virtual específica que usas.

Si usas DigitalOcean como tu proveedor de servicios en la nube, puedes borrar tu máquina virtual existente haciendo clic en el botón de engranaje y seleccionando **Destruir servidor**. Inmediatamente después, se te solicitará crear una máquina virtual nueva en una ubicación de tu preferencia.

Si quitas un servidor de Outline, este se borrará de forma definitiva y sus claves de acceso dejarán de funcionar. Si no quieres que se interrumpa el acceso para las personas a través de Outline, debes [configurar un nuevo servidor de Outline](https://support.google.com/outline/answer/15331530?sjid=5147938692963654551-NC) y compartir el acceso antes de borrar el anterior.
