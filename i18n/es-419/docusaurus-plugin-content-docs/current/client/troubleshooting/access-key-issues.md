---
title: "¿Qué ocurre si no funciona mi clave de acceso?"
sidebar_label: "¿Qué ocurre si no funciona mi clave de acceso?"
---

Si recibes el mensaje de error “Parece que tu clave de acceso no es válida. Si vuelve a suceder lo mismo, comunícate con el administrador del servicio”, sigue los pasos que se indican a continuación para solucionar el problema:

1. Asegúrate de ingresar la clave de acceso completa, incluidos los primeros cinco caracteres, “ss://”, que pueden no copiarse automáticamente en el portapapeles. Así se ve una clave de acceso completa (es solo un ejemplo no funcional):

```
ss://Y2hhY2hhMjAtaWV0Zi1wb2x5MTMwNTp1eXhUQ3MzemVEMTk=@145.230.4.1:39485/?outline=1
```

1. Si no se copia en el portapapeles la clave de acceso, es posible que el problema esté relacionado con tu plataforma o app de mensajería. Es más probable que ocurra si recibes un mensaje de alguien que no se encuentra en tu lista de contactos. Si copias el código de un mensaje, asegúrate de que el remitente esté agregado a tus contactos y, luego, intenta acceder al vínculo de nuevo.
2. Si completaste los pasos 1 y 2, y sigues recibiendo el mensaje de error, es probable que el servidor esté bloqueado o que la clave de acceso ya no sea válida. Si eres el administrador del servicio, intenta generar una clave nueva para ti. De lo contrario, comunícate con el administrador del servicio para obtener una clave nueva.
