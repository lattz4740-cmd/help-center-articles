---
title: "¿Por qué no puedo acceder a Internet incluso si tengo una conexión al servidor de Outline?"
sidebar_label: "¿Por qué no puedo acceder a Internet incluso si tengo una conexión al servidor de Outline?"
---

Si usas un teléfono celular, cambia entre las conexiones de datos móviles y Wi-Fi. A veces, un tipo de conexión funciona cuando otro no. Si usas una computadora, desconéctate de la banda ancha y vuelve a conectarte.

Si las dificultades persisten, es probable que haya un problema con el servidor de Outline. Comunícate con el [administrador del servicio](/about/terminology) para obtener una clave de acceso nueva y poder acceder a un servidor alternativo. Tal vez la empresa pueda incrementar el límite de datos de tu[clave de acceso](/about/terminology) si esta excedió su cuota.
