---
title: "¿Cuáles son los requisitos de sistema para ejecutar el cliente de Outline?"
sidebar_label: "¿Cuáles son los requisitos de sistema para ejecutar el cliente de Outline?"
---

Puedes probar Outline en cualquier sistema operativo. Estas son las versiones requeridas mínimas de los sistemas operativos:

| **Sistema operativo** | **Versión mínima** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

¿Quieres ayudar a que el cliente de Outline funcione en más sistemas operativos? [Contribuye a nuestra base de código](https://github.com/Jigsaw-Code/outline-client#platform-specific-development) en GitHub.
