1. Хэрэв таны хандалтын түлхүүр түр санах ойд тань огт хуулагдахгүй байвал энэ асуудал таны мессеж апп эсвэл платформоос үүдэлтэй байж магадгүй. Энэ нь та харилцагчийн жагсаалтдаа байхгүй хэн нэгнээс мессеж хүлээн авахад ихэвчлэн тохиолдох магадлалтай.
