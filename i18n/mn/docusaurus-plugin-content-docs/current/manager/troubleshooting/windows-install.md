sidebar_label: "Би яагаад Outline Manager-г Windows дээр суулгах боломжгүй байна вэ?"
---

Та энэ алдааны мессежийг харж магадгүй: “Уучлаарай, Outline-г зохих ёсоор суулгаагүй бололтой. Үүнийг дахин суулгахаар оролдоно уу. Хэрэв энэ нь ажиллахгүй байвал [санал хүсэлт илгээнэ үү](https://support.getoutline.org/s/contactsupport?).”

Хэрэв та Outline-г Windows дээр ашиглаж байвал үе үе гэнэтийн алдаатай тулгарч магадгүй. Ихэнх тохиолдолд Outline TAP адаптерыг (драйвер) устгаж, Outline-г дахин суулгах шаардлагатай.

Таны Windows үйлдлийн системийн хувилбараас хамааран хийх алхмууд харилцан адилгүй байж болох ч TAP адаптер, Outline Manager-г хэрхэн устгах, мөн дараа нь Outline Manager-г дахин суулгах талаарх ерөнхий алхмуудыг доор харуулав.

1. Outline Manager-н TAP адаптерыг устгах
   1. Төхөөрөмжийн менежер, дараа нь Сүлжээний адаптер луу очно уу
   2. “TAP-Windows Adapter V9 файлыг эсвэл Outline-тай холбоотой TAP адаптерыг олно уу
   3. Энэ адаптерыг устгана уу. Энэ нь таны суулгасан бусад VPN аппад нөлөөлж болохыг анхаарна уу.
2. Outline Manager-г устгах
   1. Программ, Онцлогууд, дараа нь Программыг устгах руу очно уу
   2. Outline Manager аппыг олж, Outline Manager-г устгана уу
   3. [Outline Manager-н хамгийн сүүлийн хувилбарыг татаж](https://getoutline.org/get-started/#step-1), Windows төхөөрөмж дээрээ дахин суулгана уу. Шинэ суулгалт нь шинэ TAP адаптерыг автоматаар суулгах ёстой.

Хэрэв танд асуудал гарсан хэвээр байвал [тусламжтай холбогдоно уу](https://support.getoutline.org/s/contactsupport?).
