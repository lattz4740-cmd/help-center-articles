---

Та VPN-г удирддаг серверийн администратор эсвэл нээлттэй интернэтэд хандахын тулд Outline-г ашиглаж буй нэгэн ч бай Outline программ хангамж хүн бүрд үнэ төлбөргүй байдаг.

 Гэхдээ Outline-г ажиллуулахад үүлэн серверт хандах эрх шаардлагатай байдаг. Серверт аль хэдийн хандах эрхтэй серверийн администраторууд Outline-г тухайн сервер дээр ямар ч нэмэлт зардалгүйгээр суулгах боломжтой. Серверт хандах эрхгүй хүмүүс [DigitalOcean](http://www.digitalocean.com/), Amazon Web Services зэрэг үүлэн үйлчилгээ үзүүлэгчдээс хандах эрхийг сарын 5 ам.доллароор 1 терабайт өгөгдөл дамжуулах зөвшөөрөлтэйгөөр авах боломжтой. Энэ нь нэг серверт зуу зуун хэрэглэгчийг дэмжихэд хангалттай юм.

 Та сонгосон үүлэн үйлчилгээ үзүүлэгчээрээ Outline-г ажиллуулахад хэр их зардал гарахыг тодорхойлохын тулд дараах байдлаар тооцоолж болно. Жишээлбэл:

| *Нэг хэрэглэгч сард дунджаар 5 гигабайтын өгөгдөл дамжуулалтын хэрэглээтэй байна гэж үзвэл сарын 5 ам.долларын багц нь 200 орчим хэрэглэгчид нэгэн зэрэг ашиглах боломжийг олгох бөгөөд ингэснээр нэг хэрэглэгчийн сарын төлбөр ердөө 2,5 цент болно. Хэрэглэгчид бага эсвэл өндөр зурвасын өргөнтэй үйл ажиллагаа явуулж байгаа эсэхээс хамаарч хэрэглэгч бүрийн сард ашигладаг өгөгдөл дамжуулалт ихээхэн ялгаатай байх боловч ихэнх үүлэн үйлчилгээ үзүүлэгч ачаалал нэмэгдэж буйг харгалзан уян хатан ажиллах болно.* |
| --- |

Үнэн хэрэгтээ, Outline-г ашиглахад Jigsaw болон Google-д бүрэн нэргүй байна. Бид таны таниулбар, ачааллыг хянадаггүй бөгөөд мөнгө олох ямар ч төлөвлөгөө байхгүй. Үүний оронд бид нээлттэй эх кодын нийгэмлэгтэйгээ хамтран ажиллаж, хэрэглэгчдэдээ энэ программ хангамжийг ямар ч үнэ төлбөргүй олгох боломжтой. Бидний цуглуулдаг өгөгдлийн талаар [эндээс](/about/data-collection) нэмэлт мэдээлэл авна уу.
