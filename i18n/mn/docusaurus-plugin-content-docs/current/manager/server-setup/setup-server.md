---

Outline сервер тохируулах нь Outline-г ашиглах боломжтой болох эхний алхам юм. Та Outline-р нээлттэй интернэтэд холбогдохын тулд та өөрөө эсвэл таны итгэдэг хэн нэгэн сервер тохируулах ёстой.

## Та эхлэхийн өмнө
Та Outline серверээ тохируулж эхлэхийн өмнө танд цөөн хэдэн зүйл хэрэг болно:

1. Өөрийн серверүүд эсвэл DigitalOcean, Amazon Web Services (AWS), Google Cloud Platform (GCP) зэрэг үүлэн үйлчилгээ үзүүлэгчдэд хандах эрх.

    Хэрэв танд үүлэн серверт даруй хандах эрх байхгүй бол та дээр жагсаасныг оруулаад дурын үйлчилгээ үзүүлэгчид бүртгэл хялбархан тохируулах боломжтой. Бүртгүүлэхийн тулд танд кредит карт шаардлагатай байж магадгүй.
2. MacOS 10.9+, Windows 7.0+ эсвэл Linux-г ажиллуулж буй суурин компьютер.
3. Outline Manager аппликэйшн.

## DigitalOcean-р тохируулах
Бид цөөн хэдэн товшилтоор DigitalOcean дээр Outline-г суулгахыг хүн бүрд хялбар болгосон. Компьютер дээрээ Outline Manager-г татаж, суулгасны дараа та хэдэн хялбар дэлгэцээр Outline серверээ тохируулж, суулгахад хөтлөх DigitalOcean-н тохируулгын сонголтыг сонгож болно.

## Өөр үүлэн үйлчилгээ үзүүлэгчээр тохируулах
Та Outline Manager-г татаж, суулгасны дараа AWS, GCP, DigitalOcean эсвэл өөр үйлчилгээ үзүүлэгчээр Outline серверийг виртуал машин дээр суулгахаар сонгож болно. Орчин бүр өөр тул бид Outline Manager-н тохируулгын урсгалд серверт Outline-г суулгах суулгалтын скриптийг ажиллуулахаасаа өмнө виртуал машиныхаа тохиргоог хэрхэн тохируулах зэрэг хамгийн нийтлэг үүлэн үйлчилгээ үзүүлэгчдийн зааварчилгааг багтаасан.
