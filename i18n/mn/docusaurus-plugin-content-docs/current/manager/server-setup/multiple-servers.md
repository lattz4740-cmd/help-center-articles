Outline-н нэмэлт сервер тохируулахын тулд Outline Manager аппликэйшнийхээ зүүн талд байх навигацын түр зуурын самбарын “+” дүрс тэмдэг дээр товшино уу. Шинэ сервер нэмэх зааварчилгаа нь анхны серверээ суулгаж байгаатай адил байна.

- Бид таны үүсгэж болох Outline-н серверийн тоог хязгаарладаггүй.
- Таны үүсгэх Outline-н сервер бүрд танд харгалзах виртуал машин шаардлагатай болно.
- Нэмэлт машин эсвэл droplet үүсгэх нь таны үүлэн үйлчилгээ үзүүлэгчийн хураамжийг нэмэгдүүлж магадгүй. Та ямар хүлээлттэй байхаа мэдэхийн тулд үнийн багцаа үүлэн үйлчилгээ үзүүлэгчээсээ шалгана уу.

## DigitalOcean-д Outline-н нэмэлт сервер үүсгэх

Та + дүрс тэмдгийг товшиж, DigitalOcean-д суулгахаар сонгосны дараа эхний серверээ тохируулахдаа дагасантайгаа ижил зааварчилгааг дагана. Мөн Outline Manager нь DigitalOcean-тай нэгддэг тул та Outline Manager аппаас хэзээ ч гарах шаардлагагүйгээр бид танд зориулж droplet үүсгэх боломжтой.

Outline Manager нэг удаад зөвхөн нэг DigitalOcean бүртгэл дэмжих боломжтойг анхаарна уу. Хэрэв DigitalOcean-н бусад бүртгэлээс Outline-н бусад серверийг нэмэх эсвэл үүсгэх хүсэлтэй байвал та тэдгээрийг нарийвчилсан тохируулга байдлаар нэмэх боломжтой.

## GCP, AWS эсвэл өөр үүлэн үйлчилгээ үзүүлэгч дээр Outline-н нэмэлт сервер үүсгэх

Сонгосон үүлэн үйлчилгээ үзүүлэгчээрээ шинэ виртуал машин үүсгэж эхэлнэ үү. Дараа нь Outline Manager-г нээж, анх удаа суулгасантай адилаар дэвшилтэт суулгалтын зааварчилгааг гүйцээнэ үү.
