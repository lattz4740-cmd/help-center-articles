---
title: "Би Outline серверээ хэрхэн устгах вэ?"
sidebar_label: "Би Outline серверээ хэрхэн устгах вэ?"
---

Ихэнх үүлэн үйлчилгээ үзүүлэгчийн хувьд ашиглаж буй тодорхой виртуал машиныг хасах нь нэлээд хялбар байдаг.

Хэрэв та DigitalOcean-г үүлэн үйлчилгээ үзүүлэгчээрээ ашиглаж байгаа бол арааны товчин дээр товшиж, Сервер устгахыг сонгосноор одоо байгаа виртуал машинаа устгах боломжтой. Үүний дараа тэр даруй таны сонгосон байршилд шинэ виртуал машин үүсгэхийг танд сануулна.

Хэрэв та Outline сервер хасвал уг серверийг бүрмөсөн устгах бөгөөд хандалтын түлхүүрүүд нь цаашид ажиллахгүй. Хэрэв та хүмүүсийн Outline-р дамжуулах хандалтыг тасалдалтай байхыг хүсэхгүй байвал хуучин серверээ устгахаасаа өмнө [шинэ Outline сервер тохируулж](/manager/server-setup/setup-server), тухайн серверт хандах эрх хуваалцах шаардлагатай болно.
