---
title: "Би Outline серверийн программ хангамжаа хэрхэн шинэчлэх вэ?"
sidebar_label: "Би Outline серверийн программ хангамжаа хэрхэн шинэчлэх вэ?"
---

Outline серверүүд сүүлийн үеийн аюулгүй байдлын сайжруулалтаар автоматаар шинэчлэгдэх тул та үргэлж Outline-н сүүлийн үеийн технологийг ажиллуулах болно. Автоматжуулсан шинэчлэх явцыг Outline программ хангамжийг агуулж буй холбогчийн системийн хуулбарыг тогтмол шалгаж, шинэчилдэг нээлттэй эх кодтой сан болох [Watchtower](https://github.com/containrrr/watchtower)-с идэвхжүүлдэг.

Түүнчлэн таныг Outline Manager-г ашиглан Outline-г суулгах үед бид [Unattended Upgrades](https://wiki.debian.org/UnattendedUpgrades) (Ubuntu)-г ашиглан сервер дээрх программ хангамжийг автоматаар сайжруулах cron job-г тохируулах бөгөөд шаардлагатай бол үүнийг дахин асаана. Хостыг Outline-г ажиллуулахаас гадна өөр зорилгоор ашиглаж байна гэсэн таамаглалын дагуу одоо байгаа тохируулгыг хадгалахын тулд энэ нь Дэвшилтэт горимд тохиолддоггүй гэдгийг анхаарна уу.
