---
title: "Би Outline серверийн байршлыг хэрхэн өөрчлөх вэ?"
sidebar_label: "Би Outline серверийн байршлыг хэрхэн өөрчлөх вэ?"
---

Тохируулсны дараа серверийн байршлыг өөрчлөх боломжгүй. Серверээ өөр байршлаас ажиллуулахын тулд та Outline серверээ устгаж, шинийг үүсгэх шаардлагатай.

Өөрөөр танд серверүүдийг ээлжилж, ижил түлхүүр хадгалах боломжийг олгодог [динамик түлхүүрийг](https://developer.getoutline.org/vpn/management/dynamic-access-keys/) ашиглан өөрийн VPN-н байршлыг өөрчлөх боломжтой. Серверийн байршил өөрчлөгдөхгүй.
