sidebar_label: Outline серверийн хандалтыг удирдах (хандалтын түлхүүрээр)
---

Та Outline серверээ суулгаж дууссаны дараа хүмүүсийн уг серверт хандах эрхийг хуваалцаж мөн удирдаж эхлэх боломжтой. Танаас урилга хүлээн авсан хүмүүс Outline-г интернэтийн ачааллаа хамгаалахад ашиглахын тулд Outline аппыг татах боломжтой болно.

**Outline сервертээ хандах эрх хуваалцах**

 Таныг Outline серверийг суулгаж дууссаны дараа Outline Manager дээрх серверийн дэлгэрэнгүй мэдээллийн хуудас руу чиглүүлэх ба та тэнд хандалтын түлхүүр үүсгэж болно. [Хандалтын түлхүүрийн](/about/terminology) талаар нэмэлт мэдээлэл авна уу.

- Түлхүүр үүсгэх: Шинэ түлхүүр үүсгэхийн тулд хуудасны доод талд байх жижиг "+" дүрс тэмдэг дээр товшино уу.
- Түлхүүр хуваалцах: Түлхүүр тус бүрийн баруун талд таны урилга авахын тулд товшиж болох хуваалцах дүрс бий. Энэ урилгыг мессеж бичих сонгосон системдээ хуулаад буулгана уу.

**Онцлогийн хүсэлт: Outline Manager апп дотроос хандах эрх хуваалцах**

 Серверийн олон администратор биднээс Outline Manager-т хүний имэйл хаягийг шууд оруулах сонголтыг өөрсдөд нь өгч урилгын явцыг хөнгөвчлөхийг хүсдэг.

Харамсалтай нь бид энэ фунцкийг Outline Manager-т бүрэлдэхүүн болгох магадлал багатай. Бидний үндсэн зарчмуудын нэг бол хэрэглэгчдийнхээ нууцлал, аюулгүй байдлыг дэмжих явдал бөгөөд энэ нь бид имэйл хаяг, холбоо барих мэдээлэл оруулах газрыг загварчлаагүй гэсэн үг юм.

Тиймээс бид серверийн администраторуудаас эцсийн хэрэглэгчид урилга илгээхэд имэйл, аюулгүй чат зэрэг мессеж бичих аюулгүй платформыг ашиглахыг хүсдэг.

**Таныг тухайн хэрэглэгчтэй хандалтын түлхүүр хуваалцсаны дараа тэрээр юу хийх вэ?**

1. Тухайн хэрэглэгч төхөөрөмжөөсөө суулгах холбоосон дээр товшино
2. Хэрэв тухайн хэрэглэгчид Outline апп байхгүй бол тухайн аппыг суулгахыг сануулна
3. Тухайн хэрэглэгч урилгад оруулсан өвөрмөц түлхүүрээр таны Outline сервертэй анхны холболт тогтооно
4. Тухайн хэрэглэгч одоо таны Outline серверээр дамжуулан интернэтэд хандах эрхээ удирдах холбогдох/салгах товчийг ашиглах боломжтой

**Outline сервертээ хандах эрхийг хасах**

 Та Outline Manager дэх серверийн дэлгэрэнгүй мэдээллийн хуудаснаас сервер дээрх түлхүүр бүрийн баруун талд түлхүүрийг устгах сонголттой цэсийг харна. Түлхүүр устгах нь тухайн хэрэглэгчийн таны серверт хандах эрхийг хасна.
