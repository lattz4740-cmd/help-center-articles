---
title: "Би серверийн ID-гаа хэрхэн шинэчлэх вэ?"
sidebar_label: "Би серверийн ID-гаа хэрхэн шинэчлэх вэ?"
---

Серверийн ID нь таныг Outline сервер үүсгэхэд санамсаргүй байдлаар үүсгэх серверийн талын ID юм. Та үүнийг Тохиргооны интерфейст нэргүй хэмжигдэхүүн хуваалцахад нэгдсэн үед олох боломжтой. Та серверийн ID-ныхаа байршлыг дараахаас тогтоох боломжтой: Тохиргоо => доош гүйлгэж => "нэргүй хэмжигдэхүүн хуваалцах"-ыг тэмдэглэнэ үү.

Серверийн ID нь цагийн аясаар мэдээлсэн нэргүй статистик хэрэглээг хамтад нь холбодог. Хэрэв та серверийн ID-г шинэчилж, шинийг авахыг хүсвэл одоо байгаа Outline серверээ шинээр солих шаардлагатай.

Хэрэв та DigitalOcean-г үүлэн үйлчилгээ үзүүлэгчээрээ ашиглаж байгаа бол Тохиргоо руу очиж, Сервер устгахыг сонгож серверээ шинэчлэх боломжтой. Энэ үйлдлийг буцаах боломжгүй бөгөөд таны мандат үнэмлэхийг устгана. Энэ үйлдлийн дараа тэр даруй таны сонгосон байршилд шинэ сервер үүсгэхийг танд сануулах бөгөөд серверийн шинэ ID үүсгэнэ.
