---
title: "Jaké jsou požadavky na systém, kde se spouští Klient Outline?"
sidebar_label: "Jaké jsou požadavky na systém, kde se spouští Klient Outline?"
---

Outline můžete vyzkoušet v jakémkoli operačním systému. Následující tabulka shrnuje požadavky na nejstarší možnou verzi systému:

| **Operační systém** | **Minimální verze** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Chcete nám pomoct rozšířit Klienta Outline na další operační systémy? [Přispějte do naší základny kódu](https://github.com/OutlineFoundation/outline-client#platform-specific-development) na GitHubu.
