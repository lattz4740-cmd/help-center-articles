---
title: "Jak získám přístupový klíč?"
sidebar_label: "Jak získám přístupový klíč?"
---

Outline není běžná služba VPN, ke které byste si kupovali přístup. Je to [nástroj](https://getoutline.org/#:~:text=Two%20Products%20that%20Work%20Together), který vám umožňuje provozovat vlastní soukromý server VPN a sdílet přístup k němu s ostatními. Jediný, kdo může poskytovat přístupové klíče, je [správce služeb](/about/terminology#servicemanager). Tým Outline nedistribuuje přístupové klíče, ať už pro bezplatný, nebo placený přístup. Nemáme ani žádné partnery, kteří by pro Outline oficiálně zajišťovali přístupové klíče. Výjimkou je společnost Paskoocheh pro perštinu.

 Přístupový klíč můžete získat třemi způsoby:

- Požádejte někoho, ať vás pozve na svůj server: Pokud znáte někoho, kdo provozuje server Outline, obraťte se na něj a požádejte ho o přístupový klíč.
- [Vytvořte si server sami:](/manager/server-setup/setup-server) Stáhněte si do počítače se systémem Windows, Mac nebo Linux aplikaci [Správce Outline](https://getoutline.org/get-started/#step-1) a nastavte si vlastní soukromý [server Outline](/about/terminology). Celý postup jsme zjednodušili tak, aby ho zvládl každý. Obzvlášť výhodné je využít poskytovatele cloudových služeb DigitalOcean.
- Použijte službu Outline nebo [Shadowsocks](https://en.wikipedia.org/wiki/Shadowsocks#:~:text=Shadowsocks%20is%20a%20free%20and,have%20been%20made%20available%20since.): Klienta Outline můžete použít taky se službami jiných výrobců, které využívají protokol Outline nebo Shadowsocks. Například:
   - [nthLink](https://nthlink.com/) provozuje bezplatnou službu založenou na Outline s upravenou verzí klienta Outline.
   - [ASL19](https://www.reddit.com/r/outlinevpn/comments/nwu1se/the_outline_distribution_system_is_here_to_help/) provozuje upravenou verzi Outline pod názvem [BeePass](https://beepassvpn.com/) a taky [robota Telegram](https://t.me/paskoochehbot), který poskytuje bezplatné přístupové klíče k serverům BeePass.
   - Uživatelé, kteří ovládají perštinu, si navíc můžou vyžádat přístupový klíč k Outline na tržišti Paskoocheh od společnosti [ASL19](https://outline.paskoocheh.com/).

Jakmile si stáhnete aplikaci Klient Outline, zkopírujte svůj [přístupový klíč](/about/terminology#accesskey) a vložte ho do klienta Outline. Pak se budete moct připojit k serveru Outline.
