## Můžu Outline používat bez serveru?
 Bohužel ne. Software Outline vyžaduje přístup k serveru, ať už ho spravujete vy, vaše organizace nebo důvěryhodná třetí strana.

## Jak dlouho trvá nastavit server Outline?

Většinou to trvá do 5 minut. Outline si můžete nainstalovat na jakýkoli cloudový server, ale připravili jsme pro vás snadnou vedenou instalaci u poskytovatele DigitalOcean. Pokud vyberte tuto možnost, nastavíte si server pomocí pár kliknutí a bez skriptů.

Pokud si vyberete poskytovatele AWS či GCP nebo pokročilé nastavení, zjednodušili jsme pro vás proces na jediný skript, který zvládne instalaci serveru ve většině prostředí.

## Kde si můžu nastavit server Outline?

Server Outline si můžete nastavit u většiny poskytovatelů cloudu, ať svoje servery provozují kdekoli.

Nejsnazší je nastavení u společnosti DigitalOcean, která má servery na mnoha místech, například v Amsterdamu, Torontu, San Francisku nebo Singapuru. Pokud chcete server raději nainstalovat u jiného poskytovatele cloudu nebo ve vlastní infrastruktuře, můžete v aplikaci Správce Outline vybrat rozšířený režim a postupovat podle návodu k instalaci s pomocí nastavovacího skriptu.

## Kde si mám nastavit server Outline?

1. Při vybírání umístění serveru Outline byste měli vzít v potaz několik věcí:
2. Umístění serveru Outline ovlivní, co uživatelé vidí na internetu. Pokud je server umístěný například v Amsterdamu, uživatelé budou mít k internetu stejný přístup, jako by fyzicky byli v Nizozemsku. V takovém případě se některé stránky mohou zobrazovat v holandštině. Jazyk většinou můžete změnit přímo na daných stránkách.
3. Rychlost připojení může být ovlivněna vzdáleností mezi uživateli a serverem Outline. Obvykle může mít fyzická vzdálenost mezi uživateli Outline a serverem vliv na rychlost internetu těchto uživatelů. Ve většině případů se server dá umístit blízko předpokládaných uživatelů. Případně se můžete podívat na [mapu podmořských kabelů](https://www.submarinecablemap.com/) a ověřit si, které kabely zajišťují propojení pro vaši zemi nebo oblast.
4. To, kde se server VPN nachází, může mít vliv na právní předpisy, které se budou uplatňovat. Nezapomeňte, že software Outline neukládá protokoly vašeho provozu. Přečtěte si další informace o [zabezpečení a ochraně soukromí při používání Outline](/about/security-and-privacy).
