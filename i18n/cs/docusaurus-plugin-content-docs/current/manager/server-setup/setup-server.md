---
title: "Jak nastavím server Outline?"
sidebar_label: "Jak nastavím server Outline?"
---

Nastavení serveru Outline je první krok k tomu, abyste mohli Outline používat. Pokud se chcete přes Outline připojovat k otevřenému internetu, musíte vy nebo někdo, komu důvěřujete, nastavit server.

**Než začnete**

 K nastavení serveru Outline je potřeba zajistit několik věcí:

1. Přístup k vlastním serverům nebo k serverům poskytovatele cloudových služeb, jako je DigitalOcean, Amazon Web Services (AWS) nebo Google Cloud Platform (GCP).

 Pokud zatím ke cloudovému serveru přístup nemáte, můžete se jednoduše zaregistrovat u libovolného poskytovatele, včetně těch, které uvádíme výše. K registraci budete pravděpodobně potřebovat platební kartu.
2. Stolní počítač se systémem macOS 10.9 nebo vyšším, Windows 7.0 nebo vyšším či Linux.
3. Aplikaci Správce Outline.

**Nastavení u poskytovatele DigitalOcean**

 Instalace Outline přes DigitalOcean je úplně jednoduchá, stačí pár kliknutí. Až si do počítače stáhnete a nainstalujete Správce Outline, můžete jako možnost nastavení vybrat DigitalOcean. Pak projdete několika obrazovkami a podle pokynů si jednoduše nastavíte a nainstalujete server Outline.

**Nastavení u jiného cloudového poskytovatele**

 Po stažení a instalaci Správce Outline si můžete vybrat, že server Outline nainstalujete na virtuální počítač u AWS, GCP, DigitalOcean nebo jiného poskytovatele. Každé prostředí je jiné, proto jsme do nastavení Správce Outline zahrnuli návod pro většinu běžných cloudových poskytovatelů. Popisujeme taky, jak nakonfigurovat nastavení virtuálního počítače, než spustíte instalační skript a nainstalujete Outline na server.
