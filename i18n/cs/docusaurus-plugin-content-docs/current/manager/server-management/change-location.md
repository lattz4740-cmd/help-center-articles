---
title: "Jak změním umístění serveru Outline?"
sidebar_label: "Jak změním umístění serveru Outline?"
---

Po nastavení už umístění serveru nejde změnit. Pokud chcete server Outline spouštět z jiného místa, musíte ho smazat a vytvořit nový.

Případně můžete změnit umístění sítě VPN pomocí [dynamických klíčů](https://developers.google.com/outline/docs/guides/service-providers/dynamic-access-keys), které dovolují střídat servery a ponechat si při tom stejné klíče. Umístění samotných serverů se v tomto případě nezmění.
