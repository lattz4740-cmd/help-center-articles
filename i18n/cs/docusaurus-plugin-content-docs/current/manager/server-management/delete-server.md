---
title: "Jak můžu smazat svůj server Outline?"
sidebar_label: "Jak můžu smazat svůj server Outline?"
---

U většiny cloudových poskytovatelů poměrně snadno odstraníte konkrétní virtuální počítač, který používáte.

Pokud jako poskytovatele cloudu využíváte DigitalOcean, můžete stávající virtuální počítač smazat tak, že kliknete na ozubené kolečko a vyberete možnost Zničit server. Hned potom se vám zobrazí výzva, abyste si vytvořili nový virtuální počítač v umístění, které si vyberete.

Pokud odstraníte server Outline, trvale se smaže a jeho přístupové klíče už nebudou fungovat. Pokud chcete, aby se přístup přes Outline dal využívat bez přerušení, musíte nejdřív [nastavit nový server Outline](/manager/server-setup/setup-server) a předat uživatelům přístupové údaje a až potom smazat starý server.
