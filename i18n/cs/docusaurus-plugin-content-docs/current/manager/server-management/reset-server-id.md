---
title: "Jak můžu resetovat ID svého serveru?"
sidebar_label: "Jak můžu resetovat ID svého serveru?"
---

ID serveru je identifikační číslo, které se při vytváření serveru Outline náhodně vygeneruje na straně serveru. Zjistit ho můžete, pokud se v nastavení přihlásíte ke sdílení anonymních metrik. Stačí v části Nastavení přejít dolů a zaškrtnout políčko Sdílet anonymní metriky.

ID serveru slouží k propojení anonymních statistik o používání, které se průběžně vykazují. Pokud chcete ID serveru resetovat a získat nové, musíte svůj stávající server Outline nahradit novým.

Jestliže jako poskytovatele cloudu využíváte DigitalOcean, můžete server resetovat tak, že přejdete do nastavení a vyberete Zničit server. Tato akce je nevratná a smažou se při ní vaše přihlašovací údaje. Hned potom se vám zobrazí výzva k vytvoření nového serveru v umístění, které si vyberete, a vygeneruje se nové ID serveru.
