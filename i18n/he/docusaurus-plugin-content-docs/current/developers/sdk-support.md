אתר התמיכה הזה מיועד למשתמשי Outline Manager ולמשתמשים באפליקציית הלקוח של Outline. מפתחים שרוצים לקבל תמיכה צריכים להשתמש ב-GitHub. ב-[Discussion board](https://github.com/Jigsaw-Code/outline-sdk/discussions) (אזור הדיונים) של ה-SDK אפשר לפרסם שאלות. הקטע Discussion board (אזור הדיונים) הוא מקום מצוין לשאול בו שאלות, לשתף רעיונות, לשלוח קישורים להדגמות ולעזור למפתחים אחרים שמשתמשים ב-Outline SDK. כדי לשלוח בקשה להוספת תכונה או לדווח על באג, צריך לפתוח במקום זה [Issue](https://github.com/Jigsaw-Code/outline-sdk/issues/new) (פנייה).
