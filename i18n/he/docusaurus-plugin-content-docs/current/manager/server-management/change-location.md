---
title: "איך אפשר לשנות את מיקום השרת של Outline?"
sidebar_label: "איך אפשר לשנות את מיקום השרת של Outline?"
---

אחרי שמגדירים את השרת אי אפשר לשנות את המיקום שלו. כדי להריץ את השרת ממיקום אחר, צריך למחוק את השרת של Outline וליצור אחד חדש.

לחלופין, אפשר לשנות את המיקום של ה-VPN שלכם באמצעות [מפתחות דינמיים](https://developer.getoutline.org/vpn/management/dynamic-access-keys/), שיאפשרו לכם להחליף שרתים ועדיין להשתמש באותם מפתחות. מיקום השרתים עצמם לא ישתנה.
