---
title: "איך מאפסים את מזהה השרת?"
sidebar_label: "איך מאפסים את מזהה השרת?"
---

מזהה השרת הוא המזהה של צד השרת שנוצר באופן אקראי כשיוצרים שרת של Outline. אפשר למצוא אותו כשבוחרים לשתף מדדים אנונימיים דרך ממשק ההגדרות. כדי למצוא את מזהה השרת, נכנסים אל "הגדרות" => גוללים למטה => מסמנים את האפשרות "שיתוף מדדים אנונימיים".

מזהה השרת מקשר בין נתוני שימוש אנונימיים שמדווחים לאורך זמן. אם רוצים לאפס את מזהה השרת וליצור מזהה חדש, צריך להחליף את השרת של Outline הקיים בשרת חדש.

אם הספק שלכם לשירותי ענן הוא DigitalOcean, אתם יכולים לאפס את השרת באמצעות כניסה אל "הגדרות" ובחירה באפשרות "מחיקת השרת". השרת ופרטי הכניסה אליו יימחקו לצמיתות. מיד אחרי המחיקה תופיע הנחייה ליצור שרת חדש במיקום שתבחרו ויופק מזהה שרת חדש.
