---
title: "איך מעדכנים את תוכנת השרת של Outline?"
sidebar_label: "איך מעדכנים את תוכנת השרת של Outline?"
---

הגרסה של תוכנת השרת של Outline מתעדכנת אוטומטית, כדי שתמיד יהיו לשרת של Outline את הטכנולוגיות החדשות ושיפורי האבטחה. תהליך העדכון האוטומטי מופעל על ידי [Watchtower](https://github.com/v2tec/watchtower) – ספריית קוד פתוח שבודקת ומעדכנת באופן קבוע את קובץ האימג' של Docker שמכילה את תוכנת Outline.

בנוסף, כשמתקינים את Outline באמצעות Outline Manager, אנחנו מגדירים משימת cron שתשדרג אוטומטית את התוכנה בשרת באמצעות [Unattended Upgrades](https://wiki.debian.org/UnattendedUpgrades)‏ (Ubuntu), ותפעיל אותו מחדש במידת הצורך. חשוב לשים לב שהפעולה הזאת לא מתרחשת במצב Advanced במטרה לשמר את ההגדרות הקיימות, מתוך הנחה שהמארח משמש למטרות נוספות מלבד ההרצה של Outline.
