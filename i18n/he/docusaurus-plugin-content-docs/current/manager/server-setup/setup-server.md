כדי להתחבר לרשת האינטרנט דרך Outline, קודם צריך להתקין שרת של Outline. תוכלו להתקין אותו בעצמכם, או להיעזר במישהו שאתם סומכים עליו.

 ‫**לפני שמתחילים**

 לפני ההתקנה של שרת Outline, תצטרכו:

1. גישה לשרתים משלכם או לשרתים של ספק שירותי ענן, כמו DigitalOcean,‏ Amazon Web Services (‏AWS)‏ או Google Cloud Platform (‏GCP).

 אם אין לכם כרגע גישה לשרת בענן, תוכלו ליצור חשבון אצל אחת מהחברות המספקות גישה, כולל אלו שציינו. תצטרכו כרטיס אשראי כדי להירשם.
2. מחשב עם macOS 10.9 ואילך‏, Windows 7.0 ואילך או Linux.
3. את אפליקציית Outline Manager.

‫**הגדרה באמצעות DigitalOcean**

 ההתקנה של שרת Outline באמצעות DigitalOcean פשוטה מאוד. מורידים למחשב את אפליקציית Outline Manager ומתקינים אותה. אחר כך, בוחרים להתקין את השרת של Outline דרך DigitalOcean ופועלים לפי ההנחיות הפשוטות במסכים כדי להגדיר ולהתקין אותו.

**הגדרה באמצעות ספק שירותי ענן אחר**

‫ אחרי שמורידים ומתקינים את אפליקציית Outline Manager, תוכלו לבחור להתקין שרת של Outline במכונה וירטואלית דרך AWS, ‏GCP, ‏DigitalOcean או ספק אחר. אין שתי סביבות שימוש זהות לחלוטין. לכן, אפליקציית Outline Manager כוללת הנחיות להתקנת השרת דרך רוב ספקי שירותי הענן הנפוצים, כולל הנחיות להגדרת המכונה הווירטואלית לפני שמפעילים את סקריפט ההתקנה של Outline בשרת.
