---
title: "כמה עולה להפעיל את Outline?"
sidebar_label: "כמה עולה להפעיל את Outline?"
---

כל אחד יכול להשתמש בחינם ב-Outline – מאדמינים שמנהלים את ה-VPN ועד למשתמשים שגולשים באינטרנט דרך Outline.

 עם זאת, כדי להשתמש ב-Outline צריך גישה לשרת בענן. האדמינים של השרתים שכבר יש להם גישה לשרת יכולים להתקין את Outline על השרת ללא עלות נוספת. משתמשים ללא גישה לשרת יכולים לקנות גישה מספק שירותי ענן, כמו [DigitalOcean](https://www.digitalocean.com/) או Amazon Web Services, בעלות של כ-5‎ USD לחודש (למכסת העברת נתונים של 1 טרה-בייט). הכמות הזאת מספיקה כדי לתמוך במאות משתמשים בשרת אחד.

 תוכלו להיעזר בדוגמה הבאה כדי לחשב כמה יעלה לכם להשתמש ב-Outline דרך ספק שירותי ענן שתבחרו:

| *בהנחה שהמשתמש הממוצע מעביר בחודש כ-5 ג'יגה-בייט של נתונים, תוכנית שעולה 5‎ USD אמורה להספיק ל-200 משתמשים בו-זמנית, כך שהעלות הממוצעת למשתמש תהיה 2.5 סנט לחודש. חשוב לזכור שכמות הנתונים שכל משתמש מעביר מדי חודש משתנה מאוד, בהתאם לשימוש ברוחב הפס ולפעילויות שלו באינטרנט. עם זאת, רוב ספקי שירותי הענן מספיק גמישים כדי להתמודד עם עלייה בנפח תנועת הגולשים.* |
| --- |

למעשה, השימוש ב-Outline הוא אנונימי לגמרי מבחינת Jigsaw ו-Google. אנחנו לא עוקבים אחרי הזהות שלכם או התנועה שלכם באינטרנט ואין לנו תוכנית מונטיזציה. אנחנו עובדים עם קהילת הקוד הפתוח שלנו כדי להציע את התוכנה בחינם למשתמשים. [כאן](/about/data-collection) אפשר לקרוא איזה מידע אנחנו אוספים.
