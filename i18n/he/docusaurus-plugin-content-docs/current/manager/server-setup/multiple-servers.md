כדי להתקין שרתים נוספים של Outline, לוחצים על סמל הפלוס "+" בחלונית הניווט שמימין באפליקציית Outline Manager. התהליך להוספת שרת חדש זהה לתהליך של התקנת השרת הראשון.

- אין הגבלה על מספר השרתים של Outline שאפשר ליצור.
- צריך לחבר לכל שרת של Outline שיוצרים מכונה וירטואלית משלו.
- יצירת מכונות או חיבורים נוספים עלולה להגדיל את החיוב של ספק שירותי הענן. מומלץ לבדוק את החבילה אצל ספק שירותי הענן כדי שלא יהיו הפתעות.

## יצירת שרת נוסף של Outline כשמתחברים באמצעות DigitalOcean

אחרי שלוחצים על סמל הפלוס ובוחרים להתקין את השרת הנוסף באמצעות DigitalOcean, מבצעים את אותן פעולות כמו בהתקנת השרת הראשון. בנוסף, בזכות השילוב בין אפליקציית Outline Manager ו-DigitalOcean, אנחנו יכולים ליצור בשבילכם חיבור נוסף בלי לצאת מאפליקציית Outline Manager.

חשוב לזכור שאפליקציית Outline Manager תומכת רק בחשבון DigitalOcean אחד בכל פעם. אם רוצים להוסיף או ליצור שרתים נוספים של Outline באמצעות חשבונות DigitalOcean אחרים, אפשר להוסיף אותם באמצעות התקנה מתקדמת.

## יצירת שרת נוסף של Outline כשמתחברים באמצעות GCP, ‏AWS או ספק שירותי ענן אחר

בשלב הראשון, יוצרים מכונה וירטואלית חדשה אצל ספק שירותי הענן. אחר כך, פותחים את אפליקציית Outline Manager ופועלים לפי ההוראות להתקנה מתקדמת – בדיוק כמו בהתקנת השרת הראשון.
