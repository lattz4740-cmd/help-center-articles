sidebar_label: "למה אין לי אפשרות להתקין את אפליקציית Outline Manager ב-Windows?"
---

ייתכן שתופיע הודעת השגיאה הבאה: "מצטערים, אפליקציית Outline לא הותקנה טוב וצריך להתקין אותה מחדש. אם הבעיה נמשכת, אפשר [לשלוח לנו משוב](https://support.getoutline.org/s/contactsupport?)."

אם אתם משתמשים ב-Outline ב-Windows, יכול להיות שמדי פעם תהיה שגיאה בלתי צפויה. ברוב המקרים, צריך למחוק את מתאם ה-TAP (הדרייבר) של Outline ולהתקין מחדש את Outline.

תוכלו להיעזר בהסבר הכללי הבא כדי להסיר את מתאם ה-TAP ואת אפליקציית Outline Manager, ולהתקין את האפליקציה מחדש. עם זאת, השלבים בפועל משתנים בהתאם לגרסת Windows.

1. הסרת מתאם ה-TAP של Outline Manager
   1. נכנסים ל"ניהול מכשירים", ואז אל "מתאמי רשת".
   2. מוצאים את הקובץ "TAP-Windows Adapter V9" או את מתאם ה-TAP שמשויך ל-Outline.
   3. מסירים או מוחקים את המתאם הזה. חשוב לזכור שהמחיקה עלולה להשפיע גם על אפליקציות VPN אחרות שמותקנות במכשיר.
2. הסרת האפליקציה Outline Manager
   1. נכנסים ל"תוכנות ותכונות", ואז אל "הסרת התוכנה".
   2. מוצאים את אפליקציית Outline Manager ומסירים אותה.
   3. [מורידים את הגרסה האחרונה של Outline Manager](https://getoutline.org/get-started/#step-1) ומתקינים אותה מחדש על מכשיר Windows. במסגרת ההתקנה החדשה, יותקן במכשיר מתאם TAP חדש באופן אוטומטי.

אם אתם עדיין נתקלים בבעיות אפשר [לפנות לתמיכה](https://support.getoutline.org/s/contactsupport?).
