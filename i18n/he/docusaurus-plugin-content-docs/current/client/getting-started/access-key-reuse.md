title: "אפשר להשתמש באותו מפתח גישה יותר מפעם אחת?"
sidebar_label: "אפשר להשתמש באותו מפתח גישה יותר מפעם אחת?"
---

כן. אתם יכולים להשתמש ב[מפתח הגישה](/about/terminology) שלכם בכמה מכשירים שתרצו, אבל אנחנו ממליצים לא לשתף אותו עם אחרים. לכל מי שיש את מפתח הגישה יכולה להיות גישה לכל תעבורת הנתונים שלכם, מה שאומר שהגלישה שלכם באינטרנט מפסיקה להיות מאובטחת ופרטית.
