Trang web hỗ trợ này dành cho người dùng ứng dụng Outline và ứng dụng Quản lý Outline. Nếu bạn là nhà phát triển, vui lòng tham khảo GitHub để xem thông tin hỗ trợ. Để đặt câu hỏi, vui lòng đăng trên [Diễn đàn thảo luận](https://github.com/Jigsaw-Code/outline-sdk/discussions) về Outline SDK. Mục Diễn đàn thảo luận là nơi rất phù hợp để đặt câu hỏi, chia sẻ ý tưởng, đăng đường liên kết đến bản minh hoạ và hỗ trợ các nhà phát triển khác sử dụng Outline SDK. Đối với các yêu cầu về tính năng hoặc báo cáo lỗi, vui lòng tạo phiếu [Yêu cầu giải quyết vấn đề](https://github.com/Jigsaw-Code/outline-sdk/issues/new).
