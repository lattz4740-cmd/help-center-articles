သင်က VPN ကို စီမံနေသော ဆာဗာစီမံခန့်ခွဲသူဖြစ်စေ၊ လွတ်လပ်သော အင်တာနက်သို့ ဝင်ရန် Outline သုံးနေသူဖြစ်စေ Outline ဆော့ဖ်ဝဲသည် လူတိုင်းအတွက် အခမဲ့ဖြစ်သည်။

 သို့သော် Outline လည်ပတ်ရန် cloud ဆာဗာသုံးခွင့် လိုအပ်သည်။ ဆာဗာသုံးခွင့်ရှိသော ဆာဗာစီမံခန့်ခွဲသူများသည် အပိုကြေးမပေးရဘဲ ယင်းဆာဗာတွင် Outline ကို ထည့်သွင်းနိုင်သည်။ ဆာဗာသုံးခွင့်မရှိသူများသည် [DigitalOcean](https://www.digitalocean.com/) (သို့) ‘Amazon ဝဘ်ဝန်ဆောင်မှုများ’ ကဲ့သို့ Cloud ဝန်ဆောင်မှုပေးသူများထံမှ ဒေတာလွှဲပြောင်းမှု ခွင့်ပြုပမာဏ ၁ တယ်ရာဘိုက်အတွက် တစ်လလျှင် $5 USD ခန့်ဖြင့် သုံးခွင့်ရနိုင်သည် — ၎င်းသည် ဆာဗာတစ်ခုတည်းတွင် ရာနှင့်ချီသော အသုံးပြုသူများကို ပံ့ပိုးရန် လုံလောက်သည်။

 သင်ရွေးထားသော cloud ဝန်ဆောင်မှုပေးသူနှင့် Outline လုပ်ဆောင်ရန်အတွက် ကျသင့်ငွေ တွက်ချက်နိုင်ပုံကို ဥပမာပြထားသည်-

| *အသုံးပြုသူတစ်ဦးလျှင် ဒေတာလွှဲပြောင်းမှု ၅ ဂစ်ဂါဘိုက်ကို ပျမ်းမျှလစဉ်သုံးသည်ဟု ယူဆပါက တစ်လလျှင် $5 USD ပေးရသော အစီအစဉ်သည် တစ်ပြိုင်နက် အသုံးပြုသူဦးရေ ၂၀၀ ခန့် သုံးခွင့်ရမည်ဖြစ်ပြီး အသုံးပြုသူတစ်ဦးလျှင် တစ်လ ၂.၅ ဆင့်သာ ကျသင့်ပါသည်။ အသုံးပြုသူများ၏ မြန်နှုန်း နိမ့်သော သို့မဟုတ် မြင့်သော လုပ်ဆောင်ချက်များအပေါ် မူတည်၍ အသုံးပြုသူအလိုက် တစ်လလျှင်သုံးသော ဒေတာ လွှဲပြောင်းမှုသည် သိသာစွာ ကွဲပြားမည်ကို သတိပြုပါ။ သို့သော် cloud ဝန်ဆောင်မှုပေးသူ အများစုသည် ဒေတာစီးဆင်းမှု မြင့်တက်လာမှုများကို ချိန်ညှိပေးပါမည်။* |
| --- |

Outline သုံးပါက Jigsaw နှင့် Google တွင် ကိုယ်ရေးအချက်အလက် လုံးဝဖျောက်ထားပေးသည်။ သင်၏ အထောက်အထား (သို့) ဒေတာစီးဆင်းမှုကို ကျွန်ုပ်တို့ ခြေရာမခံသကဲ့သို့ ဝင်ငွေရှာသော အစီအစဉ်လည်း မရှိပါ။ ၎င်းအစား ကျွန်ုပ်တို့သည် အသုံးပြုသူများကို ဆော့ဖ်ဝဲ အခမဲ့ပေးနိုင်ရန်အတွက် အခမဲ့ရင်းမြစ် ကွန်မြူနတီနှင့် တွဲဖက်လုပ်ဆောင်သည်။ ကျွန်ုပ်တို့စုဆောင်းသော ဒေတာများအကြောင်းကို [ဤနေရာ](https://getoutline.org/policies/data-collection) တွင် ပိုမိုလေ့လာပါ။
