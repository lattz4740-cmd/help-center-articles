## အနှစ်ချုပ်

‘Outline မန်နေဂျာ’ ရှိ ဝန်ဆောင်မှုဖြင့် သင်သည် Google Cloud တွင် လုပ်ဆောင်နေသော ဆာဗာ၌ ‘Outline ဆာဗာ’ ကို အလိုအလျောက် စီစဉ်သတ်မှတ်နိုင်သည်။ ဤတူးလ်သုံးရန် ရွေးပါက ‘Outline မန်နေဂျာ’ သည် သင်၏ Google Account ဖြင့် လက်မှတ်ထိုးဝင်ခိုင်းပါမည်။ ၎င်းသည် သင်၏ Google Cloud Account စီစဉ်သတ်မှတ်ရန်အတွက် သင့်စက်အတွင်း ‘Outline မန်နေဂျာ’ ထည့်သွင်းမှုကို [OAuth](https://developers.google.com/identity/protocols/oauth2) ခွင့်ပြုချက်အချို့ ပေးပါမည်။

 ဤခွင့်ပြုချက်များကို မပေးလိုပါက Google Cloud Platform တွင် Outline လုပ်ဆောင်ရန် ‘Outline မန်နေဂျာ’ ရှိ အဆင့်မြင့် စနစ်ထည့်သွင်းခြင်း လမ်းညွှန်ချက်များအတိုင်း ဆောင်ရွက်နိုင်ပါသည်။

## ခွင့်ပြုချက်များ ပေးထားသည်

အလိုအလျောက် စနစ်ထည့်သွင်းရန် ‘Outline မန်နေဂျာ’ သည် သင်၏ Google Account မှ အောက်ပါခွင့်ပြုချက်များ လိုအပ်ပါသည်။

## Google Cloud Platform

- Google Compute Engine ရင်းမြစ်များကို ကြည့်ရှုစီမံနိုင်သည်
- သင်၏ဒေတာကို Google Cloud ဝန်ဆောင်မှုများတွင် ကြည့်ရှုပြီး သင့် Google Account ၏ အီးမေးလ်လိပ်စာကို ကြည့်နိုင်သည်

## အခြေခံ အကောင့်အချက်အလက်များ

- သင်၏ Google Account ပင်မအီးမေးလ်လိပ်စာကို ကြည့်နိုင်သည်
- Google ရှိ သင်၏ကိုယ်ရေးအချက်အလက်နှင့် သင့်ကို ဆက်စပ်ကြည့်နိုင်သည်

## နောက်ထပ်သုံးခွင့်

- Cloud Platform ပရောဂျက်များကို စီမံနိုင်သည်
- Google Cloud Platform ငွေတောင်းခံအကောင့်များကို ကြည့်ရှုစီမံနိုင်သည်
- သင်၏ Google API ဝန်ဆောင်မှုဆိုင်ရာ စီစဉ်သတ်မှတ်ချက်ကို စီမံနိုင်သည်

ဤခွင့်ပြုချက်များသည် အောက်ပါတို့အပါအဝင် သင်၏ Outline ဆာဗာများ စီမံရန် အဆင့်မြင့်လုပ်ဆောင်ချက်ကို ပံ့ပိုးခွင့်ပြုသည်-

- မှန်ကန်သော ငွေတောင်းခံအကောင့်ကို ရွေးချယ်ခွင့်ပြုခြင်း
- သင်၏ Outline ဆာဗာများကို စုစည်းရန် ပရောဂျက်အသစ် ပြုလုပ်ခြင်း
- ရနိုင်သော ဒေတာစင်တာများကို စာရင်းလုပ်ခြင်း
- Outline လုပ်ဆောင်ရန် ပကတိအသွင် စက်အသစ်များကို ပြုလုပ်ခြင်း
- ပကတိအသွင် စက်အသစ်ကို Outline ဖြင့် စီစဉ်သတ်မှတ်ခြင်း

## ခွင့်ပြုချက်များ ရုတ်သိမ်းခြင်း

[ကျွန်ုပ်၏အကောင့်](https://myaccount.google.com/permissions) ကို ဝင်၍ ‘Outline မန်နေဂျာ’ အတွက် Google Cloud Platform ကို သုံးခွင့်ရုတ်သိမ်းနိုင်သည်။ သုံးခွင့်ရုပ်သိမ်းပါက အလိုအလျောက် စနစ်ထည့်သွင်းခြင်းဖြင့် ပြုလုပ်ထားသော ဆာဗာတိုင်းသည် ဆက်လက်လုပ်ဆောင်မည်ဖြစ်သော်လည်း ‘Outline မန်နေဂျာ’ တွင် မြင်ရတော့မည်မဟုတ်ပါ။ ၎င်းတို့ကို သုံးခွင့်ပြန်ယူရန် အလိုအလျောက် စနစ်ထည့်သွင်းခြင်း လုပ်ငန်းစဉ်ကို စတင်ခြင်းဖြင့် Google Cloud Platform သို့ ပြန်လည်ချိတ်ဆက်နိုင်သည်။

## Outline ပရောဂျက်အဖွဲ့အစည်း

Google Cloud အလိုအလျောက် စနစ်ထည့်သွင်းခြင်းသည် သင်၏ Outline ဆာဗာများကို စုစည်းရန်[Google Cloud ပရောဂျက်](https://cloud.google.com/resource-manager/docs/creating-managing-projects) တစ်ခုတည်းကို သုံးပါသည်။ အလိုအလျောက် စနစ်ထည့်သွင်းခြင်း၏ ပထမဆုံးအသုံးပြုမှုအတွင်း အကြံပြုထားသော ပရောဂျက် ID ဖြင့် ပရောဂျက်ကို ပြုလုပ်ထားသည်။ ပရောဂျက် ID သည် “Outline-” ဖြင့် စတင်ပြီး နောက်တွင် ကျပန်းစာလုံးများစာကြောင်း ပါဝင်သည်။ နှစ်သက်ပါက ပြုလုပ်မှုတွင် အခြားပရောဂျက် ID ကို ရွေးနိုင်သည်။ ပရောဂျက်ကို “Outline ဆာဗာများ” ဟု အမည်ပေးပါမည်။

## ငွေတောင်းခံအကောင့်

Google Cloud ပရောဂျက်များသည် ငွေပေးချေမှု အချက်အလက်များကို သတ်မှတ်ပေးသော လင့်ခ်ချိတ်ထားသည့် “ငွေတောင်းခံအကောင့်” လိုအပ်သည်။ Google Cloud အလိုအလျောက် စနစ်ထည့်သွင်းခြင်းကို ပထမဆုံးအသုံးပြုသည့်အခါ သင်၏ Outline ဆာဗာများနှင့် ချိတ်ဆက်ရန်အတွက် ငွေတောင်းခံအကောင့်ပေးရန် သင့်အား တောင်းဆိုပါမည်။ တစ်ခါတစ်ရံ ငွေတောင်းခံအကောင့်တွင် ပြဿနာရှိသဖြင့် ဆာဗာလုပ်ဆောင်မှု ရပ်တန့်ပါမည်။ ဤသို့ဖြစ်နေပါက [Google Cloud Console](https://console.cloud.google.com/getting-started) သို့ အကောင့်ဝင်ရပါမည်။ (“Outline ဆာဗာများ” ဟူသည့်) Outline နှင့်ဆက်စပ်သော Google Cloud ပရောဂျက်ကို နေရာချပြီး ငွေတောင်းခံခြင်းဆက်တင်များကို အပ်ဒိတ်လုပ်ပါ။

## ဆာဗာများ ဖျက်ခြင်း

အလိုအလျောက် စနစ်ထည့်သွင်းခြင်းဖြင့် ပြုလုပ်ထားသော သင့်ဆာဗာများကို ဖျက်လိုပါက အလွယ်ဆုံးနည်းလမ်းမှာ ‘Outline မန်နေဂျာ’ အတွင်း လုပ်ဆောင်ခြင်းဖြစ်သည်။ သို့သော် ဆာဗာများကို သင်ကိုယ်တိုင် ဖျက်ဆီးလိုပါက[Google Cloud Console](https://console.cloud.google.com/getting-started) သို့ အကောင့်ဝင်ရပါမည်။ (“Outline ဆာဗာများ” ဟူသည့်) ကနဦးစနစ်ထည့်သွင်းမှုအတွင်း ပြုလုပ်ထားသော ပရောဂျက်ကိုရှာပြီး ထိုနေရာရှိ ရင်းမြစ်များကို ဖျက်ပါ (သို့) ပရောဂျက်ကို အပြီးပိတ်ပါ။
