**ဆာဗာမရှိဘဲ Outline သုံးနိုင်ပါသလား။**

 မသုံးနိုင်ပါ။ Outline ဆော့ဖ်ဝဲအတွက် သင်၊ သင့်အဖွဲ့အစည်း (သို့) ယုံကြည်ရသော ပြင်ပကုမ္ပဏီက စီမံခန့်ခွဲသော ဆာဗာသုံးခွင့် လိုအပ်သည်။

## Outline ဆာဗာကို စနစ်ထည့်သွင်းရန် အချိန်မည်မျှကြာပါသလဲ။

များသောအားဖြင့် ၅ မိနစ်ပင် မကြာပါ။ မည်သည့် cloud ဆာဗာတွင်မဆို Outline ထည့်သွင်းနိုင်သော်လည်း ကျွန်ုပ်တို့က ပိုမို၍ အသုံးပြုရ လွယ်ကူသော ထည့်သွင်းမှု လမ်းညွှန်ချက်များ ကမ်းလှမ်းရန်အတွက် DigitalOcean ဖြင့် လုပ်ဆောင်ထားကာ ယင်းနေရာတွင် ကလစ်အနည်းငယ်နှိပ်ရုံဖြင့် သင့်ဆာဗာကို ထည့်သွင်းနိုင်သည်—လမ်းညွှန်ဖိုင် မလိုအပ်ပါ။

AWS၊ GCP (သို့) အဆင့်မြင့် စနစ်ထည့်သွင်းမှုကို ရွေးထားပါက အခြေအနေအများစုအတွက် စီမံခန့်ခွဲပေးသော လမ်းညွှန်ဖိုင် တစ်ခုတည်းဖြင့် ဆာဗာထည့်သွင်းမှု လုပ်ငန်းစဉ်ကို ရိုးရှင်းအောင် ပြုလုပ်ထားသည်။

## Outline ဆာဗာကို မည်သည့်နေရာတွင် စနစ်ထည့်သွင်းနိုင်ပါသလဲ။

နေရာမရွေး လုပ်ဆောင်သည့် cloud ဝန်ဆောင်မှုစနစ် အများစုတွင် Outline ဆာဗာကို စနစ်ထည့်သွင်းနိုင်သည်။

အလွယ်ကူဆုံးနည်းလမ်းမှာ DigitalOcean တွင် စနစ်ထည့်သွင်းရန်ဖြစ်သည်။ အဘယ်ကြောင့်ဆိုသော် ၎င်းသည် အမ်စတာဒမ်၊ တိုရွန်တို၊ ဆန်ဖရန်စစ္စကိုနှင့် စင်္ကာပူကဲ့သို့ တည်နေရာများစွာတွင် ဆာဗာများရှိသောကြောင့်ဖြစ်သည်။ အခြား Cloud ဝန်ဆောင်မှုပေးသူ (သို့) ကိုယ်ပိုင်အခြေခံအဆောက်အအုံတွင် ထည့်သွင်းလိုပါက ‘Outline မန်နေဂျာ’ အပလီကေးရှင်းတွင် ‘အဆင့်မြင့်မုဒ်’ ရွေးပြီး စနစ်ထည့်သွင်းမှု လမ်းညွှန်ဖိုင်သုံး၍ ညွှန်ကြားချက်များအတိုင်း လုပ်ဆောင်နိုင်သည်။

## ကျွန်ုပ်၏ Outline ဆာဗာကို မည်သည့်နေရာတွင် စနစ်ထည့်သွင်းသင့်ပါသလဲ။

1. သင်၏ ‘Outline ဆာဗာ’ အတွက် တည်နေရာ ရွေးသောအခါ အချက်အချို့ကို ထည့်သွင်းစဉ်းစားသင့်ပါသည်-
2. ‘Outline ဆာဗာ’ တည်နေရာသည် အသုံးပြုသူများ၏ အင်တာနက်သုံးမှုအပေါ် သက်ရောက်သည်။ ဥပမာ- ဆာဗာသည် အမ်စတာဒမ်တွင် တည်ရှိပါက ဤဆာဗာသုံးနေသူသည် နယ်သာလန်တွင် လူကိုယ်တိုင် ရှိနေသကဲ့သို့ အင်တာနက်ကို အသုံးပြုနိုင်ပါမည်။ ဝဘ်ဆိုက်အချို့သည် ဒတ်ချ်ဘာသာစကားဖြင့်ပင် ပြသနိုင်သည်။ ပုံမှန်အားဖြင့် ဝဘ်ဆိုက်ပေါ်ရှိ ဘာသာစကားရွေးချယ်စနစ်သုံး၍ ဒေသဆိုင်ရာ ဘာသာစကားကို အစားထိုးနိုင်သည်။
3. သင်၏ အသုံးပြုသူများနှင့် ‘Outline ဆာဗာ’ ကြား အကွာအဝေးသည် မြန်နှုန်းများအပေါ် သက်ရောက်နိုင်သည်။ ယေဘုယျအားဖြင့် Outline အသုံးပြုသူများနှင့် ဆာဗာကြား အကွာအဝေးသည် အသုံးပြုသူများ၏ အင်တာနက်မြန်နှုန်းများအပေါ် သက်ရောက်နိုင်သည်။ များသောအားဖြင့် အသုံးပြုသူများရှိမည်ဟု သင်မျှော်လင့်ထားသောနေရာနှင့် အနီးဆုံးဖြစ်သည့် ဆာဗာတည်နေရာကို ရွေးနိုင်သော်လည်း သင်၏ နိုင်ငံ (သို့) ဒေသနှင့် ချိတ်ဆက်သော အင်တာနက်ကြိုးများကို သိနိုင်ရန်အတွက် [Submarine Cable Map](https://www.submarinecablemap.com/) ကို ကြည့်နိုင်သည်။
4. သင်၏ VPN ဆာဗာ တည်ရှိသောနေရာသည် ဥပဒေဆိုင်ရာ ကန့်သတ်ချက်အပေါ် သက်ရောက်နိုင်သည်။ Outline ဆော့ဖ်ဝဲသည် သင်၏ ဒေတာစီးဆင်းမှုကို မှတ်တမ်းမတင်ကြောင်း သတိပြုပါ။ [Outline သုံးနေစဉ် လုံခြုံရေးနှင့် ကိုယ်ရေးအချက်အလက်လုံခြုံမှု](/about/security-and-privacy) အကြောင်း ပိုမိုလေ့လာပါ။
