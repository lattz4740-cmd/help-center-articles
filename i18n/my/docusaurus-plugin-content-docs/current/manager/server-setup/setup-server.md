Outline ဆာဗာကို စနစ်ထည့်သွင်းခြင်းသည် Outline သုံးနိုင်ရန် ပထမဆုံးအဆင့်ဖြစ်သည်။ Outline မှတစ်ဆင့် အများသုံး အင်တာနက်နှင့် ချိတ်ဆက်နိုင်ရန် သင် (သို့) သင်ယုံကြည်ရသူတစ်ဦးက သင့်အတွက် ဆာဗာကို စနစ်ထည့်သွင်းရပါမည်။

**မစတင်မီ**

 သင်၏ Outline ဆာဗာ စနစ်ထည့်သွင်းမှု မစတင်မီ အချို့အရာများကို လိုအပ်ပါမည်-

1. သင့်ကိုယ်ပိုင် ဆာဗာများသို့ အသုံးပြုခွင့် သို့မဟုတ် DigitalOcean၊ Amazon ဝဘ်ဝန်ဆောင်မှုများ (AWS) (သို့) Google Cloud Platform (GCP) ကဲ့သို့ Cloud ဝန်ဆောင်မှုပေးသူကို အသုံးပြုခွင့်။

 Cloud ဆာဗာ အသုံးပြုခွင့်ကို ချက်ချင်းမရပါက အထက်တွင် ဖော်ပြထားသည်များအပါအဝင် ဝန်ဆောင်မှုပေးသည့် ကုမ္ပဏီတစ်ခုခုနှင့် အကောင့်ကို အလွယ်တကူ စနစ်ထည့်သွင်းနိုင်သည်။ အကောင့်ဖွင့်ရန် ခရက်ဒစ်ကတ် လိုအပ်နိုင်ပါသည်။
2. macOS 10.9+၊ Windows 7.0+ (သို့) Linux အသုံးပြုသော ဒက်စ်တော့ကွန်ပျူတာ။
3. ‘Outline မန်နေဂျာ’ အပလီကေးရှင်း။

**DigitalOcean ဖြင့် စနစ်ထည့်သွင်းခြင်း**

 ကလစ်အနည်းငယ်နှိပ်ရုံဖြင့် DigitalOcean တွင် Outline ထည့်သွင်းနိုင်ရန် လူတိုင်းအတွက် လွယ်ကူအောင် ပြုလုပ်ပေးထားပါသည်။ သင့်ကွန်ပျူတာတွင် ‘Outline မန်နေဂျာ’ ကို ဒေါင်းလုဒ်လုပ်၍ ထည့်သွင်းပြီးနောက် DigitalOcean စနစ်ထည့်သွင်းရန် နည်းလမ်းကို ရွေးနိုင်သည်။ ယင်းနည်းလမ်းသည် သင်၏ ‘Outline ဆာဗာ’ ကို စီစဉ်သတ်မှတ်ပြီး ထည့်သွင်းနိုင်ရန် ရိုးရှင်းသော စခရင်ပြသမှု အနည်းငယ်ဖြင့် လမ်းညွှန်ပေးပါမည်။

**အခြား Cloud ဝန်ဆောင်မှုပေးသူဖြင့် စနစ်ထည့်သွင်းခြင်း**

 ‘Outline မန်နေဂျာ’ ကို ဒေါင်းလုဒ်လုပ်၍ ထည့်သွင်းပြီးနောက် ပကတိအသွင်စက်တွင် Outline ဆာဗာကို AWS၊ GCP၊ DigitalOcean (သို့) အခြားဝန်ဆောင်မှုပေးသူဖြင့် ထည့်သွင်းရန် ရွေးနိုင်သည်။ အခြေအနေတိုင်းက ကွဲပြားသဖြင့် ဆာဗာတွင် Outline ထည့်သွင်းရန် ထည့်သွင်းမှု script ကို မလုပ်ဆောင်မီ သင်၏ပကတိအသွင်စက်တွင် ဆက်တင်များ စီစဉ်သတ်မှတ်နည်းအပါအဝင် ‘Outline မန်နေဂျာ’ စနစ်ထည့်သွင်းမှု လုပ်ငန်းစဉ်အတွင်း အသုံးအများဆုံး Cloud ဝန်ဆောင်မှုပေးသူများအတွက် ညွှန်ကြားချက်များကို ထည့်ထားသည်။
