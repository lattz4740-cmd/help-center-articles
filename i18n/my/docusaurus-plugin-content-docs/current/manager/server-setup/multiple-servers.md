နောက်ထပ် ‘Outline ဆာဗာများ’ စနစ်ထည့်သွင်းရန်အတွက် ‘Outline မန်နေဂျာ’ အပလီကေးရှင်း၏ ဘယ်ဘက်ခြမ်းရှိ လမ်းညွှန်အကန့်တွင် “+” သင်္ကေတကို နှိပ်ပါ။ ဆာဗာအသစ်ထည့်ရန် ညွှန်ကြားချက်များသည် သင်၏ ပထမဆုံးဆာဗာကို ထည့်သွင်းစဉ်ကအတိုင်းဖြစ်သည်။

- သင်ပြုလုပ်နိုင်သော Outline ဆာဗာအရေအတွက်ကို ကျွန်ုပ်တို့ ကန့်သတ်မထားပါ။
- သင်ပြုလုပ်သော Outline ဆာဗာတိုင်းအတွက် သင့်တော်သည့် ပကတိအသွင်စက် လိုအပ်ပါမည်။
- နောက်ထပ်စက်များ (သို့) droplet များ ပြုလုပ်ပါက သင်၏ Cloud ဝန်ဆောင်မှုပေးသူအား အခကြေးငွေ ပိုပေးရနိုင်သည်။ သင်ရနိုင်မည့်အရာများကို သေချာသိရှိရန်အတွက် ဈေးနှုန်းပက်ကေ့ဂျ်ကို Cloud ဝန်ဆောင်မှုပေးသူထံ မေးမြန်းပါ။

## DigitalOcean တွင် နောက်ထပ် Outline ဆာဗာ ပြုလုပ်ခြင်း

+ သင်္ကေတနှိပ်ပြီး DigitalOcean တွင် ထည့်သွင်းရန် ရွေးပြီးပါက သင်၏ ပထမဆုံးဆာဗာကို စနစ်ထည့်သွင်းရန် ဆောင်ရွက်ခဲ့သော ညွှန်ကြားချက်များကို လိုက်နာရပါမည်။ ‘Outline မန်နေဂျာ’ ကို DigitalOcean နှင့် ပေါင်းစပ်ထားသဖြင့်လည်း သင်သည် ‘Outline မန်နေဂျာ’ အက်ပ်မှ ထွက်စရာမလိုဘဲ ကျွန်ုပ်တို့က သင့်အတွက် droplet ကို ပြုလုပ်ပေးနိုင်ပါသည်။

‘Outline မန်နေဂျာ’ သည် တစ်ကြိမ်လျှင် DigitalOcean အကောင့်တစ်ခုကိုသာ ပံ့ပိုးနိုင်ကြောင်း သတိပြုပါ။ အခြားသော DigitalOcean အကောင့်များမှ နောက်ထပ် Outline ဆာဗာများ ထည့်လိုပါက (သို့) ပြုလုပ်လိုပါက ၎င်းတို့ကို အဆင့်မြင့်စီစဉ်သတ်မှတ်ချက်အဖြစ် ထည့်နိုင်သည်။

## GCP၊ AWS (သို့) အခြားသော Cloud ဝန်ဆောင်မှုပေးသူထံတွင် နောက်ထပ် Outline ဆာဗာ ပြုလုပ်ခြင်း

ပကတိအသွင်စက်အသစ်ကို သင်ရွေးထားသော Cloud ဝန်ဆောင်မှုပေးသူနှင့် ပြုလုပ်ခြင်းဖြင့် စတင်ပါ။ ထို့နောက် ‘Outline မန်နေဂျာ’ ဖွင့်ပြီး ပထမဆုံးအကြိမ်တွင် ဆောင်ရွက်ထားသကဲ့သို့ အဆင့်မြင့်ထည့်သွင်းမှုအတွက် ညွှန်ကြားချက်များကို လိုက်နာပါ။
