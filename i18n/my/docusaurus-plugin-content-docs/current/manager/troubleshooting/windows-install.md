ဤမှားယွင်းကြောင်းမက်ဆေ့ဂျ်ကို သင်မြင်ရနိုင်သည်- “Outline ကို မှန်ကန်စွာ ထည့်သွင်းထားပုံမရပါ။ ထပ်မံ ထည့်သွင်းကြည့်ပါ။ မရပါက [အကြံပြုချက် ပို့ပါ](/about/feedback)။”

Outline ကို Windows တွင် သုံးနေပါက မျှော်လင့်မထားသော အမှားကို ရံဖန်ရံခါ ကြုံရနိုင်သည်။ အခြေအနေအများစုတွင် Outline TAP အဒက်တာ (ဒရိုင်ဗာ) ဖျက်ရန် လိုအပ်ပြီး Outline ကို ပြန်ထည့်သွင်းရပါမည်။

အဆင့်များသည် သင်၏ Windows လည်ပတ်သည့်စနစ် ဗားရှင်းပေါ်မူတည်၍ ကွဲပြားနိုင်သော်လည်း TAP အဒက်တာနှင့် ‘Outline မန်နေဂျာ’ တို့ကို ဖယ်ရှားပြီး ‘Outline မန်နေဂျာ’ ပြန်ထည့်သွင်းနည်းအတွက် ယေဘုယျအဆင့်များကို အောက်တွင် ပေးထားပါသည်။

1. ‘Outline မန်နေဂျာ’ အတွက် TAP အဒက်တာကို ဖယ်ရှားခြင်း
   1. ‘စက်စီမံစနစ်’ သို့သွားပြီးနောက် ‘ကွန်ရက်အဒက်တာများ’ သို့သွားပါ
   2. Outline နှင့် ဆက်စပ်သော “TAP-Windows အဒက်တာ V9” ဖိုင် (သို့) TAP အဒက်တာကို ရှာပါ
   3. ဤအဒက်တာကို ဖယ်ရှားပါ (သို့) ဖျက်ပါ။ ၎င်းသည် သင်ထည့်သွင်းထားသော အခြား VPN အက်ပ်များကို သက်ရောက်မှုရှိနိုင်ကြောင်း သတိပြုပါ။
2. Outline မန်နေဂျာကို ဖယ်ရှားခြင်း
   1. ‘ပရိုဂရမ်နှင့် ဝန်ဆောင်မှုများ’ သို့သွားပြီးနောက် ‘ပရိုဂရမ်ကို ဖယ်ရှားရန်’ သို့သွားပါ
   2. ‘Outline မန်နေဂျာ’ အက်ပ်ကို ရှာပြီး ‘Outline မန်နေဂျာ’ ကို ဖယ်ရှားပါ
   3. [Outline မန်နေဂျာ နောက်ဆုံးဗားရှင်းကို ဒေါင်းလုဒ်လုပ်](https://getoutline.org/get-started/#step-1) ပြီး သင့် Windows စက်တွင် ပြန်ထည့်သွင်းပါ။ အသစ်ထည့်သွင်းမှုသည် TAP အဒက်တာအသစ်ကို အလိုအလျောက် ထည့်သွင်းမည်။

ပြဿနာရှိနေသေးပါက [အကူအညီထံ ဆက်သွယ်ပါ](/about/feedback)။
