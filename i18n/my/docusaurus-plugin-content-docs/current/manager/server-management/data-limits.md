သုံးခွင့်ကီးအားလုံးတွင် အသုံးပြုမည့် ဒေတာကန့်သတ်ချက်ကို သတ်မှတ်နိုင်သည်။ ကန့်သတ်ချက် သတ်မှတ်ရန် ‘Outline မန်နေဂျာ’ ဖွင့်ပြီး ဆက်တင်များသို့ သွားပါ။ ထိုနေရာတွင် ‘ဒေတာကန့်သတ်ခြင်း’ ခလုတ်ကို တွေ့ရမည်ဖြစ်ပြီး ၎င်းကိုဖွင့်ထားပါက ကန့်သတ်ချက် သတ်မှတ်နိုင်သည်။

![Data limits setting in Outline Manager](/images/snippet-15787036.png)

ကန့်သတ်ချက် သတ်မှတ်ပြီးသည်နှင့် သုံးခွင့်ကီးစာမျက်နှာတွင် အသုံးပြုသူတစ်ဦးစီသည် ကန့်သတ်ချက်နှင့် မည်မျှနီးကပ်သည်ကို တွေ့မြင်နိုင်သည်။ ၎င်းနေရာတွင် ဘားဂရပ်ဖ်သည် နောက်ဆုံးရက် ၃၀ အတွင်း ဒေတာအသုံးပြုမှုကို ပြသည်။

![Outline Manager's Access Key page](/images/snippet-15787037.png)

သင်၏ ဝင်ခွင့်ကီးအားလုံးအတွက် ကန့်သတ်ချက် သတ်မှတ်နိုင်ခြင်းအပြင် ကီးတစ်ခုစီအား ကိုယ်ပိုင်ဒေတာကန့်သတ်ချက် ပေးနိုင်သည်။ ဤဆက်တင်သည် သင်သတ်မှတ်ထားသော မူလ ဒေတာကန့်သတ်ချက်တိုင်းကို အစားထိုးပါမည်။ သို့သော် မူလ ဒေတာကန့်သတ်ချက်ကို သတ်မှတ်မထားပါက မည်သည့်ကီးအတွက်မဆို ဒေတာကန့်သတ်ချက် သတ်မှတ်နိုင်ပါသေးသည်။ 

 ကီး၏ ဒေတာလွှဲပြောင်းခြင်း ကန့်သတ်ချက် သတ်မှတ်ရန် ‘Outline မန်နေဂျာ’ ဖွင့်ပါ။ သင်သတ်မှတ်လိုသော ကီးပါဝင်သည့် ‘ချိတ်ဆက်မှုများ’ တဘ်သို့ သွားပြီး ကီးအတန်း၏ ညာဘက်ရှိ မီနူးကို နှိပ်ပါ။ ထိုနေရာမှ ‘ဒေတာကန့်သတ်ခြင်း’ ကို နှိပ်ပါ။ “ကျွန်ုပ်၏ သုံးခွင့်ကီး” တွင် ဒေတာကန့်သတ်ခြင်း ပြောင်းရန် ‘ဒေတာကန့်သတ်ခြင်း’ သင်္ကေတ ![ဤပုံကို မရနိုင်သည့် အကြောင်းရင်း- သင်သည် ၎င်းကို ကြည့်ခွင့်မရှိပါ (သို့) ၎င်းကို စနစ်မှ ဖယ်ရှားထားသည်](https://lh7-us.googleusercontent.com/docsz/AD_4nXc2jByBppEN1yHPjbK2BxNuYxwmfW98eYRyJGiDmg4lSLNLxf5aav2971IntWOfqF8oJ1zhW7RVdaxJVxkdZkpsDeSgnBbJfNisidjKbcRh3FheoVjQNSZHHEgUz155B1_wRjlB2mAIa6Qfs5k7Mg_i6YJhYle80EPoZVkdl09uvBbSxUgfLvPserKL8dSCElVSLcuo7uF232qnTKFKM4gt_f0iDQ?key=oLpwwvDVb_5YbZSyjC9Agw) ကို နှိပ်ပါ။

![Selecting the data limit setting icon for an individual access key](/images/snippet-15787423.png)

‘စိတ်ကြိုက်ဒေတာကန့်သတ်ခြင်း သတ်မှတ်ရန်’ ကို ရွေးပါ။ ဤအမှတ်ခြစ်ရန် နေရာကို ရွေးပြီးပါက ယင်းကီးအတွက် စိတ်ကြိုက်ဒေတာကန့်သတ်ချက် သတ်မှတ်နိုင်သော အကွက်ကို မြင်ရပါမည်။ ဒေတာကန့်သတ်ချက် သိမ်းရန် လုပ်ဆောင်ပြီးပါက ‘သိမ်းရန်’ ခလုတ်ကို နှိပ်ပါ။

![Setting a data limit for an individual access key](/images/snippet-15788959.png)

ရွေးထားသောကီးအတွက် ဒေတာလွှဲပြောင်းမှုကန့်သတ်ချက်ကို သိမ်းပြီးပါက ကီးတစ်ခုစီအတွက် ဒေတာအသုံးပြုမှု (ပြီးခဲ့သော ရက်ပေါင်း ၃၀ ကျော်က) နှင့်အတူ ကန့်သတ်ချက်ကို ပင်မစခရင်ပေါ်တွင် ပြပါမည်။

ဝင်ခွင့်ကီးမှ ဒေတာကန့်သတ်ခြင်း ဖယ်ရှားရန် ယခင်အတိုင်း ကီး၏ ‘ဒေတာကန့်သတ်ခြင်း’ သို့ သွားပါ။ ‘စိတ်ကြိုက်ဒေတာကန့်သတ်ခြင်း သတ်မှတ်ရန်’ ဟု အညွှန်းတပ်ထားသော အကွက်ကို အမှန်ခြစ်ဖြုတ်ပြီး ‘သိမ်းရန်’ ခလုတ်ကို နှိပ်ပါ။

![Removing the data limit on an individual access key](/images/snippet-15788414.png)

****ဒေတာကန့်သတ်ခြင်း မေးခွန်းများ****

****ရက် ၃၀ ကြာ ဒေတာကန့်သတ်ခြင်း ခြေရာခံမှုဆိုတာ ဘာလဲ။****

 ရက် ၃၀ ကြာ ကန့်သတ်ဒေတာ ခြေရာခံခြင်းသည် ကီးတစ်ခုစီ၏ ပြီးခဲ့သော ရက်ပေါင်း ၃၀ ကျော်က အသုံးပြုမှုကို ပေါင်းမည်ဖြစ်ပြီး ယင်းကာလက ကီး၏ အသုံးပြုမှုကို ကန့်သတ်ချက်မကျော်အောင် ပြုလုပ်ပါမည်။ အကျိုးသက်ရောက်မှုမှာ ကီးသည် ရက် ၃၀ နှင့်အောက်ရှိသော ပြက္ခဒိန်လများအပါအဝင် မည်သည့် ရက် ၃၀ ကာလအတွင်းမဆို ကန့်သတ်ချက် ကျော်လွန်မသွားနိုင်ပါ။ ဆိုလိုသည်မှာ အသုံးပြုသူ တစ်ဦးစီသည် ပြီးခဲ့သော ၃၁ ရက်က သုံးထားသည့် ပမာဏအလိုက် သူတို့ရနိုင်သော ဒေတာများ နေ့စဉ် များပြားလာပါမည်။

**ကန့်သတ်ဒေတာ ခြေရာခံခြင်းများကို Outline က ဘာလို့သုံးပါသလဲ။**

 ကန့်သတ်ဒေတာ ခြေရာခံခြင်းသည် ရက် ၃၀ ကာလတိုင်းတွင် အာမခံချက်ပေးပါသည်။ ဆိုလိုသည်မှာ ပြန်ကျော့သော ကန့်သတ်ချက် (တစ်လတာတွင် စိတ်ကြိုက်လုပ်နိုင်သောနေ့ကဲ့သို့) သည် အလားတူအာမခံချက်များ ပေးထားသည့်တိုင်အောင် ၎င်းတို့ထက် ကန့်သတ်ဒေတာ ခြေရာခံခြင်းများက စီစဉ်သတ်မှတ်ရန် ပိုမိုရိုးရှင်းသည်။ ၎င်းတို့သည် Outline ဒေတာအသုံးပြုမှုအပြင် စိတ်ဖြာလေ့လာချက် ဝန်ဆောင်မှုနှင့် ဆာဗာ ကိန်းဂဏန်းစာရင်းများကဲ့သို့ အသုံးများသောတူးလ်များအတွက်လည်း ရှိပြီးသား ပြကွက်နှင့် ကိုက်ညီသည်။

**ဒေတာကန့်သတ်ချက်တွင် မည်သည့်ဒေတာတွေကို ရေတွက်သလဲ။**

 သုံးခွင့်ကီးတစ်ခုစီ၏ ဆာဗာမှ ထုတ်လွှတ်မှုသည် စာရင်းထဲတွင် ပါဝင်သည်။ ဆိုလိုသည်မှာ ဒေတာကို ကီးအစား ဆာဗာမှပို့ပြီး ကလိုင်းယင့်သို့လည်း ပြန်ပို့သည်။ ကီးမှ ဆာဗာသို့ပို့သော ဒေတာစီးဆင်းမှုနှင့် ချိန်ညှိမည်ဖြစ်သဖြင့် ၎င်းသည် အသုံးပြုသူများ၏ စာရင်းများနှင့် ကိုက်ညီမည်ဟု မျှော်လင့်ပါသည်။ Cloud ဝန်ဆောင်မှုပေးသူများ၏ ငွေတောင်းခံလွှာကို ကျွန်ုပ်တို့ဆန်းစစ်ရန်အတွက် egress ကို ရွေးထားခြင်းဖြစ်သည်။

**ဒေတာကန့်သတ်ချက် ပြည့်သွားပါက အသုံးပြုသူများကို အကြောင်းကြားမလား။**

 လောလောဆယ် မရနိုင်ပါ။ Cloud ဝန်ဆောင်မှုပေးသူများစွာသည် တစ်လလုံးအတွက် ၁ TB ကဲ့သို့ ကန့်သတ်ချက် ထည့်ထားသည်။ ယင်းကန့်သတ်ချက်သည် အသုံးပြုသူ ၁၀ ဦးကို ၁၀၀ GB (သို့) အသုံးပြုသူဦးရေ ၁၀၀ ကို ၁၀ GB ပံ့ပိုးနိုင်သည်။ ၎င်းတို့က အလွန်မြင့်မားသော ပမာဏများဖြစ်ပြီး အသုံးပြုသူအများအပြားသည် ၎င်းပမာဏအထိ ရောက်မည်မထင်ပါ။ အသုံးပြုသူများသည် ကန့်သတ်ချက်ပြည့်သွားသောအခါ ဆာဗာမန်နေဂျာများထံ ဆက်သွယ်လာမည်ဟု မျှော်လင့်ပါသည်။ သို့သော် သင်၏ အသုံးပြုမှုအကြောင်းအရာအတွက် အကြောင်းကြားချက်များက ကူညီနိုင်ပုံနှင့်ပတ်သက်သော သင့်သဘောထားကို ကျွန်ုပ်တို့သိလိုပါသည်။ [ဤနေရာတွင်](/about/feedback)ကျွန်ုပ်တို့ထံ ဆက်သွယ်နိုင်ပါသည်။

**ဒေတာကန့်သတ်ချက် ပြည့်ခါနီးပါက အသုံးပြုသူများကို အကြောင်းကြားမလား။**

 ကန့်သတ်ချက် ပြည့်ခါနီး အသုံးပြုသူ ရရှိမည့် ဒေတာပမာဏအသစ်သည် ပြီးခဲ့သော ရက်ပေါင်း ၃၀ က သူတို့၏ အသုံးပြုမှုပေါ် မူတည်သဖြင့် နေ့စဉ်နှင့်အမျှ ကွဲပြားမည်။ သတိပေးချက်သည် အသုံးပြုသူများအား အကူအညီဖြစ်စေမည့်အစား စိတ်ရှုပ်စေမည်ဟု ယူဆပါသည်။ ဤလုပ်ဆောင်ချက်နှင့် ပတ်သက်သော သင့်အကြံပြုချက်ကို[ဤနေရာ](/about/feedback) တွင် ပေးနိုင်ပါသည်။

**ကျွန်ုပ်သည် အသုံးပြုသူ၏ ဒေတာသုံးစွဲမှုကို ပြင်ဆင်သတ်မှတ်နိုင်ပါသလား။**

 မရပါ။ အသုံးပြုသူ၏ ကန့်သတ်ချက်တွင် ပြီးခဲ့သော ရက်ပေါင်း ၃၀ က ဒေတာအသုံးပြုမှု ပါဝင်သည်။ အသုံးပြုသူ ကီး၏ ဒေတာကန့်သတ်ချက်ကို မြှင့်ပေးနိုင်သည် (သို့) သူတို့အတွက် ကီးအသစ် လုပ်ပေးနိုင်သည်။

**ကျွန်ုပ်၏ အသုံးပြုသူအချို့သည် ဒေတာကန့်သတ်ချက်များကို ကျွန်ုပ်ဖွင့်လိုက်သည်နှင့် အဘယ်ကြောင့် သုံးခွင့်ဆုံးရှုံးသွားပါသလဲ။**

 ‘ဒေတာကန့်သတ်ခြင်း’ သည် အသုံးပြုသူ၏ ယခင် ရက်ပေါင်း ၃၀ က ဒေတာလွှဲပြောင်းခြင်းအပေါ် အခြေခံသည်။ ဒေတာကန့်သတ်ချက်များကို ဖွင့်ထားသည်ဖြစ်စေ၊ ဖွင့်မထားသည်ဖြစ်စေ ယင်းလွှဲပြောင်းမှုကို မှတ်တမ်းတင်ပါသည်။ အဆိုပါ အသုံးပြုသူများသည် ကန့်သတ်ချက် မသတ်မှတ်မီကပင် ၎င်းကို ကျော်လွန်နေခြင်းမျိုး ဖြစ်နိုင်သည်။ ကီးတစ်ခု၏ ဒေတာကန့်သတ်ချက် ပြောင်းလျှင်ပင် ဒေတာကန့်သတ်ချက်အားလုံးကို မဖြစ်မနေသတ်မှတ်သည်ကိုလည်း သတိပြုပါ။

**“ရက်ပေါင်း ၃၀ လျှင် ၁ TB” ကဲ့သို့ ဆာဗာတစ်ခုလုံးသုံးသော ကန့်သတ်ချက်ကို သတ်မှတ်နိုင်ပါသလား။**

 လောလောဆယ် မရနိုင်ပါ။ သင်၏ အသုံးပြုမှုအကြောင်းအရာကို[ဤနေရာတွင်](/about/feedback) နားထောင်လိုပါသည်။

**မူလ ဒေတာကန့်သတ်ချက်နှင့် သီးသန့်ကီးတွင် ဒေတာကန့်သတ်ချက် ရှိပါက မည်သည်ကို လိုက်နာရပါမလဲ။**

 သီးသန့်ကီး၏ ဒေတာကန့်သတ်ချက်သည် သင်သတ်မှတ်ထားသော မူလ ဒေတာကန့်သတ်ချက် (ရှိပါက) များကို အစားထိုးပါမည်။

**မူလ ဒေတာကန့်သတ်ချက် မသတ်မှတ်ဘဲ သီးသန့်ကီးအတွက် ဒေတာကန့်သတ်ချက်ကို သတ်မှတ်နိုင်ပါသလား။**

 သတ်မှတ်နိုင်ပါသည်။ ကီးတစ်ခုတွင် ဒေတာကန့်သတ်ချက် သတ်မှတ်ရန်အတွက် မူလကန့်သတ်ချက်ကို သတ်မှတ်ရန် မလိုအပ်ပါ။ ဥပမာ- အများအပြား မျှဝေနိုင်သည်ဟု ယူဆရသော ကီးတစ်ခုမှတစ်ဆင့် အလွန်အကျွံ ဒေတာလွှဲပြောင်းခြင်း မဖြစ်စေရန် ယင်းကီးတွင်ကန့်သတ်ချက် သတ်မှတ်နိုင်သည်။
