---

သတ်မှတ်ပြီးပါက ဆာဗာတည်နေရာကို ပြောင်း၍မရပါ။ သင့်ဆာဗာကို အခြားနေရာမှ လုပ်ဆောင်မည်ဆိုပါက သင်၏ Outline ဆာဗာကို ဖျက်ပြီး အသစ်လုပ်ရပါမည်။

သင့် VPN တည်နေရာကို [ပြောင်းလဲနိုင်သောကီးများ](https://developers.google.com/outline/docs/guides/service-providers/dynamic-access-keys) သုံး၍ ပြောင်းခြင်းဖြင့်လည်း ဆာဗာများကို တူညီသောကီးများဖြင့် လှည့်သုံးနိုင်ပါသည်။ ဆာဗာများ၏တည်နေရာ ပြောင်းမည်မဟုတ်ပါ။
