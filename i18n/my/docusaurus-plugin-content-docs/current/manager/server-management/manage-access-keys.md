သင်၏ Outline ဆာဗာကို စနစ်ထည့်သွင်းပြီးပါက ၎င်းသုံးခွင့်ကို လူများအား မျှဝေခြင်းနှင့် ယင်းလူများ၏ သုံးခွင့် စီမံခြင်းတို့ကို စတင်နိုင်ပါပြီ။ သင့်ထံမှ ဖိတ်ကြားချက် ရရှိသူသည် Outline သုံးရန် Outline အက်ပ်ကို ဒေါင်းလုဒ်လုပ်ပြီး သူ၏ အင်တာနက် ဒေတာစီးဆင်းမှုကို ကာကွယ်နိုင်ပါမည်။

## သင်၏ Outline ဆာဗာသုံးခွင့်ကို မျှဝေခြင်း
 Outline ဆာဗာကို စနစ်ထည့်သွင်းပြီးနောက်တွင် ‘Outline မန်နေဂျာ’ ရှိ ဆာဗာအသေးစိတ် စာမျက်နှာသို့ သင့်အား လမ်းညွှန်မည်ဖြစ်ပြီး ယင်းနေရာတွင် ဝင်ခွင့်ကီးများကို ပြုလုပ်နိုင်သည်။ [ဝင်ခွင့်ကီးများ](/about/terminology) အကြောင်း ပိုမိုလေ့လာပါ။

- ကီးများ ပြုလုပ်ရန်- ကီးအသစ်များ ပြုလုပ်ရန် စာမျက်နှာအောက်ခြေရှိ သေးငယ်သော “+” သင်္ကေတကို နှိပ်ပါ။
- ကီးများ မျှဝေရန်- ကီးတစ်ခုစီ၏ ညာဘက်ရှိ မျှဝေမှုသင်္ကေတကို နှိပ်ပြီး ဖိတ်ကြားချက် ရယူနိုင်သည်။ ဤဖိတ်ကြားချက်ကို သင်ရွေးထားသော မက်ဆေ့ဂျ်ပို့သည့်စနစ်ထဲသို့ မိတ္တူကူးပြီး ထည့်ပါ။

## အထူးပြု တောင်းဆိုချက်- Outline မန်နေဂျာ အက်ပ်အတွင်းမှ သုံးခွင့် မျှဝေခြင်း
 ဆာဗာစီမံခန့်ခွဲသူ အများအပြားသည် သူတို့အား တစ်စုံတစ်ဦး၏ အီးမေးလ်လိပ်စာကို ‘Outline မန်နေဂျာ’ သို့ တိုက်ရိုက်ထည့်ခွင့်ပေးခြင်းဖြင့် ဖိတ်ကြားခြင်းလုပ်ငန်းစဉ် ချောမွေ့အောင် ပြုလုပ်ပေးရန် ကျွန်ုပ်တို့အား တောင်းဆိုပါသည်။

ဤလုပ်ဆောင်ချက်ကို ‘Outline မန်နေဂျာ’ တွင် ထည့်၍မရနိုင်ပါ။ ကျွန်ုပ်တို့၏ အဓိကမူများအနက် တစ်ခုမှာ အသုံးပြုသူများ၏ ကိုယ်ရေးအချက်အလက်လုံခြုံမှုနှင့် လုံခြုံရေးအတွက် ပံ့ပိုးရန်ဖြစ်သဖြင့် အီးမေးလ်လိပ်စာ (သို့) ဆက်သွယ်ရန် အချက်အလက်များ ထည့်ရန် မည်သည့်နေရာကိုမျှ ပြုလုပ်မထားပါ။

ထို့ကြောင့် အသုံးပြုသူထံ ဖိတ်ကြားချက် ပို့ရန်အတွက် အီးမေးလ် (သို့) လုံခြုံသည့် ချတ်လုပ်ခြင်းကဲ့သို့ စိတ်ချရသော မက်ဆေ့ဂျ်ပို့သည့်စနစ်သုံးရန် ဆာဗာစီမံခန့်ခွဲသူများအား တောင်းဆိုခြင်းဖြစ်သည်။

## သင်သည် အသုံးပြုသူတစ်ဦးအား ဝင်ခွင့်ကီး မျှဝေပြီးနောက် သူ၏အတွေ့အကြုံများ
1. အသုံးပြုသူသည် သူ၏စက်မှ ထည့်သွင်းမှုလင့်ခ်ကို နှိပ်ပါမည်
2. သူ့တွင် Outline အက်ပ် မရှိသေးပါက ထည့်သွင်းရန် သတိပေးပါမည်
3. သူသည် ဖိတ်ကြားချက်ထဲတွင် မြှုပ်သွင်းထားသော သီးခြားကီးမှတစ်ဆင့် သင်၏ Outline ဆာဗာသို့ ကနဦးချိတ်ဆက်မှု ပြုလုပ်ပါမည်
4. သူသည် ချိတ်ဆက်ရန်/ချိတ်ဆက်မှုဖြုတ်ရန် ခလုတ်နှိပ်ပြီး သင်၏ Outline ဆာဗာမှတစ်ဆင့် သူ၏ အင်တာနက်သုံးခွင့်ကို စီမံခန့်ခွဲနိုင်ပါပြီ

## သင်၏ Outline ဆာဗာသုံးခွင့်ကို ဖယ်ရှားခြင်း
 ‘Outline မန်နေဂျာ’ ရှိ ဆာဗာအသေးစိတ် စာမျက်နှာတွင် ဆာဗာပေါ်ရှိ ကီးတိုင်း၏ ညာဘက်၌ ကီးဖျက်ရန် ရွေးစရာပါသော မီနူးကို တွေ့ရပါမည်။ ကီးဖျက်ပါက သင့်ဆာဗာသို့ သူ၏ ဝင်ခွင့်ကို ဖယ်ရှားပေးသည်။
