Cloud ဝန်ဆောင်မှုပေးသူအများစုတွင် သင်သုံးနေသော သတ်မှတ်ပကတိအသွင်စက်ကို ဖယ်ရှားရန် အတန်အသင့်လွယ်ကူပါသည်။

သင်၏ Cloud ဝန်ဆောင်မှုပေးသူအဖြစ် DigitalOcean ကို သုံးနေပါက ဂီယာခလုတ်နှိပ်ပြီး ‘ဆာဗာကို ဖျက်ရန်’ ရွေးခြင်းဖြင့် သင့်တွင် ရှိပြီးသား ပကတိအသွင်စက်ကို ဖျက်နိုင်သည်။ ထို့နောက် သင်ရွေးထားသော တည်နေရာတွင် ပကတိအသွင်စက်အသစ် ပြုလုပ်ရန်အတွက် သင့်အား တိုက်တွန်းပါမည်။

Outline ဆာဗာ ဖယ်ရှားပါက ၎င်းကို အပြီးဖျက်မည်ဖြစ်ပြီး ၎င်း၏ အသုံးပြုခွင့်ကီးများ အလုပ်လုပ်တော့မည် မဟုတ်ပါ။ လူများက Outline မှတစ်ဆင့် သုံးရာတွင် အနှောင့်အယှက် မရှိစေလိုပါက [Outline ဆာဗာအသစ် စနစ်ထည့်သွင်း](/manager/server-setup/setup-server) ပြီး ဆာဗာအဟောင်း မဖျက်မီ ယင်းဆာဗာအသစ်သုံးခွင့်ကို မျှဝေရမည်။
