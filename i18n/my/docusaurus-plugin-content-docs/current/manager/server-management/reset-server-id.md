sidebar_label: ကျွန်ုပ်၏ ဆာဗာ ID ကို ဘယ်လိုပြောင်းရမလဲ။
---

ဆာဗာ ID သည် Outline ဆာဗာပြုလုပ်သောအခါ ကျပန်းထုတ်ပေးသည့် ဆာဗာဘက်ခြမ်း ID ဖြစ်သည်။ ဆက်တင်အင်တာဖေ့စ်တွင် အမည်မသိမက်ထရစ်များ မျှဝေခြင်း ရွေးသောအခါ ၎င်းကို တွေ့နိုင်သည်။ သင့်ဆာဗာ ID ကို ရှာနိုင်သည့်နေရာ- ဆက်တင်များ => အောက်သို့လှိမ့်ရန် => “အမည်မသိမက်ထရစ်များ မျှဝေရန်” ကို အမှန်ခြစ်ပါ။

ဆာဗာ ID သည် အချိန်နှင့်အမျှ အစီရင်ခံသော အမည်မသိ သုံးစွဲမှုဆိုင်ရာ အချက်အလက် ကိန်းဂဏန်းများကို အတူပူးတွဲပေးသည်။ ဆာဗာ ID ပြင်ဆင်သတ်မှတ်ပြီး အသစ်တစ်ခု ရယူလိုပါက သင့်တွင် ရှိပြီးသား Outline ဆာဗာကို အသစ်တစ်ခုနှင့် အစားထိုးရပါမည်။

သင်၏ Cloud ဝန်ဆောင်မှုပေးသူအဖြစ် DigitalOcean ကို သုံးနေပါက ဆက်တင်များသို့သွားပြီး ‘ဆာဗာကို ဖျက်ရန်’ ရွေးခြင်းဖြင့် သင့်ဆာဗာကို ပြင်ဆင်သတ်မှတ်နိုင်သည်။ ဤလုပ်ဆောင်ချက်ကို ပြန်ပြင်၍ မရနိုင်ဘဲ ၎င်းသည် သင်၏အထောက်အထားများကို ဖျက်ပါမည်။ ထို့နောက် သင်ရွေးထားသော တည်နေရာတွင် ဆာဗာအသစ် ပြုလုပ်ရန်အတွက် သင့်အား တိုက်တွန်းမည်ဖြစ်ပြီး ဆာဗာ ID အသစ်ကို ထုတ်ပေးပါမည်။
