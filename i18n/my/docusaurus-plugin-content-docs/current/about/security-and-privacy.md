Outline သုံးနေစဉ် လုံခြုံရေးနှင့် ကိုယ်ရေးအချက်အလက် လုံခြုံမှု

## သင်၏ အွန်လိုင်းဆက်သွယ်မှုများကို Outline က ကာကွယ်ပေးပုံ

အင်တာနက် ဒေတာစီးဆင်းမှုသည် ဒေသတွင်း (သို့) နိုင်ငံတွင်း ကွန်ရက်မှတစ်ဆင့် ဖြတ်သန်းနေစဉ် စောင့်ကြည့်ခံရရန် အားနည်းချက်အရှိဆုံးဖြစ်သည်။

အင်တာနက် ဒေတာစီးဆင်းမှုသည် နိုင်ငံတွင်း ကွန်ရက်အတွင်း ဖြတ်သန်းစဉ် ၎င်းကို အသွင်ဝှက်ခြင်းဖြင့် Outline သည် သင်၏ ဆက်သွယ်မှုများ သီးသန့်ဖြစ်စေရန် ကူညီပေးပြီး Outline ဆာဗာသို့ ရောက်သည်အထိ ဆက်လက်အသွင်ဝှက်ပေးသည်။ ဒေတာစီးဆင်းမှုကို Outline ဖြင့် အသွင်ဝှက်ထားသောအခါ ကွန်ရက်စောင့်ကြည့်သူများသည် သင်ဝင်ကြည့်သော ဝဘ်ဆိုက်များ (သို့) လွှဲပြောင်းနေသော အချက်အလက်များကို မစစ်ဆေးနိုင်ပါ။

Outline သည် သင့်နိုင်ငံတွင် သုံးမရနိုင်သည့် လုံခြုံပြီး ဆက်သွယ်သူချင်းသုံးနိုင်သော ဆက်သွယ်ရေးတူးလ်များသုံးခွင့်ကို ပြန်လည်ရယူရန်လည်း ကူညီပေးနိုင်သည်။

## အသွင်ဝှက်ခြင်း စံနှုန်းများ

Outline သည် သင့်စက်နှင့် ‘Outline ဆာဗာ’ ကြား ဆက်သွယ်မှုများကို AEAD 256-bit Chacha2020 IETF Poly 1305 စာဝှက်နည်းသုံးပြီး အသွင်ဝှက်ပေးသည်။ AEAD ဝှက်စာများသည် လျှို့ဝှက်မှု၊ ခိုင်မာမှုနှင့် စစ်မှန်မှုတို့ကို ပံ့ပိုးပေးပြီး ခေတ်မီဟာ့ဒ်ဝဲတွင် ထူးကဲစွာ စွမ်းဆောင်နိုင်ကြောင်း တွေ့ရသည်။

## လုံခြုံရေးစစ်ဆေးမှုများ

## အမည်မသိ မက်ထရစ်နှင့် မှတ်တမ်းများ

Outline သည် ဝင်ခွင့်ကီးတစ်ခုစီအတွက် သုံးထားသော မြန်နှုန်းကို “လွှဲပြောင်းထားသော ဘိုက်များ” အဖြစ် ခြေရာခံသည်။ ဤအချက်အလက်သည် ဆာဗာစီမံခန့်ခွဲသူများအား မြန်နှုန်းစာရင်းသွင်းမှုများကို သူတို့၏ Cloud ဆာဗာဝန်ဆောင်မှုပေးသူများနှင့် လိုသလိုချိန်ညှိခွင့်ပြုသော်လည်း Outline ဆာဗာမှတစ်ဆင့် ဖြတ်သွားသော အချက်အလက်အမှန်များကို ကြည့်ခွင့်မပြုပါ။

Outline ၏ [ဒေတာနှင့် အချက်အလက် စုဆောင်းမှု](/about/data-collection) အကြောင်း ပိုမိုလေ့လာပါ။

## လုံခြုံရေးနှင့် ကိုယ်ရေးအချက်အလက် လုံခြုံမှုဆိုင်ရာ မေးလေ့ရှိသော မေးခွန်းများ

## Outline သည် ကျွန်ုပ်ကို အွန်လိုင်းတွင် အမည်မသိအောင် လုပ်ဆောင်နိုင်ပါသလား။

Outline သည် ကိုယ်ရေးအချက်အလက် ဖျောက်သည့်တူးလ် မဟုတ်ပါ။ Outline သည် သင်၏ ကိုယ်ရေးအချက်အလက်လုံခြုံမှုကို ကွန်ရက်ပရိသတ်များရန်မှ ကာကွယ်ပေးသည်။

Outline သည် သင်ဝင်ကြည့်သော ဝဘ်ဆိုက်များတွင် ကိုယ်ရေးအချက်အလက်ဖျောက်ရန် အပြည့်အဝလုပ်ဆောင်မပေးပါ။ အဘယ်ကြောင့်ဆိုသော် ယင်းဝဘ်ဆိုက်များသည် သင်အကောင့်ဝင်ချိန်နှင့် တစ်ခါတစ်ရံတွင် ဘရောင်ဇာ လက်ဗွေပြုလုပ်ခြင်းကဲ့သို့သော နည်းပညာများမှတစ်ဆင့် သင့်ကို ခွဲခြားသိရှိနိုင်သေးသောကြောင့်ဖြစ်သည်။ မိုဘိုင်းအက်ပ်များအတွက် ခေတ်မီစမတ်ဖုန်းအများစုတွင် API များရှိပြီး ၎င်းတို့သည် မြှုပ်သွင်းထားသည့် GPS ကို အားထားနိုင်သဖြင့် ထည့်သွင်းပြီး အက်ပ်များအား ပရောက်စီနှင့် ချိတ်မထားသော သင့်တည်နေရာကို ပြန်ယူခွင့်ပြုသည်။

VPN များသည် ယေဘုယျအားဖြင့် အင်တာနက်စောင့်ကြည့်ခံရမှုအပါအဝင် အရေးကြီးအကာအကွယ်များကို ပံ့ပိုးပေးသော်လည်း အွန်လိုင်း၌လုပ်ဆောင်ရာတွင် အန္တရာယ်အမြဲရှိသည်။ VPN သုံးလျှင်ပင် အိုင်အက်စ်ပီ (ISP) သည် သင်၏ အထောက်အထားကို သိထားပြီး ကွန်ရက်ဒေတာစီးဆင်းမှုကို စောင့်ကြည့်နိုင်ပါက ၎င်းသည် သင့် Outline ဆာဗာ၏ IP လိပ်စာကို ဖော်ထုတ်နိုင်သည်။ ဤအချက်အလက်ကို Outline ဆာဗာသုံးခွင့် ပိတ်ထားရန် (သို့) သင်အွန်လိုင်းချိတ်လေ့ရှိချိန်နှင့် သင့်တည်နေရာအကြမ်းဖျင်းကဲ့သို့သော အသုံးပြုမှုပုံစံများကို လေ့လာရန်အတွက် သုံးနိုင်သည်။

## ကျွန်ုပ် Outline သုံးနေကြောင်း အခြားသူတစ်ဦး သိနိုင်ပါသလား။

သိကောင်းသိနိုင်သည်။ သင်သုံးသော ပလက်ဖောင်းနှင့် ဝန်ဆောင်မှုများသည် Cloud ဆာဗာမှ သင်ချိတ်ဆက်ထားကြောင်း ဖော်ထုတ်နိုင်ခြေရှိသည်။ ရံဖန်ရံခါတွင် ၎င်းတို့သည် သင် VPN သုံးနေသည်ဟု ကောက်ချက်ချနိုင်သော်လည်း သင့်အင်တာနက် ဒေတာစီးဆင်းမှု အကြောင်းအရာများကို မြင်နိုင်မည် မဟုတ်ပါ။

## Outline သည် ဖြစ်နိုင်ခြေရှိသော ဆိုက်ဘာခြိမ်းခြောက်မှုအားလုံးရန်မှ ကျွန်ုပ်ကို ကာကွယ်ပေးပါသလား။

ကာကွယ်မပေးပါ။ မည်သည့်တူးလ်ကမျှ ဖြစ်နိုင်ခြေရှိသော ဆိုက်ဘာခြိမ်းခြောက်မှုအားလုံးရန်မှ သင့်ကို ကာကွယ်ပေးမည် မဟုတ်ပါ။ Outline သည် လွတ်လပ်သော အင်တာနက်သုံးခွင့်ပေးပြီး ဒေတာစီးဆင်းမှုကို အသွင်ဝှက်ခြင်းဖြင့် သင်၏ ကိုယ်ရေးအချက်အလက်လုံခြုံမှုကို တိုးမြှင့်ပေးသည်။ သို့သော် မဲလ်ဝဲနှင့် အယောင်ဆောင် ဖြားယောင်းခြင်းကဲ့သို့ အခြားတိုက်ခိုက်မှုပုံစံများရန်မှ မိမိကိုယ်ကို ကာကွယ်ရန်အတွက် ထပ်ဆောင်းကြိုတင်ကာကွယ်မှုများ ပြုလုပ်ရန် အကြံပြုပါသည်။

သင်၏ အွန်လိုင်းအကာအကွယ်များ အားကောင်းစေရန်အတွက် သင့်အဖွဲ့အစည်း၏ ဆိုက်ဘာလုံခြုံရေး ကျွမ်းကျင်သူနှင့် ပူးတွဲလုပ်ဆောင်ကြည့်ပါ။ သို့မဟုတ်ပါက အထင်ကရဖြစ်သော လုံခြုံရေးကျွမ်းကျင်သူများထံမှ ပုဂ္ဂိုလ်ရေးသီးသန့် လမ်းညွှန်ချက်ကို သင့်လုပ်ငန်းများအတွက် သင့်တော်သော ဆိုက်ဘာလုံခြုံရေးတူးလ်များ ရွေးချယ်ခြင်းနှင့်ပတ်သက်၍ ရှင်းလင်းသော ညွှန်ကြားချက်များ ပေးနိုင်ရန် ရေးဆွဲထားသည့် ဝဘ်ဆိုက်တစ်ခုဖြစ်သော [Security Planner](https://securityplanner.org/) တွင် ရယူနိုင်သည်။

[Jigsaw](https://jigsaw.google.com/) ၏ အခြားသော ဆိုက်ဘာလုံခြုံရေးထုတ်ကုန်များဖြစ်သော [Intra](https://getintra.org/)၊ [Project Shield](https://g.co/shield) နှင့် [စကားဝှက်သတိပေးချက်](https://chrome.google.com/webstore/detail/password-alert/noondiphcddnnabmjcihcjfbhfklnnep?) တို့ကိုလည်း လေ့လာနိုင်သည်။

## VPN သုံးခြင်းက တရားဝင်ပါသလား။

Outline ကို မစတင်မီ (သို့) အက်ပ်အသုံးမပြုမီ သုံးရန်ရည်ရွယ်ထားသော Cloud ဝန်ဆောင်မှုပေးသူအတွက် သင်၏ ဒေသတွင်း ဥပဒေ၊ စည်းမျဉ်းစည်းကမ်းနှင့် ‘ဝန်ဆောင်မှုစည်းမျဉ်းများ’ ကို ကြည့်ပါ။
