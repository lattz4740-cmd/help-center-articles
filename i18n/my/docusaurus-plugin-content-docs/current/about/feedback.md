Outline ပိုကောင်းလာစေရန် ကူညီပေးသည့်အတွက် ကျေးဇူးတင်ပါသည်။ တုံ့ပြန်မှုလိုအပ်ပါက အမည်မဖော်ဘဲဖြစ်စေ၊ သင့်အီးမေးလ်ဖြင့်ဖြစ်စေ ကျွန်ုပ်တို့ထံ အကြံပြုချက်ပို့ရန် နည်းလမ်းအချို့ ရှိပါသည်-

- **ဆော့ဖ်ဝဲရေးသူများအတွက်**- Outline သည် အခမဲ့ရင်းမြစ် ဆော့ဖ်ဝဲဖြစ်ပြီး ကျွန်ုပ်တို့၏ ကုဒ်အားလုံးကို [GitHub](https://github.com/OutlineFoundation/?q=outline) တွင် လက်ခံလုပ်ဆောင်ပါသည်။ သင့်စိတ်ကူးများကို GitHub (သို့) ကျွန်ုပ်တို့၏ [Reddit](https://www.reddit.com/r/outlinevpn/) ကွန်မြူနတီတွင် မျှဝေနိုင်ပါသည်။
- **အသုံးပြုသူများအတွက်**- Outline (သို့) Outline Manager အက်ပ်များမှတစ်ဆင့် ကျွန်ုပ်တို့ထံ အကြံပြုချက် ပို့နိုင်ပါသည်။ သင့်အကြံပြုချက်အကြောင်းကို ပြောပြပြီး ဆန္ဒရှိပါက အီးမေးလ်ချန်ထားလျှင် ၎င်းနှင့်ပတ်သက်ပြီး ကျွန်ုပ်တို့က သင့်ထံ စာပြန်ရေးနိုင်ပါသည်။ ကျွန်ုပ်တို့က သင်၏ ဘရောင်ဇာ၊ လည်ပတ်သည့်စနစ်နှင့် သင်သုံးနေသော ဆော့ဖ်ဝဲဗားရှင်းကဲ့သို့ သင့်နောက်ခံအကြောင်း မက်တာဒေတာအချို့ကိုလည်း စုဆောင်းပါသည်။ ထို့ကြောင့် ပြဿနာရှာဖွေဖြေရှင်းခြင်းအတွက် သင့်ကို ကူညီနိုင်ပါသည်။
- **ဤဝဘ်ဆိုက်မှတစ်ဆင့်**- ဤဝဘ်ဆိုက်အတွင်း နေရာတိုင်းတွင် တွေ့နိုင်သော ‘ကျွန်ုပ်တို့ထံ ဆက်သွယ်ရန်’ လင့်ခ်ကို နှိပ်နိုင်ပါသည်။
- **အရေးကြီးသော ပြဿနာများ**- အရေးကြီးသော လုံခြုံရေးပြဿနာအကြောင်း သတင်းပို့လိုပါက အသေးစိတ်အချက်များပါသော အီးမေးလ်ကို security [at] [getoutline.org](https://getoutline.org/) သို့ ပို့စေလိုပါသည်။

သင့်စိတ်ကူးများကို မျှဝေရန် အချိန်ပေးသည့်အတွက် ထပ်မံကျေးဇူးတင်ပါသည်။
