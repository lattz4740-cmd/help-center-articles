Outline သည် ကိုယ်ရေးကိုယ်တာ အချက်အလက်များကို ပေးရန် သင်က မရွေးချယ်မချင်း မစုဆောင်းပါ။ Outline သည် သင်ဝင်ကြည့်သော ဝဘ်ဆိုက်များ (သို့) သင်ဆက်သွယ်သူ (သို့) သင်ဆက်သွယ်သည့်အရာတို့နှင့် ပတ်သက်သော အချက်အလက်များကိုလည်း မစုဆောင်းပါ။

 ‘Outline မန်နေဂျာ’ မှတစ်ဆင့် ပြင်ပကုမ္ပဏီ cloud ဝန်ဆောင်မှုပေးသူ ပါဝင်သော အကောင့်သို့ ဝင်ရောက်နေပါက (သို့) အကောင့်ပြုလုပ်နေပါက ထိုပြင်ပကုမ္ပဏီ cloud ဝန်ဆောင်မှုပေးသူထံ ပေးအပ်ထားသည့် သင်၏အီးမေးလ်လိပ်စာ၊ အမည်၊ ငွေတောင်းခံမှု အချက်အလက်များနှင့် ငွေပေးချေမှု အချက်အလက်များကဲ့သို့ အချက်အလက်မှန်သမျှကို ကျွန်ုပ်တို့ ရယူမည်မဟုတ်ပါ။

****ကျွန်ုပ်တို့ အလိုအလျောက် ရရှိသော အချက်အလက်များ****

 အချက်အလက် အမျိုးအစားနှစ်ခုကို ကျွန်ုပ်တို့ အလိုအလျောက် စုဆောင်းပါသည်။

 ၁။ ဆာဗာ IP

 Outline ဆာဗာ IP ကို [Quay.io](http://quay.io/) က စုဆောင်းပြီး ဆာဗာသည် နောက်ဆုံးထွက် လုံခြုံရေးနှင့် တူးလ်မွမ်းမံမှုများဖြင့် အလိုအလျောက် အပ်ဒိတ်လုပ်သောအခါ ကျွန်ုပ်တို့က သုံးနိုင်သည်။ ‘ဆာဗာ IP’ သည် cloud ဆာဗာဝန်ဆောင်မှုပေးသူနှင့် Outline ဆာဗာ စနစ်ထည့်သွင်းထားသော မြို့ကို ဖော်ထုတ်နိုင်သည်။ သို့သော် ၎င်းသည် ဆာဗာကို သုံးနေသူ (သို့) ၎င်းသို့ ဝင်ထားသူအကြောင်း အချက်အလက်များကို မပေးပါ။

 ၂။ ပုဂ္ဂိုလ်ရေးအရ ခွဲခြားမသိရှိနိုင်သော နည်းပညာပိုင်းဆိုင်ရာ အချက်အလက်များ

 Outline ရပ်တန့်သွားခြင်းဖြစ်စေ၊ ဆိုးဝါးသော ခြွင်းချက်ပြဿနာဖြစ်စေ ကြုံတွေ့ပါက (သို့) Outline အက်ပ်မှတစ်ဆင့် အကြံပြုချက်ကို လူကိုယ်တိုင် ပို့ပါက အောက်တွင်ဖော်ပြထားသော အချက်အလက်များကို သတင်းပို့ပါမည်။ တည်ငြိမ်မှု (သို့) စွမ်းဆောင်ရည် ပြဿနာများကို ဖော်ထုတ်ပြီး ပြင်ဆင်ရာတွင် ကူညီရန်အတွက်သာ ဤအချက်အလက်များကို သုံးပါမည်။

- နိုင်ငံ
- ဘာသာစကား
- ရပ်တန့်သွားခြင်း / ခြွင်းချက်ပြဿနာ၏ ရက်စွဲနှင့် အချိန်၊ အသုံးပြုသူသည် ‘အကြောင်း’ ကဏ္ဍကို ဖွင့်ခြင်းကဲ့သို့ ယခင်က အစီအစဉ် အခု ၁၀၀ အထိ
- ပုံသေ စုဆောင်းထားသော ခြွင်းချက်ပြဿနာ မက်ဆေ့ဂျ်များ
- အိုအက်စ် (OS) အမည်နှင့် ဗားရှင်း
- ဖုန်းအမျိုးအစား (သုံးမည်ဆိုပါက)
- အက်ပ်စတင်ချိန်
- ဘရောင်ဇာ
- တည်ဆောက်ပုံ
- Outline ဗားရှင်းနှင့် တည်ဆောက်ပုံအမှတ်

ဤအချက်အလက်များကို အခမဲ့ရင်းမြစ်ဆိုင်ရာ အမှားခြေရာခံခြင်း ဝန်ဆောင်မှုပေးသည့် ပြင်ပကုမ္ပဏီအက်ပ်ဖြစ်သော Sentry ([sentry.io](http://sentry.io/)) သို့ HTTPS သုံးပြီး လွှဲပြောင်းသည်။ Sentry သည် သင့်ဒေတာများကို ခွင့်ပြုမထားသော ဝင်ခွင့်၊ ထုတ်ဖော်မှု၊ အသုံးပြုမှုနှင့် ဆုံးရှုံးမှုရန်များမှ ကာကွယ်ပေးရန် လုပ်ငန်းသုံး နည်းပညာနှင့် ဝန်ဆောင်မှုများကို အသုံးပြုသည်။ Sentry ၏ မူဝါဒများနှင့် ပတ်သက်၍ မေးစရာရှိပါက [https://sentry.io/security/](https://sentry.io/security/) နှင့် [https://sentry.io/privacy/](https://sentry.io/privacy/) ကို ဝင်ကြည့်ပါ (သို့) [security@sentry.io](mailto:security@sentry.io) ကို ဆက်သွယ်ပါ။ Sentry သိမ်းဆည်းထားသော Outline ဒေတာအားလုံးကို ကန့်သတ်ထားသဖြင့် Outline အဖွဲ့ဝင်များသာ သုံးနိုင်သည်။

****ပေးရန် ရွေးချယ်မှသာ ကျွန်ုပ်တို့ရရှိသော အချက်အလက်များ****

 အောက်ပါအချက်အလက်များကို ပေးရန် ရွေးချယ်လျှင် Outline သည် ၎င်းတို့ကို Outline အဖွဲ့သို့ သတင်းပို့သည်။

 ၁။ အသုံးပြုမှု မက်ထရစ်များ

 Outline ဆာဗာတစ်ခုစီသည် ပြီးခဲ့သော တစ်နာရီအတွင်းနှင့် ဝင်ခွင့်ကီးအလိုက် အခြေခံပြီး လွှဲပြောင်းထားသော ဘိုက်အရေအတွက်၊ အသုံးပြုသူကို ဆာဗာနှင့် ချိတ်ဆက်ထားသည့် အချိန်ပမာဏ၊ အထောက်အထားများ သုံးထားသော မူလဇစ်မြစ်နိုင်ငံများ၊ ကိုယ်တိုင်စီမံသော စနစ်များနှင့် ဖွင့်ထားသည့် (သို့) ပိတ်ထားသည့် ဝန်ဆောင်မှုများရှိ၊ မရှိတို့ကို အလိုအလျောက် စုဆောင်းသည်။ ဆက်သွယ်မှု၏ အကြောင်းအရာ (သို့) ပုဂ္ဂိုလ်ရေးအရ ခွဲခြားသိရှိနိုင်သော မက်တာဒေတာ (ဥပမာ- အကောင့်ဝင်ခြင်း၊ အီးမေးလ်၊ စက် ID အစရှိသော) မည်သည်ကိုမျှ မှတ်တမ်းတင်မထားပါ။ မက်ထရစ်အားလုံးကို ဆာဗာ ID တွင် ပူးတွဲထားသည်။ ဆာဗာ ID ပြောင်းခြင်းအတွက် ညွှန်ကြားချက်များကို [ဤနေရာ](/manager/server-management/reset-server-id) တွင် တွေ့နိုင်သည်။

 မူရင်းသတ်မှတ်ချက်အရ ‘Outline ဆာဗာများ’ သည် ဤမက်ထရစ်များကို Outline အဖွဲ့နှင့် မမျှဝေပါ။ ‘ဆာဗာစီမံခန့်ခွဲသူ’ သည် အသုံးပြုမှုမက်ထရစ်များကို မျှဝေရန် ရွေးချယ်ပါက ဤအချက်အလက်ကို Outline အဖွဲ့သို့ နာရီနှင့်အမျှ လုံခြုံစွာ ပို့ပါမည်။ အသုံးပြုမှုမက်ထရစ်များကို ရက်ပေါင်း ၆၀ ကြာပြီးနောက် နိုင်ငံအဆင့်တွင် ပေါင်းစည်းပါမည်။ ဆာဗာစီမံခန့်ခွဲသူများသည် အသုံးပြုမှုမက်ထရစ် မျှဝေခြင်း သတ်မှတ်ချက်ကို ‘Outline မန်နေဂျာ’ ရှိ ‘ဆက်တင်များ’ မီနူးကို ဝင်ကြည့်ခြင်းဖြင့် အချိန်မရွေး ပြောင်းနိုင်သည်။

 သင်၏ ဆာဗာအသုံးပြုမှုအကြောင်း အမည်မသိ မက်ထရစ်များကို ကျွန်ုပ်တို့နှင့် မျှဝေရန် လိုလားပြီး အသုံးပြုမှုအလားအလာများကို တိုင်းတာရန်နှင့် ကုန်ပစ္စည်း ပိုကောင်းလာစေရန် ယင်းမက်ထရစ်များကို သုံးပါသည်။

 ‘ဆာဗာစီမံခန့်ခွဲသူ’ သည် အသုံးပြုမှုမက်ထရစ်များကို ကျွန်ုပ်တို့နှင့် မျှဝေရန် ရွေးချယ်ပါက အချက်အလက်များကို ကျွန်ုပ်တို့ ရရှိနိုင်ပါသည်။ ဥပမာ- ယင်းအချက်အလက်များတွင် ID ၁၂၃၄၅ ပါ ‘ဆာဗာ’ ကို မနေ့က ၃ နာရီကြာ သုံးထားသည်၊ ဒေတာကန့်သတ်ချက်များတူးလ် ဖွင့်ထားသော ကီးသုံးခုမှ ဒေတာစုစုပေါင်း ၅၀၀ မီဂါဘိုက် လွှဲပြောင်းထားပြီး ယင်းကီးတစ်ခုစီကို အမေရိကန်ပြည်ထောင်စုနှင့် ကနေဒါတွင် သုံးထားသည်ဟု ဖော်ပြထားသည်။

 ၂။ အကြံပြုချက် ပို့ပါက သင့်မှတ်ချက်နှင့် အီးမေးလ်

 ‘Outline မန်နေဂျာ’ နှင့် ‘Outline အက်ပ်များ’ သည် သင့်အား အဖွဲ့ထံ အကြံပြုချက် ပို့ခွင့်ပြုသည်။ ပုဂ္ဂိုလ်ရေးအရ ခွဲခြားသိရှိနိုင်သော အချက်အလက်များ မထည့်ရန် အကြံပြုသော်လည်း အဖွဲ့မှ တုံ့ပြန်မှုရလိုပါက အီးမေးလ်အကွက်ကို ဖြည့်နိုင်သည်။ သင့်အကြံပြုချက်ကို နားလည်နိုင်ရန် အချို့သော အခြေခံအချက်အလက်များကိုလည်း ကျွန်ုပ်တို့ အလိုအလျောက် စုဆောင်းပါသည်။ ကျွန်ုပ်တို့ စုဆောင်းသော ဒေတာများကို အထပ်ပါ အကြောင်းအရာ ၂ ၏ “ကျွန်ုပ်တို့ အလိုအလျောက်ရရှိသော အချက်အလက်များ” အောက်တွင်ကြည့်ပါ။ Outline ၏ လုံခြုံရေးနှင့် ကိုယ်ရေးအချက်အလက် လုံခြုံမှုဆိုင်ရာ ဆောင်ရွက်ချက်များကို [ဤနေရာ](/about/security-and-privacy) တွင် ပိုမိုလေ့လာနိုင်သည်။

 သင်သည် Android တွင် Outline အက်ပ်၏ စမ်းသပ်ဗားရှင်း သုံးနေပါက ကျွန်ုပ်တို့သည် Google ၏ [Firebase](https://firebase.google.com/) ဝန်ဆောင်မှုဖြင့် ပြဿနာများကို ဖော်ထုတ်ပြီး Outline ပိုကောင်းစေရန် ကူညီနိုင်သည့် အမှားရှာပြင်သော အချက်အလက်များ စုဆောင်းနိုင်သည်။ Firebase ၏ ကိုယ်ရေးအချက်အလက် လုံခြုံမှုနှင့် လုံခြုံရေးဆိုင်ရာ မူဝါဒများကို ၎င်းတို့၏ဝဘ်ဆိုက်တွင် ပိုမိုလေ့လာနိုင်သည်- [firebase.google.com/support/privacy](https://firebase.google.com/support/privacy)။ Outline အား Firebase မှတစ်ဆင့် ဤအချက်အလက်များကို မပို့စေလိုပါက အက်ပ်၏ ထုတ်လုပ်မှုဗားရှင်းကို သုံးပါ။
