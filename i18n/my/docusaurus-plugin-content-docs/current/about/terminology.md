**VPN ဆိုတာ ဘာလဲ။**

 ပကတိအသွင် ကိုယ်ပိုင်ကွန်ရက် (VPN) ဆိုသည်မှာ သင့်စက်(များ) နှင့် လက်ခံလုပ်ဆောင်သည့် ဆာဗာအကြားရှိ သီးသန့်ချိတ်ဆက်မှုဖြစ်သည်။ သင်သည် VPN သုံးသည့်အခါတွင် သင့်ဒေတာစီးဆင်းမှုကို သင့်အင်တာနက် ဝန်ဆောင်မှုပေးသူမသိအောင် ဖျောက်ထားပေးသည်။ သင်သည် အောက်ပါဖြစ်စဥ်များတွင် VPN သုံးလိုပါမည်-

- အများသုံး Wi-Fi ကွန်ရက်သုံးစဥ် သင့်ဒေတာကိုကာကွယ်ရန်
- သင်ဖွင့်ကြည့်ထားသည့်မှတ်တမ်းဒေတာကို သင့်အင်တာနက် ဝန်ဆောင်မှုပေးသူနှင့် အစိုးရအေဂျင်စီများ မသိအောင် သီးသန့်ထားရန်
- ကမ္ဘာအနှံ့ ရင်းမြစ်များမှ ဆင်ဆာဖြတ်မထားသည့် အကြောင်းအရာ ရယူရန်

**Outline နှင့် သမားရိုးကျ VPN များ ဘယ်လိုကွာခြားသလဲ။**

 အင်တာနက် ဝန်ဆောင်မှုပေးသူများသည် ပုံမှန်လုံခြုံရေး ပရိုတိုကောများနှင့်/သို့မဟုတ် ဒေတာစီးဆင်းမှုပမာဏ ပုံစံများအား မှတ်မိပြီး သမားရိုးကျ VPN များကို အလွယ်တကူ သိရှိကာ ပိတ်ထားနိုင်သည်။ ရှာဖွေရန်ခက်ခဲအောင် ဒီဇိုင်းရေးဆွဲထားသည့်အတွက် ပိတ်ထားရန် ပိုခက်ခဲသော ပရိုတိုကောသုံးပြီး Outline ကို တည်ဆောက်ထားသောကြောင့် ၎င်းသည် သမားရိုးကျ VPN များထက် ပိုဒဏ်ခံနိုင်သည်။ Outline သည် ကွန်ရက်အခြေပြု ပိတ်ထားခြင်းနှင့် IP ပိတ်ထားခြင်းတို့ အပါအဝင် ဆန်းပြားရှုပ်ထွေးသော ဆင်ဆာဖြတ်ခြင်းပုံစံများကို ခံနိုင်ရည်ရှိသည်။

**Outline ဆာဗာဆိုတာ ဘာလဲ။**

 Outline ဆာဗာသည် အသုံးပြုများအား ချိတ်ဆက်ခွင့်ပြုထားသော VPN ကို ဝန်ဆောင်မှုပေးသည်။ သင့်တွင် Outline ဆာဗာရှိပါက ကွန်ရက်သစ်ပြုလုပ်သောအခါ ကိုယ်ပိုင် လုံခြုံသောဆာဗာကို သုံးနိုင်သည် (သို့) အောက်ပါကဲ့သို့ cloud ဝန်ဆောင်မှုပေးသူကို သုံးနိုင်သည်-

- DigitalOcean
- Google Cloud Platform (GCP)
- Amazon ဝဘ်ဝန်ဆောင်မှုများ (AWS)

သင့်ဆာဗာကို Outline မန်နေဂျာတွင် စနစ်ထည့်သွင်းရမည်။

## ဝန်ဆောင်မှုမန်နေဂျာဆိုတာ ဘာလဲ။ {#servicemanager}
 ဝန်ဆောင်မှုမန်နေဂျာဟူသည်မှာ Outline ဆာဗာ စနစ်ထည့်သွင်းခြင်းနှင့် အသုံးပြုသူများအား ဝင်ခွင့်ကီးများ မျှဝေခြင်းတို့အတွက် တာဝန်ရှိသူဖြစ်သည်။ ဝန်ဆောင်မှုမန်နေဂျာသည် ယေဘုယျအားဖြင့် ဆာဗာအသုံးပြုမှု ကုန်ကျစရိတ်အတွက် တာဝန်ရှိသည်။
