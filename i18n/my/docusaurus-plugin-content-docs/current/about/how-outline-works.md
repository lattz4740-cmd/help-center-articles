## ဆာဗာ ထည့်သွင်းခြင်း
 ​Outline ထည့်သွင်းမှုသည် ရိုးရှင်းသည်ဟု ထင်ရသော်လည်း သင့်ဆာဗာထည့်သွင်းရန် နောက်ကွယ်မှ လုပ်ဆောင်နေသည့် ခက်ခဲရှုပ်ထွေးသောအဆင့်များရှိသည်။ Outline ထည့်သွင်းသည့်အခါတိုင်း ထည့်သွင်းမှု script သည် အောက်ပါအဆင့်များကို လုပ်ဆောင်သည်-

- Shadowbox ပုံရိပ်ဖိုင် (image) ၏ တည်ငြိမ်ဗားရှင်းကို ပြန်ယူပြီး Docker ဖြင့် ထည့်သွင်းသည်။ [Quay.io](https://quay.io/) ရှိ [https://quay.io/repository/outline/shadowbox?tab=tags](https://quay.io/repository/outline/shadowbox?tab=tags) တွင် လက်ခံလုပ်ဆောင်သည်။ ဤပုံရိပ်ဖိုင်တွင် Outline ဆာဗာနှင့် Management API ပါဝင်ပြီး ၎င်းကို နောက်ပိုင်းတွင် ‘Outline ဆာဗာ စီမံခန့်ခွဲမှု’ အပလီကေးရှင်းက ဝင်ခွင့်ကီးများ ပြုလုပ်ရန်၊ ဖယ်ရှားရန်၊ ကိုယ်ရေးအချက်အလက် ဖျောက်ထားသော မက်ထရစ်များ သတင်းပို့ခြင်း သုံးရန်/မသုံးရန် စသည်တို့တွင် သုံးသည်။
- [Watchtower](https://github.com/v2tec/watchtower) ကို ထည့်သွင်းပြီး ပုံရိပ်ဖိုင် အပ်ဒိတ်များကို နာရီနှင့်အမျှ စစ်ဆေးရန် စီစဉ်သတ်မှတ်ထားသည်။ ဤသို့အားဖြင့် Outline ဆာဗာတိုင်းကို နောက်ဆုံးထွက် တူးလ်နှင့် လုံခြုံရေးမွမ်းမံမှုများဖြင့် အမြဲအပ်ဒိတ်ဖြစ်နေရန် ကူညီပေးသည်။
- Management API သို့ဝင်ရန် အသုံးပြုသော ဝဘ်ဆာဗာကို ကျပန်းပို့တ်နှင့် ကျပန်းဖိုင်တွဲများလမ်းကြောင်းတွင် စတင်သည်။
- [သုံးသူက ပြုလုပ်သော SSL အသိအမှတ်ပြုလက်မှတ်](https://en.wikipedia.org/wiki/Self-signed_certificate) ကို ပြုလုပ်ထားသဖြင့် ဒိုမိန်းအမည် မရှိသော်လည်း TLS သုံးပြီး Outline ဆာဗာစီမံခန့်ခွဲမှုကို အသွင်ဝှက်နိုင်သည်။ ဤအသိအမှတ်ပြုလက်မှတ်၏ သီးခြားလက်ဗွေကိုလည်း ထုတ်ပေးပြီး ‘Outline မန်နေဂျာ’ အပလီကေးရှင်းတွင် သိမ်းထားသည်။ ၎င်းက MITM တိုက်ခိုက်မှုများကို ကူညီကာကွယ်ပေးသည်။

Outline ထည့်သွင်းမှုကို လုပ်ဆောင်ပြီးနောက် မည်သည့်စီစဉ်သတ်မှတ်ချက်မျှ မလိုအပ်ပါ။

## ဆာဗာ လုံခြုံရေး
 Outline ဆော့ဖ်ဝဲသည် အခမဲ့ရင်းမြစ်ဖြစ်သည်။ ဆိုလိုသည်မှာ လူတိုင်းက ကုဒ်ကို မြင်နိုင်သည်။ အားနည်းချက်များ တွေ့ထားပါက ပိုကောင်းအောင် ပြုလုပ်နိုင်သည်။ ကျွန်ုပ်တို့၏ ကုဒ်ကို [GitHub](https://github.com/search?q=org%3AJigsaw-Code+outline&unscoped_q=outline) တွင် လက်ခံလုပ်ဆောင်သည်။

 ထို့အပြင် ထည့်သွင်းထားသော Outline ဆာဗာအားလုံးကို ဗားရှင်းအသစ် ဖြန့်ချိတိုင်း အလိုအလျောက် အပ်ဒိတ်လုပ်သည်။ မည်သည့် Outline ဆာဗာကိုမျှ ဆော့ဖ်ဝဲဗားရှင်းအဟောင်းများကို ဆက်မသုံးစေပါ။

 ဆာဗာရှိ ဝင်ခွင့်ကီးများကို စီမံရန်အတွက် ‘Outline မန်နေဂျာ’ အပလီကေးရှင်းသည် Outline ဆာဗာတွင် ‘စီမံခန့်ခွဲသော ဝန်ဆောင်မှု’ နှင့် ပြန်လှန်တုံ့ပြန်သည်။ ‘စီမံခန့်ခွဲသော ဝန်ဆောင်မှု’ သည် ကျပန်းပို့တ်နှင့် သီးခြားဖိုင်တွဲများလမ်းကြောင်းတွင် လုပ်ဆောင်သည်။ ‘စီမံခန့်ခွဲသော ဝန်ဆောင်မှု’ သည် သင့်တော်သော လျှို့ဝှက်ဖိုင်တွဲများလမ်းကြောင်းကို မဖော်ပြဘဲ မေးမြန်းချက်များကို အကြောင်းမပြန်သဖြင့် စုံစမ်းရခက်ခဲသည်။ ‘စီမံခန့်ခွဲသော ဝန်ဆောင်မှု’ ထံ ဆက်သွယ်မှုအားလုံးကို [သုံးသူက ပြုလုပ်သော SSL အသိအမှတ်ပြုလက်မှတ်](https://en.wikipedia.org/wiki/Self-signed_certificate) ဖြင့် အသွင်ဝှက်သည်။

 Outline ဆာဗာသည် မည်သည့်မှတ်တမ်းကိုမျှ မသိမ်းသဖြင့် အငြင်းပွားဖွယ် ဖြစ်ခဲ့လျှင်ပင် အသုံးပြုသူဒေတာကို ဖော်ပြနိုင်မည်မဟုတ်ပါ။ [ဤနေရာ](/about/security-and-privacy) တွင် ပိုမိုလေ့လာနိုင်သည်။ Outline ကို [Radically Open Security](https://radicallyopensecurity.com/) နှင့် [Cure53](https://cure53.de/) တို့က ၂၀၁၈ ခုနှစ်တွင် စစ်ဆေးထားသည်။ အစီရင်ခံစာများကို [ဤနေရာ](/about/security-and-privacy) တွင် ကြည့်ပါ။

## UDP ဒေတာစီးဆင်းမှုကို စီမံခြင်း
 Outline သည် စနစ်တစ်ခုလုံးသုံးသော VPN အဖြစ် လည်ပတ်နိုင်သည်။ ဆိုလိုသည်မှာ UDP ဒေတာစီးဆင်းမှုအားလုံးကို Outline ဆာဗာမှတစ်ဆင့် ဒေတာ အသွင်ပြောင်းပို့ဆောင်သည်။

## DNS ဒေတာစီးဆင်းမှု
Outline သည် DNS ရှာဖွေမှုအားလုံးကို Outline ဆာဗာမှတစ်ဆင့် ဆောင်ရွက်ပြီး အခြားသော ကွန်ရက်လုပ်ဆောင်ချက်အားလုံးအတွက် အသုံးပြုသော အသွင်ဝှက်ခြင်းဖြင့် ယင်းရှာဖွေမှုများကို ကာကွယ်ပေးသည်။ သင်၏ DNS မေးမြန်းချက်များသည် Outline ဆာဗာမှတစ်ဆင့် Dyn Internet Guide၊ OpenDNS၊ Cloudflare DNS (သို့) Quad9 DNS သို့ သွားပါမည်။ Outline သည် သင်၏ DNS ရှာဖွေမှုများကို မည်သည့်အခါမျှ မှတ်တမ်းမတင်ပါ။
