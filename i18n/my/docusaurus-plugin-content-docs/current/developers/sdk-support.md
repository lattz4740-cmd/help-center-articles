ဤအကူအညီဝဘ်ဆိုက်သည် Outline မန်နေဂျာနှင့် ကလိုင်းယင့် အသုံးပြုသူများအတွက် ဖြစ်သည်။ ဆော့ဖ်ဝဲရေးသူအကူအညီအတွက် GitHub သုံးပါ။ မေးခွန်းမေးရန် SDK [ဆွေးနွေးမှုဘုတ်](https://github.com/Jigsaw-Code/outline-sdk/discussions) တွင် ပို့စ်တင်ပါ။ ‘ဆွေးနွေးမှု’ ဘုတ်ကဏ္ဍသည် Outline SDK သုံး၍ မေးခွန်းများမေးရန်၊ စိတ်ကူးများမျှဝေရန်၊ သရုပ်ပြများနှင့် လင့်ခ်ချိတ်ရန်၊ အခြားဆော့ဖ်ဝဲရေးသူများကို ကူညီရန် နေရာကောင်းတစ်ခု ဖြစ်သည်။ ၎င်းအစား တူးလ်တောင်းဆိုချက် (သို့) ချွတ်ယွင်းမှု တိုင်ကြားချက်တို့အတွက် [ပြဿနာ](https://github.com/Jigsaw-Code/outline-sdk/issues/new) ဖွင့်ပါ။
