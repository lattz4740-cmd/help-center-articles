## သင့်စက်ကို Outline ဆာဗာသို့ ချိတ်ဆက်ခြင်း

သင့်စက်ကို Outline ဆာဗာသို့ ချိတ်ဆက်ရန်အတွက် ဆာဗာစီမံခန့်ခွဲသူက သူ၏ဆာဗာသို့ ချိတ်ဆက်ရန် သီးခြား [အသုံးပြုခွင့်ကီး](/about/terminology) ပါသော ဖိတ်ကြားချက်ကို သင့်ထံ ပို့ရပါမည်။ ဤဖိတ်ကြားချက်သည် အောက်ပါတို့ကို ပြုလုပ်ပါမည်-

- သင့်တွင် Outline မရှိသေးပါက စက်၌ ၎င်းကို ဒေါင်းလုဒ်လုပ်ပြီး ထည့်သွင်းရန် သင့်အား တိုက်တွန်းခြင်း
- သင်နှင့် Outline ဆာဗာကြားတွင် လုံခြုံစွာချိတ်ဆက်ရန် အသုံးပြုခွင့်ကီး သုံးခြင်း

ဆာဗာသို့ သင်ချိတ်ဆက်ပြီးပါက Outline သုံးရန်အတွက် “ချိတ်ဆက်ရန်” (သို့) “ချိတ်ဆက်မှုဖြုတ်ရန်” ကို နှိပ်နိုင်သည်။

*အရေးကြီးသည်-* Outline သည် အသုံးပြုခွင့်ကီးနှင့် Outline ဆာဗာ မရှိဘဲ အလုပ်မလုပ်ပါ။ ကီးမရှိဘဲ Outline အက်ပ်ကို ဒေါင်းလုဒ်လုပ်ပြီး ထည့်သွင်းပါက သင်၏ အင်တာနက် ဒေတာစီးဆင်းမှုကို ကာကွယ်ပေးမည် မဟုတ်ပါ။
