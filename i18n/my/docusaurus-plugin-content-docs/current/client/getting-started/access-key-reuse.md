sidebar_label: အသုံးပြုခွင့်ကီးကို တစ်ကြိမ်ထက်ပို၍ သုံးနိုင်ပါသလား။
---

သုံးနိုင်ပါသည်။ သင့်စက်အရေအတွက် မည်မျှတွင်မဆို [အသုံးပြုခွင့်ကီး](/about/terminology) ကို သုံးနိုင်သော်လည်း သင့်ကီးကို အခြားသူနှင့်မျှဝေရန် ကျွန်ုပ်တို့ အကြံမပြုပါ။ သင်၏ အသုံးပြုခွင့်ကီးရှိသော တစ်စုံတစ်ဦးသည် ၎င်းကြည့်ခွင့်ရနေသည့်သင့်အင်တာနက် ဒေတာစီးဆင်းမှုအားလုံးကို စစ်ဆေးကြည့်နိုင်ဖွယ်ရာ ရှိသည်။ ၎င်းက သင်၏ အင်တာနက်အသုံးပြုမှုကို လုံခြုံစေမည် (သို့) သီးသန့်ဖြစ်စေမည် မဟုတ်တော့ပါ။
