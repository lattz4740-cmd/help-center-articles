title: چرا نمی‌توانم «مدیر Outline» را در Windows نصب کنم؟
sidebar_label: چرا نمی‌توانم «مدیر Outline» را در Windows نصب کنم؟
---

ممکن است این پیام خطا را ببینید: «متأسفیم، به‌نظر می‌رسد Outline به‌درستی نصب نشده است. لطفاً آن را دوباره نصب کنید. اگر کار نمی‌کند، لطفاً [بازخورد ارسال کنید](https://support.getoutline.org/s/contactsupport?).»

اگر از Outline در Windows استفاده می‌کنید، گاهی ممکن است با خطایی غیرمنتظره مواجه شوید. در بیشتر موارد، آداپتور Outline TAP (درایور) باید حذف شود و Outline بازنصب شود.

بسته به نسخه سیستم‌عامل Windows ممکن است مراحل متفاوت باشد، با‌این‌حال، مراحل عمومی حذف نصب آداپتور TAP و «مدیر Outline»، و سپس بازنصب «مدیر Outline» درزیر ارائه شده است.

1. حذف نصب آداپتور TAP برای «مدیر Outline»
   1. به **مدیران دستگاه**، سپس به **Network Adapters** بروید
   2. فایل «**TAP-Windows Adapter V9** یا آداپتور TAP وابسته‌به Outline را پیدا کنید
   3. این آداپتور را حذف نصب یا حذف کنید. به‌خاطر داشته باشید که این کار می‌تواند روی دیگر برنامه‌های VPN که نصب کرده‌اید تأثیر بگذارد.
2. حذف نصب «مدیر Outline»
   1. به **برنامه‌ها و ویژگی‌ها**، سپس به **حذف نصب برنامه** بروید
   2. برنامه «مدیر Outline» را پیدا کنید و «مدیر Outline» را حذف نصب کنید
   3. [آخرین نسخه مدیر Outline‏را بارگیری کنید](https://getoutline.org/get-started/#step-3) و آن را دردستگاه Windows خودتان بازنصب کنید. نصب جدید باید آداپتور TAP جدیدی برای شما نصب کند.

اگر هنوز با مشکل مواجه هستید، [با پشتیبانی تماس بگیرید](https://support.getoutline.org/s/contactsupport?)
