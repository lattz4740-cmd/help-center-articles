---
title: چطور نرم‌افزار سرور Outline خودم را به‌روز کنم؟
sidebar_label: چطور نرم‌افزار سرور Outline خودم را به‌روز کنم؟
---

سرورهای Outline به‌طور خودکار با جدیدترین موارد بهبودیافته امنیتی به‌روزرسانی می‌شوند تا همواره از جدیدترین فناوری Outline استفاده کنید. فرایند به‌روزرسانی خودکار توسط [Watchtower](https://github.com/v2tec/watchtower) فعال شده است، کتابخانه متن‌بازی که به‌طور مرتب تصویر «داکر» را که شامل نرم‌افزار Outline است بررسی و به‌روز‌رسانی می‌کند.

علاوه‌براین، وقتی Outline را بااستفاده از «مدیر Outline» نصب می‌کنید، یک کرون‌جاب راه‌اندازی می‌کنیم تا نرم‌افزاری را در سرور به‌طور خودکار به‌روزرسانی کند که برای به‌روزرسانی آن، هرجا لازم باشد، از [به‌روزرسانی ‌های بی‌متصدی](https://wiki.debian.org/UnattendedUpgrades) (Ubuntu) و راه‌اندازی مجدد استفاده می‌کند. توجه داشته باشید که این امر در «حالت پیشرفته» اتفاق نمی‌افتد تا پیکربندی فعلی تحت این فرض حفظ شود که این میزبان برای مقاصد دیگری افزون‌بر اجرای Outline استفاده می‌شود.
