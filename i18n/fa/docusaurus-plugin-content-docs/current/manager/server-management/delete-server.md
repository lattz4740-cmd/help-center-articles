---
title: چطور سرور Outline خودم را حذف کنم؟
sidebar_label: چطور سرور Outline خودم را حذف کنم؟
---

دربیشتر ارائه‌دهندگان ابری، حذف ماشین مجازی خاصی که استفاده می‌کنید به‌نسبت آسان است.

اگر از DigitalOcean به‌عنوان ارائه‌دهنده ابری استفاده می‌کنید، می‌توانید باکلیک کردن روی دکمه چرخ‌دنده و انتخاب **تخریب سرور** ماشین مجازی موجودتان را حذف کنید. بلافاصله پس‌از این کار، از شما خواسته می‌شود تا ماشین مجازی جدیدی را در مکانی که خودتان انتخاب می‌کنید ایجاد کنید.

اگر یک سرور Outline را بردارید، برای همیشه حذف می‌شود و کلیدهای دسترسی آن دیگر کار نخواهد کرد. اگر نمی‌خواهید دردسترسی افراد ازطریق Outline وقفه ایجاد شود، باید [سرور Outline جدیدی راه‌اندازی کنید](/manager/server-setup/setup-server) و پیش‌از حذف نسخه قبلی، دسترسی به آن را هم‌رسانی کنید.
