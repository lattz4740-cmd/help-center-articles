---
title: چگونه «شناسه سرور» خود را بازنشانی کنم؟
sidebar_label: چگونه «شناسه سرور» خود را بازنشانی کنم؟
---

شناسه سرور یک شناسه سمت سرور است که هنگام ایجاد سرور Outline به‌طور تصادفی ایجاد شده است. می‌توانید این شناسه را هنگام انتخاب هم‌رسانی سنجه‌های ناشناس در میانای «تنظیمات»، پیدا کنید. شناسه سرور را می‌توانید اینجا پیدا کنید: تنظیمات => پیمایش به‌پایین => بررسی کردن «هم‌رسانی سنجه‌های ناشناس».

شناسه سرور با آمار کاربرد ناشناس که درطول زمان گزارش شده‌اند مرتبط است. اگر بخواهید شناسه سرور را بازنشانی کنید و شناسه جدیدی دریافت کنید، باید سرور Outline فعلی‌تان را با سرور جدیدی جایگزین کنید.

اگر از DigitalOcean به‌عنوان ارائه‌دهنده ابری استفاده می‌کنید، می‌توانید با رفتن به **تنظیمات** و انتخاب **تخریب سرور** سرورتان را بازنشانی کنید. این کنش برگشت‌پذیر نیست و بااین کار همه اطلاعات اعتباری‌تان پاک خواهد شد. بلافاصله پس‌از این کار، از شما خواسته می‌شود تا سرور جدیدی را در مکانی که خودتان انتخاب می‌کنید ایجاد کنید و شناسه سرور جدیدی ایجاد خواهد شد.
