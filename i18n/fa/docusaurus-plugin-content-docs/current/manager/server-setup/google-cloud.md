## نمای کلی

«مدیر Outline» ویژگی‌ای دارد که به شما امکان می‌دهد «سرور Outline» را به‌طور خودکار در سروری که در Google Cloud اجرا می‌شود پیکربندی کنید. اگر انتخاب کنید که از این ویژگی استفاده کنید، «مدیر Outline» از شما می‌خواهد با «حساب Google» خودتان به سیستم وارد شوید، که به‌منظور پیکربندی «حساب Google» Cloud» شما اجازه‌های خاصی را از [OAuth](https://developers.google.com/identity/protocols/oauth2) به نصب محلی «مدیر Outline» شما می‌دهد.

اگر نمی‌خواهید این اجازه‌ها را ارائه دهید، می توانید از دستورالعمل‌های راه‌اندازی پیشرفته در «مدیر Outline» پیروی کنید تا Outline را در Google Cloud Platform اجرا کنید.

## اجازه‌ها ارائه شد

به‌منظور ارائه راه‌اندازی خودکار، «مدیر Outline» به اجازه‌های زیر از «حساب Google» شما نیاز دارد.

Google Cloud Platform

- مشاهده و مدیریت منابع موتور محاسبه Google
- مشاهده داده‌های شما در سرویس‌های Google Cloud و دیدن نشانی ایمیل «حساب Google» شما

## اطلاعات اصلی حساب

- دیدن نشانی ایمیل اصلی «حساب Google»
- مرتبط کردن شما با اطلاعات شخصی‌تان در Google

## دسترسی اضافی

- مدیریت پروژه‌های Cloud Platform
- مشاهده و مدیریت حساب صورت‌حساب Google Cloud Platform شما
- مدیریت پیکربندی سرویس Google API

## این اجازه‌ها به ما امکان می‌دهد از عملکردهای پیشرفته برای مدیریت سرورهای Outline شما پشتیبانی کنیم، مثلاً:

- اجازه دادن به شما برای انتخاب حساب صورت‌حساب صحیح
- ایجاد پروژه جدید برای سازمان‌دهی سرورهای Outline
- فهرست کردن مرکز داده‌های دردسترس
- ایجاد ماشین‌های مجازی جدید برای اجرای Outline
- پیکربندی ماشین‌های مجازی جدید با Outline

## لغو اجازه‌ها

با مراجعه به [حساب من می‌توانید دسترسی به Google Cloud Platform را برای «مدیر Outline» لغو کنید](https://myaccount.google.com/permissions). اگر دسترسی را لغو کنید، سرورهایی که با راه‌اندازی خودکار ایجاد کرده‌اید همچنان اجرا می‌شوند اما دیگر در «مدیر Outline» نشان داده نمی‌شوند. برای بازیابی دسترسی به آن‌ها، کافی است با شروع جریان خودکار راه‌اندازی مجدداً به Google Cloud Platform متصل شوید.

## سازمان پروژه Outline

راه‌اندازی خودکار Google Cloud از یک [پروژه Google Cloud](https://cloud.google.com/resource-manager/docs/creating-managing-projects) برای سازماندهی سرورهای Outline شما استفاده می‌کند. پروژه درحین اولین استفاده از تنظیمات خودکار، با شناسه پروژه پیشنهادی که با «Outline-» شروع می‌شود و رشته‌ای از نویسه‌های تصادفی در ادامه دارد ایجاد می‌شود. درصورت تمایل می‌توانید شناسه پروژه دیگری را در هنگام ایجاد انتخاب کنید. نام پروژه «سرورهای Outline» خواهد بود.

## حساب صورت‌حساب

پروژه‌های Google Cloud به «حساب صورت‌حساب» پیوندشده‌ای که اطلاعات پرداخت را مشخص می‌کند نیاز دارد. وقتی برای اولین‌بار از تنظیمات خودکار Google Cloud استفاده می‌کنید، از شما خواسته می‌شود که حساب صورت‌حسابی را برای ارتباط با سرورهای Outline خودتان ارائه دهید. گاهی سرور متوقف می‌شود زیرا مشکلی در حساب صورت‌حساب وجود دارد. در این شرایط، باید به سیستم [Google Cloud Console](https://console.cloud.google.com/getting-started) وارد شوید، پروژه Google Cloud مربوط به Outline (به‌نام «سرورهای Outline») را پیدا کنید و تنظیمات صورت‌حساب را به‌روز کنید.

## ازبین بردن سرورها

اگر می‌خواهید سرورهایتان را که بااستفاده از تنظیمات خودکار ایجاد شده است ازبین ببرید، ساده‌ترین راه برای انجام این کار ازطریق «مدیر Outline» است. بااین‌حال، اگر می‌خواهید سرورها را خودتان ازبین ببرید، می‌توانید به سیستم [Google Cloud Console](https://console.cloud.google.com/getting-started) وارد شوید، پروژه‌ای را که هنگام راه‌اندازی اولیه ایجاد شده است (به‌نام «سرورهای Outline») پیدا کنید و یا منابع موجود را حذف کنید یا پروژه را تعطیل کنید
