sidebar_label: من توسعه‌دهنده هستم. از کجا می‌توانم برای ادغام کردن Outline SDK در برنامه‌ام پشتیبانی دریافت کنم؟

این وب‌سایت پشتیبانی برای کاربران «مشتری و مدیر Outline» است. توسعه‌دهندگان، لطفاً از GitHub برای پشتیبانی استفاده کنید. برای پرسیدن سؤال، لطفاً در [تابلو گفتگوی](https://github.com/Jigsaw-Code/outline-sdk/discussions) «کیت توسعه نرم‌افزار» (SDK) پست کنید. «تابلو گفتگو» جای بسیار خوبی برای پرسیدن، هم‌رسانی کردن ایده‌ها، پیوند دادن به نسخه نمایشی، و پشتیبانی کردن از توسعه‌دهندگان دیگر بااستفاده از Outline SDK است. برای درخواست ویژگی یا گزارش اشکال، به‌جای آن لطفاً [مشکل](https://github.com/Jigsaw-Code/outline-sdk/issues/new) را باز کنید.
