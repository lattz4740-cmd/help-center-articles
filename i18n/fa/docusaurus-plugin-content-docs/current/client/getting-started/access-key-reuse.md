title: آیا می‌توانم بیش‌از یک‌بار از کلید دسترسی استفاده کنم؟
sidebar_label: آیا می‌توانم بیش‌از یک‌بار از کلید دسترسی استفاده کنم؟
---

بله. می‌توانید از [کلید دسترسی](/about/terminology) در هر تعداد دستگاهی که می‌خواهید استفاده کنید، اما توصیه نمی‌کنیم کلیدتان را با دیگران هم‌رسانی کنید. کسی که کلید دسترسی‌تان را داشته باشد می‌تواند به کل ترافیک اینترنت شما دسترسی داشته باشد و این باعث می‌شود استفاده شما از اینترنت دیگر امن یا خصوصی نباشد.
