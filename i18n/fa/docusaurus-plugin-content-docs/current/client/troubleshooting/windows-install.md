---
title: چرا نمی‌توانم Outline Client را در Windows نصب کنم؟
sidebar_label: چرا نمی‌توانم Outline Client را در Windows نصب کنم؟
---

ممکن است این پیام خطا را ببینید: «متأسفیم، به‌نظر می‌رسد Outline به‌درستی نصب نشده است. لطفاً آن

ممکن است این پیام خطا را ببینید: «متأسفیم، به‌نظر می‌رسد Outline به‌درستی نصب نشده است. لطفاً آن را دوباره نصب کنید. اگر کار نمی‌کند، لطفاً [بازخورد ارسال کنید](/about/feedback).»

اگر از Outline در Windows استفاده می‌کنید، گاهی ممکن است با خطایی غیرمنتظره مواجه شوید. در بیشتر موارد، آداپتور Outline TAP (درایور) باید حذف شود و Outline بازنصب شود.

بسته به نسخه سیستم‌عامل Windows ممکن است مراحل متفاوت باشد، با‌این‌حال، مراحل عمومی حذف نصب آداپتور TAP و Outline، و سپس بازنصب Outline درزیر ارائه شده است.

1. حذف نصب آداپتور TAP برای Outline Client
   1. به «مدیران دستگاه»، سپس به Network Adapters بروید؛
   2. فایل «TAP-Windows Adapter V9» یا آداپتور TAP مربوط به Outline را پیدا کنید؛
   3. این آداپتور را حذف نصب یا حذف کنید. به‌خاطر داشته باشید که این کار می‌تواند روی دیگر برنامه‌های VPN که نصب کرده‌اید تأثیر بگذارد.
2. لغو نصب کردن Outline Client
   1. به «برنامه‌ها و ویژگی‌ها»، سپس به «حذف نصب برنامه» بروید؛
   2. برنامه Outline Client را پیدا کنید و Outline Client را حذف نصب کنید؛
   3. [آخرین نسخه Outline Client را بارگیری کنید](https://getoutline.org/get-started/#step-3) و آن را در دستگاه Windows بازنصب کنید. نصب جدید باید به‌طور خودکار آداپتور TAP جدیدی را نصب کند.

اگر هنوز با مشکل مواجه هستید، [با پشتیبانی تماس بگیرید](/about/feedback).
