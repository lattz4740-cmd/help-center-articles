sidebar_label: اگرچه به سرور Outline متصل هستم، چرا نمی‌توانم  به اینترنت دسترسی داشته باشیم؟
---

اگر از تلفن همراه استفاده می‌کنید، اتصال به اینترنت را بین داده تلفن همراه و Wi-Fi عوض کنید. گاهی یک نوع اتصال کار می‌کند و دیگری کار نمی‌کند. اگر از رایانه استفاده می‌کنید، فراخ‌باند را قطع کنید و دوباره آن را وصل کنید.

اگر همچنان مشکلاتی دارید، احتمالاً مشکل سرور Outline است. با [مدیر سرویس](/about/terminology) تماس بگیرید تا کلید دسترسی جدیدی برای سرور جایگزین به شما بدهد. مدیر ممکن است بتواند محدوده داده‌های [کلید دسترسی](/about/terminology) شما را درصورتی‌که از سهمیه فراتر رفته باشد افزایش دهد
