sidebar_label: "Je, masharti yapi ya mfumo yanahitajika ili kutekeleza programu ya Outline?"
---

Unakaribishwa kujaribu programu ya Outline kwenye mfumo wowote wa uendeshaji. Ifuatayo ni mifumo ya uendeshaji ya kiwango cha chini zaidi inayohitajika:

| **Mfumo wa uendeshaji** | **Toleo la kiwango cha chini** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Je, ungependa kusaidia Programu ya Outline ifanye kazi kwenye mifumo mingi ya uendeshaji? [Changia mkusanyiko wetu wa chanzo cha misimbo](https://github.com/OutlineFoundation/outline-client#platform-specific-development) kwenye GitHub!
