---
title: "Que faire si ma clé d'accès ne fonctionne pas ?"
sidebar_label: "Que faire si ma clé d'accès ne fonctionne pas ?"
---

"Votre clé d'accès ne semble pas valide. Si cela se reproduit, veuillez contacter votre gestionnaire de service."

Suivez ces instructions pour résoudre le problème :

1. Veillez à bien saisir la clé d'accès complète, y compris les cinq premiers caractères "ss://", qui ne sont pas toujours copiés automatiquement dans le presse-papiers. Voici un exemple de clé d'accès complète (non fonctionnelle) :

```
ss://Y2hhY2hhMjAtaWV0Zi1wb2x5MTMwNTp1eXhUQ3MzemVEMTk=@145.230.4.1:39485/?outline=1
```


ss://Y2hhY2hhMjAtaWV0Zi1wb2x5MTMwNTp1eXhUQ3MzemVEMTk=@145.230.4.1:39485/?outline=1

1. Si vous ne parvenez pas du tout à copier votre clé d'accès dans le presse-papiers, cela peut être dû à votre plate-forme ou application de messagerie. Cela peut surtout se produire lorsque vous recevez un message d'une personne ne figurant pas dans votre liste de contacts. Si vous copiez le code à partir d'un message, assurez-vous d'ajouter l'expéditeur à vos contacts, puis réessayez d'accéder au lien.
2. Si le message d'erreur persiste après que vous avez suivi les étapes 1 et 2, il est probable que le serveur soit bloqué ou que la clé d'accès ne soit plus valide. Si vous êtes le gestionnaire du service, essayez de générer une nouvelle clé. Autrement, contactez votre gestionnaire de service afin d'obtenir une nouvelle clé.
