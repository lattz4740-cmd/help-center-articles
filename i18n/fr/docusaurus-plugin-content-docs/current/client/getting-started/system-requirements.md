---
title: "Quelle est la configuration système requise pour exécuter le client Outline ?"
sidebar_label: "Quelle est la configuration système requise pour exécuter le client Outline ?"
---

Nous vous invitons à essayer Outline sur n'importe quel système d'exploitation. Voici la configuration minimale requise :

| **Système d'exploitation** | **Version minimale** |
| --- | --- |
| Android | 10 |
| iOS | 15.5 |
| macOS | 12.0 |
| Windows | 10 |
| Linux | Ubuntu 20.04 |

Vous voulez nous aider à faire fonctionner le client Outline sur d'autres systèmes d'exploitation ? [Contribuez à notre code base](https://github.com/OutlineFoundation/outline-client#platform-specific-development) sur GitHub !
