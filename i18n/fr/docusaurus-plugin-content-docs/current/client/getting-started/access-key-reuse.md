---
title: "Puis-je utiliser une clé d'accès plusieurs fois ?"
sidebar_label: "Puis-je utiliser une clé d'accès plusieurs fois ?"
---

Oui. Vous pouvez utiliser votre [clé d'accès](/about/terminology) sur autant d'appareils que vous le souhaitez, mais nous vous recommandons de ne pas la partager avec d'autres personnes. Une personne ayant votre clé d'accès pourrait inspecter l'ensemble de votre trafic Internet, ce qui fait que votre utilisation d'Internet ne serait plus sécurisée ni privée.
