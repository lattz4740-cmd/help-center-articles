sidebar_label: "Je suis développeur/développeuse. Où puis-je obtenir de l'aide pour intégrer le SDK Outline dans mon application ?"
---

Ce site Web d'assistance s'adresse aux utilisateurs d'Outline Manager et du client Outline. Veuillez utiliser GitHub pour obtenir de l'aide si vous êtes développeur/développeuse. Pour poser une question, veuillez publier un message sur le [forum de discussion](https://github.com/Jigsaw-Code/outline-sdk/discussions) du SDK. C'est l'espace idéal pour poser des questions, partager des idées, proposer des liens vers des démonstrations et aider d'autres développeurs qui utilisent le SDK Outline. Pour toute demande de fonctionnalité ou rapport de bug, veuillez plutôt ouvrir une [demande d'assistance](https://github.com/Jigsaw-Code/outline-sdk/issues/new).
