title: Envoyer des commentaires ou des suggestions
sidebar_label: Envoyer des commentaires ou des suggestions
---

Merci de contribuer à l'amélioration d'Outline ! Vous pouvez nous transmettre vos commentaires par différents moyens, de façon anonyme ou en indiquant votre adresse e-mail si vous attendez une réponse de notre part :

- **Pour les développeurs** : Outline est un logiciel Open Source dont le code complet est hébergé sur [GitHub](https://github.com/Outline-Foundation/?q=outline). Vous pouvez partager vos idées sur GitHub ou par le biais de notre communauté [Reddit](https://www.reddit.com/r/outlinevpn/).

- **Pour les utilisateurs** : vous pouvez nous envoyer des commentaires via les applications Outline et Outline Manager. Indiquez-nous le sujet de votre commentaire et, si vous le souhaitez, laissez-nous votre adresse e-mail afin que nous puissions vous répondre. Nous [collectons aussi certaines métadonnées](https://getoutline.org/) relatives à votre environnement (navigateur, système d'exploitation et version du logiciel que vous utilisez) afin de pouvoir vous aider en cas de dépannage.

- **Sur ce site** : vous pouvez cliquer sur les liens "Nous contacter" disponibles sur ce site.

- **Problèmes graves** : si vous avez un grave problème de sécurité à nous signaler, merci de nous faire parvenir tous les détails le concernant par e-mail à l'adresse security [at] getoutline.org.

Nous vous remercions à nouveau de prendre le temps de nous transmettre vos commentaires.
