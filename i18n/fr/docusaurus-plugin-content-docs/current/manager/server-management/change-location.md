---
title: "Comment modifier l'emplacement du serveur Outline ?"
sidebar_label: "Comment modifier l'emplacement du serveur Outline ?"
---

Une fois que l'emplacement d'un serveur est configuré, vous ne pouvez pas le modifier. Pour exécuter votre serveur Outline à partir d'un emplacement différent, vous devez le supprimer, puis en créer un autre.

Vous pouvez aussi modifier l'emplacement de votre VPN à l'aide de [clés dynamiques](https://developer.getoutline.org/vpn/management/dynamic-access-keys/). Cela vous permet d'effectuer une rotation des serveurs tout en gardant les mêmes clés. L'emplacement des serveurs eux-mêmes ne sera pas modifié.
