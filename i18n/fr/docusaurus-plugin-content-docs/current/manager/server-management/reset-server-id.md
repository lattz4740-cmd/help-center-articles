---
title: "Comment réinitialiser l'ID de mon serveur ?"
sidebar_label: "Comment réinitialiser l'ID de mon serveur ?"
---

L'ID de serveur est un identifiant généré de manière aléatoire côté serveur lorsque vous créez un serveur Outline. Il est visible lorsque vous choisissez de partager des statistiques anonymes dans les paramètres. Pour ce faire, accédez aux paramètres, faites défiler l'écran vers le bas, puis cochez l'option "Partagez des statistiques anonymes".

L'ID de serveur permet de regrouper les statistiques d'utilisation anonymes consignées au fil du temps. Pour réinitialiser cet ID et en obtenir un autre, vous devez remplacer votre serveur Outline existant par un nouveau.
