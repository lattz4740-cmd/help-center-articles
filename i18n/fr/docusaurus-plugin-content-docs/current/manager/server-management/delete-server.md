---
title: "Comment supprimer mon serveur Outline?"
sidebar_label: "Comment supprimer mon serveur Outline?"
---

Avec la plupart des fournisseurs de services cloud, il est assez facile de supprimer la machine virtuelle que vous utilisez.

Si votre fournisseur de services cloud est DigitalOcean, vous pouvez supprimer votre machine virtuelle actuelle en cliquant sur le bouton en forme de roue dentée et en sélectionnant **Supprimer le serveur**. Ensuite, vous serez immédiatement invité à créer une machine virtuelle à l'emplacement de votre choix.

La suppression d'un serveur Outline est définitive et rend ses clés d'accès obsolètes. Pour éviter toute interruption d'accès à Outline, vous devez [configurer un nouveau serveur Outline](/manager/server-setup/setup-server) et en partager l'accès avec les utilisateurs avant de supprimer votre ancien serveur.
