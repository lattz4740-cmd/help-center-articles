---
title: Installer plusieurs serveurs Outline
sidebar_label: Installer plusieurs serveurs Outline
---

Pour installer d'autres serveurs Outline, cliquez sur l'icône "+" qui se trouve dans le panneau de navigation, sur la gauche de votre application Outline Manager. La procédure à suivre est la même que pour votre premier serveur.

- Vous pouvez créer autant de serveurs Outline que vous le souhaitez.
- Pour chaque serveur Outline créé, vous aurez besoin d'une machine virtuelle correspondante.
- La création de machines ou de droplets supplémentaires peut accroître les frais facturés par votre fournisseur de services cloud. Veuillez vérifier les tarifs pratiqués par votre fournisseur, afin de savoir à quoi vous attendre.

## Créer un serveur Outline supplémentaire sur DigitalOcean

Une fois que vous avez cliqué sur l'icône "+" et sélectionné l'option d'installation sur DigitalOcean, la procédure à suivre est la même que pour votre premier serveur. De plus, Outline Manager et DigitalOcean étant intégrés, nous pouvons créer le droplet pour vous sans que vous ayez à quitter l'application Outline Manager.

 Notez que l'application Outline Manager ne peut pas être associée à plusieurs comptes DigitalOcean simultanément. Si vous souhaitez ajouter ou créer d'autres serveurs Outline à partir d'autres comptes DigitalOcean, vous pouvez les ajouter dans le cadre d'une configuration avancée.

## Créer un serveur Outline supplémentaire sur GCP, AWS ou un autre fournisseur de services cloud

Commencez par créer une machine virtuelle auprès du fournisseur de services cloud de votre choix. Ensuite, ouvrez Outline Manager et suivez les instructions d'installation avancée, comme vous l'avez fait la première fois.
