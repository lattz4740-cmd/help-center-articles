L'installation du serveur Outline est la première étape à réaliser pour pouvoir utiliser Outline. Pour vous connecter à l'Internet public via Outline, vous devez installer un serveur Outline ou confier cette tâche à une personne de confiance.

## Avant de commencer

Pour installer votre serveur Outline, vous aurez besoin des éléments suivants :

1. Accès à vos propres serveurs ou à un fournisseur de services cloud tel que DigitalOcean, Amazon Web Services (AWS) ou Google Cloud Platform (GCP)

    Si vous ne disposez pas encore d'un accès à un serveur cloud, vous pouvez facilement créer un compte auprès d'un fournisseur, y compris auprès de ceux répertoriés ci-dessus. Vous aurez probablement besoin d'une carte de crédit pour vous inscrire.
2. Un ordinateur de bureau sous macOS 10.9 ou version ultérieure, Windows 7.0 ou version ultérieure, ou Linux
3. L'application Outline Manager

## Installer Outline sur DigitalOcean

Il suffit de quelques clics pour installer Outline sur DigitalOcean. Une fois Outline Manager téléchargé et installé sur votre ordinateur, vous pouvez sélectionner l'option d'installation sur DigitalOcean. Elle vous permettra de configurer et d'installer votre serveur Outline en quelques étapes simples.

## Installer Outline sur un autre fournisseur de services cloud

Une fois Outline Manager téléchargé et installé, vous avez la possibilité d'installer un serveur Outline sur une machine virtuelle avec AWS, GCP, DigitalOcean ou un autre fournisseur. Chaque environnement est différent, mais nous fournissons dans Outline Manager les instructions d'installation correspondant aux principaux fournisseurs de services cloud. Nous vous indiquons, entre autres, comment configurer les paramètres de votre machine virtuelle avant de lancer le script d'installation d'Outline sur un serveur.
