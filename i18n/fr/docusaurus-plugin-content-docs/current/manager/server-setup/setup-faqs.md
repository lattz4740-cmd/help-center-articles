## Puis-je utiliser Outline sans serveur ?

Malheureusement, non. Le logiciel Outline a besoin d'accéder à un serveur, que ce dernier soit géré par vous-même, votre organisation ou un tiers de confiance.

## Combien de temps faut-il pour installer un serveur Outline ?

Dans la plupart des cas, cela demande moins de 5 minutes. Vous pouvez installer Outline sur le serveur cloud de votre choix, mais nous nous sommes associés à DigitalOcean pour vous offrir une expérience d'installation plus conviviale qui vous permet d'installer un serveur en quelques clics, sans aucun script.

 Si vous optez pour AWS, GCP ou une configuration avancée, nous vous proposons un processus d'installation simplifié tenant en un seul script compatible avec la plupart des environnements.

## Où puis-je installer un serveur Outline ?

Vous pouvez installer un serveur Outline chez la plupart des fournisseurs de services cloud, quel que soit le pays où ils opèrent.

 Le fournisseur DigitalOcean offre la solution la plus simple, puisqu'il possède des serveurs dans différentes régions (Amsterdam, Toronto, San Francisco et Singapour, par exemple). Si vous préférez l'installer chez un autre fournisseur de services cloud ou sur votre propre infrastructure, vous pouvez sélectionner le mode avancé dans l'application Outline Manager et suivre les instructions pour procéder à l'installation à l'aide d'un script de configuration.

## Où dois-je installer mon serveur Outline ?

Le choix du lieu où vous installerez votre serveur Outline dépend de différents facteurs :

1. L'emplacement du serveur Outline a un impact sur l'expérience Internet des utilisateurs. Par exemple, si le serveur est situé à Amsterdam, l'utilisateur qui y accède est considéré sur Internet comme résidant aux Pays-Bas. Certains sites Web pourraient même apparaître en néerlandais. En général, les sites Web fournissent une option permettant de modifier le paramètre régional.
2. La distance entre vos utilisateurs et le serveur Outline peut affecter le débit des connexions. De manière générale, la distance physique entre le serveur Outline et ses utilisateurs peut avoir un impact sur le débit de leurs connexions Internet. Dans la plupart des cas, il suffit de choisir le serveur le plus proche de vos utilisateurs, mais vous pouvez également consulter la [carte des câbles sous-marins](https://www.submarinecablemap.com/) pour identifier les câbles Internet reliés à votre pays ou à votre région.
3. L'emplacement de votre serveur VPN peut déterminer le cadre juridique applicable. Notez que le logiciel Outline ne journalise pas votre trafic. En savoir plus sur [la sécurité et la confidentialité lorsque vous utilisez Outline](/about/security-and-privacy)
