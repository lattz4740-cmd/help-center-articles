Google Cloud-এর অটোমেটিক সেট-আপ

এক নজরে​

Outline Manager-এ এমন একটি ফিচার আছে যা আপনাকে Google Cloud-এ রান করা কোনও সার্ভারে Outline সার্ভারকে অটোমেটিক কনফিগার করতে দেয়। আপনি এই ফিচার ব্যবহার করার বিকল্প বেছে নিলে, Outline Manager আপনার Google অ্যাকাউন্ট দিয়ে সাইন-ইন করতে বলবে, যার মাধ্যমে, আপনার Google Cloud অ্যাকাউন্ট কনফিগার করার উদ্দেশ্যে, স্থানীয় লেভেলে Outline Manager ইনস্টলেশনের জন্য নির্দিষ্ট OAuth অনুমতি মঞ্জুর করতে হয়।

আপনি এইসব অনুমতি দিতে না চাইলে, Google Cloud Platform-এ Outline রান করতে, Outline Manager-এ দেখানো উন্নত সেট-আপ প্রক্রিয়ার জন্য প্রয়োজনীয় নির্দেশাবলী ফলো করতে পারবেন।

অনুমতি মঞ্জুর করা হয়েছে​

অটোমেটিক সেট-আপ প্রদান করার জন্য, Outline Manager-কে আপনার Google অ্যাকাউন্ট থেকে নিম্নলিখিত অনুমতিগুলি নিতে হয়।

Google Cloud Platform​

  • আপনার Google Compute Engine সংক্রান্ত রিসোর্স দেখা ও ম্যানেজ করা
  • Google Cloud পরিষেবা জুড়ে আপনার ডেটা এবং Google অ্যাকাউন্টের ইমেল আইডি দেখা

অ্যাকাউন্টের প্রাথমিক তথ্য​

  • আপনার Google অ্যাকাউন্টের প্রাথমিক ইমেল আইডি দেখা
  • Google-এ আপনার ব্যক্তিগত তথ্যের সাথে আপনাকে যুক্ত করা

অতিরিক্ত অ্যাক্সেস​

  • আপনার Cloud Platform-এর প্রোজেক্ট ম্যানেজ করা
  • আপনার Google Cloud Platform সংক্রান্ত বিলিং অ্যাকাউন্ট দেখা ও ম্যানেজ করা
  • আপনার Google API পরিষেবা কনফিগারেশন ম্যানেজ করা

এইসব অনুমতি আপনার Outline সার্ভার ম্যানেজ করার জন্য আমাদের প্রয়োজনীয় উন্নত কার্যকারিতা প্রয়োগ করতে দেয়। এগুলির মধ্যে অন্তর্ভুক্ত হল:

  • আপনাকে সঠিক বিলিং অ্যাকাউন্ট বেছে নিতে দেওয়া
  • আপনার Outline সার্ভার গোছানোর জন্য একটি নতুন প্রোজেক্ট তৈরি করা
  • উপলভ্য ডেটা সেন্টারের তালিকা তৈরি করা
  • Outline রান করার জন্য নতুন ভার্চুয়াল মেশিন তৈরি করা
  • Outline-এর সাথে নতুন ভার্চুয়াল মেশিন কনফিগার করা

অনুমতি প্রত্যাহার করে নেওয়া হচ্ছে​

আপনিআমার অ্যাকাউন্ট পৃষ্ঠাতে গিয়ে Outline Manager-এর জন্য Google Cloud Platform-এর অ্যাক্সেস প্রত্যাহার করতে পারবেন। অ্যাক্সেসের অনুমতি ফিরিয়ে নিলে, অটোমেটিক সেট-আপ প্রক্রিয়ার মাধ্যমে আপনার তৈরি করা সবকটি সার্ভার রান করলেও সেখানে আর Outline Manager দেখা যাবে না। সেগুলিতে অ্যাক্সেস ফিরিয়ে দিতে, শুধু অটোমেটিক সেট-আপ ফ্লো শুরু করে Google Cloud Platform-এ আবার কানেক্ট করতে হবে।

Outline প্রোজেক্ট অর্গানাইজেশন​

আপনার Outline সার্ভার সাজানোর জন্য Google Cloud-এর অটোমেটিক সেট-আপ একটি মাত্রGoogle Cloud প্রোজেক্ট ব্যবহার করে। অটোমেটিক সেট-আপ প্রথম ব্যবহার করার সময় প্রোজেক্ট তৈরি করা হয় এবং এর সাজেস্ট করা প্রোজেক্ট আইডি “Outline-” লেখা দিয়ে শুরু হয় এবং তারপরে তাতে কিছু র‌্যান্ডম অক্ষরের স্ট্রিং দেখানো হয়। আপনি চাইলে প্রোজেক্ট তৈরি হওয়ার সময়েই একটি আলাদা প্রোজেক্ট আইডি বেছে নিতে পারবেন। প্রোজেক্টের নাম “Outline সার্ভার” দেওয়া হবে।

বিলিং অ্যাকাউন্ট​

Google Cloud প্রোজেক্টের জন্য একটি “বিলিং অ্যাকাউন্ট” দরকার হয় যা পেমেন্ট সংক্রান্ত তথ্য নির্ধারণ করে। প্রথমবার Google Cloud-এ অটোমেটিক সেট-আপ ব্যবহার করার সময়, Outline সার্ভারের সাথে যুক্ত করার জন্য আপনাকে একটি বিলিং অ্যাকাউন্ট দিতে বলা হবে। বিলিং অ্যাকাউন্টে সমস্যা থাকার কারণে কখনও কখনও সার্ভার রান করা বন্ধ করা হবে। এই ক্ষেত্রে, আপনাকেGoogle Cloud Console-এ লগ-ইন করে, Outline-এর সাথে যুক্ত Google Cloud প্রোজেক্টের (যার নাম “Outline সার্ভার” দেওয়া হয়েছে) লোকেশন খুঁজে বিলিং সেটিংস আপডেট করতে হবে।

সার্ভার মুছে দেওয়া​

অটোমেটিক সেট-আপ ব্যবহার করে আপনার তৈরি করা সার্ভার মুছে দিতে চাইলে, তা Outline Manager-এর মধ্যে থেকে সবচেয়ে সহজে করা যায়। তবে, আপনি নিজে থেকেই সার্ভার মুছে দিতে চাইলে, আপনাকে হয়তGoogle Cloud Console-এ লগ-ইন করে, প্রারম্ভিক সেট-আপ করার সময় তৈরি করা সেই প্রোজেক্টটি (যার নাম “Outline সার্ভার” রাখা হয়েছে) খুঁজে নিয়ে, সেটির রিসোর্স মুছতে অথবা প্রোজেক্ট বন্ধ করতে হবে।
