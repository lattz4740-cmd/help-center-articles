הגדרה אוטומטית של Google Cloud

סקירה כללית​

אפליקציית Outline Manager כוללת פיצ'ר שמאפשר להגדיר אוטומטית את השרת Outline בשרת שפועל ב-Google Cloud. אם תבחרו להשתמש בפיצ'ר הזה, אפליקציית Outline Manager תבקש מכם להיכנס לחשבון Google. הפעולה הזו תעניק הרשאות OAuth מסוימות להתקנה המקומית של אפליקציית Outline Manager, לטובת הגדרה של חשבון Google Cloud שלכם.

אם אתם לא רוצים להעניק את ההרשאות האלה, כדי להפעיל את Outline ב-Google Cloud Platform תוכלו לפעול לפי ההוראות להגדרה מתקדמת באפליקציית Outline Manager.

הרשאות שהוענקו​

כדי שתהיה אפשרות לספק הגדרה אוטומטית, צריך לתת לאפליקציית Outline Manager את ההרשאות הבאות בחשבון Google שלכם:

Google Cloud Platform​

  • הצגה וניהול של המשאבים ב-Google Compute Engine
  • צפייה בנתונים בשירותי Google Cloud והצגת כתובת האימייל של חשבון Google שלכם

פרטי חשבון בסיסיים​

  • הצגת כתובת האימייל הראשית שמשויכת לחשבון Google שלכם
  • שיוך של המידע האישי שלכם ב-Google אליכם

גישה נוספת​

  • ניהול הפרויקטים ב-Cloud Platform
  • הצגה וניהול של חשבונות לחיוב ב-Google Cloud Platform
  • ניהול תצורת השירות ב-Google API

בעזרת ההרשאות האלה אנחנו יכולים לתמוך בפונקציונליות מתקדמת לניהול השרתים שלכם ב-Outline, כולל:

  • אפשרות לבחור בחשבון הנכון לחיוב
  • יצירת פרויקט חדש לארגון שרתי Outline
  • רישום של מרכזי נתונים זמינים
  • יצירת מכונות וירטואליות חדשות להרצת Outline
  • הגדרת המכונה הווירטואלית החדשה באמצעות Outline

ביטול הרשאות​

רוצים לבטל את הגישה של Outline Manager ל-Google Cloud Platform? תוכלו לעשות זאת בדף החשבון שלי. אם תבטלו את הגישה, כל השרתים שיצרתם באמצעות ההגדרה האוטומטית ימשיכו לרוץ, אבל הם לא יופיעו יותר ב-Outline Manager. כדי לשחזר את הגישה אליהם, פשוט מתחברים מחדש ל-Google Cloud Platform ומתחילים את תהליך ההגדרה האוטומטי.

ארגון פרויקטים ב-Outline​

בהגדרה האוטומטית של Google Cloud, המערכת משתמשת בפרויקט Google Cloud אחד לארגון השרתים שלכם ב-Outline. הפרויקט נוצר במהלך השימוש הראשון בהגדרה האוטומטית, ומזהה הפרויקט שהוצע לו מתחיל ב-"Outline-‎" וממשיך במחרוזת של תווים אקראיים. אם אתם מעדיפים לבחור מזהה פרויקט אחר, תוכלו לעשות זאת בזמן היצירה. השם של הפרויקט יהיה "שרתי Outline"‏ [“Outline servers”].

חשבון לחיוב​

כדי להשתמש בפרויקטים של Google Cloud צריך חשבון לחיוב מקושר שמוגדרים בו פרטי תשלום. בפעם הראשונה שתשתמשו בהגדרה האוטומטית של Google Cloud, תתבקשו להזין חשבון לחיוב כדי לשייך אותו לשרתים שלכם ב-Outline. לפעמים שרת מפסיק לפעול כי יש בעיה בחשבון לחיוב. במקרה כזה, צריך להתחבר ל-Google Cloud Console, למצוא את הפרויקט ב-Google Cloud שמשויך ל-Outline (שנקרא "שרתי Outline") ולעדכן את הגדרות החיוב.

כיבוי סופי של שרתים​

אם אתם רוצים לכבות באופן סופי את השרתים שנוצרו באמצעות ההגדרה האוטומטית, הדרך הקלה ביותר לעשות זאת היא מתוך אפליקציית Outline Manager. עם זאת, אם אתם רוצים לכבות את השרתים באופן סופי בעצמכם, תוכלו להתחבר ל-Google Cloud Console, למצוא את הפרויקט (בשם "שרתי Outline") שנוצר במהלך ההגדרה הראשונית ושם למחוק את המשאבים או להשבית את הפרויקט.
