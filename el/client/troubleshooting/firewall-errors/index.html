Σφάλματα τείχους προστασίας

Υπάρχουν τρεις τύποι προβλημάτων που μπορεί να αντιμετωπίσετε λόγω ενός τείχους προστασίας:

Μπορεί να αποκλειστείτε από ένα τείχος προστασίας δικτύου.​

Εάν προσπαθείτε να εγκαταστήσετε το Outline ενώ είστε συνδεδεμένοι σε ένα δίκτυο που προστατεύεται από τείχος προστασίας, όπως το δίκτυο ενός εκπαιδευτικού ιδρύματος ή το δίκτυο στον χώρο εργασίας σας, κάντε την εγκατάσταση αφού συνδεθείτε σε άλλο δίκτυο.

Εάν αυτό δεν έχει αποτέλεσμα, επικοινωνήστε με τον διαχειριστή δικτύου και ζητήστε του να επιτρέψει τις συνδέσεις μεταξύ του προστατευόμενου δικτύου και του διακομιστή Outline που χρησιμοποιείτε. Θα πρέπει να γνωρίζετε τη διεύθυνση IP του διακομιστή Outline και τις θύρες στις οποίες εκτελείται το Outline. Οι θύρες αναφέρονται στο τέλος του σεναρίου εγκατάστασης.

Μπορεί να αποκλειστείτε από ένα τείχος προστασίας συσκευής.

Εάν υπάρχει στη συσκευή σας λογισμικό που εμποδίζει τις εξερχόμενες συνδέσεις σε μη τυπικές θύρες, ή μη αναγνωρισμένο λογισμικό (ZoneAlarm της CheckPoint), συμβουλευτείτε το υλικό τεκμηρίωσης της συσκευής ή του λογισμικού σας για να μάθετε πώς μπορείτε να δημιουργήσετε μια εξαίρεση για το Outline.

Μπορεί να αποκλειστείτε από ένα τείχος προστασίας διακομιστή.​

Ο πάροχος cloud που έχετε επιλέξει μπορεί να απαιτεί την αυτόματη δημιουργία εξαιρέσεων στο τείχος προστασίας του διακομιστή σας για το άνοιγμα των θυρών στις οποίες εκτελείται το Outline. Μετά την εκτέλεση του σεναρίου εγκατάστασης, θα πρέπει να σας γνωστοποιήθηκαν οι δύο τυχαία επιλεγμένες θύρες στις οποίες θα εκτελείται το Outline στον διακομιστή σας. Αρκεί να ανοίξετε αυτές τις δύο θύρες.

Για να δημιουργήσετε εξαιρέσεις στο τείχος προστασίας του διακομιστή σας, σας συνιστούμε να συμβουλευτείτε το υλικό τεκμηρίωσης για το 'ufw' και το 'iptables':

  • UFW: https://help.ubuntu.com/community/UFW
  • Iptables: https://help.ubuntu.com/community/IptablesHowTo
