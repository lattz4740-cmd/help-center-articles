Ασφάλεια και απόρρητο κατά τη χρήση του Outline

Ασφάλεια και απόρρητο κατά τη χρήση του Outline

Πώς το Outline προστατεύει τις διαδικτυακές επικοινωνίες σας​

Η διαδικτυακή κίνηση μπορεί να αποτελέσει στόχο παρακολούθησης, ιδιαίτερα κατά τη διακίνηση των δεδομένων μέσω του τοπικού ή του εθνικού δικτύου σας.

Το Outline συμβάλλει στην προστασία της ιδιωτικότητας των επικοινωνιών σας, με κρυπτογράφηση της διαδικτυακής κίνησης κατά τη διακίνηση των δεδομένων στο εθνικό δίκτυο και μέχρι να φτάσουν στον διακομιστή Outline. Όταν η επισκεψιμότητα κρυπτογραφείται με το Outline, οι παρατηρητές δικτύου δεν μπορούν να δουν τους ιστοτόπους που επισκέπτεστε ή τις πληροφορίες που διακινείτε.

Το Outline μπορεί επίσης να σας βοηθήσει να αποκαταστήσετε την πρόσβαση σε ασφαλή εργαλεία επικοινωνίας από τερματικό σε τερματικό (end-to-end) τα οποία μπορεί να μην είναι προσβάσιμα στη χώρα σας.

Πρότυπα κρυπτογράφησης​

Το Outline κρυπτογραφεί την επικοινωνία ανάμεσα στη συσκευή σας και τον διακομιστή Outline, χρησιμοποιώντας κρυπτογράφηση AEAD 256-bit Chacha2020 IETF Poly 1305. Τα κρυπτογραφήματα AEAD παρέχουν εμπιστευτικότητα, ακεραιότητα και αυθεντικότητα, και αποδίδουν εξαιρετικά στον σύγχρονο εξοπλισμό.

Έλεγχοι ασφαλείας​

Το 2018, το Outline ελέγχθηκε από το Radically Open Security και το Cure53, δύο ανεξάρτητους οργανισμούς ψηφιακής ασφάλειας που αξιολόγησαν το λογισμικό σε σχέση με τα τελευταία πρότυπα ασφαλείας. Το Radically Open Security διεξήγαγε έναν πρόσθετο έλεγχο το 2022 και η Cure53 διεξήγαγε έναν έλεγχο του Outline SDK το 2024. Μπορείτε να διαβάσετε τις αναφορές εδώ:

  • Radically Open Security Penetration Test Report (Μάρτιος 2018)
  • Cure53 Pentest & Audit Report Jigsaw Outline (Δεκέμβριος 2018)
  • Radically Open Security Penetration Test Report (Δεκέμβριος 2022)
  • Cure53 Pentest Report Jigsaw Outline VPN SDK (Ιανουάριος 2024)

Ανώνυμες μετρήσεις και αρχεία καταγραφής​

Το Outline παρακολουθεί τη χρήση του εύρους ζώνης, δηλαδή τα "μεταφερόμενα byte" ανά κλειδί πρόσβασης. Αυτές οι πληροφορίες παρέχουν στους διαχειριστές διακομιστών τη δυνατότητα να προσαρμόζουν τις συνδρομές τους για εύρος ζώνης στους παρόχους διακομιστών cloud ανάλογα με τις ανάγκες τους. Ωστόσο, δεν τους επιτρέπουν να βλέπουν τις πληροφορίες που διακινούνται μέσω του διακομιστή Outline.

Μάθετε περισσότερα σχετικά με τη συλλογή δεδομένων και πληροφοριών του Outline.

Συνήθεις ερωτήσεις σχετικά με την ασφάλεια και το απόρρητο​

Μπορεί το Outline να με κάνει ανώνυμο στο διαδίκτυο;​

Όχι, το Outline δεν είναι εργαλείο ανωνυμοποίησης. Το Outline προστατεύει το απόρρητό σας από πιθανούς παρατηρητές δικτύου.

Το Outline δεν προσφέρει πλήρη ανωνυμία στους ιστοτόπους που επισκέπτεστε, καθώς οι ιστότοποι μπορούν να προσδιορίσουν την ταυτότητά σας όταν συνδέεστε ή ενδεχομένως μέσω άλλων τεχνικών, όπως το μοναδικό χαρακτηριστικό προγράμματος περιήγησης. Ως προς τις εφαρμογές για κινητά, τα περισσότερα σύγχρονα smartphone έχουν API που επιτρέπουν στις εγκατεστημένες εφαρμογές την ανάκτηση της τοποθεσίας σας, ανεξάρτητα από τον διακομιστή μεσολάβησης, καθώς μπορούν να βασιστούν στο ενσωματωμένο GPS.

Τα εικονικά ιδιωτικά δίκτυα (VPN) προσφέρουν σε γενικές γραμμές ικανοποιητική προστασία, ειδικά από την παρακολούθηση διαδικτύου, ωστόσο εξακολουθούν να υπάρχουν κίνδυνοι κατά τη χρήση του διαδικτύου. Ακόμα και με ένα VPN, εάν ένας πάροχος υπηρεσιών διαδικτύου (ISP) γνωρίζει ήδη την ταυτότητά σας και μπορεί να παρακολουθεί την επισκεψιμότητα διαδικτύου σας, μπορεί ενδεχομένως να προσδιορίσει τη διεύθυνση IP του διακομιστή Outline που χρησιμοποιείτε. Αυτές οι πληροφορίες μπορούν να χρησιμοποιηθούν για τον αποκλεισμό της πρόσβασης στον διακομιστή Outline ή τον προσδιορισμό μοτίβων χρήσης, όταν είστε συνδεδεμένοι στο διαδίκτυο, και ενδεχομένως για τον εντοπισμό της τοποθεσίας σας κατά προσέγγιση.

Μπορεί κανείς να καταλάβει εάν χρησιμοποιώ το Outline;​

Πιθανώς. Οι πλατφόρμες και οι υπηρεσίες στις οποίες αποκτάτε πρόσβαση θα μπορούν να διαπιστώσουν ότι η σύνδεσή σας προέρχεται από έναν διακομιστή cloud. Μερικές φορές, μπορούν να υποθέσουν ότι χρησιμοποιείτε ένα VPN, αλλά δεν θα μπορούν να δουν τα περιεχόμενα της διαδικτυακής σας κίνησης.

Το Outline με προστατεύει από όλες τις κυβερνοαπειλές;​

Όχι. Κανένα εργαλείο δεν μπορεί να σας προστατέψει από όλες τις πιθανές κυβερνοαπειλές. Το Outline σάς παρέχει πρόσβαση στο ανοικτό διαδίκτυο και ενισχύει την προστασία του απορρήτου σας, κρυπτογραφώντας την επισκεψιμότητά σας, αλλά συνιστούμε τη λήψη πρόσθετων προφυλάξεων για την προστασία σας από άλλους τύπους επιθέσεων, όπως τα κακόβουλα προγράμματα και το ηλεκτρονικό ψάρεμα (phishing).

Για να ενισχύσετε την ασφάλειά σας στο διαδίκτυο, συνεργαστείτε με τον ειδικό του οργανισμού σας σε θέματα κυβερνοασφάλειας. Εναλλακτικά, μπορείτε να λάβετε εξατομικευμένη καθοδήγηση από κορυφαίους ειδικούς σε θέματα ασφαλείας στο Security Planner, έναν ιστότοπο που έχει σχεδιαστεί για να σας παρέχει σαφείς οδηγίες σχετικά με την επιλογή των κατάλληλων εργαλείων κυβερνοασφάλειας σύμφωνα με τις ανάγκες σας.

Μπορείτε επίσης να ρίξετε μια ματιά σε άλλα προϊόντα κυβερνοασφάλειας της Jigsaw, όπως το Intra, το Project Shield και το Password Alert.

Είναι νόμιμη η χρήση VPN;​

Πριν από τη λειτουργία του Outline ή τη χρήση της εφαρμογής, ελέγξτε την ισχύουσα τοπική νομοθεσία, τους κανονισμούς καθώς και τους Όρους Παροχής Υπηρεσιών του παρόχου cloud που σκοπεύετε να χρησιμοποιήσετε.
