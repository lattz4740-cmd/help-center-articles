서버 설치

Outline 설치 과정은 간단해 보일 수 있지만 사실 복잡한 일련의 단계를 거쳐야 서버를 설치할 수 있습니다.

Outline이 설치될 때마다 설치 스크립트는 다음 단계를 실행합니다.
  • Docker를 통해 안정적인 버전의 Shadowbox 이미지를 검색해 가져옵니다. 이미지는 Quay.io(https://quay.io/repository/outline/shadowbox?tab=tags)에 호스팅되어 있습니다. 이 이미지에는 Outline 서버 및 Management API가 포함되어 있으며, 이 API는 나중에 Outline Server Management 애플리케이션에서 액세스 키를 생성 및 삭제하고, 익명처리된 측정항목 보고서를 선택 또는 선택 해제할 때 사용됩니다.
  • 매시간 이미지 업데이트를 확인하도록 Watchtower가 설치 및 구성되므로 모든 Outline 서버는 지속적으로 최신 기능 및 보안 개선 사항을 받아 최신 상태를 유지할 수 있습니다.
  • Management API에 액세스하는 데 사용되는 웹 서버가 비공개 고유 경로를 통해 랜덤 포트에서 시작됩니다.
  • 도메인 이름 없이도 TLS를 사용해 Outline 서버 관리 내역을 암호화할 수 있도록 자체 서명된 SSL 인증서가 생성됩니다. 이 인증서에 사용할 고유 디지털 지문이 생성되고 Outline Manager 애플리케이션에 저장되기 때문에 MITM 공격을 방지하는 데 도움이 됩니다.
Outline은 설치가 완료된 후 따로 구성할 필요가 없습니다.

서버 보안

Outline 소프트웨어는 오픈소스이므로 누구나 코드를 보고 취약점이 발견되는 경우 이를 개선할 수 있습니다. Outline의 코드는 GitHub에 호스팅되어 있습니다.

또한 설치된 모든 Outline 서버는 새 버전이 출시될 때마다 자동으로 업데이트되므로 이전 버전의 소프트웨어를 실행 중인 Outline 서버가 남아 있지 않도록 보장합니다.

Outline Manager 애플리케이션은 서버에서 액세스 키를 관리하기 위해 Outline 서버의 관리 서비스와 상호작용합니다. 관리 서비스는 랜덤 포트와 비공개 고유 경로에서 실행됩니다. 적절한 비공개 경로가 지정되지 않으면 쿼리에 응답하지 않기 때문에 관리 서비스는 자체적으로 탐색에 강합니다. 마지막으로 관리 서비스로의 모든 통신은 자체 서명 SSL 인증서로 암호화됩니다.

Outline 서버는 어떤 로그도 저장하지 않으므로 서버가 해킹되는 경우에도 사용자 데이터는 공개되지 않습니다. 여기에서 자세히 알아보세요.

Radically Open Security 및 Cure53에서는 2018년에 Outline을 대상으로 감사를 실시했습니다. 여기에서 보고서를 확인하세요. 

UDP 트래픽 처리

Outline은 시스템 차원의 VPN으로 작동할 수 있습니다. 즉, 모든 UDP 트래픽이 Outline 서버를 통해 터널링됩니다.

DNS 트래픽

Outline은 Outline 서버를 통해 모든 DNS 조회를 처리하고 다른 모든 네트워크 활동에 사용되는 것과 동일한 암호화를 사용하여 보호합니다. DNS 쿼리가 Outline 서버를 통과해 Dyn Internet Guide 또는 OpenDNS로 이동합니다.

Outline은 사용자의 DNS 조회를 절대 기록하지 않습니다.

Outline 사용 시 보안 및 개인 정보 보호

Outline에서 온라인 통신을 보호하는 방법

인터넷 트래픽의 감시는 지역 또는 국가 네트워크를 통과할 때 가장 취약해집니다.

Outline은 인터넷 트래픽이 국가 네트워크에서 이동하고 Outline 서버에 도달할 때까지 트래픽을 암호화하여 보안을 유지합니다. Outline을 통해 트래픽이 암호화되면 네트워크 관찰자는 사용자가 방문한 웹사이트 또는 전송하는 정보를 검사할 수 없습니다.

또한 Outline을 사용하면 사용자의 국가에서 액세스할 수 없는 안전한 엔드 투 엔드 통신 도구에 대한 액세스가 가능해질 수도 있습니다. 

암호화 표준

Outline은 AEAD 256비트 Chacha2020 IETF Poly 1305 암호화를 사용해 기기와 Outline 서버 간의 통신을 암호화합니다. AEAD 암호화는 기밀성, 무결성, 신뢰성을 제공하며, 최신 하드웨어에서 뛰어난 성능을 보여줍니다.

익명 처리된 측정항목 및 로그

Outline에서는 각 액세스 키에 '전송된 바이트 수', 즉 사용된 대역폭 추적이 이뤄집니다. 서버 관리자는 이 정보를 사용해 필요에 따라 클라우드 서버 제공업체의 대역폭 사용을 조정할 수 있지만, Outline 서버를 통과한 실제 정보를 볼 수는 없습니다.

보안 및 개인 정보 보호 FAQ 

Outline을 사용하면 온라인에서 익명으로 활동할 수 있나요?

아니요. Outline은 익명성을 확보하기 위한 도구가 아닙니다. Outline을 사용하면 잠재적인 네트워크 관찰자로부터 사용자의 개인정보를 보호할 수 있습니다.

웹사이트에서는 브라우저 지문 인식과 같은 기술을 통해 또는 로그인할 때 사용자를 식별할 수 있으므로 Outline을 사용해도 방문하는 웹사이트에서 완전한 익명성이 보장되지 않습니다. 대부분의 최신 스마트폰에는 설치된 모바일 앱이 프록시와는 별도로 내장 GPS에 따라 사용자의 위치 정보를 가져올 수 있는 API가 있습니다.

일반적으로 VPN은 인터넷 감시 등에 대한 중요 보호 기능을 제공하지만 온라인 운영에는 항상 위험이 따릅니다. VPN을 사용하더라도 ISP에서 사용자의 신원을 알고 있고 네트워크 트래픽을 관찰할 수 있는 경우 Outline 서버의 IP 주소를 파악할 수 있습니다. 이 정보는 Outline 서버에 대한 액세스를 차단하거나, 사용자가 일반적으로 온라인 상태가 되는 시기와 같은 사용 패턴 및 사용자의 대략적인 위치를 파악하는 데 사용될 수 있습니다. 

다른 사람이 내가 Outline을 사용 중인지 알 수 있나요?

그럴 수도 있습니다. 사용자가 액세스하는 플랫폼 및 서비스는 사용자의 연결이 클라우드 서버에서 비롯함을 알 수 있을 가능성이 큽니다. 이 플랫폼과 서비스에서 사용자가 VPN을 사용하고 있음을 유추할 수도 있지만 인터넷 트래픽의 내용을 볼 수는 없습니다. 

Outline을 사용하면 모든 사이버 위협으로부터 보호받을 수 있나요?

아니요. 하나의 도구로 모든 사이버 위협을 막을 수는 없습니다. Outline은 개방된 인터넷에 대한 액세스를 제공하면서 트래픽 암호화를 통해 개인 정보 보호 수준을 높입니다. 하지만 멀웨어나 피싱과 같은 다른 유형의 공격에 대비해 추가적인 예방 조치를 취하는 것이 좋습니다.

온라인 방어를 강화하려면 조직의 사이버 보안 전문가와 협력하세요. 또는 Security Planner에서 업계 최고 보안 전문가로부터 맞춤형 안내를 받을 수 있습니다. 이 웹사이트는 사용자가 우려하는 사안에 맞는 적합한 사이버 보안 도구를 선택할 수 있도록 명확한 안내를 제공합니다.

Intra, Project Shield, 비밀번호 경보와 같은 Jigsaw의 다른 사이버 보안 제품도 확인해 보세요. 

VPN 사용은 합법인가요?

Outline을 운영하거나 Outline 앱을 사용하기 전에 사용하려는 클라우드 제공업체의 서비스 약관과 현지 법규 및 규정을 확인하세요.

VPN이 무엇인가요?

가상 사설망(VPN)은 기기와 호스트 서버 간의 비공개 연결입니다. VPN을 사용하면 트래픽이 인터넷 제공업체로부터 숨겨집니다.

다음 시나리오에서 VPN을 사용할 수 있습니다.

  • 공용 Wi-Fi 네트워크 사용 시 데이터 보호
  • 인터넷 공급자 및 정부 기관으로부터 인터넷 사용 기록을 비공개로 유지
  • 전 세계의 다양한 소스에서 검열되지 않은 콘텐츠에 액세스

Outline은 기존 VPN과 어떻게 다른가요?

인터넷 서비스 제공업체는 일반적인 보안 프로토콜이나 트래픽 볼륨 패턴을 인식함으로써 기존의 VPN을 쉽게 감지하고 차단할 수 있습니다. Outline은 감지하기 어려워 차단하기도 까다롭게 설계된 프로토콜을 사용해 개발되었으므로 기존 VPN에 비해 탄력성이 더 우수합니다. Outline은 네트워크 기반의 차단 및 IP 차단과 같은 복잡한 형태의 검열도 우회합니다.

Outline 서버란 무엇인가요?

Outline 서버는 허가된 사용자가 연결할 수 있는 VPN을 실행합니다.

 사용자가 새로운 네트워크를 만드는 경우 사용자는 자체 보안 서버를 Outline 서버로 사용할 수 있으며, 다음과 같은 클라우드 서비스 제공업체를 사용할 수도 있습니다.

  • DigitalOcean
  • Google Cloud Platform(GCP)
  • Amazon Web Services(AWS)

Outline Manager에서 서버를 설정할 수 있습니다. 

서비스 관리자는 누구인가요?

서비스 관리자는 Outline 서버를 설정하고 사용자에게 액세스 키를 공유하는 담당자입니다. 서비스 관리자는 일반적으로 서버 사용 비용을 관리하는 일을 맡습니다.

액세스 키란 무엇인가요?

액세스 키는 기존 Outline 서버에 액세스하고 VPN에 연결하는 데 사용됩니다. 서비스 관리자가 액세스 키를 제공할 수도 있고 사용자가 직접 Outline 서버를 설정할 수도 있습니다. 

다음은 액세스 키의 예입니다(샘플 전용, 작동하지 않음). 

ss://Y2hhY2hhMjAtaWV0Zi1wb2x5MTMwNTp1eXhUQ3MzemVEMTk=@XXX.XXX.4.1:39485/?outline=1

Outline Manager란 무엇인가요?

Outline Manager는 서비스 담당자가 Outline 서버를 설정하고, 액세스 키를 생성하고, 키 1개당 사용 가능한 데이터 한도를 설정하도록 도와주는 데스크톱 애플리케이션입니다. 여기 또는 여기에서 최신 버전의 Outline Manager를 다운로드할 수 있습니다.

Outline 클라이언트란 무엇인가요?

  • Outline 서버에 대한 액세스를 네트워크 방화벽이 차단하고 있습니다. 학교, 직장 또는 무료 무선 네트워크와 같은 공용 네트워크를 사용하는 경우 일반적인 현상입니다.

  • 기기에 Outline 서버로의 액세스를 차단하는 방화벽 또는 바이러스 백신 소프트웨어가 있습니다.

  • 휴대전화 기기 설정을 변경해야 할 수도 있습니다.

  • 서비스 관리자가 서버를 삭제했거나 ISP에서 요청을 차단했을 수 있습니다.

  • 네트워크가 복원되지 않은 경우 잠시 기다렸다가 연결 설정이 자체적으로 업데이트되는지 확인하세요.

Outline에서는 사용자가 개인 정보를 제공하겠다고 선택하지 않는 한 개인 정보를 수집하지 않습니다. 또한 사용자가 방문하는 웹사이트, 통신하는 대상 또는 내용에 관한 정보도 수집하지 않습니다.

Outline Manager에서 서드 파티 클라우드 제공업체를 통해 계정을 만들거나 계정에 로그인하는 경우, Outline에서는 이메일 주소, 이름, 청구 정보, 결제 세부정보 등 사용자가 서드 파티 클라우드 제공업체에 제공하는 정보를 수집하지 않습니다.

Outline에서 자동으로 수집하는 정보

Outline에서는 두 가지 정보가 자동으로 수집됩니다.
1. 서버 IP
Outline 서버 IP는 Quay.io에 의해 수집되며, 최신 보안 및 기능 개선사항 등의 서버 자동 업데이트가 이뤄질 때 Outline에 액세스 권한이 부여됩니다. 서버 IP에서 클라우드 서버 제공업체와 Outline 서버가 설정된 도시의 식별이 가능할 수 있지만, 누가 서버를 실행 또는 액세스하는지에 대한 정보는 제공하지 않습니다.

2. 개인 식별이 불가능한 기술 정보
Outline이 비정상 종료되거나, 치명적인 예외가 발생하거나, 사용자가 Outline 앱을 통해 직접 의견을 보내는 경우 아래에 나열된 정보가 전송됩니다. 이 정보는 안정성 또는 성능 문제를 확인하고 해결하는 데만 사용됩니다.

  • 국가
  • 언어
  • 비정상 종료/예외 발생 날짜 및 시간과 직전 이벤트 최대 100건(예: 사용자가 '정보' 섹션을 열어봄 등)
  • 정적 컴파일된 예외 메시지
  • OS 이름 및 버전
  • 휴대전화 모델(해당하는 경우)
  • 앱 시작 시간
  • 브라우저
  • 아키텍처
  • Outline 버전 및 빌드 번호


이 정보는 HTTPS를 사용하여 서드 파티 오픈소스 오류 추적 제공업체인 Sentry(sentry.io)로 전송됩니다. Sentry에서는 다양한 업계 표준 기술 및 서비스를 사용하여 무단 액세스, 공개, 사용, 손실로부터 데이터를 보호합니다. Sentry의 정책에 대해 궁금한 점이 있는 경우 https://sentry.io/security/ 및 https://sentry.io/privacy/를 확인하거나 security@sentry.io에 문의하세요. Sentry에 저장된 모든 Outline 데이터는 Outline팀만 액세스할 수 있도록 제한됩니다.

사용자가 정보 제공을 선택한 경우 Outline에서 다음과 같은 정보를 Outline팀에 전송합니다.

데이터 한도 FAQ

30일 누적 데이터 한도란 무엇인가요?

30일 누적 데이터 한도는 지난 30일 동안 각 키에서의 데이터 사용량을 합산하고 이 기간에 대해 키의 데이터 사용량을 특정 한도 이하로 유지합니다. 키는 어떠한 30일의 기간 동안 한도를 초과할 수 없으며, 여기에는 30일 미만의 달도 포함됩니다. 사실상 이는 각 사용자가 사용할 수 있는 데이터가 31일 전에 사용한 양만큼 매일 늘어남을 의미합니다.

Outline에서 누적 한도를 사용하는 이유는 무엇인가요?

누적 한도는 30일의 기간마다 데이터 사용량을 일정 수준으로 확실하게 유지합니다. 즉, 반복 한도(한 달 중 특정 날짜로 맞춤설정하는 등)보다 간단하게 구성할 수 있으면서도 비슷한 수준의 제어를 제공합니다. 또한 Outline에서의 데이터 사용량을 보여주는 기존 디스플레이와 분석 서비스 및 서버 통계와 같은 일반적인 도구와도 어울립니다.

데이터 한도에 어떤 데이터가 집계되나요?

각 액세스 키의 서버 이그레스가 총계에 포함됩니다. 엄밀히 말하면 이는 키를 대신하여 서버 외부로 전송된 데이터 및 클라이언트로 다시 전송된 데이터를 의미합니다. 사실상 이 수치는 키에서 서버로 전송된 트래픽 및 서버에서 키로 다시 전송된 트래픽에 근접하므로, 이 수치가 사용자의 총계와 일치할 것으로 기대하고 있습니다. 설문조사를 실시한 결과 클라우드 제공업체는 이그레스에 대해 청구하므로 이그레스를 선택하였습니다.

사용자가 데이터 한도를 초과하면 알림이 전송되나요?

현재로서는 아닙니다. 많은 클라우드 제공업체에서는 1개월당 1TB와 같은 한도를 두고 있으며, 이러한 방식을 사용하면 10명의 사용자가 100GB를 사용하거나 100명의 사용자가 10GB를 사용할 수 있습니다. 이는 꽤 큰 수치이며, 이 한도를 초과하는 사용자가 많지 않을 것이라고 예상합니다. 한도에 도달한 사용자는 서버 관리자에게 직접 문의하도록 할 예정입니다. 그러나 알림이 귀하의 사용 사례에 어떤 도움이 될 수 있을지에 대해 의견을 제공해 주시기 바랍니다. 여기를 통해 연락해 주세요.

사용자가 데이터 한도에 근접하면 알림이 전송되나요?

데이터 한도에 가까워지는 사용자가 받게 될 새 데이터의 양은 해당 사용자의 30일 전 사용량에 따라 정해지므로 매일 다릅니다. 알림이 전송되면 최종 사용자에게 도움을 주기보다는 혼란을 야기할 수 있습니다. 여기에서 이 동작에 관한 의견을 보내주시기 바랍니다.

사용자의 데이터 사용량을 초기화할 수 있나요?

아니요. 사용자의 한도에는 항상 지난 30일간의 데이터 사용이 반영됩니다. 하지만 사용자의 키 데이터 한도를 높이거나 새로운 키를 만들 수는 있습니다.

데이터 한도를 사용 설정하자마자 일부 사용자가 액세스 권한을 잃은 이유는 무엇인가요?

데이터 한도는 사용자의 이전 30일간의 데이터 전송을 기반으로 하며, 30일간의 데이터 사용량은 데이터 한도 설정 여부와 관계없이 기록됩니다. 데이터 한도를 설정하기 전에 이미 해당 사용자가 한도를 초과했을 수 있습니다.  또한 하나의 키 데이터 한도를 변경하더라도 모든 데이터 한도가 시행됩니다.

'30일당 1TB'와 같이 서버 전체 한도를 설정할 수 있나요?

현재로서는 설정할 수 없습니다. 여기를 통해 귀하의 사용 사례에 대해 자세히 알려 주세요.

기본 데이터 한도와 특정 키 데이터 한도가 있는 경우 어떤 한도가 시행되나요?

특정 키의 데이터 한도가 사용자가 설정한 기본 데이터 한도(있는 경우)보다 우선 적용됩니다.

예.  하나의 키에 데이터 한도를 설정하려고 할 때 기본 한도가 필요하지는 않습니다.  예를 들어 키를 통한 과도한 데이터 전송을 방지하기 위해 널리 공유될 수 있는 특정 키에만 한도를 설정할 수 있습니다.

액세스 키로 Outline 서버 액세스 관리하기

GKMS WEB

Outline 서버 설치를 완료하면 사용자의 액세스 권한을 공유하고 관리할 수 있습니다. 초대를 받은 사용자는 Outline 앱을 다운로드한 다음 Outline을 사용해 인터넷 트래픽을 보호할 수 있습니다.

Outline 서버 액세스 권한 공유하기
Outline 서버 설치를 완료하면 Outline Manager의 서버 세부정보 페이지로 이동하며 여기에서 액세스 키를 생성할 수 있습니다. 액세스 키에 관해 자세히 알아보세요.

  • 키 생성: 페이지 하단에 있는 작은 '+' 아이콘을 클릭하여 새 키를 생성합니다.
  • 키 공유: 각 키의 오른쪽에 있는 공유 아이콘을 클릭하면 초대를 받을 수 있습니다. 이 초대를 복사하여 원하는 메시지 시스템에 붙여넣으세요.

기능 요청: Outline Manager 앱 내에서 액세스 권한 공유
많은 서버 관리자가 다른 사용자의 이메일 주소를 Outline Manager에 직접 입력하는 옵션을 제공하여 초대 과정을 간소화해 달라고 요청했습니다.

아쉽지만 해당 기능은 Outline Manager에 구현하지 않을 예정입니다. Outline의 핵심 원칙 중 하나는 사용자의 개인정보를 보호하고 보안을 강화하는 것입니다. 따라서 Outline에서는 이메일 주소 또는 연락처 정보를 삽입할 위치를 만들지 않았습니다.

그러므로 서버 관리자에게 이메일 또는 보안 채팅과 같은 안전한 메시지 플랫폼을 통해 최종 사용자에게 초대를 보내 주기를 요청합니다.

액세스 키를 공유받은 사용자가 거치는 단계

  1. 사용자가 자신의 기기에서 설치 링크를 클릭합니다.
  2. 사용자에게 Outline 앱이 없는 경우 Outline 앱을 설치하라는 메시지가 표시됩니다.
  3. 초대에 포함된 고유 키를 통해 Outline 서버와 초기 연결을 설정합니다.
  4. 연결/연결 해제 버튼을 사용하여 Outline 서버를 통해 인터넷 액세스 관리가 가능해집니다.

Outline 서버 액세스 권한 삭제
Outline Manager의 서버 세부정보 페이지를 보면, 서버에 있는 모든 키의 오른쪽에 키를 삭제할 수 있는 옵션이 포함된 메뉴가 표시됩니다. 키를 삭제하면 서버 액세스 권한이 삭제됩니다.

Debian 기반 Linux 배포판용 Outline 클라이언트 설치하기(권장)

 

다음 명령어를 실행합니다.

  1. Outline의 저장소 키를 설치하고 저장소를 추가합니다.

    wget -qO- https://us-apt.pkg.dev/doc/repo-signing-key.gpg | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/gcloud-artifact-registry-us.gpg

    echo "deb [arch=amd64] https://us-apt.pkg.dev/projects/jigsaw-outline-apps outline-client main" | sudo tee /etc/apt/sources.list.d/outline-client.list

  2. apt 패키지 목록을 업데이트하고 최신 버전의 Outline 클라이언트를 설치합니다.

    sudo apt update

    sudo apt install outline-client

향후 업데이트를 확인하거나 설치하려면 2단계의 명령어를 다시 실행합니다. 버전 1.15부터 Linux의 Outline 클라이언트에서는 인앱 자동 업데이트가 사용 중지된다는 점을 참고하세요.

Outline 클라이언트를 제거하려면 다음 명령어를 실행합니다.

sudo apt purge outline-client

  2. 명령줄에서 다음 명령어를 실행하여 패키지를 설치합니다.

    wget -O ./outline-client.deb https://s3.amazonaws.com/outline-releases/client/linux/stable/outline-client_amd64.deb

Outline 서버는 어떻게 설정하나요?

GKMS WEB

Outline을 사용하기 위한 첫걸음은 Outline 서버를 설정하는 것입니다. Outline을 통해 개방형 인터넷에 연결하려면 나 또는 신뢰할 수 있는 다른 사용자가 나를 대신해 서버를 설정해야 합니다.

시작하기 전에

Outline 서버를 설정하기 전에 다음과 같은 몇 가지 준비가 필요합니다.

  1. 자체 서버 또는 DigitalOcean, Amazon Web Services(AWS), Google Cloud Platform(GCP)과 같은 클라우드 서비스 제공업체에 대한 액세스
    클라우드 서버에 즉시 액세스할 수 없는 경우 위에 나열된 제공업체를 포함해 다양한 제공업체를 통해 계정을 손쉽게 설정할 수 있습니다. 가입하려면 신용카드가 필요합니다.
  2. macOS 10.9 이상, Windows 7.0 이상 또는 Linux를 실행하는 데스크톱 컴퓨터
  3. Outline Manager 애플리케이션

DigitalOcean을 통한 설정

DigitalOcean에서 누구나 클릭 몇 번만으로 Outline을 손쉽게 설치할 수 있습니다. 컴퓨터에 Outline Manager를 다운로드 및 설치한 다음 DigitalOcean 설정 옵션을 선택하면 간단한 화면 몇 개를 통해 Outline 서버를 구성하고 설치할 수 있습니다.

다른 클라우드 제공업체를 통한 설정

Outline Manager를 다운로드 및 설치한 다음 AWS, GCP, DigitalOcean 또는 다른 제공업체를 선택해 가상 머신을 기반으로 Outline 서버를 설치할 수 있습니다. 모든 환경은 서로 다르기 때문에 Outline Manager 설정 과정을 통해 일반적인 대부분의 클라우드 제공업체를 대상으로 한 안내를 제공했으며, 서버에 Outline을 설치하기 위해 설치 스크립트를 실행하기 전에 가상 머신의 설정을 구성하는 방법도 포함되어 있습니다.

여러 개의 Outline 서버 설정 방법

GKMS WEB
추가로 Outline 서버를 설정하려면 Outline Manager 애플리케이션의 왼쪽에 있는 탐색 패널에서 '+' 아이콘을 클릭합니다. 새 서버를 추가하는 방법은 처음 서버를 설치하는 방법과 동일합니다.
  • 사용자가 만들 수 있는 Outline 서버의 수에는 제한이 없습니다.
  • 생성하는 모든 Outline 서버에는 관련된 가상 머신이 필요합니다.
  • 추가 가상 머신 또는 Droplet을 만들면 클라우드 제공업체에 지불할 수수료가 증가할 수 있습니다. 예상 수수료를 확인하려면 클라우드 제공업체의 가격 패키지를 참고하세요.

DigitalOcean에서 추가 Outline 서버 만들기

이러한 권한을 제공하지 않으려면 Outline Manager의 고급 설정 안내에 따라 Google Cloud Platform에서 Outline을 실행하세요.

부여된 권한

자동 설정을 제공하려면 Outline Manager에서 Google 계정으로부터 다음 권한을 요구합니다.

Google Cloud Platform

  • Google Compute Engine 리소스 조회 및 관리
  • Google Cloud 서비스 전체 데이터 조회 및 Google 계정 이메일 주소 확인

기본 계정 정보

  • 기본 Google 계정 이메일 주소 확인
  • Google에서 내 개인 정보를 나와 연결

추가 액세스

  • Cloud Platform 프로젝트 관리
  • Google Cloud Platform 결제 계정 조회 및 관리
  • Google API 서비스 구성 관리

이러한 권한을 통해 Google은 다음과 같은 Outline 서버 관리를 위한 고급 기능을 지원할 수 있습니다.

  • 정확한 결제 계정을 선택하도록 지원
  • Outline 서버를 정리하기 위한 새 프로젝트 생성
  • 사용 가능한 데이터 센터 나열
  • Outline을 실행할 새 가상 머신 생성
  • Outline으로 새 가상 머신 구성

권한 취소

내 계정을 방문하여 Outline Manager용 Google Cloud Platform에 관한 액세스 권한을 취소할 수 있습니다. 액세스 권한을 취소하면 자동 설정으로 만든 모든 서버가 계속 실행되지만 Outline Manager에는 더 이상 표시되지 않습니다. 액세스 권한을 복원하려면 자동 설정 과정을 시작하여 Google Cloud Platform에 다시 연결하세요.

Outline 프로젝트 조직

Google Cloud 자동 설정에서는 단일 Google Cloud 프로젝트를 사용하여 Outline 서버를 정리합니다. 프로젝트는 자동 설정을 처음 사용하는 동안 생성되며 ‘Outline-’ 뒤에 임의의 문자가 오는 추천 프로젝트 ID로 생성됩니다. 원하는 경우 생성 시 다른 프로젝트 ID를 선택할 수 있습니다. 프로젝트 이름은 ‘Outline 서버’로 지정됩니다.

결제 계정

Google Cloud 프로젝트에는 결제 정보를 정의하는 연결된 '결제 계정'이 필요합니다. Google Cloud 자동 설정을 처음 사용할 때 Outline 서버와 연결할 결제 계정을 제공하라는 메시지가 표시됩니다. 결제 계정에 문제가 있어 서버 실행이 중지되는 경우가 있습니다. 이 경우 Google Cloud Console에 로그인하여 Outline과 연결된 Google Cloud 프로젝트(‘Outline 서버’라고 함)를 찾아 결제 설정을 업데이트해야 합니다.

서버 폐기

자동 설정을 사용하여 생성된 서버를 폐기하려는 경우 Outline Manager 내에서 가장 간편하게 폐기할 수 있습니다. 하지만 서버를 직접 폐기하려면 Google Cloud Console에 로그인하여 초기 설정 중에 생성된 프로젝트(‘Outline 서버’라고 함)를 찾아 리소스를 삭제하거나 프로젝트를 종료할 수 있습니다.

서버 없이 Outline을 사용할 수 있나요?

아니요. Outline 소프트웨어는 사용자, 조직, 신뢰할 수 있는 제3자 등 서버를 관리하는 주체와 관계없이 서버에 액세스할 수 있어야 합니다.

Outline 서버를 설정하는 데 얼마나 오래 걸리나요?

대부분의 경우 5분 미만입니다. 어떤 클라우드 서버에서든 Outline을 설치할 수 있습니다. 하지만 Outline에서는 DigitalOcean과 협력하여 좀 더 사용자 친화적이고 친절한 안내가 제공되는 설치 환경을 제공하고 있습니다. 스크립트 없이 클릭 몇 번 만에 설정할 수 있습니다.

AWS, GCP 또는 고급 설정을 선택하셨나요? Outline에서는 서버 설치 과정을 하나의 스크립트로 간소화했으며 대부분의 경우 이 스크립트 하나면 충분합니다.

Outline 서버를 어디에서 설정할 수 있나요?

대부분의 클라우드 제공업체의 경우 운영되는 곳 어디에서나 Outline 서버를 설정할 수 있습니다.

암스테르담, 토론토, 샌프란시스코, 싱가포르와 같이 여러 위치에 서버를 보유하고 있는 DigitalOcean을 사용해 서버를 설정하는 것이 가장 쉽습니다. 다른 클라우드 제공업체나 자체 인프라에서 설치하려는 경우, Outline Manager 애플리케이션에서 ‘고급 모드’를 선택하고 설정 스크립트를 통한 설치 안내를 따르면 됩니다

Outline 서버를 어디에 설정해야 하나요?

Outline 서버의 위치를 선택하기 전에 다음과 같은 몇 가지 사항을 고려해 보아야 합니다.

  1. Outline 서버의 위치는 사용자가 인터넷을 사용하는 방식에 영향을 줍니다. 예를 들어 서버가 암스테르담에 있는 경우 이 서버에 액세스하는 사용자는 실제로 네덜란드에 있는 것처럼 인터넷을 경험하게 됩니다. 일부 웹사이트가 네덜란드어로 표시될 수도 있습니다. 일반적인 경우 웹사이트의 언어 선택기를 사용하면 현지 언어를 재정의할 수 있습니다.

  2. 사용자와 Outline 서버 간의 거리가 속도에 영향을 미칠 수 있습니다. 일반적으로 Outline 사용자와 서버 간의 거리가 사용자의 인터넷 속도에 영향을 주기도 합니다. 대부분의 경우 사용자의 예상 위치에 가장 가까운 서버 위치를 선택하면 됩니다. 하지만 해저 케이블 지도를 확인하면 선택한 국가 또는 지역에 어떤 인터넷 케이블이 연결되어 있는지 볼 수 있습니다.

  3. VPN 서버의 위치가 법적 프레임워크에 영향을 줄 수 있습니다. Outline 소프트웨어는 트래픽을 기록하지 않습니다. Outline 사용 시 보안 및 개인정보 보호에 관해 자세히 알아보세요.

방화벽 문제에는 다음과 같은 세 가지 유형이 있을 수 있습니다.

네트워크 방화벽에 의해 차단되는 경우

학교나 직장과 같이 방화벽이 있는 네트워크에 연결된 상태에서 Outline을 설치하려는 경우 다른 네트워크에서 설치를 진행해 보세요.

이 방법으로 문제가 해결되지 않으면 네트워크 관리자에게 방화벽이 있는 네트워크에서 Outline 서버에 연결할 수 있는지 문의하세요. Outline 서버의 IP 주소와 Outline이 실행되는 포트(설치 스크립트 마지막 부분에 표시됨)를 알아야 합니다.

기기 방화벽에 의해 차단되는 경우

기기에 비표준 포트 또는 인식할 수 없는 소프트웨어의 발신 연결을 차단하는 소프트웨어(예: CheckPoint의 ZoneAlarm)가 있는 경우 기기 또는 소프트웨어 문서에서 Outline에 적용할 예외를 만드는 방법이 있는지 확인하세요.

서버 방화벽에 의해 차단되는 경우

사용 중인 클라우드 공급업체에서 Outline이 실행되는 포트를 열기 위해 사용자에게 서버 방화벽 예외를 직접 만들도록 요청할 수 있습니다. 설치 스크립트 실행을 마치면 서버에 Outline이 실행되는 포트 2개가 무작위로 선택되어 표시되어야 합니다. 이 포트 2개를 열면 충분합니다.

서버 방화벽 예외를 만들 때는 'ufw' 및 'iptables' 도움말을 참고하세요.
