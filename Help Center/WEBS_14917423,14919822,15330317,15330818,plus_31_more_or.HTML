Linuxରେ Outline Client ଇନଷ୍ଟଲ କରିବା

GKMS WEB

Outline Client ଭର୍ସନ 1.15ରୁ ଆରମ୍ଭ କରି ଭବିଷ୍ୟତର ସମସ୍ତ ଭର୍ସନ Linux ଅପରେଟିଂ ସିଷ୍ଟମ ପାଇଁ Debian ପେକେଜ ଭାବେ ରିଲିଜ କରାଯିବ। ଆମେ ସପୋର୍ଟ କରୁଥିବା ଅପରେଟିଂ ସିଷ୍ଟମ ବିଷୟରେ ଅଧିକ ସୂଚନା ପାଇଁ ଆମ ସର୍ବନିମ୍ନ ସିଷ୍ଟମ ଆବଶ୍ୟକତାଗୁଡ଼ିକର ସମୀକ୍ଷା କରନ୍ତୁ।

 

Debian-ଆଧାରିତ Linux ଡିଷ୍ଟ୍ରିବ୍ୟୁସନ ପାଇଁ Outline Client ଇନଷ୍ଟଲ କରନ୍ତୁ (ସୁପାରିଶ କରାଯାଇଛି)

 

ନିମ୍ନୋକ୍ତ କମାଣ୍ଡଗୁଡ଼ିକୁ ଚଲାନ୍ତୁ:

  1. Outlineର ରିପୋଜିଟୋରୀ କୀ ଇନଷ୍ଟଲ କରି ରିପୋଜିଟୋରୀ ଯୋଗ କରନ୍ତୁ।

    wget -qO- https://us-apt.pkg.dev/doc/repo-signing-key.gpg | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/gcloud-artifact-registry-us.gpg

    echo "deb [arch=amd64] https://us-apt.pkg.dev/projects/jigsaw-outline-apps outline-client main" | sudo tee /etc/apt/sources.list.d/outline-client.list

  2.  ଏପିଟି ପେକେଜ ତାଲିକା ଅପଡେଟ କରି Outline Clientର ନବୀନତମ ଭର୍ସନ ଇନଷ୍ଟଲ କରନ୍ତୁ।

   sudo apt update

   sudo apt install outline-client

ଭବିଷ୍ୟତର ଅପଡେଟଗୁଡ଼ିକୁ ଯାଞ୍ଚ କରିବା କିମ୍ବା ଇନଷ୍ଟଲ କରିବାକୁ, ଷ୍ଟେପ 2ରେ କମାଣ୍ଡଗୁଡ଼ିକୁ ପୁଣି ଚଲାନ୍ତୁ। ଧ୍ୟାନ ଦିଅନ୍ତୁ ଯେ ଭର୍ସନ 1.15ରୁ ଆରମ୍ଭ ହେଉଥିବା Linuxରେ Outline Client ପାଇଁ ଇନ-ଆପ ସ୍ୱତଃ-ଅପଡେଟକୁ ଅକ୍ଷମ କରାଯାଇଛି।

Outline Clientକୁ ଅନଇନଷ୍ଟଲ କରିବା ପାଇଁ ନିମ୍ନୋକ୍ତ କମାଣ୍ଡଗୁଡ଼ିକୁ ଚଲାନ୍ତୁ:

sudo apt purge outline-client

ଅନ୍ୟ ବିକଳ୍ପ

  1. https://s3.amazonaws.com/outline-releases/client/linux/stable/outline-client_amd64.debରୁ ନବୀନତମ Outline Client Debian ପେକେଜ ଡାଉନଲୋଡ କରନ୍ତୁ
  2. ପେକେଜ ଇନଷ୍ଟଲ କରିବାକୁ କମାଣ୍ଡ ଲାଇନରେ ନିମ୍ନୋକ୍ତ କମାଣ୍ଡଗୁଡ଼ିକୁ ଚଲାନ୍ତୁ

wget -O ./outline-client.deb https://s3.amazonaws.com/outline-      releases/client/linux/stable/outline-client_amd64.deb

sudo apt install ./outline-client.deb

  3.  ଭର୍ସନ 1.15ରୁ ଆରମ୍ଭ ହେଉଥିବା Linuxରେ Outline Client ପାଇଁ ଇନ-ଆପ ସ୍ୱତଃ-ଅପଡେଟକୁ ଅକ୍ଷମ କରାଯାଇଥିବା ଭାବେ ମାନୁଆଲୀ ଅପଡେଟ ଯାଞ୍ଚ କରନ୍ତୁ।

  4.  Outline Clientକୁ ଅନଇନଷ୍ଟଲ କରିବା ପାଇଁ କମାଣ୍ଡ ଲାଇନରେ ଥିବା ନିମ୍ନୋକ୍ତ କମାଣ୍ଡଗୁଡ଼ିକୁ ଚଲାନ୍ତୁ:

sudo apt purge outline-client

ହଁ। ଆପଣଙ୍କର ଏକାଧିକ ଡିଭାଇସରେ ଆପଣ ଆପଣଙ୍କ ଆକ୍ସେସ କୀ ବ୍ୟବହାର କରିପାରିବେ, କିନ୍ତୁ ଆପଣଙ୍କ କୀ ଅନ୍ୟ କୌଣସି ବ୍ୟକ୍ତିଙ୍କ ସହ ସେୟାର କରନ୍ତୁ ବୋଲି ଆମେ ସୁପାରିଶ କରୁନାହୁଁ। ଯଦି ଆପଣଙ୍କ ଆକ୍ସେସ କୀ ଥିବା କୌଣସି ବ୍ୟକ୍ତିଙ୍କର ଏହାକୁ ଆକ୍ସେସ ଅଛି, ତେବେ ସେ ସମ୍ଭବତଃ ଆପଣଙ୍କ ସମସ୍ତ ଇଣ୍ଟର୍ନେଟ ଟ୍ରାଫିକକୁ ନିରୀକ୍ଷଣ କରିପାରନ୍ତି, ଯାହା ଆଉ ଆପଣଙ୍କ ଇଣ୍ଟର୍ନେଟ ବ୍ୟବହାରକୁ ସୁରକ୍ଷିତ କିମ୍ବା ପ୍ରାଇଭେଟ ରଖେ ନାହିଁ।

ମୁଁ କିପରି ଏକ ଆକ୍ସେସ କୀ ପାଇପାରିବି?

Outline ସେହି VPN ସେବାଗୁଡ଼ିକ ପରି ନୁହେଁ ଯାହା ପାଇଁ ଆପଣ ଆକ୍ସେସ କ୍ରୟ କରନ୍ତି; ଏହା ଏକ ଟୁଲ ଯାହା ଆପଣଙ୍କୁ ଏକ ପ୍ରାଇଭେଟ VPN ସର୍ଭର ଚଲାଇବା ଏବଂ ଆକ୍ସେସ ସେୟାର କରିବାକୁ ଦିଏ। ଜଣେ ସେବା ପରିଚାଳକ ହେଉଛନ୍ତି ଏକମାତ୍ର ବ୍ୟକ୍ତି ଯିଏ ଏକ ଆକ୍ସେସ କୀ ପ୍ରଦାନ କରିପାରିବେ। Outline ଟିମ ମାଗଣା କିମ୍ବା ଦେୟଯୁକ୍ତ ଆକ୍ସେସ କୀଗୁଡ଼ିକୁ ଡିଷ୍ଟ୍ରିବ୍ୟୁଟ କରେ ନାହିଁ। ଫାର୍ସି ଭାଷାରେ Paskoocheh ବ୍ୟତୀତ ଆମର କୌଣସି ଅଫିସିଆଲ Outline ଆକ୍ସେସ କୀ ପାର୍ଟନର ନାହିଁ।

ଏକ ଆକ୍ସେସ କୀ ପାଇବା ପାଇଁ ଏଠାରେ ତିନୋଟି ବିକଳ୍ପ ଅଛି: 

  • କୌଣସି ବ୍ୟକ୍ତିଙ୍କୁ ତାଙ୍କ ସର୍ଭରକୁ ଆପଣଙ୍କୁ ନିମନ୍ତ୍ରଣ କରିବାକୁ କୁହନ୍ତୁ: ଯଦି ଆପଣ Outline ସର୍ଭର ଥିବା କୌଣସି ବ୍ୟକ୍ତିଙ୍କୁ ଜାଣନ୍ତି, ତେବେ ତାଙ୍କୁ କଣ୍ଟାକ୍ଟ କରି ଏକ ଆକ୍ସେସ କୀ ମାଗନ୍ତୁ।
  • ନିଜେ ଏକ ସର୍ଭର ତିଆରି କରନ୍ତୁ: ଏକ Windows, Mac କିମ୍ବା Linux କମ୍ପ୍ୟୁଟର ବ୍ୟବହାର କରି Outline ମେନେଜର ଡାଉନଲୋଡ କରନ୍ତୁ ଏବଂ ଆପଣଙ୍କ ନିଜର ପ୍ରାଇଭେଟ Outline ସର୍ଭର ସେଟ ଅପ କରନ୍ତୁ। ଆମେ ଏହି ପ୍ରକ୍ରିୟାକୁ ସମସ୍ତଙ୍କ ପାଇଁ ସହଜ କରିଛୁ, ବିଶେଷକରି କ୍ଲାଉଡ ସେବା ପ୍ରଦାନକାରୀ DigitalOcean ମାଧ୍ୟମରେ।
  • ଏକ Outline କିମ୍ବା Shadowsocks ସେବା ବ୍ୟବହାର କରନ୍ତୁ: Outline କ୍ଲାଏଣ୍ଟକୁ Outline କିମ୍ବା Shadowsocks ପ୍ରୋଟୋକଲ ବ୍ୟବହାର କରୁଥିବା ତୃତୀୟ-ପକ୍ଷ ସେବା ସହିତ ମଧ୍ୟ ବ୍ୟବହାର କରାଯାଇପାରିବ। ଉଦାହରଣ ସ୍ଵରୂପ:
    • nthLink Outline କ୍ଲାଏଣ୍ଟର ଏକ ପରିବର୍ତ୍ତିତ ଭର୍ସନ ସହିତ Outline ଉପରେ ଆଧାରିତ ଏକ ମାଗଣା ସେବା ଚଲାଏ।
    • ASL19 BeePass ନାମକ Outlineର ଏକ ପରିବର୍ତ୍ତିତ ଭର୍ସନ ସହିତ ଏକ Telegram ବଟ ଚଲାଏ ଯାହା BeePass ସର୍ଭରଗୁଡ଼ିକୁ ମାଗଣା ଆକ୍ସେସ କୀ ପ୍ରଦାନ କରେ।
    • ଫାର୍ସି ଭାଷାର ୟୁଜରମାନେ ASL19ର Paskoochehରୁ ଏକ Outline ଆକ୍ସେସ କୀ ପାଇଁ ମଧ୍ୟ ଅନୁରୋଧ କରିପାରିବେ।

Outline Client ଆପ ଡାଉନଲୋଡ କରିବା ପରେ, Outline ସର୍ଭର ସହ କନେକ୍ଟ କରିବାକୁ ଆପଣଙ୍କ ଆକ୍ସେସ କୀ'କୁ କପି କରି Outline Clientରେ ପେଷ୍ଟ କରନ୍ତୁ।
