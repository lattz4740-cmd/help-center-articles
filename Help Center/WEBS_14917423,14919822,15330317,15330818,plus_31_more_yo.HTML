GKMS WEB

Ààbò àti ìpamọ́ nígbà tí o bá ń lo Outline

Bí Outline ṣe ń dáàbò bo àwọn ìbánisọ̀rọ̀ rẹ lórí ayélujára

Lílọ-bíbọ̀ lórí ìtàkùn ayélujára máa ń tètè di èyí tí wọ́n ń tọpinpin nígbà tí ó bá ń kọjá lórí ìtàkùn abẹ́lé tàbí ti gbogbo orílẹ̀-èdè.

Outline máa ń ṣe ìrànlọ́wọ́ láti fi ìbánisọ̀rọ̀ rẹ sí ìpamọ́ nípasẹ̀ fífi lílọ-bíbọ̀ rẹ lórí ìtàkùn ayélujára sí ìkọ̀kọ̀ nígbà tí ó bá ń rìnrìn àjò nínú ìtàkùn ayélujára orílẹ̀-èdè rẹ, ó sì máa fi pamọ́ títí tí ó máa fi dé orí olùpèsè Outline. Nígbà tí lílọ-bíbọ̀ bá wà ní ìkọ̀kọ̀ pẹ̀lú Outline, àwọn tó ń wo àsopọ̀ lórí ẹ̀rọ kò lè wo àwọn ìkànnì ayélujára tí o bá lọ, tàbí ìsọfúnni tí o ń fi ránṣẹ́.

Outline tún lè ràn ọ́ lọ́wọ́ láti rí àyè padà sí àwọn ohun èlò ìbánisọ̀rọ̀ tí ó ní ààbò tí ó lè má ṣeé rí ní orílẹ̀-èdè rẹ. 

Àwọn ìlànà ìpamọ́

Outline ń fi ìbánisọ̀rọ̀ láàrin ẹ̀rọ rẹ àti Olùpèsè Outline sí ìdákọ́nkọ́ nípasẹ̀ lílo ọ̀rọ̀ ìdákọ́nkọ́ AEAD 256-bit Chacha2020 IETF Poly 1305. Àwọn ọ̀rọ̀ ìdákọ́nkọ́ AEAD máa ń fúnni ní ìpamọ́ àṣirí, ìdúróṣinṣin, àti ìjẹ́ ojúlówó, ó sì máa ń ṣe iṣẹ́ dáadáa lórí ohun èlò ìgbàlódé. 

Àwọn àyẹ̀wò ààbò

Ní ọdún 2018, àwọn àjọ Radically Open Security àti Cure53, àwọn àjọ elétò ààbò díjítà olómìnira méjì tí wọ́n ń ṣe àgbéyẹ̀wò ohun èlò ẹ̀rọ ní ìbámu pẹ̀lú àwọn ìlànà ààbò tuntun, ni wọ́n ṣe àyẹ̀wò Outline. Radically Open Security ṣe àyẹ̀wò àfikún kan ní ọdún 2022 tí Cure53 sì ṣe àyẹ̀wò Outline SDK ní ọdún 2024. O lè ka àwọn ìjábọ̀ náà níbí:

  • Ìjábọ̀ àyẹ̀wò Radically Open Security Penetration (Oṣù kẹẹ̀ta ọdún 2018)
  • Ìjábọ̀ Pentest àti àyẹ̀wò Cure53 ti Jigsaw Outline (Oṣù kejìlá ọdún 2018)
  • Ìjábọ̀ àyẹ̀wò Radically Open Security Penetration (Oṣù kejìlá ọdún 2022)
  • Ìjábọ̀ Cure53 Pentest ti Jigsaw Outline VPN SDK (Oṣù kínní ọdún 2024)

Àwọn ìṣirò àti àwọn àkọsílẹ̀ ẹni tí a kò mọ̀

Outline ń tọpinpin ìwọ̀n dátà tí a lò, gẹ́gẹ́ bíi "àwọn ìwọ̀n báìtì tí a fi ránṣẹ́" fún kọ́kọ́rọ́ ìráyè sí kọ̀ọ̀kan. Àlàyé yìí ń gba àwọn alákòóso olùpèsè láàyè láti ṣàtúnṣe àwọn ìforúkọsílẹ̀ ìwọ̀n dátà wọn pẹ̀lú àwọn olùpèsè ìpèsè ibùdó ìpamọ́ dátà, ṣùgbọ́n kò kí ń gbà wọ́n láàyè láti wo àlàyé gangan tó gba olùpèsè Outline kọjá.

Mọ̀ síi nípa dátà Outline àti àkójọ ìsọfúnni.

Àwọn ìbéèrè tó sábà máa ń wáyé lórí ààbò àti ìpamọ́ 

Ǹjẹ́ Outline lè sọ mí di ẹni tí a kò mọ̀ lórí ayélujára?

Rárá o, Outline kì í ṣe ohun èlò àìdánimọ̀. Outline ń dáàbò bo ìkọ̀kọ̀ rẹ kúrò lọ́wọ́ àwọn tó lè máa wò ọ́ lórí ẹ̀rọ.

Outline kò ní fún ọ ní ẹ̀kúnrẹ́rẹ́ àìdánimọ̀ ní àwọn ojú-òpó ayélujára tí o bá lọ, nítorí wọ́n ṣì lè dá ọ mọ̀ nígbà tí o bá wọlé àti nígbà mìíràn nípasẹ̀ àwọn ọ̀nà, bíi ọ̀nà àkójọ àlàyé aṣàwákiri. Fún àwọn áàpù orí ẹ̀rọ alágbèéká, ọ̀pọ̀lọpọ̀ àwọn fóònù ayárabíàṣá ìgbàlódé ní àwọn API tí ó ń jẹ́ kí àwọn ohun èlò tí wọ́n fi sórí ẹ̀rọ gba ibi tí o wà lọ́wọ́ láì sí àtìlẹ́yìn aṣojú rẹ, nítorí wọ́n lè gbára lé GPS tí ó wà nínú rẹ̀

Àwọn VPN lápapọ̀ máa ń pèsè àwọn ààbò pàtàkì, pàápàá kúrò lọ́wọ́ ìtọpinpin orí ayélujára, àmọ́ àwọn ewu sábà máa ń wà nínú ṣíṣe iṣẹ́ lórí ayélujára. Kódà pẹ̀lú VPN, bí ISP bá ti mọ ẹni tí o jẹ́, tí ó sì ríbi wo lílọ-bíbọ̀ rẹ lórí ìtàkùn ayélujára, ó lè mọ àdírẹ́sì IP olùpèsè Outline rẹ. Wọ́n lè lo àlàyé yìí láti dènà ìrááyè sí olùpèsè Outline tàbí kọ́ àwọn ìlànà ìlò, bíi ìgbà tí o sábà máa ń wà lórí ayélujára àti bóyá sàkání ibi tí o wà. 

Ǹjẹ́ ẹnìkan lè mọ̀ tí mo bá ń lo Outline?

Ó ṣeé ṣe. Àwọn ìkànnì àti àwọn iṣẹ́ tí o bá wọlé sí ni ó ṣeé ṣe kí wọ́n mọ̀ pé ìsopọ̀ ayélujára rẹ ń wá láti inú olùpèsè ibùdó ìpamọ́ dátà kan. Ní ẹ̀kọ̀ọ̀kan, wọ́n lè mọ̀ pé ò ń lo VPN, àmọ́ wọn kò ní lè rí àwọn àkóónú lílọ-bíbọ̀ orí ìtàkùn ayélujára rẹ. 

Ṣé Outline ń dáàbò bò mí kúrò lọ́wọ́ gbogbo ewu tó ṣeé ṣe kó wáyé lórí ìtàkùn ayélujára?

Rárá o. Kò sí irinṣẹ́ kan tó lè dáàbò bò ẹ́ lọ́wọ́ gbogbo ewu tó ṣeé ṣe kó wà lórí ayélujára. Outline ń fún ọ ní ààyè sí orí ìtàkùn ayélujára tí ó ṣí sílẹ̀, ó sì ń mú àlékún bá ìkọ̀kọ̀ rẹ nípa fífi lílọ-bíbọ̀ rẹ pamọ́, ṣùgbọ́n a dábàá kí o fi kún ìṣọ́ra rẹ láti dáàbò bo ara rẹ kúrò lọ́wọ́ àwọn onírúurú àkọlù mìíràn, bíi aṣejànbá àti gbígba àlàyé ẹni ní ọ̀nà àrékérekè.

Láti lè mú àwọn ààbò orí ayélujára rẹ lágbara, jọ̀wọ́ rò ó láti ṣiṣẹ́ pẹ̀lú akọ́ṣẹ́mọṣẹ́ létò ààbò ayélujára ti àjọ rẹ. Tàbí, o lè gba ìtọ́sọ́nà tí a ṣe ní àdáni láti ọ̀dọ àwọn àgbà-ọ̀jẹ̀ akọ́ṣẹ́mọṣẹ́ létò ààbò ní Security Planner, ojú òpó wẹ́ẹ̀bù kan tí a ṣe láti fún ọ ní àwọn ìtọ́nisọ́nà kedere lóríi yíyan àwọn irinṣẹ́ ààbò ayélujára tí ó tọ́ fún àwọn ìfiyèsí rẹ.

O tún lè wo àwọn àgbéjáde ààbò orí ayélujára mìíràn láti ọwọ́ Jigsaw, bíi Intra, Project Shield, àti Password Alert. 

Ṣé ó bófin mu láti lo VPN?

Jọ̀wọ́ wo àwọn òfin agbègbè rẹ, àwọn ìlànà, àti àwọn òfin iṣẹ fún olùpèsè ibùdó ìpamọ́ dátà tí o gbèrò láti lò ṣáájú lílo Outline tàbí lílo áàpù ọ̀hún.

GKMS ARTICLE TITLE
Báwo ni mo ṣe lè ṣètò gbèdéke dátà lórí àwọn kọ́kọ́rọ́ ìwọlé?

GKMS WEB

O lè ṣètò gbèdéke dátà tó máa wà fún gbogbo àwọn kọ́kọ́rọ́ ìwọlé. Láti ṣètò gbèdéke náà, ṣí Outline Manager, kí o sì lọ sí Àwọn ètò. Níbẹ̀, o máa rí bọ́tìnnì gbèdéke dátà tó jẹ́ pé, nígbà tí o bá tàn-án, ó máa jẹ́ kí o lè ṣètò gbèdéke.

Ní kété tí o bá ti ṣètò gbèdéke, o lè rí i bí ẹnìkọ̀ọ̀kan ṣe sún mọ́ gbèdéke náà sí ní ojú-ìwé kọ́kọ́rọ́ ìwọlé, níbi tí àtẹ ìsọfúnni kan ti ń ṣàfihàn ìlo dátà ní ọjọ́ 30 tó kọjá.

Ní àfikún sí àti lè ṣètò gbèdéke fún gbogbo àwọn kọ́kọ́rọ́ ìwọlé rẹ, o lè fún kọ́kọ́rọ́ ìwọlé kọ̀ọ̀kan ní gbèdéke dátà rẹ̀. Ètò yìí máa borí èyíkéyìí gbèdéke dátà ìpilẹ̀ṣẹ̀ tí o ti ṣètò, ṣùgbọ́n tí o kò báì tíì ṣètò gbèdéke dátà ìpilẹ̀ṣẹ̀ kankan, o ṣì lè ṣètò gbèdéke dátà fún èyíkéyìí kọ́kọ́rọ́. 

Láti ṣètò gbèdéke ìfiránṣẹ́ datà ti kọ́kọ́rọ́ kan, ṣí Outline Manager, lọ sí táàbù àwọn Ìsopọ̀ tí kọ́kọ́rọ́ tí o fẹ́ ṣètò wà nínú rẹ̀, kí o sì tẹ àkójọ-àṣàyàn ní apá ọ̀tún ìlà-ìbú kọ́kọ́rọ́ náà. Láti ibẹ̀, tẹ Gbèdéke dátà. Láti yí gbèdéke dátà padà lóríi "Kọ́kọ́rọ́ ìwọlé mi", tẹ àmì àwọn Gbèdéke dátà náà .

Yan ṣètò gbèdéke dátà àkànṣe kan. Ní kété tí o bá ti yan àpótí yìí, ààyè kan máa hàn níbi tí o ti lè ṣètò àkànṣe gbèdéke dátà fún kọ́kọ́rọ́ ọ̀hún. Tẹ bọ́tìnnì FI PAMỌ́ nígbà tí o bá ṣetán láti fi gbèdéke dátà náà pamọ́.

Ní kété tí o bá ti fi gbèdéke ìfiránṣẹ́ dátà rẹ pamọ́ fún kọ́kọ́rọ́ tí o yàn, gbèdéke náà máa hàn ní ojú-ìwòran àkọ́kọ́, lẹ́gbẹ̀ẹ́ ìlò dátà (ní ọjọ́ 30 tó kọjá) fún kọ́kọ́rọ́ kọ̀ọ̀kan.

Látì yọ gbèdéke dátà náà kúrò nínú kọ́kọ́rọ́ ìwọlé kan, lọ sí àpótí Gbèdéke dátà kọ́kọ́rọ́ náà bíi ti tẹ́lẹ̀, yọ àmì kúrò nínú àpótí tí a pè ní Ṣètò gbèdéke dátà àkànṣe, kí o sì tẹ bọ́tìnnì FI PAMỌ́.

Àwọn ìbéèrè tó wọ́pọ̀ nípa gbèdéke dátà

Kí ni gbèdéke dátà àtẹ̀yìnwá ọlọ́jọ́ 30?

Gbèdéke dátà àtẹ̀yìnwá ọlọ́jọ́ 30 máa ro àròpọ̀ ìlò kọ́kọ́rọ́ kọ̀ọ̀kan ní ọjọ́ 30 sẹ́yìn, ó sì máa mú kí ìlò kọ́kọ́rọ́ náà ní àkókò ọ̀hún wà lábẹ́ gbèdéke. Ìyọrísí rẹ̀ ni pé kọ́kọ́rọ́ náà kò lè kọjá gbèdéke náà ní èyíkéyìí ìgbà tó bá ń pé ọjọ́ 30, títí kan àwọn oṣù kàlẹ́ńdà tó jẹ́ ọjọ́ 30 tàbí tí kò tó bẹ́ẹ̀. Ní ṣíṣe, èyí túmọ̀ sí pé iye dátà tó wà lárọ̀ọ́wọ́tó olùṣàmúlò kọ̀ọ̀kan máa lékún síi ní ọjọ́ kọ̀ọ̀kan ní iye tí wọ́n lò ní ọjọ́ 31 sẹ́yìn.

Kí ló dé tí Outline fi ń lo àwọn gbèdéke àtẹ̀yìnwá?

Àwọn gbèdéke àtẹ̀yìnwá máa ń fúnni ní ìdánilójú ní gbogbo ọjọ́ 30, èyí túmọ̀ sí pé wọ́n rọrùn láti yí padà ju gbèdéke tó ń wáyé ní lemọ́-lemọ́ lọ (gẹ́gẹ́ bíi ọjọ́ tí a lè ṣe ní àkànṣe nínú oṣù) nígbà tó ń fúnni ní ìdánilójú tó jọ èyí. Wọ́n tún bá àfihàn tó wà nílẹ̀ tẹ́lẹ̀ fún ìlò dátà Outline mu, àti àwọn irinṣẹ́ tó wọ́pọ̀ bíi àwọn iṣẹ́ àtúpalẹ̀ àti àwọn ìṣirò olùpín.

Àwọn dátà wo ni à ń kà nínú gbèdéke dátà?

À ń fi iye dátà tó ń jáde láti inú olùpín fún kọ́kọ́rọ́ ìwọlé kọ̀ọ̀kan sí inú ìṣirò náà. Ní tòótọ́, èyí túmọ̀ sí dátà tí a fi ránṣẹ́ lórúkọ kọ́kọ́rọ́ náà láti inú olùpín, àti padà sí ọ̀dọ̀ oníbàárà. Ní ṣíṣe, èyí yẹ kó ṣe rẹ́gí pẹ̀lú lílọ-bíbọ̀ tí a fi ránṣẹ́ láti kọ́kọ́rọ́ náà sí olùpín àti láti olùpín padà sí kọ́kọ́rọ́, nítorí náà, a ní ìrètí pé ó máa bá àwọn ìṣirò àwọn olùṣàmúlò rẹ mu. A yan ìjáde dátà, níwọ̀nba ìgbà tó jẹ́ pé ohun tí àwọn olùpèsè ibùdó ìpamọ́ dátà tí a wádìí gba owó fún nìyẹn.

Ṣé wọ́n máa sọ fún àwọn olùṣàmúlò tí wọ́n bá ti kọjá gbèdéke dátà wọn?

Kò rí bẹ́ẹ̀ ní báyìí. Ọ̀pọ̀lọpọ̀ àwọn olùpèsè ibùdó ìpamọ́ dátà ní gbèdéke bíi 1TB fún odidi oṣù kan, èyí tó lè ṣe àtìlẹyìn fún àwọn olùṣàmúlò 10 ní ìwọ̀n 100 GB tàbí àwọn olùṣàmúlò 100 ní ìwọ̀n 10 GB. Àwọn iye wọ̀nyìí pọ̀, a ò sì retí pé ọ̀pọ̀lọpọ̀ àwọn olùṣàmúlò máa lò tó bẹ́ẹ̀. A ní ìrètí pé àwọn olùṣàmúlò máa kàn sí àwọn alákòóso olùpín nígbà tí wọ́n bá dé gbèdéke wọn. Àmọ́, a máa mọ rírì ìwòye rẹ nípa bí àwọn ìfitónilétí ṣe lè wúlò fún ọ, o sì le kàn sí wa níbí.

Ṣé wọ́n máa sọ fún àwọn olùṣàmúlò tí wọ́n bá ti sún mọ́ gbèdéke dátà wọn?

Iye dátà tuntun tí olùṣàmúlò tó ń sún mọ́ gbèdéke rẹ̀ máa gbà máa yàtọ̀ láti ọjọ́ sí ọjọ́ nítorí pé ìlò wọn ní ọjọ́ 30 sẹ́yìn ló dá lé lórí. A rò pé ó ṣe é ṣe kí ìkìlọ̀ rú àwọn olùṣàmúlò lójú ju kí ó ràn wọ́n lọ́wọ́ lọ. A máa mọ rírì èsì yín lórí ìhùwàsí yìí níbí.

Ṣé mo lè ṣe àtúntò ìlò dátà olùṣàmúlò?

Rárá, gbèdéke olùṣàmúlò sábà máa ń ní ìlò dátà ti ọjọ́ 30 tó kọjá nínú. Àmọ́, o lè fi kún gbèdéke dátà kọ́kọ́rọ́ wọn tàbí kí o ṣẹ̀dá kọ́kọ́rọ́ tuntun fún wọn.

Kí ló dé tí àwọn kan lára àwọn olùṣàmúlò mi fi pàdánù ìráyè sí wọn ní kété tí mo ṣètò àwọn gbèdéke dátà?

Àwọn gbèdéke dátà dá lórí ìfiránṣẹ́ dátà ọjọ́ 30 ìṣáájú ti àwọn olùṣàmúlò, èyí tí wọ́n ṣe àkọsílẹ̀ rẹ̀, bóyá àwọn gbèdéke dátà ti wà ní títò tàbí bẹ́ẹ̀ kọ́. Ó ṣe é ṣe pé àwọn olùṣàmúlò tí wọ́n ń sọ̀rọ̀ nípa ti kọjá gbèdéke náà kí wọ́n tó ṣètò rẹ̀.  Bákan náà, ṣe àkíyèsí pé gbogbo àwọn gbèdéke dátà ni à ń mú ṣẹ, kódà nígbà tí a bá ń yí gbèdéke dátà kọ́kọ́rọ́ kan padà.

Ṣé mo lè ṣètò gbèdéke sí gbogbo olùpín, bíi “1 TB fún ọjọ́ 30“?

O kò le tíì ṣe bẹ́ẹ̀ ní báyìí. A máa fẹ́ láti gbọ́ púpọ̀ síi nípa ọ̀ràn ìlò rẹ níbí.

Tó bá jẹ́ pé gbèdéke dátà ìpilẹ̀ṣẹ̀ àti gbèdéke dátà lórí kọ́kọ́rọ́ kan pàtó bá wà, èwo ló máa jẹ́ mímú ṣẹ?

Gbèdéke dátà kọ́kọ́rọ́ pàtó náà máa borí èyíkéyìí gbèdéke dátà ìpilẹ̀ṣẹ̀ (bí èyíkéyìí bá wà) tí o ti ṣètò.

Ṣé mo lè ṣètò gbèdéke dátà fún kọ́kọ́rọ́ kan pàtó láì sètò gbèdéke dátà ìpilẹ̀ṣẹ̀ kankan?

Fífi Outline Client sí orí Linux

GKMS WEB

Bẹ̀rẹ̀ láti Outline Client ẹ̀yà 1.15, gbogbo àwọn ẹ̀yà ọjọ́ iwájú ni a máa gbé jáde gẹ́gẹ́ bíi àwọn àkójọ Debian fún àwọn ètò ìṣiṣẹ́ Linux. Ṣe àgbéyẹ̀wò àwọn ìbéèrè ẹ̀rọ tí ó kéré jùlọfún ẹ̀kúnrẹ́rẹ́ àlàyé nípa àwọn ètò ìṣiṣẹ́ tí à ń tì lẹ́yìn.

 

Ṣe ìfilọ́ọ́lẹ̀ Outline Client fún àwọn ìpínkiri Linux tó dá lóríi Debian (A dábàá rẹ̀)

 

Mú àwọn àṣẹ wọ̀nyìí ṣẹ:

  1. Ṣe ìfilọ́ọ́lẹ̀ kọ́kọ́rọ́ ibùdó ìpamọ́ Outline, kí o sì fi ibùdó ìpamọ́ náà kún un.

    wget -qO- https://us-apt.pkg.dev/doc/repo-signing-key.gpg | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/gcloud-artifact-registry-us.gpg

    echo "deb [arch=amd64] https://us-apt.pkg.dev/projects/jigsaw-outline-apps outline-client main" | sudo tee /etc/apt/sources.list.d/outline-client.list

  2.  Ṣe ìmúdójúìwọ̀n àtòkọ àkójọ apt, kí o sì fi ẹ̀yà Outline Client tuntun síi.

   sudo apt update

   sudo apt install outline-client

Láti wá tàbí gbé àwọn ìmúdójúìwọ̀n ọjọ́ iwájú wọlé, mú àwọn àṣẹ tó wà ní ìgbésẹ̀ 2 ṣẹ lẹ́ẹ̀kan síi. Ṣe àkíyèsí pé a dá'ṣẹ́ ìmúdójúìwọ̀n àìfọwọ́yí inú áàpù dúró fún Outline Client lóríi Linux, bẹ̀rẹ̀ láti ẹ̀yà 1.15.

Láti yọ Outline Client kúrò, mú àṣẹ yìí ṣẹ:

sudo apt purge outline-client

Àṣàyàn mìíràn

  1. Ṣe ìgbàsílẹ̀ àkójọ Debian tuntun ti Outline Client láti https://s3.amazonaws.com/outline-releases/client/linux/stable/outline-client_amd64.deb
  2. Mú àwọn àṣẹ wọ̀nyìí ṣẹ lórí ìlà àṣẹ láti gbé àkójọ náà wọlé

wget -O ./outline-client.deb https://s3.amazonaws.com/outline-      releases/client/linux/stable/outline-client_amd64.deb

sudo apt install ./outline-client.deb

  3.  Wá àwọn ìmúdójúìwọ̀n fún ara rẹ, nítorí a ti dá iṣẹ́ ìmúdójúìwọ̀n àìfọwọ́yí inú áàpù dúró fún Outline Client lóríi Linux, bẹ̀rẹ̀ láti ẹ̀yà 1.15.

  4.  Láti yọ Outline Client, mú àṣẹ yìí ṣẹ lórí ìlà àṣẹ:

sudo apt purge outline-client

Ṣé mo lè lo kọ́kọ́rọ́ ìwọlé kan ju ẹ̀ẹ̀kan lọ?

GKMS WEB

Bẹ́ẹ̀ ni. O lè lo kọ́kọ́rọ́ ìwọlé rẹ lóríi èyíkéyìí iye àwọn ẹ̀rọ rẹ, ṣùgbọ́n a kò dábàá kí o pín kọ́kọ́rọ́ rẹ pẹ̀lú ẹlòmíràn.
