फीडबॅक किंवा सूचना कशा पाठवाव्यात

Outline ला आणखी चांगले बनवण्यात मदत केल्याबद्दल धन्यवाद! निनावीपणे किंवा तुम्हाला प्रतिसाद हवा असल्यास, तुमच्या ईमेलवरून, असे आम्हाला फीडबॅक पाठवण्याचे काही मार्ग आहेत:

  • डेव्हलपरसाठी: Outline हे मुक्त स्रोत सॉफ्टवेअर आहे आणि आमचे सर्व कोड आम्ही GitHub वर होस्ट करतो. तुमचे मत तुम्ही GitHub किंवा आमच्या Reddit समुदायावर शेअर करू शकता.
  • वापरकर्त्यांसाठी: तुम्ही Outline किंवा Outline Manager अ‍ॅप्सद्वारे आम्हाला फीडबॅक पाठवू शकता. तुमचा फीडबॅक कशाबद्दल आहे ते आम्हाला सांगा आणि आम्हाला तुम्हाला उत्तर पाठवता यावे, यासाठी पर्याय म्हणून सोबत ईमेल द्या. तुमच्या वातावरणाबद्दल काही मेटाडेटा गोळा करणे हेदेखील आम्ही करतो, जेणेकरून आम्हाला तुमचे ब्राउझर, ऑपरेटिंग सिस्टीम आणि तुम्ही कोणती सॉफ्टवेअर आवृत्ती वापरत आहात यांसारख्या गोष्टींच्या ट्रबलशूटिंगसंदर्भात तुम्हाला मदत करता येऊ शकते.
  • या साइटद्वारे: या साइटवर तुम्हाला जिथे आमच्याशी संपर्क साधा ही लिंक दिसेल तिथे तुम्ही तिच्यावर क्लिक करू शकता.
  • गंभीर समस्या: तुम्हाला सुरक्षेशी संबंधित गंभीर समस्येची तक्रार करायची असल्यास, तुम्ही तपशिलांसह security [at] getoutline.org येथे ईमेल पाठवल्यास आम्हाला आवडेल.

तुमचे विचार आमच्यासोबत शेअर करण्यासाठी वेळ दिल्याबद्दल पुन्हा धन्यवाद.
