การติดตั้งเซิร์ฟเวอร์

แม้ว่าการติดตั้ง Outline อาจดูง่าย แต่แท้จริงแล้วมีขั้นตอนที่ซับซ้อนเกิดขึ้นอยู่เบื้องหลังหลายประการกว่าที่จะติดตั้งเซิร์ฟเวอร์ของคุณได้

เมื่อใดก็ตามที่มีการติดตั้ง Outline สคริปต์การติดตั้งจะทำงานตามขั้นตอนต่อไปนี้
  • ระบบจะเรียกและนำเข้าไฟล์อิมเมจ Shadowbox เวอร์ชันเสถียรโดยใช้ Docker ระบบจะฝากไฟล์อิมเมจดังกล่าวไว้บน Quay.io ใน https://quay.io/repository/outline/shadowbox?tab=tags ไฟล์อิมเมจนี้จะประกอบด้วยเซิร์ฟเวอร์ Outline และ API การจัดการซึ่งแอปพลิเคชันการจัดการเซิร์ฟเวอร์ Outline จะนำไปใช้ในภายหลังเพื่อสร้างและนำคีย์การเข้าถึงออก เลือกหรือไม่เลือกใช้การรายงานเมตริกที่ไม่ระบุตัวตน และอื่นๆ
  • Watchtower จะได้รับการติดตั้งและกำหนดค่าเพื่อตรวจสอบการอัปเดตไฟล์อิมเมจทุกๆ ชั่วโมงเพื่อให้มั่นใจได้ว่าเซิร์ฟเวอร์ Outline ทุกเครื่องจะได้รับการอัปเดตฟีเจอร์และระบบรักษาความปลอดภัยเวอร์ชันล่าสุดอย่างต่อเนื่อง
  • เว็บเซิร์ฟเวอร์ที่ใช้เข้าถึง API การจัดการจะเริ่มต้นทำงานในพอร์ตที่สุ่มในเส้นทางลับที่สุ่ม
  • ระบบจะสร้างใบรับรอง SSL แบบ Self-signed ขึ้นเพื่อเข้ารหัสการจัดการเซิร์ฟเวอร์ Outline โดยใช้ TLS แม้ว่าจะไม่มีชื่อโดเมนก็ตาม ระบบจะสร้างลายนิ้วมือที่ไม่ซ้ำกันของใบรับรองนี้และจัดเก็บไว้ในแอปพลิเคชัน Outline Manager ซึ่งช่วยป้องกันจากการโจมตีแบบ MITM
เมื่อติดตั้ง Outline แล้วจะไม่จำเป็นต้องกำหนดค่าใดๆ หลังการติดตั้ง

ความปลอดภัยของเซิร์ฟเวอร์

ซอฟต์แวร์ Outline คือซอฟต์แวร์โอเพนซอร์ส ซึ่งหมายความว่าทุกคนจะเห็นและปรับปรุงโค้ดได้หากพบช่องโหว่ ซึ่งเราฝากโค้ดไว้บน GitHub

นอกจากนี้เซิร์ฟเวอร์ Outline ที่ติดตั้งทั้งหมดจะได้รับการอัปเดตโดยอัตโนมัติทุกครั้งที่มีการเปิดตัวเวอร์ชันใหม่เพื่อให้มั่นใจได้ว่าจะไม่มีเซิร์ฟเวอร์ Outline ใดใช้ซอฟต์แวร์เวอร์ชันเก่า

แอปพลิเคชัน Outline Manager จะโต้ตอบกับบริการการจัดการในเซิร์ฟเวอร์ Outline เพื่อจัดการคีย์การเข้าถึงในเซิร์ฟเวอร์ดังกล่าว โดยบริการการจัดการจะทำงานบนพอร์ตแบบสุ่มรวมทั้งเส้นทางลับและไม่ซ้ำกัน นอกจากนี้ ตัวบริการการจัดการเองก็มีระบบป้องกันการล้วงข้อมูล เนื่องจากบริการจะไม่ตอบกลับคำขอยกเว้นจะระบุเส้นทางลับอย่างถูกต้อง ประการสุดท้ายคือการสื่อสารทั้งหมดกับบริการการจัดการจะได้รับการเข้ารหัสด้วยใบรับรอง SSL แบบ Self-signed

อีกทั้งเซิร์ฟเวอร์ Outline ไม่ได้เก็บบันทึกข้อมูลใดๆ และแม้ว่าจะถูกบุกรุกก็จะไม่เปิดเผยข้อมูลผู้ใช้ ดูข้อมูลเพิ่มเติมได้ที่นี่

Outline ได้รับการตรวจสอบโดย Radically Open Security และ Cure53 ในปี 2018 ดูรายงานได้ที่นี่

การจัดการการรับส่งข้อมูล UDP

Outline ใช้งานได้ในรูปแบบ VPN ทั่วทั้งระบบซึ่งหมายความว่าการรับส่งข้อมูล UDP ทั้งหมดจะส่งผ่านเซิร์ฟเวอร์ Outline

การรับส่งข้อมูล DNS

Outline ดำเนินการค้นหา DNS ทั้งหมดผ่านเซิร์ฟเวอร์ Outline และปกป้องการค้นหาเหล่านั้นด้วยการเข้ารหัสแบบเดียวกับที่ใช้ในกิจกรรมเครือข่ายอื่นๆ ทั้งหมด ระบบจะส่งคำขอ DNS ไปยัง Dyn Internet Guide หรือ OpenDNS โดยผ่านเซิร์ฟเวอร์ Outline

Outline จะไม่บันทึกการค้นหา DNS ของคุณ

ความปลอดภัยและความเป็นส่วนตัวขณะใช้ Outline

วิธีที่ Outline ปกป้องการสื่อสารออนไลน์

การเข้าใช้อินเทอร์เน็ตนั้นจะมีความเสี่ยงต่อการรักษาความปลอดภัยมากที่สุดในขณะที่ข้อมูลเดินทางอยู่ในเครือข่ายในท้องถิ่นหรือระดับประเทศ

Outline จะช่วยทำให้การสื่อสารของคุณมีความเป็นส่วนตัวโดยเข้ารหัสการเข้าใช้อินเทอร์เน็ตในขณะที่ข้อมูลเดินทางภายในเครือข่ายระดับประเทศและคงการเข้ารหัสจนกว่าการสื่อสารนั้นจะถึงเซิร์ฟเวอร์ Outline เมื่อใช้ Outline เข้ารหัสการเข้าใช้ บุคคลอื่นที่สังเกตการณ์อยู่ในเครือข่ายจะตรวจสอบเว็บไซต์ที่คุณเข้าชมหรือข้อมูลที่คุณโอนไม่ได้

Outline ยังอาจช่วยให้เข้าถึงเครื่องมือการสื่อสารแบบต้นทางไปยังปลายทางที่ปลอดภัยซึ่งปกติอาจใช้งานไม่ได้ในประเทศของคุณ 

มาตรฐานการเข้ารหัส

Outline จะเข้ารหัสการสื่อสารระหว่างอุปกรณ์ของคุณกับเซิร์ฟเวอร์ Outline โดยใช้การเข้ารหัส AEAD 256-bit Chacha2020 IETF Poly 1305 การเข้ารหัส AEAD จะทำให้ฮาร์ดแวร์สมัยใหม่ทำงานได้อย่างมีประสิทธิภาพ มีความน่าเชื่อถือ สมบูรณ์แบบ และมีความถูกต้อง 

การตรวจสอบความปลอดภัย

Outline ได้รับการตรวจสอบโดย Radically Open Security และ Cure53 ในปี 2018 ซึ่งเป็นองค์กรด้านความปลอดภัยดิจิทัลอิสระทั้ง 2 แห่งที่ตรวจสอบซอฟต์แวร์กับมาตรฐานความปลอดภัยล่าสุด โดย Radically Open Security ได้ทำการตรวจสอบเพิ่มเติมในปี 2022 และ Cure53 ได้ทำการตรวจสอบ Outline SDK ในปี 2024 อ่านข้อมูลเพิ่มเติมได้ในรายงานต่อไปนี้

  • Radically Open Security Penetration Test Report (มีนาคม 2018)
  • Cure53 Pentest & Audit Report Jigsaw Outline (ธันวาคม 2018)
  • Radically Open Security Penetration Test Report (ธันวาคม 2022)
  • Cure53 Pentest Report Jigsaw Outline VPN SDK (มกราคม 2024)

เมตริกและบันทึกที่ไม่ระบุตัวตน

Outline จะติดตามแบนด์วิดท์ที่ใช้เป็น "จำนวนไบต์ที่ถ่ายโอน" สำหรับคีย์การเข้าถึงแต่ละรายการ ข้อมูลนี้จะช่วยให้ผู้ดูแลระบบเซิร์ฟเวอร์ปรับการสมัครใช้บริการแบนด์วิดท์ที่ซื้อกับผู้ให้บริการเซิร์ฟเวอร์ระบบคลาวด์ได้ตามต้องการ แต่จะไม่อนุญาตให้เห็นข้อมูลจริงที่ส่งผ่านเซิร์ฟเวอร์ Outline

ดูข้อมูลเพิ่มเติมเกี่ยวกับการเก็บรวบรวมข้อมูลและสารสนเทศของ Outline

คำถามที่พบบ่อยเกี่ยวกับความปลอดภัยและความเป็นส่วนตัว 

Outline ทำให้ไม่มีใครรู้ตัวตนบนโลกออนไลน์ของฉันได้ใช่ไหม

ไม่ใช่ Outline ไม่ใช่เครื่องมือปกปิดตัวตน แต่จะปกป้องความเป็นส่วนตัวจากผู้สังเกตการณ์ในเครือข่ายที่เป็นไปได้

Outline ไม่ได้ปกปิดตัวตนของคุณแบบเต็มรูปแบบเมื่อเข้าชมเว็บไซต์ เนื่องจากเว็บไซต์เหล่านั้นจะระบุตัวตนของคุณได้เมื่อเข้าสู่ระบบและผ่านทางเทคนิคต่างๆ ในบางครั้ง เช่น การใช้ลายนิ้วมือของเบราว์เซอร์ สำหรับแอปบนอุปกรณ์เคลื่อนที่ สมาร์ทโฟนรุ่นใหม่ส่วนใหญ่จะมี API ที่อนุญาตให้แอปที่ติดตั้งไว้เรียกดูตำแหน่งของคุณได้โดยไม่ต้องผ่านพร็อกซีเนื่องจากแอปเหล่านั้นใช้ GPS ในเครื่องได้

โดยทั่วไปแล้ว VPN จะเป็นด่านป้องกันที่สำคัญโดยเฉพาะจากการสอดส่องกิจกรรมบนอินเทอร์เน็ต อย่างไรก็ดีการใช้งานออนไลน์มักจะมีความเสี่ยงอยู่เสมอ ถึงแม้ว่าจะใช้ VPN แล้วก็ตาม หาก ISP รู้ถึงตัวตนของคุณและเฝ้าสังเกตการจราจรของข้อมูลในเครือข่ายได้ ISP ก็อาจจะรู้ที่อยู่ IP ของเซิร์ฟเวอร์ Outline ของคุณด้วย ซึ่งข้อมูลนี้อาจจะนำไปใช้เพื่อปิดกั้นการเข้าถึงเซิร์ฟเวอร์ Outline หรือเรียนรู้รูปแบบการใช้งาน เช่น เวลาที่คุณมักจะออนไลน์ และอาจใช้ค้นหาตำแหน่งของคุณอย่างคร่าวๆ ได้อีกด้วย 

ผู้อื่นจะทราบหรือไม่ว่าฉันกำลังใช้ Outline อยู่

อาจจะทราบ แพลตฟอร์มและบริการที่คุณเข้าถึงส่วนใหญ่อาจจะรู้ว่าการเชื่อมต่อของคุณมาจากเซิร์ฟเวอร์ระบบคลาวด์ ซึ่งก็อาจจะคาดเดาได้ในบางครั้งว่าคุณใช้ VPN แต่จะไม่เห็นเนื้อหาการเข้าใช้อินเทอร์เน็ตของคุณ 

Outline จะช่วยปกป้องฉันจากภัยคุกคามทางไซเบอร์ที่อาจเกิดขึ้นทั้งหมดไหม

ไม่ ไม่มีเครื่องมือใดจะช่วยป้องกันคุณจากภัยคุกคามทางไซเบอร์ที่อาจเกิดขึ้นทั้งหมดได้ แต่ Outline จะช่วยให้คุณใช้งานอินเทอร์เน็ตสาธารณะและเพิ่มความเป็นส่วนตัวได้โดยเข้ารหัสการเข้าใช้ของคุณ แต่เราขอแนะนำให้คุณยึดหลักปลอดภัยไว้ก่อนเพื่อป้องกันตัวคุณเองจากการโจมตีประเภทอื่นๆ เช่น มัลแวร์และฟิชชิง

หากต้องการเพิ่มประสิทธิภาพการป้องกันทางออนไลน์ โปรดทำงานร่วมกับผู้เชี่ยวชาญด้านการรักษาความมั่นคงปลอดภัยไซเบอร์ขององค์กร หรือรับคำแนะนำที่ปรับเปลี่ยนให้เหมาะกับคุณจากผู้เชี่ยวชาญอันดับต้นๆ ในด้านความปลอดภัยได้ที่ Security Planner ซึ่งเป็นเว็บไซต์ที่สร้างเพื่อช่วยให้คุณเข้าใจวิธีการต่างๆ ในการเลือกเครื่องมือเพื่อรักษาความมั่นคงปลอดภัยไซเบอร์ที่เหมาะสมกับความต้องการ

นอกจากนี้ คุณยังดูผลิตภัณฑ์ที่เกี่ยวกับการรักษาความมั่นคงปลอดภัยไซเบอร์อื่นๆ ได้จาก Jigsaw เช่น Intra, Project Shield และ Password Alert 

การใช้ VPN ถูกกฎหมายไหม

ก่อนใช้ Outline หรือแอปใดก็ตาม โปรดตรวจสอบกฎหมายและข้อบังคับในท้องถิ่นรวมถึงข้อกำหนดในการให้บริการของผู้ให้บริการคลาวด์ที่คุณวางแผนจะใช้งาน

VPN คืออะไร

เครือข่ายส่วนตัวเสมือน (VPN) คือการเชื่อมต่อส่วนตัวระหว่างอุปกรณ์ของคุณและเซิร์ฟเวอร์โฮสต์ ซึ่งจะซ่อนการรับส่งข้อมูลของคุณจากผู้ให้บริการอินเตอร์เน็ตเมื่อคุณใช้ VPN

คุณอาจเลือกใช้ VPN ในสถานการณ์ต่อไปนี้

  • ปกป้องข้อมูลของคุณเมื่อใช้เครือข่าย Wi-Fi สาธารณะ
  • เก็บข้อมูลการท่องเว็บของคุณให้เป็นส่วนตัวจากผู้ให้บริการอินเทอร์เน็ตและหน่วยงานรัฐบาล
  • เข้าถึงเนื้อหาจากแหล่งที่มาต่างๆ ทั่วโลกโดยไม่ถูกปิดกั้น

Outline แตกต่างจาก VPN แบบดั้งเดิมอย่างไร

ผู้ให้บริการอินเทอร์เน็ตสามารถตรวจจับและบล็อก VPN แบบดั้งเดิมได้ง่ายโดยการจดจำโปรโตคอลการรักษาความปลอดภัยทั่วไปและ/หรือรูปแบบปริมาณการรับส่งข้อมูล แต่ Outline มีความยืดหยุ่นมากกว่า VPN แบบดั้งเดิม เนื่องจากสร้างด้วยโปรโตคอลที่ออกแบบให้ตรวจพบได้ยาก ดังนั้นจึงบล็อกได้ยากขึ้น อีกทั้ง Outline ยังช่วยป้องกันการเซ็นเซอร์ขั้นสูงได้หลายรูปแบบ เช่น การบล็อกบนเครือข่าย หรือการบล็อก IP

เซิร์ฟเวอร์ Outline คืออะไร

เซิร์ฟเวอร์ Outline จะทำหน้าที่บริหารจัดการ VPN ซึ่งผู้ใช้ที่ได้รับอนุญาตจะเชื่อมต่อได้

 หากคุณต้องการสร้างเครือข่ายใหม่ คุณสามารถใช้เซิร์ฟเวอร์ที่ปลอดภัยของคุณ (หากมี) เป็นเซิร์ฟเวอร์ Outline ได้ หรือจะใช้ผู้ให้บริการระบบคลาวด์ก็ได้ เช่น

  • DigitalOcean
  • Google Cloud Platform (GCP)
  • Amazon Web Services (AWS)

ผู้ดูแลบริการคือบุคคลที่รับผิดชอบการตั้งค่าเซิร์ฟเวอร์ Outline และแชร์คีย์การเข้าถึงกับผู้ใช้ ซึ่งทั่วไปแล้วผู้ดูแลบริการมีหน้าที่ดูแลเรื่องค่าใช้จ่ายในการใช้งานเซิร์ฟเวอร์

คุณอาจเห็นความแสดงข้อผิดพลาดนี้ "ขออภัย ดูเหมือนว่า Outline ไม่ได้ติดตั้งอย่างถูกต้อง โปรดลองติดตั้งอีกครั้ง หากไม่ได้ผล โปรดส่งความคิดเห็น"

 

หากคุณใช้ Outline ใน Windows บางครั้งคุณอาจพบข้อผิดพลาดที่ไม่คาดคิด ในกรณีส่วนใหญ่ คุณจะต้องลบอะแดปเตอร์ (ไดรเวอร์) Outline TAP และควรติดตั้ง Outline อีกครั้ง

 

ขั้นตอนอาจแตกต่างกันไปตามเวอร์ชันของระบบปฏิบัติการ Windows แต่ด้านล่างนี้เป็นขั้นตอนทั่วไปในการถอนการติดตั้งอะแดปเตอร์ TAP และ Outline แล้วติดตั้ง Outline อีกครั้ง

 
  1. ถอนการติดตั้งอะแดปเตอร์ TAP สำหรับไคลเอ็นต์ Outline
    1. ไปที่โปรแกรมจัดการอุปกรณ์ จากนั้นไปที่อะแดปเตอร์เครือข่าย
    2. ค้นหาไฟล์ TAP-Windows Adapter V9 หรืออะแดปเตอร์ TAP ที่เชื่อมโยงกับ Outline
    3. ถอนการติดตั้งหรือลบอะแดปเตอร์นี้ โปรดทราบว่าการดำเนินการนี้อาจส่งผลต่อแอป VPN อื่นๆ ที่คุณติดตั้งไว้
  2. ถอนการติดตั้งไคลเอ็นต์ Outline
    1. ไปที่โปรแกรมและฟีเจอร์ จากนั้นไปที่ถอนการติดตั้งโปรแกรม
    2. ค้นหาแอปไคลเอ็นต์ Outline แล้วถอนการติดตั้งแอปดังกล่าว
    3. ดาวน์โหลดไคลเอ็นต์ Outline เวอร์ชันล่าสุด แล้วติดตั้งแอปในอุปกรณ์ Windows อีกครั้ง ซึ่งการติดตั้งดังกล่าวจะทำให้ระบบติดตั้งอะแดปเตอร์ TAP ใหม่โดยอัตโนมัติ

หากคุณสร้างบัญชีหรือเข้าสู่ระบบบัญชีที่มีอยู่กับผู้ให้บริการคลาวด์บุคคลที่สามผ่าน Outline Manager เราจะไม่เก็บข้อมูลใดๆ ที่คุณมอบให้ผู้ให้บริการคลาวด์บุคคลที่สาม ไม่ว่าจะเป็นอีเมล ชื่อ ข้อมูลสำหรับการเรียกเก็บเงิน หรือรายละเอียดการชำระเงิน

ข้อมูลที่เราได้รับโดยอัตโนมัติ

เราจะเก็บข้อมูล 2 ประเภทโดยอัตโนมัติ ดังนี้
1. IP ของเซิร์ฟเวอร์
เมื่อเซิร์ฟเวอร์ Outline มีการอัปเดตการปรับปรุงระบบรักษาความปลอดภัยและฟีเจอร์เวอร์ชันล่าสุดโดยอัตโนมัติ Quay.io จะเก็บข้อมูล IP ของเซิร์ฟเวอร์ Outline และทำให้เราเข้าถึงข้อมูล IP ได้ ทั้งนี้ IP ของเซิร์ฟเวอร์อาจระบุผู้ให้บริการเซิร์ฟเวอร์บนระบบคลาวด์และเมืองที่ตั้งของเซิร์ฟเวอร์ Outline ได้ แต่จะไม่ให้ข้อมูลเกี่ยวกับบุคคลที่กำลังใช้งานหรือเข้าถึงเซิร์ฟเวอร์นั้น

2. ข้อมูลทางเทคนิคที่ระบุตัวบุคคลไม่ได้
หาก Outline เกิดเหตุขัดข้องหรือเกิดข้อผิดพลาดร้ายแรง หรือหากคุณส่งความคิดเห็นด้วยตนเองผ่านแอป Outline ระบบจะรายงานข้อมูลด้านล่างนี้ เราจะใช้ข้อมูลนี้เพื่อช่วยระบุและแก้ไขปัญหาด้านเสถียรภาพหรือประสิทธิภาพเท่านั้น

  • ประเทศ
  • ภาษา
  • วันที่และเวลาที่เกิดเหตุขัดข้อง/ข้อผิดพลาดและเหตุการณ์ก่อนหน้านี้ 100 รายการ เช่น เหตุการณ์ที่ผู้ใช้เปิดส่วน "เกี่ยวกับ"
  • ข้อความแสดงข้อผิดพลาดที่เก็บรวบรวมเป็นสถิติ
  • ชื่อและเวอร์ชันของระบบปฏิบัติการ
  • รุ่นโทรศัพท์ (หากทราบ)
  • เวลาเริ่มต้นใช้แอป
  • เบราว์เซอร์
  • สถาปัตยกรรมระบบ
  • เวอร์ชันและหมายเลขบิลด์ของ Outline


ระบบจะโอนข้อมูลนี้ด้วย HTTPS ไปยัง Sentry (sentry.io) ซึ่งเป็นผู้ให้บริการบุคคลที่สามสำหรับการติดตามข้อผิดพลาดแบบโอเพนซอร์ส Sentry จะใช้เทคโนโลยีและบริการระดับมาตรฐานอุตสาหกรรมที่หลากหลายเพื่อปกป้องข้อมูลของคุณจากการเข้าถึง การเปิดเผย และการใช้โดยไม่ได้รับอนุญาต รวมถึงช่วยป้องกันไม่ให้สูญหายอีกด้วย หากมีข้อสงสัยเกี่ยวกับนโยบายของ Sentry โปรดไปที่ https://sentry.io/security/ และ https://sentry.io/privacy/ หรือติดต่อ security@sentry.io ข้อมูล Outline ทั้งหมดที่จัดเก็บโดย Sentry จะจำกัดให้เฉพาะสมาชิกทีม Outline เข้าถึงได้

ข้อมูลที่เราจะเก็บเฉพาะเมื่อมีการอนุญาต

Outline จะรายงานข้อมูลต่อไปนี้ให้กับทีม Outline เมื่อมีการอนุญาต
1. เมตริกการใช้งาน
เซิร์ฟเวอร์ Outline แต่ละเซิร์ฟเวอร์จะเก็บรวบรวมจำนวนไบต์ที่ถ่ายโอน ระยะเวลาที่ผู้ใช้เชื่อมต่อกับเซิร์ฟเวอร์ ประเทศ และระบบเครือข่ายอัตโนมัติของข้อมูลเข้าสู่ระบบที่ใช้ โดยจะเก็บข้อมูลย้อนหลังไป 1 ชั่วโมงและเก็บตามคีย์การเข้าถึงแต่ละรายการโดยอัตโนมัติ รวมไปถึงข้อมูลว่ามีฟีเจอร์ใดที่เปิดหรือปิดใช้อยู่บ้าง ทั้งนี้ระบบจะไม่บันทึกเนื้อหาการสื่อสารหรือข้อมูลเมตาที่ระบุตัวบุคคลได้ (เช่น ข้อมูลเข้าสู่ระบบ อีเมล รหัสอุปกรณ์ ฯลฯ) เมตริกทั้งหมดจะเชื่อมโยงกับรหัสเซิร์ฟเวอร์ ดูวิธีการเปลี่ยนรหัสเซิร์ฟเวอร์ได้ที่นี่

เซิร์ฟเวอร์ Outline จะไม่แชร์เมตริกเหล่านี้กับทีม Outline โดยค่าเริ่มต้น หากผู้ดูแลระบบเซิร์ฟเวอร์เลือกแชร์เมตริกการใช้งานอย่างเปิดเผย ระบบจะส่งข้อมูลเหล่านี้ไปให้ทีม Outline ทุกๆ ชั่วโมงด้วยวิธีที่ปลอดภัย หลังจาก 60 วัน เมตริกการใช้งานจะได้รับการรวบรวมในระดับประเทศ ผู้ดูแลระบบเซิร์ฟเวอร์จะเปลี่ยนการกำหนดค่าการแชร์เมตริกการใช้งานได้ทุกเมื่อโดยไปที่เมนู "การตั้งค่า" ใน Outline Manager

ขอขอบคุณที่แชร์เมตริกที่ไม่ระบุตัวตนเกี่ยวกับการใช้เซิร์ฟเวอร์ให้เรา เราจะใช้ข้อมูลดังกล่าวเพื่อวัดแนวโน้มการใช้งานและปรับปรุงผลิตภัณฑ์

ตัวอย่างเช่น หากผู้ดูแลระบบเซิร์ฟเวอร์เลือกแชร์เมตริกการใช้งานให้เรา เราอาจได้รับข้อมูลที่ระบุว่ามีการใช้เซิร์ฟเวอร์รหัส 12345 เป็นเวลา 3 ชั่วโมงเมื่อวาน โดยได้โอนข้อมูลรวม 500 เมกะไบต์ มีการใช้คีย์ 3 คีย์จากในสหรัฐอเมริกาและแคนาดา และมีการเปิดฟีเจอร์จำกัดข้อมูล

2. ความคิดเห็นและอีเมลหากคุณส่งความคิดเห็น
แอป Outline Manager และ Outline ช่วยให้คุณส่งความคิดเห็นถึงทีมได้ เราไม่แนะนำให้ใส่ข้อมูลส่วนบุคคลที่ระบุตัวบุคคลนั้นได้ แต่คุณจะเลือกช่องทางอีเมลได้หากต้องการรับการตอบกลับจากทีม นอกจากนี้เรายังรวบรวมข้อมูลพื้นฐานบางส่วนโดยอัตโนมัติเพื่อให้เข้าใจความคิดเห็นของคุณ โปรดดูข้อมูลที่เรารวบรวมที่ข้อ 2 ข้างต้นในหัวข้อ "ข้อมูลที่เราได้รับโดยอัตโนมัติ" ดูข้อมูลเพิ่มเติมเกี่ยวกับหลักปฏิบัติเกี่ยวกับความปลอดภัยและความเป็นส่วนตัวของ Outline ได้ที่นี่

หากคุณกำลังใช้แอป Outline รุ่นเบต้าใน Android เราอาจใช้บริการ Firebase ของ Google เพื่อเก็บข้อมูลการแก้ไขข้อบกพร่อง ซึ่งอาจช่วยให้เราตรวจพบปัญหาและปรับปรุง Outline ได้ ดูข้อมูลเพิ่มเติมเกี่ยวกับนโยบายด้านความเป็นส่วนตัวและความปลอดภัยของ Firebase ได้ที่เว็บไซต์ firebase.google.com/support/privacy หากไม่ต้องการให้ Outline ส่งข้อมูลนี้ผ่านทาง Firebase โปรดใช้แอปเวอร์ชันที่ใช้งานจริง

ฉันจะตั้งค่าขีดจำกัดของข้อมูลในคีย์การเข้าถึงได้อย่างไร

คุณสามารถตั้งค่าขีดจำกัดของข้อมูลซึ่งจะมีผลกับคีย์การเข้าถึงทั้งหมดได้ หากต้องการตั้งขีดจำกัด ให้เปิด Outline Manager และไปที่การตั้งค่า โดยคุณจะเห็นปุ่มเปิด/ปิดขีดจำกัดของข้อมูล ซึ่งเมื่อเปิดใช้แล้ว จะช่วยให้คุณตั้งค่าขีดจำกัดได้

เมื่อตั้งค่าขีดจำกัดแล้ว คุณจะเห็นว่าผู้ใช้แต่ละรายใกล้ถึงขีดจำกัดมากน้อยเท่าใดแล้วในหน้าคีย์การเข้าถึง ซึ่งกราฟแท่งจะแสดงปริมาณการใช้ข้อมูลในช่วง 30 วันที่ผ่านมา

นอกจากการตั้งค่าขีดจำกัดสำหรับคีย์การเข้าถึงทั้งหมดแล้ว คุณยังสามารถกำหนดขีดจำกัดของข้อมูลให้กับคีย์แต่ละคีย์ได้ด้วย การตั้งค่านี้จะลบล้างขีดจำกัดของข้อมูลค่าเริ่มต้นทั้งหมดที่คุณเคยตั้งไว้ แต่หากคุณไม่ได้ตั้งค่าขีดจำกัดของข้อมูลค่าเริ่มต้นไว้ คุณจะยังคงตั้งค่าขีดจำกัดสำหรับคีย์ได้อยู่ 

หากต้องการตั้งค่าขีดจำกัดการโอนข้อมูลของคีย์ ให้เปิด Outline Manager แล้วไปยังแท็บการเชื่อมต่อ ซึ่งในนั้นจะมีคีย์ที่คุณต้องการตั้งค่า จากนั้นให้คลิกเมนูที่ด้านขวาของแถวของคีย์ ในส่วนนั้น ให้คลิกที่ "ขีดจำกัดของข้อมูล" หากต้องการเปลี่ยนขีดจำกัดของข้อมูลใน "คีย์การเข้าถึงของฉัน" ให้คลิกที่ไอคอนขีดจำกัดของข้อมูล 

เลือก "ตั้งค่าขีดจำกัดของข้อมูลที่กำหนดเอง" เมื่อเลือกช่องทำเครื่องหมายนี้แล้วจะมีช่องปรากฏขึ้น ซึ่งในส่วนนี้คุณจะตั้งค่าขีดจำกัดของข้อมูลที่กำหนดเองสำหรับคีย์นั้นได้ คลิกปุ่ม "บันทึก" เมื่อเสร็จแล้ว เพื่อบันทึกขีดจำกัดของข้อมูล

เมื่อบันทึกขีดจำกัดของการโอนข้อมูลสำหรับคีย์ที่เลือกแล้ว ขีดจำกัดดังกล่าวจะแสดงขึ้นในหน้าจอหลัก พร้อมด้วยปริมาณการใช้ข้อมูล (ในช่วง 30 วันที่ผ่านมา) สำหรับแต่ละคีย์

หากต้องการนำขีดจำกัดของข้อมูลออกจากคีย์การเข้าถึง ให้ไปที่กล่องโต้ตอบขีดจำกัดของข้อมูลของคีย์ตามที่ระบุไว้ก่อนหน้านี้ แล้วยกเลิกการเลือกช่องที่มีข้อความว่า "ตั้งค่าขีดจำกัดของข้อมูลที่กำหนดเอง" แล้วคลิกปุ่ม "บันทึก"

คำถามที่พบบ่อยเกี่ยวกับขีดจำกัดของข้อมูล

ขีดจำกัดของข้อมูลช่วงเวลาล่าสุด 30 วันคืออะไร

ขีดจำกัดของข้อมูลช่วงเวลาล่าสุด 30 วันจะสรุปข้อมูลการใช้งานของคีย์แต่ละคีย์ในช่วง 30 วันที่ผ่านมา และจำกัดการใช้งานคีย์ในช่วงเวลาดังกล่าวให้อยู่ภายใต้ขีดจำกัด ผลก็คือการใช้งานคีย์จะไม่เกินขีดจำกัดไม่ว่าในช่วงระยะเวลา 30 วันใดก็ตามโดยรวมถึงเดือนตามปฏิทินที่มีจำนวนวันไม่เกิน 30 วันด้วย ซึ่งหมายความว่าปริมาณข้อมูลที่ใช้ได้จะเพิ่มขึ้นในแต่ละวันตามปริมาณที่ใช้ไปเมื่อ 31 วันก่อน

ทำไม Outline จึงใช้ขีดจำกัดช่วงเวลาล่าสุด

ขีดจำกัดช่วงเวลาล่าสุดจะให้การรับประกันในช่วงระยะเวลา 30 วัน ซึ่งจะกำหนดค่าได้ง่ายกว่าขีดจำกัดตามรอบ (เช่น วันที่กำหนดเองได้ของเดือนนั้นๆ) โดยที่มีการรับประกันในรูปแบบที่คล้ายกัน และยังสอดคล้องกับการแสดงปริมาณการใช้ข้อมูล Outline ที่มีอยู่ รวมถึงเครื่องมือทั่วไป เช่น บริการวิเคราะห์และสถิติของเซิร์ฟเวอร์ด้วย

ข้อมูลใดบ้างที่จะนับรวมในขีดจำกัดของข้อมูล

ข้อมูลขาออกของคีย์การเข้าถึงแต่ละรายการจากเซิร์ฟเวอร์จะรวมอยู่ในการนับ หากกล่าวให้เฉพาะเจาะจงก็คือเมื่อข้อมูลที่ส่งในนามของคีย์เดินทางออกจากเซิร์ฟเวอร์ รวมถึงข้อมูลที่เดินทางกลับไปยังไคลเอ็นต์ด้วย ในทางปฏิบัติแล้ว วิธีนี้ควรสอดคล้องกับปริมาณการรับส่งข้อมูลที่ส่งจากคีย์ไปยังเซิร์ฟเวอร์และย้อนกลับมา เราจึงหวังว่าข้อมูลนี้จะตรงกับการนับของผู้ใช้ เราเลือกใช้ข้อมูลขาออกเนื่องจากผู้ให้บริการคลาวด์ที่เราสำรวจจะเรียกเก็บเงินจากข้อมูลส่วนนี้

เรียกใช้คำสั่งต่อไปนี้

  1. ติดตั้งคีย์ที่เก็บของ Outline และเพิ่มที่เก็บ

    wget -qO- https://us-apt.pkg.dev/doc/repo-signing-key.gpg | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/gcloud-artifact-registry-us.gpg

    echo "deb [arch=amd64] https://us-apt.pkg.dev/projects/jigsaw-outline-apps outline-client main" | sudo tee /etc/apt/sources.list.d/outline-client.list

  2. อัปเดตรายการแพ็กเกจ apt และติดตั้งไคลเอ็นต์ Outline เวอร์ชันล่าสุด

    sudo apt update

    sudo apt install outline-client

    หากยังไม่มีสิทธิ์เข้าถึงเซิร์ฟเวอร์ระบบคลาวด์ก็ไม่ต้องกังวล เพราะคุณสร้างบัญชีกับผู้ให้บริการรายใดก็ได้ ซึ่งรวมถึงผู้ให้บริการที่กล่าวถึงไปแล้วข้างต้นด้วย โดยคุณอาจต้องใช้บัตรเครดิตในการลงชื่อสมัครใช้
  2. คอมพิวเตอร์เดสก์ท็อปที่ใช้ macOS 10.9+, Windows 7.0+ หรือ Linux
  3. แอปพลิเคชัน Outline Manager

ตั้งค่ากับ DigitalOcean

ผู้ใช้ทุกคนจะตั้งค่า Outline กับ DigitalOcean ได้อย่างง่ายดายผ่านการคลิกเพียงไม่กี่ครั้ง หลังจากดาวน์โหลดและติดตั้ง Outline Manager ในคอมพิวเตอร์แล้ว ให้เลือกตัวเลือกการตั้งค่า DigitalOcean ที่จะแนะนำวิธีการกำหนดค่าและติดตั้ง Outline Server ซึ่งมีเพียงไม่กี่ขั้นตอนเท่านั้น

ตั้งค่ากับผู้ให้บริการระบบคลาวด์รายอื่น

หลังจากดาวน์โหลดและติดตั้ง Outline Manager แล้ว คุณจะเลือกติดตั้งเซิร์ฟเวอร์ Outline ในเครื่องเสมือนกับ AWS, GCP, DigitalOcean หรือผู้ให้บริการรายอื่นได้ ขั้นตอนสำหรับผู้ให้บริการแต่ละรายนั้นแตกต่างกัน เราจึงได้รวบรวมวิธีการต่างๆ สำหรับผู้ให้บริการระบบคลาวด์ทั่วไปโดยส่วนใหญ่ไว้ในขั้นตอนการตั้งค่า Outline Manager รวมถึงวิธีกำหนดค่าการติดตั้งในเครื่องเสมือนก่อนที่จะเรียกใช้สคริปต์การติดตั้งเพื่อติดตั้ง Outline ในเซิร์ฟเวอร์

  • ขอให้ใครสักคนเชิญคุณเข้าเซิร์ฟเวอร์: หากคุณรู้จักบุคคลที่มีเซิร์ฟเวอร์ Outline ให้ติดต่อบุคคลดังกล่าวและขอคีย์การเข้าถึง
  • สร้างเซิร์ฟเวอร์เอง: ใช้คอมพิวเตอร์ Windows, Mac, หรือ Linux เพื่อดาวน์โหลด Outline Manager แล้วตั้งค่าเซิร์ฟเวอร์ Outline ของคุณเอง เราทำให้กระบวนการนี้ง่ายสำหรับทุกคน โดยเฉพาะอย่างยิ่งเมื่อใช้งานผ่านผู้ให้บริการระบบคลาวด์ DigitalOcean
  • ใช้บริการของ Outline หรือ Shadowsocks: คุณยังสามารถใช้ไคลเอ็นต์ Outline กับบริการของบุคคลที่สามที่ใช้โปรโตคอล Outline หรือ Shadowsocks ได้ด้วย เช่น
    • nthLink ให้บริการฟรีโดยอิงตาม Outline ซึ่งทำงานร่วมกับไคลเอ็นต์ Outline เวอร์ชันที่ผ่านการปรับแต่ง
    • ASL19 ให้บริการ Outline เวอร์ชันที่ผ่านการปรับแต่งที่ชื่อ BeePass เช่นเดียวกับ Telegram Bot ซึ่งมอบคีย์การเข้าถึงฟรีสำหรับเซิร์ฟเวอร์ BeePass
    • ผู้ใช้ภาษาฟาร์ซียังสามารถขอคีย์การเข้าถึง Outline จาก Paskoocheh ของ ASL19 ได้เช่นกัน

Outline Manager มีฟีเจอร์ที่ช่วยให้คุณกําหนดค่าเซิร์ฟเวอร์ Outline ในเซิร์ฟเวอร์ที่ทํางานใน Google Cloud ได้โดยอัตโนมัติ หากเลือกใช้ฟีเจอร์นี้ Outline Manager จะขอให้คุณลงชื่อเข้าใช้ด้วยบัญชี Google ซึ่งจะให้สิทธิ์บางอย่างกับ OAuth ในการติดตั้ง Outline Manager เพื่อจุดประสงค์ในการกําหนดค่าบัญชี Google Cloud

หากไม่ต้องการให้สิทธิ์เหล่านี้ โปรดทําตามวิธีการตั้งค่าขั้นสูงใน Outline Manager เพื่อเรียกใช้ Outline ใน Google Cloud Platform

ได้รับสิทธิ์แล้ว

Outline Manager ต้องใช้สิทธิ์ต่อไปนี้จากบัญชี Google ของคุณในการตั้งค่าอัตโนมัติ

Google Cloud Platform

  • ดูและจัดการแหล่งข้อมูล Google Compute Engine ของคุณ

  • ดูข้อมูลในบริการของ Google Cloud รวมถึงดูอีเมลของบัญชี Google

ข้อมูลบัญชีทั่วไป

  • ดูอีเมลหลักของบัญชี Google
  • เชื่อมโยงตัวคุณกับข้อมูลส่วนบุคคลใน Google

การเข้าถึงเพิ่มเติม

  • จัดการโครงการ Cloud Platform

  • ดูและจัดการบัญชีสำหรับการเรียกเก็บเงินบน Google Cloud Platform ของคุณ

  • จัดการการกำหนดค่าบริการ Google API

สิทธิ์เหล่านี้ช่วยให้เรารองรับฟังก์ชันการทํางานขั้นสูงสําหรับการจัดการเซิร์ฟเวอร์ Outline ได้ เช่น

  • แสดงรายการศูนย์ข้อมูลที่มีอยู่
  • การสร้างเครื่องเสมือนใหม่เพื่อเรียกใช้ Outline
  • การกําหนดค่าเครื่องเสมือนใหม่ด้วย Outline

คุณเพิกถอนสิทธิ์เข้าถึง Outline Manager ใน Google Cloud Platform ได้โดยไปที่ บัญชีของฉัน หากคุณเพิกถอนสิทธิ์เข้าถึง เซิร์ฟเวอร์ที่คุณสร้างด้วยการตั้งค่าอัตโนมัติจะยังคงทํางานอยู่ แต่จะไม่ปรากฏใน Outline Manager อีกต่อไป หากต้องการคืนค่าสิทธิ์การเข้าถึง เพียงเชื่อมต่อ Google Cloud Platform อีกครั้งโดยเริ่มต้นขั้นตอนการตั้งค่าอัตโนมัติ

การตั้งค่าอัตโนมัติของ Google Cloud ใช้ โปรเจ็กต์ Google Cloud รายการเดียวจัดระเบียบเซิร์ฟเวอร์ Outline ระบบจะสร้างโปรเจ็กต์ขึ้นระหว่างการใช้การตั้งค่าอัตโนมัติครั้งแรก โดยใช้รหัสโปรเจ็กต์ที่แนะนําซึ่งขึ้นต้นด้วย "Outline-" ตามด้วยสตริงอักขระแบบสุ่ม คุณจะเลือกรหัสโปรเจ็กต์อื่นขณะสร้างได้หากต้องการ โปรเจ็กต์จะมีชื่อว่า "เซิร์ฟเวอร์ Outline"

บัญชีสำหรับการเรียกเก็บเงิน

โปรเจ็กต์ Google Cloud ต้องใช้ "บัญชีสําหรับการเรียกเก็บเงิน" ที่เชื่อมโยงอยู่และมีข้อมูลการชําระเงิน เมื่อใช้การตั้งค่าอัตโนมัติของ Google Cloud เป็นครั้งแรก ระบบจะขอให้คุณระบุบัญชีสําหรับการเรียกเก็บเงินเพื่อเชื่อมโยงกับเซิร์ฟเวอร์ Outline บางครั้งเซิร์ฟเวอร์จะหยุดทํางานเนื่องจากพบปัญหาในบัญชีสําหรับการเรียกเก็บเงิน ในกรณีนี้ คุณควรลงชื่อเข้าสู่ระบบ Google Cloud Console ค้นหาโปรเจ็กต์ใน Google Cloud ที่เชื่อมโยงกับ Outline (ชื่อว่า "เซิร์ฟเวอร์ Outline") และอัปเดตการตั้งค่าการเรียกเก็บเงิน

การทําลายเซิร์ฟเวอร์

หากต้องการทําลายเซิร์ฟเวอร์ที่สร้างขึ้นโดยใช้การตั้งค่าอัตโนมัติ วิธีที่ง่ายที่สุดคือดำเนินการจากภายใน Outline Manager แต่ถ้าต้องการทําลายเซิร์ฟเวอร์ด้วยตนเอง ให้เข้าสู่ระบบ Google Cloud Console ค้นหาโปรเจ็กต์ที่สร้างระหว่างการตั้งค่าเริ่มต้น (ชื่อ "เซิร์ฟเวอร์ Outline") และลบทรัพยากรในเครื่องออกหรือปิดโปรเจ็กต์

ฉันใช้ Outline โดยไม่มีเซิร์ฟเวอร์ได้ไหม

น่าเสียดายที่ไม่ได้ ซอฟต์แวร์ Outline จำเป็นต้องมีสิทธิ์เข้าถึงเซิร์ฟเวอร์ ไม่ว่าเซิร์ฟเวอร์นั้นจะได้รับการจัดการโดยคุณ องค์กร หรือบุคคลที่สามที่เชื่อถือได้ก็ตาม

ระยะเวลาในการตั้งค่าเซิร์ฟเวอร์ Outline

ส่วนใหญ่แล้วจะใช้เวลาน้อยกว่า 5 นาที คุณติดตั้ง Outline ในเซิร์ฟเวอร์ระบบคลาวด์ใดก็ได้ แต่เราได้ทำงานร่วมกับ DigitalOcean เพื่อมอบประสบการณ์การติดตั้งที่ง่ายดายให้แก่คุณ กล่าวคือคุณจะตั้งค่าเซิร์ฟเวอร์ได้โดยการคลิกเพียงไม่กี่ครั้งโดยไม่มีสคริปต์ใดๆ ทั้งสิ้น
หากเลือก AWS, GCP หรือการตั้งค่าขั้นสูง เราก็ได้จัดทำกระบวนการติดตั้งเซิร์ฟเวอร์แบบง่ายเป็นสคริปต์เดียวที่รองรับผู้ให้บริการส่วนใหญ่ได้

ฉันจะตั้งค่าเซิร์ฟเวอร์ Outline ได้ที่ไหน

คุณจะตั้งค่าเซิร์ฟเวอร์ Outline ในสถานที่ที่ผู้ให้บริการระบบคลาวด์ส่วนใหญ่ดำเนินงานอยู่ได้
วิธีที่ง่ายที่สุดคือการตั้งค่าใน DigitalOcean เนื่องจาก DigitalOcean มีเซิร์ฟเวอร์หลายแห่ง เช่น อัมสเตอร์ดัม โตรอนโต ซานฟรานซิสโก และสิงคโปร์ หากต้องการติดตั้งกับผู้ให้บริการระบบคลาวด์รายอื่นหรือบนโครงสร้างพื้นฐานของคุณเอง ให้เลือก "โหมดขั้นสูง" ในแอปพลิเคชัน Outline Manager และทำตามวิธีการติดตั้งโดยใช้สคริปต์การตั้งค่า

ฉันควรจะตั้งค่าเซิร์ฟเวอร์ Outline ที่ไหน

ปัจจัยสำคัญบางประการที่คุณควรพิจารณาเมื่อตัดสินใจเลือกตำแหน่งที่ตั้งสำหรับเซิร์ฟเวอร์ Outline มีดังนี้

  1. ตำแหน่งเซิร์ฟเวอร์ Outline ส่งผลต่อประสบการณ์การใช้งานอินเทอร์เน็ตของผู้ใช้ เช่น หากเซิร์ฟเวอร์อยู่ในอัมสเตอร์ดัม ผู้ใช้ที่เข้าถึงเซิร์ฟเวอร์นี้จะใช้งานอินเทอร์เน็ตได้เหมือนกับว่าตนเองอยู่ในประเทศเนเธอร์แลนด์ บางเว็บไซต์อาจแสดงผลเป็นภาษาดัตช์ โดยปกติแล้ว คุณจะลบล้างภาษาท้องถิ่นได้โดยใช้ตัวเลือกภาษาในเว็บไซต์

  2. ระยะห่างระหว่างผู้ใช้และเซิร์ฟเวอร์ Outline อาจส่งผลต่อความเร็ว โดยทั่วไป ระยะห่างทางกายภาพระหว่างตัวผู้ใช้ Outline และเครื่องเซิร์ฟเวอร์เองจะส่งผลต่อความเร็วอินเทอร์เน็ตของผู้ใช้ โดยส่วนใหญ่แล้ว คุณจะเลือกตำแหน่งของเซิร์ฟเวอร์ให้ใกล้กับตำแหน่งที่คาดว่าผู้ใช้จะอาศัยอยู่มากที่สุด แต่คุณอาจตรวจสอบ Submarine Cable Map เพื่อดูการเชื่อมต่อสายอินเทอร์เน็ตในประเทศหรือภูมิภาคของคุณก็ได้เช่นกัน

  3. ตำแหน่งที่ตั้งของเซิร์ฟเวอร์ VPN อาจส่งผลต่อกรอบด้านกฎหมาย โปรดทราบว่าซอฟต์แวร์ Outline ไม่ได้บันทึกการเข้าชมของคุณ ดูข้อมูลเพิ่มเติมเกี่ยวกับความปลอดภัยและความเป็นส่วนตัวขณะใช้ Outline

คุณอาจถูกบล็อกโดยไฟร์วอลล์ของเครือข่าย

หากคุณพยายามติดตั้ง Outline ในขณะที่มีการเชื่อมต่อเครือข่ายที่มีไฟร์วอลล์ เช่น ที่โรงเรียนหรือในที่ทำงาน ให้ลองติดตั้งโดยใช้เครือข่ายอื่น

หากไม่ได้ผล โปรดติดต่อผู้ดูแลเครือข่ายเพื่ออนุญาตการเชื่อมต่อระหว่างเครือข่ายที่มีไฟร์วอลล์กับเซิร์ฟเวอร์ Outline คุณจะต้องทราบที่อยู่ IP ของเซิร์ฟเวอร์และพอร์ตที่ Outline ใช้งาน ซึ่งมีการระบุไว้ที่ท้ายสคริปต์การติดตั้ง

คุณอาจถูกบล็อกโดยไฟร์วอลล์ของอุปกรณ์

หากคุณมีซอฟต์แวร์ในอุปกรณ์ที่บล็อกการเชื่อมต่อขาออกในพอร์ตที่ไม่ใช่แบบมาตรฐาน หรือซอฟต์แวร์ที่ไม่รู้จัก (เช่น ZoneAlarm ของ CheckPoint) โปรดอ่านคู่มือของอุปกรณ์หรือซอฟต์แวร์เพื่อดูข้อมูลเกี่ยวกับวิธีสร้างข้อยกเว้นสำหรับ Outline

คุณอาจถูกบล็อกโดยไฟร์วอลล์ของเซิร์ฟเวอร์

ผู้ให้บริการระบบคลาวด์ที่คุณเลือกอาจกำหนดให้คุณต้องสร้างข้อยกเว้นในไฟร์วอลล์ของเซิร์ฟเวอร์ด้วยตนเองเพื่อเปิดพอร์ตที่ Outline ใช้งานอยู่ หลังจากที่เรียกใช้สคริปต์การติดตั้ง ระบบจะแสดงพอร์ตที่เลือกไว้แบบสุ่ม 2 พอร์ตที่ Outline ใช้งานอยู่ในเซิร์ฟเวอร์ การเปิดพอร์ต 2 พอร์ตนี้ก็น่าจะเพียงพอแล้ว
