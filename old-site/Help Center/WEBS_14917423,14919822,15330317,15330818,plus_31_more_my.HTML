ဆာဗာ ထည့်သွင်းခြင်း

​Outline ထည့်သွင်းမှုသည် ရိုးရှင်းသည်ဟု ထင်ရသော်လည်း သင့်ဆာဗာထည့်သွင်းရန် နောက်ကွယ်မှ လုပ်ဆောင်နေသည့် ခက်ခဲရှုပ်ထွေးသောအဆင့်များရှိသည်။ Outline ထည့်သွင်းသည့်အခါတိုင်း ထည့်သွင်းမှု script သည် အောက်ပါအဆင့်များကို လုပ်ဆောင်သည်-

  • Shadowbox ပုံရိပ်ဖိုင် (image) ၏ တည်ငြိမ်ဗားရှင်းကို ပြန်ယူပြီး Docker ဖြင့် ထည့်သွင်းသည်။ ပုံရိပ်ဖိုင်ကို https://quay.io/repository/outline/shadowbox?tab=tags ရှိ Quay.io တွင် လက်ခံလုပ်ဆောင်သည်။ ဤပုံရိပ်ဖိုင်တွင် Outline ဆာဗာနှင့် Management API ပါဝင်ပြီး ၎င်းကို နောက်ပိုင်းတွင် ‘Outline ဆာဗာ စီမံခန့်ခွဲမှု’ အပလီကေးရှင်းက ဝင်ခွင့်ကီးများ ပြုလုပ်ရန်၊ ဖယ်ရှားရန်၊ ကိုယ်ရေးအချက်အလက် ဖျောက်ထားသော မက်ထရစ်များ သတင်းပို့ခြင်း သုံးရန်/မသုံးရန် စသည်တို့တွင် သုံးသည်။
  • Watchtower ကို ထည့်သွင်းပြီး ပုံရိပ်ဖိုင် အပ်ဒိတ်များကို နာရီနှင့်အမျှ စစ်ဆေးရန် စီစဉ်သတ်မှတ်ထားသည်။ ဤသို့အားဖြင့် Outline ဆာဗာတိုင်းကို နောက်ဆုံးထွက် တူးလ်နှင့် လုံခြုံရေးမွမ်းမံမှုများဖြင့် အမြဲအပ်ဒိတ်ဖြစ်နေရန် ကူညီပေးသည်။
  • Management API သို့ဝင်ရန် အသုံးပြုသော ဝဘ်ဆာဗာကို ကျပန်းပို့တ်နှင့် ကျပန်းဖိုင်တွဲများလမ်းကြောင်းတွင် စတင်သည်။
  • သုံးသူက ပြုလုပ်သော SSL အသိအမှတ်ပြုလက်မှတ် ကို ပြုလုပ်ထားသဖြင့် ဒိုမိန်းအမည် မရှိသော်လည်း TLS သုံးပြီး Outline ဆာဗာစီမံခန့်ခွဲမှုကို အသွင်ဝှက်နိုင်သည်။ ဤအသိအမှတ်ပြုလက်မှတ်၏ သီးခြားလက်ဗွေကိုလည်း ထုတ်ပေးပြီး ‘Outline မန်နေဂျာ’ အပလီကေးရှင်းတွင် သိမ်းထားသည်။ ၎င်းက MITM တိုက်ခိုက်မှုများကို ကူညီကာကွယ်ပေးသည်။

Outline ထည့်သွင်းမှုကို လုပ်ဆောင်ပြီးနောက် မည်သည့်စီစဉ်သတ်မှတ်ချက်မျှ မလိုအပ်ပါ။

ဆာဗာ လုံခြုံရေး

Outline ဆော့ဖ်ဝဲသည် အခမဲ့ရင်းမြစ်ဖြစ်သည်။ ဆိုလိုသည်မှာ လူတိုင်းက ကုဒ်ကို မြင်နိုင်သည်။ အားနည်းချက်များ တွေ့ထားပါက ပိုကောင်းအောင် ပြုလုပ်နိုင်သည်။ ကျွန်ုပ်တို့၏ ကုဒ်ကို GitHub တွင် လက်ခံလုပ်ဆောင်သည်။

ထို့အပြင် ထည့်သွင်းထားသော Outline ဆာဗာအားလုံးကို ဗားရှင်းအသစ် ဖြန့်ချိတိုင်း အလိုအလျောက် အပ်ဒိတ်လုပ်သည်။ မည်သည့် Outline ဆာဗာကိုမျှ ဆော့ဖ်ဝဲဗားရှင်းအဟောင်းများကို ဆက်မသုံးစေပါ။

ဆာဗာရှိ ဝင်ခွင့်ကီးများကို စီမံရန်အတွက် ‘Outline မန်နေဂျာ’ အပလီကေးရှင်းသည် Outline ဆာဗာတွင် ‘စီမံခန့်ခွဲသော ဝန်ဆောင်မှု’ နှင့် ပြန်လှန်တုံ့ပြန်သည်။ ‘စီမံခန့်ခွဲသော ဝန်ဆောင်မှု’ သည် ကျပန်းပို့တ်နှင့် သီးခြားဖိုင်တွဲများလမ်းကြောင်းတွင် လုပ်ဆောင်သည်။ ‘စီမံခန့်ခွဲသော ဝန်ဆောင်မှု’ သည် သင့်တော်သော လျှို့ဝှက်ဖိုင်တွဲများလမ်းကြောင်းကို မဖော်ပြဘဲ မေးမြန်းချက်များကို အကြောင်းမပြန်သဖြင့် စုံစမ်းရခက်ခဲသည်။ ‘စီမံခန့်ခွဲသော ဝန်ဆောင်မှု’ ထံ ဆက်သွယ်မှုအားလုံးကို သုံးသူက ပြုလုပ်သော SSL အသိအမှတ်ပြုလက်မှတ် ဖြင့် အသွင်ဝှက်သည်။

Outline ဆာဗာသည် မည်သည့်မှတ်တမ်းကိုမျှ မသိမ်းသဖြင့် အငြင်းပွားဖွယ် ဖြစ်ခဲ့လျှင်ပင် အသုံးပြုသူဒေတာကို ဖော်ပြနိုင်မည်မဟုတ်ပါ။ ဤနေရာ တွင် ပိုမိုလေ့လာနိုင်သည်။ Outline ကို Radically Open Security နှင့် Cure53 တို့က ၂၀၁၈ ခုနှစ်တွင် စစ်ဆေးထားသည်။ အစီရင်ခံစာများကို ဤနေရာ တွင် ကြည့်ပါ။

UDP ဒေတာစီးဆင်းမှုကို စီမံခြင်း

Outline သည် စနစ်တစ်ခုလုံးသုံးသော VPN အဖြစ် လည်ပတ်နိုင်သည်။ ဆိုလိုသည်မှာ UDP ဒေတာစီးဆင်းမှုအားလုံးကို Outline ဆာဗာမှတစ်ဆင့် ဒေတာ အသွင်ပြောင်းပို့ဆောင်သည်။

DNS ဒေတာစီးဆင်းမှု


Outline သည် DNS ရှာဖွေမှုအားလုံးကို Outline ဆာဗာမှတစ်ဆင့် ဆောင်ရွက်ပြီး အခြားသော ကွန်ရက်လုပ်ဆောင်ချက်အားလုံးအတွက် အသုံးပြုသော အသွင်ဝှက်ခြင်းဖြင့် ယင်းရှာဖွေမှုများကို ကာကွယ်ပေးသည်။ သင်၏ DNS မေးမြန်းချက်များသည် Outline ဆာဗာမှတစ်ဆင့် Dyn Internet Guide၊ OpenDNS၊ Cloudflare DNS (သို့) Quad9 DNS သို့ သွားပါမည်။ Outline သည် သင်၏ DNS ရှာဖွေမှုများကို မည်သည့်အခါမျှ မှတ်တမ်းမတင်ပါ။

Outline သုံးနေစဉ် လုံခြုံရေးနှင့် ကိုယ်ရေးအချက်အလက် လုံခြုံမှု

သင်၏ အွန်လိုင်းဆက်သွယ်မှုများကို Outline က ကာကွယ်ပေးပုံ

အင်တာနက် ဒေတာစီးဆင်းမှုသည် ဒေသတွင်း (သို့) နိုင်ငံတွင်း ကွန်ရက်မှတစ်ဆင့် ဖြတ်သန်းနေစဉ် စောင့်ကြည့်ခံရရန် အားနည်းချက်အရှိဆုံးဖြစ်သည်။

အင်တာနက် ဒေတာစီးဆင်းမှုသည် နိုင်ငံတွင်း ကွန်ရက်အတွင်း ဖြတ်သန်းစဉ် ၎င်းကို အသွင်ဝှက်ခြင်းဖြင့် Outline သည် သင်၏ ဆက်သွယ်မှုများ သီးသန့်ဖြစ်စေရန် ကူညီပေးပြီး Outline ဆာဗာသို့ ရောက်သည်အထိ ဆက်လက်အသွင်ဝှက်ပေးသည်။ ဒေတာစီးဆင်းမှုကို Outline ဖြင့် အသွင်ဝှက်ထားသောအခါ ကွန်ရက်စောင့်ကြည့်သူများသည် သင်ဝင်ကြည့်သော ဝဘ်ဆိုက်များ (သို့) လွှဲပြောင်းနေသော အချက်အလက်များကို မစစ်ဆေးနိုင်ပါ။

Outline သည် သင့်နိုင်ငံတွင် သုံးမရနိုင်သည့် လုံခြုံပြီး ဆက်သွယ်သူချင်းသုံးနိုင်သော ဆက်သွယ်ရေးတူးလ်များသုံးခွင့်ကို ပြန်လည်ရယူရန်လည်း ကူညီပေးနိုင်သည်။ 

အသွင်ဝှက်ခြင်း စံနှုန်းများ

Outline သည် သင့်စက်နှင့် ‘Outline ဆာဗာ’ ကြား ဆက်သွယ်မှုများကို AEAD 256-bit Chacha2020 IETF Poly 1305 စာဝှက်နည်းသုံးပြီး အသွင်ဝှက်ပေးသည်။ AEAD ဝှက်စာများသည် လျှို့ဝှက်မှု၊ ခိုင်မာမှုနှင့် စစ်မှန်မှုတို့ကို ပံ့ပိုးပေးပြီး ခေတ်မီဟာ့ဒ်ဝဲတွင် ထူးကဲစွာ စွမ်းဆောင်နိုင်ကြောင်း တွေ့ရသည်။ 

လုံခြုံရေးစစ်ဆေးမှုများ

၂၀၁၈ ခုနှစ်တွင် သီးခြား ဒစ်ဂျစ်တယ်လုံခြုံရေး အဖွဲ့အစည်းနှစ်ခုဖြစ်သော Radically Open Security နှင့် Cure53 တို့က Outline ကို စစ်ဆေးထားပြီး ၎င်းတို့သည် နောက်ဆုံးပေါ် လုံခြုံရေးစံနှုန်းများနှင့်ယှဉ်၍ ဆော့ဖ်ဝဲကို သုံးသပ်သည်။ Radically Open Security က ၂၀၂၂ ခုနှစ်တွင် နောက်ထပ်စစ်ဆေးခဲ့ပြီး Cure53 က ၂၀၂၄ ခုနှစ်တွင် Outline SDK ကို စစ်ဆေးခဲ့သည်။ အစီရင်ခံစာများကို ဤနေရာတွင် ဖတ်ရှုနိုင်ပါသည်-

  • Radically Open Security ၏ ထိုးဖောက်နိုင်မှု စမ်းသပ်ချက် အစီရင်ခံစာ (၂၀၁၈ မတ်လ)
  • Cure53 ၏ Jigsaw Outline ကို ထိုးဖောက်နိုင်မှုနှင့် စစ်ဆေးမှု အစီရင်ခံစာ (၂၀၁၈ ဒီဇင်ဘာ)
  • Radically Open Security ၏ ထိုးဖောက်နိုင်မှု စမ်းသပ်ချက် အစီရင်ခံစာ (၂၀၂၂ ဒီဇင်ဘာ)
  • Cure53 ၏ Jigsaw Outline VPN SDK ကို ထိုးဖောက်နိုင်မှုနှင့် စစ်ဆေးမှု အစီရင်ခံစာ (၂၀၂၄ ဇန်နဝါရီ)

အမည်မသိ မက်ထရစ်နှင့် မှတ်တမ်းများ

Outline သည် ဝင်ခွင့်ကီးတစ်ခုစီအတွက် သုံးထားသော မြန်နှုန်းကို “လွှဲပြောင်းထားသော ဘိုက်များ” အဖြစ် ခြေရာခံသည်။ ဤအချက်အလက်သည် ဆာဗာစီမံခန့်ခွဲသူများအား မြန်နှုန်းစာရင်းသွင်းမှုများကို သူတို့၏ Cloud ဆာဗာဝန်ဆောင်မှုပေးသူများနှင့် လိုသလိုချိန်ညှိခွင့်ပြုသော်လည်း Outline ဆာဗာမှတစ်ဆင့် ဖြတ်သွားသော အချက်အလက်အမှန်များကို ကြည့်ခွင့်မပြုပါ။

Outline ၏ ဒေတာနှင့် အချက်အလက် စုဆောင်းမှု အကြောင်း ပိုမိုလေ့လာပါ။

၁။ အသုံးပြုမှု မက်ထရစ်များ
Outline ဆာဗာတစ်ခုစီသည် ပြီးခဲ့သော တစ်နာရီအတွင်းနှင့် ဝင်ခွင့်ကီးအလိုက် အခြေခံပြီး လွှဲပြောင်းထားသော ဘိုက်အရေအတွက်၊ အသုံးပြုသူကို ဆာဗာနှင့် ချိတ်ဆက်ထားသည့် အချိန်ပမာဏ၊ အထောက်အထားများ သုံးထားသော မူလဇစ်မြစ်နိုင်ငံများ၊ ကိုယ်တိုင်စီမံသော စနစ်များနှင့် ဖွင့်ထားသည့် (သို့) ပိတ်ထားသည့် ဝန်ဆောင်မှုများရှိ၊ မရှိတို့ကို အလိုအလျောက် စုဆောင်းသည်။ ဆက်သွယ်မှု၏ အကြောင်းအရာ (သို့) ပုဂ္ဂိုလ်ရေးအရ ခွဲခြားသိရှိနိုင်သော မက်တာဒေတာ (ဥပမာ- အကောင့်ဝင်ခြင်း၊ အီးမေးလ်၊ စက် ID အစရှိသော) မည်သည်ကိုမျှ မှတ်တမ်းတင်မထားပါ။ မက်ထရစ်အားလုံးကို ဆာဗာ ID တွင် ပူးတွဲထားသည်။ ဆာဗာ ID ပြောင်းခြင်းအတွက် ညွှန်ကြားချက်များကို ဤနေရာ တွင် တွေ့နိုင်သည်။

မူရင်းသတ်မှတ်ချက်အရ ‘Outline ဆာဗာများ’ သည် ဤမက်ထရစ်များကို Outline အဖွဲ့နှင့် မမျှဝေပါ။ ‘ဆာဗာစီမံခန့်ခွဲသူ’ သည် အသုံးပြုမှုမက်ထရစ်များကို မျှဝေရန် ရွေးချယ်ပါက ဤအချက်အလက်ကို Outline အဖွဲ့သို့ နာရီနှင့်အမျှ လုံခြုံစွာ ပို့ပါမည်။ အသုံးပြုမှုမက်ထရစ်များကို ရက်ပေါင်း ၆၀ ကြာပြီးနောက် နိုင်ငံအဆင့်တွင် ပေါင်းစည်းပါမည်။ ဆာဗာစီမံခန့်ခွဲသူများသည် အသုံးပြုမှုမက်ထရစ် မျှဝေခြင်း သတ်မှတ်ချက်ကို ‘Outline မန်နေဂျာ’ ရှိ ‘ဆက်တင်များ’ မီနူးကို ဝင်ကြည့်ခြင်းဖြင့် အချိန်မရွေး ပြောင်းနိုင်သည်။

Firewall အမှားများ

GKMS WEB

သင်ကြုံတွေ့နိုင်သော Firewall ပြဿနာ သုံးမျိုးရှိသည်-

ကွန်ရက် Firewall က သင့်ကို ပိတ်ထားနိုင်သည်။

ကျောင်း (သို့) သင့်လုပ်ငန်းခွင်တွင်ကဲ့သို့ Firewall ဖြင့် ကာကွယ်ထားသော ကွန်ရက်နှင့် ချိတ်ဆက်ထားစဉ် Outline ထည့်သွင်းနေခြင်းဖြစ်ပါက အခြားကွန်ရက်သုံးနေစဉ် ထည့်သွင်းကြည့်ပါ။

၎င်းအလုပ်မလုပ်ပါက Firewall ဖြင့် ကာကွယ်ထားသော ကွန်ရက်နှင့် သင်၏ Outline ဆာဗာကြား ချိတ်ဆက်မှုများအတွက် ခွင့်ပြုရန် ကွန်ရက်စီမံခန့်ခွဲသူထံ ဆက်သွယ်ပါ။ သင့် Outline ဆာဗာ၏ IP လိပ်စာနှင့် Outline လုပ်ဆောင်နေသော ပို့တ်များကို သိရှိရမည်ဖြစ်ပြီး ၎င်းတို့ကို ထည့်သွင်းမှု Script အဆုံးတွင် ပြထားသည်။

စက် Firewall က သင့်ကို ပိတ်ထားနိုင်သည်။

သင့်စက်၌ ပုံမှန်မဟုတ်သော ပို့တ် (သို့) အသိအမှတ်မပြုသော ဆော့ဖ်ဝဲတွင် အထွက်ချိတ်ဆက်မှုများကို ပိတ်သော ဆော့ဖ်ဝဲရှိပါက (CheckPoint ၏ ZoneAlarm), Outline အတွက် ခြွင်းချက်ပြုလုပ်နည်းကို လေ့လာရန် သင်၏ စက် (သို့) ဆော့ဖ်ဝဲမှတ်တမ်းကို မှီငြမ်းပါ။

ဆာဗာ Firewall က သင့်ကို ပိတ်ထားနိုင်သည်။

သင်ရွေးထားသော Cloud ဝန်ဆောင်မှုပေးသူသည် သင့်အား ဆာဗာ Firewall တွင် ခြွင်းချက်များကို ကိုယ်တိုင်ပြုလုပ်ခိုင်းပြီး Outline လုပ်ဆောင်နေသော ပို့တ်များကို ဖွင့်ခိုင်းနိုင်သည်။ ထည့်သွင်းမှု Script ကို လုပ်ဆောင်ပြီးနောက် သင့်ဆာဗာတွင် Outline လုပ်ဆောင်နေသည့် ကျပန်းရွေးထားသော ပို့တ်နှစ်ခုကို သင့်အား တင်ပြပါမည်။ ဤပို့တ်နှစ်ခုကို ဖွင့်ရုံဖြင့် လုံလောက်ပါသည်။

သင်၏ ‘ဆာဗာ Firewall’ တွင် ခြွင်းချက်များ ပြုလုပ်ရန်အတွက် ‘ufw’ နှင့် ‘iptables’ အတွက် မှတ်တမ်းလေ့လာရန် အကြံပြုပါသည်-
