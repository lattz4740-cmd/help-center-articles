Seguranza e privacidade mentres se usa Outline

Como protexe Outline as túas comunicacións en liña?

O tráfico de Internet é máis vulnerable á vixilancia cando viaxa pola túa rede local ou nacional.

Outline axuda a protexer a privacidade das túas comunicacións encriptando o tráfico de Internet mentres pasa pola túa rede nacional. Ademais, manteno encriptado ata que chegue ao servidor de Outline. Cando se encripta o tráfico con Outline, os observadores da rede non poden inspeccionar os sitios web que visitas nin a información que transfires.

Outline tamén che pode axudar a recuperar o acceso a ferramentas de comunicación seguras de extremo a extremo que igual non están dispoñibles no teu país. 

Estándares de encriptación

Outline encripta as comunicacións entre o teu dispositivo e o servidor de Outline mediante a cifraxe Chacha2020 IETF Poly 1305 de 256 bits de AEAD. A cifraxe de AEAD ofrece confidencialidade, integridade e autenticidade, e ten un rendemento excelente no hardware moderno. 

Auditorías de seguranza

En 2018, Outline someteuse ás auditorías de Radically Open Security e Cure53, dúas organizacións de seguranza dixital independentes que revisan software para ver se cumpre os estándares de seguranza máis recentes. Radically Open Security realizou unha auditoría adicional en 2022 e Cure53 levou a cabo outra do SDK de Outline en 2024. Podes ler os informes nestas ligazóns:

  • Informe de proba de penetración de Radically Open Security (marzo de 2018)
  • Informe de auditoría e proba de penetración de Cure53 sobre Outline de Jigsaw (decembro de 2018)
  • Informe de proba de penetración de Radically Open Security (decembro de 2022)
  • Informe de proba de penetración de Cure53 sobre o SDK da VPN de Outline de Jigsaw (xaneiro de 2024)

Métricas e rexistros anónimos

Outline fai un seguimento da largura de banda utilizada, como "bytes transferidos" para cada clave de acceso. Esta información permítelle a quen administre o servidor axustar as subscricións de largura de banda cos provedores do seu servidor na nube segundo sexa necesario, pero non ver a información real que pasou polo servidor de Outline.

Obtén máis información sobre a recompilación de datos e información de Outline.

Preguntas frecuentes sobre seguranza e privacidade 

Outline pode anonimizarme en liña?

Non, Outline non é unha ferramenta de anonimización. Outline protexe a túa privacidade dos posibles observadores da rede.

Outline non che ofrece anonimato absoluto nos sitios web que visitas, xa que te poden identificar cando inicias sesión e, ás veces, tamén mediante técnicas como a creación da impresión dixital do navegador. No caso das aplicacións para móbiles, case todos os smartphones modernos dispoñen de API que permiten que as aplicacións instaladas obteñan a túa localización independentemente do teu proxy, xa que poden usar o GPS integrado.

En xeral, as VPN ofrecen unha protección avanzada, sobre todo no referente á vixilancia en Internet, pero operar en liña sempre ten os seus riscos. Aínda que teñas unha VPN, se un provedor de Internet xa coñece a túa identidade e pode observar o teu tráfico de rede, é posible que poida determinar o enderezo IP do teu servidor de Outline. Con esta información, pode bloquear o acceso ao servidor de Outline ou descubrir padróns de uso (por exemplo, cando adoitas estar en liña e, posiblemente, a túa localización aproximada). 

Alguén pode saber se estou usando Outline?

Posiblemente. O máis probable é que as plataformas e servizos aos que accedes sexan capaces de saber se a túa conexión procede dun servidor na nube. De cando en vez, poden deducir que utilizas unha VPN, pero non poden ver o contido do teu tráfico de Internet. 

Outline protéxeme de todas as ameazas cibernéticas posibles?

Non, non hai ningunha ferramenta que te protexa de todas as ameazas cibernéticas posibles. Outline dáche acceso á Internet aberta e encripta o teu tráfico para mellorar a privacidade. Porén, recomendámosche que tomes precaucións adicionais para protexerte contra outro tipo de ataques, como o software malicioso e o phishing.

Para reforzar as túas defensas en liña, é aconsellable que traballes coa persoa que se encarga da ciberseguranza na túa organización. Tamén podes obter orientación personalizada dos especialistas en seguranza de Security Planner, un sitio web creado co fin de ofrecer instrucións claras para elixir as ferramentas de ciberseguranza que se adapten ás túas necesidades.

Podes revisar outros produtos de ciberseguranza de Jigsaw, como Intra, Project Shield e Alerta de protección de contrasinal. 

É legal usar unha VPN?

Antes de usar Outline ou a aplicación, consulta as leis e os regulamentos locais, así como as condicións de servizo do provedor de servizos na nube que teñas previsto utilizar.

Instalar o cliente de Outline en Linux

GKMS WEB

As versións 1.15 e posteriores do cliente de Outline lanzaranse como paquetes Debian para os sistemas operativos Linux. Se necesitas máis información sobre os sistemas operativos compatibles, bótalles unha ollada aos requisitos mínimos do sistema.

 

Instalar o cliente de Outline para distribucións de Linux baseadas en Debian (opción recomendada)

 

Executa os seguintes comandos:

  1. Engade o almacén de Outline despois de instalar a súa clave.

    wget -qO- https://us-apt.pkg.dev/doc/repo-signing-key.gpg | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/gcloud-artifact-registry-us.gpg

    echo "deb [arch=amd64] https://us-apt.pkg.dev/projects/jigsaw-outline-apps outline-client main" | sudo tee /etc/apt/sources.list.d/outline-client.list

  2.  Actualiza a lista de paquetes apt e instala a versión máis recente do cliente de Outline.

   sudo apt update

   sudo apt install outline-client

Para comprobar se hai actualizacións ou instalalas no futuro, volve executar os comandos do paso 2. Ten presente que, a partir da versión 1.15, a opción de actualización automática na aplicación está desactivada para o cliente de Outline en Linux.

Para desinstalar o cliente de Outline, executa o seguinte comando:

sudo apt purge outline-client

Opción alternativa

  1. Descarga a versión máis recente do paquete Debian do cliente de Outline en https://s3.amazonaws.com/outline-releases/client/linux/stable/outline-client_amd64.deb
  2. Para instalalo, executa na liña correspondente os comandos que se indican a continuación:

wget -O ./outline-client.deb https://s3.amazonaws.com/outline-      releases/client/linux/stable/outline-client_amd64.deb

sudo apt install ./outline-client.deb

  3.  Busca as actualizacións manualmente, xa que a opción automática da aplicación está desactivada para o cliente de Outline en Linux a partir das versións 1.15 e posteriores.

  4.  Para desinstalar o cliente de Outline, executa o seguinte comando na liña de comandos:

sudo apt purge outline-client
