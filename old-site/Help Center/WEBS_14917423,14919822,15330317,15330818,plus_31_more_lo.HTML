ການຕິດຕັ້ງເຊີບເວີ

​ເຖິງແມ່ນວ່າການຕິດຕັ້ງ Outline ອາດເບິ່ງຄືງ່າຍ, ແຕ່ຄວາມຈິງແລ້ວມີຂັ້ນຕອນທີ່ຊັບຊ້ອນເກີດຂຶ້ນຢູ່ເບື້ອງຫຼັງຫຼາຍຢ່າງໃນການຕິດຕັ້ງເຊີບເວີຂອງທ່ານ. ເມື່ອໃດກໍຕາມທີ່ມີການຕິດຕັ້ງ Outline, ສະຄຣິບການຕິດຕັ້ງຈະເອີ້ນໃຊ້ຂັ້ນຕອນຕໍ່ໄປນີ້:

  • ລະບົບຈະດຶງຂໍ້ມູນ ແລະ ນຳເຂົ້າຮູບ Shadowbox ເວີຊັນສະຖຽນໂດຍໃຊ້ Docker. ລະບົບຈະຝາກຮູບດັ່ງກ່າວໄວ້ຢູ່ Quay.io, ໃນ https://quay.io/repository/outline/shadowbox?tab=tags. ຮູບນີ້ຈະປະກອບດ້ວຍເຊີບເວີ Outline ແລະ API ການຈັດການເຊິ່ງແອັບພລິເຄຊັນການຈັດການເຊີບເວີ Outline ຈະນຳໄປໃຊ້ໃນພາຍຫຼັງເພື່ອສ້າງ ແລະ ລຶບກະແຈການເຂົ້າເຖິງອອກ, ເລືອກໃຊ້/ບໍ່ໃຊ້ການລາຍງານການວັດແທກທີ່ບໍ່ລະບຸຕົວຕົນ ແລະ ອື່ນໆ.
  • Watchtower ຈະໄດ້ຮັບການຕິດຕັ້ງ ແລະ ຕັ້ງຄ່າເພື່ອກວດສອບການອັບເດດຮູບທຸກໆຊົ່ວໂມງເພື່ອໃຫ້ໝັ້ນໃຈໄດ້ວ່າເຊີບເວີ Outline ທຸກເຄື່ອງຈະໄດ້ຮັບການອັບເດດຄຸນສົມບັດ ແລະ ການປັບປຸງການຮັກສາຄວາມປອດໄພເວີຊັນຫຼ້າສຸດຢູ່ສະເໝີ.
  • ເວັບເຊີບເວີທີ່ໃຊ້ເຂົ້າເຖິງ API ການຈັດການຈະເລີ່ມຕົ້ນເຮັດວຽກໃນຜອດແບບສຸ່ມໃນເສັ້ນທາງລັບ ແລະ ສຸ່ມ.
  • ລະບົບຈະສ້າງ ໃບຮັບຮອງ SSL ແບບເຊັນດ້ວຍຕົນເອງ ຂຶ້ນເພື່ອໃຫ້ສາມາດເຂົ້າລະຫັດການຈັດການເຊີບເວີ Outline ໄດ້ໂດຍໃຊ້ TLS ເຖິງແມ່ນວ່າຈະບໍ່ມີຊື່ໂດເມນກໍຕາມ. ນອກຈາກນີ້, ລະບົບຍັງຈະສ້າງລາຍນິ້ວມືທີ່ບໍ່ຊ້ຳກັນຂອງໃບຮັບຮອງນີ້ ແລະ ຈັດເກັບໄວ້ໃນແອັບພລິເຄຊັນ Outline Manager, ເຊິ່ງຊ່ວຍປ້ອງກັນຈາກການໂຈມຕີແບບ MITM.

ເມື່ອຕິດຕັ້ງ Outline ແລ້ວບໍ່ຈຳເປັນຕ້ອງຕັ້ງຄ່າໃດໆຫຼັງຈາກການຕິດຕັ້ງ.

ຄວາມປອດໄພຂອງເຊີບເວີ

ຊອບແວ Outline ເປັນຊອບແວໂອເພນຊອດ, ເຊິ່ງໝາຍຄວາມວ່າທຸກຄົນສາມາດເຫັນ ແລະ ປັບປຸງໂຄດໄດ້ຫາກພົບຊ່ອງຫວ່າງໃດໆ. ເຊິ່ງພວກເຮົາຝາກໂຄດໄວ້ຢູ່ GitHub.

ນອກຈາກນີ້, ເຊີບເວີ Outline ທີ່ຕິດຕັ້ງທັງໝົດຈະໄດ້ຮັບການອັບເດດໂດຍອັດຕະໂນມັດທຸກເທື່ອທີ່ມີການເປີດໂຕເວີຊັນໃໝ່ເພື່ອໃຫ້ໝັ້ນໃຈໄດ້ວ່າຈະບໍ່ມີເຊີບເວີ Outline ໃດໃຊ້ຊອບແວເວີຊັນເກົ່າ.

ແອັບພລິເຄຊັນ Outline Manager ຈະໂຕ້ຕອບກັບບໍລິການການຈັດການໃນເຊີບເວີ Outline ເພື່ອຈັດການກະແຈການເຂົ້າເຖິງໃນເຊີບເວີດັ່ງກ່າວ. ໂດຍບໍລິການການຈັດການຈະເຮັດວຽກໃນຜອດແບບສຸ່ມ ຮວມທັງໃນເສັ້ນທາງລັບ ແລະ ບໍ່ຊ້ຳກັນ. ບໍລິການການຈັດການແມ່ນມີຄວາມຕ້ານທານຕໍ່ການເຈາະຂໍ້ມູນ ເນື່ອງຈາກມັນບໍ່ຕອບສະໜອງຕໍ່ການສອບຖາມເວັ້ນເສຍແຕ່ໄດ້ກໍານົດເສັ້ນທາງລັບທີ່ເໝາະສົມໄວ້ແລ້ວ. ສຸດທ້າຍ, ການສື່ສານທັງໝົດກັບບໍລິການການຈັດການຈະໄດ້ຖືກເຂົ້າລະຫັດດ້ວຍ ໃບຮັບຮອງ SSL ແບບເຊັນດ້ວຍຕົນເອງ.

ນອກຈາກນີ້, ເຊີບເວີ Outline ຈະບໍ່ຈັດເກັບບັນທຶກໃດໆ, ດັ່ງນັ້ນເຖິງແມ່ນວ່າຈະຖືກຮຸກຮານແຕ່ກໍຈະບໍ່ມີການເປີດເຜີຍຂໍ້ມູນຜູ້ໃຊ້. ສຶກສາເພີ່ມເຕີມໄດ້ ບ່ອນນີ້. Outline ໄດ້ຮັບການກວດສອບໂດຍ Radically Open Security ແລະ Cure53 ໃນປີ 2018. ເບິ່ງລາຍງານໄດ້ ບ່ອນນີ້.

ການຈັດການການຮັບສົ່ງຂໍ້ມູນ UDP

Outline ສາມາດນຳໃຊ້ໄດ້ໃນຮູບແບບ VPN ທົ່ວທັງລະບົບ, ເຊິ່ງໝາຍຄວາມວ່າການຮັບສົ່ງຂໍ້ມູນ UDP ທັງໝົດຈະສົ່ງຜ່ານເຊີບເວີ Outline.

ການຮັບສົ່ງຂໍ້ມູນ DNS


Outline ຈະດຳເນີນການຊອກຫາ DNS ທັງໝົດຜ່ານເຊີບເວີ Outline ແລະ ປົກປ້ອງການຊອກຫາເຫຼົ່ານັ້ນໂດຍໃຊ້ການເຂົ້າລະຫັດແບບດຽວກັນກັບທີ່ໃຊ້ໃນການເຄື່ອນໄຫວເຄືອຂ່າຍອື່ນໆທັງໝົດ. ລະບົບຈະສົ່ງຄຳຊອກຫາ DNS ຂອງທ່ານໄປຫາ Dyn Internet Guide, OpenDNS, Cloudflare DNS ຫຼື Quad9 DNS ໂດຍຜ່ານເຊີບເວີ Outline. Outline ຈະບໍ່ບັນທຶກການຊອກຫາ DNS ຂອງທ່ານ.

ຄວາມປອດໄພ ແລະ ຄວາມເປັນສ່ວນຕົວໃນຂະນະທີ່ໃຊ້ Outline

ວິທີທີ່ Outline ປົກປ້ອງການສື່ສານອອນລາຍຂອງທ່ານ

ທຣາບຟິກອິນເຕີເນັດມີຄວາມສ່ຽງຕໍ່ການຖືກຕິດຕາມຫຼາຍທີ່ສຸດໃນຂະນະທີ່ຂໍ້ມູນເດີນທາງຜ່ານເຄືອຂ່າຍໃນພື້ນທີ່ ຫຼື ລະດັບປະເທດຂອງທ່ານ.

Outline ຈະຊ່ວຍໃຫ້ການສື່ສານຂອງທ່ານມີຄວາມເປັນສ່ວນຕົວໂດຍການເຂົ້າລະຫັດທຣາບຟິກອິນເຕີເນັດຂອງທ່ານໃນຂະນະທີ່ຂໍ້ມູນເດີນທາງພາຍໃນເຄືອຂ່າຍລະດັບປະເທດຂອງທ່ານ ແລະ ຄົງການເຂົ້າລະຫັດໄວ້ຈົນກວ່າການສື່ສານນັ້ນຈະຮອດເຊີບເວີ Outline. ເມື່ອການເຂົ້າເບິ່ງໄດ້ຖືກເຂົ້າລະຫັດດ້ວຍ Outline, ບຸກຄົນອື່ນທີ່ສັງເກດການຢູ່ໃນເຄືອຂ່າຍຈະບໍ່ສາມາດກວດສອບເວັບໄຊທີ່ທ່ານເຂົ້າເບິ່ງ ຫຼື ຂໍ້ມູນທີ່ທ່ານໂອນຍ້າຍໄດ້.

Outline ຍັງອາດຊ່ວຍໃຫ້ທ່ານກູ້ຄືນສິດເຂົ້າເຖິງເຄື່ອງມືການສື່ສານແບບຕົ້ນທາງໄປຫາປາຍທາງທີ່ປອດໄພເຊິ່ງປົກກະຕິອາດບໍ່ສາມາດເຂົ້າເຖິງໄດ້ໃນປະເທດຂອງທ່ານ. 

ມາດຕະຖານການເຂົ້າລະຫັດ

Outline ຈະເຂົ້າລະຫັດການສື່ສານລະຫວ່າງອຸປະກອນຂອງທ່ານກັບເຊີບເວີ Outline ໂດຍໃຊ້ການເຂົ້າລະຫັດ AEAD 256-bit Chacha2020 IETF Poly 1305. ການເຂົ້າລະຫັດ AEAD ຈະມອບການຮັກສາຄວາມລັບ, ຄວາມສົມບູນແບບ ແລະ ຄວາມຖືກຕ້ອງ, ຮວມທັງສະແດງປະສິດທິພາບທີ່ດີເລີດໃນຮາດແວສະໄໝໃໝ່. 

ການກວດສອບຄວາມປອດໄພ

Outline ໄດ້ຮັບການກວດສອບໂດຍ Radically Open Security ແລະ Cure53 ໃນປີ 2018, ເຊິ່ງເປັນອົງກອນດ້ານຄວາມປອດໄພດິຈິຕອນອິດສະຫຼະທັງ 2 ແຫ່ງທີ່ກວດສອບຊອບແວກັບມາດຕະຖານຄວາມປອດໄພຫຼ້າສຸດ. Radically Open Security ໄດ້ດຳເນີນການກວດສອບເພີ່ມເຕີມໃນປີ 2022 ແລະ Cure53 ໄດ້ດຳເນີນການກວດສອບ Outline SDK ໃນປີ 2024. ທ່ານສາມາດອ່ານລາຍງານໄດ້ບ່ອນນີ້:

  • Radically Open Security Penetration Test Report (ມີນາ 2018)
  • Cure53 Pentest & Audit Report Jigsaw Outline (ທັນວາ 2018)
  • Radically Open Security Penetration Test Report (ທັນວາ 2022)

ຂັ້ນຕອນອາດແຕກຕ່າງກັນໄປຕາມເວີຊັນຂອງລະບົບປະຕິບັດການ Windows ຂອງທ່ານ, ແຕ່ທາງລຸ່ມນີ້ແມ່ນຂັ້ນຕອນທົ່ວໄປສຳລັບວິທີຖອນການຕິດຕັ້ງອະແດັບເຕີ TAP ແລະ Outline, ຈາກນັ້ນຈຶ່ງຕິດຕັ້ງ Outline ຄືນໃໝ່.

    • ເຂົ້າໄປ ຕົວຈັດການອຸປະກອນ, ຈາກນັ້ນເຂົ້າໄປ ອະແດັບເຕີເຄືອຂ່າຍ

    • ຖອນການຕິດຕັ້ງ ຫຼື ລຶບອະແດັບເຕີນີ້. ກະລຸນາຮັບຊາບວ່າການດຳເນີນການນີ້ອາດສົ່ງຜົນຕໍ່ແອັບ VPN ອື່ນໆທີ່ທ່ານຕິດຕັ້ງໄວ້.

ທ່ານສາມາດຕັ້ງຄ່າຂີດຈຳກັດຂອງຂໍ້ມູນເຊິ່ງຈະມີຜົນກັບກະແຈການເຂົ້າເຖິງທັງໝົດໄດ້. ເພື່ອຕັ້ງຄ່າຂີດຈຳກັດ, ໃຫ້ເປີດ Outline Manager ແລະ ນຳທາງໄປຫາການຕັ້ງຄ່າ. ໂດຍທ່ານຈະເຫັນປຸ່ມສະຫຼັບຂີດຈຳກັດຂອງຂໍ້ມູນເຊິ່ງເມື່ອເປີດການນຳໃຊ້ແລ້ວ, ຈະຊ່ວຍໃຫ້ທ່ານຕັ້ງຄ່າຂີດຈຳກັດໄດ້.

ເມື່ອທ່ານຕັ້ງຂີດຈຳກັດແລ້ວ, ທ່ານຈະສາມາດເບິ່ງເຫັນໄດ້ວ່າຜູ້ໃຊ້ແຕ່ລະຄົນເຂົ້າໃກ້ຂີດຈຳກັດຫຼາຍປານໃດຢູ່ໜ້າກະແຈສິດເຂົ້າເຖິງ, ເຊິ່ງຈະມີກຣາບແບບແຖບສະແດງການນຳໃຊ້ໃນຮອບ 30 ມື້ທີ່ຜ່ານມາ.

ນອກຈາກການຕັ້ງຄ່າຂີດຈຳກັດສຳລັບກະແຈການເຂົ້າເຖິງທັງໝົດຂອງທ່ານແລ້ວ, ທ່ານຍັງສາມາດກຳນົດຂີດຈຳກັດຂອງຂໍ້ມູນໃຫ້ກັບກະແຈແຕ່ລະລາຍການໄດ້ນຳ. ການຕັ້ງຄ່ານີ້ຈະຍົກເລີກຂີດຈຳກັດຂອງຂໍ້ມູນຄ່າເລີ່ມຕົ້ນໃດໆທີ່ທ່ານເຄີຍຕັ້ງໄວ້, ແຕ່ຫາກທ່ານບໍ່ໄດ້ຕັ້ງຄ່າຂີດຈຳກັດຂອງຂໍ້ມູນຄ່າເລີ່ມຕົ້ນໄວ້, ທ່ານຍັງຄົງສາມາດຕັ້ງຄ່າຂີດຈຳກັດຂອງຂໍ້ມູນສຳລັບກະແຈໃດໆໄດ້ຢູ່. 

ເພື່ອຕັ້ງຄ່າຂີດຈຳກັດການໂອນຍ້າຍຂໍ້ມູນຂອງກະແຈ, ໃຫ້ເປີດ Outline Manager, ແລ້ວນຳທາງໄປຫາແຖບການເຊື່ອມຕໍ່ທີ່ມີກະແຈທີ່ທ່ານຕ້ອງການຕັ້ງຄ່າ, ຈາກນັ້ນຄລິກເມນູຢູ່ເບື້ອງຂວາຂອງແຖວຂອງກະແຈ. ຈາກບ່ອນນັ້ນ, ໃຫ້ຄລິກໃສ່ຂີດຈໍາກັດຂໍ້ມູນ. ເພື່ອປ່ຽນຂີດຈຳກັດຂໍ້ມູນໃນ "ກະແຈການເຂົ້າເຖິງຂອງຂ້ອຍ", ໃຫ້ຄລິກທີ່ໄອຄອນຂີດຈຳກັດຂໍ້ມູນ .

ເລືອກການຕັ້ງຄ່າຂີດຈຳກັດຂໍ້ມູນແບບກໍານົດເອງ. ເມື່ອທ່ານເລືອກກ່ອງໝາຍນີ້ແລ້ວ, ຊ່ອງຂໍ້ມູນຈະປາກົດຂຶ້ນບ່ອນທີ່ທ່ານສາມາດຕັ້ງຄ່າຂີດຈຳກັດຂໍ້ມູນແບບກຳນົດເອງສຳລັບກະແຈນັ້ນ. ຄລິກທີ່ປຸ່ມບັນທຶກເມື່ອທ່ານເຮັດສຳເລັດແລ້ວເພື່ອບັນທຶກຂີດຈຳກັດຂໍ້ມູນ.

ເມື່ອທ່ານໄດ້ບັນທຶກຂີດຈໍາກັດການໂອນຂໍ້ມູນຂອງທ່ານສໍາລັບກະແຈທີ່ເລືອກແລ້ວ, ຂີດຈໍາກັດຈະສະແດງຢູ່ໃນໜ້າຈໍຫຼັກ, ຄຽງຄູ່ກັບການນໍາໃຊ້ຂໍ້ມູນ (ໃນໄລຍະ 30 ມື້ທີ່ຜ່ານມາ) ສໍາລັບແຕ່ລະກະແຈ.

ເພື່ອລຶບຂີດຈຳກັດຂໍ້ມູນອອກຈາກກະແຈການເຂົ້າເຖິງ, ໃຫ້ນຳທາງໄປທີ່ກ່ອງໂຕ້ຕອບຂີດຈຳກັດຂໍ້ມູນຂອງກະແຈຄືເກົ່າ, ຍົກເລີກການເລືອກກ່ອງທີ່ມີປ້າຍກຳກັບ ຕັ້ງຄ່າຂີດຈຳກັດຂໍ້ມູນແບບກຳນົດເອງ ແລະ ຄລິກທີ່ປຸ່ມບັນທຶກ.

ຂີດຈຳກັດຂອງຂໍ້ມູນຊ່ວງເວລາຫຼ້າສຸດ 30 ມື້ຈະສະຫຼຸບຂໍ້ມູນການນຳໃຊ້ຂອງກະແຈແຕ່ລະລາຍການໃນໄລຍະ 30 ມື້ທີ່ຜ່ານມາ ແລະ ຈຳກັດການນຳໃຊ້ກະແຈໃນໄລຍະເວລາດັ່ງກ່າວໃຫ້ຢູ່ພາຍໃຕ້ຂີດຈຳກັດ. ຜົນກໍຄືການນຳໃຊ້ກະແຈຈະບໍ່ເກີນຂີດຈຳກັດບໍ່ວ່າໃນໄລຍະເວລາ 30 ມື້ໃດກໍຕາມ, ໂດຍຮວມທັງເດືອນຕາມປະຕິທິນທີ່ມີຈຳນວນມື້ບໍ່ເກີນ 30 ມື້ນຳ. ເຊິ່ງໝາຍຄວາມວ່າປະລິມານຂໍ້ມູນທີ່ໃຊ້ໄດ້ຈະເພີ່ມຂຶ້ນໃນແຕ່ລະມື້ຕາມປະລິມານທີ່ໃຊ້ໄປເມື່ອ 31 ມື້ກ່ອນ.

ຂີດຈຳກັດຊ່ວງເວລາຫຼ້າສຸດຈະໃຫ້ການຮັບປະກັນໃນໄລຍະເວລາ 30 ມື້, ເຊິ່ງໝາຍຄວາມວ່າຈະຕັ້ງຄ່າໄດ້ງ່າຍກວ່າຂີດຈຳກັດທີ່ເກີດຂຶ້ນເລື້ອຍໆ (ເຊັ່ນ: ມື້ທີ່ປັບແຕ່ງເອງໄດ້ຂອງເດືອນນັ້ນໆ) ໂດຍທີ່ມີການຮັບປະກັນໃນຮູບແບບທີ່ຄ້າຍກັນ. ນອກຈາກນີ້, ກໍຍັງກົງກັບການສະແດງປະລິມານການໃຊ້ຂໍ້ມູນ Outline ທີ່ມີຢູ່, ຮວມທັງເຄື່ອງມືທົ່ວໄປ ເຊັ່ນ: ບໍລິການວິເຄາະ ແລະ ສະຖິຕິຂອງເຊີບເວີນຳ.

ຂໍ້ມູນໃດແດ່ທີ່ຈະນັບຮວມໃນຂີດຈຳກັດຂອງຂໍ້ມູນ?

ຂໍ້ມູນຂາອອກຂອງກະແຈການເຂົ້າເຖິງແຕ່ລະລາຍການຈາກເຊີບເວີຈະຮວມຢູ່ໃນການນັບນຳ. ຫາກກ່າວໃຫ້ສະເພາະເຈາະຈົງກໍຄືເມື່ອຂໍ້ມູນທີ່ສົ່ງໃນນາມຂອງກະແຈເດີນທາງອອກຈາກເຊີບເວີ, ຮວມທັງຂໍ້ມູນທີ່ເດີນທາງກັບຄືນໄປຫາລູກຂ່າຍນຳ. ຕາມຕົວຈິງແລ້ວ, ສິ່ງນີ້ຄວນຈະສອດຄ່ອງຢ່າງໃກ້ຊິດກັບການຈະລາຈອນທີ່ສົ່ງຈາກກະແຈໄປຫາເຊີບເວີ ແລະ ກັບຄືນ, ດັ່ງນັ້ນພວກເຮົາຫວັງວ່າມັນຈະກົງກັບຕົວເລກຂອງຜູ້ໃຊ້ຂອງທ່ານ. ພວກເຮົາເລືອກໃຊ້ຂໍ້ມູນຂາອອກເນື່ອງຈາກຜູ້ໃຫ້ບໍລິການຄລາວທີ່ພວກເຮົາສຳຫຼວດຈະຮຽກເກັບເງິນຈາກຂໍ້ມູນສ່ວນນີ້.

ຜູ້ໃຊ້ຈະໄດ້ຮັບການແຈ້ງເຕືອນຫາກເຂົາເຈົ້າໃຊ້ຂໍ້ມູນເກີນຂີດຈຳກັດບໍ?

ຍັງບໍ່ໄດ້ໃນຕອນນີ້. ຜູ້ໃຫ້ບໍລິການຄລາວຈຳນວນຫຼາຍກຳນົດຂີດຈຳກັດ ເຊັ່ນ: 1 TB ຕະຫຼອດທັງເດືອນ, ເຊິ່ງສາມາດຮອງຮັບຜູ້ໃຊ້ໄດ້ 10 ຄົນໆລະ 100 GB ຫຼື 100 ຄົນໆລະ 10 GB. ສິ່ງເຫຼົ່ານີ້ແມ່ນຕົວເລກຂ້ອນຂ້າງຫຼວງຫຼາຍ ແລະ ພວກເຮົາບໍ່ໄດ້ຄາດຫວັງວ່າຜູ້ໃຊ້ຫຼາຍຄົນຈະໃຊ້ຮອດພວກມັນ. ພວກເຮົາຫວັງວ່າຜູ້ໃຊ້ຈະໄປຮອດຕົວຈັດການເຊີບເວີເມື່ອເຂົາເຈົ້າຮອດຂີດຈໍາກັດຂອງເຂົາເຈົ້າແລ້ວ. ແນວໃດກໍຕາມ, ພວກເຮົາຂໍຂອບໃຈສຳລັບຂໍ້ມູນເຈາະເລິກກ່ຽວກັບວິທີທີ່ການແຈ້ງເຕືອນອາດເປັນປະໂຫຍດຕໍ່ກໍລະນີການນຳໃຊ້ຂອງທ່ານ ແລະ ທ່ານສາມາດຕິດຕໍ່ພວກເຮົາໄດ້ ບ່ອນນີ້.

ຜູ້ໃຊ້ຈະໄດ້ຮັບການແຈ້ງເຕືອນຫາກເຂົາເຈົ້າໃກ້ຮອດຂີດຈຳກັດຂອງຂໍ້ມູນຂອງຕົນເອງບໍ?

ປະລິມານຂໍ້ມູນໃໝ່ທີ່ຜູ້ໃຊ້ໃກ້ຮອດຂີດຈຳກັດຈະໄດ້ຮັບນັ້ນຈະແຕກຕ່າງກັນໄປໃນແຕ່ລະມື້ເນື່ອງຈາກຈະຂຶ້ນຢູ່ກັບການນຳໃຊ້ໃນໄລຍະ 30 ມື້ກ່ອນ. ພວກເຮົາຄິດວ່າຄຳເຕືອນອາດເຮັດໃຫ້ຜູ້ໃຊ້ປາຍທາງສັບສົນຫຼາຍກວ່າທີ່ຈະເປັນປະໂຫຍດ. ຫາກທ່ານມີຄຳຕິຊົມກ່ຽວກັບກໍລະນີນີ້, ກະລຸນາແຈ້ງໃຫ້ພວກເຮົາຮູ້ ບ່ອນນີ້.

ຂ້ອຍຈະຣີເຊັດປະລິມານການນຳໃຊ້ຂໍ້ມູນຂອງຜູ້ໃຊ້ໄດ້ບໍ?

ບໍ່ໄດ້, ຂີດຈຳກັດຂອງຜູ້ໃຊ້ຈະຮວມການໃຊ້ຂໍ້ມູນໃນໄລຍະ 30 ມື້ທີ່ຜ່ານມາສະເໝີ. ແນວໃດກໍຕາມ, ທ່ານສາມາດເພີ່ມຂີດຈຳກັດຂອງຂໍ້ມູນສຳລັບກະແຈ ຫຼື ສ້າງກະແຈໃໝ່ໃຫ້ເຂົາເຈົ້າກໍໄດ້.

ເປັນຫຍັງຜູ້ໃຊ້ບາງສ່ວນຂອງຂ້ອຍຈຶ່ງເສຍສິດເຂົ້າເຖິງໃນທັນທີທີ່ຂ້ອຍເປີດການນຳໃຊ້ຂີດຈຳກັດຂອງຂໍ້ມູນ?

ຂີດຈຳກັດຂອງຂໍ້ມູນຈະອີງຕາມການໂອນຍ້າຍຂໍ້ມູນຂອງຜູ້ໃຊ້ໃນໄລຍະ 30 ມື້ກ່ອນໜ້ານີ້, ເຊິ່ງລະບົບຈະບັນທຶກຂໍ້ມູນນີ້ບໍ່ວ່າຈະເປີດການນຳໃຊ້ຂີດຈຳກັດຂອງຂໍ້ມູນໄວ້ຫຼືບໍ່. ເຊິ່ງອາດເປັນໄປໄດ້ວ່າຜູ້ໃຊ້ຜູ້ນັ້ນນຳໃຊ້ຂໍ້ມູນເກີນຂີດຈຳກັດໄປແລ້ວກ່ອນທີ່ຈະມີການບັງຄັບໃຊ້ຂີດຈຳກັດ.  ນອກຈາກນີ້, ກະລຸນາຮັບຊາບວ່າລະບົບຈະບັງຄັບໃຊ້ຂີດຈຳກັດຂອງຂໍ້ມູນທຸກລາຍການ, ເຖິງແມ່ນວ່າຈະເປັນຕອນທີ່ປ່ຽນຂີດຈຳກັດຂອງຂໍ້ມູນຂອງກະແຈໃດກະແຈໜຶ່ງກໍຕາມ.

ຂ້ອຍຈະກຳນົດຂີດຈຳກັດຂອງທັງເຊີບເວີໄດ້ຫຼືບໍ່ ເຊັ່ນ: “1 TB ຕໍ່ 30 ມື້”?

ຍັງບໍ່ໄດ້ໃນຕອນນີ້. ກະລຸນາແຈ້ງຂໍ້ມູນເພີ່ມເຕີມກ່ຽວກັບກໍລະນີການນຳໃຊ້ຂອງທ່ານ ບ່ອນນີ້.

ຫາກມີຂີດຈຳກັດຂອງຂໍ້ມູນຄ່າເລີ່ມຕົ້ນ ແລະ ຂີດຈຳກັດຂອງຂໍ້ມູນໃນກະແຈໃດກະແຈໜຶ່ງໂດຍສະເພາະ, ລະບົບຈະບັງຄັບໃຊ້ຂີດຈຳກັດໃດ?

ຂີດຈຳກັດຂອງຂໍ້ມູນສະເພາະຂອງກະແຈນັ້ນໆຈະຍົກເລີກຂີດຈຳກັດຂອງຂໍ້ມູນຄ່າເລີ່ມຕົ້ນລາຍການໃດກໍຕາມທີ່ທ່ານຕັ້ງຄ່າໄວ້ (ຫາກມີ).

ຂ້ອຍຈະຕັ້ງຄ່າຂີດຈຳກັດຂອງຂໍ້ມູນສຳລັບກະແຈໃດກະແຈໜຶ່ງໂດຍສະເພາະໂດຍບໍ່ຕ້ອງຕັ້ງຄ່າຂີດຈຳກັດຂອງຂໍ້ມູນຄ່າເລີ່ມຕົ້ນໄດ້ບໍ?

ໄດ້.  ການຕັ້ງຄ່າຂີດຈຳກັດຂອງຂໍ້ມູນໃນກະແຈໃດກະແຈໜຶ່ງບໍ່ຈຳເປັນຕ້ອງມີການກຳນົດຂີດຈຳກັດເລີ່ມຕົ້ນ.  ຕົວຢ່າງ: ທ່ານສາມາດຕັ້ງຄ່າຂີດຈຳກັດໃນກະແຈທີ່ທ່ານຄິດວ່າອາດມີການແບ່ງປັນໃນວົງກວ້າງເພື່ອປ້ອງກັນບັນຫາຈາກການໂອນຍ້າຍຂໍ້ມູນຜ່ານກະແຈນັ້ນຫຼາຍເກີນໄປໄດ້.

firewall ຜິດພາດ

GKMS WEB

ບັນຫາຂອງ firewall ທີ່ທ່ານອາດພົບມີ 3 ຢ່າງດັ່ງນີ້:

ທ່ານອາດຖືກບລັອກໂດຍ firewall ຂອງເຄືອຂ່າຍ.

ຫາກທ່ານກຳລັງພະຍາຍາມຕິດຕັ້ງ Outline ໃນລະຫວ່າງທີ່ເຊື່ອມຕໍ່ກັບເຄືອຂ່າຍທີ່ມີ firewall ເຊັ່ນ: ຢູ່ໂຮງຮຽນ ຫຼື ໃນບ່ອນເຮັດວຽກຂອງທ່ານ, ໃຫ້ລອງຕິດຕັ້ງໂດຍໃຊ້ເຄືອຂ່າຍອື່ນ.

ຫາກບໍ່ໄດ້ຜົນ, ກະລຸນາຕິດຕໍ່ຜູ້ເບິ່ງແຍງລະບົບເຄືອຂ່າຍຂອງທ່ານເພື່ອອະນຸຍາດການເຊື່ອມຕໍ່ລະຫວ່າງເຄືອຂ່າຍທີ່ມີ firewall ກັບເຊີບເວີ Outline ຂອງທ່ານ. ທ່ານຈະຕ້ອງຮູ້ທີ່ຢູ່ IP ຂອງເຊີບເວີ Outline ຂອງທ່ານ ແລະ ຜອດທີ່ Outline ນຳໃຊ້, ເຊິ່ງມີການລະບຸໄວ້ຢູ່ໃນຕອນທ້າຍຂອງສະຄຣິບການຕິດຕັ້ງ.

ທ່ານອາດຖືກບລັອກໂດຍ firewall ຂອງອຸປະກອນ.

ຫາກທ່ານມີຊອບແວຢູ່ອຸປະກອນທີ່ບລັອກການເຊື່ອມຕໍ່ຂາອອກໃນຜອດທີ່ບໍ່ແມ່ນແບບມາດຕະຖານ ຫຼື ຊອບແວທີ່ບໍ່ຮູ້ຈັກ, (ZoneAlarm ຂອງ CheckPoint), ກະລຸນາອ່ານຄູ່ມືຂອງອຸປະກອນ ຫຼື ຊອບແວຂອງທ່ານເພື່ອສຶກສາວິທີສ້າງຂໍ້ຍົກເວັ້ນສຳລັບ Outline.

ທ່ານອາດຖືກບລັອກໂດຍ firewall ຂອງເຊີບເວີ.

ຜູ້ໃຫ້ບໍລິການຄລາວທີ່ທ່ານເລືອກອາດກຳນົດໃຫ້ທ່ານຕ້ອງສ້າງຂໍ້ຍົກເວັ້ນໃນ firewall ຂອງເຊີບເວີຂອງທ່ານດ້ວຍຕົນເອງ, ເພື່ອເປີດຜອດທີ່ Outline ນຳໃຊ້ຢູ່. ຫຼັງຈາກທີ່ທ່ານແລ່ນສະຄຣິບການຕິດຕັ້ງ, ທ່ານຄວນຖືກນໍາສະເໜີດ້ວຍສອງຜອດທີ່ເລືອກແບບສຸ່ມທີ່ Outline ກຳລັງແລ່ນຢູ່ໃນເຊີບເວີຂອງທ່ານ. ການເປີດທັງສອງຜອດນີ້ຄວນຈະພຽງພໍແລ້ວ.

ເພື່ອສ້າງຂໍ້ຍົກເວັ້ນໃນ firewall ຂອງເຊີບເວີຂອງທ່ານ, ພວກເຮົາຂໍແນະນຳໃຫ້ທ່ານອ່ານເອກະສານສຳລັບ 'ufw' ແລະ 'iptables' ດັ່ງນີ້:
