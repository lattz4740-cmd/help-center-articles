GKMS ARTICLE TITLE
Outline을 차단하기가 다른 대부분의 VPN보다 어려운 이유는 무엇인가요?

GKMS WEB

다음과 같은 이유로 차단 프로그램에서는 Outline이 까다롭습니다.

  1. 눈에 잘 띄는 코드를 사용하는 다른 VPN과 달리 인식하기 Outline은 어려운 특수 코드를 사용합니다.
  2. 서버 목록은 비공개로 유지되므로 차단 프로그램에서 쉽게 찾을 수 없습니다.
  3. 차단 프로그램이 Outline 서버 중 하나를 중지하더라도 Outline은 빠르게 새 서버를 만들 수 있습니다.

GKMS ARTICLE TITLE
Outline을 사용하려면 얼마를 지불해야 하나요?

GKMS WEB

Outline VPN은 무료로 사용할 수 있습니다.

하지만 DigitalOcean 또는 Amazon Web Services와 같은 곳에서 서버를 구매해야 하며, 비용은 매월 약 5달러입니다. 이 수수료는 서버 제공업체에 직접 지급되며 Outline과는 관련이 없습니다. 해당 제공업체에 정확한 가격을 물어보세요.

Google에서는 개인 정보를 안전하게 보호하고 있으니 안심하세요. Jigsaw와 Google은 사용자 또는 사용자의 데이터를 추적하지 않습니다. Google은 이 서비스로 수익을 창출하지 않으며 이는 인터넷을 무료로 이용할 수 있도록 하기 위함입니다.
