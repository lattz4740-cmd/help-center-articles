Como configurar vários servidores do Outline

Para configurar mais servidores do Outline, clique no ícone "+" no painel de navegação do lado esquerdo da aplicação Gestor Outline. As instruções para adicionar um novo servidor são iguais às da instalação de um primeiro servidor.

  • Não existe um limite para o número de servidores do Outline que pode criar.
  • Para cada servidor do Outline que criar, precisa de uma máquina virtual correspondente.
  • A criação de máquinas ou droplets adicionais pode aumentar as suas taxas junto do fornecedor de nuvem. Consulte o seu pacote de preços junto do fornecedor de nuvem para se certificar de que sabe o que esperar.

Criar um servidor do Outline adicional no DigitalOcean​

Depois de clicar no ícone + e selecionar a instalação no DigitalOcean, siga as mesmas instruções que usou para configurar o seu primeiro servidor. Além disso, uma vez que o Gestor Outline se integra com o DigitalOcean, podemos criar o droplet por si sem que tenha de sair da app Gestor Outline.

Tenha em atenção que o Gestor Outline só suporta uma conta do DigitalOcean de cada vez. Se quiser adicionar ou criar outros servidores do Outline a partir de outras contas do DigitalOcean, pode adicioná-los como uma configuração avançada.

Criar um servidor do Outline adicional na GCP, nos serviços Web da Amazon ou noutro fornecedor de serviços na nuvem​

Comece por criar uma nova máquina virtual com o fornecedor de nuvem escolhido. Em seguida, abra o Gestor Outline e siga as instruções para a instalação avançada, tal como fez da primeira vez.
