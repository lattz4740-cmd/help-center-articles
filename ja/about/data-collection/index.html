データと情報の収集

ユーザーが個人情報の提供を許可した場合を除き、Outline が個人情報を収集することはありません。また、ユーザーがアクセスするウェブサイトや、ユーザーの通信相手や通信内容に関する情報を収集することもありません。

お客様が Outline マネージャーを使用してサードパーティのクラウド プロバイダのアカウントを作成する場合や、そのアカウントにログインする場合に、お客様がクラウド プロバイダに提供する情報（メールアドレス、名前、課金情報、お支払いの詳細など）を Google が収集することは一切ありません。

Google が自動的に収集する情報​

Google は次の 2 種類の情報を自動的に収集します。

  1. サーバー IP

　　Outline のサーバー IP が Quay.io によって収集されます。サーバーが最新のセキュリティ機能や強化機能を伴って自動更新される際、Google はこのサーバーの IP アドレスにアクセスできるようになります。サーバーの IP アドレスからクラウド サーバー プロバイダや、Outline サーバーが設置されている都市が特定される可能性はありますが、サーバーの運用者や、サーバーにアクセスしているユーザーに関する情報が明らかになることはありません。

  1. 個人を特定できない技術情報

Outline で障害または深刻な例外が発生した場合や、ユーザーが Outline アプリを通じて手動でフィードバックを送信した場合は、以下に示す情報が報告されます。これらの情報は、安定性やパフォーマンスの問題を特定して解決する目的でのみ利用されます。

  • 国
  • 言語、地域
  • 障害や例外の発生日時と、発生以前の最大 100 件のイベント（ユーザーが [概要] 欄を開いたなど）
  • 静的にコンパイルされた例外メッセージ
  • OS の名前とバージョン
  • スマートフォンのモデル（該当する場合）
  • アプリの起動時刻
  • ブラウザ
  • アーキテクチャ
  • Outline のバージョンとビルド番号

上記の情報は、HTTPS 経由でサードパーティのオープンソース エラー トラッキング プロバイダである Sentry（sentry.io）に転送されます。Sentry は業界標準のさまざまテクノロジーやサービスを利用して、ユーザーのデータを不正なアクセス、開示、使用、損失から保護します。Sentry のポリシーについてのご質問は、https://sentry.io/security/ および https://sentry.io/privacy/ をご覧になるか、security@sentry.io までお問い合わせください。Sentry によって保管されるすべての Outline データへのアクセスは、Outline チームのメンバーのみに制限されます。

ユーザーの許可を得た場合にのみ Google が取得する情報​

ユーザーの許可を得られた場合、Outline は以下の情報を Outline チームに報告します。

  1. 使用状況の指標

　　各 Outline サーバーは、過去 1 時間に転送されたバイト数、ユーザーがサーバーに接続していた時間、使用された認証情報の発信元の国および自律システム、一部の機能がオンかオフかの情報を、アクセスキーごとに自動的に収集します。通信の内容や個人を特定できるメタデータ（ログイン、メール、デバイス ID など）はいずれもログに記録されません。指標はすべて、特定のサーバー ID に関連付けられます。サーバー ID を変更する手順については、こちらをご覧ください。

　　

　　デフォルトでは、Outline サーバーはこうした指標を Outline チームと共有しません。使用状況の指標を共有することをサーバー管理者が明示的に許可した場合、これらの情報は 1 時間ごとに Outline チームに安全に送信されます。送信された使用状況の指標は、60 日後に国別に集約されます。サーバー管理者は、Outline マネージャーの [設定] メニューにアクセスして、使用状況の指標の共有設定をいつでも変更できます。

　　

　　Google では、サーバーの使用状況に関する匿名化された指標を、使用状況の傾向の測定やサービスの改善に使用しています。これらの情報の共有にご協力をお願いいたします。

　　

　　たとえば、使用状況の指標を Google と共有することをサーバー管理者が許可した場合、Google は「ID 12345 のサーバーが昨日 3 時間にわたって使用され、米国とカナダで使われている 3 つのキーから、データの上限機能がオンの状態で合計 500 MB のデータが転送された」といった情報を取得します。

  1. ユーザーのコメントとメール（ユーザーがフィードバックを送信した場合）

ユーザーは Outline マネージャーや Outline アプリを使用して、Outline チームにフィードバックを送信できます。フィードバックには個人を特定できる情報を含めないことをおすすめしますが、Outline チームからの返答を希望される場合は、任意でメールアドレス欄を使用できます。Google はユーザーの基本情報もいくつか自動的に収集しますが、これはユーザーからのフィードバックを理解できるようにするためです。Google が収集するデータについては、上記の「Google が自動的に収集する情報」の項目 2 をご覧ください。 Outline でのセキュリティとプライバシーへの対応について詳しくは、こちらをご覧ください。

　　

　　ユーザーが Android で Outline アプリのベータ版を使用している場合、Google は自社の Firebase サービスを使用して、問題の検出と Outline の改善につなげるためのデバッグ情報を収集することがあります。Firebase のプライバシー ポリシーとセキュリティ ポリシーの詳細については、ウェブサイト firebase.google.com/support/privacy をご覧ください。Outline から Firebase を経由してこのような情報が送信されないようにするには、製品版のアプリを使用してください。
