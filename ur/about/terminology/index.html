‫VPN کیا ہے؟​

ورچوئل نجی نیٹ ورک (VPN) آپ کے آلے (آلات) اور میزبان سرور کے درمیان ایک نجی کنکشن ہے۔ جب آپ VPN استعمال کرتے ہیں تو آپ کی ٹریفک انٹرنیٹ فراہم کنندہ سے پوشیدہ رہتی ہے۔ ممکن ہے کہ آپ مندرجہ ذیل منظرناموں میں VPN استعمال کرنا چاہیں:

  • عوامی Wi-Fi نیٹ ورک استعمال کرتے وقت اپنے ڈیٹا کی حفاظت کریں
  • اپنے براؤزنگ ڈیٹا کو اپنے انٹرنیٹ فراہم کنندہ اور سرکاری ایجنسیوں سے نجی رکھیں
  • دنیا بھر کے مختلف ذرائع سے غیر سینسر شدہ مواد تک رسائی حاصل کریں

‫Outline روایتی VPNs سے کیسے مختلف ہے؟​

انٹرنیٹ فراہم۔ کنندگان عام سیکورٹی پروٹوکولز اور/یا ٹریفک والیوم پیٹرنز کی شناخت کر کے روایتی VPNs کو آسانی سے تلاش اور بلاک کر سکتے ہیں۔ ‫Outline روایتی VPNs کے مقابلے میں زیادہ لچکدار ہے کیونکہ اسے ایک ایسے پروٹوکول کا استعمال کرتے ہوئے بنایا گیا ہے جس کا پتہ لگانا مشکل ہے اور اس وجہ سے اسے مسدود کرنا مشکل تر ہے۔ آؤٹ لائن سنسرشپ کی جدید ترین شکلوں کے خلاف مزاحم ہے جس میں نیٹ ورک پر مبنی بلاکنگ اور IP کو مسدود کرنا شامل ہیں۔

‫Outline سرور کیا ہے؟​

‫Outline سرور VPN چلاتا ہے جس سے اجازت یافتہ صارفین منسلک ہوں گے۔ اگر آپ ایک نیا نیٹ تخلیق کر رہے ہیں تو آپ اپنے محفوظ سرور کو اپنے Outline سرور کے طور پر استعمال کر سکتے ہیں اگر آپ کے پاس ہے یا آپ کلاؤڈ سروسز فراہم کنندہ کو استعمال کر سکتے ہیں جیسے:

  • ‫DigitalOcean
  • ‫Google Cloud Platform (GCP)
