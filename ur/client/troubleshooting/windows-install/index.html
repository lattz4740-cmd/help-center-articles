میں Windows پر Outline کلائنٹ انسٹال کیوں نہیں کر سکتا؟

آپ کو یہ خرابی کا پیغام نظر آ سکتا ہے: "معذرت، ایسا لگتا ہے کہ Outline صحیح طریقے سے انسٹال نہیں ہے۔ براہ کرم اسے دوبارہ انسٹال کرنے کی کوشش کریں۔ اگر یہ کام نہیں کرتا ہے تو براہ کرم تاثرات جمع کرائیں۔"

اگر آپ Windows پر Outline استعمال کر رہے ہیں تو آپ کو کبھی کبھار غیر متوقع خرابی کا سامنا کرنا پڑ سکتا ہے۔ بیشتر معاملات میں، Outline TAP اڈاپٹر (ڈرائیور) کو حذف کرنے کی ضرورت پڑ سکتی ہے اور Outline کو دوبارہ انسٹال کیا جانا چاہیے۔

آپ کے Windows آپریٹنگ سسٹم کے ورژن کی بنیاد پر مراحل مختلف ہو سکتے ہیں، لیکن نیچے TAP اڈاپٹر اور Outline اَن انسٹال کرنے اور پھر Outline دوبارہ انسٹال کرنے کے طریقے کیلئے عمومی مراحل دیے گئے ہیں۔

  1. ‫Outline کلائنٹ کیلئے TAP اڈاپٹر اَن انسٹال کریں
    • ڈیوائس مینیجرز پھر نیٹ ورک اڈاپٹرز پر جائیں
    • ‫TAP-Windows Adapter V9 فائل یا Outline کے ساتھ وابستہ TAP اڈاپٹر تلاش کریں
    • یہ اڈاپٹر اَن انسٹال یا حذف کریں۔ ذہن نشین کر لیں کہ یہ آپ کی انسٹال کردہ دیگر VPN ایپس کو متاثر کر سکتا ہے۔
  2. ‫Outline کلائنٹ کو اَن انسٹال کریں
    • پروگرامز اور خصوصیات، پھر پروگرام کو ان انسٹال کریں پر جائیں
    • ‫Outline کلائنٹ ایپ تلاش کریں اور Outline کلائنٹ کو اَن انسٹال کریں
    • ‫Outline کلائنٹ کا تازہ ترین ورژن ڈاؤن لوڈ کریں اور اسے اپنے Windows آلے پر دوبارہ انسٹال کریں۔ نئی انسٹالیشن کو خودکار طور پر ایک نیا TAP اڈاپٹر انسٹال کرنا چاہیے۔

اگر آپ کو ابھی بھی دشواری پیش آ رہی ہے تو سپورٹ سے رابطہ کریں۔
