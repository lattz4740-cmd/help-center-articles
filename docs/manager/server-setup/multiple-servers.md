---
title: How to set up multiple Outline servers
sidebar_label: Multiple servers
---

To set up additional Outline Servers, click on the “+” icon on the navigation panel on the left side of your Outline Manager application. The instructions to add a new server are the same as if you were installing your first.

- We do not have a limit on the number of Outline servers you can create.
- For every Outline server you create, you’ll need a corresponding virtual machine.
- Creating additional machines or droplets may increase your fees with your cloud provider. Please check your pricing package with your cloud provider to make sure you know what to expect.

## Creating an additional Outline server on DigitalOcean

After clicking the + icon and selecting to install on DigitalOcean, you’ll follow the same instructions you did to set up your first server. Also, since Outline Manager integrates with DigitalOcean, we’re able to create the droplet for you without your ever having to leave the Outline Manager app.

Note that Outline Manager can only support one DigitalOcean account at a time. If want to add or create other Outline servers from other DigitalOcean accounts, you can add them as an advanced configuration.

## Creating an additional Outline server on GCP, AWS, or another cloud service provider

Start by creating a new virtual machine with your chosen cloud provider. Then open up Outline Manager and complete the instructions for advanced installation, just like you may have the first time.
