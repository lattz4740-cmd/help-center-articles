Once you've finished installing your Outline server, you can now start sharing and managing people's access to it. People who receive an invitation from you will be able to download the Outline app to use Outline to protect their internet traffic.

## Share access to your Outline server
 After you've finished installing an Outline server, you'll be directed to the server details page on Outline Manager, where you can create access keys. Learn more about [access keys](/about/terminology).

- Create keys: Click the small "+" icon at the bottom of the page to create new keys.
- Share keys: To the right of each key, there's a share icon you can click to get an invitation. Copy and paste this invitation into the messaging system of your choice.

## Feature request: Sharing access from within the Outline Manager app
 A lot of server administrators ask us to streamline the invitation process by giving them the option to enter someone’s email address directly into Outline Manager.

Unfortunately, we are unlikely to build this functionality into Outline Manager. One of our core principles is to support our users’ privacy and security, which means that we didn’t design any place to insert email addresses or contact information.

This is why we ask server administrators to use a secure messaging platform, like email or secure chat, to send the invitation to the end user.

## What the user experiences after you share an access key with them
1. The user will click on the installation link from their device
2. They will be prompted the install Outline app if they don’t already have it
3. They will establish an initial connection to your Outline server via the unique key embedded in the invitation
4. They can now use the connect/disconnect button to manage their access to the internet through your Outline server

## Remove access to your Outline server
 From the server details page in Outline Manager, to the right of every key on the server, you'll see a menu with an option to delete a key. Deleting a key removes their access to your server.
