---
title: "How do I reset my server ID?"
sidebar_label: Reset server ID
---

The server ID is a server-side ID that is randomly generated when you create an Outline server. You can find it when opting into sharing anonymous metrics in the Settings interface. You can locate your server ID from: Settings => scroll to bottom => check "share anonymous metrics".

The server ID ties together anonymous usage statistics reported over time. If you want to reset the server ID and obtain a new one, you’ll need to replace your existing Outline server with a new one.

If you’re using DigitalOcean as your cloud provider, you can reset your server by going to the Settings and selecting Destroy Server. This action is irreversible and will erase your credentials. Immediately following this action, you’ll be prompted to create a new server in a location of your choosing, and a new server ID will be generated.
