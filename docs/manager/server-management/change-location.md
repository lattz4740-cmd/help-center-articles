---
title: "How do I change the location of the Outline server?"
sidebar_label: Change server location
---

Once set up, a server location cannot be changed. To run your server from a different location, you need to delete your Outline server and create a new one.

Alternatively, you can change the location of your VPN using [dynamic keys](https://developers.google.com/outline/docs/guides/service-providers/dynamic-access-keys), which allow you to rotate servers and keep the same keys. The location of the servers themselves will not change.
